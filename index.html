数学重学路线图

几何含义 + 物理含义 · 从初一数学到大学数学（共 74 章）

目标：系统重学 初中 → 高中 → 大学（高等数学 / 线性代数 / 离散数学）全部课程，每个知识点都追问三个问题：
1. 它是什么？（定义、公式、规则）
2. 它的几何含义是什么？（在图形、空间、数轴上长什么样）
3. 它的物理含义是什么？（对应现实世界的什么现象）

学习原则

  • 先直觉，后符号：每个概念先讲它"对应现实里的什么"，再给严格定义。
  • 几何是桥梁：代数与几何互相印证（数形结合）。
  • 物理是土壤：负数来自"亏欠"、方程来自"找平衡"、微积分来自"变化率与累积"。
  • 每章闭环：概念 → 公式 → 动图 → 典型例题 → 常见误区 → 练习卷（含答案）。
