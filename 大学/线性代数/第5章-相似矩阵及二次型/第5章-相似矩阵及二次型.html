第5章 相似矩阵及二次型

大学 / 线性代数

一句话总纲：特征值与特征向量是线性变换的「不变方向 + 伸缩因子」；把矩阵沿这些方向「对角化」就是换到主轴坐标系；而二次型 xᵀAx 在这些主轴方向上被「旋转、消交叉项」成标准形，其正负（惯性指数）决定了曲面形状与能量函数的稳定性——正定即「碗口向上、原点为极小、系统稳定」。

5.1 特征值与特征向量

定义

设 A 是 n 阶方阵。若存在数 λ 与非零列向量 x，使得

A x = λ x

则称 λ 为 A 的特征值（eigenvalue），x 为 A 的对应于 λ 的特征向量（eigenvector）。方程 Ax = λx 可改写为 (λE − A)x = 0，它有非零解 ⟺ 系数行列式为 0：

det(λE − A) = 0     （特征方程）
f(λ) = |λE − A|      （特征多项式）

f(λ) 是 λ 的 n 次多项式，它的根就是全部特征值（重根按重数计，即代数重数）。对每个特征值 λᵢ，解齐次线性方程组 (λᵢE − A)x = 0，得到的非零解就是对应的特征向量；其基础解系的维数称为该特征值的几何重数。

几何含义（本章第一核心）：把方阵 A 看成空间中的一个线性变换（旋转、缩放、剪切、反射…）。方程 Ax = λx 说的是：向量 x 经过变换 A 后，方向不改变（或只反向），仅仅被拉伸/压缩了 λ 倍。因此特征向量就是线性变换的「不变方向」（特征直线），特征值就是沿该方向的「伸缩因子」：λ > 0 表示同向拉伸、0 < λ < 1 表示同向压缩、λ < 0 表示反向再拉伸、λ = 0 表示沿该方向压扁到原点（所以 λ = 0 意味着 A 不可逆）。
物理含义：特征值与特征向量刻画了一个系统的「固有模式」。在振动系统中，特征向量是主振型（各质点按固定比例振动的固有形状），特征值的平方根正比于固有频率；在材料力学里，应力张量的特征向量是主方向、特征值是主应力；在刚体力学里，转动惯量张量的特征轴是主轴；在马尔可夫链与 PageRank 中，转移矩阵特征值 1 对应的特征向量是稳态分布。一句话：特征值 = 固有放大率，特征向量 = 固有模式/主轴。

一个完整算例（后续各节反复使用）

求 A 的特征值与特征向量：

       ┌      ┐
  A =  │ 2  1 │
       │ 1  2 │
       └      ┘

第一步（特征值）：解 |λE − A| = 0
            ┌             ┐
  λE − A =  │ λ−2    −1   │
            │  −1   λ−2   │
            └             ┘
  |λE − A| = (λ−2)² − 1 = λ² − 4λ + 3 = (λ−1)(λ−3) = 0
  ⇒  λ₁ = 1，λ₂ = 3

第二步（特征向量）：
  λ₁ = 1：解 (E − A)x = 0，即 −x₁ − x₂ = 0 ⇒ x = t(1, −1)ᵀ
  λ₂ = 3：解 (3E − A)x = 0，即  x₁ − x₂ = 0 ⇒ x = t(1,  1)ᵀ

检验：tr(A) = 2 + 2 = 4 = 1 + 3（特征值之和 = 迹 ✓）；det(A) = 4 − 1 = 3 = 1 × 3（特征值之积 = 行列式 ✓）。两个特征向量 (1,−1)ᵀ 与 (1,1)ᵀ 正交，这是实对称矩阵的普遍性质。

核心性质

  1. n 阶方阵恰有 n 个特征值（重根按重数计，可能在复数范围）。
  2. 特征值之和 = 迹：λ₁ + λ₂ + … + λₙ = tr(A) = 主对角元之和。
  3. 特征值之积 = 行列式：λ₁λ₂…λₙ = det(A)。由此：A 可逆 ⟺ 所有特征值都不为 0。
  4. 若 λ 是 A 的特征值，则 λᵏ 是 Aᵏ 的特征值；若 A 可逆，则 1/λ 是 A⁻¹ 的特征值。
  5. A 与 Aᵀ 有相同特征值（特征向量一般不同）。
  6. 不同特征值对应的特征向量线性无关。
  7. 属于同一特征值 λ 的所有特征向量，再添上零向量，构成一个子空间——特征子空间（维数 = 几何重数）。
  8. 实对称矩阵：特征值全是实数，且不同特征值对应的特征向量两两正交（这是后面二次型正交标准化的基础）。
几何反例（为什么特征向量不一定存在）：平面旋转 90° 的矩阵 A = [[0,−1],[1,0]]，其特征方程 λ² + 1 = 0 只有复根 λ = ±i，没有实特征值。几何上这是显然的：一个旋转会把每一个方向都转走，不存在「方向不变」的直线，所以没有实特征向量。它暗示：要讨论特征向量，最好在复数域里；而实对称矩阵保证有实特征值与实特征向量。

5.2 相似矩阵与相似对角化

相似的定义与不变量

设 A、B 为 n 阶方阵，若存在可逆矩阵 P，使得

B = P⁻¹ A P

则称 A 与 B 相似，记作 A ∼ B。相似是等价关系，且相似矩阵保持所有「与基选择无关」的量不变：

  • 特征多项式、特征值相同（因此特征值也叫「相似不变量」）；
  • 行列式、迹、秩相同。
几何含义：B = P⁻¹AP 是「换基 → 变换 → 换回」的三段动作：P 把旧坐标换成新坐标（P⁻¹），在新基下用 A 作用，再换回旧坐标。所以 A 与 B 是同一个线性变换在不同基下的矩阵表示。既然变换是同一个，其特征值（伸缩因子）当然不变。
物理含义：同一个物理系统（同一个线性作用）在不同坐标系/不同仪表下的「读数」不同，但系统的固有属性——固有频率、主应力、能量本征值——不变。相似关系就是「换坐标系描述同一个系统」。

相似对角化

若 A 相似于一个对角矩阵 Λ，即存在可逆 P 使

P⁻¹ A P = Λ = diag(λ₁, λ₂, …, λₙ)

则称 A 可对角化。此时 Λ 的对角元恰好是 A 的全部特征值，而 P 的列向量是对应的 n 个线性无关的特征向量。等价写法（特征分解）：

A = P Λ P⁻¹
几何含义：对角化 = 找到一组主轴（特征向量基）。在这组基下，线性变换 A 变得极其简单——它只是沿每个坐标轴独立地伸缩（对角元就是各轴方向的伸缩因子 λᵢ），交叉作用全部消失。形象地说：原来 A 是「边旋转边斜着拉扯」，换到主轴坐标系后变成了「规规矩矩地沿三根轴分别拉伸/压缩/翻转」。
物理含义：对角化就是解耦。一个耦合的多自由度系统（各变量相互牵制），通过坐标变换 P 被分解成 n 个彼此独立的「正则模式」：每个模式独自按自己的固有频率振动、独立地衰减或增长。A = PΛP⁻¹ 读作「进入主轴系 → 各模式独立缩放 → 回到原坐标系」。

可对角化的判定

  1. 充要条件：A 有 n 个线性无关的特征向量。
  2. 充分条件：A 有 n 个互不相同的特征值 ⇒ A 必可对角化（但反过来不成立）。
  3. 充要条件（重数角度）：每个特征值的几何重数 = 代数重数。几何重数 < 代数重数时，特征向量「不够数」，不可对角化（此时最多化成若尔当标准形，本章不展开）。
  4. 重要特例：实对称矩阵一定可以对角化，且可以正交对角化（即存在正交矩阵 Q 使 Q⁻¹AQ = QᵀAQ = Λ）。

对角化为什么有用：快速求幂 Aᵏ

若 A = PΛP⁻¹，则 Aᵏ = P Λᵏ P⁻¹ = P diag(λ₁ᵏ, λ₂ᵏ, …, λₙᵏ) P⁻¹

这使矩阵高次幂、差分方程 xₖ₊₁ = A xₖ 的迭代、线性微分方程组 x′ = A x 的求解都化为「对每个独立模式单独做 λᵏ 或 e^(λt)」。例：斐波那契数列 Fₖ₊₂ = Fₖ₊₁ + Fₖ 用矩阵 [[1,1],[1,0]] 对角化，即可得到闭式通项（含黄金比 φ = (1+√5)/2）。

几何含义再概括：对 Aᵏ 来说，对角化把「k 次复合变换」拆成「换到主轴 → 每根轴伸缩 λᵏ 倍 → 换回来」。λ 的绝对值决定该主轴方向是增长（|λ| > 1）、衰减（|λ| < 1）还是保持（|λ| = 1）——这正是动力系统稳定性的几何判据。

5.3 二次型及其标准形

二次型与对称矩阵的一一对应

只含平方项与交叉乘积项、每项都是 2 次的 n 元齐次多项式，称为二次型。任何二次型都可唯一地写成

f(x₁, x₂, …, xₙ) = xᵀ A x     （要求 A 为对称矩阵）

其中交叉项系数被对半分给 A 的两个对称位置。例：f = 2x₁² + 2x₁x₂ + 2x₂² 对应

       ┌      ┐          ┌     ┐
  A =  │ 2  1 │    x =   │ x₁  │
       │ 1  2 │          │ x₂  │
       └      ┘          └     ┘
（2x₁x₂ 的系数 2 拆成 a₁₂ = a₂₁ = 1）
几何含义：二次型是二次曲面（二次曲线）的方程左端。平面上的二次曲线 ax² + 2bxy + cy² + 低次项 = 0，其形状完全由齐次二次部分（椭圆、双曲线、抛物线）决定；空间中的二次曲面（椭球面、双曲面、锥面…）同理。交叉项 xy 的出现意味着坐标轴与曲面的主轴不重合（曲面「斜放着」）。
物理含义：二次型几乎等同于能量：质点的动能 T = ½mvᵀv、多自由度小振动的势能 V = ½xᵀKx（K 为刚度矩阵）、刚体转动动能 T = ½ωᵀIω（I 为转动惯量张量）、电网络的功率、最小二乘误差都是二次型。因此研究二次型的「标准形」就是研究能量在什么坐标下最简单。

化标准形的两种方法

通过可逆线性变换 x = Cy（C 可逆），二次型化为只含平方项的标准形：

f = λ₁y₁² + λ₂y₂² + … + λᵣyᵣ²   （r = rank(A)）

方法一：配方法（拉格朗日配方法）——逐步配方消去交叉项，适用于含平方项的一般情形。

方法二：正交变换法（主轴法，最本质）——因 A 实对称，存在正交矩阵 Q 使 QᵀAQ = Λ = diag(λ₁,…,λₙ)。令 x = Qy，则

f = xᵀAx = yᵀ(QᵀAQ)y = yᵀΛy = λ₁y₁² + λ₂y₂² + … + λₙyₙ²

标准形的系数就是 A 的全部特征值，Q 的列是对应的正交单位特征向量。

几何含义（主轴定理）：正交变换 x = Qy 是旋转（或反射）坐标轴，它保持长度与夹角不变。化标准形 = 把坐标轴旋转到曲面的主轴方向，于是交叉项全部消失，曲面「摆正」，方程变成主轴上的标准形式。例如上例 f = 2x₁² + 2x₁x₂ + 2x₂² 经特征值 λ = 1, 3 化为 f = y₁² + 3y₂²：曲线 f = 1 是一个椭圆，其长短轴沿特征向量方向 (1,−1) 与 (1,1)（即旋转了 45°），半轴长分别为 1/√1 与 1/√3。
物理含义：正交变换法 = 转到「主轴/主方向」坐标系。转动惯量张量对角化给出主转动惯量与主轴；小振动系统的刚度矩阵对角化给出各主振型的等效刚度，使总能量写成各独立模式能量之和 E = ½Σλᵢyᵢ²——交叉耦合消失，每个模式可单独分析。

惯性定理（标准形不唯一，但「正负个数」唯一）

二次型的标准形不唯一（配方法、不同变换得到的系数可以不同），但惯性定理保证：无论用何种可逆线性变换化标准形，正系数个数 p（正惯性指数）与负系数个数 q（负惯性指数）都是唯一确定的。记 r = rank(A)，则 p + q = r，p − q 称为符号差。进一步可化为规范形（系数只取 ±1 或 0）：

f = z₁² + … + z_p² − z_{p+1}² − … − z_r²
几何含义：惯性指数 p、q 是二次曲面（曲线）的「型」的完整刻画：平面二次曲线中，正惯性指数决定它本质上是椭圆（p=2）还是双曲线（p=q=1）还是抛物线退化（r<2）；空间二次曲面中 p、q 决定是椭球面、单叶/双叶双曲面还是锥面。缩放、旋转都改变不了这个「型」，只有 p、q 是本质的。

矩阵合同

若存在可逆矩阵 C 使 B = CᵀAC，则称 A 与 B 合同。二次型经可逆线性变换 x = Cy 后，矩阵由 A 变为 CᵀAC，所以「二次型化标准形」=「把对称矩阵合同对角化」。正交变换是合同的特例（此时 Cᵀ = C⁻¹，合同与相似重合）。

5.4 正定二次型

定义

实二次型 f = xᵀAx：若对任意非零向量 x，都有 f(x) > 0，则称 f 为正定二次型，对称矩阵 A 为正定矩阵，记作 A ≻ 0。类似可定义：

类型条件（对任意 x ≠ 0）例子 f(x₁,x₂)
正定f(x) > 0x₁² + 2x₂²
负定f(x) < 0−x₁² − x₂²
半正定f(x) ≥ 0（有非零 x 使 =0）x₁²
半负定f(x) ≤ 0（有非零 x 使 =0）−x₂²
不定有 x 使 f>0，也有 x 使 f<0x₁² − x₂²
几何含义：正定二次型 f(x) = xᵀAx 的图像是「原点处开口向上的碗」：原点 f(0)=0 是严格的全局极小点，沿任何方向离开原点函数值都增大。它的等值面 f(x) = c > 0 是椭球面（椭球壳）——因为正定 ⟺ 所有特征值 λᵢ > 0，标准形 f = Σλᵢyᵢ² 中每个主轴方向的「曲率」都为正，等值面就是各半轴长 1/√λᵢ 的椭球。不定二次型（如 x₁² − x₂²）则对应马鞍面：原点是鞍点，沿某方向升高、沿另一方向降低。
物理含义：正定 ⟺ 能量的严格极小 ⟺ 稳定平衡。弹簧势能 V = ½kx²（k>0）正定，故平衡位置稳定；刚体转动动能 T = ½ωᵀIω 中转动惯量张量 I 恒正定（能量必为正）；最小二乘的误差平方和、协方差矩阵、刚度矩阵、质量矩阵也都是正定的。若势能矩阵在某平衡点不定，则该平衡点不稳定（如倒立摆、马鞍势）。

正定的判定（五个等价条件）

设 A 为实对称矩阵，下列命题两两等价：

  1. A 正定（定义：x ≠ 0 时 xᵀAx > 0）；
  2. A 的全部特征值都大于 0；
  3. A 的各阶顺序主子式全大于 0（Sylvester / 赫尔维茨判据）；
  4. 正惯性指数 p = n（规范形全为 + 号）；
  5. A 与单位阵 E 合同，即存在可逆 C 使 A = CᵀC。

    6. 顺序主子式：取 A 左上角的 k×k 子块的行列式 Δₖ（k = 1, 2, …, n）。例：

           ┌      ┐
  A =  │ 2  1 │   Δ₁ = 2 > 0，Δ₂ = |A| = 3 > 0  ⇒ A 正定 ✓
       │ 1  2 │
       └      ┘

       ┌      ┐
  B =  │ 1  2 │   Δ₁ = 1 > 0，Δ₂ = |B| = 1−4 = −3 < 0  ⇒ B 不定（特征值 3, −1）
       │ 2  1 │
       └      ┘

    常用推论：正定矩阵的主对角元全为正（必要条件，但不充分）；负定 ⟺ A 的奇数阶顺序主子式为负、偶数阶为正（即 −A 正定）。

    本章 · 几何与物理含义总结

    概念几何含义物理含义
    特征值 λ线性变换沿特征方向的伸缩因子系统的固有放大率（固有频率²、主应力、能量本征值）
    特征向量 x变换下方向不变的直线（不变方向/特征轴）固有模式：主振型、主轴、主方向、稳态分布
    特征方程 |λE−A|=0求「存在不变方向」的条件求系统的固有值（本征值方程）
    相似 B=P⁻¹AP同一变换在不同基下的表示同一系统换坐标系描述，固有属性不变
    相似对角化找到主轴系，变换变为沿各轴独立缩放解耦：把耦合系统分解为独立正则模式
    Aᵏ = PΛᵏP⁻¹每根主轴方向按 λᵏ 独立伸缩迭代/动力系统的增长、衰减与稳定性
    二次型 xᵀAx二次曲线/曲面的方程左端（形状）能量：动能、势能、转动惯量、误差平方和
    化标准形（正交变换）旋转坐标轴到主轴，消去交叉项转到主方向，能量写成各独立模式之和
    惯性指数 p, q曲面「型」的本质：椭圆/双曲线/马鞍面能量函数正负模式的数目（本质不变量）
    合同 B=CᵀAC二次型在不同基下的矩阵关系同一能量函数换坐标后的矩阵表示
    正定二次型原点为严格极小的「碗」；等值面为椭球能量正定 ⟺ 稳定平衡、正定惯性/刚度张量
    顺序主子式判据各维子空间截口都「开口向上」沿任意方向能量都增大的代数判定

    典型例题（自测）

    1. 求 A = [[3,1],[0,2]] 的特征值、特征向量；它是否可对角化？写出 P 与 Λ。
    2. 已知 3 阶方阵 A 的特征值为 1, 2, −3，求 det(A)、tr(A)、det(A⁻¹)、A² 的特征值，并判断 A 是否可逆、是否可对角化。
    3. 判断 A = [[1,2],[2,1]] 是否可对角化；求 P 使 P⁻¹AP 为对角阵（或说明不可）。
    4. 用正交变换化 f = 3x₁² + 2x₁x₂ + 3x₂² 为标准形，写出正交矩阵 Q 与标准形，并说明曲线 f = 1 的类型与主轴方向。
    5. 用配方法化 f = x₁² + 2x₁x₂ + 2x₂² 为标准形，并与正交变换法比较系数。
    6. 判定下列矩阵的正定性：[[2,−1],[-1,2]]、[[1,2],[2,1]]、[[2,1,0],[1,3,0],[0,0,5]]。
    7. 设 f = x₁² + x₂² + x₃² + 2x₁x₂ + 2x₁x₃，求正惯性指数、负惯性指数与符号差。
    8. 若 A 正定，证明 A⁻¹ 也正定、A 的主对角元全为正。

    常见误区

    • ❌ 「特征向量可以取零向量」→ ❌ 定义要求 x 必须非零；零向量满足 Ax = λx 恒成立，无意义。
    • ❌ 「特征值都不为 0」→ ❌ λ = 0 完全可以是特征值；它恰好对应「A 不可逆」（det A = 特征值之积 = 0）。
    • ❌ 「n 个不同特征值才可对角化」→ ❌ 这是充分不必要条件；有重特征值时只要「几何重数 = 代数重数」仍可对角化。
    • ❌ 「相似矩阵有相同的特征向量」→ ❌ 相似矩阵特征值相同，但特征向量一般不同（只是经过 P 的变换）。
    • ❌ 「二次型的矩阵随便怎么写都行」→ ❌ 二次型与对称矩阵一一对应；交叉项系数必须对半拆分到对称位置。
    • ❌ 「配方法得到的标准形是唯一的」→ ❌ 标准形不唯一；唯一的是正、负惯性指数 p、q（惯性定理）。
    • ❌ 「正定矩阵只要主对角元全为正」→ ❌ 主对角元为正只是必要条件；如 [[1,2],[2,1]] 对角元都正但不定，必须用顺序主子式全 > 0 判定。
    • ❌ 「正交变换会改变向量的长度」→ ❌ 正交变换保持长度与夹角（只是旋转/反射），因此化标准形只「摆正」曲面、不改变形状。
    • ❌ 「实对称矩阵的特征值可能是复数」→ ❌ 实对称矩阵特征值必为实数，且可正交对角化。

    本章练习卷（含答案）

    一、练习题

    1. 设 A = [[2,1],[1,2]]，判断向量 α₁=(1,1)ᵀ、α₂=(1,−1)ᵀ 是否为 A 的特征向量；若是，写出对应特征值，并说明其几何含义（「不变方向」与「伸缩因子」）。
    2. 已知 3 阶方阵 A 的特征值为 2、−1、3，求 tr(A)、det(A)、A² 的特征值，并判断 A 是否可逆。
    3. 平面旋转 90° 的矩阵 A = [[0,−1],[1,0]] 为什么没有实特征值？请用「不变方向」的几何意义解释，并说明这与「实对称矩阵必有实特征值」是否矛盾。
    4. 设 A = [[3,1],[0,2]]，求特征值与特征向量，判断 A 是否可对角化；若可，写出 P 与 Λ 使 P⁻¹AP = Λ。
    5. 用正交变换化二次型 f = 3x₁² + 2x₁x₂ + 3x₂² 为标准形，写出正交矩阵 Q、标准形，并说明曲线 f = 1 的类型与主轴方向。
    6. 判断矩阵 B = [[2,−1],[−1,2]] 与 C = [[1,2],[2,1]] 是否正定（分别用顺序主子式与特征值两种方法），并从物理角度解释「正定 ⟺ 稳定平衡、原点为严格极小」。

    二、参考答案（点击展开）

    查看第1题答案

    α₁=(1,1)ᵀ 是特征向量：Aα₁ = (3,3)ᵀ = 3·(1,1)ᵀ，对应 λ = 3；α₂=(1,−1)ᵀ 也是：Aα₂ = (1,−1)ᵀ = 1·(1,−1)ᵀ，对应 λ = 1。几何上，沿这两个方向线性变换只做伸缩（分别拉伸 3 倍、1 倍）而不改变方向，即它们是该变换的「不变方向（主轴）」，特征值即伸缩因子。

    查看第2题答案

    tr(A) = 2 + (−1) + 3 = 4；det(A) = 2 × (−1) × 3 = −6 ≠ 0，故 A 可逆；A² 的特征值为各特征值的平方：2²=4、(−1)²=1、3²=9。

    查看第3题答案

    特征方程为 λ² + 1 = 0，只有复根 λ = ±i。几何上，旋转 90° 把每一个方向都转走，不存在「方向不变」的直线，故没有实特征向量（也就没有实特征值）。这不矛盾：实对称矩阵才保证有实特征值，一般的实矩阵可以有复特征值。

    查看第4题答案

    特征多项式 |λE−A| = (λ−3)(λ−2)，故 λ₁ = 3、λ₂ = 2。对 λ=3：解 (3E−A)x=0 得 x₂=0，取 x = t(1,0)ᵀ；对 λ=2：得 x₁+x₂=0，取 x = t(−1,1)ᵀ。两个特征向量线性无关，故 A 可对角化：P = [[1,−1],[0,1]]，Λ = diag(3,2)，且 P⁻¹AP = Λ。

    查看第5题答案

    二次型对应对称矩阵 A = [[3,1],[1,3]]，特征值 λ₁ = 2、λ₂ = 4，对应的正交单位特征向量为 (1/√2)(1,−1)ᵀ 与 (1/√2)(1,1)ᵀ。取 Q = (1/√2)[[1,1],[−1,1]]，则 x = Qy 化为标准形 f = 2y₁² + 4y₂²。曲线 f = 1 是椭圆，主轴沿 (1,−1) 与 (1,1) 方向（相对坐标轴旋转 45°），半轴长分别为 1/√2 与 1/2。

    查看第6题答案

    B：顺序主子式 Δ₁=2>0、Δ₂=4−1=3>0 ⇒ 正定（特征值 1、3 均 > 0）。C：Δ₁=1>0、Δ₂=1−4=−3<0 ⇒ 不定（特征值 3、−1，一正一负）。物理上，正定二次型的图像是原点处开口向上的「碗」，原点为严格极小，能量正定 ⟺ 稳定平衡；不定二次型对应马鞍面，原点为鞍点，平衡不稳定。
