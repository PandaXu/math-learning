第4章 向量组的线性相关性

大学 / 线性代数

一句话总纲：本章回答一个根本问题——「一组向量里，有几个是"多余的"，有几个是"真正独立的"？」线性无关的向量彼此"方向不冗余"，极大无关组把它们能撑开的空间压缩到最少，向量空间则是这个"可张成"世界的完整舞台。掌握本章，你就能在任何维度里数清"独立自由度"。

4.1 向量与向量组

n 维向量的定义

由 n 个有顺序的数 a₁, a₂, ⋯, aₙ 组成的有序数组，称为一个 n 维向量，这 n 个数称为它的 分量，第 i 个数 aᵢ 叫第 i 个分量。通常记作（列向量）：

         ┌ a₁ ┐
         │ a₂ │
   α  =  │ ⋮  │    （或写成行向量  α = (a₁, a₂, …, aₙ)）
         └ aₙ ┘

分量全为零的向量叫 零向量，记作 0；分量全为实数的向量叫实向量（本章默认实向量）。两个 n 维向量 相等，当且仅当它们对应分量都相等。向量的 线性运算：加法（对应分量相加）与数乘（每个分量同乘一个数）。

几何含义：在平面（n=2）与空间（n=3）中，向量就是一个有长度、有方向的箭头（有向线段）：分量给出它沿各坐标轴投影的长度。n 维向量把"箭头"从看得见的 2、3 维抽象到任意维——你虽然画不出 4 维，但"方向 + 长度 + 可加减可伸缩"的直觉原封不动。零向量就是长度为零、没有方向的"点"。
物理含义：向量就是一切"既有大小又有方向"的物理量的数学化身：力、速度、加速度、位移、动量、电场强度。分量的加减数乘对应"把几个力按分量合成、把力放大 k 倍"。

向量组

若干个同维数的向量放在一起，就构成一个 向量组。例如由 m 个 n 维向量组成的向量组记作：

  A : α₁, α₂, …, αₘ

向量组可以有限（本章主要研究），也可以无限。一个 m×n 矩阵既可以看成 m 个行向量（每个行向量是 n 维），也可以看成 n 个列向量（每个列向量是 m 维）——矩阵与向量组是一体两面，这是本章一切判别的桥梁。

几何含义：一个向量组就是空间中的一组箭头（都从原点出发）。向量组的问题本质是：这组箭头里有没有"多余"的方向？它们合起来能铺满多大的空间？
物理含义：向量组对应作用在同一点上的一组力、一组速度、一组观测数据。接下来要研究的"相关性"，就是问：其中某个力是不是其余力的合力（可以被拆掉）？

4.2 线性组合与线性表示

线性组合

给定向量组 A : α₁, α₂, …, αₘ 和一组实数 k₁, k₂, …, kₘ，称向量

  β = k₁α₁ + k₂α₂ + ⋯ + kₘαₘ

为向量组 A 的一个 线性组合，k₁, …, kₘ 称为 组合系数。若向量 β 能写成上面这种形式，就说 β 可由向量组 A 线性表示（或说 β 是 A 的线性组合）。

几何含义：k₁α₁ + k₂α₂ 就是把 α₁ 拉长/压缩/反向 k₁ 倍、α₂ 拉长 k₂ 倍，再按平行四边形法则相加：它是"以 k₁α₁、k₂α₂ 为邻边的平行四边形的对角线"。因此 两个不共线的向量 α₁、α₂ 的一切线性组合能铺满整个平面（取遍所有系数 k₁、k₂，终点扫过整个平面）。一个向量 β 能被 α₁、α₂ 表示 ⇔ β 落在这个平面内。
物理含义：线性组合就是力的合成（平行四边形法则）："β 可由 α₁、α₂ 表示"意为——合力 β 可以分解成沿 α₁、α₂ 两个方向的分力，k₁、k₂ 就是各分力的大小。

两个基本问题

  1. 表示问题：给定 β 与向量组 A，问 β 能否由 A 线性表示？若能，系数是否唯一？——这对应线性方程组 k₁α₁ + ⋯ + kₘαₘ = β 是否有解、解是否唯一。
  2. 等价问题：若两组向量能互相线性表示，称它们等价（记作 A ≅ B）。等价的向量组"撑开同样的空间"。
几何含义："β 能否由 A 表示"就是问 β 是否落在 A 张成的子空间内；"两组向量等价"就是问它们张成的是同一个子空间。

4.3 线性相关与线性无关

定义（本章核心）

给定向量组 A : α₁, α₂, …, αₘ，若存在不全为零的数 k₁, k₂, …, kₘ，使得

  k₁α₁ + k₂α₂ + ⋯ + kₘαₘ = 0

则称向量组 A 线性相关；否则（即只有当 k₁ = k₂ = ⋯ = kₘ = 0 时才成立），称向量组 A 线性无关。

等价表述：线性相关 ⇔ 其中至少有一个向量可由其余向量线性表示；线性无关 ⇔ 任何一个向量都不能由其余向量线性表示。

几何含义：两个向量线性相关 ⇔ 它们共线（一个在另一个所在的直线上）；两个向量线性无关 ⇔ 它们不共线，能撑开一个平面。三个向量线性相关 ⇔ 它们共面（三个箭头都落在同一平面内，其中一个能被另外两个"拼"出来）；三个向量线性无关 ⇔ 它们不共面，能撑起整个三维空间。于是「线性无关」=「方向互不冗余，能撑开更高一维」，每加一个真正无关的向量，维度就多一层。
物理含义：线性相关 = 有冗余的力：其中一个力恰好是其余力的合力，拆掉它信息不丢。线性无关 = 一组彼此独立的分量/自由度：谁也代替不了谁，缺一个就少覆盖一个维度。工程师口中的"独立方程"、"独立自由度"，正是线性无关。

几个重要结论（记牢）

  • 含零向量必相关：只要向量组里有一个零向量 0，它必线性相关（取该零向量系数为 1、其余为 0 即可）。
  • 个数超过维数必相关：m 个 n 维向量，若 m > n，必线性相关（"m 个箭头挤在 n 维空间里，必有冗余"）。
  • 部分相关 ⇒ 整体相关；逆否命题 整体无关 ⇒ 部分无关。
  • 两个向量线性相关 ⇔ 对应分量成比例（共线）。
  • 向量组线性相关 ⇔ 以它们为列构成的矩阵的 秩 < 向量个数；线性无关 ⇔ 秩 = 向量个数。

用行列式 / 秩判别

把 m 个 n 维向量排成一个 n×m 矩阵 A = (α₁, α₂, …, αₘ)，解齐次方程组 Ax = 0：

  • 若 Ax = 0 只有零解 ⇔ 向量组线性无关；
  • 若 Ax = 0 有非零解 ⇔ 向量组线性相关。

特别地，n 个 n 维向量构成方阵 A，则：

  A 的向量组线性无关  ⇔  det(A) ≠ 0  ⇔  A 可逆
  A 的向量组线性相关  ⇔  det(A) = 0
几何含义：det(A) 是这 n 个向量张成的"平行多面体"的带符号体积（二维就是平行四边形面积，三维就是平行六面体体积）。体积 ≠ 0 ⇔ 向量不共面/不共线，真正撑满 n 维；体积 = 0 ⇔ 它们被"压扁"进低一维，于是线性相关。
物理含义：行列式非零表示 n 个力（或 n 组测量）线性独立、信息不冗余，是判断"方程组是否有唯一解""坐标系是否可逆"的试金石。

4.4 极大无关组与向量组的秩

极大无关组

设 A₀ 是向量组 A 的一个部分组，若满足两条：

  1. 无关：A₀ 本身线性无关；
  2. 极大：向 A₀ 中再添入 A 的任何一个其余向量，所得的新向量组都线性相关；

则称 A₀ 为向量组 A 的一个 极大（线性）无关组（最大无关组）。

性质：

  • A 的任一向量都可由极大无关组线性表示（因此极大无关组与 A 等价）；
  • 极大无关组是"能从 A 里挑出的、仍能表示出整个 A 的最少向量"；
  • 极大无关组一般不唯一，但所含向量个数唯一。
几何含义：向量组 A 张成一个子空间（过原点的直线/平面/空间），极大无关组就是这个子空间的一组"基"——用最少的箭头撑起同一片空间。不唯一，好比同一平面可以选"东+北"当坐标轴，也可以选"东北+西北"，但基里箭头个数（维数）不变。
物理含义：从一组力/信号里剔除所有冗余、保留真正独立的分量，极大无关组就是"最小独立集"——既不多余（无关），又不遗漏（极大，能表示其余全部）。

向量组的秩

向量组 A 的极大无关组所含向量的个数，称为向量组 A 的秩，记作 R(A) 或 rank(A)。规定只含零向量的向量组秩为 0。

关键事实：把 A 排成矩阵，则向量组的秩 = 该矩阵的秩 = 该矩阵行/列阶梯形中非零行的个数。因此求秩就用初等行变换化阶梯形。

结论：m 个向量线性无关 ⇔ R(A) = m；线性相关 ⇔ R(A) < m。

几何含义：秩 = 向量组张成的子空间的维数。三个共面但不全共线的向量：秩 = 2（只撑开一个平面）；三个不共面向量：秩 = 3（撑满空间）。秩告诉你这组箭头"实际占据了几维"。
物理含义：秩 = 一组物理量/方程组中独立信息的个数（独立方程数、独立自由度、独立约束数）。秩小于向量个数，就说明存在线性冗余（某些方程/测量可由其余推出）。

4.5 向量空间

向量空间（线性空间）的定义

设 V 是一个非空集合，其中定义了加法（V 中任意 α、β 的和仍在 V 中）与数乘（实数 k 乘 V 中向量仍在 V 中），且满足八条运算规律，则称 V 为数域（实数域 ℝ）上的 向量空间（线性空间）。八条规律为：

  加法：α+β = β+α             (交换律)
        (α+β)+γ = α+(β+γ)     (结合律)
        存在零元 0，α+0 = α
        存在负元 −α，α+(−α) = 0
  数乘：1·α = α
        k(lα) = (kl)α
        (k+l)α = kα + lα
        k(α+β) = kα + kβ

全体 n 维实向量的集合 ℝⁿ（按通常的向量加法与数乘）是最重要的向量空间。本章"向量组张成的空间"就是 ℝⁿ 的子集。

几何含义：向量空间就是过原点的"整片"直线、平面或整个空间（及高维推广）——之所以必须过原点，是因为加法与数乘要求 0 一定在 V 里。ℝ¹ 是一条直线，ℝ² 是整个平面，ℝ³ 是我们生活的三维空间；ℝⁿ 是"看不见但可算"的 n 维空间。
物理含义：向量空间 = 某一类物理量所有可能取值的全集：所有可能的力构成一个向量空间（两个力的合力还是力，力放大 k 倍还是力）。"线性叠加原理"成立的一切系统（力、电场、量子态、信号），其状态都住在某个向量空间里。

子空间、基、维数与坐标

  • 子空间：V 的非空子集 W 若对加法与数乘封闭（α、β∈W ⇒ α+β∈W，kα∈W），则 W 是 V 的子空间。例：过原点的直线、平面是 ℝ³ 的子空间；不过原点的直线、平面不是子空间。
  • 基：向量空间 V 中一组线性无关、且能表示出 V 中一切向量的向量组，称为 V 的一组基。基就是"整片空间"的极大无关组。
  • 维数：V 的基所含向量个数，记 dim V。ℝⁿ 的维数是 n。
  • 坐标：给定基后，V 中任一向量 α 可唯一写成 α = x₁ε₁ + ⋯ + xₙεₙ，称 (x₁, …, xₙ) 为 α 在该基下的坐标。
几何含义：基 = 坐标轴（方向尺子），坐标 = 沿各坐标轴的投影长度。选不同的基相当于换一套坐标轴（旋转/斜放），同一个点坐标不同，但"轴的根数 = 维数"永远不变。ℝ³ 的标准基 e₁、e₂、e₃ 就是 x、y、z 三根坐标轴。
物理含义：基 = 一套正交/独立的测量方向，坐标 = 物理量在该方向上的分量读数（力的 Fx、Fy、Fz）。维数 = 描述该系统最少需要几个独立参数。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
n 维向量有长度、有方向的箭头（2、3 维可画，n 维抽象推广）力、速度、位移等"有大小有方向"的量
向量组空间中的一组箭头作用在同一点的一组力 / 一组观测数据
线性组合拉伸压缩后按平行四边形法则合成（对角线）力的合成与分解（分力→合力）
线性表示目标向量落在向量组张成的子空间内合力能被分解成若干分力
线性相关共线（两向量）、共面（三向量），方向有冗余存在冗余的力/方程，可被其余代替
线性无关不共线 / 不共面，能撑开更高一维独立分量、独立自由度、独立信息
极大无关组撑起同一子空间的"最少箭头"，即一组基剔除冗余后的最小独立集
向量组的秩张成子空间的维数独立信息/独立方程的个数
行列式判据平行多面体的带符号体积（=0 即被压扁）是否线性独立、方程组是否唯一可解
向量空间过原点的直线/平面/整个空间（ℝⁿ）某类物理量全部可能状态的集合
基与维数坐标轴与空间维数独立测量方向与所需最少参数个数
坐标沿各坐标轴的投影长度分量读数（如力的 Fx、Fy、Fz）

典型例题（自测）

  1. 判断向量组 α₁=(1,2,3)ᵀ，α₂=(2,4,6)ᵀ，α₃=(1,0,1)ᵀ 是否线性相关；若相关，找出其中的线性表示关系。
  2. 求向量组 α₁=(1,1,1)ᵀ，α₂=(0,1,1)ᵀ，α₃=(0,0,1)ᵀ，α₄=(1,2,3)ᵀ 的秩，并求一个极大无关组，把其余向量用它线性表示。
  3. 问 β=(1,3,−2)ᵀ 能否由 α₁=(1,0,0)ᵀ，α₂=(0,1,0)ᵀ，α₃=(1,1,1)ᵀ 线性表示？若能，表示是否唯一？
  4. 设 α₁、α₂、α₃ 线性无关，证明：β₁=α₁+α₂，β₂=α₂+α₃，β₃=α₃+α₁ 也线性无关。
  5. 判断集合 W = { (x, y, z)ᵀ | x + y + z = 0 } 是否为 ℝ³ 的子空间；若是，求它的一组基和维数。
  6. 用行列式判断向量组 (1,1,1)ᵀ、(1,2,3)ᵀ、(1,3,6)ᵀ 是否线性无关。

常见误区

  • ❌ "线性相关就是每个向量都能被其余向量表示" → ❌ 正确是「至少存在一个」向量可被其余表示；全体都能被表示是更强的条件。
  • ❌ "向量两两不共线，整组就线性无关" → ❌ 线性无关是整体概念：三个向量可以两两不共线却仍共面而相关。须看整体能否组合出零向量。
  • ❌ "向量个数 = 维数时必线性无关" → ❌ 还需行列式 ≠ 0（或秩 = 个数）。例如 (1,1)ᵀ 与 (2,2)ᵀ 共线，虽个数=维数=2 却相关。
  • ❌ "极大无关组是唯一的" → ❌ 一般不唯一，但所含向量个数（秩）唯一。例如平面内可任选两条不共线向量作极大无关组。
  • ❌ "向量组的秩就是向量个数" → ❌ 秩 = 极大无关组的个数，只有向量组线性无关时才等于向量个数。
  • ❌ "零向量组也有极大无关组" → ❌ 只含零向量的向量组没有极大无关组，规定其秩为 0。
  • ❌ "子空间不必过原点" → ❌ 子空间必须对加法、数乘封闭，故一定含零向量、一定过原点。不过原点的直线/平面不是子空间。
  • ❌ "线性相关 ⇒ 行列式为 0（任何情况）" → ❌ 行列式判据只对 n 个 n 维向量（方阵）成立；一般情形统一用秩判断。

查看第2题答案

线性相关。依据"含零向量必相关"：取系数 k₁=0、k₂=1、k₃=0（不全为零），则 0·α₁ + 1·α₂ + 0·α₃ = 0。物理上零向量是"大小为 0 的力"，对张成空间毫无贡献，属于冗余分量。

查看第3题答案

查看第5题答案

线性相关。排成矩阵求行列式：det = 1·(0·0 − (−1)·1) − 2·(1·0 − (−1)·1) + 1·(1·1 − 0·1) = 1 − 2 + 1 = 0。几何上这三个向量张成的平行六面体体积为 0，即三向量共面、被"压扁"进低一维，故不撑满三维空间。

查看第6题答案

是 ℝ³ 的子空间。W 对加法、数乘封闭：若 α=(x,y,z)ᵀ、β=(x′,y′,z′)ᵀ ∈ W，则 2(x+x′) − (y+y′) + (z+z′) = (2x−y+z) + (2x′−y′+z′) = 0 + 0 = 0；kα 同理。取基 {(1,2,0)ᵀ, (0,1,1)ᵀ}（验证 2·1−2+0=0、2·0−1+1=0，且二者不共线），故 dim W = 2。几何上 W 是 ℝ³ 中过原点的一张平面。
