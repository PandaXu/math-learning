第2章 矩阵及其运算

大学 / 线性代数

一句话总纲：矩阵是「线性变换」的记法，也是「批量数据」的容器——它把一组数打包成一张表，加、乘、求逆这些运算的本质，分别对应「合成变换」「复合变换」「把变换倒回去」，而分块矩阵则是「把大系统拆成子系统」的思想。

2.1 矩阵的概念

定义

由 m × n 个数 aij（i = 1,2,…,m；j = 1,2,…,n）排成的 m 行 n 列的数表，称为一个 m×n 矩阵，记作：

        ⎡ a₁₁  a₁₂  ⋯  a₁ₙ ⎤
        ⎢ a₂₁  a₂₂  ⋯  a₂ₙ ⎥
  A  =  ⎢  ⋮    ⋮    ⋱    ⋮  ⎥  =  (aᵢⱼ)_{m×n}
        ⎣ aₘ₁  aₘ₂  ⋯  aₘₙ ⎦
  • 元素 aij：位于第 i 行、第 j 列的数（行标在前，列标在后）。
  • 行数 m、列数 n 决定矩阵的「型」（形状），两个矩阵同型才能谈相等。
  • 矩阵相等：A = B ⟺ 同型且对应元素全部相等。
  • 矩阵常用大写字母 A、B、C 表示，元素用小写字母表示。

矩阵 vs 行列式（务必分清）

对象本质记号是否算出一个数
矩阵一张数表（m 行 n 列）圆括号或方括号 ( ) / [ ]否，它本身就是一个整体对象
行列式一个数值（只对方阵定义）两条竖线 | |是，按规则算出一个数
核心直觉：矩阵是「表格 / 变换」，行列式是「这个方阵的一个特征数」。例如 |A| = 0 说的是「这个变换把体积压成了 0（不可逆）」，而不是矩阵本身等于 0。

特殊矩阵

  • 方阵：行数 = 列数（m = n），称为 n 阶方阵，有主对角线、行列式、逆等专属概念。
  • 行矩阵 / 列矩阵：只有一行 / 只有一列。列矩阵常被看作「向量」，是几何里最基本的对象。
  • 零矩阵：所有元素都是 0，记作 O 或 0。它是加法的「零元」。
  • 单位矩阵：主对角线全为 1、其余为 0 的方阵，记作 E 或 I。它是乘法的「单位元」。
  • 对角矩阵：非主对角线元素全为 0；对角元全相等的对角矩阵叫 数量矩阵。
  • 上三角 / 下三角矩阵：主对角线下方 / 上方全为 0。
  • 对称矩阵：Aᵀ = A（关于主对角线对称，即 aij = aji）。
  • 反对称矩阵：Aᵀ = −A（aij = −aji，主对角线必为 0）。
单位矩阵 E₃       对角矩阵 D        对称矩阵 S
⎡1 0 0⎤         ⎡2 0 0⎤           ⎡1 2 3⎤
⎢0 1 0⎥         ⎢0 3 0⎥           ⎢2 4 5⎥
⎣0 0 1⎦         ⎣0 0 5⎦           ⎣3 5 6⎦
几何含义：一个 m×n 矩阵 = 一个从 n 维空间到 m 维空间的线性变换：输入一个 n 维列向量 x，输出一个 m 维列向量 y = Ax。矩阵的每一列，就是「标准基向量被送到哪里去了」——看懂了各列，就看懂了这个变换。
物理含义：矩阵 = 一个「多分量系统」的状态表。例如 2×2 矩阵可记录一个平面上的两组数据：两列分别是两个基向量（或两种状态）的分量；3×3 矩阵可描述一个刚体在三维空间的惯性张量。矩阵把「一堆相关的数」组织成「一个可以整体操作的对象」。

2.2 矩阵的运算

2.2.1 加法与减法

同型矩阵才能相加：对应元素相加。

(A + B)ᵢⱼ = aᵢⱼ + bᵢⱼ
  • 交换律：A + B = B + A
  • 结合律：(A + B) + C = A + (B + C)
  • A + O = A；A + (−A) = O（−A 是 A 的负矩阵）
几何含义：矩阵加法 = 两个线性变换「逐分量叠加」。作用在向量上：(A+B)x = Ax + Bx，即「先各自变换、再把结果相加」。它对应着物理上「两个场/两种效应的合成（叠加原理）」。
物理含义：两套数据表按位置相加，例如把两个时刻的位移表叠加，或把两组力分别写成分量表后逐项合成。

2.2.2 数与矩阵相乘（数乘）

(kA)ᵢⱼ = k · aᵢⱼ        （k 为任意数，逐元素乘）
  • k(A + B) = kA + kB；(k + l)A = kA + lA；k(lA) = (kl)A
几何含义：数乘 = 把变换整体按比例缩放。作用在向量上：(kA)x = k(Ax)，即「先变换、再拉伸到 k 倍」。
物理含义：把一张数据表整体放大/缩小，如把某个量纲（单位）整体换算、把整个系统的响应统一放大 k 倍。

2.2.3 矩阵乘法（本章核心）

定义：设 A 是 m × s 矩阵，B 是 s × n 矩阵，则乘积 C = AB 是 m × n 矩阵，且

cᵢⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + ⋯ + aᵢₛbₛⱼ = Σₖ aᵢₖ bₖⱼ

口诀：左行 × 右列，对应相乘再相加。C 的第 (i, j) 元素 = A 的第 i 行与 B 的第 j 列做「内积」。

可乘条件：左矩阵的列数 = 右矩阵的行数（内维 s 必须相等），结果的行列取「外维」m × n。

     A(m×s)  ·  B(s×n)  =  C(m×n)
        └──── 相等 s ────┘

例：

⎡1 2⎤   ⎡5 6⎤   ⎡1·5+2·7  1·6+2·8⎤   ⎡19 22⎤
⎣3 4⎦ × ⎣7 8⎦ = ⎣3·5+4·7  3·6+4·8⎦ = ⎣43 50⎦

运算律：

  • 结合律：(AB)C = A(BC)（可随意分组，但顺序不能换）
  • 分配律：A(B + C) = AB + AC，(B + C)A = BA + CA
  • 与数乘：k(AB) = (kA)B = A(kB)
  • 一般不满足交换律：AB ≠ BA（甚至 AB 有意义而 BA 无意义；即便都有意义，通常也不相等）。
  • 有「零因子」：A ≠ O, B ≠ O 却可能 AB = O；也可能 AB = AC 而 A ≠ O 时推不出 B = C（消去律不成立）。
几何含义：矩阵乘法 = 线性变换的复合（先后作用）。(AB)x = A(Bx)：先把 x 用 B 变换，再用 A 变换。所以「先作用 B、后作用 A」要写成 AB——从右往左读。这也直接解释了为什么交换律不成立：先旋转再拉伸 ≠ 先拉伸再旋转（一般不等）。
物理含义：矩阵乘法 = 级联系统的传递。若 A 描述「输入 → 中间量」、B 描述「中间量 → 输出」，则 AB 描述「输入 → 输出」的整体传递函数；连续两次作用（两次变换、两级滤波、两次坐标系变换）就写成乘积。

2.2.4 转置

把矩阵的行与列互换，得到 转置矩阵 Aᵀ（或 A′）：

(Aᵀ)ᵢⱼ = aⱼᵢ      （A 的第 i 行变成 Aᵀ 的第 i 列）
  • (Aᵀ)ᵀ = A
  • (A + B)ᵀ = Aᵀ + Bᵀ
  • (kA)ᵀ = kAᵀ
  • (AB)ᵀ = BᵀAᵀ（注意顺序颠倒！）
几何含义：转置 = 把「行视角」换成「列视角」（或反过来）。在实内积空间里，转置对应伴随（对偶）：(Ax)·y = x·(Aᵀy)，即「A 作用在左边」等价于「Aᵀ 作用在右边」——它把向量空间的对偶关系「翻了个面」。
物理含义：把「以行为单位组织的记录」变成「以列为单位组织的记录」，例如状态量按行写还是按列写、输入与输出的角色互换。

2.2.5 方阵的行列式与矩阵的关系

只有方阵才有行列式 |A|（或 det A）：

  • |Aᵀ| = |A|
  • |kA| = kⁿ|A|（A 为 n 阶方阵，k 要提 n 次方）
  • |AB| = |A|·|B|（乘积的行列式 = 行列式的乘积）
几何含义：|A| = 线性变换 A 对有向体积（面积）的缩放倍率。2×2 的 |A| = 平行四边形有向面积放大倍数；3×3 的 |A| = 平行六面体有向体积放大倍数。|AB| = |A||B| 就是说「先按 B 缩、再按 A 缩」的总倍率 = 两者倍率相乘。

2.2.6 共轭矩阵（复矩阵）

当元素为复数时，把每个元素取共轭得到 共轭矩阵 Ā；取共轭再转置得到 共轭转置 Aᴴ = (Ā)ᵀ。性质：

(AB)ᴴ = BᴴAᴴ，  (Aᴴ)ᴴ = A
物理含义：量子力学里，可观测量（如能量、动量）对应的算符是自伴（厄米）矩阵，满足 Aᴴ = A；态向量的「内积」也由共轭转置定义。共轭转置是复空间里「伴随/对偶」的推广。

2.3 逆矩阵

定义

设 A 为 n 阶方阵，若存在 n 阶方阵 B，使

AB = BA = E

则称 A 可逆（非奇异），B 称为 A 的 逆矩阵，记作 A⁻¹。

  • 逆矩阵若存在必唯一。
  • 可逆 ⟺ |A| ≠ 0（这是判定可逆最常用的充要条件）。
  • 单位矩阵的逆是自身：E⁻¹ = E；零矩阵不可逆。

求法一：伴随矩阵法（公式法）

A⁻¹ = (1/|A|) · A*        （其中 |A| ≠ 0）

这里 A* 是 A 的伴随矩阵（由各元素的代数余子式按「转置」排列而成）。二阶方阵有简洁公式：

A = ⎡a b⎤  ⟹  A⁻¹ = (1/(ad−bc)) · ⎡ d  −b⎤
    ⎣c d⎦                            ⎣−c   a⎦     （要求 ad − bc ≠ 0）

求法二：初等行变换法（最实用）

把 A 与单位阵 E 并排，对整行做初等行变换，把左边变成 E，右边就得到 A⁻¹：

( A | E )  ──初等行变换──▶  ( E | A⁻¹ )

若左边无法化成 E（出现整行 0），则 |A| = 0，A 不可逆。

性质

  • (A⁻¹)⁻¹ = A
  • (AB)⁻¹ = B⁻¹A⁻¹（顺序颠倒）
  • (Aᵀ)⁻¹ = (A⁻¹)ᵀ
  • (kA)⁻¹ = (1/k) · A⁻¹（k ≠ 0）
  • |A⁻¹| = 1/|A|

可逆与线性方程组（克莱姆法则）

方程组 Ax = b，当 A 可逆时，解唯一且可写为：

x = A⁻¹ b

克莱姆法则：xi = |Ai| / |A|，其中 Ai 是把 A 的第 i 列换成 b 得到的矩阵（要求 |A| ≠ 0）。

几何含义：逆矩阵 = 逆变换，把线性变换「倒着做回去」。A 把 x 送到 y，A⁻¹ 就把 y 送回 x：A⁻¹(Ax) = x。可逆 ⟺ 变换不降维、不折叠（把体积缩到 0 的变换，即 |A| = 0，丢失了信息，就无法还原）。
物理含义：「已知结果反推原因」。若 A 是「原因 x → 结果 b」的系统矩阵，则 A⁻¹ 是「由测得的结果 b 反解出原始输入 x」的反问题求解器；在电路、力学、统计回归里，A⁻¹ 就是「去卷积/反演」的算子。

2.4 分块矩阵

基本思想

用若干横线、竖线把矩阵切成若干子块，每个子块本身又是一个（较小的）矩阵，从而把大矩阵的运算化归为小块间的运算。

        ⎡ A₁₁  A₁₂ ⎤
  A  =  ⎣ A₂₁  A₂₂ ⎦      （每个 Aᵢⱼ 都是一个小矩阵）

分块的目的：

  • 结构清晰：把「0 块」集中暴露出来，简化计算；
  • 降维：大矩阵运算变成若干小矩阵运算；
  • 揭示系统结构：一个块对应一个子系统。

分块运算规则

  • 加法：同型且同一种分法时，对应子块相加。
  • 数乘：每个子块都乘 k。
  • 乘法：把子块当「元素」按矩阵乘法规则做，但要求子块的乘法都合法（左块列分法 = 右块行分法）。
  • 转置：整体转置且每个子块内部也转置：(A)ᵀ 的第 (i,j) 块 = (Aⱼᵢ)ᵀ。

重要特例：分块对角矩阵

        ⎡ A₁  0   0 ⎤
  A  =  ⎢ 0   A₂  0 ⎥   （主对角上是方阵 A₁, A₂, A₃，其余为 0 块）
        ⎣ 0   0   A₃⎦
  • 行列式：|A| = |A₁| · |A₂| · |A₃|（各块行列式相乘）。
  • 逆：A⁻¹ = diag(A₁⁻¹, A₂⁻¹, A₃⁻¹)（各块分别求逆再对角放回）。
  • 幂：Aᵏ = diag(A₁ᵏ, A₂ᵏ, A₃ᵏ)。

对分块三角矩阵：

⎡ A  C ⎤ 的行列式 = |A|·|B|；  可逆 ⟺ A、B 都可逆
⎣ 0  B ⎦
几何含义：分块对角矩阵 = 空间被分解成若干「互不干扰」的子空间的直和，变换在每个子空间里各自独立地作用（互不混合）。因此整体效果 = 各子空间效果的「独立乘积」。
物理含义：把大系统解耦成子系统。例如把耦合的振动系统通过坐标变换变成分块对角形，各块对应独立的简正模（各自振动的自由度）；把「电路网络、多体问题」按块组织，一块就是一个子系统，可以分别处理再拼接。

概念几何含义物理/现实含义

矩阵加法两个变换逐分量叠加两种效应（力/场）的叠加原理

常见误区

  • ❌ 「矩阵就是行列式」→ ❌ 矩阵是数表（本身不是数），行列式是方阵按规则算出的一个数，两者本质不同。
  • ❌ 「任何两个矩阵都能相乘」→ ❌ 必须满足左列数 = 右行数，否则无定义。
  • ❌ 「矩阵乘法满足交换律」→ ❌ 一般 AB ≠ BA；能用交换律的只是特殊情形（如对角阵之间）。
  • ❌ 「AB = O 说明 A = O 或 B = O」→ ❌ 矩阵有零因子，非零矩阵相乘可为零阵。
  • ❌ 「AB = AC 且 A ≠ O ⟹ B = C」→ ❌ 矩阵乘法没有消去律，除非 A 可逆才能左乘 A⁻¹ 消去。
  • ❌ 「(AB)ᵀ = AᵀBᵀ」→ ❌ 转置要颠倒顺序：(AB)ᵀ = BᵀAᵀ。
  • ❌ 「(AB)⁻¹ = A⁻¹B⁻¹」→ ❌ 求逆也要颠倒顺序：(AB)⁻¹ = B⁻¹A⁻¹。
  • ❌ 「|kA| = k|A|」→ ❌ 对 n 阶方阵，数 k 要提 n 次方：|kA| = kⁿ|A|。
  • ❌ 「只要 A 是方阵就一定可逆」→ ❌ 可逆 ⟺ |A| ≠ 0；|A| = 0（降维/折叠）则不可逆。
  • ❌ 「分块乘法随便切就行」→ ❌ 分块必须让子块之间的乘法合法（左块列分法 = 右块行分法），不能乱切。

  4. （行列式与数乘）设 A、B 为 3 阶方阵，|A| = 2，|B| = −3。求 |AB|、|Aᵀ|、|2A|，并从"有向体积缩放倍率"的角度解释 |2A| 为何不是 2|A|。
  5. （逆矩阵·反演）求 A = ⎡1 2⎤ 的逆矩阵（用二阶公式），并验证 AA⁻¹ = E；若 y = Ax 且已知 y = ⎡5⎤，用 A⁻¹ 反解出 x，说明逆矩阵"由结果反推原因"的物理含义。
    　　　　　　　　　　⎣3 4⎦　　　　　　　　　　　　　　　　　　　⎣11⎦
  6. （分块矩阵）设 A = ⎡2 1 0 0⎤，用分块法（分成两个 2×2 对角块）求 |A| 与 A⁻¹，并从"空间直和分解"的角度说明分块对角矩阵的优势。
    　　　　　　　　⎢0 2 0 0⎥
    　　　　　　　　⎢0 0 3 1⎥
    　　　　　　　　⎣0 0 1 2⎦

二、参考答案（点击展开）

查看第1题答案

错。矩阵是一张数表（本身不是数），行列式只是对方阵按规则算出的一个数。2×3 矩阵 A 不是方阵，根本不存在 |A|；两者本质不同，不可混用。

查看第2题答案

复合矩阵写作 SR。矩阵乘法表示线性变换的复合，从右往左先后作用：SR 表示"先作用 R（旋转），再作用 S（拉伸）"。计算 SR = ⎡0 −2⎤；若写成 RS 则顺序颠倒，表示"先拉伸后旋转"，一般结果不同。
　　　　　　　⎣1 0⎦

查看第3题答案

AB = ⎡19 22⎤，(AB)ᵀ = ⎡19 43⎤；BᵀAᵀ = ⎡19 43⎤，两者相等 ✓。转置是行、列视角互换，在数据表中对应"行记录 ↔ 列记录"的角色互换。
　　　⎣43 50⎦　　　　　⎣22 50⎦　　　⎣22 50⎦

查看第4题答案

|AB| = |A|·|B| = 2×(−3) = −6；|Aᵀ| = |A| = 2；|2A| = 2³|A| = 8×2 = 16。几何上，|A| 表示 A 对有向体积的缩放倍率；2A 把每个列向量都放大 2 倍，三维空间三个方向各自翻倍，体积变为 2³ = 8 倍（再乘原倍率 2），所以是 16 而不是 2。

查看第5题答案

|A| = 1×4 − 2×3 = −2。A⁻¹ = (1/|A|)⎡ d −b⎤ = (−1/2)⎡4 −2⎤ = ⎡−2 1⎤。验证 AA⁻¹ = E ✓。
　　　　　　　　　　　　　　⎣−c a⎦　　　　　⎣−3 1⎦　　⎣3/2 −1/2⎦
x = A⁻¹y = ⎡1⎤。含义：已知输出 y 反推输入 x，即"反演"——逆矩阵把线性变换倒回去，由结果恢复原因。
　　　　　　⎣2⎦

查看第6题答案

分块 A = diag(B₁, B₂)，其中 B₁ = ⎡2 1⎤、B₂ = ⎡3 1⎤。|A| = |B₁|·|B₂| = 4×5 = 20。
　　　　　　　　　　　　　　　　　　　　　⎣0 2⎦　　　⎣1 2⎦
B₁⁻¹ = ⎡1/2 −1/4⎤，B₂⁻¹ = ⎡2/5 −1/5⎤，故 A⁻¹ = 分块对角 ⎡B₁⁻¹ 0⎤。优势：把 4 维问题拆成两个独立的 2 维子问题，各子空间互不影响，实现"解耦"。
　　　　⎣ 0 1/2⎦　　　　⎣−1/5 3/5⎦　　　　　　　　⎣ 0 B₂⁻¹⎦
