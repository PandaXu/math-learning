第1章 行列式

大学 / 线性代数

一句话总纲：行列式 = 「由矩阵的列向量张成的 有向体积」。它是把"几个向量"压缩成"一个数"的机器，这个数的绝对值是体积、正负号是定向，而这个数是否为零，直接决定了线性方程组有没有唯一解。

1.1 二阶与三阶行列式（从面积、体积出发）

为什么引入行列式？（从解方程组到几何量）

解二元一次方程组

   a₁₁ x₁ + a₁₂ x₂ = b₁
   a₂₁ x₁ + a₂₂ x₂ = b₂

用加减消元法（假设 a₁₁a₂₂ − a₁₂a₂₁ ≠ 0）可得唯一解：

   x₁ = (b₁a₂₂ − a₁₂b₂) / (a₁₁a₂₂ − a₁₂a₂₁)
   x₂ = (a₁₁b₂ − b₁a₂₁) / (a₁₁a₂₂ − a₁₂a₂₁)

分子分母出现了同一种"交叉相乘再相减"的式子。把它单独拎出来、记成一个符号，就是二阶行列式。

二阶行列式 = 有向面积

        | a  b |
   det = |      | = a·d − b·c
        | c  d |
  • 主对角线（左上→右下）乘积取正：a·d；副对角线（右上→左下）乘积取负：−b·c。
  • 例：|2 1; 3 4| = 2×4 − 1×3 = 5。
几何含义：把两列看成平面向量 u = (a, c)ᵀ、v = (b, d)ᵀ，则行列式的绝对值 = 这两个向量张成的平行四边形的面积；正负号 = 从 u 旋转到 v 的方向（逆时针为正、顺时针为负），称为有向面积。行列式为 0 意味着两向量共线，平行四边形"塌缩"成一条线段，面积为 0。
物理含义：二阶行列式就是两个向量的"叉积模长"（在二维平面上的有向面积）。它是力矩、角动量的雏形：力臂与力张成的有向面积正是"旋转效果"的度量。

三阶行列式 = 有向体积（对角线法则）

        | a₁  a₂  a₃ |
   det = | b₁  b₂  b₃ |  （把每一行或每一列写成一个三元组）
        | c₁  c₂  c₃ |

对角线法则（只适用于三阶）：把前两列抄到右侧，三条主对角线（↘）乘积相加、三条副对角线（↙）乘积相减：

   a₁b₂c₃ + a₂b₃c₁ + a₃b₁c₂ − a₃b₂c₁ − a₁b₃c₂ − a₂b₁c₃
几何含义：三列是三个三维向量，行列式的绝对值 = 它们张成的平行六面体的体积；符号表示这组向量构成右手系（正）还是左手系（负）。行列式为 0 ⇔ 三个向量共面 ⇔ 体积塌缩为 0 ⇔ 线性相关。
物理含义：三阶行列式就是三个向量的混合积（三重积） [a, b, c] = a · (b × c)。它是平行六面体体积，也是流体微元、晶体原胞体积的度量。

1.2 n 阶行列式的定义

从低阶到高阶的"破题"

对角线法则不能推广到四阶及以上（四阶行列式有 4! = 24 项，而"对角线"只有 8 条，根本对不上）。要给出统一定义，需要两个准备：排列与逆序数。

排列与逆序数

  • 排列：n 个不同元素排成一列。n 个元素共有 n! 种排列。
  • 逆序：在一个排列中，大数排在小数前面，就构成一个逆序。如排列 3 1 2 中，3 在 1、2 前面，共 2 个逆序。
  • 逆序数 τ：一个排列中逆序的总数。例：τ(3 1 2) = 2。
  • 奇排列 / 偶排列：逆序数为奇数叫奇排列，为偶数叫偶排列。例：3 1 2 是偶排列，1 3 2（τ=1）是奇排列。
  • 性质：交换排列中任意两个元素（一次对换），排列的奇偶性改变。

n 阶行列式的展开式定义

设 n 阶方阵 A = (aᵢⱼ)，它的行列式记作 |A| 或 det(A)，定义为：

   |A| = Σ (−1)^τ(j₁ j₂ … jₙ) · a_{1j₁} a_{2j₂} … a_{njn}
         (对 1,2,…,n 的所有排列 j₁j₂…jₙ 求和)
  • 共有 n! 项，每项是取自不同行、不同列的 n 个元素之积。
  • 每一项的正负由列下标排列 j₁j₂…jₙ 的逆序数决定：τ 为偶取正，τ 为奇取负（即 (−1)^τ）。
  • n = 2 时它还原为 a₁₁a₂₂ − a₁₂a₂₁；n = 3 时还原为对角线法则的 6 项。
几何含义：n 阶行列式 = n 个 n 维向量张成的 n 维有向超体积。定义式里"每一项取自不同行不同列"正对应"每个向量各取一个分量相乘"，而 ±1 的符号编码了这些向量的"定向"（是右手系还是经过奇数次交换的镜像系）。
物理含义：它是线性变换的体积缩放因子：一个区域在变换 x ↦ Ax 作用后，体积变为原来的 |det A| 倍，det A < 0 表示变换"翻转"了空间方向（镜像）。这正是变量替换中雅可比行列式的本质。

几个特殊行列式（务必记住）

   上三角 / 下三角 / 对角行列式 = 主对角线元素之积
   （其余位置全为 0 的三角阵，行列式 = a₁₁a₂₂…aₙₙ）

1.3 行列式的性质

下列性质是简化计算的全部工具，都可以由展开式定义严格证明。

性质内容一句记忆
① 转置不变|Aᵀ| = |A|行列式对"行"和"列"一视同仁，凡对行成立的性质对列也成立。
② 交换变号互换两行（或两列），行列式变号。换一次行 = 体积定向翻转一次。
③ 提公因子某行（列）有公因子 k，可提到行列式外：|… k·(某行) …| = k |… (某行) …|。整行同乘 k，体积缩放 k 倍。
④ 可加性某行是两组数之和，则行列式拆成两个行列式之和（其余行不变）。"和的贡献 = 各贡献之和"。
⑤ 零行某行（列）元素全为 0，行列式为 0。有一个方向"没有长度"，体积为 0。
⑥ 两行成比例两行（列）相同或成比例，行列式为 0。两个方向重合，退化，体积为 0。
⑦ 倍加不变把某行（列）的 k 倍加到另一行（列），行列式不变。这是化三角形、消元的最强工具。
⑧ 拆分不变把"一行 + 另一行的 k 倍"替换某行，行列式不变（即⑦）。高斯消元就是不断做这件事。
几何含义（统一视角）：③ = 一个向量被拉伸 k 倍，体积放大 k 倍；⑥ = 两个向量共线（或成比例），张成的区域退化为低维，体积为 0；⑦ = 把向量 v 换成 v + k·u，相当于沿 u 方向"斜推"这个平行四边形/平行六面体——斜推不改变体积（就像把一摞扑克牌斜着推一下，底面积×高不变）。
物理含义：② 交换变号 = 右手系与左手系（镜像）的区分，是手性在数学里的体现；⑦ 倍加不变 = 力的分解中，把力沿某一方向平移或叠加平行分量，不改变系统的"体积效应"。

核心技巧：化三角形法

用性质 ⑦、② 把矩阵化为上三角，行列式 = 主对角线乘积。这是手算高阶行列式的标准流程。

1.4 行列式按行（列）展开

余子式与代数余子式

在 n 阶行列式中，划去元素 aᵢⱼ 所在的第 i 行和第 j 列，剩下的 (n−1) 阶行列式叫 aᵢⱼ 的余子式 Mᵢⱼ；再乘以符号 (−1)^(i+j) 得到代数余子式：

   Aᵢⱼ = (−1)^(i+j) · Mᵢⱼ

符号棋盘：位置 (i, j) 的符号为 + 当 i+j 为偶，− 当 i+j 为奇。

   [+  −  +  −  …]
   [−  +  −  +  …]
   [+  −  +  −  …]

展开定理（拉普拉斯展开）

按第 i 行展开：

   |A| = aᵢ₁Aᵢ₁ + aᵢ₂Aᵢ₂ + … + aᵢₙAᵢₙ   （任意取定一行）

按第 j 列展开：

   |A| = a₁ⱼA₁ⱼ + a₂ⱼA₂ⱼ + … + aₙⱼAₙⱼ   （任意取定一列）

异乘变零（重要推论）：某行元素与另一行对应元素的代数余子式乘积之和等于 0：

   aᵢ₁Aⱼ₁ + aᵢ₂Aⱼ₂ + … + aᵢₙAⱼₙ = 0   (i ≠ j)
几何含义：按行展开 = 把高维体积拆成"底 × 高"逐层累加。aᵢⱼ 是第 i 维上的"高"，Aᵢⱼ 是划去该方向后剩余 (n−1) 维子空间的"底体积"，(−1)^(i+j) 校正定向——这正是"体积 = Σ (高 × 底面积)"的高维推广。
物理含义：展开过程 = 把 n 维效应降维分解：先固定一个方向，计算它在所有 (n−1) 维"截面"上的贡献，再求和。这与把体积积分写成"先对一维积分、再对余下维积分"（累次积分/切片法）完全同构。

1.5 克拉默法则

定理（克拉默法则，Cramer's Rule）

n 元线性方程组 Ax = b（A 为 n 阶方阵，x、b 为 n 维列向量）。若系数行列式 D = |A| ≠ 0，则方程组有唯一解：

   x₁ = D₁/D，  x₂ = D₂/D，  …，  xₙ = Dₙ/D

其中 Dⱼ 是把 D 中第 j 列换成常数项列 b 得到的行列式（其余列不变）。

两个推论（判定解的唯一性）

  • D ≠ 0 ⇔ 非齐次方程组 Ax = b 有唯一解。
  • 齐次方程组 Ax = 0：D ≠ 0 时只有零解；D = 0 时有非零解（有非零解 ⇔ D = 0）。
几何含义：D ≠ 0 表示系数矩阵的列向量张成"满维"的平行多面体（体积不为 0），即这些列向量线性无关、张满整个空间，于是任意目标向量 b 都能被唯一地线性表出——解 xⱼ 正是表出系数。D = 0 表示列向量"塌缩"到低维，b 若不在这个低维子空间内就无解，在子空间内则有无穷多解。
物理含义：解线性方程组 = 用一组"基向量"去拼出目标向量 b，系数 xⱼ 是各基向量的"用量"。克拉默法则告诉我们：只要基向量组"体积"不为 0（能张满空间），任何目标都能唯一拼出；这对应物理中"给定足够且独立的参照方向，任何向量可唯一分解"（如斜面上的力沿法向、切向分解）。

克拉默法则的适用边界

  • 只适用于方程个数 = 未知数个数（方阵）且 D ≠ 0 的情形。
  • 计算量约为 n! 级别，n 较大时不实用，一般只用于 n ≤ 3 或理论推导；工程上多用消元法。
  • 它的真正价值是理论意义：把"解存在且唯一"与"行列式非零"等价起来，为第 3 章矩阵可逆、第 4 章向量组线性相关性奠基。

典型例题（自测）

例题

  1. 计算二阶行列式 |3 −2; 1 4|，并说明它对应的平行四边形面积。
  2. 用对角线法则计算三阶行列式 |1 2 3; 4 5 6; 7 8 9|，它为什么等于 0？几何上说明理由。
  3. 用化三角形法（性质⑦）计算四阶行列式：把第一行的 −2 倍、−3 倍、−4 倍分别加到第 2、3、4 行，再观察结果。
  4. 求三阶行列式中元素 a₂₃ 的余子式与代数余子式，并按第 2 行展开计算该行列式。
  5. 用克拉默法则解方程组：x₁ + 2x₂ = 5；3x₁ + 4x₂ = 11。先算 D，再算 D₁、D₂。
  6. 判断齐次方程组 2x + 3y = 0；4x + 6y = 0 是否有非零解，并说明几何含义。

常见误区

⚠️ 常见误区

  • ❌ "对角线法则可以算四阶行列式" → ❌ 对角线法则只适用于二阶、三阶；n 阶行列式有 n! 项，必须用定义式、性质或按行展开。
  • ❌ "行列式 = 矩阵" → ❌ 行列式是方阵对应的一个数；矩阵是一张数表。只有方阵才有行列式。
  • ❌ "交换两行行列式不变" → ❌ 交换两行（列）行列式变号，符号 = 定向翻转。
  • ❌ "某行提公因子时，把整个行列式乘 k" → ❌ 只有一行（或一列）的公因子提到外面；n 行各提 k，才是整体乘 kⁿ。
  • ❌ "两行成比例但比例常数是 0 也行" → ❌ 严格说，是"两行对应元素成比例"或"两行相等"⇒ 行列式为 0；不要和"全 0 行"混淆。
  • ❌ "代数余子式忘了符号 (−1)^(i+j)" → ❌ 余子式 Mᵢⱼ 不带符号，代数余子式 Aᵢⱼ = (−1)^(i+j)Mᵢⱼ，展开时漏符号必错。
  • ❌ "克拉默法则万能，什么方程组都能解" → ❌ 仅当方程数 = 未知数数且 D ≠ 0 时才有唯一解；D = 0 时法则失效，且高阶时计算量巨大，不实用。
  • ❌ "D = 0 时齐次方程组只有零解" → ❌ 恰好相反：齐次方程组 D = 0 才有非零解，D ≠ 0 只有零解。

课本外 · 典故与思考

史点击展开：关孝和与莱布尼茨——两个互不相识的人，几乎同时"发明"了行列式

一句话答案：行列式的早期展开方法，最早出现在 1683 年前后日本数学家关孝和 的著作里；而在欧洲，莱布尼茨在 1693 年 也给洛必达的信中写出了类似的东西。两人相隔万里、互不知情，却撞出了同一个数学结构。

  • 关孝和（1642–1708）：日本江户时代"和算"的集大成者。他在 1683 年写成的《解伏题之法》里，为了从方程组里消去未知量，给出了展开行列式的方法（并处理到了五阶）。这是世界上对"行列式展开"最早的明确使用之一。
  • 莱布尼茨（1646–1716）：就是微积分的那位莱布尼茨。他在 1693 年 4 月 28 日写给洛必达的信里，用"结果式"（resultant）的方法讨论线性方程组的消元——本质上也是在用行列式，尽管他自己没有把它发展成一套理论。

"行列式"这个名字呢？是 高斯在 1801 年（《算术研究》里）第一次用了 determinant 这个词；真正把行列式建成完整理论的，是 1812 年柯西 的论文。所以一个概念的历程常常是：许多人各自摸到门，最后由某个人把它盖成房子。

一句话总结：行列式不是某一个人的发明，而是 消元问题在全球不同文明里开出的同一朵花；从"消元的副产品"到"有向体积的语言"，它走了两千年。
问点击展开：为什么叫"克莱默法则"？——他其实不是第一个

今天每个学线性代数的人都会背克莱默法则，但严格的历史是：麦克劳林比克莱默更早给出这个公式。

  • 麦克劳林（1698–1746）：就是麦克劳林级数的那位。他的《代数论》（A Treatise of Algebra）在他去世后的 1748 年 出版，书中已经给出了二、三元线性方程组的"分母行列式"解法。
  • 克莱默（1704–1752）：瑞士数学家。在 1750 年 出版的《代数曲线分析引论》里，他为了研究曲线插值问题，把这个法则写成了更系统、更一般的形式——于是后人把它命名为"克莱默法则"。

数学史上这种"别人先做、后人命名"的例子很多。名字记的是传播者与系统化者，而不是最早的探索者——这既是巧合，也是数学命名约定里的常见现象。

一句话总结：克莱默法则的名字记的是"系统化者"而非"第一人"——数学史常常这样：最出名的名字，不一定是第一个想到它的人。

有向面积 = −7：绝对值 7 是两列向量 (2,3) 与 (5,4) 张成的平行四边形面积；负号表示从 (2,3) 转到 (5,4) 是顺时针方向（逆时针为正、顺时针为负）。

查看第2题答案

对角线法则：1·5·9 + 2·6·7 + 3·4·8 − 3·5·7 − 1·6·8 − 2·4·9 = 45 + 84 + 96 − 105 − 48 − 72 = 0。
几何：第三行 = 2×第二行 − 第一行（三行线性相关），等价地三个列向量共面，张成的平行六面体"塌缩"为平面图形，有向体积为 0。

查看第3题答案

r₂ − 2r₁ → (0,1,1)；r₃ − 3r₁ → (0,2,4)；r₃ − 2r₂ → (0,0,2)。
得上三角形 [1 2 3; 0 1 1; 0 0 2]，det = 1×1×2 = 2。倍加不改变行列式，故原式也为 2。

查看第4题答案

a₂₃ = 1，M₂₃ = |2 1; 0 1| = 2，A₂₃ = (−1)^(2+3)·M₂₃ = −2。
按第 2 行展开：|A| = a₂₁A₂₁ + a₂₂A₂₂ + a₂₃A₂₃，其中 A₂₁ = −|1 0; 1 2| = −2，A₂₂ = |2 0; 0 2| = 4，A₂₃ = −2。
故 |A| = 1×(−2) + 3×4 + 1×(−2) = 8。

查看第5题答案

D = |1 2; 3 4| = 1×4 − 2×3 = −2。
D₁ = |5 2; 11 4| = 5×4 − 2×11 = −2；D₂ = |1 5; 3 11| = 1×11 − 5×3 = −4。
x₁ = D₁/D = (−2)/(−2) = 1，x₂ = D₂/D = (−4)/(−2) = 2，即解为 (1, 2)。

查看第6题答案

D = |2 3; 4 6| = 12 − 12 = 0，且第二行 = 2×第一行（两行成比例）⇒ 齐次方程组有非零解。
几何：两个列向量 (2,4) 与 (3,6) 共线，张成的平行四边形面积为 0，方向不独立，故存在非零组合为零向量。例如 (x, y) = (−3, 2) 满足两式。
