第6章 线性空间与线性变换

大学 / 线性代数

一句话总纲：线性空间 = 「对加法和数乘封闭、满足八条公理的向量世界」；线性变换 = 「保持加法和数乘这两种结构的映射」。学完本章，你要能在心里"看见"两件事：一是任意一组向量如何"张成"一个空间、基如何给这个空间装上"坐标系"；二是线性变换如何被一张矩阵"完全决定"——换基则矩阵随之"相似"，如同同一个物理规律换了坐标描述。

6.1 线性空间的定义与例子

从"箭头"到"抽象的向量"

中学里向量是"有大小有方向的箭头"，放在平面或空间里。但大量数学对象——多项式、矩阵、函数、数列——也满足与箭头完全一样的运算规律：能相加、能乘数，且这些运算遵守同样的代数规则。把它们统称为"向量"，把满足公理的集合统称为"线性空间"（也叫向量空间），就是抽象化的动机。

物理含义：线性空间是"叠加原理"成立的舞台。物理中的位移、速度、力、电场、量子态都满足"两个状态可以叠加、可以成倍放大"——这正是线性空间的八条公理所刻画的本质，因此物理上凡是线性系统都在一个线性空间里描述。

定义：八条公理

设 V 是一个非空集合，数域 F（本书取实数域 R 或复数域 C）上定义了两种运算：

  • 加法：对任意 α, β ∈ V，有唯一元素 α + β ∈ V（加法封闭）；
  • 数乘：对任意 k ∈ F, α ∈ V，有唯一元素 kα ∈ V（数乘封闭）。

若它们满足以下八条，则称 V 为数域 F 上的线性空间：

(1) α + β = β + α                     （加法交换律）
(2) (α + β) + γ = α + (β + γ)         （加法结合律）
(3) 存在零元 0，使 α + 0 = α
(4) 对每个 α，存在负元 −α，使 α + (−α) = 0
(5) 1·α = α
(6) k(α + β) = kα + kβ                （数乘对加法的分配律）
(7) (k + l)α = kα + lα                （数乘对数的分配律）
(8) k(lα) = (kl)α                     （数乘的结合律）

前四条说 V 关于加法构成交换群，后四条把"数"与"向量"的乘法协调起来。

几何含义：公理(1)(2)是说两个位移合成与顺序无关、可结合；(3)(4)是"原地不动"和"反向走回来"；(5)(8)是说"乘以1不变""先乘 l 再乘 k 等于一次乘 kl"。这一套正是"平行四边形法则 + 伸缩"的代数化。

经典例子（要会验证封闭性）

空间元素加法数乘
Rⁿn 元有序数组 (x₁,…,xₙ)逐分量相加逐分量乘数
Pₙ[x]次数 < n 的多项式全体多项式相加系数乘数
R^{m×n}m×n 实矩阵全体矩阵相加矩阵数乘
C[a,b][a,b] 上的连续函数函数相加 (f+g)(x)(kf)(x)
数列空间收敛（或任意）实数列逐项相加逐项乘数
关键认识："向量"未必是箭头——一个多项式、一个矩阵、一个函数都可能是"向量"。判断是不是线性空间，核心只看两条：加法封闭、数乘封闭（八条公理里分配律、结合律等一般都自动继承自实数运算）。例：P₂[x]（次数 ≤ 2 的多项式）关于"多项式加法"是线性空间，但"次数恰为 2 的多项式"全体不是——因为 x² 与 −x² 相加得 0，次数不再是 2，加法不封闭。

6.2 子空间、线性相关与无关

子空间（几何：空间里的"平面"和"直线"）

V 的非空子集 W 若关于 V 的加法与数乘也封闭，则称 W 是 V 的子空间。判定只需两条：

  • 对任意 α, β ∈ W，有 α + β ∈ W；
  • 对任意 k ∈ F, α ∈ W，有 kα ∈ W。

平凡例子：{0}（零子空间）与 V 本身。常见非平凡子空间：R³ 中过原点的平面、过原点的直线都是子空间；而不过原点的平面/直线不是子空间（因为不含零元 0）。

几何含义：子空间就是"过原点的平坦部分"——原点(零向量)必须在内，且沿其中任意方向走、任意伸缩都不离开它。物理含义：所有可能的合力方向（力系能合成的所有结果）构成一个子空间；约束系统的"允许状态集"往往也是子空间。

线性组合、张成与生成子空间

设 α₁,…,αₘ ∈ V，形如 k₁α₁ + k₂α₂ + … + kₘαₘ 的向量叫这些向量的线性组合；所有线性组合构成的集合叫生成子空间（张成），记作：

span{α₁, …, αₘ} = { k₁α₁ + … + kₘαₘ : kᵢ ∈ F }
几何含义：一个向量的张成是一条直线，两个不共线向量的张成是一个平面，三个不共面向量的张成是整个三维空间。物理含义：span 是"由若干基元状态通过叠加能到达的全部状态"——比如两个方向的单位位移张成整个平面运动。

线性相关与线性无关

对 α₁,…,αₘ，若存在不全为零的数 k₁,…,kₘ 使

k₁α₁ + k₂α₂ + … + kₘαₘ = 0

则称这组向量线性相关；否则（只有 k₁=k₂=…=kₘ=0 才使上式为 0）称线性无关。

几何含义：线性无关 = 这组向量"没有一个是多余的"，没有一个能被其余线性表出；相关 = 至少有一个向量落在其余向量张成的子空间里（"贡献"被重复了）。物理含义：无关的力/位移是"独立的方向自由度"，相关的量之间存在冗余约束。n 维空间里线性无关向量的个数最多为 n。

关键结论：

  • 含零向量的向量组必线性相关（取零向量的系数为 1，其余为 0 即可）。
  • 两个向量相关 ⟺ 它们共线（成比例）；三个向量相关 ⟺ 它们共面。
  • 向量组线性相关 ⟺ 其中至少有一个向量可由其余向量线性表出。
  • 若 α₁,…,αₘ 线性无关，而添加 β 后相关，则 β 可由它们唯一表出。

6.3 维数、基与坐标

基（几何：坐标系）与维数

若 V 中向量组 α₁,…,αₙ 满足：

  • 线性无关；
  • 张成整个空间：V = span{α₁,…,αₙ}，即任意 α ∈ V 都能写成它们的线性组合。

则称其为 V 的一组基，基所含向量的个数 n 叫 V 的维数，记 dim V = n。若维数无限，称无限维空间（如 C[a,b]）。

几何含义：基就是"坐标轴"。平面里两个不共线向量构成一组基（不一定是垂直的直角坐标，斜的也可以）；空间里三个不共面向量构成基。关键定理：维数与基的选择无关——无论你选哪组基，基向量的个数都一样，这是"维度"概念的坚实根基。

坐标（几何：向量在坐标系下的"读数"）

给定基 α₁,…,αₙ，任意 α ∈ V 可唯一表成

α = x₁α₁ + x₂α₂ + … + xₙαₙ

称有序数组 (x₁, x₂, …, xₙ)ᵀ 为 α 在这组基下的坐标。唯一性来自基的线性无关性（若有两种表出，相减得零的线性组合，系数必全为零）。

几何含义：坐标 = 从原点出发，沿各基向量"走多远"才能到达目标向量。在标准基 e₁,e₂,e₃ 下坐标就是熟悉的直角坐标。物理含义：一个物理量"在某个参考系（基）下的分量"——同一个速度矢量，换了坐标系分量就变，但矢量本身不变。这就是后面"换基"的物理原型。

标准基与维数公式

Rⁿ 的标准基：e₁=(1,0,…,0), e₂=(0,1,…,0), …, eₙ=(0,…,0,1)，故 dim Rⁿ = n。

Pₙ[x] 的一组基：1, x, x², …, xⁿ⁻¹        ⇒ dim Pₙ[x] = n
R^{m×n} 的基：Eᵢⱼ（第 i 行第 j 列为 1，其余为 0） ⇒ dim R^{m×n} = mn

维数公式（子空间的交与和）：设 W₁, W₂ 是 V 的子空间，则

dim(W₁ + W₂) = dim W₁ + dim W₂ − dim(W₁ ∩ W₂)
几何含义：两个过原点的平面在三维空间中相交于一条直线（也可能重合）：2 + 2 − 1 = 3。维数公式正是"容斥原理"在空间维度上的体现。

6.4 线性变换的定义与性质

定义：保持两种结构的映射

设 V, W 都是数域 F 上的线性空间，映射 T : V → W 若满足对任意 α, β ∈ V, k ∈ F：

T(α + β) = T(α) + T(β)      （保加法）
T(kα)    = k·T(α)           （保数乘）

则称 T 是线性变换（W = V 时称线性变换/线性算子；一般情形也叫线性映射）。两条可合并为一条：

T(kα + lβ) = k·T(α) + l·T(β)     对任意 k, l ∈ F
几何含义：线性变换把"平行四边形"映成"平行四边形"——把直线映成直线（或原点），把原点映成原点，且"均匀"地缩放。物理含义：线性变换是"保持叠加原理"的物理过程：两列波的叠加后再变换 = 变换后再叠加；放大 k 倍再变换 = 变换后放大 k 倍。旋转、投影、伸缩、镜像、剪切都是线性变换。

例子（几何直觉）

变换在 R² 上的作用几何效果
旋转 Rot(θ)绕原点逆时针转 θ 角刚体旋转
投影 P投到 x 轴：(x,y) ↦ (x,0)压扁到一条直线
伸缩 S(x,y) ↦ (ax,by)坐标轴方向缩放
镜像 M(x,y) ↦ (x,−y)关于 x 轴翻折
剪切 Sh(x,y) ↦ (x+y, y)横向错切
判定技巧：检查是否线性，先看"原点是否映成原点"（T(0)=0 必须成立），再验证 T(kα + lβ) = kT(α) + lT(β)。例：平移 T(x,y)=(x+a, y+b) 当 (a,b)≠(0,0) 时不是线性变换——因为它把原点移走了，属于"仿射变换"。

核与像、秩—零度定理

核（kernel/零空间）：被映成零向量的全体输入。

Ker T = { α ∈ V : T(α) = 0 }

像（image/值域）：所有输出构成的集合。

Im T = { T(α) : α ∈ V }

核是 V 的子空间，像是 W 的子空间。称 dim(Ker T) 为零度，dim(Im T) 为秩。核心定理——秩—零度定理（维数定理）：

dim V = dim(Ker T) + dim(Im T)
几何含义：输入空间的维数 = "被压成零点的方向数" + "存活下来的方向数"。例如把 R³ 垂直投影到 xy 平面：z 轴整个被压成原点（dim Ker = 1），像就是 xy 平面（dim Im = 2），而 3 = 1 + 2。物理含义：线性系统里"解的自由度" = 方程个数（列空间维数）之外的零空间维数；秩度量了变换"保留了多少独立信息"，零度度量了"丢失了多少独立方向"。

6.5 线性变换的矩阵表示与换基

核心思想：选定基之后，变换 = 一张矩阵

设 dim V = n, dim W = m。取 V 的基 α₁,…,αₙ 与 W 的基 β₁,…,βₘ。对每个基向量 αⱼ，它在 W 基下的坐标为：

T(αⱼ) = a₁ⱼβ₁ + a₂ⱼβ₂ + … + aₘⱼβₘ

把这些坐标按列排成 m×n 矩阵 A = (aᵢⱼ)，称为 T 在这两组基下的矩阵表示。于是对任意 α = x₁α₁+…+xₙαₙ，其像的坐标满足：

y = A x，其中 x = (x₁,…,xₙ)ᵀ，y = (y₁,…,yₘ)ᵀ
几何含义：矩阵 A 的第 j 列 = 第 j 个基向量被变换后的"影子坐标"。也就是说，一个线性变换被它在基向量上的取值完全决定——因为任何向量都是基向量的线性组合，而变换又保持线性组合。所以"选好基后，变换 ↔ 矩阵"是一一对应。
物理含义：这就是"物理规律在具体坐标系里的数字形式"。同样的转动（一个几何/物理动作），在标准直角坐标下是一张矩阵，换了坐标轴又变成另一张矩阵——它们描述的是同一个变换，这就是"相似矩阵"的物理来源。

复合与矩阵乘法

若 T : V→W 与 S : W→U 的矩阵分别为 A、B，则复合 S∘T 的矩阵为 BA。即：

矩阵乘法 = 线性变换的复合
几何含义：先做 T 再做 S，对应"先乘 A 再乘 B"——从右到左依次作用。这正是"先旋转后拉伸"与"先拉伸后旋转"一般不等（BA ≠ AB）的几何根源：变换一般不交换。

换基公式与相似矩阵（同一变换，不同坐标）

设 V = W（同一空间上的线性算子），旧基 α₁,…,αₙ 与新基 α'₁,…,α'ₙ。若 T 在旧基下矩阵为 A，在新基下矩阵为 B，则存在可逆的过渡矩阵（基变换矩阵） P 使

B = P⁻¹ A P

此时称 A 与 B相似。过渡矩阵 P 的列 = 新基向量在旧基下的坐标。

几何含义：换基只是"换一副坐标系看同一个几何动作"。A 和 B 是同一个变换的两张"照片"。物理含义：同一个物理规律（转动、惯性张量、量子算符）在不同参考系下有不同矩阵，但它们相似；相似不变量（如迹、行列式、特征值、秩）才是这个变换的"本质属性"，与坐标系无关——正如矢量长度不随坐标系改变。

可逆变换与同构

若线性变换 T 既是单射（Ker T = {0}）又是满射（Im T = W），则称 T 可逆，其矩阵 A 是方阵且可逆，逆变换的矩阵为 A⁻¹。两个线性空间若存在可逆线性映射，称它们同构；同维数的线性空间必同构。

几何含义：可逆变换不"压扁"任何方向（核只有零点），空间经过它之后维数不损失，还能"复原"。物理含义：可逆性 = 信息不丢失、过程可逆；行列式 det A ≠ 0 是"体积不被压成零"的代数判据。

典型例题（自测）

  1. 判断下列集合是否构成线性空间（加法、数乘为通常意义）：(a) 全体 n 次多项式；(b) 全体 n 阶上三角矩阵；(c) 满足 f(1)=0 的全体实系数多项式。
  2. 判断向量组是否线性无关：α₁=(1,2,3)，α₂=(2,−1,4)，α₃=(0,5,2)。
  3. 设 R³ 中 β₁=(1,1,0), β₂=(0,1,1), β₃=(1,0,1)。证明它是一组基，并求 α=(1,2,3) 在该基下的坐标。
  4. 设 T : R³ → R²，T(x,y,z)=(x+y, y−z)。求 T 在标准基下的矩阵、Ker T 与 Im T 的维数，并验证秩—零度定理。
  5. 设 T 是 R² 上逆时针旋转 90° 的变换。写出它在标准基下的矩阵 A；若新基为 α₁=(1,1), α₂=(−1,1)，求过渡矩阵 P 及新基下的矩阵 B = P⁻¹AP。

常见误区

  • ❌ "子空间只要对加法封闭就行" → ❌ 还必须对数乘封闭、含零向量；只对加法封闭不足以成为子空间。
  • ❌ "维数就是向量里数字的个数" → ❌ 维数是"基向量的个数"，是空间的属性，不是单个向量分量的个数；Pₙ[x] 里的向量是多项式，没有"分量个数"，但 dim 仍是 n。
  • ❌ "基必须是相互垂直的单位向量" → ❌ 基只要求线性无关且张成全空间，可以斜交、可以非单位长；垂直单位的是"标准正交基"这一特例。
  • ❌ "坐标是唯一的吗？换基不变" → ❌ 同一向量在给定一组基下坐标唯一，但换一组基坐标就变；坐标依赖基的选择。
  • ❌ "把原点映成原点的映射都是线性变换" → ❌ 仅是必要条件不充分；T(x)=x² 在 R 上把 0 映成 0，但不满足 T(x+y)=T(x)+T(y)，不是线性的。
  • ❌ "相似矩阵相等" → ❌ 相似矩阵一般不相等，只是描述同一变换在不同基下；它们的迹、行列式、特征值、秩相同。
  • ❌ "矩阵乘法的顺序无所谓" → ❌ 矩阵乘法对应变换的复合，一般 BA ≠ AB；先旋转后拉伸 ≠ 先拉伸后旋转。

  2. 判断向量组 α₁=(1,1,0)、α₂=(0,1,1)、α₃=(1,2,1) 是否线性无关，并从几何角度说明其含义。
  3. 设 β₁=(1,0,1)、β₂=(0,1,1)、β₃=(1,1,0)。证明它是 R³ 的一组基，并求 α=(2,3,4) 在该基下的坐标。
  4. 设 T:R³→R²，T(x,y,z)=(x+y, y−z)。求 T 在标准基下的矩阵 A，以及 Ker T、Im T 的维数，并验证秩—零度定理。
  5. 设 T 是 R² 上逆时针旋转 90° 的变换。写出它在标准基下的矩阵 A；若新基为 α₁=(1,1)、α₂=(−1,1)，求过渡矩阵 P 及新基下的矩阵 B = P⁻¹AP，并验证相似不变量。
  6. 设 T 是 R³ 向 xy 平面的正交投影：T(x,y,z)=(x,y,0)。(a) 求 Ker T 与 Im T 及其维数，验证秩—零度定理；(b) 用一两句话说明其几何含义，并指出这一变换"丢失"了哪一维信息。

二、参考答案（点击展开）

查看第1题答案

(a) 不是。取 x² 与 −x² 相加得 0，次数不再是 2，加法不封闭（也不含零元 0）。 (b) 是。它是过原点的平面，含零向量；任取两向量相加、任意数乘后分量之和仍为 0，故对加法与数乘都封闭，八条公理自动继承。 (c) 不是。单位圆不含原点 0，且 (1,0)+(0,1)=(1,1) 不在圆上，加法不封闭。

查看第2题答案

线性相关。因为 α₃ = α₁ + α₂，即 1·α₁ + 1·α₂ + (−1)·α₃ = 0，存在不全为零的系数。几何上：α₃ 落在 α₁、α₂ 张成的平面内，是被"重复"的冗余方向，故三者不能构成独立的方向。

查看第3题答案

先证无关：设 c₁β₁+c₂β₂+c₃β₃=0，展开得方程组 c₁+c₃=0, c₂+c₃=0, c₁+c₂=0，解得 c₁=c₂=c₃=0，故线性无关；又 dim R³=3，三个无关向量张成整个 R³，所以是基。求坐标：设 α=xβ₁+yβ₂+zβ₃，解 x+z=2, y+z=3, x+y=4，得 x=3/2, y=5/2, z=1/2，即坐标为 (3/2, 5/2, 1/2)ᵀ。

查看第4题答案

取标准基：T(e₁)=(1,0)、T(e₂)=(1,1)、T(e₃)=(0,−1)，故 A = [[1,1,0],[0,1,−1]]。求核：解 x+y=0, y−z=0 得 x=−y, z=y，自由变量为 y，故 Ker T = span{(−1,1,1)}，dim Ker T = 1。像由 A 的列张成，两行线性独立，故 dim Im T = 2。验证：3 = 1 + 2，秩—零度定理成立。几何上：沿 (−1,1,1) 这一个方向被"压"到原点，另外两个独立方向存活下来。

查看第5题答案

旋转 90° 把 e₁→(0,1)、e₂→(−1,0)，故 A = [[0,−1],[1,0]]。过渡矩阵 P 的列是新基在旧基下的坐标：P = [[1,−1],[1,1]]，det P = 2，P⁻¹ = (1/2)[[1,1],[−1,1]]。计算 B = P⁻¹AP = [[0,−1],[1,0]]，恰与 A 相同（这组新基下 90° 旋转仍取同一形式）。相似不变量保持不变：tr(A)=tr(B)=0、det(A)=det(B)=1。

查看第6题答案

(a) Ker T = {(0,0,z)} 即 z 轴，dim Ker T = 1；Im T = {(x,y,0)} 即 xy 平面，dim Im T = 2；3 = 1 + 2，定理成立。(b) 几何上这是把整个空间"压扁"到 xy 平面，z 轴方向被整体映成原点；它丢失了"高度"（z 分量）这一维信息——正如把三维物体拍成平面照片，纵深信息丢失。核的维数（1）正是被丢失的独立方向数。
