第10章 重积分

大学 / 高等数学

一句话总纲：重积分 = 一元定积分的「高维推广」——二重积分算「曲顶柱体的体积 / 平面薄片的质量」，三重积分算「空间物体的质量」，本质都是「分割—近似—求和—取极限」，最终把平面或空间区域上的连续量累加，化成一串可算的累次积分（二次、三次积分）。

10.1 二重积分的概念

从哪里来？一元定积分的推广

一元定积分 ∫ₐᵇ f(x) dx 解决的是「曲边梯形的面积」：把区间 [a,b] 无限细分，每段高 f(x) 乘微小宽度 dx，再累加取极限。二重积分把问题从「一条线上的函数」推广到「一块平面区域上的函数」：被积函数 f(x,y) 定义在平面闭区域 D 上，我们想知道它在 D 上「累加」起来是多少。

几何背景：曲顶柱体的体积

设曲面 z = f(x,y) ≥ 0 在闭区域 D 上连续，以 D 为底、曲面为顶、以 D 的边界为准线、母线平行于 z 轴的柱面为侧面，围成的立体叫曲顶柱体。它的体积 V 无法用「底面积 × 高」直接算（因为「高」f(x,y) 处处不同），于是用「切细、求积、累加、取极限」四步。

定义（四步法）

  1. 分割：把 D 任意分成 n 个小闭区域 Δσ₁, Δσ₂, …, Δσₙ（Δσᵢ 同时表示该小区域的面积）。
  2. 近似：在每个 Δσᵢ 内任取一点 (ξᵢ, ηᵢ)，小柱体体积近似为 f(ξᵢ, ηᵢ)·Δσᵢ。
  3. 求和：V ≈ Σᵢ₌₁ⁿ f(ξᵢ, ηᵢ)·Δσᵢ。
  4. 取极限：记 λ 为各 Δσᵢ 的直径（区域上任意两点距离的最大值）的最大者，令 λ → 0，若极限存在，且与分割方式、取点方式都无关，则称 f 在 D 上可积。
        n
∬_D f(x,y) dσ = lim  Σ  f(ξᵢ, ηᵢ)·Δσᵢ
        λ→0  i=1

其中 f 叫被积函数，D 叫积分区域，dσ 叫面积元素。在直角坐标下面积元素也写成 dσ = dx dy，所以常记作 ∬_D f(x,y) dx dy。

几何含义：当 f(x,y) ≥ 0 时，二重积分 ∬_D f dσ 就是曲顶柱体的体积；特别地，当 f(x,y) ≡ 1 时，∬_D 1 dσ = 以 D 为底、高为 1 的平顶柱体体积 = D 的面积。这就是「积分算面积」在高维的体现。
物理含义：设平面薄片占据区域 D，其面密度为 ρ(x,y)（单位面积的质量，可以逐点变化），则薄片的总质量 M = ∬_D ρ(x,y) dσ。这就是「密度 × 面积」从「均匀」到「非均匀」的推广：把 D 切成无数小片，每小片质量 ≈ ρ·dσ，再累加。

可积的充分条件：闭区域 D 上的连续函数一定可积（本课程绝大多数函数都满足）。

10.2 二重积分的性质

设 f、g 都在 D 上可积，k 为常数，σ 表示区域 D 的面积。

  • 线性性：∬_D [f(x,y) ± g(x,y)] dσ = ∬_D f dσ ± ∬_D g dσ；∬_D k·f(x,y) dσ = k·∬_D f dσ。
  • 区域可加性：若 D = D₁ ∪ D₂，且 D₁、D₂ 除边界外互不重叠，则 ∬_D f dσ = ∬_{D₁} f dσ + ∬_{D₂} f dσ。
  • 保号性：若在 D 上 f(x,y) ≥ 0，则 ∬_D f dσ ≥ 0。
  • 单调性：若在 D 上 f(x,y) ≤ g(x,y)，则 ∬_D f dσ ≤ ∬_D g dσ。
  • 绝对值不等式：| ∬_D f dσ | ≤ ∬_D |f| dσ。
  • 估值不等式：若在 D 上 m ≤ f(x,y) ≤ M，则 m·σ ≤ ∬_D f dσ ≤ M·σ。
  • 二重积分中值定理：若 f 在闭区域 D 上连续，σ 为 D 的面积，则存在点 (ξ,η) ∈ D，使 ∬_D f dσ = f(ξ,η)·σ。
几何直觉：估值不等式说「曲顶柱体的体积夹在『最小高度 × 底面积』与『最大高度 × 底面积』之间」；中值定理说「曲顶柱体必在某一点的高度 f(ξ,η) 正好等于它的平均高度（总体积 ÷ 底面积）」。两者都把「积分」翻译成「高度」的语言，非常好记。

10.3 二重积分的计算（直角坐标）

核心思想：化二重积分为累次积分（二次积分）

二重积分的定义极限没法直接算，实际计算靠「先对一个变量积分、再对另一个变量积分」，把它变成连续的两个一元定积分。关键是：把积分区域 D 用不等式组描述清楚，从而确定上下限。

X 型区域（先积 y，再积 x）

若区域可写成：D = {(x,y) | a ≤ x ≤ b, φ₁(x) ≤ y ≤ φ₂(x)}（用两条竖线 x=a、x=b 和两条曲线 y=φ₁(x)、y=φ₂(x) 围成），则

                 φ₂(x)
∬_D f(x,y) dσ = ∫ₐᵇ [ ∫_{φ₁(x)}  f(x,y) dy ] dx

口诀：「先积 y、后积 x」——内层对 y 积分时把 x 当常数，积出只含 x 的函数（它是「垂直于 x 轴的截面面积」S(x)），外层再对 x 积分。

几何含义（切片法）：固定一个 x，用垂直于 x 轴的平面去切曲顶柱体，截面是一块「曲边梯形」，其面积 S(x) = ∫_{φ₁(x)}^{φ₂(x)} f(x,y) dy；再让 x 从 a 扫到 b，把这些薄片的面积 S(x)dx 累加起来，正好是体积 V = ∫ₐᵇ S(x) dx。

Y 型区域（先积 x，再积 y）

若区域可写成：D = {(x,y) | c ≤ y ≤ d, ψ₁(y) ≤ x ≤ ψ₂(y)}，则

                 ψ₂(y)
∬_D f(x,y) dσ = ∫꜀ᵈ [ ∫_{ψ₁(y)}  f(x,y) dx ] dy
物理含义：累次积分就是「先沿一条线竖着扫（积 x），再横着扫过整片区域（积 y）」。对质量而言：先算出「一条竖直细条」的质量，再把所有细条并排累加成整块薄片的质量。

交换积分次序

有时按一种次序积分会碰到积不出来的内层积分（如 ∫ e^{x²} dx 没有初等原函数），此时需要交换积分次序。步骤：① 由原积分限写出区域 D 的不等式组；② 画出 D 的草图；③ 改用另一种变量作外层，重新写出上下限；④ 再积分。

选择次序的原则：看区域是「上下型」(X型) 还是「左右型」(Y型)，再看被积函数先对哪个变量好积，通常「先积的那个变量」应是好积的。

10.4 二重积分的计算（极坐标）

什么时候用极坐标

  • 积分区域 D 是圆、圆环、扇形（边界含 x² + y²）。
  • 被积函数含 x² + y² 或 y/x 等旋转对称结构。

坐标变换与面积元素

x = r·cos θ,   y = r·sin θ
dσ = r · dr · dθ

于是

∬_D f(x,y) dσ = ∬_D f(r cos θ, r sin θ) · r · dr dθ
几何含义：面积元素为什么多个 r？极坐标网格由「同心圆 + 从原点出发的射线」组成，一个小格是「小扇形」，其面积 ≈ (1/2)(r+dr)²·dθ − (1/2)r²·dθ ≈ r·dr·dθ。那个多出来的 r 反映：离原点越远，同样的角度张开的弧越长，所以小格面积随 r 放大。漏掉这个 r 是初学者最常见的错误。

典型极坐标区域

区域 D极坐标表示
圆域 x²+y² ≤ R²0 ≤ r ≤ R, 0 ≤ θ ≤ 2π
圆环 R₁ ≤ √(x²+y²) ≤ R₂R₁ ≤ r ≤ R₂, 0 ≤ θ ≤ 2π
扇形（圆心角 β−α）0 ≤ r ≤ R, α ≤ θ ≤ β
圆心在原点、位于第一象限的圆0 ≤ r ≤ R, 0 ≤ θ ≤ π/2

重要结论（联系概率与误差函数）：由 ∬ e^{−(x²+y²)} dσ 在全平面第一象限的积分，可得著名的泊松积分 ∫₀^∞ e^{−x²} dx = √π / 2——这是「直角坐标算不出、极坐标一换就出」的经典范例。

10.5 三重积分的概念与计算

概念：三元函数在空间区域上的累加

与二重积分完全类比：把空间闭区域 Ω 分成 n 个小区域 ΔVᵢ，在每个小区域内取点 (ξᵢ, ηᵢ, ζᵢ)，求和取极限：

                n
∭_Ω f(x,y,z) dV = lim  Σ  f(ξᵢ, ηᵢ, ζᵢ)·ΔVᵢ
        λ→0  i=1

d V 叫体积元素；直角坐标下 dV = dx dy dz。

几何含义：当 f ≡ 1 时，∭_Ω 1 dV = 区域 Ω 的体积。一般 f 没有直接的三维几何体（它表示一个「四维超体积」，想象不出但可类比），我们主要依赖物理意义和「切片」来理解。
物理含义：设空间物体 Ω 的体密度为 ρ(x,y,z)（单位体积质量），则物体的总质量 M = ∭_Ω ρ(x,y,z) dV。这是「密度 × 体积」从均匀到非均匀的推广。

直角坐标计算：投影法（先一后二）

把 Ω 投影到 xOy 平面得区域 D，设 Ω 可写成

Ω = { (x,y,z) | (x,y) ∈ D,  z₁(x,y) ≤ z ≤ z₂(x,y) }

则

                           z₂(x,y)
∭_Ω f dV = ∬_D [ ∫_{z₁(x,y)}  f(x,y,z) dz ] dxdy

先对 z 积分（把 x、y 当常数），再对投影区域 D 做二重积分（可再按 10.3 化成二次积分）。

几何含义：「先一」= 沿 z 方向竖着穿一根「线」，积出该点上方到曲面之间的「高」的贡献；「后二」= 在投影区域上把整片立体的贡献累加。这正是一元定积分「竖条累加」向「竖线累加成一片」的推广。

直角坐标计算：截面法（先二后一）

若用垂直于 z 轴的平面去截 Ω，得到截面 D_z（随 z 变化，z ∈ [c,d]），则

              d
∭_Ω f dV = ∫꜀ᵈ [ ∬_{D_z}  f(x,y,z) dxdy ] dz
几何含义：「先二」= 先算某一高度 z 处截面的「面积」（当 f ≡ 1 时就是截面 D_z 的面积 A(z)）；「后一」= 沿 z 轴把各截面面积累加。这就是熟悉的「体积 = ∫ 截面积 dz」（祖暅原理 / 卡瓦列里原理）。被积函数只含 z（f = f(z)）且截面面积易求时，此法特别省事。

10.6 柱坐标与球坐标下的三重积分

柱坐标（三维的「极坐标 + z」）

x = r·cos θ,   y = r·sin θ,   z = z
dV = r · dr · dθ · dz

适用：积分区域 Ω 是圆柱体、圆台、旋转抛物面、圆锥面等绕 z 轴旋转的结构，或被积函数含 x² + y²。

几何含义：柱坐标就是「xOy 平面用极坐标，竖直方向 z 不动」。体积元素 dV = (r dr dθ)·dz = 「小扇形面积 r dr dθ」×「小高 dz」。那个 r 与二重积分极坐标里的 r 是同一个道理。

球坐标

x = r·sin φ·cos θ
y = r·sin φ·sin θ
z = r·cos φ

dV = r² · sin φ · dr · dφ · dθ

三个变量的意义与范围：

  • r：点到原点的距离，r ≥ 0。
  • φ：向径与 z 轴正向的夹角（纬度方向），0 ≤ φ ≤ π（不是 0~2π！）。
  • θ：向径在 xOy 平面的投影与 x 轴正向的夹角（经度方向），0 ≤ θ ≤ 2π。

适用：积分区域是球体、球壳、球的一部分、圆锥，或被积函数含 x² + y² + z²。

几何含义：球坐标网格是一个「弯曲的小长方体」，三条棱分别是：径向 dr、经线弧长 r·dφ、纬线弧长 r·sin φ·dθ，三边相乘得 dV = r²·sin φ·dr·dφ·dθ。注意纬线半径是 r·sin φ（不是 r），所以纬线弧长要乘 sin φ——漏掉 r² sin φ 是最常见错误。

例：半径为 R 的球体 Ω，用球坐标算体积

         2π      π       R
V = ∫₀  ∫₀  ∫₀  r²·sin φ  dr dφ dθ
  = (∫₀^2π dθ)·(∫₀^π sin φ dφ)·(∫₀^R r² dr)
  = 2π · 2 · (R³/3) = (4/3)πR³

一步得到熟悉的球体积公式，球坐标的威力可见一斑。

10.7 重积分的应用

1. 曲面的面积

曲面 z = z(x,y)（在区域 D 上）的面积：

S = ∬_D √( 1 + z_x² + z_y² ) dxdy
几何含义：把曲面「贴」到平面区域 D 上，曲面上的小面积元素被放大 √(1 + z_x² + z_y²) 倍（曲面越「陡」，放大越多；水平时 z_x = z_y = 0，倍数为 1）。这是「曲面面积 = 平面面积 × 局部放大系数」的累加。

2. 平面薄片的质量、质心、转动惯量

设薄片 D 的面密度 ρ(x,y)：

  • 质量 M = ∬_D ρ dσ
  • 质心（质量中心）x̄ = (1/M)∬_D x·ρ dσ，ȳ = (1/M)∬_D y·ρ dσ
  • 转动惯量：关于 x 轴 I_x = ∬_D y²·ρ dσ；关于 y 轴 I_y = ∬_D x²·ρ dσ；关于原点 I_O = ∬_D (x²+y²)·ρ dσ
物理含义：质心 = 把整块质量「加权平均」到的那个点（重心）；转动惯量 = 每个质量元 × 它到转轴距离的平方 的累加，度量「让它转起来/停下来有多费劲」，距离越远的质量贡献越大（平方放大）。

3. 空间物体的质量、质心、转动惯量

设物体 Ω 的体密度 ρ(x,y,z)：

  • 质量 M = ∭_Ω ρ dV
  • 质心 x̄ = (1/M)∭_Ω x·ρ dV，ȳ = (1/M)∭_Ω y·ρ dV，z̄ = (1/M)∭_Ω z·ρ dV
  • 转动惯量：关于 z 轴 I_z = ∭_Ω (x²+y²)·ρ dV；关于 x 轴 I_x = ∭_Ω (y²+z²)·ρ dV；关于 y 轴 I_y = ∭_Ω (x²+z²)·ρ dV
物理含义：关于 z 轴的转动惯量中，质量元到 z 轴的距离平方就是 x² + y²（水平投影距离的平方），所以 I_z = ∭ (x²+y²)ρ dV。均匀物体（ρ 为常数）的质心退化为几何形心，此时质量可以「约掉」，只用几何区域算形心。

常见误区

本章易错点

  • ❌ 极坐标把 dσ 直接写成 dr dθ → 正确是 dσ = r dr dθ，漏掉 r 必错。
  • ❌ 球坐标体积元素写成 r² dr dφ dθ 或 sinφ dr dφ dθ → 正确是 r² sinφ dr dφ dθ。
  • ❌ 球坐标里 φ 取 0 到 2π → φ 是「与 z 轴夹角」，范围是 0 到 π；θ 才取 0 到 2π。
  • ❌ 交换积分次序后直接把上下限对调 → 必须先画区域草图、重新定限，次序一变限就变。
  • ❌ 二重积分值一定等于体积 → 只有 f ≥ 0 时才是体积；f 可为负，体积要积 |f| 或按正负分段。
  • ❌ 三重积分投影法忘写 z 的上下限函数 → 内层上下限是 z₁(x,y)、z₂(x,y)（曲面方程），不是常数。
  • ❌ 用估值不等式 / 中值定理时忘记 σ 是区域的面积（要算 D 的面积，不是随便代入）。
  • ❌ 极坐标下 θ 的范围一律写 0 到 2π → 半圆、扇形、第一象限等区域 θ 范围要按角度实际确定。

本章练习卷（含答案）

一、练习题

  1. （面积）设 D 为矩形区域 0 ≤ x ≤ 2, 0 ≤ y ≤ 3，计算 ∬_D 1 dσ。
  2. （物理·质量）平面薄片 D 为单位圆盘 x² + y² ≤ 1，面密度 ρ(x,y) = x² + y²，求薄片的总质量 M。
  3. （直角坐标）计算 ∬_D x dσ，其中 D 由曲线 y = x 与 y = x² 围成。
  4. （交换次序）交换积分 ∫₀¹ dy ∫_y¹ f(x,y) dx 的积分次序，写出新表达式。
  5. （三重积分·体积）用球坐标计算半径为 R 的球体 x²+y²+z² ≤ R² 的体积。
  6. （球坐标·物理）计算 ∭_Ω z dV，其中 Ω 为上半球体 x²+y²+z² ≤ R²（z ≥ 0）。

二、参考答案（点击展开）

查看第1题答案

∬_D 1 dσ = D 的面积 = 2 × 3 = 6。几何意义：被积函数恒为 1 时，二重积分就是以 D 为底、高为 1 的平顶柱体体积，数值上等于区域面积。

查看第2题答案

M = ∬_D (x²+y²) dσ，换极坐标 x²+y²=r²、dσ=r dr dθ：M = ∫₀^2π dθ ∫₀^1 r³ dr = 2π · (1/4) = π/2。

查看第3题答案

交点 x=0,1，区域为 0 ≤ x ≤ 1, x² ≤ y ≤ x。∬_D x dσ = ∫₀¹ dx ∫_{x²}^{x} x dy = ∫₀¹ x(x−x²) dx = [x³/3 − x⁴/4]₀¹ = 1/3 − 1/4 = 1/12。

查看第4题答案

区域为三角形 0 ≤ y ≤ 1, y ≤ x ≤ 1（即 0 ≤ x ≤ 1, 0 ≤ y ≤ x），交换后为 ∫₀¹ dx ∫₀ˣ f(x,y) dy。口诀：先画区域草图，再重新定限。

查看第5题答案

球坐标 dV = r² sin φ dr dφ dθ，0 ≤ r ≤ R, 0 ≤ φ ≤ π, 0 ≤ θ ≤ 2π：V = ∫₀^2π dθ · ∫₀^π sin φ dφ · ∫₀^R r² dr = 2π · 2 · (R³/3) = (4/3)πR³。

查看第6题答案

球坐标 z = r cos φ，上半球 0 ≤ φ ≤ π/2：∭_Ω z dV = ∫₀^2π dθ · ∫₀^{π/2} cos φ sin φ dφ · ∫₀^R r³ dr = 2π · (1/2) · (R⁴/4) = πR⁴/4。
