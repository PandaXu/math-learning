第4章 不定积分

大学 / 高等数学

一句话总纲：不定积分是微分的逆运算——由「导数/变化率 f(x)」反推「原函数 F(x)」，得到的是相差任意常数的一族函数 F(x) + C；它在几何上是「由切线斜率还原整族曲线」，在物理上是「由速度还原位移、由加速度还原速度」。

4.1 不定积分的概念与性质

4.1.1 原函数

定义：设函数 f(x) 在区间 I 上有定义，若存在可导函数 F(x)，使得对区间 I 上每一点 x 都有

F'(x) = f(x)     (或  dF(x) = f(x) dx)

则称 F(x) 是 f(x) 在区间 I 上的一个原函数。

例：因为 (x²)' = 2x，所以 x² 是 2x 的一个原函数；因为 (sin x)' = cos x，所以 sin x 是 cos x 的一个原函数；因为 (eˣ)' = eˣ，所以 eˣ 是 eˣ 的一个原函数。

4.1.2 原函数的存在性与不唯一性

存在性定理：若 f(x) 在区间 I 上连续，则 f(x) 在 I 上必有原函数。（注意：连续是充分条件而非必要条件，某些不连续函数也可能有原函数。）

不唯一性：若 F(x) 是 f(x) 的一个原函数，则对任意常数 C，F(x) + C 也是 f(x) 的原函数，因为常数的导数为 0：

[F(x) + C]' = F'(x) = f(x)

反过来，同一区间上 f(x) 的任意两个原函数只相差一个常数。于是 f(x) 的全部原函数构成一族函数 {F(x) + C | C 为任意常数}。

几何含义（积分曲线族）：把 F(x) + C 画在坐标系里，得到的是彼此「沿 y 轴方向平移」的一族曲线——任取两条曲线，它们在同一个 x 处的切线斜率都等于 f(x)，所以曲线族在每一铅直方向上是「平行」的（切线互相平行）。已知导数 f(x) 只能确定曲线的形状与倾斜趋势，不能确定它上下落在哪个高度；那个「任意常数 C」就是整族曲线上下平移的幅度。
物理含义（运动学）：若已知速度函数 v(t) = f(t)，则位移 s(t) = F(t) + C 是 v(t) 的原函数。但仅凭速度无法确定初始位置——这正是常数 C 的物理意义：C = 初始条件（起点位置）。给定 s(t₀) = s₀ 才能把 C 定下来。同理，已知加速度求速度，也会多出一个「初速度」常数。

4.1.3 不定积分的定义与记号

定义：f(x) 在区间 I 上的全体原函数，称为 f(x) 在 I 上的不定积分，记作

∫ f(x) dx = F(x) + C

其中 ∫ 称为积分号（是拉长的 S，源自 sum「求和」），f(x) 称为被积函数，f(x) dx 称为被积表达式，x 称为积分变量，C 称为积分常数。

记号 dx 不是摆设：它指明「对哪个变量积分」，并来自微分 dF = F'dx = f dx 的逆过程。例：

∫ 2x dx = x² + C        （因为 (x² + C)' = 2x）
∫ cos x dx = sin x + C   （因为 (sin x + C)' = cos x）
∫ 1/x dx = ln|x| + C     （注意 x ≠ 0，绝对值保证对数有意义）

4.1.4 基本积分表

基本积分表就是基本导数公式「倒着读」，必须熟记（其中 α ≠ −1，且每行省略常数 C）：

1.  ∫ 0 dx = C
2.  ∫ xᵅ dx = xᵅ⁺¹/(α+1) + C        (α ≠ −1)
3.  ∫ 1/x dx = ln|x| + C
4.  ∫ eˣ dx = eˣ + C
5.  ∫ aˣ dx = aˣ/ln a + C            (a > 0, a ≠ 1)
6.  ∫ sin x dx = −cos x + C
7.  ∫ cos x dx = sin x + C
8.  ∫ sec²x dx = tan x + C
9.  ∫ csc²x dx = −cot x + C
10. ∫ sec x·tan x dx = sec x + C
11. ∫ csc x·cot x dx = −csc x + C
12. ∫ 1/(1+x²) dx = arctan x + C
13. ∫ 1/√(1−x²) dx = arcsin x + C

记忆要点：这些公式都是「谁的导数是它」。比如第 3 行对应 (ln|x|)' = 1/x；第 12 行对应 (arctan x)' = 1/(1+x²)；第 13 行对应 (arcsin x)' = 1/√(1−x²)。

4.1.5 不定积分的性质

（1）线性性质：积分可逐项进行，常数因子可提出：

∫ [k₁f(x) + k₂g(x)] dx = k₁∫ f(x) dx + k₂∫ g(x) dx

例：∫ (3x² + 2cos x) dx = 3·(x³/3) + 2sin x + C = x³ + 2sin x + C。

（2）微分与积分互逆（两种次序，结果略有差别）：

先积后微：  d/dx [ ∫ f(x) dx ] = f(x)       （求导还原被积函数）
先微后积：  ∫ F'(x) dx = F(x) + C           （积分比原函数多一个常数 C）

或写成微分形式：d∫ f(x)dx = f(x)dx、∫ dF(x) = F(x) + C。「先微后积」多出一个任意常数，这是理解不定积分一切性质的关键。

几何含义（方向场 / 斜率场）：把 f(x) 在平面上每一点 (x, y) 处画一段斜率为 f(x) 的小线段，得到的图形叫斜率场（方向场）。求 ∫f(x)dx 就是找一条处处与这些线段相切的光滑曲线；因为斜率场只规定「倾斜方向」而不管「高低」，所以解是一整族互相平移的曲线——不定积分 = 沿方向场「顺流而下」的全部轨迹。
物理含义（从变化率到总量）：不定积分是「已知变化率反推总量」的通用工具：速度 → 位移、加速度 → 速度、电流 i(t) → 电荷量 Q(t)（因 Q'(t) = i(t)）、边际成本 C'(x) → 总成本 C(x)、功率 → 功。凡是「某量的导数已知」的还原问题，都归结为求不定积分。

4.2 换元积分法

换元积分法的本质是复合函数求导（链式法则）的逆运算。链式法则 d[F(φ(x))]/dx = F'(φ(x))·φ'(x)，倒过来读，就得到换元积分。

4.2.1 第一换元法（凑微分法）

若被积表达式能凑成 f(φ(x))·φ'(x) dx 的形式，而 f 的原函数 F 已知，则

∫ f(φ(x))·φ'(x) dx = [ ∫ f(u) du ]  u=φ(x)  = F(φ(x)) + C

核心动作：把 φ'(x) dx「凑」成 dφ(x)，即令 u = φ(x)，dx 换为 du/dφ' 的形式。常用的凑微分公式：

dx = d(x + a)                    x dx = (1/2) d(x²)
eˣ dx = d(eˣ)                    (1/x) dx = d(ln|x|)
sin x dx = −d(cos x)             cos x dx = d(sin x)
sec²x dx = d(tan x)              (1/(1+x²)) dx = d(arctan x)
(1/√(1−x²)) dx = d(arcsin x)     (1/(2√x)) dx = d(√x)

例 1：∫ 2x·e^(x²) dx。令 u = x²，则 du = 2x dx，于是

∫ 2x·e^(x²) dx = ∫ eᵘ du = eᵘ + C = e^(x²) + C

例 2：∫ sin x·cos x dx。令 u = sin x，则 du = cos x dx：

∫ sin x·cos x dx = ∫ u du = u²/2 + C = (sin²x)/2 + C
几何含义（换视角再还原）：第一换元法相当于把「沿 x 轴的度量」换到「沿 u = φ(x) 的度量」上——用 φ(x) 做新的横坐标，把弯曲的坐标轴「拉直」，算出原函数后再换回 x。被积函数里那个 φ'(x) 正是两种坐标尺度之间的比例因子（尺度换算），类似地图上「比例尺」的变换。
物理含义（换单位 / 换参考量）：把自变量从 x 换成 u = φ(x)，在物理上常对应更换测量单位或参考量。例如把对时间 t 的积分换成对温度 T、对角度 θ、对能量 E 的积分，只要知道两者间的变化率 φ'(x)（即「单位换算率」），就能在新物理量下完成积分再还原。

4.2.2 第二换元法

第一换元是「令 u = φ(x) 作新变量」；第二换元反过来，主动令 x = ψ(t)（把 x 表示成新变量 t 的函数），则 dx = ψ'(t) dt，于是

∫ f(x) dx = ∫ f(ψ(t))·ψ'(t) dt = G(t) + C = G(ψ⁻¹(x)) + C

最后要把 t 用 x 表示回来（回代 t = ψ⁻¹(x)）。第二换元主要对付根式，三种典型代换：

（1）三角代换——利用平方和/差恒等式去掉根号：

含 √(a² − x²)：令 x = a·sin t   （利用 1 − sin²t = cos²t）
含 √(a² + x²)：令 x = a·tan t   （利用 1 + tan²t = sec²t）
含 √(x² − a²)：令 x = a·sec t   （利用 sec²t − 1 = tan²t）

例 3：求 ∫ 1/√(a² − x²) dx。令 x = a·sin t（−π/2 < t < π/2），dx = a·cos t dt，√(a²−x²) = a·cos t：

∫ 1/√(a²−x²) dx = ∫ (a·cos t)/(a·cos t) dt = ∫ 1 dt = t + C = arcsin(x/a) + C

（2）根式代换：被积函数含 ⁿ√(ax+b) 时，令 t = ⁿ√(ax+b)，把根号整体设成新变量。例：∫ √(x−1) dx，令 t = √(x−1)，则 x = t²+1，dx = 2t dt。

（3）倒代换：x = 1/t，适用于分母次数远高于分子的情形，可降低分母次数。

几何含义（重新参数化曲线）：第二换元 x = ψ(t) 就是把曲线用新参数 t 重新描述。三角代换的本质是把圆 x² + y² = a² 参数化成 x = a cos t、y = a sin t：根式 √(a²−x²) 正是圆上一点的纵坐标 y，换成角度参数 t 后，根号就「消掉了」——因为半径 a 在极坐标里是常数。这相当于把直角坐标下的曲线问题搬到极坐标/参数坐标下，让对称性显形。
物理含义（换坐标系 / 换参考系）：三角代换对应「从直角坐标换到极坐标/角度描述」：求一个圆周运动相关的量，用角度 θ 比用直角坐标 x 更自然。倒代换 x = 1/t 对应「把无穷远与原点对调」，处理远场（x 很大）问题时把大距离折算成小量。

4.3 分部积分法

分部积分法源自乘积的导数法则：(uv)' = u'v + uv'，移项并积分：

∫ uv' dx = uv − ∫ u'v dx         即        ∫ u dv = uv − ∫ v du

其中 u = u(x)、v = v(x)。要点：把被积函数拆成 u 与 dv 两部分，让 dv 容易积出 v，并且新积分 ∫ v du 比原积分更简单。

4.3.1 u 的选取顺序（LIATE / 反—对—幂—三—指）

当被积函数是两类不同函数相乘时，按下列优先级选 u（越靠前越优先当 u，其余部分凑成 dv）：

反三角函数  >  对数函数  >  幂函数（代数）  >  三角函数  >  指数函数
（Anti）      （Log）      （Algebra）       （Trig）       （Exp）

直觉：「好积分」的部分留给 dv，先积分掉；「好求导」的部分当 u，让它在下一步被求导降下来。指数函数、三角函数求导不降复杂度，幂函数求导降次数，而对数、反三角求导会「变得简单」（ln x → 1/x，arctan x → 1/(1+x²)），所以对数和反三角优先当 u。

例 4：∫ x·eˣ dx。按 LIATE，幂函数 x 优先于指数 eˣ，取 u = x、dv = eˣ dx，则 du = dx、v = eˣ：

∫ x·eˣ dx = x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = (x − 1)eˣ + C

例 5：∫ ln x dx。对数函数优先当 u，取 u = ln x、dv = dx，则 du = (1/x)dx、v = x：

∫ ln x dx = x·ln x − ∫ x·(1/x) dx = x·ln x − x + C = x(ln x − 1) + C

4.3.2 三种典型情形

（1）降幂型：∫ xⁿ·eˣ dx、∫ xⁿ·sin x dx 等，取 u = xⁿ，每做一次分部积分，幂次降 1，重复 n 次即可。例：∫ x²·eˣ dx 做两次分部积分得 (x² − 2x + 2)eˣ + C。

（2）循环型：被积函数含有 eˣ 与 sin x（或 cos x）相乘时，两次分部积分后原积分会「重现」，把它当作未知量移项解出。例：

∫ eˣ·sin x dx = (eˣ sin x − eˣ cos x)/2 + C   （两次分部后移项解出）

（3）递推型：∫ sinⁿx dx、∫ (x²+a²)⁻ⁿ dx 等，用分部积分建立「Iₙ 与 Iₙ₋₁（或 Iₙ₊₁）」之间的递推公式，从低次逐步算出高次。例：∫ sinⁿx dx 的递推可逐步化到 ∫ sin x dx = −cos x + C。

几何含义（面积的守恒分配）：由 (uv)' = u'v + uv' 积分得 uv = ∫u'v dx + ∫uv' dx，即 uv = ∫v du + ∫u dv。在几何上，乘积 uv 是一个「矩形总面积」，分部积分就是把这个矩形面积拆成两块互补的部分 ∫v du 与 ∫u dv，把难算的那块（∫u dv）转化为总面积 uv 减去好算的那块（∫v du）——本质是一种「面积守恒 + 补形」技巧。
物理含义（功与能量、分部与分配）：若 v 表示速度、u 表示某个随时间变化的量（如力或质量），则 ∫u dv 可理解为「力随位移积累的功」。分部积分把「对 dv（位移）的积累」换成「uv 的整体量减去对 du 的积累」，对应物理中把总能量拆成两部分再重组的配分思想，例如 d(mv) = m·dv + v·dm 是变质量问题的核心。

4.4 有理函数的积分

有理函数是两个多项式之商 R(x) = P(x)/Q(x)（P、Q 为多项式，Q ≠ 0）。任何有理函数的原函数都是初等函数，因此有理函数积分有系统化的通用算法。

4.4.1 化假分式为「多项式 + 真分式」

若分子次数 ≥ 分母次数（假分式），先做多项式长除法，写成

P(x)/Q(x) = 多项式 + 真分式

其中真分式分子次数 < 分母次数。多项式部分逐项直接积分。

4.4.2 真分式的部分分式分解

把分母 Q(x) 在实数范围内分解为一次因式与不可约二次因式的幂的乘积，再按下列规则把真分式拆成部分分式之和：

（一）Q(x) 含单因子 (x − a)：拆出  A/(x − a)
（二）Q(x) 含重因子 (x − a)ᵏ：拆出  A₁/(x−a) + A₂/(x−a)² + … + Aₖ/(x−a)ᵏ
（三）Q(x) 含不可约二次因子 (x² + px + q)（Δ = p²−4q < 0）：
        拆出  (Mx + N)/(x² + px + q)
（四）Q(x) 含重二次因子 (x² + px + q)ᵏ：
        拆出  (M₁x+N₁)/(x²+px+q) + … + (Mₖx+Nₖ)/(x²+px+q)ᵏ

系数 A、M、N 由通分后比较分子系数（或代入特殊 x 值）解出。

4.4.3 四种基本类型的不定积分

部分分式分解后，积分归结为下面四种标准型：

(Ⅰ)  ∫ A/(x − a) dx = A·ln|x − a| + C

(Ⅱ)  ∫ A/(x − a)ᵏ dx = A/(1−k)·(x − a)^(1−k) + C    (k > 1)

(Ⅲ)  ∫ (Mx + N)/(x² + px + q) dx
        = (M/2)·ln(x² + px + q) + (N − Mp/2)·(2/√(4q−p²))·arctan((2x+p)/√(4q−p²)) + C
        （先凑分子为 (2x+p) 的倍数 + 常数，再配方用 arctan）

(Ⅳ)  ∫ (Mx + N)/(x² + px + q)ᵏ dx    （k > 1）
        = 用配方、换元 t = x + p/2 化为 (t² + a²)⁻ᵏ 与 t(t²+a²)⁻ᵏ 之和，
          前者由递推公式计算

其中第 (Ⅲ) 型的配方细节最常用：x² + px + q = (x + p/2)² + (q − p²/4)，令 t = x + p/2、a² = q − p²/4，则

∫ 1/(x² + px + q) dx = ∫ 1/(t² + a²) dt = (1/a)·arctan(t/a) + C

4.4.4 可化为有理函数的积分

（1）三角有理式 ∫ R(sin x, cos x) dx（R 为有理函数）：用万能代换 t = tan(x/2)，则

sin x = 2t/(1+t²)，  cos x = (1−t²)/(1+t²)，  dx = 2/(1+t²) dt

代入后化为 t 的有理函数积分。当被积函数关于 sin x、cos x 有奇偶对称性时，可先用更简单的代换（如 t = tan x 或 t = cos x）。

（2）含简单根式 ⁿ√(ax+b) 或 ⁿ√((ax+b)/(cx+d)) 的积分：令 t = ⁿ√(…)，化为有理函数。

几何含义（复杂曲线拆成基本曲线）：部分分式分解在几何上相当于把一条「复杂的有理曲线 y = R(x)」拆成若干条最简单曲线的叠加：A/(x−a) 对应双曲型曲线（积出对数），(Mx+N)/(x²+px+q) 对应「钟形 + 反正切型」曲线（积出 ln 与 arctan）。任何有理函数的面积都可以由这些基本形状线性叠加而成——这是「分解再合成」的分析思想。
物理含义（系统响应与叠加原理）：在电路、控制系统、信号处理中，有理函数常是传递函数。分母的一次因式 (x−a) 对应一阶惯性环节（指数衰减 eᵃᵗ），二次因式对应二阶振荡环节（eᵖᵗ sin/cos 型振荡）。部分分式分解就是把系统总响应拆成这些基本环节响应的线性叠加——这正是线性系统的叠加原理。

典型例题（自测）

例题

  1. 求 ∫ (3x² + 5/x − 2sin x) dx。
  2. 用第一换元法求 ∫ x·cos(x²) dx 与 ∫ eˣ/(1+eˣ) dx。
  3. 用第二换元法（三角代换）求 ∫ 1/√(a² + x²) dx（提示：令 x = a·tan t）。
  4. 用分部积分法求 ∫ x·sin x dx 与 ∫ arctan x dx。
  5. 用循环型分部积分求 ∫ e²ˣ·cos 3x dx。
  6. 把 (3x + 5)/(x² − 1) 分解为部分分式，并求其不定积分。
  7. 求 ∫ 1/(x² + 2x + 5) dx（提示：配方后化为 arctan 型）。
  8. 用万能代换 t = tan(x/2) 求 ∫ 1/(1 + cos x) dx。

常见误区

常见误区

  • ❌ 「忘了加积分常数 C」 → ❌ 不定积分是一族函数，丢 C 就是丢掉无穷多个解；「先微后积」必多一个 C。
  • ❌ 「∫ 1/x dx = ln x + C」 → ❌ 应为 ln|x| + C，x 为负时也必须有意义。
  • ❌ 「∫ xᵅ dx = xᵅ⁺¹/(α+1) 对一切 α 成立」 → ❌ 当 α = −1 时是 ln|x|，不能套幂公式。
  • ❌ 「换元后忘了回代」 → ❌ 第二换元 x = ψ(t) 求出 G(t) 后必须代回 t = ψ⁻¹(x)，否则结果含新变量 t 是错的。
  • ❌ 「三角代换 x = a·sin t 时 √(a²−x²) = a·sin t」 → ❌ 应为 a·cos t（用 1 − sin²t = cos²t，且取 t ∈ (−π/2, π/2) 保证 cos t ≥ 0）。
  • ❌ 「分部积分时 u 与 dv 随便拆」 → ❌ 拆错方向会让 ∫ v du 越来越复杂；应按 LIATE 顺序，对数、反三角优先当 u。
  • ❌ 「假分式直接分解部分分式」 → ❌ 必须先用长除法化为「多项式 + 真分式」，只有真分式才能做部分分式分解。
  • ❌ 「二次因式部分分式分子写成 A」 → ❌ 不可约二次因式对应的部分分式分子必须是一次式 Mx + N，不是常数。
  • ❌ 「循环型分部积分遇到原积分重现就以为无解」 → ❌ 此时应把原积分当未知量移项解出（系数相减），而不是死循环。

课本外 · 典故与思考

典积分号 ∫ 的来历：一个被拉长的字母 S（点击展开）

先看直觉：积分号 ∫ 长得像拉长的 S。这不是巧合——它本来就是拉丁文 summa（和、总和）的首字母，是莱布尼茨 1675 年 10 月 29 日前后在一份手稿中首次写下的记号，用来表示"无穷多项的和"。

为什么"积分"要叫"和"？在莱布尼茨看来，求面积、求总路程这类问题，本质都是把无穷多个"微小的量"累加起来：

∫ f(x) dx = 把所有 f(x)dx 加起来  （dx 是"微小的宽"，f(x)dx 是"细条面积"）

他同时创造了配套的记号：把"微小的差"记作 dx，把"和"记作拉长的 ∫——这一对记号互为逆运算，正是不定积分"逆运算"思想在符号上的体现：d(∫ f(x)dx) = f(x)dx，∫ df(x) = f(x) + C。

中文"积分"一词：1859 年，李善兰与伟烈亚力合译《代微积拾级》（据美国数学家 Loomis 的微积分教材翻译），首次把 integral calculus 译作"积分"、differential calculus 译作"微分"——"积"取"累积、求和"之义，与拉丁文 summa 的"和"一脉相承，沿用至今已 160 多年。

一句话总结：∫ 是莱布尼茨给"求和"画的标志，dx 是给"微小量"画的标志——不定积分"逆微分"的直觉，从一开始就被刻进了记号本身。
思为什么没有"万能求积分公式"？——有些积分真的"积不出来"（点击展开）

先看直觉：本章学了换元、分部、有理函数分解，每道题都有招。但你可能会疑惑：能不能总结出一条"万能公式"，把任何函数的积分都算出来？答案是：不能，而且不是因为技巧不够。

刘维尔的发现：1830 年代，法国数学家刘维尔（Joseph Liouville，1809–1882）严格证明了：以下积分不存在初等原函数（不能用有限次加减乘除、幂、指数、对数、三角函数表示）：

∫ e^(x²) dx      ∫ e^(−x²) dx      ∫ sin x / x dx      ∫ eˣ / x dx

也就是说，无论你换多少次元、分多少次部，这些"积不出来"的量都不是你没算对，而是数学结构上就不存在初等结果——它们是"另一个级别的函数"。

物理含义：这些"积不出来"的积分反而在物理与工程中到处出现：∫ e^(−x²)dx 是正态分布与误差函数 erf(x)（概率论、统计物理）的核心；∫ sin x / x dx 是正弦积分函数 Si(x)（光学衍射、信号处理）。数学家的对策是：给它们起个新名字（erf、Si 等）并做成函数表/数值算法——"积不出来"于是变成了"定义了新函数"。

反过来看本章：换元法、分部法并不是在"碰运气"，而是刘维尔理论划定的"初等可积范围"里的系统手段。遇到表里没有、又明显可积的被积函数，多想想形式上的线索（含 f′(x)·g(f(x)) 想换元、多项式×指数/三角想分部），就是在高效地利用这块"可积领地"。

一句话总结：求不定积分是一门"识别可积结构"的学问，而不是一劳永逸的公式库——刘维尔告诉我们哪些能积、哪些天生不能，而本章的技巧，就是处理"能积"那部分的最佳路径。

本章练习卷（含答案）

一、练习题

  1. 验证：x²、x² + 1、x² − 5 都是 2x 的原函数，并写出 ∫ 2x dx 的一般结果。为什么答案必须带上 +C？
  2. （几何含义）已知某曲线的切线斜率处处为 f(x) = 2x，且该曲线过点 (1, 3)。求曲线方程，并说明为什么必须给出这个「过点」条件才能定出唯一曲线。
  3. 用第一换元法（凑微分）求 ∫ 2x·e^(x²) dx。
  4. （物理含义）质点沿直线运动，速度 v(t) = 3t²，且 t = 0 时位移 s = 1。求位移函数 s(t)，并指出常数 C 的物理意义。
  5. 用分部积分法求 ∫ x·sin x dx。
  6. 把 (3x + 5)/(x² − 1) 分解为部分分式，并求其不定积分。

二、参考答案（点击展开）

查看第1题答案

因为 (x²)' = (x² + 1)' = (x² − 5)' = 2x，所以 x²、x² + 1、x² − 5 都是 2x 的原函数；∫ 2x dx = x² + C。+C 表示「相差任意常数的一族函数」：同一个导数对应沿 y 轴上下平移的一整族曲线，若不加 C 就会漏掉无穷多个原函数。

查看第2题答案

y = ∫ 2x dx = x² + C。代入点 (1, 3)：3 = 1 + C，得 C = 2，故曲线为 y = x² + 2。仅凭斜率 f(x) 只能确定曲线的「形状/倾斜趋势」（一族互相平移的曲线），「过点」给出的是初始高度（初始条件），用来把任意常数 C 定下来。

查看第3题答案

令 u = x²，则 du = 2x dx。∫ 2x·e^(x²) dx = ∫ eᵘ du = eᵘ + C = e^(x²) + C。关键是把 2x dx 凑成 d(x²)，即「凑微分」。

查看第4题答案

s(t) = ∫ 3t² dt = t³ + C。由 s(0) = 1 得 C = 1，故 s(t) = t³ + 1。这里的 C 就是初始位置：只知速度只能还原出「相差一个常数的全部运动」，初始条件 s(0) 才能确定唯一轨迹。

查看第5题答案

取 u = x、dv = sin x dx，则 du = dx、v = −cos x。∫ x·sin x dx = −x cos x − ∫ (−cos x) dx = −x cos x + sin x + C。按 LIATE 顺序，幂函数 x 优先当 u，三角函数 sin x 凑成 dv。

查看第6题答案

x² − 1 = (x − 1)(x + 1)。设 (3x + 5)/(x² − 1) = A/(x − 1) + B/(x + 1)，通分得 3x + 5 = A(x + 1) + B(x − 1)。令 x = 1：8 = 2A → A = 4；令 x = −1：2 = −2B → B = −1。于是原式 = ∫ [4/(x − 1) − 1/(x + 1)] dx = 4ln|x − 1| − ln|x + 1| + C。
