第2章 导数与微分

大学 / 高等数学

一句话总纲：导数 = 「曲线的切线斜率」= 「瞬时变化率」。学完本章，你要能在心里同时"看见"两件事：几何上，f′(x₀) 是曲线 y=f(x) 在点 x₀ 处切线的斜率；物理上，它是量在 x₀ 这一瞬的变化快慢（速度、加速度、增长率）。而微分是"以直代曲"的工具——用切线上的增量 dy 去近似曲线上的增量 Δy。

2.1 导数的概念

导数从两个经典问题而来

微积分的诞生源于两个看似无关、实则同构的问题：

  • 几何问题——切线：给定曲线 y=f(x) 上一点 P(x₀, f(x₀))，如何求过 P 的切线斜率？
  • 物理问题——瞬时速度：变速直线运动中，如何求某一时刻 t₀ 的瞬时速度（而不是一段时间的平均速度）？

两者的共同套路都是「先算平均变化率，再让时间/距离间隔趋近于 0 取极限」：

平均变化率 = Δy/Δx = [f(x₀+Δx) − f(x₀)] / Δx
瞬时变化率 = lim(Δx→0) Δy/Δx

导数的定义

设函数 y=f(x) 在点 x₀ 的某个邻域内有定义。给自变量一个增量 Δx（Δx ≠ 0），函数相应地有增量 Δy = f(x₀+Δx) − f(x₀)。若极限

lim(Δx→0)  Δy/Δx  =  lim(Δx→0)  [f(x₀+Δx) − f(x₀)] / Δx

存在，则称 f(x) 在点 x₀ 处可导，这个极限值称为 f(x) 在点 x₀ 处的导数，记作：

f′(x₀) ,  y′|_(x=x₀) ,  dy/dx|_(x=x₀) ,  df/dx|_(x=x₀)

等价形式（换元 h = Δx 或直接令 x → x₀）：

f′(x₀) = lim(h→0) [f(x₀+h) − f(x₀)] / h
f′(x₀) = lim(x→x₀) [f(x) − f(x₀)] / (x − x₀)

左导数与右导数：单侧极限

f₋′(x₀) = lim(h→0⁻) [f(x₀+h) − f(x₀)] / h
f₊′(x₀) = lim(h→0⁺) [f(x₀+h) − f(x₀)] / h

可导的充要条件：f(x) 在 x₀ 处可导 ⟺ 左导数与右导数都存在且相等。

导函数：若 f(x) 在区间 I 内每一点都可导，则对应关系 x ↦ f′(x) 是 I 上的一个新函数，称为导函数，简称导数：

f′(x) = lim(h→0) [f(x+h) − f(x)] / h

几何含义：切线的斜率

在曲线 y=f(x) 上取 P(x₀, f(x₀)) 与邻近点 Q(x, f(x))，割线 PQ 的斜率为 [f(x) − f(x₀)]/(x − x₀)。当 Q 沿曲线无限逼近 P（x → x₀）时，割线绕 P 旋转、极限位置就是切线。因此：

f′(x₀) = 曲线 y=f(x) 在点 (x₀, f(x₀)) 处切线的斜率
  • 切线方程：y − f(x₀) = f′(x₀)(x − x₀)
  • 法线方程（垂直于切线）：y − f(x₀) = −(1/f′(x₀))(x − x₀)　（f′(x₀) ≠ 0）
几何含义：导数是"割线斜率的极限"——先画一条割线（两个点），再让其中一个点滑向另一个点，割线最终定格成的直线就是切线，其斜率就是导数。f′(x₀) > 0 表示曲线在该点上升，f′(x₀) < 0 表示下降，f′(x₀) = 0 表示该点处切线水平。

物理含义：瞬时变化率

在变速直线运动中，位移 s=s(t)：

平均速度 = Δs/Δt = [s(t₀+Δt) − s(t₀)] / Δt
瞬时速度 v(t₀) = s′(t₀) = lim(Δt→0) Δs/Δt

更一般地，导数就是瞬时变化率：y 关于 x 的导数 f′(x) 描述"当 x 变一点点时，y 变多快"。物理与工程中处处可见：

  • 速度：位移对时间的导数 v = ds/dt
  • 加速度：速度对时间的导数 a = dv/dt
  • 电流：电量对时间的导数 i = dq/dt
  • 增长率：人口、细菌数量对时间的导数
  • 边际量（经济）：边际成本 = 总成本对产量的导数
物理含义：导数把"一段时间内的平均快慢"压缩成"这一瞬的快慢"。速度表上的读数，就是位移函数在该时刻的导数。

可导与连续的关系

定理：若 f(x) 在 x₀ 处可导，则 f(x) 在 x₀ 处必连续。（可导 ⟹ 连续）

反之不成立：连续不一定可导。经典反例是 y = |x| 在 x=0 处：

f₋′(0) = −1， f₊′(0) = +1  ⟹  左、右导数不相等，故在 x=0 不可导

函数在某点不可导的常见几何情形：尖点（如 |x| 的拐角）、切线垂直于 x 轴（如 y = ∛x 在 x=0 处切线为铅直线）、间断点、有振荡等。

几何/物理含义：「连续」= 曲线不断裂（一笔能画下去）；「可导」= 曲线光滑（没有折角、有唯一不垂直于 x 轴的切线）。|x| 在 0 点"有个尖"，连续的线却突然折了个角——对应物理上"速度方向瞬间突变"的运动。

2.2 求导法则

求导不能每次都从极限定义出发，而要建立一套"运算规则"：先记住基本初等函数的导数（公式表），再用四则运算、链式法则把复杂函数拆解求导。

基本初等函数的导数公式

函数 f(x)导数 f′(x)函数 f(x)导数 f′(x)
C（常数）0xμ（μ 为实数）μ xμ−1
sin xcos xcos x−sin x
tan xsec²xcot x−csc²x
sec xsec x·tan xcsc x−csc x·cot x
axax ln aexex
loga x1/(x ln a)ln x1/x
arcsin x1/√(1−x²)arccos x−1/√(1−x²)
arctan x1/(1+x²)arccot x−1/(1+x²)
物理含义：这张表是"变化率的字典"。例如 (ex)′ = ex 说明指数增长的增长率等于自身——钱越多、涨得越快；(sin x)′ = cos x 说明正弦波的"上升快慢"恰好是相位提前 π/2 的余弦。

四则运算法则

(u ± v)′ = u′ ± v′
(Cu)′    = C·u′                     （C 为常数）
(uv)′    = u′v + uv′
(u/v)′   = (u′v − uv′)/v²            （v ≠ 0）

例：y = x³ + 3 sin x − ex + 5，则 y′ = 3x² + 3 cos x − ex。

物理含义：变化率是"线性"的——几个量叠加时，总变化率等于各变化率之和；(uv)′ = u′v + uv′ 是"两者都在变"时的乘法规则：乘积的变化 = (u 的增量)(v) + (u)(v 的增量)。

复合函数求导：链式法则

若 u = g(x) 在 x 处可导，y = f(u) 在对应点 u = g(x) 处可导，则复合函数 y = f(g(x)) 在 x 处可导，且

dy/dx = dy/du · du/dx    即    [f(g(x))]′ = f′(g(x)) · g′(x)

例：y = ln(sin x)。外层 f(u) = ln u，内层 u = sin x：

y′ = (1/u) · cos x = (1/sin x)·cos x = cot x
物理含义：链式法则是"变化率的乘法传递"。y 随 u 变化快 f′(u)，u 随 x 变化快 g′(x)，那么 y 随 x 的变化率 = 两者相乘。类比：每小时工资 × 每天工作小时数 = 每天收入的"变化速率"。

反函数求导

设 y=f(x) 在区间内单调、可导且 f′(x) ≠ 0，则它的反函数 x = φ(y) 也可导，且

φ′(y) = 1/f′(x)    即    dx/dy = 1/(dy/dx)

例：y = arcsin x 是 x = sin y 的反函数，故

(arcsin x)′ = 1/(cos y) = 1/√(1−sin²y) = 1/√(1−x²)   （因 cos y > 0）
几何含义：y=f(x) 与其反函数 x=φ(y) 的图像关于直线 y=x 对称；一条直线的斜率 m 经 y=x 镜像后变成 1/m，所以反函数在对应点的切线斜率互为倒数。

2.3 高阶导数

定义

导函数 f′(x) 若仍可导，它的导数称为 f(x) 的二阶导数，记作 f″(x) 或 d²y/dx²。逐次求下去得到 n 阶导数：

f″(x) = [f′(x)]′
f‴(x) = [f″(x)]′
f⁽ⁿ⁾(x) = [f⁽ⁿ⁻¹⁾(x)]′   （n ≥ 2；n ≥ 4 时也记作 f⁽ⁿ⁾）

物理含义：加速度

位移 s=s(t) 的一阶导数是速度 v(t)，二阶导数就是加速度：

v(t) = s′(t) = ds/dt
a(t) = s″(t) = d²s/dt² = dv/dt
物理含义：二阶导数是"变化率的变化率"——速度变多快，即加速度。一阶导回答"走多快"，二阶导回答"越来越快还是越来越慢"。

几何含义：弯曲的方向

f″(x) 刻画曲线弯曲的方向（凹凸性，第3章将系统展开）：

  • f″(x) > 0：切线斜率 f′(x) 随 x 递增，曲线向上凹（开口朝上）。
  • f″(x) < 0：切线斜率 f′(x) 随 x 递减，曲线向下凹（开口朝下）。
几何含义：f″ 是"切线斜率的变化率"——正表示切线越转越陡地向上翘，负表示越转越平/向下弯。它与曲线曲率（弯得有多急）密切相关。

常见函数的高阶导数

(xⁿ)⁽ᵏ⁾ = n(n−1)…(n−k+1)·xⁿ⁻ᵏ        （k ≤ n；k > n 时为 0）
(eˣ)⁽ⁿ⁾ = eˣ
(sin x)⁽ⁿ⁾ = sin(x + nπ/2)
(cos x)⁽ⁿ⁾ = cos(x + nπ/2)
(ln x)⁽ⁿ⁾ = (−1)ⁿ⁻¹·(n−1)!/xⁿ
物理含义：sin 每求一次导就"相位前移 π/2"——sin → cos → −sin → −cos → sin，四次一个循环，这正是简谐振动中"位移、速度、加速度"依次相差 π/2 相位的数学根源。

莱布尼茨公式（乘积的高阶导数）

(uv)⁽ⁿ⁾ = Σ(k=0..n) C(n,k)·u⁽ⁿ⁻ᵏ⁾·v⁽ᵏ⁾
C(n,k) = n!/[k!(n−k)!]

它与二项式定理 (a+b)n 的展开形式完全一致，只是把"幂次"换成了"求导阶数"。

2.4 隐函数与参数方程求导

隐函数求导

若方程 F(x, y) = 0 确定了一个隐函数 y = y(x)，不必（有时也无法）先解出显式 y，而是把 y 看成 x 的函数，对方程两边关于 x 求导，用链式法则处理 y，再解出 y′。

例：单位圆 x² + y² = 1。

两边对 x 求导：2x + 2y·y′ = 0
解得：y′ = −x/y
几何含义：隐函数求导在不显式解出曲线方程的情况下，直接给出曲线在任一点 (x, y) 处的切线斜率。圆 x²+y²=1 在点 (x, y) 的切线斜率是 −x/y——恰是"半径斜率 y/x 的负倒数"，说明切线垂直于半径。

对数求导法

对幂指函数、连乘除、开方等情形，先取对数再求导可大大简化。原理：

y = f(x)  ⟹  ln|y| = ln|f(x)|  ⟹  y′/y = [ln|f(x)|]′  ⟹  y′ = y·[ln|f(x)|]′

例：y = xx（x > 0）。

ln y = x ln x  ⟹  y′/y = ln x + 1  ⟹  y′ = xˣ(ln x + 1)
物理含义：对数把"乘法变成加法、幂变成乘法"，于是复杂的增长率分解为若干简单增长率之和——在经济学中这就是"增长率叠加"（如 GDP = 价格 × 数量，其增长率 ≈ 通胀率 + 数量增长率）。

参数方程求导

设曲线由参数方程 x = φ(t)、y = ψ(t) 确定，且 φ′(t) ≠ 0，则

dy/dx = (dy/dt)/(dx/dt) = ψ′(t)/φ′(t)
d²y/dx² = d(dy/dx)/dx = [d(dy/dx)/dt] / (dx/dt)

例：椭圆 x = a cos t，y = b sin t。

dx/dt = −a sin t，dy/dt = b cos t
dy/dx = (b cos t)/(−a sin t) = −(b/a) cot t
几何/物理含义：参数方程把曲线看成"质点随时间运动的轨迹"。dx/dt、dy/dt 是速度的两个分量，dy/dx = (dy/dt)/(dx/dt) = vy/vx 正是速度方向（轨迹切线方向）的斜率——质点运动方向永远沿轨迹切线。

2.5 微分

定义

设 y=f(x) 在 x₀ 处可导，则函数增量 Δy 可写成：

Δy = f(x₀+Δx) − f(x₀) = f′(x₀)·Δx + o(Δx)

其中 o(Δx) 是比 Δx 更高阶的无穷小。我们称线性部分 f′(x₀)·Δx 为 f(x) 在 x₀ 处的微分，记作

dy = f′(x₀)·Δx = f′(x₀)·dx      （规定自变量的微分 dx = Δx）

因此可导与可微等价，且 dy/dx = f′(x₀)：导数就是"微分之商"（这也解释了 dy/dx 这个记号的来源）。

几何含义：切线上的增量

几何含义：当 x 从 x₀ 变到 x₀+Δx 时，曲线上的真实增量是 Δy（沿曲线走），而微分 dy 是切线上的增量（沿切线走）。用切线代替曲线——"以直代曲"，两者之差 o(Δx) 是高阶无穷小，Δx 越小越精确。

物理含义：微小变化的线性近似

物理含义：微分是"小变化量的近似"。位移 s=s(t) 中 ds = v·dt：在极短时间 dt 内，用"匀速"近似"变速"，位移 ≈ 速度 × 时间。任何量的小变化 ≈ (变化率) × (自变量小变化)。

微分的运算法则

d(u ± v) = du ± dv
d(uv) = v du + u dv
d(u/v) = (v du − u dv)/v²
d(f(g(x))) = f′(g(x))·g′(x)·dx = f′(u)·du

一阶微分形式不变性：无论 u 是自变量还是中间变量，dy = f′(u) du 的形式都不变。

近似计算（线性近似）

由 Δy ≈ dy 得近似公式：

f(x₀+Δx) ≈ f(x₀) + f′(x₀)·Δx

取 x₀=0，令 Δx=x（|x| 很小），得到常用近似公式：

(1+x)^α ≈ 1 + αx        e^x ≈ 1 + x        ln(1+x) ≈ x
sin x ≈ x                tan x ≈ x          arctan x ≈ x
物理含义：这些是"小角度/小量近似"的数学来源，如单摆小振幅时 sin θ ≈ θ、热胀冷缩、相对误差估算等，本质都是"在很小范围内用切线替代曲线"。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
导数 f′(x₀)曲线在 (x₀, f(x₀)) 处切线的斜率瞬时变化率（瞬时速度、增长率、边际量）
可导与连续可导=光滑（有唯一切线）；连续=不断裂轨迹连续但可能有"折角"（速度方向突变）
基本求导公式各基本曲线的"斜率函数"各基本运动/过程的变化率规律
四则运算法则和差积商曲线斜率的合成多个变化率的线性组合与乘积分解
链式法则复合函数切线的"斜率传递"变化率的乘法传递（复合速率）
反函数求导图像关于 y=x 对称，斜率互为倒数自变量/因变量角色互换后速率互为倒数
高阶导数 f″凹凸性、切线斜率的变化率、曲率加速度（速度的变化率）
隐函数求导不显式解出曲线也能求切线斜率隐式约束下变量间的变化率关系
参数方程求导轨迹切线方向 = 速度分量之比运动方向：斜率 = vy/vx
微分 dy切线上的增量（以直代曲）微小变化的线性近似（ds = v·dt）

典型例题（自测）

  1. 用定义求导：用导数定义求 f(x) = x² 在 x=1 处的导数。
    提示：f′(1) = lim(h→0) [(1+h)² − 1]/h = lim(h→0)(2h+h²)/h = 2。
  2. 四则运算：求 y = x³ + 3 sin x − ex + 7 的导数。
    答案：y′ = 3x² + 3 cos x − ex。
  3. 链式法则：求 y = ln(sin x) 的导数。
    答案：y′ = cos x / sin x = cot x。
  4. 对数求导：求 y = xx（x > 0）的导数。
    答案：y′ = xx(ln x + 1)。
  5. 隐函数求导：由 x² + y² = r² 确定 y=y(x)，求 dy/dx，并写出圆在点 (3, 4)（r=5）处的切线斜率。
    答案：y′ = −x/y；在 (3,4) 处斜率 = −3/4。
  6. 参数方程求导：椭圆 x = a cos t，y = b sin t，求 dy/dx 及 t = π/4 处的切线斜率。
    答案：dy/dx = −(b/a) cot t；t=π/4 时 = −b/a。
  7. 高阶导数：求 y = ex cos x 的二阶导数。
    答案：y′ = ex(cos x − sin x)，y″ = −2ex sin x。
  8. 微分与近似：y = x³ 在 x=2、Δx=0.1 处，求微分 dy 与增量 Δy 的差。
    答案：dy = 3·2²·0.1 = 1.2；Δy = 2.1³ − 2³ = 1.261；误差 0.061（高阶小量）。

常见误区

  • ❌ "导数就是切线" → ❌ 导数是切线的斜率（一个数），切线是过切点的一条直线（一个几何对象）。
  • ❌ "可导与连续等价" → ❌ 可导必连续，但连续不一定可导（如 y=|x| 在 0 处连续却不可导）。
  • ❌ "(f(g(x)))′ = f′(x)·g′(x)" → ❌ 链式法则必须"外层在 内层值处求导"：[f(g(x))]′ = f′(g(x))·g′(x)。
  • ❌ "(uv)′ = u′v′" → ❌ 乘积法则要"交叉相加"：(uv)′ = u′v + uv′。
  • ❌ "d²y/dx² 等于 (dy/dx)²" → ❌ d²y/dx² 是二阶导数（求导两次），(dy/dx)² 是一阶导数的平方，两者完全不同。
  • ❌ "参数方程二阶导 = ψ″(t)/φ″(t)" → ❌ 二阶导数要对 dy/dx 再对 x 求导：d²y/dx² = [d(dy/dx)/dt]/(dx/dt)，分母仍是 φ′(t)。
  • ❌ "隐函数求导忘了 y 是 x 的函数" → ❌ 对 y 求导必须乘 y′：d(y²)/dx = 2y·y′，而不是 2y。
  • ❌ "微分 dy 与增量 Δy 相等" → ❌ 一般 Δy ≠ dy；Δy = dy + o(Δx)，dy 只是 Δy 的线性主部。
  • ❌ "反函数求导 (φ)′(y) = 1/f′(y)" → ❌ 应代入原自变量 x：(φ)′(y) = 1/f′(x)，其中 x 与 y 满足 y=f(x)。

课本外 · 典故与思考

史牛顿与莱布尼茨：一场跨越英吉利海峡的发明权之争（点击展开）

先看直觉：今天全世界用的导数记号 dy/dx 是莱布尼茨的，而把导数称为"变化率"的物理直觉，是牛顿先建立的——两个人各自独立地发明了微积分，却为此吵了半辈子。

  • 牛顿（1642–1727）：约 1665–1666 年因瘟疫避居乡间时建立了"流数法"：把变量看成流动的量，导数就是流动的"流数"，物理画面是速度和加速度。但他迟迟没有系统发表，直到 1687 年的《自然哲学的数学原理》才以几何形式公之于众，流数法本身更晚才整理出版。
  • 莱布尼茨（1646–1716）：1675 年前后独立发明微分与积分，1684 年在《教师学报》发表第一篇微积分论文，并创造了一整套沿用至今的记号：dy/dx、积分号 ∫、记号 dx 表示"微小的差"。

争端：1708 年起有人公开指控莱布尼茨剽窃牛顿。莱布尼茨向英国皇家学会申诉，1712 年学会的调查报告（由牛顿本人主导撰写）判定牛顿优先。事后研究认为两人是独立发明，但这场争端让英欧数学界对立了几十年——英国固守牛顿的几何与点记号，错失了莱布尼茨记号的传播期，数学发展一度落后于大陆。

一句话总结：同一座数学大厦，两个人各搭了一半脚手架：牛顿给了"变化率"的物理直觉，莱布尼茨给了"能运算的记号"——今天课本里的 dy/dx，正是这场争论的"幸存者"。
思莱布尼茨记号为什么"好用"？——dy/dx 不是分数，却假装是分数（点击展开）

先看直觉：如果导数真是"两个无穷小之比"，那么链式法则就是普通分数约分：

dy/dx = (dy/du) · (du/dx)   像   (a/b)(b/c) = a/c 一样"约掉" du

反函数求导 dx/dy = 1/(dy/dx) 像取倒数；换元积分里 dx 甚至可以真的参与变量代换。这些"假装分数"的操作，几乎全是对的——这正是莱布尼茨记号的最大价值：记号本身在替你"计算"。

为什么能假装？牛顿用点记号（ẋ 表示对时间求导）简洁却"不透明"，它只适合物理上的时间变量。莱布尼茨把求导看成"比值的极限"：dy/dx = lim(Δx→0) Δy/Δx。既然是比值的极限，比值能做的运算（乘除、约分），在极限下大多仍成立。而本章 2.5 节引入的微分概念，正是给这个直觉配上了严谨的底座：dy、dx 被定义为与"线性主部"有关的量，链式法则的"约分"就有了严格的证明，而不是碰巧对。

物理含义：记号还承载了量纲直觉。在物理里，dy/dx 的"单位"确实是 (y 的单位)/(x 的单位)：速度 ds/dt 的单位是米/秒，加速度是 (米/秒)/秒。记号让单位换算自动浮现，工程师一眼就能看出"这是谁对谁的导数"。
一句话总结：莱布尼茨记号赢在"形似分数而胜似分数"——它把导数"比值极限"的本质装进记号里，让链式法则、反函数、换元这些运算变得像初等算术一样自然；微分理论则保证这份直觉永远有定理兜底。

本章练习卷（含答案）

一、练习题

  1. 导数定义：用导数定义求 f(x) = x² 在 x = 2 处的导数 f′(2)。（写出差商并求极限的完整过程）
  2. 几何含义：求曲线 y = x³ 在点 (1, 1) 处的切线方程与法线方程，并说明切线斜率 f′(1) 的几何意义。
  3. 物理含义：质点沿直线运动，位移 s(t) = t³（单位：米，t 为秒）。求 t = 2 时的瞬时速度 v(2) 与加速度 a(2)，并解释它们分别是 s(t) 的几阶导数。
  4. 隐函数求导：由圆的方程 x² + y² = 25 确定 y = y(x)。求 dy/dx，并写出圆在点 (3, 4) 处的切线斜率；再验证该切线斜率与半径斜率之积为 −1，说明几何含义。
  5. 对数求导法：求 y = xˣ（x > 0）的导数 y′。
  6. 微分与近似：利用线性近似 f(x₀ + Δx) ≈ f(x₀) + f′(x₀)·Δx，估算 √4.04（取 x₀ = 4），并说明「以直代曲」的几何含义。

二、参考答案（点击展开）

查看第1题答案

f′(2) = lim(h→0) [f(2+h) − f(2)]/h = lim(h→0) [(2+h)² − 4]/h = lim(h→0) [4 + 4h + h² − 4]/h = lim(h→0) (4h + h²)/h = lim(h→0) (4 + h) = 4。

查看第2题答案

y′ = 3x²，故 f′(1) = 3，即曲线在点 (1, 1) 处切线的斜率为 3（几何上表示该点处曲线上升、上升快慢为 3）。切线方程：y − 1 = 3(x − 1)，即 y = 3x − 2。法线方程：y − 1 = −(1/3)(x − 1)，即 y = −(1/3)x + 4/3。

查看第3题答案

v(t) = s′(t) = 3t²（位移的一阶导数，即瞬时速度），故 v(2) = 3·2² = 12 m/s。a(t) = s″(t) = 6t（位移的二阶导数，即加速度），故 a(2) = 6·2 = 12 m/s²。

查看第4题答案

两边对 x 求导：2x + 2y·y′ = 0，解得 y′ = −x/y。在点 (3, 4) 处斜率 = −3/4。该点半径斜率为 4/3，两者乘积 (−3/4)·(4/3) = −1，故切线垂直于半径——这正是圆的几何性质。

查看第5题答案

两边取对数：ln y = x ln x。两边对 x 求导：y′/y = ln x + 1。故 y′ = xˣ(ln x + 1)。

查看第6题答案

取 f(x) = √x，x₀ = 4，Δx = 0.04，则 f′(x) = 1/(2√x)，f′(4) = 1/4。故 √4.04 ≈ √4 + (1/4)·0.04 = 2 + 0.01 = 2.01（真实值约 2.00998，误差极小）。几何上就是用 x=4 处的切线替代曲线，在极小区间内以直代曲。
