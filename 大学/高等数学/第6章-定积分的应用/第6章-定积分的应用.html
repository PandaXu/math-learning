第6章 定积分的应用

大学 / 高等数学

一句话总纲：定积分的应用 = 用元素法（微元法）把几何量（面积、体积、弧长）与物理量（功、水压力、引力）都还原成"无穷小元素的累加"，统一写成 Q = ∫ab f(x) dx——抓住"切薄片 → 找微元 → 无限累加"这一条主线，就能把所有应用公式自行推导出来。
本章目录 6.1 元素法（微元分析法）6.2 几何应用一：平面图形的面积6.3 几何应用二：体积6.4 几何应用三：平面曲线的弧长6.5 物理应用：功、水压力、引力几何与物理含义总结典型例题常见误区

6.1 元素法（微元分析法）

从"和式的极限"到"微元的累加"

第5章把定积分定义为"分割—近似—求和—取极限"，即

  ∫ab f(x) dx = lim (λ→0) Σ f(ξᵢ) Δxᵢ

但在应用中，我们通常反着用：要算的量 Q 是"分布在区间 [a,b] 上的量"，并且对区间具有可加性（整体 = 各部分之和）。这时不必每次都从极限定义出发，而是抓住一个"典型微元"直接写出积分。这就是元素法。

元素法的四步（务必背熟、每一步都懂为什么）

  1. 选积分变量，定区间：选取合适的坐标变量 x（或 θ、t 等），确定其变化范围 [a,b]。
  2. 取微元，作局部近似：在 [a,b] 内任取一个小区间 [x, x+dx]，在这个小区间上把"变的东西近似看成不变的、曲的近似看成直的"，求出局部量 ΔQ 的近似值 dQ = f(x) dx，这个 dQ 就叫做元素（微元）。
  3. 求和：把全部元素加起来，Q ≈ Σ f(x) dx。
  4. 取极限：令 dx → 0，得 Q = ∫ab f(x) dx。

元素法的成立条件（最容易被忽略、也最致命）

第 2 步的近似 dQ = f(x)dx 必须是"精度足够"的近似：要求 ΔQ 与 dQ 之差是 dx 的高阶无穷小，即

  ΔQ − dQ = o(dx)   （即 ΔQ = f(x)dx + o(dx)）

换句话说，f(x)dx 必须等于局部量 ΔQ 的"线性主部"。这样在求和、取极限时，所有被丢掉的 o(dx) 加起来才趋于 0，近似才"变成"精确。若用太粗糙的近似当微元，积分结果就会错。

几何含义：元素法 = "化整为零、以直代曲、积零为整"。把整体切成无穷薄的一片片，每一片都用最简单的图形（矩形、圆盘、圆环、圆柱壳、直线段……）近似，再把无穷多片累加。这是微积分"无限细分 + 极限还原"思想的直接运用。
物理含义：所有物理量本质上都是"分布量"——质量分布在长度/面积/体积上、力分布在位移上、压强分布在面积上。元素法的物理版本就是"密度 × 微元 = 局部量"：只要写出 dQ = (某密度) × (某微元)，积分自然给出总量。功、压力、引力、质心、转动惯量……全部如此。

6.2 几何应用一：平面图形的面积

(1) 直角坐标：X 型区域（"上下型"，对 x 积分）

由曲线 y = f(x)、y = g(x)（在 [a,b] 上 f(x) ≥ g(x)）与直线 x = a、x = b 围成的图形，面积为

  A = ∫ab [ f(x) − g(x) ] dx

微元：dA = [ f(x) − g(x) ] dx——宽 dx、高为"上减下"的窄竖条矩形。

特例：若只有曲线 y = f(x)（f ≥ 0）、x 轴、x = a、x = b 围成，则 g(x) = 0，得

  A = ∫ab f(x) dx

(2) 直角坐标：Y 型区域（"左右型"，对 y 积分）

由曲线 x = φ(y)、x = ψ(y)（在 [c,d] 上 φ(y) ≥ ψ(y)）与直线 y = c、y = d 围成的图形，面积为

  A = ∫cd [ φ(y) − ψ(y) ] dy

微元：dA = [ φ(y) − ψ(y) ] dy——高 dy、宽为"右减左"的窄横条矩形。

选型原则：怎么好算怎么来。有时"竖着切"（对 x 积分）要分好几段，"横着切"（对 y 积分）一段就够；反之亦然。动手前先画出草图、标出交点。

(3) 极坐标下的面积

由极坐标曲线 r = r(θ)（r(θ) ≥ 0 且连续）与两条射线 θ = α、θ = β（α < β）围成的"扇形区域"，面积为

  A = (1/2) ∫αβ [ r(θ) ]² dθ

微元：dA = (1/2) r² dθ——半径 r、圆心角 dθ 的小扇形（用扇形面积公式 ½r²θ 近似）。

几何含义：直角坐标下的面积微元是"窄矩形"，其核心动作是以直代曲——在宽 dx 的一小段内，把曲线看成水平直线，高近似取"上减下"；极坐标下的面积微元是"小扇形"，用 ½r²dθ 以"扇形代曲边"。总面积的几何意义，就是把这些细条/细扇形的面积无限累加。
物理含义：曲线下的面积在物理上就是"速率 × 时间"型的累积量：v–t 图下面积 = 位移，a–t 图下面积 = 速度变化量，P–t（功率–时间）图下面积 = 功，F–x（力–位移）图下面积 = 功。凡"横轴量的微元 × 纵轴量"能构成某物理量的微分，该物理量就是某曲线下的面积。

6.3 几何应用二：体积（截面法与旋转体）

(1) 平行截面面积已知的立体（切片法，最一般）

设立体夹在垂直于 x 轴的两个平面 x = a、x = b 之间，且过点 x 处垂直于 x 轴的截面面积 A(x) 是已知的连续函数，则体积为

  V = ∫ab A(x) dx

微元：dV = A(x) dx——底面积 A(x)、厚度 dx 的薄片（薄柱体，体积 ≈ 底面积 × 厚度）。

(2) 旋转体：圆盘法（Disk Method）

曲线 y = f(x)（a ≤ x ≤ b，f ≥ 0）绕 x 轴旋转一周所得旋转体体积：

  V = π ∫ab [ f(x) ]² dx

微元：dV = π [f(x)]² dx——半径 f(x)、厚度 dx 的薄圆盘（圆柱）。

(3) 旋转体：垫圈法（Washer Method）

由 y = R(x) 与 y = r(x)（a ≤ x ≤ b，且 R(x) ≥ r(x) ≥ 0）围成的区域绕 x 轴旋转一周所得"空心"旋转体体积：

  V = π ∫ab ( [R(x)]² − [r(x)]² ) dx

微元：dV = π([R(x)]² − [r(x)]²) dx——外半径 R、内半径 r、厚度 dx 的薄垫圈（圆环片）。

(4) 旋转体：柱壳法（Shell Method）

由 y = f(x)（f ≥ 0）、x 轴、x = a、x = b 围成的区域绕 y 轴旋转一周所得体积：

  V = 2π ∫ab x · f(x) dx

微元：dV = 2π x · f(x) · dx——半径 x、高 f(x)、厚度 dx 的薄圆柱壳；把它沿一条母线剪开展平，近似为长 2πx、宽 f(x)、厚 dx 的长方体。

选法提示：绕水平轴（x 轴）通常用圆盘/垫圈法（以 x 为积分变量）；绕竖直轴（y 轴）通常用柱壳法（仍以 x 为积分变量，避免反解函数）。两种方法结果一致，难易可差很多，选对方法往往比硬算更重要。

几何含义：体积的三种微元对应三种"几何母体"：圆盘（半径 f、厚 dx）、垫圈（外半径 R、内半径 r）、圆柱壳（周长 2πx × 高 f × 厚 dx，剪开近似长方体）。共同点是"把立体切成无穷多片规则小体，再累加"。截面法是母方法，圆盘/垫圈/柱壳都是"旋转对称"这一特殊情形下的截面法。
物理含义：体积 × 密度 = 质量，所以"求体积"与"求质量"同构：若立体线密度为 ρ(x)，质量 M = ∫ ρ(x) A(x) dx。圆盘法把旋转体切成薄圆盘，是后面求转动惯量（I = ∫ r² dm）等力学量的几何基础；柱壳法则对应"把物体看成一层层同心薄壳"。

6.4 几何应用三：平面曲线的弧长

弧微分：一切弧长公式的共同源头

弧长元素来自勾股定理 + 以切线代弧线：在微小区间上，弧段 Δs 可用切线段近似，于是

  ds² = dx² + dy²   ⟹   ds = √( dx² + dy² )

不同坐标系只是把 ds 换成相应变量的形式。

(1) 直角坐标

曲线 y = f(x)，a ≤ x ≤ b，f′(x) 连续，则

  L = ∫ab √( 1 + [f′(x)]² ) dx

(2) 参数方程

曲线 x = x(t)、y = y(t)，α ≤ t ≤ β，x′(t)、y′(t) 连续，则

  L = ∫αβ √( [x′(t)]² + [y′(t)]² ) dt

(3) 极坐标

曲线 r = r(θ)，α ≤ θ ≤ β，r′(θ) 连续，则

  L = ∫αβ √( [r(θ)]² + [r′(θ)]² ) dθ
几何含义：弧微分的本质是"以切线代弧线"：把一段无限短的曲线看成直线段，用勾股定理 ds = √(dx² + dy²) 求出它的长，再无限累加。三种坐标形式的弧长公式是同一句"勾股定理"分别用 x、t、θ 三种参数写出来。
物理含义：若参数 t 是时间，(x(t), y(t)) 是质点的运动轨迹，那么 √([x′(t)]² + [y′(t)]²) = |v(t)| 恰好是瞬时速率，于是 L = ∫ v(t) dt 就是质点从 t=α 到 t=β 走过的路程。这给出重要结论：路程 = 速率对时间的积分；而位移只关心起终点，与弧长不同。

6.5 物理应用：功、水压力、引力

(1) 变力沿直线所做的功

质点在变力 F(x) 作用下沿 x 轴从 x = a 移到 x = b（F 方向与运动方向一致），所做的功为

  W = ∫ab F(x) dx

微元：dW = F(x) dx——在小区间 [x, x+dx] 上把力近似看成常力，功 = 力 × 位移。

弹簧（胡克定律 F = kx）：把弹簧从自然长度拉长 X，克服弹力做功

  W = ∫0X kx dx = (1/2) k X²

抽水（提水）做功：要把容器中的水抽出，需把"深度 h 处、厚度 dh 的一层水"提升到指定高度，设该层截面积为 A(h)、密度 ρ、重力加速度 g、提升距离 D(h)，则

  dW = ρ g · A(h) dh · D(h)
  W  = ∫ ρ g · A(h) · D(h) dh

(2) 液体的静压力（水压力）

液体压强随深度线性增大：P = ρ g h。面积微元 dA 上所受压力

  dF = P · dA = ρ g h · dA

对竖直浸入水中的平板，取"深 h、厚 dh"的水平窄条（该窄条宽度 W(h)），则整块板所受总压力

  F = ∫ ρ g · h · W(h) dh

关键：压强不是常数，深度 h 是积分变量；窄条上各点深度近似相同，故整条可用 P = ρgh 近似，这正是元素法。

(3) 万有引力（连续体对质点的引力）

万有引力 F = G m₁ m₂ / r²，方向沿两物体连线。对连续分布的物体（如细棒、圆环、薄片）对质点的引力，须把物体切成质量微元 dm，先写出微元引力

  dF = G · m · dm / r²   （方向沿质点与 dm 的连线）

注意 dF 是向量，方向随 dm 位置而变，必须按坐标分量分解后再分别积分，不能把大小直接标量相加。

经典例：长为 L、线密度为 ρ（均匀，总质量 M = ρL）的细棒，对位于其延长线上、距近端 a 处质量为 m 的质点的引力（取棒上 x ∈ [0, L]，dm = ρ dx，距离 = a + x）：

  F = ∫0L G m ρ dx / (a+x)² = G m ρ [ 1/a − 1/(a+L) ] = G m M / [ a (a+L) ]

(4) 补充：平均值与质心（重心）

函数平均值：f(x) 在 [a,b] 上的平均值

  f̄ = ( 1/(b−a) ) ∫ab f(x) dx

质心（重心）坐标：对质量连续分布的物体，用元素法对质量微元加权平均

  x̄ = ∫ x dm / ∫ dm ，  ȳ = ∫ y dm / ∫ dm
几何含义：变力做功的 W = ∫ F(x)dx 在几何上就是"力–位移曲线下的面积"；函数平均值 f̄ 是"与曲线下面积等面积的矩形的高"（面积相等原则）；质心是"使各质量微元关于该点的力矩之和为零"的平衡点，几何上对应图形的几何中心（均匀体 = 形心）。
物理含义：功 = 力 × 位移的累积（力是位置的函数，必须积分）；水压力 = 压强 × 面积的累积（压强随深度线性变化，深度是积分变量）；引力 = 连续体各微元引力的矢量叠加（要分解分量）。三者都是"分布量"——分别分布在位移、面积、质量上，元素法把它们统一为 ∫ (密度) d(微元)。

典型例题（自测）

  1. 面积：求抛物线 y = x² 与 y = √x 所围成图形的面积。（交点 (0,0)、(1,1)，A = ∫01 (√x − x²) dx = 1/3）
  2. 体积（圆盘法）：求曲线 y = x² 在 [0,1] 上绕 x 轴旋转所得旋转体体积。（V = π ∫01 x⁴ dx = π/5）
  3. 体积（柱壳法）：求 y = x² 与 x 轴、x = 1 围成的区域绕 y 轴旋转所得体积。（V = 2π ∫01 x·x² dx = 2π ∫01 x³ dx = π/2）
  4. 弧长：求曲线 y = (2/3) x3/2 从 x = 0 到 x = 1 的弧长。（y′ = √x，L = ∫01 √(1+x) dx = (2/3)(2√2 − 1)）
  5. 变力做功：力 F(x) = x²（单位沿 x 轴正向）把物体从 x = 0 拉到 x = 2，求做功。（W = ∫02 x² dx = 8/3）
  6. 水压力：一宽 2 m、高 3 m 的矩形闸门竖直浸入水中，其上边在水面下 1 m 处，求水对闸门的总压力。（取深度 h ∈ [1,4]，F = ∫14 ρg h · 2 dh = 15ρg；取 ρ = 1000、g = 9.8，得 147000 N）
  7. 引力：长 L、总质量 M 的均匀细棒，对延长线上距近端 a 处质量为 m 的质点的引力。（F = GmM/[a(a+L)]）

常见误区

⚠️ 常见误区与纠正

  • ❌ 面积公式"上减下"弄反，算出负面积 → ❌ 面积恒正，务必保证 f ≥ g，否则取绝对值或分区间；"上减下、右减左"要先画草图。
  • ❌ 旋转体绕 x 轴与绕 y 轴混用公式 → ❌ 绕水平轴用圆盘/垫圈法，绕竖直轴常用柱壳法；先明确旋转轴再选公式。
  • ❌ 柱壳法把"半径"写成 f(x)、把"高"写成 x → ❌ 柱壳半径是 x（到 y 轴的距离），高是 f(x)，微元 dV = 2π·x·f(x)·dx。
  • ❌ 弧长公式写成 ∫[1+f′(x)]dx 或 ∫√(1+f(x))dx → ❌ 正确是 ∫√(1+[f′(x)]²)dx，平方在导数上、整体再开方。
  • ❌ 变力做功仍用 W = F·s，把 F 当常数 → ❌ 力随位置变化时必须积分 W = ∫F(x)dx。
  • ❌ 水压力把压强 ρgh 当常数（用表面深度）→ ❌ 压强随深度线性增大，深度是积分变量，必须 ∫ρg·h·W(h)dh。
  • ❌ 引力把方向各异的微元引力直接标量相加 → ❌ dF 是向量，须按坐标分量分解后分别积分，利用对称性可抵消某些分量。
  • ❌ 元素法不做"ΔQ − dQ = o(dx)"验证，用粗糙近似当微元 → ❌ 微元必须是局部量的线性主部，否则积分结果错误。
