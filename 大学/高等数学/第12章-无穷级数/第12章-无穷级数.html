第12章 无穷级数

大学 / 高等数学

一句话总纲：无穷级数 = 「把无穷多个数（或函数）加起来的极限过程」。学完本章，你要能"看见"两件事：常数项级数是无穷多段线段在数轴上不断累加、逼近一个总长度的过程；函数项级数（幂级数、傅里叶级数）是用无穷多个"基元"（多项式项 / 正弦余弦波）去无限逼近一条曲线或一个信号的叠加过程。

12.1 常数项级数的概念与性质

无穷级数的定义与部分和

给定一个无穷数列 u₁, u₂, u₃, …, uₙ, …，把它们用加号依次连起来：

u₁ + u₂ + u₃ + … + uₙ + …  =  Σ uₙ  (n = 1 → ∞)

称为常数项无穷级数（简称级数），uₙ 叫一般项（通项）。它本身是"加不完"的，所以我们用部分和来把握它：

前 n 项部分和：  Sₙ = u₁ + u₂ + … + uₙ = Σ uₖ  (k=1…n)

于是得到一个部分和数列 {Sₙ}。级数的敛散性就定义为部分和数列的敛散性：

  • 若 lim Sₙ = S（有限数）存在，则称级数收敛，S 叫它的和，记 Σ uₙ = S。
  • 若 {Sₙ} 的极限不存在（趋于无穷或振荡），则称级数发散。
  • 余项 rₙ = S − Sₙ = uₙ₊₁ + uₙ₊₂ + …：收敛级数的余项必趋于 0。
几何含义（核心）：把每一项看成数轴上的一段位移。S₁、S₂、S₃、… 是一个点一步步往前（或来回）移动后停下的位置。级数收敛，就是这个点在数轴上不断逼近、最终"停"在一个确定位置 S；发散，就是这个点越走越远、或者永远在两个位置之间来回打转。
物理含义：无穷级数是"无穷多个微小量的累加"。匀速直线运动里，把总路程切成 1/2 + 1/4 + 1/8 + … 这样无穷多段，累加起来仍是有限的总路程——这正是芝诺悖论的破解：无穷多段"越来越短"的位移可以加出有限结果。反过来，像 1 + 1/2 + 1/3 + … 这种"虽然每段在变短、但衰减得不够快"的累加，会发散到无穷。

几何级数（等比级数）——最重要的标准级数

Σ a·qⁿ = a + aq + aq² + aq³ + …   (a ≠ 0)
  • 当 |q| < 1 时收敛，和为 a / (1 − q)。
  • 当 |q| ≥ 1 时发散。

证明思路（首项 a、公比 q）：部分和 Sₙ = a(1 − qⁿ)/(1 − q)，当 |q| < 1 时 qⁿ → 0，故 Sₙ → a/(1 − q)。

几何含义：每一步都"截取剩余部分的固定比例 q"。例如先走 1，再走剩下距离的一半、再一半……总长度 = 1/(1 − 1/2) = 2。a/(1 − q) 就是"首段长度 ÷ 每次剩余的比例"，几何上等价于把一个线段反复按比例分割后并起来的总长。
物理含义：衰减与折现。放射性衰变（每单位时间衰减固定比例）、有阻尼的反复碰撞（每次速度按比例 q 衰减）、按固定利率 r 折现的无穷现金流 1 + q + q² + … = 1/(1 − q)（这里 q = 1/(1+r)），都是几何级数。

级数收敛的必要条件

若 Σ uₙ 收敛，则必有  lim uₙ = 0  (n → ∞)
  • 逆否命题（判定发散的法宝）：若 lim uₙ ≠ 0 或极限不存在，则级数必发散。例：Σ n/(n+1) 的通项趋于 1 ≠ 0，故发散。
  • 注意反方向不成立：通项趋于 0 只是收敛的必要条件而非充分条件，见下面的调和级数。

调和级数：通项趋于 0 却发散

Σ 1/n = 1 + 1/2 + 1/3 + 1/4 + …  (发散)

虽然 1/n → 0，但和仍发散到无穷。经典证法（分组比较）：

1 + 1/2 + (1/3+1/4) + (1/5+…+1/8) + (1/9+…+1/16) + …
每一组都 ≥ 1/2，且组数无穷，故部分和 → +∞
几何含义：数轴上的点 Sₙ = 1 + 1/2 + … + 1/n ≈ ln n + γ，虽然每一步的步长 1/n 越来越小，但减小的速度太慢（只是"倒数"级别地减小），累加起来的移动距离仍然无界。
物理含义：能量/质量的"慢衰减"累加。像水滴以"1/n 的速率"不断滴入一个无底桶，虽然每一滴越来越小，总量仍会无限增长。对比 p 级数（12.2）可知：衰减速度是否"足够快"决定总量是否有限。

级数的基本性质

  • 线性性：若 Σ uₙ、Σ vₙ 收敛，则 Σ (αuₙ + βvₙ) = αΣuₙ + βΣvₙ。
  • 去掉/增加/改变有限项：不改变级数的敛散性（但会改变和的值）。
  • 加括号：收敛级数任意加括号后仍收敛于原和；但发散级数加括号可能变得收敛（如 1 − 1 + 1 − 1 + … 按两项一组加括号得 0 + 0 + … 收敛，而原级数发散），所以加括号不能证明原级数收敛。
  • 通项趋于 0是收敛的必要条件（见上）。

12.2 正项级数审敛法与任意项级数

正项级数及其基本定理

若 uₙ ≥ 0（n = 1, 2, …），则称 Σ uₙ 为正项级数。此时部分和数列 {Sₙ} 单调不减。

基本定理（几何本质）：正项级数收敛 ⟺ 部分和数列 {Sₙ} 有上界。因为单调不减数列有极限的充要条件是它有上界——这正是"单调有界必有极限"。几何上，S₁ ≤ S₂ ≤ … 是一串只往右走、绝不回头的点，只要被一堵"墙 M"挡住，就必定收敛到 ≤ M 的某个位置。
物理含义：正项级数是"累加正量"（能量、电荷、质量、面积）。收敛 = 总量有限（有上界）；发散 = 总量无限。

p 级数——与调和级数对照的标尺

Σ 1/n^p = 1 + 1/2^p + 1/3^p + …   (p > 0)

  当 p > 1 时 收敛
  当 p ≤ 1 时 发散
  • p = 1 就是调和级数（发散）；p = 2（Σ 1/n² = π²/6）收敛。
  • p 级数 + 几何级数是审敛法里最常用的两个"标尺级数"。
物理含义：通项 1/n^p 是幂律衰减。p 越大衰减越快：p > 1 时衰减"足够快"，总量有限；p ≤ 1 时衰减太慢，总量发散。自然界里很多量（引力、长程相互作用）按幂律衰减，p 级数决定了"长程贡献"是否可积。

比较审敛法（含极限形式）

普通形式：设 0 ≤ uₙ ≤ vₙ：

  • 若 Σ vₙ 收敛，则 Σ uₙ 收敛（"大"的收敛 ⇒ "小"的收敛）；
  • 若 Σ uₙ 发散，则 Σ vₙ 发散（"小"的发散 ⇒ "大"的发散）。

极限形式：若 lim uₙ/vₙ = l（0 < l < +∞），则 Σ uₙ 与 Σ vₙ 同敛散。

几何含义：把 vₙ 当作一把"已知长度的标尺"，拿 uₙ 去比：如果 uₙ 始终比一把"总长有限"的尺子还短，那么 uₙ 的总长也有限。极限形式就是看两者的"渐近比例"，比例相同（同阶无穷小）则总长有限与否也相同。

比值审敛法（达朗贝尔判别法）

设 Σ uₙ 为正项级数，若  lim uₙ₊₁ / uₙ = ρ：

  ρ < 1  ⇒ 收敛
  ρ > 1  ⇒ 发散
  ρ = 1  ⇒ 失效（改用别的方法）

典型例子：Σ n!/nⁿ 收敛（ρ = lim (n/(n+1))ⁿ = 1/e < 1）；Σ 2ⁿ/n! 收敛（ρ = 0）。

几何含义：比值 ρ 是"相邻两项的缩放比"。当 n 很大时，级数近似于公比为 ρ 的几何级数：ρ < 1 表示每一项按固定比例"缩水"，总长有限；ρ > 1 表示每一项在放大，总长必发散。ρ = 1 时缩放比恰好临界（如 1/n、1/n² 的比值都趋于 1，但一个发散一个收敛），所以判不出结果。

根值审敛法（柯西判别法）

设 Σ uₙ 为正项级数，若  lim ⁿ√uₙ = ρ：

  ρ < 1  ⇒ 收敛
  ρ > 1  ⇒ 发散
  ρ = 1  ⇒ 失效

适用于通项是 n 次幂的情形，如 Σ (n/(2n+1))ⁿ（ρ = 1/2 < 1，收敛）。

交错级数与莱布尼茨判别法

交错级数：Σ (−1)ⁿ⁻¹ uₙ = u₁ − u₂ + u₃ − u₄ + …（uₙ > 0）。

莱布尼茨判别法：若 ① uₙ 单调递减（uₙ₊₁ ≤ uₙ）
                   ② lim uₙ = 0
则交错级数收敛，且 |S − Sₙ| ≤ uₙ₊₁（余项不超过下一项的绝对值）。
几何含义：交错级数的部分和在数轴上左右来回振荡：先前进 u₁，再退回 u₂，再前进 u₃……由于步长单调递减且趋于 0，这个点像"阻尼振动"一样越摆幅度越小，最终收敛到一个确定位置，且真值总被夹在相邻两个部分和之间。

任意项级数：绝对收敛与条件收敛

  • 若 Σ |uₙ| 收敛，则 Σ uₙ 必收敛，此时称 Σ uₙ 绝对收敛。
  • 若 Σ uₙ 收敛但 Σ |uₙ| 发散，则称 Σ uₙ 条件收敛。例：Σ (−1)ⁿ⁻¹/n 条件收敛（本身收敛，但 Σ 1/n 发散）。
物理/现实含义：绝对收敛 = "所有项都取绝对值后总量仍有限"，它允许任意交换求和顺序而和不变（像把一堆钱任意清点，总数不变）；条件收敛 = "靠正负相消才收敛"，交换顺序或重排可能改变和甚至改变敛散性（黎曼重排定理）。这决定了在物理里做级数求和时能否随意调整项的顺序。

12.3 幂级数

幂级数的形式

Σ aₙ xⁿ = a₀ + a₁x + a₂x² + … + aₙxⁿ + …     （关于 x 的幂级数）

Σ aₙ (x − x₀)ⁿ = a₀ + a₁(x−x₀) + a₂(x−x₀)² + …  （关于 x₀ 的幂级数）

常数项级数是"固定的数相加"，而幂级数是随 x 变化的函数：对每一个 x，它都变成一个常数项级数。使这个级数收敛的所有 x 的集合叫收敛域。

几何含义：幂级数是"无穷次多项式"。多项式 a₀ + a₁x + … + aₙxⁿ 在几何上是一条平滑曲线，幂级数就是把这种曲线"无限地加长项"，用无穷多项去逼近某个更复杂的函数曲线。它天然具备"局部性"：展开中心 x₀ 附近最准。

阿贝尔定理与收敛半径

阿贝尔定理：

  • 若幂级数在 x = x₁（≠ 0）处收敛，则在 |x| < |x₁| 内绝对收敛；
  • 若在 x = x₂ 处发散，则在 |x| > |x₂| 处发散。

由此，存在唯一非负数 R（0 ≤ R ≤ +∞），叫收敛半径：

|x| < R   绝对收敛
|x| > R   发散
|x| = R   端点需单独判定（可能收敛也可能发散）

求收敛半径（对 Σ aₙxⁿ）：

R = lim |aₙ / aₙ₊₁|        （比值法，若极限存在）

R = 1 / lim sup ⁿ√|aₙ|      （根值法，柯西–阿达马公式）
  • R = 0：只在 x = 0 收敛；R = +∞：在整个数轴收敛。
  • 收敛区间 = (−R, R)；收敛域 = 收敛区间再加上收敛的端点。
几何含义：收敛半径 R 刻画了幂级数"有效范围"的大小。在复平面 z = x + iy 上，收敛范围恰好是一个以展开中心为圆心、半径 R 的圆盘（圆内绝对收敛、圆外发散），这是复分析里最漂亮的几何事实之一。回到实轴上，它就退化成区间 (−R, R)。
物理含义：收敛半径 = 近似/展开的"作用距离"。许多物理近似（泰勒近似、微扰展开）只在某个半径内有效，超出半径展开式就"爆炸"（发散），对应物理上近似的失效边界。

幂级数的运算（逐项求导与逐项积分）

设 S(x) = Σ aₙxⁿ，收敛半径为 R，则在 (−R, R) 内：

  S′(x) = Σ n·aₙ xⁿ⁻¹        （逐项求导）
  ∫₀ˣ S(t) dt = Σ aₙ xⁿ⁺¹/(n+1)   （逐项积分）

求导和积分后收敛半径不变（但端点收敛性可能改变）。

几何含义："求导/积分"与"无穷求和"这两个极限运算可以交换次序——曲线逐项求导就是切线斜率的级数，逐项积分就是面积函数的级数。它保证我们能在收敛区间内把幂级数当作普通多项式一样微积分。

12.4 函数展开成幂级数（泰勒级数）

泰勒公式与泰勒级数

若 f(x) 在 x₀ 的某邻域内具有任意阶导数，则它的泰勒级数为：

f(x) = f(x₀) + f′(x₀)(x−x₀) + f″(x₀)(x−x₀)²/2! + …
     = Σ f⁽ⁿ⁾(x₀) (x−x₀)ⁿ / n!   (n = 0,1,2,…)

当 x₀ = 0 时称麦克劳林级数：

f(x) = f(0) + f′(0)x + f″(0)x²/2! + … = Σ f⁽ⁿ⁾(0) xⁿ / n!

关键条件：泰勒级数在收敛区间内是否收敛到 f(x) 本身，取决于拉格朗日余项是否趋于 0：

Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ) (x−x₀)ⁿ⁺¹ / (n+1)!  →  0 (n → ∞)
几何含义（本章最核心的直觉）：泰勒展开 = 用多项式在某点逐级"贴合"曲线。n = 0 用水平线（常数）贴；n = 1 用切线（一阶）贴；n = 2 用抛物线（二阶，含曲率）贴；阶数越高，多项式在 x₀ 附近"拐弯的形态"与 f 越一致，贴合的范围越宽。幂级数就是"贴合到无穷阶"的极限。
物理含义：泰勒展开是线性化与小量近似的根基。经典例子：sin x ≈ x（单摆小角度）、cos x ≈ 1 − x²/2、(1+x)ⁿ ≈ 1 + nx、eˣ ≈ 1 + x。物理中几乎处处用"取到一阶/二阶"来把复杂非线性问题化成线性问题，泰勒余项就是误差的定量估计。

五个必须熟记的麦克劳林展开式

函数麦克劳林展开式收敛范围
eˣ1 + x + x²/2! + x³/3! + … = Σ xⁿ/n!|x| < ∞
sin xx − x³/3! + x⁵/5! − … = Σ (−1)ⁿ x²ⁿ⁺¹/(2n+1)!|x| < ∞
cos x1 − x²/2! + x⁴/4! − … = Σ (−1)ⁿ x²ⁿ/(2n)!|x| < ∞
1/(1−x)1 + x + x² + x³ + … = Σ xⁿ|x| < 1
ln(1+x)x − x²/2 + x³/3 − … = Σ (−1)ⁿ⁻¹ xⁿ/n−1 < x ≤ 1
(1+x)ᵅ1 + αx + α(α−1)x²/2! + …（二项式级数）|x| < 1（端点视 α 而定）

这些展开式是间接展开法的素材库：对已知展开式做换元、逐项求导、逐项积分、加减，即可求出更多函数的展开，而不必每次都去算高阶导数。

欧拉公式——泰勒展开的巅峰应用

把 eˣ 的展开式中的 x 换成 ix（i² = −1）：

e^(ix) = 1 + ix + (ix)²/2! + (ix)³/3! + …
       = (1 − x²/2! + x⁴/4! − …) + i(x − x³/3! + x⁵/5! − …)
       = cos x + i·sin x
几何含义：欧拉公式把指数函数（增长）与三角函数（旋转）在复数平面上统一起来：e^(iθ) 表示复平面单位圆上、幅角为 θ 的点。特别地 e^(iπ) + 1 = 0 把 e、i、π、1、0 五个常数串成一句。
物理含义：e^(iωt) = cos ωt + i·sin ωt 是振动与波动、交流电、量子力学里最常用的表示：把一个简谐振动写成复指数，相位、振幅、频率的运算都变成复数的乘除，极大简化计算。下一节的傅里叶级数也用 e^(inx) 作基元。

12.5 傅里叶级数

三角级数与傅里叶系数

幂级数用多项式基元 {1, x, x², …}逼近函数；傅里叶级数改用三角基元 {1, cos nx, sin nx}去逼近周期函数。设 f(x) 以 2π 为周期，则：

f(x) ~ a₀/2 + Σ (aₙ cos nx + bₙ sin nx)   (n = 1,2,…)

其中傅里叶系数：
  aₙ = (1/π) ∫_{-π}^{π} f(x) cos nx dx   (n = 0,1,2,…)
  bₙ = (1/π) ∫_{-π}^{π} f(x) sin nx dx   (n = 1,2,…)

周期为 2l 的一般情形（换元 x = l·t/π 即可得到）：

f(x) ~ a₀/2 + Σ [aₙ cos(nπx/l) + bₙ sin(nπx/l)]

  aₙ = (1/l) ∫_{-l}^{l} f(x) cos(nπx/l) dx
  bₙ = (1/l) ∫_{-l}^{l} f(x) sin(nπx/l) dx
几何含义：把一条周期曲线 f(x) 看成由不同频率、不同振幅的正弦/余弦波"叠加"而成。a₀/2 是"平均高度"（直流分量），cos nx、sin nx 是频率递增的"谐波"，aₙ、bₙ 是各谐波的权重。这正是"任何一个周期图形都能由最基本的波浪拼出来"的几何事实。
物理含义（频谱分析）：傅里叶级数是信号的频谱分解。任何周期振动（声波、交流电、机械振动）都可分解为基波（n=1）+ 各次谐波（n=2,3,…）；aₙ、bₙ 决定每个频率成分的振幅与相位。音乐里"音色"的差别就是谐波成分的差别；热传导（傅里叶研究热方程时发明了它）、电路滤波、图像压缩（JPEG）全基于此。

狄利克雷收敛定理

若 f(x) 在 [−π, π] 上满足狄利克雷条件：① 连续或只有有限个第一类间断点；② 只有有限个极值点（分段光滑），则其傅里叶级数收敛，且：

  • 在 连续点 x 处，级数收敛于 f(x)；
  • 在 间断点 x 处，级数收敛于左右极限的平均值 [f(x−) + f(x+)] / 2。
几何含义：在间断点处，傅里叶级数"取中间值"，正好补在"跳变缺口"的正中——就像用波浪去拟合一个台阶，台阶中间那条平均线就是级数的极限。

奇函数与偶函数：正弦级数与余弦级数

f(x) 的对称性系数简化展开结果
偶函数（关于 y 轴对称）bₙ = 0，aₙ = (2/π)∫₀^π f cos nx dx纯余弦级数：f(x) ~ a₀/2 + Σ aₙ cos nx
奇函数（关于原点对称）aₙ = 0，bₙ = (2/π)∫₀^π f sin nx dx纯正弦级数：f(x) ~ Σ bₙ sin nx
几何含义：余弦函数是偶函数、正弦函数是奇函数。奇函数没有"偶的分量"（对称部分），偶函数没有"奇的分量"（反对称部分）——对称性决定了一个周期图形由哪些基本波组成，这正是"波形分解尊重对称性"。

经典例子：方波的傅里叶展开

方波 f(x) = ┌  1   (0 < x < π)
            └ −1   (−π < x < 0)   （奇函数）

f(x) = 4/π [sin x + sin 3x/3 + sin 5x/5 + sin 7x/7 + …]
     = 4/π Σ sin(2k−1)x / (2k−1)   (k = 1,2,…)
几何含义：用 1 个正弦波只能得到一个"圆滚滚"的近似方波；叠加 sin 3x/3、sin 5x/5、… 越多，波形越逼近真正的"方角"。在间断点附近，即使取无穷多项，仍会残留约 9% 的过冲（吉布斯现象）——这是几何上"用连续波拟合跳变"永远无法完全消除的固有现象。
物理含义：方波 = 只有奇次谐波（1、3、5、…次）且振幅按 1/k 衰减。电子学里生成方波信号，本质就是叠加这些奇次谐波；滤波时去掉高次谐波，方波就会变"圆"，这正是理想低通滤波会让脉冲"振铃"（出现过冲）的原因。

概念几何含义物理/现实含义
无穷级数（部分和）数轴上的点一步步累加、逼近极限位置无穷多个微小量（位移/能量/电荷）的累加
级数收敛 / 发散部分和点"停住" / 越走越远或来回振荡总量有限 / 总量无限或无确定值
几何级数每次截取剩余部分的固定比例衰减、折现、有阻尼的反复碰撞
调和级数发散步长 1/n 减小得太慢，移动距离无界慢衰减累加可无限增长（反芝诺直觉）
正项级数基本定理单调右移的点被"上界之墙"挡住即收敛正量累加：有上界 ⇒ 总量有限
比较 / 比值 / 根值审敛拿"已知长度标尺"比；通项按固定比缩放判断衰减是否"足够快"（幂律/指数律）
交错级数（莱布尼茨）点左右来回摆动、幅度递减趋于定点阻尼振动收敛、正负相消

典型例题（自测）

  1. 判断 Σ n/(2n+1) 的敛散性。（提示：通项是否趋于 0？）
  2. 求几何级数 1 + 1/3 + 1/9 + 1/27 + … 的和。
  3. 用比较审敛法或极限形式判断 Σ 1/(n²+1) 与 Σ 1/√n 的敛散性。
  4. 用比值审敛法判断 Σ n!/nⁿ 与 Σ 3ⁿ/n! 的敛散性。
  5. 判断交错级数 Σ (−1)ⁿ⁻¹/√n 是否收敛；它是否绝对收敛？
  6. 求幂级数 Σ xⁿ/n 的收敛半径、收敛区间与收敛域（注意端点）。
  7. 写出 f(x) = eˣ 的麦克劳林级数，并求 e 的近似值（取到 x=1 的前 5 项，估算误差）。
  8. 求周期为 2π 的函数 f(x) = x（−π < x < π）的傅里叶级数（它是奇函数）。
  9. 验证：方波在间断点 x=0 处，其傅里叶级数收敛于 [f(0−)+f(0+)]/2 = 0。

常见误区

  • ❌ "通项趋于 0，级数就收敛" → ❌ 调和级数 Σ 1/n 通项趋于 0 却发散；通项趋于 0 只是必要条件。
  • ❌ "比值法 ρ = 1 时级数收敛" → ❌ ρ = 1 时比值法失效，须换比较法/积分法等另行判定。
  • ❌ "加括号能证明原级数收敛" → ❌ 发散级数（如 1−1+1−1+…）加括号后可能收敛，加括号不能作为收敛证明。
  • ❌ "收敛级数去掉括号仍收敛" → ❌ 收敛级数加括号后和不变，但去括号可能破坏收敛性。
  • ❌ "幂级数收敛区间端点一定收敛" → ❌ 端点 x = ±R 必须单独代入判定（如 Σ xⁿ/n 在 x=1 发散、x=−1 收敛）。
  • ❌ "泰勒级数在收敛区间内一定等于原函数" → ❌ 还需余项趋于 0（反例：e^(−1/x²) 在 0 处泰勒级数恒为 0，却不等于原函数）。
  • ❌ "傅里叶级数在间断点取左右极限之一" → ❌ 取左右极限的平均值 [f(x−)+f(x+)]/2。
  • ❌ "任何函数都能展开成傅里叶级数" → ❌ 需满足狄利克雷条件（有限个第一类间断点、有限个极值点）。
  • ❌ "条件收敛级数可以任意交换求和顺序" → ❌ 条件收敛级数重排会改变和甚至敛散性（黎曼重排定理）；只有绝对收敛才可任意重排。

本章练习卷（含答案）

一、练习题（由易到难）

  1. 判断级数 Σ n/(2n+1)（n 从 1 到 ∞）的敛散性，并结合数轴上部分和点"是否停得下来"说明理由。
  2. 求几何级数 1 + 1/3 + 1/9 + 1/27 + … 的和，并用"每次截取剩余部分的固定比例"解释结果。
  3. 判断 Σ 1/n² 与 Σ 1/√n 的敛散性，并说明 p 级数的"衰减速度"如何决定总量是否有限。
  4. 用比值审敛法判断 Σ 2ⁿ/n! 的敛散性，并解释比值 ρ 的几何含义。
  5. 判断交错级数 Σ (−1)ⁿ⁻¹/√n 是否收敛；若收敛，它是绝对收敛还是条件收敛？
  6. 求幂级数 Σ xⁿ/n 的收敛半径、收敛区间与收敛域，并说明两个端点为何要单独判定。

二、参考答案（点击展开）

查看第1题答案

通项 uₙ = n/(2n+1) 当 n → ∞ 时趋于 1/2 ≠ 0。由级数收敛必要条件的逆否命题：通项不趋于 0 必发散，故该级数发散。几何上，部分和点每次仍往前移近 1/2 的步长，永远"停不下来"。

查看第2题答案

首项 a = 1、公比 q = 1/3（|q| < 1），和 S = a/(1−q) = 1/(1−1/3) = 3/2。几何含义：先走 1，再走剩下距离的 1/3，再走新的剩余的 1/3……每一步都截取剩余部分的固定比例 1/3，把线段反复按比例分割后并起来，总长 = 首段长度 ÷ 每次剩余的比例 = 3/2。

查看第3题答案

Σ 1/n² 是 p = 2 的 p 级数，p > 1，收敛；Σ 1/√n = Σ 1/n^(1/2) 是 p = 1/2 的 p 级数，p ≤ 1，发散。物理含义：通项按幂律 1/n^p 衰减，p 越大衰减越快；p > 1 时衰减"足够快"、总量有限，p ≤ 1 时衰减太慢、总量无限。

查看第4题答案

uₙ = 2ⁿ/n!，ρ = lim uₙ₊₁/uₙ = lim (2ⁿ⁺¹/(n+1)!) · (n!/2ⁿ) = lim 2/(n+1) = 0 < 1，故级数收敛。几何含义：ρ 是相邻两项的"缩放比"，ρ = 0 表示每一项比前一项缩水得比任何固定比例都快，比公比 < 1 的几何级数衰减更快，总长必有限。

查看第5题答案

这是交错级数，uₙ = 1/√n 单调递减且 lim uₙ = 0，满足莱布尼茨条件，故收敛。但 Σ |uₙ| = Σ 1/√n 是 p = 1/2 的 p 级数，发散，所以原级数是条件收敛。几何含义：部分和点左右来回摆动、步长递减趋于 0 而收敛，但"取绝对值后总量仍无限"，说明它靠正负相消才收敛，重排求和顺序可能改变和。

查看第6题答案

系数 aₙ = 1/n，收敛半径 R = lim |aₙ/aₙ₊₁| = lim (n+1)/n = 1，故收敛区间为 (−1, 1)。端点单独判定：x = 1 时代入得 Σ 1/n（调和级数）发散；x = −1 时代入得 Σ (−1)ⁿ/n（交错级数，莱布尼茨条件满足）收敛。所以收敛域为 [−1, 1)。端点之所以要单独判定，是因为阿贝尔定理只保证 |x| < R 内绝对收敛、|x| > R 外发散，对 |x| = R 的临界情况不给结论。
