第11章 曲线积分与曲面积分

大学 / 高等数学

一句话总纲：把"分割—近似—求和—取极限"的积分思想从数轴、平面区域推广到弯曲的曲线和曲面上，于是得到曲线积分（沿曲线累加）与曲面积分（沿曲面累加），用来量化质量、功、环量、通量等物理量；而格林公式、高斯公式、斯托克斯公式则是三条"桥梁定理"，把边界上的积分与区域内部的积分联结起来，揭示"旋转（旋度）"与"源（散度）"这两个向量场的内在本质。

11.1 对弧长的曲线积分（第一类曲线积分）

从"曲线构件的质量"说起

一根弯曲的金属丝（空间曲线或平面曲线），如果线密度均匀，质量 = 密度 × 总弧长；但现实中线密度往往逐点变化——设线密度为 ρ(x,y,z)，怎么求总质量？这就是第一类曲线积分的动机。

基本思想（四步法）：把曲线 L 分割成 n 个小弧段 → 在第 i 段上任取一点，用 ρ(该点) × 弧段长 近似该段质量 → 求和 → 令最长弧段趋于 0 取极限。

∫_L f(x,y,z) ds = lim(λ→0) Σ f(ξᵢ,ηᵢ,ζᵢ) · Δsᵢ

其中 ds 是弧长元素（弧微分），λ 是最长弧段的长度。

几何含义：① 当 f = 1 时，∫_L ds 就是曲线 L 的弧长；② 当 f ≥ 0 时，∫_L f ds 是以曲线 L 为准线、以 f 为"高"的柱面面积（想象一道沿曲线竖起的"栅栏"）；③ 更本质地说，它是"把曲线拉直、按弧长逐点加权累加"的过程。物理含义：线密度为 ρ 的曲线构件的质量 m = ∫_L ρ ds；由此还能求质心 x̄ = ∫_L xρ ds / m、对轴与对原点的转动惯量等。

重要性质

  • 与方向无关：因为 ds 是弧长（恒正），所以 ∫_L f ds = ∫_{−L} f ds（从 A 到 B 与从 B 到 A 结果相同）。这是第一类与第二类曲线积分最本质的区别。
  • 线性性：∫_L (af + bg) ds = a∫_L f ds + b∫_L g ds。
  • 对弧段可加：L = L₁ + L₂ 时，∫_L f ds = ∫_{L₁} f ds + ∫_{L₂} f ds。
  • 保序性：若 f ≤ g，则 ∫_L f ds ≤ ∫_L g ds。

计算方法：化为定积分

核心是写出 弧微分 ds，把曲线积分化为关于一个参数的定积分。

① 平面曲线参数式 L: x=x(t), y=y(t), α ≤ t ≤ β：

ds = √( [x'(t)]² + [y'(t)]² ) dt
∫_L f(x,y) ds = ∫_α^β f(x(t),y(t)) · √( [x'(t)]² + [y'(t)]² ) dt

② 直角坐标 y = y(x), a ≤ x ≤ b（视 x 为参数）：

ds = √( 1 + [y'(x)]² ) dx

③ 极坐标 r = r(θ), θ₁ ≤ θ ≤ θ₂：

ds = √( r² + [r'(θ)]² ) dθ

④ 空间曲线 x=x(t), y=y(t), z=z(t), α ≤ t ≤ β：

ds = √( [x'(t)]² + [y'(t)]² + [z'(t)]² ) dt
为什么 ds = √(dx² + dy²)？微元上，ds 是"斜边的长"，dx、dy 是两条直角边，由勾股定理 ds² = dx² + dy²。这是本章所有"弧微分"的几何根源，务必在脑中画出一个"微小的直角三角形"。

11.2 对坐标的曲线积分（第二类曲线积分）

从"变力沿曲线做功"说起

一个质点受变力 F(x,y) = (P(x,y), Q(x,y)) 作用，沿有向曲线 L 从 A 移动到 B，求力做的功。把曲线分成小段，在第 i 段上力近似不变、位移为 drᵢ = (dxᵢ, dyᵢ)，做功近似 F·drᵢ = P dxᵢ + Q dyᵢ，求和取极限得：

W = ∫_L P(x,y) dx + Q(x,y) dy = ∫_L (P dx + Q dy)

这是第二类曲线积分，也叫对坐标的曲线积分。向量形式写作 ∫_L F·dr，其中 dr = (dx, dy) 是有向弧微元。

几何含义：它是"被积函数与有向坐标增量 dx、dy 的乘积"沿曲线的累加，本质是向量场沿曲线的"有向投影"积分。物理含义：变力 F 沿曲线 L 所做的功。推广到三维，∫_L P dx + Q dy + R dz = ∫_L F·dr 仍是"力 × 位移"的连续累加。

关键性质：与方向有关

∫_{−L} P dx + Q dy = − ∫_L P dx + Q dy

反向积分变号——这是它区别于第一类的标志：dx、dy 是有向增量，反向走时它们同时变号。此外线性性、对弧段可加性同样成立。

计算方法：化为定积分（参数必须与方向对应）

设 L: x=x(t), y=y(t)，起点对应 t=α、终点对应 t=β（下限对应起点、上限对应终点）：

∫_L P dx + Q dy = ∫_α^β [ P(x(t),y(t))·x'(t) + Q(x(t),y(t))·y'(t) ] dt

三维情形同理，把 dx、dy、dz 分别换成 x'(t)dt、y'(t)dt、z'(t)dt 代入。

两类曲线积分的联系

记曲线在点处的单位切向量为 T = (cosα, cosβ)，则有 dx = cosα·ds、dy = cosβ·ds，于是：

∫_L P dx + Q dy = ∫_L (P cosα + Q cosβ) ds = ∫_L (F·T) ds
一句话统一：第二类曲线积分 = 把"向量场在切线方向上的投影分量"沿弧长累加。第一类是对标量沿弧长加权；第二类是对向量沿切向做点积后再沿弧长加权。二者通过 cosα、cosβ（切向方向余弦）互相转化。

11.3 格林公式（Green）

定理内容

设平面闭区域 D 由分段光滑曲线 L 围成，P、Q 在 D 上有一阶连续偏导数，L 取正向，则：

∮_L P dx + Q dy = ∬_D ( ∂Q/∂x − ∂P/∂y ) dx dy

正向：沿边界 L 行走时，区域 D 始终在左手边（对单连通区域即"逆时针"）。

几何含义：它把沿闭曲线的一圈积分（线积分）转化为所围平面区域上的二重积分（面积分）——"绕边界一圈"的信息完全由"区域内部的分布"决定。物理含义：∂Q/∂x − ∂P/∂y 正是二维向量场 (P,Q) 的旋度（rot，标量形式）；格林公式即"沿边界的环量 = 内部旋度的面积总和"，它是平面版的斯托克斯公式。

两大用途

用途一：用曲线积分求平面图形面积。取适当的 P、Q 使 ∂Q/∂x − ∂P/∂y = 1，例如：

A = ∮_L x dy = − ∮_L y dx = (1/2) ∮_L ( x dy − y dx )

于是椭圆的面积等可用"沿边界的线积分"求出。

用途二：把复杂的曲线积分化为较易的二重积分（或反向运用）。当闭曲线上的积分难算、而内部偏导差简单时，用格林公式降维或换域。

平面上曲线积分与路径无关的等价条件

设 D 是单连通区域，P、Q 在 D 上有连续偏导数，以下四条等价：

  1. 沿 D 内任意闭曲线的积分 ∮_L P dx + Q dy = 0。
  2. 积分 ∫_L P dx + Q dy 与路径无关，只与起点、终点有关。
  3. ∂P/∂y = ∂Q/∂x 在 D 内恒成立。
  4. 存在可微函数 u(x,y)，使 du = P dx + Q dy（即 P dx + Q dy 是某个函数的全微分，∂u/∂x = P、∂u/∂y = Q）。
几何/物理含义：∂P/∂y = ∂Q/∂x 意味着该向量场无旋（旋度为零），是无旋场（保守场）——它一定来自某个势函数（u，即势能），"做功与路径无关，只取决于起终点的势能差"，这正是重力、静电力等保守力的特征。

求原函数 u(x,y)：先由 ∂u/∂x = P 对 x 积分得 u = ∫P dx + φ(y)，再由 ∂u/∂y = Q 定出 φ(y)；或沿折线 (x₀,y₀)→(x,y₀)→(x,y) 逐段积分。于是 ∫_{(A)}^{(B)} P dx + Q dy = u(B) − u(A)（"积分 = 势函数增量"）。

11.4 曲面积分（第一类与第二类）

第一类曲面积分（对面积）

仿照第一类曲线积分，把"曲线 + 弧长"换成"曲面 + 面积"：

∫∫_Σ f(x,y,z) dS = lim(λ→0) Σ f(ξᵢ,ηᵢ,ζᵢ) · ΔSᵢ
几何含义：① 当 f = 1 时，∫∫_Σ dS 就是曲面 Σ 的面积；② 它是"按面积逐点加权累加"。物理含义：面密度为 ρ(x,y,z) 的曲面薄壳的质量 m = ∫∫_Σ ρ dS；此外可求质心、转动惯量。

计算方法：把曲面投影到一个坐标面，写出面积元素 dS。设 Σ: z = z(x,y)，在 xOy 面上的投影区域为 D：

dS = √( 1 + z_x² + z_y² ) dx dy
∫∫_Σ f dS = ∫∫_D f(x,y,z(x,y)) · √( 1 + z_x² + z_y² ) dx dy

同理，向 yOz 或 zOx 面投影时，dS 分别带 √(1 + x_y² + x_z²)、√(1 + y_x² + y_z²)。第一类曲面积分与曲面的侧（方向）无关。

为什么 dS = √(1 + z_x² + z_y²) dxdy？切平面上，dS 是"斜面积"，它在 xOy 面的投影是 dxdy，二者夹角余弦 cosγ = 1/√(1+z_x²+z_y²)（法向与 z 轴夹角的余弦），故 dS = dxdy / cosγ。斜面越陡，cosγ 越小，同样投影对应的真实面积越大。

第二类曲面积分（对坐标）

背景是求向量场的通量（流量）：流体以速度 v = (P,Q,R) 穿过有向曲面 Σ，单位时间流量 = 把速度在法向上的分量沿面积累加：

∫∫_Σ P dy dz + Q dz dx + R dx dy = ∫∫_Σ (P cosα + Q cosβ + R cosγ) dS = ∫∫_Σ F · dS

其中 dS = n dS 是有向面积元素，n = (cosα, cosβ, cosγ) 是指定侧的单位法向量。

几何含义：第二类曲面积分是"向量场在法向上的分量"沿曲面的累加——是有方向的：选定曲面的一侧为正，n 指向哪一侧，结果的正负就反映"穿越方向"。物理含义：它就是向量场（流速、电场、磁场）穿过曲面 Σ 的通量（流量），单位时间穿过曲面的"物质或场线"总量。

计算方法（投影法）：以 R dxdy 项为例，把 Σ 投影到 xOy 面得 D，若取上侧（法向与 z 轴正向夹角为锐角）取正号，下侧取负号：

∫∫_Σ R dx dy = ± ∫∫_D R(x,y,z(x,y)) dx dy

同理 P dydz 项投影到 yOz 面（前侧正 / 后侧负）、Q dzdx 项投影到 zOx 面（右侧正 / 左侧负）。

两类曲面积分的联系

∫∫_Σ P dy dz + Q dz dx + R dx dy = ∫∫_Σ (P cosα + Q cosβ + R cosγ) dS

其中 (cosα, cosβ, cosγ) 是曲面指定侧的单位法向量，满足 cosα² + cosβ² + cosγ² = 1。第二类曲面积分与侧有关：反向 −Σ 积分变号，而第一类 dS 恒正、与侧无关。

11.5 高斯公式（Gauss / 散度定理）

定理内容

设空间闭区域 Ω 由分片光滑的闭曲面 Σ 围成，P、Q、R 在 Ω 上有一阶连续偏导数，Σ 取外侧，则：

∯_Σ P dy dz + Q dz dx + R dx dy = ∭_Ω ( ∂P/∂x + ∂Q/∂y + ∂R/∂z ) dV

记散度 div F = ∂P/∂x + ∂Q/∂y + ∂R/∂z，则高斯公式写作：

∯_Σ F · n dS = ∭_Ω div F dV
几何含义：它把闭曲面上的面积分转化为所围空间区域上的三重积分——"穿过封闭表面的总量"由"内部每一点的发散程度"累加决定。物理含义：散度 div F 是向量场在一点的"源强度 / 产生率"：div F > 0 该点有源（向外流出），div F < 0 有汇（向内流入），div F = 0 无源无汇。高斯公式即"闭合曲面总通量 = 内部所有源的总和"，是流体、电磁学（麦克斯韦方程之一）的基石。

使用要点：曲面必须封闭且取外侧；若曲面不封闭，可补面使之为闭曲面，再用高斯公式减去补面上的积分（补面通常取坐标平面，其上某些项为零）。

11.6 斯托克斯公式（Stokes）

定理内容

设 Γ 为分段光滑的空间有向闭曲线，Σ 是以 Γ 为边界的分片光滑曲面，Γ 的正向与 Σ 的侧满足右手法则（右手四指沿 Γ 正向，拇指指向 Σ 的法向），则：

∮_Γ P dx + Q dy + R dz
  = ∬_Σ ( ∂R/∂y − ∂Q/∂z ) dy dz
  + ∬_Σ ( ∂P/∂z − ∂R/∂x ) dz dx
  + ∬_Σ ( ∂Q/∂x − ∂P/∂y ) dx dy

记旋度 rot F = (∂R/∂y − ∂Q/∂z, ∂P/∂z − ∂R/∂x, ∂Q/∂x − ∂P/∂y)，则向量形式为：

∮_Γ F · dr = ∬_Σ (rot F) · n dS
几何含义：它把沿闭曲线的环量（线积分）与张在其上的曲面的面积分联系起来——格林公式正是它在平面（曲面退化为平面区域）上的特例。物理含义：旋度 rot F 度量向量场在一点的旋转程度与旋转轴方向；斯托克斯公式即"沿闭合回路的环量 = 穿过该回路的旋度通量"。流体中某点旋度不为零，表示该处有"涡旋"；静电场无旋（rot E = 0）故为保守场，而磁场一般有旋。

空间曲线积分与路径无关的条件：在单连通空间区域内，∮_Γ P dx + Q dy + R dz = 0（任意闭曲线） ⟺ rot F = 0 ⟺ 存在 u 使 du = P dx + Q dy + R dz，即 F 是无旋场 / 有势场。

使用要点：Γ 必须是闭曲线；Σ 的选取可任意（只要以 Γ 为边界且定向符合右手法则），所以常选平面作 Σ 简化计算（如取坐标平面或其平行面，使某些项为零）。

典型例题（自测）

对弧长的曲线积分

  1. 计算 ∫_L (x² + y²) ds，其中 L 为圆心在原点、半径为 a 的上半圆周 x = a cos t, y = a sin t (0 ≤ t ≤ π)。（提示：ds = a dt，答案 π a³）
  2. 求螺旋线 x = cos t, y = sin t, z = t (0 ≤ t ≤ 2π) 的弧长。

对坐标的曲线积分与格林公式

  1. 计算 ∫_L (x² + y) dx + (x + y²) dy，L 为从 (0,0) 沿抛物线 y = x² 到 (1,1)。
  2. 用格林公式求 ∮_L (2xy − x²) dx + (x + y²) dy，L 为顶点 (0,0),(1,0),(0,1) 的三角形正向边界。
  3. 验证 (2xy) dx + (x²) dy 是否为某函数的全微分，若是，求出 u(x,y) 并计算沿任意路径从 (0,0) 到 (1,2) 的积分。

曲面积分、高斯与斯托克斯公式

  1. 求上半球面 z = √(a² − x² − y²) 的面积。
  2. 用高斯公式计算 ∯_Σ x dy dz + y dz dx + z dx dy，Σ 为球面 x² + y² + z² = a² 的外侧。（答案 4π a³）
  3. 用斯托克斯公式计算 ∮_Γ y dx + z dy + x dz，Γ 为平面 x + y + z = 1 与三坐标面的交线（从 z 轴正向看为逆时针）。

常见误区

易错点清单

  • ❌ 把对弧长的曲线积分 ∫_L f ds 反向计算时变号 → ✅ 第一类曲线积分与方向无关，ds 恒正，反向不变号；只有第二类（对坐标）才反向变号。
  • ❌ 用格林公式前不检查闭曲线、正向、P、Q 有连续偏导三个条件 → ✅ 三个条件缺一不可；有奇点时（如原点处的 1/(x²+y²)）必须先挖去奇点或另作处理。
  • ❌ 判断路径无关只验 ∂P/∂y = ∂Q/∂x 却忘了要求区域单连通 → ✅ 对含"洞"的区域，该条件只是必要而非充分。
  • ❌ 用高斯公式时曲面不封闭或取成内侧、方向搞反 → ✅ 高斯公式要求封闭曲面取外侧；不封闭要先补面，取内侧要变号。
  • ❌ 把 dS 直接写成 dxdy → ✅ 曲面元素 dS = √(1 + z_x² + z_y²) dxdy，只有平面（或法向平行 z 轴）时 dS = dxdy。
  • ❌ 第二类曲面积分投影后符号随意取 → ✅ 符号由曲面的侧决定（上侧正、下侧负，前侧正、后侧负，右侧正、左侧负），侧错了整个结果反号。
  • ❌ 用斯托克斯公式时 Σ 的定向与 Γ 正向不配套 → ✅ 必须满足右手法则：四指沿 Γ 正向，拇指指向 Σ 的法向。
  • ❌ 混淆"散度"与"旋度"的物理意义 → ✅ 散度描述"源/汇"（流出量），旋度描述"旋转"（环量密度）；无散 ≠ 无旋，二者互相独立。

本章练习卷（含答案）

一、练习题

  1. 设平面曲线 L 为上半圆 x = cos t, y = sin t（0 ≤ t ≤ π），计算第一类曲线积分 ∫_L (x² + y²) ds；并说明当被积函数 f ≡ 1 时 ∫_L ds 的几何意义。
  2. 判断正误并说明理由：对弧长的曲线积分（第一类曲线积分）与曲线的方向有关，反向积分需要变号。
  3. 质点在力场 F = (x² + y, x + y²) 作用下沿抛物线 y = x² 从点 (0,0) 移动到点 (1,1)，求力所做的功 W = ∫_L (x² + y) dx + (x + y²) dy。
  4. 利用格林公式计算 ∮_L (2xy − x²) dx + (x + y²) dy，其中 L 是以 (0,0)、(1,0)、(0,1) 为顶点的三角形区域的正向边界。
  5. 验证 (2xy) dx + (x²) dy 是某个二元函数 u(x,y) 的全微分，求出 u(x,y)，并计算沿任意路径从 (0,0) 到 (1,2) 的曲线积分。
  6. 用高斯公式计算 ∯_Σ x dy dz + y dz dx + z dx dy，其中 Σ 为球面 x² + y² + z² = a² 的外侧；并结合散度说明其物理意义。

二、参考答案（点击展开）

查看第1题答案

参数化 x = cos t, y = sin t，则 ds = √[(x′)² + (y′)²] dt = dt，且 x² + y² = 1。故 ∫_L (x²+y²) ds = ∫_0^π 1·dt = π。当 f ≡ 1 时，∫_L ds 表示曲线 L 的弧长（此处上半圆周长 = π）。

查看第2题答案

错误。对弧长的曲线积分与方向无关：弧长元素 ds 恒为正，反向只是把同一弧段按相反顺序累加，结果不变，即 ∫_{−L} f ds = ∫_L f ds。只有对坐标的曲线积分（第二类）反向才变号。

查看第3题答案

取参数 x = t, y = t²（t 从 0 到 1），dx = dt, dy = 2t dt；P = x² + y = 2t²，Q = x + y² = t + t⁴。W = ∫_0^1 [2t² + (t + t⁴)·2t] dt = ∫_0^1 (4t² + 2t⁵) dt = [4t³/3 + t⁶/3]_0^1 = 4/3 + 1/3 = 5/3。

查看第4题答案

P = 2xy − x², Q = x + y²，则 ∂Q/∂x = 1，∂P/∂y = 2x。由格林公式，∮_L = ∬_D (∂Q/∂x − ∂P/∂y) dA = ∬_D (1 − 2x) dA。区域 D: x ≥ 0, y ≥ 0, x + y ≤ 1。∬_D (1−2x) dA = ∫_0^1 ∫_0^{1−x} (1−2x) dy dx = ∫_0^1 (1−2x)(1−x) dx = ∫_0^1 (1 − 3x + 2x²) dx = 1 − 3/2 + 2/3 = 1/6。

查看第5题答案

令 P = 2xy, Q = x²，∂P/∂y = 2x = ∂Q/∂x，且在全平面（单连通）成立，故该式是某函数的全微分。由 ∂u/∂x = 2xy 得 u = ∫ 2xy dx = x²y + φ(y)；再由 ∂u/∂y = x² + φ′(y) = x² 得 φ′(y) = 0，故 u = x²y + C。于是 ∫_{(0,0)}^{(1,2)} = u(1,2) − u(0,0) = 2。

查看第6题答案

记 F = (x, y, z)，P = x, Q = y, R = z，散度 div F = ∂P/∂x + ∂Q/∂y + ∂R/∂z = 3。由高斯公式，∯_Σ = ∭_Ω 3 dV = 3 × (4/3 π a³) = 4π a³。物理意义：这是径向向量场 F = (x,y,z) 从球内流向外侧的总通量；散度恒为 3，表示空间处处有强度为 3 的均匀“源”，故总通量 = 源强度 × 球体体积 = 3 × 4πa³/3 = 4πa³。
