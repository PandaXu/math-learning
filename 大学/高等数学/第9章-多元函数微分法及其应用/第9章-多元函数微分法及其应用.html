第9章 多元函数微分法及其应用

大学 / 高等数学

一句话总纲：多元微积分把一元函数的思想搬到曲面、空间与物理场里——偏导数是"沿坐标轴方向的局部变化率"，全微分是"切平面（局部线性化）"，梯度是"上升最快的方向"，而极值与拉格朗日乘数法则是"在几何约束下寻找最值点"。学完本章，你要能在心里"看见"一张曲面，以及它上面的切平面、等高线和最陡下降方向。
本章目录 9.1 多元函数的基本概念9.2 偏导数9.3 全微分9.4 复合函数求导与隐函数求导9.5 方向导数与梯度9.6 多元函数的极值9.7 拉格朗日乘数法含义总结典型例题常见误区

9.1 多元函数的基本概念

从一元到多元：为什么需要多元函数？

一元函数 y = f(x) 描述"一个量决定另一个量"。但现实中大多数结果由多个因素共同决定：温度随位置和时间变化、圆柱体积由半径和高共同决定、企业的利润由价格和产量共同决定。把这些因素都当成自变量，就得到多元函数。

定义：设 D 是平面（或空间）上的点集，若对 D 中每一点 (x, y)（或 (x, y, z)），按一定法则 f 有唯一确定的实数与之对应，则称 f 是定义在 D 上的二元（三元）函数，记作 z = f(x, y)。D 称为定义域，全体函数值构成值域。

  • 二元函数：z = f(x, y)，如 z = x² + y²、z = √(1 − x² − y²)。
  • 三元函数：u = f(x, y, z)，如 u = x² + y² + z²。
几何含义：二元函数 z = f(x, y) 的图像是三维空间中的一张曲面。每个定义域点 (x, y) 正上方高度为 z 的点 (x, y, f(x,y)) 连成曲面。例如 z = x² + y² 是一个开口向上的旋转抛物面（碗形），z = √(x² + y²) 是圆锥面，z = √(1 − x² − y²) 是上半球面。一元函数是"一条曲线"，二元函数是"一张曲面"，这就是从一维到二维的几何升级。
物理含义：二元/三元函数天然描述场：房间内每一点 (x, y, z) 的温度 T = T(x, y, z) 是温度场；大气中每一点的气压 P = P(x, y, z) 是气压场；平面板上每点的密度 ρ = ρ(x, y) 是密度分布。多元函数就是"给空间中每个位置赋一个数值"的数学语言。

平面点集与邻域

  • 邻域：点 P₀(x₀, y₀) 的 δ 邻域 = 到 P₀ 距离小于 δ 的所有点，即一个开圆盘（不含边界）。
  • 内点 / 边界点 / 开区域 / 闭区域：与一元区间概念对应，只是从"线段"推广到"平面区域"。
  • 有界区域：能被一个大圆盘完全覆盖的区域。

二元函数的极限

二重极限：当点 P(x, y) 沿任意路径无限趋近 P₀(x₀, y₀) 时，f(x, y) 都无限趋近同一个常数 A，则称 A 为 f 在 P₀ 处的极限，记作

lim        f(x, y) = A
(x,y)→(x₀,y₀)

关键：点 (x, y) → (x₀, y₀) 可以沿无穷多条曲线（直线、抛物线、任意曲线）趋近，必须沿任意路径极限都相同二重极限才存在。

几何含义：在曲面上，二重极限存在意味着：无论你从哪个方向"走向" (x₀, y₀) 正上方的那个点，曲面高度都收敛到同一个高度 A。若沿不同路径高度趋于不同值，曲面在该点附近是"撕裂的"或"尖刺丛生"的。

二元函数的连续性

若 lim f(x,y) = f(x₀,y₀)，则称 f 在 (x₀, y₀) 处连续。连续函数在闭区域上有最大值与最小值定理（有界闭区域上连续函数必取得最大最小值）和介值定理。

几何含义：连续 = 曲面没有断裂、没有洞，是一张"可以一笔不断画完"的连续曲面。

9.2 偏导数

偏导数的定义：固定其它变量，只看一个方向

一元导数研究"自变量变化时函数的变化率"。多元函数有多个自变量，我们一次只让一个自变量变化，把其余变量暂时冻结为常数，这样得到的变化率就是偏导数。

对 z = f(x, y) 在点 (x₀, y₀) 处：

∂f        lim   f(x₀+Δx, y₀) − f(x₀, y₀)
──(x₀,y₀) =  ─────────────────────────────
∂x        Δx→0            Δx

∂f        lim   f(x₀, y₀+Δy) − f(x₀, y₀)
──(x₀,y₀) =  ─────────────────────────────
∂y        Δy→0            Δy

偏导数也记作 f_x、z_x（对 x 的偏导）和 f_y、z_y（对 y 的偏导）。

  • 求 ∂f/∂x：把 y 当常数，对 x 用一元求导法则。
  • 求 ∂f/∂y：把 x 当常数，对 y 用一元求导法则。

例：z = x³ + 3xy + y²，则 ∂z/∂x = 3x² + 3y（把 y 当常数），∂z/∂y = 3x + 2y（把 x 当常数）。

几何含义（本章最重要的图景）：把曲面 z = f(x, y) 用平面 y = y₀（垂直于 y 轴）截一刀，交线是一条曲线（只有 x 在变）。偏导数 f_x(x₀, y₀) 就是这条曲线在 x = x₀ 处的切线斜率——即"沿 x 正方向走，曲面上升有多陡"。同理 f_y 是用平面 x = x₀ 截得的曲线在 y 方向的切线斜率。两个偏导数给出了曲面在 (x₀, y₀) 处沿两个坐标轴方向的"陡峭程度"。
物理含义：偏导数 = 保持其它因素不变时，单个因素的边际变化率。经济学里 ∂Q/∂L 是"资本不变时增加一个劳动力带来的产量增量"（劳动的边际产出）；热力学里 ∂U/∂T 是体积不变时内能对温度的（定容）变化率。这正是"在控制变量的前提下，看单一因素的影响力"。

高阶偏导数与混合偏导的次序无关性

偏导数仍然是 (x, y) 的函数，可继续求偏导，得到二阶偏导数：

∂²z    ∂   ∂z        ∂²z    ∂   ∂z
─── = ── (──)   ，   ─── = ── (──)
∂x²    ∂x  ∂x        ∂y²    ∂y  ∂y

      ∂²z    ∂   ∂z           ∂²z    ∂   ∂z
混合：─── = ── (──)   ， 混合：─── = ── (──)
      ∂x∂y   ∂x  ∂y           ∂y∂x   ∂y  ∂x

定理（Clairaut / Schwarz）：若两个混合偏导数 f_xy 与 f_yx 在区域 D 内连续，则它们相等：

∂²z      ∂²z
───  =  ───
∂x∂y     ∂y∂x
几何含义：混合偏导 f_xy 衡量"沿 x 方向的斜率，随 y 变化有多快"；f_yx 衡量"沿 y 方向的斜率，随 x 变化有多快"。次序无关性说明：曲面的"扭曲"无论先沿哪个方向度量都一样——这保证了二阶偏导数矩阵（Hessian 矩阵）是对称矩阵，是后面极值判别的几何基础。

9.3 全微分

全增量与全微分的定义

当 x、y 同时变化时，函数值的总变化称为全增量：

Δz = f(x₀+Δx, y₀+Δy) − f(x₀, y₀)

若 Δz 能写成"关于 Δx、Δy 的线性部分 + 高阶无穷小"：

Δz = A·Δx + B·Δy + o(ρ)，   其中 ρ = √(Δx² + Δy²)

则称 f 在 (x₀, y₀) 处可微，其中线性主部 A·Δx + B·Δy 称为全微分，记作

dz = A·Δx + B·Δy = f_x(x₀,y₀) dx + f_y(x₀,y₀) dy

（可微时必有 A = f_x，B = f_y，且取 Δx = dx，Δy = dy）。

几何含义（切平面 = 局部线性近似）：全微分 dz = f_x dx + f_y dy 对应一张切平面。曲面 z = f(x, y) 在点 (x₀, y₀, z₀) 处的切平面方程为
z − z₀ = f_x(x₀,y₀)·(x − x₀) + f_y(x₀,y₀)·(y − y₀)
这张切平面是曲面在 (x₀, y₀) 附近的最佳线性近似：把曲面局部"拍平"。当 Δx、Δy 都很小时，用平面上的增量 dz 代替曲面上的真实增量 Δz，误差是比 ρ 更高阶的无穷小。可微的几何意义就是：曲面在该点足够光滑，存在唯一的切平面。
物理含义：全微分 = 小变化下的"线性叠加"。当多个因素同时微小变化时，总效果约等于各因素单独作用的线性之和（一阶近似）。例：圆柱体积 V = πr²h，dV = 2πrh·dr + πr²·dh——体积的总变化 ≈ 半径变化带来的贡献 + 高度变化带来的贡献。工程上用 ΔV ≈ dV 估算误差和微小增量，正是"微分近似"。

可微、偏导存在、偏导连续三者的关系

  • 可微 ⇒ 偏导数存在（且全微分里的系数就是偏导数）。
  • 偏导数存在 ⇏ 可微（反例：f(x,y) = √(x²+y²) 在原点偏导存在但不可微——原点处是"尖点"，没有切平面）。
  • 偏导数连续 ⇒ 可微（这是判断可微最常用的充分条件）。
几何含义：偏导数存在只保证"沿两条坐标轴方向有切线"，但曲面可能沿其它方向是折的，整体没有切平面（如圆锥的顶点）。可微要求"四面八方"都能被同一张平面逼近——偏导存在是两条切线，可微是一整张切平面。

全微分用于近似计算

f(x₀+Δx, y₀+Δy) ≈ f(x₀,y₀) + f_x(x₀,y₀)Δx + f_y(x₀,y₀)Δy

例：求 (1.02)^3.01 的近似值。令 f(x,y) = x^y，取 x₀=1, y₀=3, Δx=0.02, Δy=0.01，得 f ≈ 1 + 3·0.02 + 0·0.01 = 1.06。

9.4 复合函数求导与隐函数求导

多元复合函数的链式法则

设 z = f(u, v)，而 u = u(x, y)、v = v(x, y)，则 z 是 x、y 的复合函数。链式法则：z 对某自变量的偏导 = 经过每一条中间路径的"偏导之积"求和。

∂z   ∂z ∂u   ∂z ∂v
── = ──·── + ──·──
∂x   ∂u ∂x   ∂v ∂x

∂z   ∂z ∂u   ∂z ∂v
── = ──·── + ──·──
∂y   ∂u ∂y   ∂v ∂y

若中间变量只有一个自变量（如 z = f(u,v), u = u(t), v = v(t)），则 z 只是 t 的一元函数，用全导数：

dz   ∂z du   ∂z dv
── = ──·── + ──·──
dt   ∂u dt   ∂v dt

画"树形图"记链式法则：从 z 出发，画出到各中间变量、再到各自变量的所有路径；∂z/∂x 就是把"从 z 到 x 的所有路径"上的偏导连乘后相加。

物理含义：链式法则是"变化率的传递与叠加"。z 随 x 变化，既通过 u 这条路传递（∂z/∂u · ∂u/∂x），又通过 v 这条路传递（∂z/∂v · ∂v/∂x），总变化率是各条通道的贡献之和。典型应用是相关变化率：例如矩形面积 S = xy，边长都随时间变化，则 dS/dt = y·dx/dt + x·dy/dt——面积变化率 = 长度贡献 + 宽度贡献。
几何含义：当 (x, y) 沿某条参数曲线 (x(t), y(t)) 移动时，曲面上对应点划出一条空间曲线，dz/dt 就是这条空间曲线的高度变化率（切线的 z 分量），等于梯度沿速度方向的投影。

隐函数求导公式

一元隐函数：由 F(x, y) = 0 确定的隐函数 y = y(x)，其导数为

dy     F_x
── = − ───    (F_y ≠ 0)
dx     F_y

二元隐函数：由 F(x, y, z) = 0 确定的隐函数 z = z(x, y)，其偏导为

∂z     F_x        ∂z     F_y
── = − ───   ，   ── = − ───    (F_z ≠ 0)
∂x     F_z        ∂y     F_z
几何含义：F(x, y, z) = 0 是空间中的一张曲面（如球面 x² + y² + z² = R²）。∂z/∂x 是"固定 y 后，曲面沿 x 方向的高度变化率"，即曲面与平面 y = 常数的交线切线斜率。而梯度 ∇F = (F_x, F_y, F_z) 处处垂直于等值面，隐函数求导公式本质上来自"沿曲面走时 F 保持不变"这一约束。

9.5 方向导数与梯度

方向导数：沿任意方向的变化率

偏导数只衡量沿坐标轴方向的变化率。更一般地，我们想知道函数沿任意方向变化有多快，这就是方向导数。

设 单位方向 u = (cos α, cos β)（二维，α、β 是方向角，cos²α + cos²β = 1），则 f 在 P₀ 沿 u 的方向导数为

∂f
──│     = f_x(P₀)·cos α + f_y(P₀)·cos β
∂l│P₀

三维中，方向 u = (cos α, cos β, cos γ)：

∂f
── = f_x·cos α + f_y·cos β + f_z·cos γ
∂l

梯度：变化最快的方向

把三个偏导数组成一个向量，称为梯度：

grad f = ∇f = (f_x, f_y, f_z) = f_x i + f_y j + f_z k

方向导数可用梯度简洁表示为点积：

∂f
── = ∇f · u = |∇f| · |u| · cos θ = |∇f| · cos θ
∂l

其中 θ 是 ∇f 与方向 u 的夹角。由此得到本章最重要的结论：

  • 当 u 与 ∇f 同向（θ = 0，cos θ = 1）时，方向导数最大，最大值为 |∇f| —— 梯度方向是函数增长最快的方向。
  • 当 u 与 ∇f 反向（θ = π）时，方向导数最小，为 −|∇f| —— 负梯度方向是下降最快的方向。
  • 当 u 与 ∇f 垂直（θ = π/2）时，方向导数为 0 —— 沿等值线方向函数值不变。
几何含义（梯度垂直于等值线/等值面）：二维函数 z = f(x, y) 的等值线（等高线） f(x, y) = c，是把曲面用水平面 z = c 截出的曲线投影到 xy 平面。梯度 ∇f 在每一点都垂直于过该点的等值线，并指向函数值增大（高度上升）的一侧。看一张地形图：等高线密集处坡度陡（|∇f| 大），等高线稀疏处坡度缓（|∇f| 小）；梯度就像地图上"最陡的上山箭头"，永远垂直于等高线指向山顶。三维中，梯度垂直于等值面 f(x, y, z) = c。
物理含义（梯度是场的"驱动力"）：
  • 热传导：热量从高温流向低温，热流密度向量 q = −k·∇T（傅里叶定律），即热量沿温度梯度的反方向流动。
  • 保守力场：力 = 势能的负梯度，F = −∇V。物体在势场中受力总指向势能下降最快的方向（水往低处流、物体向势能最低处滚）。
  • 电场：电场强度 = 电势的负梯度，E = −∇φ。
梯度把"标量场"变成一个"向量场"，这个向量处处指出"标量增长最快的方向"，是理解所有"驱动力"的钥匙。

9.6 多元函数的极值

极值的定义与必要条件

若在点 (x₀, y₀) 的某邻域内，恒有 f(x, y) ≤ f(x₀, y₀)，则 (x₀, y₀) 是极大值点（≤ 换成 ≥ 则为极小值点）。

必要条件：若 f 在 (x₀, y₀) 处取得极值且偏导数存在，则

f_x(x₀, y₀) = 0 ，  f_y(x₀, y₀) = 0

满足这两个方程的点称为驻点（稳定点）。极值点必是驻点，但驻点不一定是极值点（可能是鞍点）。

几何含义：驻点处两个偏导数都为 0，意味着切平面的两个方向斜率都为 0，即切平面是水平的。极值点 = 曲面的"山顶（极大）"或"谷底（极小）"；而鞍点像马鞍——沿 x 方向它是谷底、沿 y 方向却是山脊，切平面虽水平却不是极值。

充分条件（用二阶偏导判别，AC − B² 判别法）

设 (x₀, y₀) 是驻点，记

A = f_xx(x₀,y₀)，  B = f_xy(x₀,y₀)，  C = f_yy(x₀,y₀)
Δ = AC − B²
条件结论几何形象
Δ > 0 且 A > 0极小值谷底（碗底）
Δ > 0 且 A < 0极大值山顶（倒扣的碗）
Δ < 0不是极值（鞍点）马鞍面
Δ = 0无法判定，需其它方法需进一步分析
几何含义：AC − B² 是 Hessian 矩阵的行列式，刻画曲面在驻点附近的弯曲方式。A > 0 表示沿 x 方向"向上凹"，若四面八方都向上凹（Δ > 0）就是谷底；若沿某个方向向上凹、沿另一方向向下凹（Δ < 0），就是鞍点——曲面既"托着"又"压着"，两个方向弯曲相反。
物理含义：极值在物理中对应平衡与最优状态：系统能量最低处是稳定平衡（极小值），能量最高处是不稳定平衡（极大值）；经济学中利润最大化、成本最小化都归结为多元函数极值问题。

条件极值（约束最值）

很多实际问题要在约束下求最值，例如"在表面积固定的前提下使体积最大"。这就是条件极值，其一般解法是下一节的拉格朗日乘数法。

9.7 拉格朗日乘数法

问题的提出

求目标函数 z = f(x, y) 在约束条件 g(x, y) = 0 下的极值。注意：现在 (x, y) 不能在整个区域自由取值，只能取在曲线 g = 0 上。

构造拉格朗日函数（λ 为拉格朗日乘数）：

L(x, y, λ) = f(x, y) + λ·g(x, y)

对 x、y、λ 分别求偏导并令其为 0：

∂L/∂x = f_x + λ·g_x = 0
∂L/∂y = f_y + λ·g_y = 0
∂L/∂λ = g(x, y) = 0

解这个方程组得到候选点，再比较函数值确定最值。等价地，条件可写成向量形式：

∇f = λ·∇g   且   g(x, y) = 0
几何含义（本章的精华之一）：约束 g(x, y) = 0 是一条曲线，目标函数 f 有一族等值线 f(x, y) = c。我们在这条曲线上找 f 最大/最小的点。想象等值线"套"在约束曲线上：当 f 的某条等值线恰好与约束曲线相切时，切点就是条件极值点。相切意味着两曲线在该点的法线方向相同，而 ∇f 正是 f 的等值线的法向，∇g 正是约束曲线的法向，于是 ∇f ∥ ∇g，即 ∇f = λ·∇g。这就是拉格朗日乘数法背后的几何画面：在约束上找最值 = 找 f 的等值线与约束曲线相切的点。
物理含义：拉格朗日乘数法是有约束最优化的通用工具：给定周长求最大面积、给定材料求最大容积、给定预算求最大效用（经济学）、求物理系统在约束下的平衡构型（力学）等。λ 本身也有含义——它是"约束每放宽一个单位时，目标函数最值的变化率"（经济学中称为影子价格，衡量资源的边际价值）。

多约束情形：求 f(x, y, z) 在 g₁ = 0、g₂ = 0 下的极值，构造 L = f + λ₁g₁ + λ₂g₂，对 x、y、z、λ₁、λ₂ 求偏导令其为 0。几何上对应 ∇f = λ₁∇g₁ + λ₂∇g₂。

典型例题（自测）

基础题

  1. 求 z = x²y + xy³ 的偏导数 ∂z/∂x、∂z/∂y，以及二阶偏导 ∂²z/∂x²、∂²z/∂x∂y。
  2. 求 z = ln(x² + y²) 的全微分 dz，并用它近似计算 ln(1.02² + 1.01²) 在点 (1, 1) 附近的值。
  3. 设 z = e^(uv)，u = x² + y²，v = xy，用链式法则求 ∂z/∂x。
  4. 求曲面 z = x² + y² 在点 (1, 1, 2) 处的切平面方程。

综合题

  1. 求 f(x, y) = x² + y² 在点 (1, 2) 处沿方向 (3, 4)（先单位化）的方向导数；并求该点处函数增长最快的方向与最大增长率。
  2. 求 f(x, y) = x³ − y³ + 3x² + 3y² − 9x 的极值。
  3. 求 f(x, y) = xy 在约束 x² + y² = 1 下的最大值与最小值（用拉格朗日乘数法）。
  4. 证明：表面积为常数 S 的长方体中，体积最大的是立方体。

常见误区

  • ❌ "偏导数存在就能保证可微" → ❌ 偏导存在只是两条坐标方向的切线存在，曲面沿其它方向可能是折的；可微要求存在整张切平面（偏导连续才是可微的充分条件）。
  • ❌ "求 ∂z/∂x 时把 y 当 0" → ❌ 应把 y 当常数（保留它），不是当作 0。例：∂(x² + xy)/∂x = 2x + y，而不是 2x。
  • ❌ "二重极限存在 = 沿一条直线趋近的极限存在" → ❌ 必须沿任意路径极限都相同；沿两条不同路径得到不同值即可证明极限不存在。
  • ❌ "链式法则只乘一条路径" → ❌ 要把所有路径的贡献相加，漏掉任何一条中间变量都会出错。
  • ❌ "梯度是数值（标量）" → ❌ 梯度是向量，方向指向增长最快方向，大小等于最大方向导数。
  • ❌ "方向导数取负梯度方向时最大" → ❌ 负梯度方向方向导数最小（下降最快）；沿梯度方向才是最大。
  • ❌ "驻点一定是极值点" → ❌ 驻点可能是鞍点（AC − B² < 0），需用二阶充分条件判别。
  • ❌ "拉格朗日乘数 λ 毫无意义" → ❌ λ 表示约束每放松一个单位时最值的变化率（影子价格），有实际经济含义。
  • ❌ "切平面方程与全微分是两个不同东西" → ❌ 二者本质相同：dz = f_x dx + f_y dy 就是切平面方程的增量形式，都来自局部线性化。

本章练习卷（含答案）

一、练习题

  1. 设 z = x³ + 3xy + y²，求 ∂z/∂x 与 ∂z/∂y。
  2. 设 z = ln(x² + y²)，求全微分 dz，并写出它在点 (1, 1) 处的增量关系 Δz ≈ dz。
  3. 用几何语言解释：偏导数 f_x(x₀, y₀) 在曲面 z = f(x, y) 上代表什么？它与"用平面 y = y₀ 截曲面所得曲线的切线"有何关系？
  4. 设 z = e^(uv)，u = x² + y²，v = xy，用链式法则求 ∂z/∂x。
  5. 求 f(x, y) = x² + y² 在点 (1, 2) 处沿方向 (3, 4)（先单位化）的方向导数，并求该点函数增长最快的方向与最大增长率。
  6. 求 f(x, y) = xy 在约束 x² + y² = 1 下的最大值与最小值（用拉格朗日乘数法），并结合几何含义说明极值点在何处。

二、参考答案（点击展开）

查看第1题答案

把 y 当常数对 x 求导：∂z/∂x = 3x² + 3y；把 x 当常数对 y 求导：∂z/∂y = 3x + 2y。注意"冻结"的是变量本身，不是把它当成 0。

查看第2题答案

f_x = 2x/(x²+y²)，f_y = 2y/(x²+y²)，故 dz = (2x·dx + 2y·dy)/(x²+y²)。在 (1,1) 处 f_x = f_y = 1，所以 Δz ≈ dz = dx + dy，即 z ≈ ln 2 + (x−1) + (y−1)。

查看第3题答案

偏导数 f_x(x₀,y₀) 是"用平面 y = y₀ 截曲面 z = f(x,y) 所得交线（一条曲线）在 x = x₀ 处的切线斜率"，即沿 x 正方向走时曲面的陡峭程度；f_y 同理是沿 y 方向的切线斜率。两者只给出两个坐标轴方向的斜率，并不保证整张切平面存在（可微要求四面八方都能被同一平面逼近）。

查看第4题答案

链式法则：∂z/∂x = ∂z/∂u · ∂u/∂x + ∂z/∂v · ∂v/∂x = v·e^(uv)·2x + u·e^(uv)·y = e^(uv)·(2xv + uy)。要点：把从 z 到 x 的每一条路径的偏导之积相加，不要漏掉任何中间变量。

查看第5题答案

方向 (3,4) 单位化得 u = (3/5, 4/5)。f_x = 2x = 2，f_y = 2y = 4，故方向导数 = ∇f·u = 2·(3/5) + 4·(4/5) = 22/5 = 4.4。增长最快的方向即梯度方向 ∇f = (2, 4)（单位化为 (1/√5, 2/√5)），最大增长率 = |∇f| = √(2²+4²) = 2√5。

查看第6题答案

构造 L = xy + λ(x²+y²−1)。∂L/∂x = y + 2λx = 0，∂L/∂y = x + 2λy = 0，∂L/∂λ = x²+y²−1 = 0。由前两式得 y = −2λx、x = −2λy，消去 λ 得 x² = y²，结合 x²+y² = 1 得 x² = y² = 1/2，即 x = ±1/√2、y = ±1/√2。f = xy：同号时取最大值 1/2，异号时取最小值 −1/2。几何上，这四点正是 f 的等值线（双曲线 xy = c）与单位圆相切的位置，即 ∇f ∥ ∇g 处。
