第5章 定积分

大学 / 高等数学

一句话总纲：定积分 = 「无限细分、以直代曲、再求和取极限」。它的几何意义是曲边梯形的（代数）面积，物理意义是"变化率的累积 = 总量"；而微积分基本定理把它与求原函数（微分）打通，让计算从"无限求和"简化为「求一个原函数、代入上下限做差」。

5.1 定积分的概念

两个引例：面积问题与路程问题

引例 1（几何·面积问题）：求由曲线 y = f(x)（f(x) ≥ 0）、直线 x = a、x = b 与 x 轴围成的「曲边梯形」的面积。矩形的面积 = 底 × 高，但曲边梯形的"高" f(x) 处处在变，直接乘不出来。

引例 2（物理·路程问题）：质点沿直线以变速 v = v(t) 运动，求从时刻 T₁ 到 T₂ 走过的路程。匀速时"路程 = 速度 × 时间"，但变速时速度每一瞬间都在变。

两个问题同构：一个求"变高度的面积"，一个求"变速度的路程"——本质都是 「一个连续变化的量，在区间上的累积」。定积分就是为这一类"累积问题"发明的统一工具。

统一思想：分割 → 近似 → 求和 → 取极限

这是整个微积分最核心的一套动作，四步缺一不可：

  1. 分割：在 [a,b] 内插入 n−1 个分点，a = x₀ < x₁ < … < xₙ = b，得到 n 个小区间 [xᵢ₋₁, xᵢ]，每段长 Δxᵢ = xᵢ − xᵢ₋₁。
  2. 近似：在每个小区间上任取一点 ξᵢ，用"以直代曲、以不变代变"：小矩形面积 f(ξᵢ)Δxᵢ 近似小曲边梯形面积；物理上 v(ξᵢ)Δtᵢ 近似小段路程。
  3. 求和：得到黎曼和 S = Σ[i=1..n] f(ξᵢ)Δxᵢ（它把整个量近似成 n 块"直"的小量之和）。
  4. 取极限：令 λ = max{Δxᵢ}（最长的那个小区间的长度）趋于 0，即越分越细。若 S 的极限存在，这个极限值就是所求的精确值。

定积分的定义

设函数 f(x) 在 [a,b] 上有界。任意分割区间、任意取点 ξᵢ，若当 λ → 0 时黎曼和的极限存在，且这个极限值与分割方式无关、与 ξᵢ 的取法无关，则称 f(x) 在 [a,b] 上可积，并称该极限为 f(x) 在 [a,b] 上的定积分，记作：

∫[a,b] f(x) dx = lim(λ→0) Σ[i=1..n] f(ξᵢ) Δxᵢ

其中 a 叫积分下限，b 叫积分上限，[a,b] 叫积分区间，x 叫积分变量，f(x) 叫被积函数，f(x)dx 叫被积表达式。

几何含义：若 f(x) ≥ 0，∫[a,b] f(x) dx 就等于曲边梯形的面积；若 f(x) 有正有负，它等于 "代数面积"（signed area）= x 轴上方部分面积 − x 轴下方部分面积。定积分把"弯曲的量"通过无限细分、以直代曲，精确化成了一个极限值。
物理含义：若 v(t) 是瞬时速度，则 ∫[T₁,T₂] v(t) dt 就是这段时间的总位移（v 恒正时即路程）。更一般地，任何"变化率 f(t)" 在区间上积分，就等于该物理量在这段时间的总变化量——这是"总量累积原理"，也是微积分基本定理的伏笔。

两个必须记住的结论

  • 定积分是一个数（极限值），不是一个函数；它由被积函数与上下限唯一确定。
  • 与积分变量无关：∫[a,b] f(x) dx = ∫[a,b] f(t) dt = ∫[a,b] f(u) du——字母只是"哑变量"，换哪个都不改变结果。

可积的条件（什么时候极限一定存在）

  • 定理 1：若 f(x) 在 [a,b] 上连续，则 f(x) 在 [a,b] 上可积。
  • 定理 2：若 f(x) 在 [a,b] 上有界且只有有限个间断点，则 f(x) 在 [a,b] 上可积。
  • 注意方向：连续是可积的充分条件，不是必要条件——有有限个间断点的有界函数也可能可积。

5.2 定积分的性质

以下设 f(x)、g(x) 在 [a,b] 上可积，k 为常数。

（1）线性性质

∫[a,b] [k₁f(x) + k₂g(x)] dx = k₁∫[a,b] f(x) dx + k₂∫[a,b] g(x) dx
几何/物理：面积按系数缩放、多个图形面积直接相加；总路程 = 各分运动路程的代数和。积分运算对"线性叠加"是忠实的。

（2）区间可加性

∫[a,c] f(x) dx = ∫[a,b] f(x) dx + ∫[b,c] f(x) dx  （对任意 b 都成立）

注意：b 不一定要落在 a 与 c 之间，只要各积分都有意义，等式就成立。

几何/物理：整块面积 = 各段面积之和；全程路程 = 各段路程之和。这是"累积量可分段累加"的直接体现。

（3）交换上下限变号、区间退化

∫[a,a] f(x) dx = 0        ∫[a,b] f(x) dx = −∫[b,a] f(x) dx
几何含义：从右向左"扫描"图形，面积取负；同一点到同一点的"扫描"长度为 0，面积自然为 0。

（4）保号性与比较性质

  • 若 f(x) ≥ 0（且 a < b），则 ∫[a,b] f(x) dx ≥ 0。
  • 若 f(x) ≤ g(x)（a ≤ x ≤ b），则 ∫[a,b] f(x) dx ≤ ∫[a,b] g(x) dx。

（5）绝对值不等式

|∫[a,b] f(x) dx| ≤ ∫[a,b] |f(x)| dx
物理含义：位移的绝对值 ≤ 路程（走了又折回时，位移会抵消，路程只增不减）。这是"代数面积"与"绝对面积"的关系。

（6）估值定理

若在 [a,b] 上 m ≤ f(x) ≤ M，则：

m(b−a) ≤ ∫[a,b] f(x) dx ≤ M(b−a)
几何含义：曲边梯形的面积夹在"最小高 × 底"与"最大高 × 底"两个矩形之间。

（7）积分中值定理

若 f(x) 在 [a,b] 上连续，则至少存在一点 ξ ∈ [a,b]，使：

∫[a,b] f(x) dx = f(ξ) · (b − a)

称 f(ξ) = (1/(b−a)) ∫[a,b] f(x) dx 为 f(x) 在 [a,b] 上的平均值。

几何含义：存在某个"平均高度" f(ξ)，使这个高 × 底的矩形面积恰好等于曲边梯形面积——平均高度是面积的"等面积矩形"高。物理含义：存在某个瞬间，瞬时值（如瞬时速度）恰好等于整个过程的平均值（平均速度）。

（8）对称区间上的奇偶性（非常重要！）

f 为偶函数 ⇒ ∫[−a,a] f(x) dx = 2∫[0,a] f(x) dx
f 为奇函数 ⇒ ∫[−a,a] f(x) dx = 0
几何含义：偶函数图形关于 y 轴对称，左右两块面积相等，故翻倍；奇函数图形关于原点对称，左右两块面积一正一负相互抵消，故为 0。遇到对称区间先看奇偶，能省去一大半计算。

（9）周期函数

若 f(x) 以 T 为周期，则 ∫[a,a+T] f(x) dx = ∫[0,T] f(x) dx，即一个周期长度区间上的积分值与起点无关。

5.3 微积分基本定理

这是连接「微分」与「积分」的桥梁，是微积分的灵魂所在，分两个部分。

变上限积分（积分上限函数）

设 f(x) 在 [a,b] 上连续，定义：

Φ(x) = ∫[a,x] f(t) dt   (a ≤ x ≤ b)

把上限 x 当作自变量，Φ(x) 就是一个新函数，称为变上限积分。

几何含义：Φ(x) = 从 a 到 x 的"累计面积"。x 向右移动，就不断"扫过"更多面积，所以 Φ(x) 是"面积随右端点变化的函数"。物理含义：若 f = v(t) 是速度，Φ(t) 就是从时刻 a 到 t 的累计路程（即位移函数）。

原函数存在定理（基本定理·第一部分）

若 f(x) 在 [a,b] 上连续，则变上限积分 Φ(x) = ∫[a,x] f(t) dt 在 [a,b] 上可导，且：

Φ'(x) = f(x)

即 Φ(x) 是 f(x) 的一个原函数。这直接证明了：连续函数必有原函数。它也说明"先积分再求导，又回到原函数"——积分与微分互为逆运算。

求导公式的推广（链式法则）：

d/dx ∫[a,ψ(x)] f(t) dt = f(ψ(x)) · ψ'(x)

牛顿–莱布尼茨公式（基本定理·第二部分）

设 F(x) 是连续函数 f(x) 在 [a,b] 上的任一原函数，则：

∫[a,b] f(x) dx = F(b) − F(a) = [F(x)]ₐᵦ

这是计算定积分的根本方法：先求一个原函数 F，再代入上下限做差，彻底绕开了"分割、求和、取极限"的笨办法。

几何含义：曲边梯形的面积 = 原函数（"累计面积函数"）在右端点与左端点的高度差。也就是说，面积问题最终归结为"求原函数"这一个点。
物理含义：总位移 = 位置函数在末时刻减初时刻。s'(t) = v(t)，于是 ∫[T₁,T₂] v(t) dt = s(T₂) − s(T₁)。这正是"变化率的累积 = 总量的净变化量"——位移、电量、功、质量等一切由变化率累积而成的量，都可用"末值减初值"算出。

两个部分合起来的完整含义：第一部分说"连续函数的变上限积分是它的原函数"（积分 → 微分）；第二部分说"定积分 = 原函数两端值之差"（微分 → 积分）。二者互为逆运算，微积分基本定理因此得名。

5.4 定积分的换元积分法

定理：设 f(x) 在 [a,b] 上连续，函数 x = φ(t) 满足：

  1. φ'(t) 在 [α,β]（或 [β,α]）上连续；
  2. φ(α) = a，φ(β) = b，且当 t 在 [α,β]（或 [β,α]）上变化时，φ(t) 的值落在包含 [a,b] 的区间内（通常取 φ 单调）。

则有换元公式：

∫[a,b] f(x) dx = ∫[α,β] f(φ(t)) · φ'(t) dt

关键操作要点

  • 换元必换限：x 从 a 变到 b，对应 t 从 α 变到 β，新积分上下限就写成 α、β。
  • 求出结果后不必换回原变量：直接代入新变量的上下限即可（这与不定积分"必须换回 x"不同）。
  • 注意 φ 的单调性：为保证 x 与 t 的区间一一对应，通常要求 φ 单调；换元时上下限要按 t 的实际走向对应写。
几何含义：换元 = 换一把"刻度尺"（坐标变换）。图形的面积、总量是客观存在的，不因你用 x 还是用 t 来度量而改变，所以 ∫ f(x)dx = ∫ f(φ(t))φ'(t)dt，其中 φ'(t)dt 正是新尺子下的"微小长度"（dx = φ'(t)dt）。
物理含义：换元 = 换参数描述同一条路径、同一个量。比如把位移用"时间参数"或"弧长参数"表示，总量不变；又如在对称问题里换元能把复杂区间映射到对称区间，从而套用奇偶性简化。

常用结论（换元 + 奇偶性的经典组合）

∫[−a,a] f(x) dx = 0          （f 为奇函数）
∫[−a,a] f(x) dx = 2∫[0,a] f(x) dx   （f 为偶函数）
∫[0,π/2] sinⁿx dx = ∫[0,π/2] cosⁿx dx
∫[0,π] x·f(sin x) dx = (π/2) ∫[0,π] f(sin x) dx

第三条来自换元 t = π/2 − x；第四条来自换元 t = π − x。它们能把"带 x 的因子"消掉，是定积分计算的利器。

5.5 定积分的分部积分法

由乘积求导公式 (uv)' = u'v + uv' 在 [a,b] 上两边积分，移项即得：

∫[a,b] u(x)v'(x) dx = [u(x)v(x)]ₐᵦ − ∫[a,b] u'(x)v(x) dx
或写为：∫[a,b] u dv = [uv]ₐᵦ − ∫[a,b] v du

用法：把被积式拆成 u 与 dv 两部分，使新积分 ∫ v du 比原来的 ∫ u dv 更简单。选 u 的口诀："反对幂指三，靠后的作 u"（反三角、对数、幂、指数、三角，靠后者优先取作 u）。

几何含义：分部积分是"补形法"。把 uv 的净变化拆成"u 不变、v 变"与"v 不变、u 变"两部分：uv 的净增量 = u·dv 的累积 + v·du 的累积，移项即得公式。几何上可理解为"面积 = 大矩形 − 余下面积"。
物理含义：乘积量 uv（如 位移 × 力 = 功、电压 × 电荷 = 能量）的变化，等于两因子各自变化贡献之和。分部积分把"两者都在变的累积"拆成"一个不变、另一个变"的两块来算。

典型适用类型

类型取 u 与 dv例
幂 × 指数u = xⁿ，dv = eˣdx∫ x eˣ dx
幂 × 三角u = xⁿ，dv = sin x dx∫ x sin x dx
幂 × 对数u = ln x，dv = xⁿ dx∫ x ln x dx
指数 × 三角u 任取其一，两次分部后解方程∫ eˣ sin x dx
反三角 × 1u = arcsin x，dv = dx∫ arcsin x dx

递推公式（Wallis 思想）

记 Iₙ = ∫[0,π/2] sinⁿx dx，用分部积分可得递推：

Iₙ = ((n−1)/n) · Iₙ₋₂，  I₀ = π/2，  I₁ = 1

由此能快速算出 ∫[0,π/2] sin²x dx = π/4、∫[0,π/2] sin⁴x dx = 3π/16 等结果。

典型例题（自测）

  1. 用"N-L 公式"求 ∫[0,1] x² dx，并说明其几何意义。
    答案：[x³/3]₀¹ = 1/3。几何：抛物线 y = x² 在 [0,1] 下的面积 = 1/3。
  2. 计算 ∫[0,π] sin x dx。
    答案：[−cos x]₀^π = −cos π − (−cos 0) = 1 + 1 = 2。
  3. 利用奇偶性求 ∫[−1,1] (x³ + x) dx 与 ∫[−2,2] x² dx。
    答案：前者被积函数为奇函数 ⇒ 0；后者为偶函数 ⇒ 2∫[0,2] x² dx = 2·(8/3) = 16/3。
  4. 用换元法求 ∫[0,1] x/(1+x²) dx。
    答案：令 u = 1 + x²，du = 2x dx，限 x:0→1 对应 u:1→2，原式 = (1/2)∫[1,2] du/u = (1/2)ln 2。
  5. 用分部积分法求 ∫[0,1] x eˣ dx。
    答案：取 u = x、dv = eˣdx，得 [x eˣ]₀¹ − ∫[0,1] eˣ dx = e − (e − 1) = 1。
  6. 设 G(x) = ∫[0,x²] sin(t²) dt，求 G'(x)。
    答案：G'(x) = sin((x²)²) · 2x = 2x · sin(x⁴)。

常见误区

  • ❌ "定积分就是面积，永远为正" → ❌ 定积分是代数面积：x 轴下方的部分为负，有正有负时是"上方面积 − 下方面积"。
  • ❌ "∫[a,b] f(x) dx 是一个关于 x 的函数" → ❌ 它是一个数，且与积分变量的写法无关（∫[a,b] f(x)dx = ∫[a,b] f(t)dt）。
  • ❌ "换元后不用改上下限" → ❌ 换元必换限，且求完后不必换回原变量，直接代入新上下限。
  • ❌ "换元 x = φ(t) 时 φ 可以不单调" → ❌ 一般要求 φ 单调、值域覆盖积分区间，否则区间对应会错乱。
  • ❌ "偶函数在对称区间积分也是 0" → ❌ 偶函数是 2∫[0,a] 翻倍，奇函数才是 0。
  • ❌ "有原函数就一定能用 N-L 公式算定积分" → ❌ N-L 公式要求 f 连续；"可积"与"有原函数"是两个不同概念，不可混用。
  • ❌ "积分中值定理的 ξ 只能在区间内部取到" → ❌ 定理只保证 ξ ∈ [a,b]（f 连续时确可加强到开区间 (a,b)，但原定理结论是闭区间）。
  • ❌ "|∫ f dx| = ∫ |f| dx" → ❌ 正确的是 |∫[a,b] f dx| ≤ ∫[a,b] |f| dx，等号仅当 f 不变号时成立（位移 ≤ 路程）。

课本外 · 典故与思考

典阿基米德的穷竭法：两千年前，有人就已经"算出了定积分"（点击展开）

先看直觉：本章的"分割 → 近似 → 求和 → 取极限"四步，看起来是 17 世纪微积分的产物。但早在公元前 3 世纪，阿基米德（约公元前 287–前 212 年）就用几乎一样的套路，算出了抛物线弓形的精确面积——只不过他把"取极限"藏在了"穷竭"论证里。

他的做法：求抛物线 y = x² 下方（0 到 1）这块曲边三角形的面积。阿基米德在弓形里内接一串三角形，每次细分都会补上新的一层三角形；他发现面积一层层累加，恰好形成一个等比级数：

内接三角形面积之和 = 1/4 + 1/16 + 1/64 + … → 1/3

然后他用"反证 + 夹逼"（穷竭法）：如果面积大于 1/3，多割出几层内接三角形就能超过它，矛盾；如果面积小于 1/3，也能用外接图形逼近得出矛盾。于是精确面积只能是 1/3——与现代定积分的结果完全一致。

更惊人的是：他还用同样的方法证明了球的体积 = 4/3·πr³、球表面积 = 4πr²，以及螺旋线围成的面积。这些成果领先了微积分将近两千年，以至于数学家们感叹：若非阿基米德之死（公元前 212 年叙拉古城破时被杀），希腊人也许能提前两千年发明微积分。

思考：穷竭法缺的不是"分割求和"，而是一套通用的记号与算法——每个问题都要单独构造几何级数。而黎曼和与微积分基本定理把同一套动作抽象成一个记号 ∫，从此"算面积"变成了"算原函数"的机械操作。这就是"思想早就有了，语言（记号与定理）改变一切"的绝佳例证。
一句话总结：阿基米德的穷竭法就是没有极限符号的定积分——他算对了每个答案，只是没有人造出那台能"一劳永逸"的机器（微积分）。
史微积分基本定理的"三位发现者"：巴罗、牛顿与莱布尼茨（点击展开）

先看直觉：本章 5.3 节那个"变上限积分的导数等于被积函数"——把求面积和求切线（微分）焊在一起的定理——历史上并不是牛顿或莱布尼茨的灵光一现，而是有一段三人接力：

  • 巴罗（Isaac Barrow，1630–1677）：牛顿的老师，1669 年在《几何讲义》中已用纯几何语言证明："曲线下方的面积随右端点的变化率，恰等于曲线在该点的纵坐标"——这就是微积分基本定理的几何形态。但巴罗用的是繁琐的几何论证，没有发展出算法与记号。
  • 牛顿（1642–1727）：约 1665–1666 年用流数法独立建立了"微分与积分互逆"，并利用它计算面积与弧长。
  • 莱布尼茨（1646–1716）：1670 年代独立发现同一事实，并写下那对著名的互逆记号：d 与 ∫——∫ 与 d 互相抵消，像 √ 与 ² 一样自然。

为什么它配得上"基本"二字？在这之前，求面积（积分）与求切线（微分）是两套各做各的问题；基本定理说它们是同一枚硬币的两面。从此"算面积"退化为"找原函数"：

∫[a,b] f(x) dx = F(b) − F(a)   （F′ = f）

这也是本章从第 4 章继承的最大红利：上一章辛辛苦苦练的换元、分部，立刻变成了算定积分的武器库。

一句话总结：巴罗看到了图景，牛顿和莱布尼茨造出了语言——微积分基本定理是"面积"与"切线"的世纪联姻，也是"为什么先学微分、再学积分"的最终答案。

本章练习卷（含答案）

一、练习题

  1. 计算 ∫[0,1] x dx，并指出它的几何意义。
  2. 质点沿直线运动，速度 v(t) = 2t（m/s），求 t = 1 到 t = 3 的位移，并结合牛顿–莱布尼茨公式说明「变化率的累积 = 总量」。
  3. 求 ∫[−1,1] x dx，说明它为什么等于 0，以及它与「面积」的区别。
  4. 利用对称区间上的奇偶性求 ∫[−2,2] (x³ + x²) dx。
  5. 设 F(x) = ∫[0,x] cos t dt，求 F'(x) 与 F(π/2)。
  6. 用分部积分法求 ∫[0,π] x sin x dx，并说明分部积分的几何思路。

二、参考答案（点击展开）

查看第1题答案

∫[0,1] x dx = [x²/2]₀¹ = 1/2。几何意义：直线 y = x 与 x 轴、x = 0、x = 1 围成的三角形面积恰为 1/2。

查看第2题答案

位移 = ∫[1,3] 2t dt = [t²]₁³ = 9 − 1 = 8（m）。因 s'(t) = v(t) = 2t，取原函数 s(t) = t²，由 N-L 公式位移 = s(3) − s(1) = 8：速度（变化率）的累积等于位置函数的末值减初值。

查看第3题答案

∫[−1,1] x dx = [x²/2]₋₁¹ = 1/2 − 1/2 = 0。因为 y = x 是奇函数；它是「代数面积」：x 轴上方三角形面积 +1/2 与下方三角形面积 −1/2 正负相消，所以不是普通（非负）面积。

查看第4题答案

x³ 为奇函数 ⇒ 该项积分为 0；x² 为偶函数 ⇒ ∫[−2,2] x² dx = 2∫[0,2] x² dx = 2·(8/3) = 16/3。故原式 = 16/3。

查看第5题答案

由基本定理第一部分，F'(x) = cos x；F(π/2) = ∫[0,π/2] cos t dt = [sin t]₀^(π/2) = 1 − 0 = 1。

查看第6题答案

取 u = x、dv = sin x dx，则 v = −cos x：∫[0,π] x sin x dx = [−x cos x]₀^π − ∫[0,π] (−cos x) dx = [−x cos x]₀^π + [sin x]₀^π = π + 0 = π。也可用换元结论 ∫[0,π] x f(sin x) dx = (π/2)∫[0,π] f(sin x) dx = π。几何思路：分部积分即「补形法」，面积 = 大矩形 − 余下面积。
