第7章 微分方程

大学 / 高等数学

一句话总纲：微分方程 = 「用变化率写成的方程」。它的解不是几个数，而是一条（或一族）曲线——几何上，你是在一张"方向场"里沿着处处与它相切的积分曲线行走；物理上，你在追踪一个系统（弹簧、电路、温度、种群）随时间的演化轨迹。学完本章，你要能对每一个方程"看"出它曲线的形状与背后的动力学。

7.1 微分方程的概念

什么是微分方程

定义：含有未知函数及其导数（或微分）的方程，叫做微分方程。未知函数是一元函数的，称为常微分方程（本章只讨论常微分方程）；含多元函数偏导数的，称为偏微分方程。

y' = 2x                 （一阶，可直接积分）
y' + y = 0              （一阶线性）
y'' - 3y' + 2y = 0      （二阶常系数线性）
y'' = -g                （二阶可降阶，自由落体）

其中 y 是未知函数 y(x)，y'、y'' 是它关于 x 的一、二阶导数。

阶、线性、次数

  • 阶：方程中出现的最高阶导数的阶数。上面前两个是一阶，后两个是二阶。
  • 线性：若未知函数及其各阶导数都只以一次幂出现、且彼此不相乘，则称线性方程。如 y' + P(x)y = Q(x) 是一阶线性；y'' + p y' + q y = f(x) 是二阶线性。出现 y·y'、sin y、(y')² 等就是非线性。
  • 次数：对可化为多项式型的方程，指最高阶导数项的最高幂次。如 (y'')² + y = 0 是二阶、二次。
记牢："阶"看导数的阶，纵向数几次求导；"线性"看未知函数是否一次；"次数"看最高阶导数项的幂。三者是三个不同的维度，别混。

解、通解、特解、初值条件

  • 解：代入方程能使之在某个区间上恒成立的函数 y = φ(x)。
  • 通解：含相互独立的任意常数、且常数个数等于方程阶数的解。它代表"一整族"解。例：y' = 2x 的通解是 y = x² + C（一个常数，对应一阶）。
  • 特解：给通解里的常数取了具体值后得到的某一个解。
  • 初值条件（定解条件）：指定解在某个点的取值（及若干阶导数取值），从而从"一族解"里挑出唯一的一条。例：y' = 2x，y(0) = 1 唯一确定 y = x² + 1。

几何含义：方向场与积分曲线

一阶方程 y' = f(x, y) 的右端给的是"在某点 (x, y) 处曲线应当具有的斜率"。于是：

在平面每一点 (x, y) 处，画出斜率为 f(x, y) 的一小段短线
          ↓ 得到
     方向场（斜率场、线素场）
          ↓ 满足
     解曲线处处与这些短线相切 = 积分曲线
几何含义：微分方程不直接告诉你曲线"长什么样"，而是告诉你每一点上的方向（切线斜率）。通解就是整个方向场里那一族处处相切的积分曲线；初值条件就是"指定这条曲线必须经过哪个点"，从而从一族里挑出一条。方程的阶数 = 曲线族的参数个数 = 需要多少个初值才能定出一条。

物理含义：变化率的语言

物理含义：自然界的大多数定律说的不是"量是多少"，而是"量变化得有多快"——速度是位置的导数，加速度是速度的导数，电流是电荷的导数，增长率是种群数的导数，降温速度是温差的函数……微分方程就是把这些变化率之间的因果关系写下来。所以"解微分方程" = "由变化规律反推出量的演化轨迹"，这正是牛顿用微积分描述运动的方式。

7.2 可分离变量方程

标准形式

dy/dx = f(x) · g(y)     （右端可写成"只含 x"与"只含 y"两部分之积）

解法三步

  1. 分离变量：把含 y 的项搬到 dy 一边，含 x 的项搬到 dx 一边。
  2. 两边积分：分别求不定积分。
  3. 解出 y：尽量化成显式 y = φ(x, C)；化不出就保留隐式 Φ(x, y) = C。
dy/dx = f(x)·g(y)
→  (1/g(y)) dy = f(x) dx          （当 g(y) ≠ 0）
→  ∫ (1/g(y)) dy = ∫ f(x) dx
→  G(y) = F(x) + C

典型例题：指数律

dy/dx = k y
→ dy/y = k dx
→ ln|y| = kx + C1
→ |y| = e^(kx + C1) = e^C1 · e^(kx)
→ y = C e^(kx)     （C = ±e^C1，任意非零常数）
注意：y = 0 也是解，可并入 C = 0 的情况，故通解 y = C e^(kx)
几何含义：可分离变量意味着方向场的等倾线（斜率相同的点的连线）恰好是"竖直线 x = 常数"与"水平线 y = 常数"组成的矩形网格——斜率被"拆成"x 部分与 y 部分的乘积。因此解曲线族在不同高度 y 上的"生长趋势"彼此成比例，图形呈层状。
物理含义：y' = ky 是一切"增长速度与当前量成正比"现象的共同模型：种群增长、放射性衰变（k 为负）、复利、传热温差。它的解 y = Ce^(kx) 就是指数增长（k > 0）或指数衰减（k < 0）。k 决定"翻倍/减半"的快慢，C 是初始量 y(0)。

容易踩的坑：丢解

分离变量时除以了 g(y)，就必须单独检查 g(y) = 0 给出的常数解是否被遗漏（如上面 y = 0）。这些"额外"的解若不在通解中，称为奇解（奇异解）——它是方向场里被一族积分曲线"包络"的那条特殊曲线。

7.3 一阶线性方程

标准形式

y' + P(x) y = Q(x)      （y 与 y' 都只一次，不交叉相乘）
  • 齐次：Q(x) ≡ 0，即 y' + P(x) y = 0（可分离，直接得通解）。
  • 非齐次：Q(x) ≠ 0。

方法一：积分因子法（最常用）

积分因子： μ(x) = e^(∫ P(x) dx)
两边同乘 μ：
   μ y' + μ P y = μ Q
即 (μ y)' = μ Q          （因为 μ' = μ P）
积分：  μ y = ∫ μ Q dx + C
通解：  y = (1/μ) [ ∫ μ Q dx + C ]
     = e^(-∫P dx) [ ∫ Q · e^(∫P dx) dx + C ]
为什么乘 μ？我们要把左边"凑"成某个乘积的导数。μ 的作用就像一个"补全因子"，使 μy' + μPy 恰好是 (μy)'。条件是 μ' = μP，解之即得 μ = e^(∫P dx)。

方法二：常数变易法（理解"叠加"的钥匙）

  1. 先解齐次方程 y' + P y = 0，得 y = C e^(-∫P dx)。
  2. 把常数 C "变"成待定函数 u(x)：设 y = u(x) e^(-∫P dx)。
  3. 代回原方程，解出 u'(x)，再积分得 u(x)，即得非齐次通解。
几何含义（叠加原理）：一阶线性方程的通解 = 齐次通解 y_c（一族）+ 非齐次一个特解 y_p（一条）。几何上，这是"仿射结构"：把齐次解族整体"平移"一下（平移量 = y_p）就得到非齐次解族。任何两条解曲线之差，都是齐次方程的解。
物理含义：非齐次项 Q(x) 是"外强迫/驱动"，齐次通解是系统的"固有响应（自然衰减）"，特解是"受迫响应"。例如 L di/dt + R i = E(t)（RL 电路）：电流 = 由电感储能决定的暂态衰减 + 由电压源决定的稳态响应。总响应 = 暂态 + 稳态。

7.4 可降阶方程

高阶方程可以通过换元把阶降下来，降到一阶（甚至直接积分）再解。三种典型类型：

类型一：y^(n) = f(x)（右端只含 x）

y'' = f(x)
→ y' = ∫ f(x) dx + C1
→ y  = ∫ [∫ f(x) dx] dx + C1 x + C2       （积分两次）

例：自由落体 y'' = -g，积分两次得 y = y0 + v0 t - (1/2) g t²。

类型二：y'' = f(x, y')（缺 y）

令 p = y'，则 y'' = p' = dp/dx
原方程化为： p' = f(x, p)      （关于 p 的一阶方程）
解出 p = φ(x, C1) 后，再积一次： y = ∫ φ(x, C1) dx + C2

类型三：y'' = f(y, y')（缺 x）

令 p = y'，并把 y 当作自变量：
   y'' = dp/dx = (dp/dy)·(dy/dx) = p·(dp/dy)
原方程化为： p·(dp/dy) = f(y, p)   （关于 p 的一阶方程）
解出 p = ψ(y, C1)，再分离变量积出 x 与 y 的关系。
几何含义：类型二"缺 y"意味着方程里没有出现函数值本身，只出现斜率与二阶导数，所以解曲线族沿竖直方向平移（y → y + C）后仍是解——一族解是另一族解上下平移得到的"平行"族。类型三"缺 x"（自治方程）意味着演化规律不显含自变量，所以解族沿水平方向平移（x → x + C）不变，即"时间平移不变性"。
物理含义：类型一是"加速度只随时刻变化"的运动（如给定力 F(t)/m）；类型二是"加速度只由时刻和速度决定、与位置无关"的运动；类型三（自治）是"加速度只由位置和速度决定、与时刻无关"的运动——机械能守恒的保守系统多属此类，其解可用相平面（y, y'）上的轨线来刻画。

7.5 二阶常系数线性方程

齐次方程与特征方程

y'' + p y' + q y = 0        （p、q 为常数）
特征方程： r² + p r + q = 0，判别式 Δ = p² - 4q

设解形如 y = e^(rx) 代入，就得到特征方程。它的根决定了解的结构，分三种情形：

Δ > 0：两不等实根 r1 ≠ r2
      → y = C1 e^(r1 x) + C2 e^(r2 x)

Δ = 0：重根 r（= -p/2）
      → y = (C1 + C2 x) e^(r x)

Δ < 0：共轭复根 r = α ± βi   （α = -p/2，β = √(4q - p²)/2）
      → y = e^(αx) ( C1 cos βx + C2 sin βx )
几何含义：特征根是解曲线的"基本增长模式"。实根对应纯指数：r > 0 发散增长、r < 0 衰减、r = 0 是常数；重根多出一个 x 因子，使曲线"压着指数走"但仍与另一个线性独立；复根对应振荡：cos/sin 给出往复波形，前面的 e^(αx) 是"包络"——α > 0 振荡越来越大（发散），α = 0 等幅振荡，α < 0 振荡越来越小（衰减）。
物理含义（弹簧振子/阻尼振动）：m y'' + c y' + k y = 0 中，m 是质量、c 是阻尼、k 是弹性系数。判别式 Δ = c² - 4mk 的符号对应三种运动：c² > 4mk 过阻尼（两实根，缓慢爬回平衡、不振荡）；c² = 4mk 临界阻尼（重根，最快回到平衡且不振荡）；c² < 4mk 欠阻尼（复根，来回振荡且振幅按 e^(αx) 衰减，α = -c/(2m) < 0）。这就是"复根 ↔ 振动、实部 ↔ 衰减/发散、虚部 ↔ 角频率"的物理图像。

非齐次方程：通解 = 齐次通解 + 一个特解

y'' + p y' + q y = f(x)
通解 y = y_c + y_p
      （y_c：对应齐次方程的通解；y_p：非齐次的任一特解）

求特解：待定系数法（右端为常见函数时）

f(x) 的形式试解 y_p 的形式备注
n 次多项式同次的完全多项式（含所有低次项）缺项也照写全
A e^(kx)B e^(kx)若 k 是特征根，试解乘 x（重根乘 x²）
A cos ωx 或 A sin ωxB cos ωx + C sin ωx正弦余弦必须成对出现；若 ±iω 是特征根，试解乘 x
上述的和/积对应试解的和/积叠加原理逐项猜
物理含义（共振）：当 f(x) 的"频率/指数"与齐次解同型（即 k 或 ±iω 是特征根）时，试解必须乘 x（升幂）——对应物理上的共振：驱动力频率等于系统固有频率，振幅随时间线性增大（x·sin ωx 项）。

求特解：常数变易法（对任意 f(x) 通用）

设齐次通解 y_c = C1 y1 + C2 y2
令特解 y_p = u1(x) y1 + u2(x) y2，其中 u1、u2 满足：
   u1' y1 + u2' y2 = 0
   u1' y1' + u2' y2' = f(x)
解此二元一次线性方程组得 u1'、u2'，再积分即得 y_p。

7.6 应用

建模三步曲

  1. 找变化率：把自然定律翻译成"某量的导数 = 什么"。
  2. 建方程 + 初值：写出微分方程与定解条件。
  3. 解并解释：求通解、代初值、说明各参数含义。

应用一：牛顿冷却定律（可分离 + 一阶线性）

物体温度 T(t)，环境温度 T_a（常数）：
dT/dt = -k (T - T_a)，k > 0        （降温速度与温差成正比）
解： T(t) = T_a + (T0 - T_a) e^(-kt)
几何/物理：解是"从 T0 指数地逼近水平渐近线 T = T_a"的曲线；k 越大降温越快。法医根据尸体温度推算死亡时刻、热咖啡放凉，都是同一模型。

应用二：指数增长与放射性衰变

种群/原子核数 N(t)：
dN/dt = k N
解： N = N0 e^(kt)
   k > 0 增长；k < 0 衰变；半衰期 τ = ln2/|k|

应用三：自由落体（可降阶）

y'' = -g，y(0) = y0，y'(0) = v0
→ y' = v0 - g t
→ y = y0 + v0 t - (1/2) g t²

应用四：弹簧振子 / 阻尼振动（二阶常系数）

m y'' + c y' + k y = 0
特征方程 m r² + c r + k = 0
欠阻尼 (c² < 4mk)：y = e^(-(c/2m)t) (C1 cos ωt + C2 sin ωt)，
                   ω = √(4mk - c²) / (2m)

应用五：RL 电路（一阶线性）

L di/dt + R i = E(t)
积分因子 e^(Rt/L)：
i(t) = e^(-Rt/L) [ (1/L)∫ E(t) e^(Rt/L) dt + C ]
右端为常数 E 时：i = E/R + C e^(-Rt/L)  →  稳态 E/R + 暂态衰减。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
微分方程 y' = f(x,y)方向场（斜率场）：每点一根小短线每个状态点上的瞬时变化率（速度场、力场）
解（积分曲线）处处与方向场相切的曲线系统随时间的实际演化轨迹
通解 / 特解一族曲线 / 过定点的某一条曲线一族可能状态 / 给定初值后的唯一演化
初值条件指定曲线经过的点（与方向）指定初始位置、初始速度等初始状态
可分离变量等倾线为竖直 + 水平线组成的矩形网格增长只取决于自身量（指数律）
一阶线性齐次解族 + 特解平移（仿射结构）固有响应（暂态）+ 受迫响应（稳态）
可降阶（缺 y）解族沿竖直方向平移不变运动只由位置/速度决定，与"高度基准"无关
可降阶（缺 x，自治）解族沿水平方向平移不变演化规律不随时间改变（时间平移不变）
二阶常系数特征根决定曲线：指数 / 振荡包络弹簧振子、阻尼振动、RLC 电路
特征根解曲线的基本"增长/振荡模式"系统固有频率与衰减（或发散）因子

典型例题（自测）

  1. 求 dy/dx = -2xy 满足 y(0) = 3 的解。
  2. 求一阶线性方程 y' + 2y = e^(-x) 的通解。
  3. 求 y'' - 5y' + 6y = 0 的通解。
  4. 求 y'' + 4y = 0 满足 y(0) = 1, y'(0) = 0 的解。
  5. 解可降阶方程 y'' = 6x。
  6. 一杯 90℃ 的咖啡放在 20℃ 的房间里，1 分钟后降到 80℃。用牛顿冷却定律求任意时刻温度 T(t)。

参考答案/提示：

  1. 分离变量得 y = 3 e^(-x²)（钟形曲线，x→∞ 时衰减到 0）。
  2. 积分因子 μ = e^(2x)，通解 y = e^(-x) + C e^(-2x)（特解 + 齐次衰减）。
  3. 特征根 2、3，通解 y = C1 e^(2x) + C2 e^(3x)。
  4. 复根 ±2i，y = cos 2x（等幅振荡，周期 π）。
  5. 积分两次：y = x³ + C1 x + C2。
  6. dT/dt = -k(T - 20)，解得 T = 20 + 70 e^(-kt)；由 T(1)=80 得 e^(-k) = 6/7，故 T(t) = 20 + 70·(6/7)^t。

常见误区

⚠️ 高频错误自查

  • ❌ 分离变量时除以 g(y)，忘了检查 g(y) = 0 的常数解 → 可能丢失奇解。
  • ❌ 把"阶"与"次数"混为一谈 → 阶看最高阶导数是几阶；次数看该最高阶导数项的幂。
  • ❌ 重根情形写成 y = (C1 + C2) e^(rx)（两个常数合并成一个，实质只剩一个独立常数）→ 应写 y = (C1 + C2 x) e^(rx)。
  • ❌ 复根情形漏掉包络 e^(αx)，只写 C1 cos βx + C2 sin βx → 漏了衰减/发散因子，图像完全不对。
  • ❌ 待定系数法：当 f(x) 与齐次解"同型"（共振）时不升幂，导致猜不出特解 → 应把试解乘 x（重根乘 x²）。
  • ❌ 一阶线性方程积分因子丢常数、或乘 μ 后不写成 (μy)' 就去积分 → 记牢 (μy)' = μQ 之后两边才对 x 积分。
  • ❌ 以为 y' = y 的解是直线 → 实际是 y = Ce^x，是指数曲线（增长率正比于自身）。
  • ❌ 通解里任意常数的个数随手写 → 相互独立的常数个数必须等于方程的阶数。

  2. 求可分离变量方程 dy/dx = y/x（x ≠ 0）的通解，并说明这些解在几何上是什么图形。
  3. 方程 y' = ky 中，k > 0 与 k < 0 两种情形解曲线的走势有何不同？分别对应哪些现实现象？
  4. 求一阶线性方程 y' + y = 2 的通解，并指出当 x → ∞ 时解的极限（稳态）是多少、哪一项是"暂态"。
  5. 求二阶常系数方程 y'' - 3y' + 2y = 0 的通解，并说明特征根如何决定解曲线是发散还是衰减。
  6. 解方程 y'' + 4y = 0，说明它对应怎样的物理运动，并写出周期。

二、参考答案（点击展开）

查看第1题答案

在点 (0, 1) 处斜率 y' = 0 + 1 = 1。方向场是在平面每一点 (x, y) 处按右端 f(x, y) 画出的短线段（指示该处切线斜率）；积分曲线就是处处与这些短线相切的曲线，即微分方程的解曲线。

查看第2题答案

分离变量 dy/y = dx/x，两边积分得 ln|y| = ln|x| + C1，即 |y| = e^(C1)|x|，故通解为 y = Cx（C 为任意常数）。几何上是一族过原点的直线。

查看第3题答案

通解为 y = C e^(kx)。k > 0 时指数增长（种群增长、复利），k < 0 时指数衰减（放射性衰变、温差冷却）；|k| 决定翻倍或减半的快慢。

查看第4题答案

乘积分因子 e^x 得 (e^x y)' = 2e^x，积分得 e^x y = 2e^x + C，故通解 y = 2 + C e^(-x)。当 x → ∞ 时 C e^(-x) → 0，稳态极限为 2；C e^(-x) 是暂态（固有响应），2 是稳态（受迫响应）。

查看第5题答案

特征方程 r² - 3r + 2 = 0，得两不等实根 r1 = 1, r2 = 2，通解 y = C1 e^(x) + C2 e^(2x)。两根均为正，故 x → ∞ 时解发散，且由较大的根 r = 2 主导；若实根为负则衰减，若为复根则振荡。

查看第6题答案

特征方程 r² + 4 = 0，得共轭复根 ±2i，通解 y = C1 cos 2x + C2 sin 2x。它是等幅简谐振动（无阻尼弹簧振子），角频率 ω = 2，周期 T = 2π/2 = π。
