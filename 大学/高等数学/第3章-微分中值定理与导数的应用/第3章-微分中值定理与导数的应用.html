第3章 微分中值定理与导数的应用

大学 / 高等数学

一句话总纲：导数是"瞬时变化率"，本章所有结论都来自同一个核心图像——把曲线在一点附近"拉直"成切线：中值定理说"全局的平均变化 = 某一点的瞬时变化"，洛必达法则用"变化快慢之比"求极限，泰勒公式用"多项式切触"逼近曲线，单调性/极值/凹凸/拐点用"一阶、二阶导数的符号"读曲线形状，曲率用"切线方向角的变化率"量弯曲程度。学完本章，你要能在心里"看见"每一条光滑曲线在每一点上的切线，并用切线这把尺子读懂函数的升降、弯曲与转折。

3.1 罗尔中值定理

罗尔定理是整个"微分中值定理"的起点，也是一切"导数与函数性质"之间的桥梁。它说的是：如果一段光滑曲线两端点一样高，那么中间一定有一点的切线是水平的。

定理内容

设函数 f(x) 满足三个条件：

  1. f(x) 在闭区间 [a, b] 上连续；
  2. f(x) 在开区间 (a, b) 内可导；
  3. f(a) = f(b)（两端点函数值相等）。

则至少存在一点 ξ ∈ (a, b)，使得

f′(ξ) = 0
几何含义：在连续、光滑（可导）且两端等高的曲线弧上，至少存在一点 ξ，其切线水平（平行于 x 轴）。直观地想：一条从 P(a) 出发、又回到同一高度的光滑绳子，要么中间完全水平（处处切斜率为 0），要么先升后降（或先降后升），那么"升转降"的最高点（或"降转升"的最低点）处的切线必然是水平的。最高点、最低点处的导数就是 0。
物理含义：把 f(t) 看成物体在 t 时刻的位置（沿直线运动）。若物体在 t=a 与 t=b 两个时刻处于同一位置（位移为 0），则在运动过程中至少存在某一时刻 ξ，瞬时速度为 0（物体瞬时静止）。例如竖直上抛一个球，它从手中抛出又落回同一高度时，最高点那一瞬间速度恰好为 0。

三个条件缺一不可

罗尔定理的每个条件都必不可少，丢掉任何一个都可能找不到使 f′(ξ)=0 的点：

  • 缺"连续性"：在 [0,1] 上令 f(0)=f(1)=1，而 f(x)=x（0<x≤1），端点处"断"了一下（不连续）。虽然 f(0)=f(1)，但 (0,1) 内 f′(x)=1 恒不为 0。
  • 缺"可导性"：f(x)=|x| 在 [−1,1] 上连续且 f(−1)=f(1)=1，但 x=0 处不可导（尖点）。尽管两端等高，(0,1) 与 (−1,0) 内导数恒为 ±1，没有导数为 0 的点。
  • 缺"端点等高"：f(x)=x 在 [0,1] 上连续可导，但 f(0)=0≠1=f(1)，f′(x)=1 恒不为 0。

3.2 拉格朗日中值定理

罗尔定理要求"两端等高"很苛刻，拉格朗日把这条限制去掉，得到微分学里最常用、最核心的定理。

定理内容

设函数 f(x) 满足：在闭区间 [a, b] 上连续，在开区间 (a, b) 内可导。则至少存在一点 ξ ∈ (a, b)，使得

f′(ξ) = [ f(b) − f(a) ] / (b − a)

等价地写成 f(b) − f(a) = f′(ξ)(b − a)，也叫有限增量公式。

几何含义：连接曲线两端点 A(a, f(a))、B(b, f(b)) 的割线（弦），其斜率为 [f(b)−f(a)]/(b−a)。拉格朗日中值定理说：曲线上至少存在一点 ξ，该点切线平行于这条弦。也就是说，光滑曲线的某一段上，总有一点的切线方向等于"整段的平均方向"。罗尔定理正是"弦水平（斜率为 0）"时的特例。
物理含义：把 f(t) 看成 t 时刻的位置，则 [f(b)−f(a)]/(b−a) 就是 [a,b] 时间段内的平均速度。定理断言：运动过程中至少存在某一时刻 ξ，其瞬时速度恰好等于这段时间的平均速度。比如你从家开车到公司 60 公里用了 1 小时，平均速度 60 km/h，那么途中至少有一瞬间，仪表盘指针正好指在 60 km/h。

两个重要推论（证明恒等式、判断常数的利器）

  1. 推论一：若在区间 I 内恒有 f′(x) ≡ 0，则 f(x) 在 I 上是一个常数。逆命题也成立。
  2. 推论二：若在区间 I 内恒有 f′(x) = g′(x)，则 f(x) − g(x) ≡ C（相差一个常数）。这正是不定积分里"两个原函数只差一个常数"的理论依据。
为什么"导数处处为 0 ⇔ 函数为常数"？物理上：瞬时速度恒为 0，意味着物体任何瞬间都不动，位置自然不变。几何上：切线处处水平，曲线就"贴"在一条水平线上，不升也不降，只能是常数函数。

3.3 柯西中值定理

柯西中值定理把拉格朗日定理从"一条曲线"推广到"参数方程描述的一条曲线"，是证明洛必达法则的直接工具。

定理内容

设 f(x)、g(x) 在 [a, b] 上连续，在 (a, b) 内可导，且 g′(x) ≠ 0。则至少存在一点 ξ ∈ (a, b)，使得

[ f(b) − f(a) ] / [ g(b) − g(a) ] = f′(ξ) / g′(ξ)

当 g(x) = x 时，g′(ξ)=1，g(b)−g(a)=b−a，柯西定理就退化成了拉格朗日定理。所以三者关系是：罗尔 ⊂ 拉格朗日 ⊂ 柯西。

几何含义：把曲线写成参数形式 x=g(t)、y=f(t)，那么该曲线上某点切线斜率为 dy/dx = f′(t)/g′(t)，连接参数 t=a 与 t=b 两点割线的斜率为 [f(b)−f(a)]/[g(b)−g(a)]。柯西定理说：参数曲线上总存在一点，其切线与这段参数弧的弦平行。
物理含义：把 g(t)、f(t) 分别看成两个质点的位置，则 f′(t)/g′(t) 是二者的瞬时速度之比，[f(b)−f(a)]/[g(b)−g(a)] 是二者的平均速度之比。定理断言：两质点同时间运动时，存在某一时刻，它们的瞬时速度之比等于整段的平均速度之比。

3.4 洛必达法则

洛必达法则把"求两个量之比（且都趋于 0 或都趋于 ∞）的极限"转化为"求它们导数之比的极限"，是处理 0/0 与 ∞/∞ 型未定式的核心工具。

法则内容（0/0 与 ∞/∞ 型）

设 lim f(x) = 0 且 lim g(x) = 0（或二者都趋于 ∞），且 f、g 在 x₀ 的某去心邻域内可导、g′(x) ≠ 0。若 lim f′(x)/g′(x) 存在（或为 ∞），则

lim f(x)/g(x) = lim f′(x)/g′(x)

一个最典型的例子：

lim(x→0) sin x / x = lim(x→0) cos x / 1 = 1
几何/极限含义：当 x→x₀ 时，f(x) 与 g(x) 都趋于 0，此时直接比"大小"是 0/0 无法判断。但二者"趋于 0 的快慢"不同：在 x₀ 附近，f(x) ≈ f′(x₀)(x−x₀)、g(x) ≈ g′(x₀)(x−x₀)（切线近似），所以比值取决于切线斜率之比 f′(x₀)/g′(x₀)。洛必达法则本质上就是"用切线近似替代曲线"来比较两个无穷小量的阶。
物理含义：若 f(t)、g(t) 分别表示两个物体在同一时刻从同一点出发后、经过很短时间 Δt 走过的位移（都趋于 0），那么 f/g 的极限就是二者瞬时速度之比：谁"起速"更快，谁的位移增长就更占主导。

其他未定式的转化

洛必达法则只能直接用于 0/0 与 ∞/∞。其余五种未定式须先变形：

未定式转化方法示例
0·∞把其中一个因子取倒数移到分母，化成 0/0 或 ∞/∞x·ln x（x→0⁺）= ln x / (1/x)
∞ − ∞通分、有理化、提公因子，化为商式1/x − 1/sin x（x→0）
1^∞、0^0、∞^0先取对数：u^v = e^(v·ln u)，再求 v·ln u 的极限(1 + 1/x)^x（x→∞）

使用洛必达法则的三个关键注意点

  1. 先验证再使用：必须确认当前是 0/0 或 ∞/∞ 型，否则直接用会得出错误结果。
  2. 可反复使用：若 f′/g′ 仍是 0/0 或 ∞/∞，可继续洛必达，直到求出极限。
  3. 失效不等于极限不存在：若 lim f′/g′ 不存在（且不为 ∞），洛必达法则失效，但原极限 lim f/g 可能仍然存在，需要换其他方法（夹逼、等价无穷小、泰勒等）。洛必达是"充分条件"而非"必要条件"。

3.5 泰勒公式

泰勒公式回答了一个深刻的问题：能否用多项式（人类最会算的函数）去逼近任意光滑函数？答案是：在一点附近，用多项式"贴合"得越来越好，其系数由函数在该点的各阶导数决定。

带皮亚诺余项的泰勒公式（局部逼近）

设 f(x) 在 x₀ 处具有 n 阶导数，则

f(x) = f(x₀) + f′(x₀)(x−x₀) + f″(x₀)/2!·(x−x₀)² + … + f⁽ⁿ⁾(x₀)/n!·(x−x₀)ⁿ + o((x−x₀)ⁿ)

余项 o((x−x₀)ⁿ) 表示当 x→x₀ 时，误差比 (x−x₀)ⁿ 趋于 0 得更快。

带拉格朗日余项的泰勒公式（定量估计误差）

若 f(x) 在 x₀ 的某邻域内具有 (n+1) 阶导数，则存在 ξ 介于 x 与 x₀ 之间，使

f(x) = f(x₀) + f′(x₀)(x−x₀) + … + f⁽ⁿ⁾(x₀)/n!·(x−x₀)ⁿ + f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·(x−x₀)ⁿ⁺¹

最后一项就是拉格朗日余项，给出了误差的上界估计（拉格朗日中值定理正是 n=0 时的特例）。

麦克劳林公式（x₀ = 0 的泰勒公式）

令 x₀ = 0，得最常用的五个展开式（务必牢记）：

eˣ    = 1 + x + x²/2! + x³/3! + … + xⁿ/n! + o(xⁿ)
sin x = x − x³/3! + x⁵/5! − x⁷/7! + … + (−1)ᵏ x²ᵏ⁺¹/(2k+1)! + o(x²ᵏ⁺²)
cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + … + (−1)ᵏ x²ᵏ/(2k)! + o(x²ᵏ⁺¹)
ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + … + (−1)ⁿ⁻¹ xⁿ/n + o(xⁿ)
(1+x)^α = 1 + αx + α(α−1)/2!·x² + … + α(α−1)…(α−n+1)/n!·xⁿ + o(xⁿ)
几何含义：n 阶泰勒多项式 Tₙ(x) 与曲线 y=f(x) 在 x₀ 处"切触"到 n 阶：它们在该点有相同的函数值、相同的一阶导、二阶导、……、n 阶导。n=1 时就是切线（一阶贴合）；n 越大，多项式与曲线"贴"得越紧。直观上是"用一个弯曲程度可控的抛物线、三次曲线……去贴合原曲线"。
物理含义：泰勒公式是"局部近似"的核心。经典例子：sin θ ≈ θ（θ 很小时）让单摆小角度振动退化为简谐运动；(1+x)^α ≈ 1+αx 是低速相对论、微小形变里的一阶近似。它把复杂的非线性运动，在"附近"简化为最容易处理的线性或多项式模型。

3.6 单调性与极值

一阶导数的符号，直接告诉我们函数是"上升"还是"下降"。

单调性判定定理

设 f(x) 在 [a,b] 上连续，在 (a,b) 内可导：

  • 若在 (a,b) 内 f′(x) > 0，则 f(x) 在 [a,b] 上单调递增；
  • 若在 (a,b) 内 f′(x) < 0，则 f(x) 在 [a,b] 上单调递减；
  • 若 f′(x) ≥ 0（或 ≤ 0），且等号只在个别点成立，结论仍然成立。
几何含义：切线斜率（f′）为正 → 切线向右上方倾斜 → 曲线随 x 增大而上升；斜率为负 → 切线向右下方倾斜 → 曲线下降。导数符号就是曲线在每一点"朝向"的读数。
物理含义：若 f(t) 是位置，则 f′(t) 是速度。速度为正（向右运动）→ 位移随 t 增加；速度为负（向左运动）→ 位移随 t 减少。单调性判定 = "速度方向决定位移方向"。

极值及其两个充分条件

极值：若在 x₀ 的某邻域内，恒有 f(x) ≤ f(x₀)（或 ≥），则 f(x₀) 为极大值（或极小值）。极值是局部概念，不是整体最大最小。

必要条件：若 f 在 x₀ 处可导且取得极值，则 f′(x₀) = 0（x₀ 称为驻点）。注意：极值还可能出现在不可导点（如尖点、角点），所以候选点 = 驻点 ∪ 不可导点。

第一充分条件（看 f′ 在 x₀ 两侧是否变号）：

  • f′ 由正变负 → 左升右降 → 极大值；
  • f′ 由负变正 → 左降右升 → 极小值；
  • f′ 不变号 → 不是极值。

第二充分条件（用二阶导）：设 f′(x₀)=0 且 f″(x₀) ≠ 0，则

  • f″(x₀) < 0 → 极大值（曲线在该点向下弯，是"峰"）；
  • f″(x₀) > 0 → 极小值（曲线向上弯，是"谷"）。
几何含义：极值点是曲线的"峰顶"与"谷底"，该处切线水平（f′=0）。第一充分条件看的是"山峰还是山谷"（先升后降 / 先降后升）；第二充分条件看的是峰顶处的"朝向"（向下凹的峰、向上凹的谷）。
物理含义：竖直上抛运动中，位移 f(t) 在最高点达到极大值，此时瞬时速度 f′=0；而速度函数 v(t) 的极值点出现在加速度 a(t)=v′(t)=0 的时刻（速度的增减发生转折）。求极值 = 找"运动状态的转折瞬间"。

3.7 凹凸性与拐点

一阶导看"升降"，二阶导看"弯曲"。凹凸性描述曲线是"向上弯（碗）"还是"向下弯（帽）"。

凹凸性判定定理

设 f(x) 在 [a,b] 上连续，在 (a,b) 内具有二阶导数：

  • 若在 (a,b) 内 f″(x) > 0，则曲线是凹（向上凹）的，曲线位于其任一点切线的上方；
  • 若在 (a,b) 内 f″(x) < 0，则曲线是凸（向下凹）的，曲线位于其任一点切线的下方。
几何含义：f″ > 0 意味着切线斜率 f′ 在增大，切线随着 x 逆时针转动，曲线"兜住"切线往上凹，像一只碗；f″ < 0 则切线顺时针转动，曲线压在切线下方，像一顶帽子。判断凹凸最快的图像记忆：f″>0 是"∪"（盛水），f″<0 是"∩"（倒扣）。
物理含义：若 f(t) 是位置，f″(t) 就是加速度。速度函数 v(t) 的凹凸性由加速度决定：a(t)>0 时 v(t) 是向上凹的（速度增长越来越快）；a(t)<0 时 v(t) 是向下凹的（速度减少越来越快）。f″ 符号 = 加速度方向，决定"速度曲线的弯曲方向"。

拐点

拐点：连续曲线上凹凸性发生改变的点（曲线由"碗"翻成"帽"，或反之）。

必要条件：若 (x₀, f(x₀)) 是拐点且 f″(x₀) 存在，则 f″(x₀) = 0。但 f″(x₀)=0 的点不一定是拐点（还要看是否变号）；拐点也可能出现在 f″ 不存在处。

充分条件：f″(x) 在 x₀ 两侧变号（由正变负或由负变正），则 (x₀, f(x₀)) 是拐点。

几何含义：拐点是曲线"弯曲方向"翻转的位置：从"向上弯"翻到"向下弯"。想象一条 S 形曲线，正中间那一点就是拐点——曲线在这里由"兜住切线"变成"压在切线下"。
物理含义：拐点对应 f″（加速度）变号 的时刻：运动从"加速"转向"减速"（或反之）的瞬间，物体的运动状态发生质的改变。例如汽车先踩油门（a>0）再踩刹车（a<0），速度曲线的凹凸性改变处就是"开始刹车"的那一刻。

一句话辨析：驻点看一阶导（切线水平），拐点看二阶导（弯曲翻转）；二者是不同的概念，可同时出现也可只出现其一。

3.8 曲率

曲率定量回答"曲线弯曲得有多厉害"。它不是笼统的形容词，而是一个可以用公式算出来的数。

弧微分与曲率的定义

设曲线弧为 y=f(x)，则弧微分（一小段弧长的近似）：

ds = √(1 + y′²) · dx

曲率定义为：切线方向角 α 对弧长 s 的变化率的绝对值，即

K = |dα / ds|

对 y=f(x) 的曲线，曲率计算公式为

K = |y″| / (1 + y′²)^(3/2)

曲率半径（密切圆半径）为 ρ = 1/K。

几何含义：曲率 = 沿曲线走单位弧长时切线方向转过的角度。直线：切线方向永远不变，dα=0，所以 K=0（曲率半径为 ∞，可以看成"半径无限大的圆"）；半径为 R 的圆：走弧长 ds 时方向转过 dα=ds/R，所以 K=1/R（常数）。曲率半径 ρ=1/K 就是"与该点曲线最贴合的那个圆（密切圆）"的半径——弯曲越厉害，ρ 越小，越接近一个急转弯。
物理含义：车辆沿曲线行驶，向心加速度 a = v²/ρ（v 为速率，ρ 为曲率半径）。曲率越大（ρ 越小），同样速度下需要更大的向心力，转弯越"急"。这就是高速公路弯道要"外高内低"并限制车速、铁路要铺设缓和曲线（让曲率从 0 平滑过渡，避免列车横向加速度突变）的原因。

特例速记：直线上 K=0；圆（半径 R）上 K=1/R；抛物线 y=x² 在顶点 x=0 处 y′=0、y″=2，故 K=2（曲率半径 1/2）。

本章 · 几何与物理含义总结

概念几何含义物理含义
罗尔定理两端等高的光滑曲线必有水平切线位移为 0 的运动过程必有瞬时速度为 0 的时刻
拉格朗日中值定理曲线上存在切线平行于两端点连线（弦）必有一瞬时速度等于整段的平均速度
柯西中值定理参数曲线上存在切线与参数弧的弦平行两质点的瞬时速度之比等于平均速度之比
洛必达法则用切线斜率之比比较两条曲线趋近的快慢比较两个同时趋于 0/∞ 量的相对变化率
泰勒公式用多项式在一点处"切触"逼近曲线局部线性/多项式近似（小角度、低速近似）
单调性切线斜率的正负 → 曲线升降速度方向 → 位移增减
极值局部的峰与谷（切线水平处）瞬时速度为零的位移转折点
凹凸性曲线在切线上方（碗）或下方（帽）加速度符号决定速度曲线的弯曲方向

典型例题（自测）

例题与提示

  1. 验证罗尔定理：f(x)=x³−3x 在 [0, √3] 上是否满足罗尔定理条件？求出 ξ。 （提示：f(0)=f(√3)=0；f′(x)=3x²−3=0 得 x=±1，ξ=1∈(0,√3)。）
  2. 用拉格朗日定理证不等式：证明当 x>0 时，x/(1+x) < ln(1+x) < x。 （提示：对 ln(1+x) 在 [0,x] 上用拉格朗日中值定理。）
  3. 洛必达：求 lim(x→0) (sin x − x)/x³。 （答案：−1/6，需连续三次洛必达或配泰勒。）
  4. 洛必达：求 lim(x→0) (eˣ − 1 − x)/x²。 （答案：1/2。）
  5. 泰勒：写出 f(x)=eˣ 在 x=0 处的带拉格朗日余项的 n 阶麦克劳林公式，并据此近似计算 e（取 x=1）。
  6. 单调性与极值：求 f(x)=x³−3x²−9x+5 的单调区间与极值。 （f′=3(x−3)(x+1)；x=−1 处极大值 10，x=3 处极小值 −22。）
  7. 凹凸与拐点：求曲线 y=x³−3x 的凹凸区间与拐点。 （y″=6x；x<0 凸、x>0 凹，拐点 (0,0)。）
  8. 曲率：求抛物线 y=x² 在 x=1 处的曲率与曲率半径。 （y′=2、y″=2；K=2/5^(3/2)，ρ=5√5/2。）

常见误区

⚠ 务必避开的坑

  • ❌ "罗尔定理只要求 f(a)=f(b)" → ❌ 还必须闭区间连续、开区间可导，三个条件缺一不可，否则结论可能不成立。
  • ❌ "只要两个函数都趋于 0 就能洛必达" → ❌ 必须先验证是 0/0 或 ∞/∞ 未定式，且求导后极限存在（或为 ∞）；其他未定式要变形。
  • ❌ "lim f′/g′ 不存在 ⇒ lim f/g 不存在" → ❌ 洛必达法则失效不等于原极限不存在，此时要换夹逼、等价无穷小、泰勒等方法。
  • ❌ "f′(x₀)=0 就一定是极值点" → ❌ 还可能是拐点（如 y=x³ 在 x=0 处 f′=0 但不是极值）；还要看 f′ 是否变号。
  • ❌ "f″(x₀)=0 就一定是拐点" → ❌ 还要求 f″ 在 x₀ 两侧变号（如 y=x⁴ 在 x=0 处 f″=0 但两侧都凹，不是拐点）。
  • ❌ "凹、凸是绝对的" → ❌ 不同教材对"凹/凸"命名可能相反，以f″>0 曲线在切线上方（碗 ∪）为准，做题先确认所用定义。
  • ❌ "曲率公式记成 K=|y″|/(1+y′²)" → ❌ 分母是 (1+y′²)^(3/2)，漏掉 3/2 次方是常见错误。
  • ❌ "极值点 = 最值点" → ❌ 极值是局部概念，最值在闭区间上还需比较端点值与驻点、不可导点的值。

本章练习卷（含答案）

一、练习题

  1. 罗尔定理的几何含义：设 f(x)=x²−2x 在区间 [0,2] 上。验证它是否满足罗尔定理的三个条件；若满足，求出使 f′(ξ)=0 的 ξ，并用"切线水平"解释其几何含义。
  2. 拉格朗日中值定理的物理含义：一辆汽车沿直线行驶，位置函数为 f(t)=t²+2t（t 单位：小时，f 单位：公里）。求它在 t=0 到 t=2 这段时间内的平均速度，并找出至少一个瞬时速度恰好等于该平均速度的时刻。
  3. 洛必达法则：求极限 lim(x→0) (1−cos x)/x²，并说明为什么可以用洛必达法则。
  4. 单调性与极值：求 f(x)=x³−3x 的单调区间与极值，并说明极大/极小值的几何含义。
  5. 凹凸性与拐点：求曲线 y=x³−3x 的凹凸区间与拐点，并用"碗 ∪ / 帽 ∩"的图像解释。
  6. 泰勒公式：写出 f(x)=eˣ 在 x=0 处的带皮亚诺余项的麦克劳林公式（展开到 x³ 项），并据此估算 e^0.1 的近似值（保留 4 位小数）。

二、参考答案（点击展开）

查看第1题答案

f(x)=x²−2x 是多项式，在闭区间 [0,2] 上连续，在开区间 (0,2) 内可导；又 f(0)=0，f(2)=4−4=0，两端函数值相等，满足罗尔定理全部三个条件。f′(x)=2x−2，令 f′(ξ)=0 得 ξ=1∈(0,2)。几何含义：曲线两端点 (0,0) 与 (2,0) 等高，因此在顶点 (1,−1) 处存在一条水平的切线（切线平行于 x 轴，即平行于两端点连线所在的水平线）。

查看第2题答案

平均速度 = [f(2)−f(0)]/(2−0) = (8−0)/2 = 4 km/h。由拉格朗日中值定理，存在 ξ∈(0,2) 使 f′(ξ)=4。而 f′(t)=2t+2，令 2t+2=4 得 t=1。即 t=1 小时那一刻的瞬时速度恰等于整段平均速度 4 km/h。物理含义：物体在一段时间内必有一个瞬间，其瞬时速度等于这段的平均速度。

查看第3题答案

x→0 时 1−cos x→0、x²→0，是 0/0 型未定式，且分子分母都可导、分母导数 x→0 时不为 0，故可用洛必达法则。第一次洛必达：lim (1−cos x)/x² = lim sin x/(2x)。再由重要极限 sin x/x→1，得原极限 = 1/2。也可对 sin x/(2x) 再用一次洛必达得 lim cos x/2 = 1/2。答案：1/2。

查看第4题答案

f′(x)=3x²−3=3(x−1)(x+1)。由 f′>0 得 x<−1 或 x>1，故在 (−∞,−1) 与 (1,+∞) 上单调递增；由 f′<0 得 −1<x<1，故在 (−1,1) 上单调递减。在 x=−1 处 f′ 由正变负，取得极大值 f(−1)=2；在 x=1 处 f′ 由负变正，取得极小值 f(1)=−2。几何含义：x=−1 是曲线的"峰顶"（左升右降），x=1 是"谷底"（左降右升），这两处切线都是水平的（f′=0）。

查看第5题答案

y′=3x²−3，y″=6x。当 x<0 时 y″<0，曲线是凸（向下凹，像倒扣的帽子 ∩）；当 x>0 时 y″>0，曲线是凹（向上凹，像盛水的碗 ∪）。y″ 在 x=0 两侧由负变正，凹凸性发生翻转，故 (0,0) 是拐点。直观上曲线从"向下弯"翻成"向上弯"，S 形翻转的中心正是原点。

查看第6题答案

eˣ 的各阶导数都是 eˣ，在 x=0 处全为 1，故 eˣ = 1 + x + x²/2! + x³/3! + o(x³)。取 x=0.1 得 e^0.1 ≈ 1 + 0.1 + 0.1²/2 + 0.1³/6 = 1 + 0.1 + 0.005 + 0.0001667 ≈ 1.1052。泰勒公式的意义：在 x=0 附近用多项式"切触"逼近曲线，项数越多贴合越紧，越小的 |x| 近似越准。
