第1章 函数与极限

大学 / 高等数学

一句话总纲：极限是「无限逼近」的精确语言——函数描述一个量随另一个量的变化，极限刻画它「越来越接近某个值」的趋势，连续刻画它「不断开」。学完本章，你要能把「越来越近、最终稳定」这句直觉，翻译成 ε–δ / ε–N 的严谨定义，并用「图像」与「运动」两幅画面真正理解每一个结论。

1.1 函数

函数的定义与三要素

定义：设 D 是一个非空数集，若对 D 中的每一个数 x，按照某个确定的对应法则 f，都有唯一确定的数 y 与之对应，则称 f 是定义在 D 上的函数，记作 y = f(x)，x ∈ D。

  • 定义域 D：自变量 x 的取值范围（使表达式有意义的全体 x）。
  • 值域 R(f)：全体函数值 y 的集合。
  • 对应法则 f：由 x 得到 y 的规则。

两个函数相等，当且仅当定义域相同且对应法则相同。例如 f(x) = x²（x 为任意实数）与 g(x) = x²（x ≥ 0）不是同一个函数，因为定义域不同。

几何含义：函数 y = f(x) 的图像是平面坐标系里的一条曲线：给一个横坐标 x，向上（或向下）量出纵坐标 y，就得到曲线上的一点 (x, f(x))。判断一条曲线是否是函数图像，用铅垂线检验：任一条竖直直线与图像至多交于一点——因为每个 x 只能对应唯一的 y。
物理含义：函数描述「一个量随另一个量变化」的规律。路程是时间的函数 s = s(t)；速度是时间的函数 v = v(t)；温度是时间的函数 T = T(t)。给一个时刻，就唯一得到一个位置/速度/温度。

函数的四种基本性质

  • 有界性：若存在 M > 0，使得对一切 x ∈ D 都有 |f(x)| ≤ M，则称 f 在 D 上有界。几何上，图像被夹在两条水平线 y = M 与 y = −M 之间。
  • 单调性：若 x₁ < x₂ 时恒有 f(x₁) ≤ f(x₂)，则 f 单调增加（严格增：f(x₁) < f(x₂)）；反之单调减少。几何上，单调增的图像从左到右「只升不降」。
  • 奇偶性：若 f(−x) = −f(x)，f 为奇函数，图像关于原点对称；若 f(−x) = f(x)，f 为偶函数，图像关于 y 轴对称。
  • 周期性：若存在 T ≠ 0，使 f(x + T) = f(x) 对一切 x 成立，则 f 是周期为 T 的周期函数。几何上，图像沿 x 轴平移 T 后与原图完全重合。
物理含义：有界 = 物理量不会「跑出范围」（如电压不超过某上限）；单调 = 量随时间只增不减（如熵、耗散过程）；奇偶 = 系统关于参考点/参考轴的对称性（正反方向等价）；周期 = 往复运动（单摆、交流电、简谐振动）在每个周期内重复同一状态。

反函数与复合函数

反函数：若 f 是一一对应（每个 y 也唯一对应一个 x），则可解出 x = f⁻¹(y)，交换记号得反函数 y = f⁻¹(x)。反函数的图像与原函数的图像关于直线 y = x 对称。

复合函数：设 y = f(u)、u = g(x)，把 g(x) 代入 f 得 y = f(g(x))，记作 (f ∘ g)(x)。要求 g(x) 的值域落在 f 的定义域内。例：y = sin(x²) 是 y = sin u 与 u = x² 的复合。

初等函数

以下六类称为基本初等函数：

名称表达式说明
常数函数y = C水平直线
幂函数y = xᵅ（α 为常数）如 x²、x³、√x = x^(1/2)
指数函数y = aˣ（a > 0, a ≠ 1）a > 1 增长，0 < a < 1 衰减
对数函数y = logₐx（a > 0, a ≠ 1）指数函数的反函数
三角函数y = sin x、cos x、tan x…周期函数
反三角函数y = arcsin x、arccos x、arctan x三角函数的反函数（主值）

由基本初等函数经有限次四则运算与有限次复合所构成的、能用一个式子表示的函数，统称初等函数。例如 y = ln(1 + x²)、y = e^(sin x) 都是初等函数。绝大多数高等数学讨论的函数都是初等函数。

1.2 数列极限

数列与收敛

数列：按正整数顺序排列的一串数 x₁, x₂, x₃, …, xₙ, …，记作 {xₙ}。例如 xₙ = 1/n 给出 1, 1/2, 1/3, …，越来越接近 0。

数列极限的定义（ε–N）：设 {xₙ} 是数列，a 是常数。若对任意给定的正数 ε（无论多小），总存在正整数 N，使得当 n > N 时，恒有

|xₙ − a| < ε

则称数列 {xₙ} 以 a 为极限（收敛于 a），记作

lim(n→∞) xₙ = a   或   xₙ → a (n → ∞)

不收敛的数列称为发散。定义的精髓在于 ε 的「任意小」与 N 的「存在性」：N 依赖 ε，ε 越小，通常 N 要取越大，但总能找到这样的 N。

几何含义：不等式 |xₙ − a| < ε 等价于 a − ε < xₙ < a + ε，即在数轴上以 a 为中心、半径为 ε 的开区间 (a − ε, a + ε) 内。定义说的是：无论把这个「小区间」取得多窄，从某一项 N 之后，所有项 xₙ 都落在这个小区间里；落在区间外的至多只有前面有限项（x₁ 到 x_N）。也就是说，数列的「点」最终密密麻麻地挤在 a 的周围。
物理含义：数列极限描述「无限逼近但不一定到达」的过程。温度逐渐冷却到室温：T₁, T₂, T₃, … → 室温；阻尼振动的振幅 Aₙ → 0；放射性物质的剩余量 mₙ → 0。极限刻画的是最终的稳定趋势（稳态值），而不是某一步恰好等于它。

收敛数列的性质

  • 唯一性：若数列收敛，则它的极限唯一。一个数列不可能同时趋于两个不同的数。
  • 有界性：收敛数列必有界（存在 M > 0，使 |xₙ| ≤ M 对一切 n 成立）。注意：有界不一定收敛（如 xₙ = (−1)ⁿ 有界但来回跳动、不收敛）。
  • 保号性：若 lim xₙ = a > 0（或 a < 0），则从某项之后，xₙ 与 a 同号（保持正或保持负）。
  • 子列：收敛数列的任一子列也收敛，且极限相同。反过来，若某数列的两个子列极限不同，则该数列发散。

1.3 函数极限

x → x₀ 时的极限（ε–δ 定义）

设函数 f(x) 在 x₀ 的某去心邻域内有定义，A 是常数。若对任意 ε > 0，总存在 δ > 0，使得当 0 < |x − x₀| < δ 时，恒有

|f(x) − A| < ε

则称 A 是 f(x) 当 x → x₀ 时的极限，记作

lim(x→x₀) f(x) = A   或   f(x) → A (x → x₀)

关键：条件 0 < |x − x₀| 表示 x ≠ x₀，即研究的是 x 无限接近 x₀ 但不取到 x₀ 时 f(x) 的趋势。因此极限 A 与 f(x₀) 是否有定义、取值是多少完全无关。

x → ∞ 时的极限

若对任意 ε > 0，存在正数 X，当 |x| > X 时恒有 |f(x) − A| < ε，则称

lim(x→∞) f(x) = A

表示 |x| 无限增大时 f(x) 趋于 A。几何上，曲线无限延伸但越来越贴近水平直线 y = A。

左极限与右极限

x 从 x₀ 的左侧（x < x₀）趋于 x₀ 的极限叫左极限，记作 f(x₀⁻) 或 lim(x→x₀⁻) f(x)；从右侧（x > x₀）趋于 x₀ 的极限叫右极限，记作 f(x₀⁺) 或 lim(x→x₀⁺) f(x)。

充要条件

极限 lim(x→x₀) f(x) = A 存在的充要条件是：左右极限都存在且相等，即

lim(x→x₀⁻) f(x) = lim(x→x₀⁺) f(x) = A

若左右极限不相等，或其中之一不存在，则极限不存在。

几何含义：lim(x→x₀) f(x) = A 的图像画面是：把注意力放在「以 y = A 为中心、宽度任意小（2ε）的水平横带」上，总能找到 x₀ 的一个足够小的去心邻域，使这段邻域内曲线上所有的点 (x, f(x)) 都落进这条横带里。换句话说，当 x 沿 x 轴滑向 x₀ 时，曲线被「吸」向水平线 y = A。左右极限不等，意味着曲线在 x₀ 处「断成上下两截」——左边接一条、右边接另一条，出现台阶式跳跃。
物理含义：函数极限正是「瞬时量」的来源。平均速度 v̄ = Δs/Δt，当 Δt → 0 时平均速度的极限就是瞬时速度：v(t) = lim(Δt→0) Δs/Δt。位置函数 s(t) 在 t → t₀ 的极限描述物体「即将到达、无限靠近」的那个位置；只要极限等于 s(t₀)，物体的运动就没有「瞬移」或「停顿错位」。

函数极限的性质

  • 唯一性：若极限存在，则唯一。
  • 局部有界性：若 lim(x→x₀) f(x) = A，则 f(x) 在 x₀ 的某个去心邻域内有界。
  • 局部保号性：若 lim(x→x₀) f(x) = A > 0，则在 x₀ 的某个去心邻域内 f(x) > 0（与 A 同号）。

1.4 无穷小与无穷大

无穷小

定义：若 lim f(x) = 0（自变量按某确定方式变化），则称 f(x) 为该变化过程中的无穷小（无穷小量）。

  • 无穷小是一个「变量/函数」，不是「很小的数」。0.000001 不是无穷小，因为它不「趋向」0。
  • 常数 0 是唯一一个「既是数又是无穷小」的特殊无穷小。
  • 无穷小与极限的关系：lim f(x) = A 的充要条件是 f(x) = A + α(x)，其中 α(x) 是无穷小。即「极限 A = 常数 A + 一个趋向 0 的误差项」。

无穷大

定义：若当 x → x₀（或 x → ∞）时，|f(x)| 无限增大，则称 f(x) 为该过程中的无穷大，记作 lim f(x) = ∞。严格说此时极限不存在（不趋于有限常数），但习惯上记作趋于无穷大。

注意区分「无穷大」与「无界」：无穷大要求从某一阶段起 |f(x)| 一直超过任意给定的正数；无界只是「没有上界」但可能来回振荡（如 x·sin x 无界但不是无穷大）。

无穷小与无穷大的关系

同一变化过程中：
若 f(x) 是无穷大，则 1/f(x) 是无穷小；
若 f(x) 是无穷小且 f(x) ≠ 0，则 1/f(x) 是无穷大。

无穷小的比较

设 α(x)、β(x) 都是同一过程中的无穷小（β ≠ 0）：

  • 若 lim(α/β) = 0，称 α 是比 β 高阶的无穷小（α 更快趋于 0），记 α = o(β)。
  • 若 lim(α/β) = ∞，称 α 是比 β 低阶的无穷小。
  • 若 lim(α/β) = c ≠ 0（常数），称 α 与 β 是同阶无穷小。
  • 若 lim(α/β) = 1，称 α 与 β 是等价无穷小，记 α ~ β。

常用等价无穷小（x → 0 时）：

sin x ~ x          tan x ~ x          arcsin x ~ x
arctan x ~ x       ln(1+x) ~ x        eˣ − 1 ~ x
1 − cos x ~ x²/2   (1+x)ᵅ − 1 ~ αx
几何含义：等价无穷小 α ~ β 表示两者「以相同的速率趋向 0」——比值趋于 1，即它们的图像在原点附近几乎重合、贴在一起（如一阶近似）。高阶无穷小 α = o(β) 表示 α 比 β「消失得更快」，在原点附近 α 相对 β 可忽略不计。整张等价无穷小表，本质上是「这些基本曲线在原点附近与 y = x（或 y = x²/2）相切、可互相替换」。
物理含义：无穷小是微积分「化整为零」的基石：把时间分成无穷小段 Δt → 0、把位移分成无穷小份 Δs → 0，才能在极限下定义瞬时速度。高阶无穷小 = 「比主项更快消失的微小量」——工程中常说「忽略高阶小量」，例如摆角很小时 (sin θ − θ) 是比 θ 高阶的无穷小，于是可用 θ 替代 sin θ 作线性近似。

1.5 极限运算法则

四则运算法则

设 lim f(x) = A，lim g(x) = B，则（自变量同一变化过程）：

lim[f(x) ± g(x)] = A ± B
lim[f(x) · g(x)] = A · B
lim[f(x) / g(x)] = A / B    （要求 B ≠ 0）

推论：常数因子可提到极限号外，lim[c·f(x)] = c·A；lim[f(x)]ⁿ = Aⁿ（n 为正整数）。

复合函数的极限法则

若 lim(x→x₀) g(x) = u₀，且 lim(u→u₀) f(u) = A，则（在适当条件下）

lim(x→x₀) f(g(x)) = A

即「先让内层趋于 u₀，再让外层趋于 A」，可作变量代换 u = g(x) 换元求极限。

夹逼准则（两边夹定理）

若在 x₀ 的某去心邻域内有 g(x) ≤ f(x) ≤ h(x)，且

lim g(x) = lim h(x) = A

则 lim f(x) = A。对数列同理：若 yₙ ≤ xₙ ≤ zₙ 且 yₙ、zₙ 都趋于 a，则 xₙ → a。

单调有界准则

单调有界数列必收敛。具体地：单调增加且有上界的数列必有极限；单调减少且有下界的数列必有极限。这是一个「存在性」定理——它保证极限存在，但不直接给出极限值。

几何含义：夹逼准则的画面是「曲线被两条曲线夹住」：f(x) 的图像被挤在 g(x) 与 h(x) 之间，而 g、h 都收敛到同一条水平线 y = A，于是 f 也必然被「挤」向 y = A。单调有界准则的画面是：一个单调递增、有上界的数列，像在数轴上「一路上升但永远不越过天花板」，它只能无限逼近某个上确界，即极限。
物理含义：夹逼用于估计难以精确计算的量——用「下界序列」和「上界序列」从两侧逼近真实值（如数值方法中的上下界估计）。单调有界对应「单调变化但有饱和/上限的物理过程」：例如逐渐充磁、逐渐充电的电压单调上升但不超过电源电压，故必有极限值；单调增加且受约束的温度必趋于稳态。

1.6 两个重要极限

第一个重要极限

lim(x→0) sin x / x = 1

几何证明思路（单位圆夹逼）：在单位圆中取圆心角 x（0 < x < π/2），比较三块面积：

△OAB 的面积  ≤  扇形 OAB 的面积  ≤  △OAC 的面积
   sin x / 2   ≤      x / 2      ≤    tan x / 2

两边同除以 sin x / 2 得 1 ≤ x/sin x ≤ 1/cos x，取倒数得 cos x ≤ sin x / x ≤ 1。当 x → 0⁺ 时 cos x → 1，由夹逼准则得 sin x / x → 1；x → 0⁻ 时由奇偶对称性同样成立。

推论与变形：

lim(x→0) x / sin x = 1
lim(x→0) tan x / x = 1
lim(x→0) (1 − cos x) / x² = 1/2
几何含义：当圆心角 x 很小时，「弦长 sin x」与「弧长 x」几乎相等（sin x / x → 1），同时「弧长」被夹在弦与正切之间、三者趋于一致。即小角度下弧长 ≈ 弦长 ≈ 对应的正弦，扇形退化为几乎等边的三角形。
物理含义：这是「小角度近似」的严格根基：单摆小幅摆动时 sin θ ≈ θ，把非线性的回复力 mg·sin θ 线性化为 mg·θ，从而得到简谐运动方程。光学近轴近似、测量误差的小角修正都依赖 sin x ≈ x（x 用弧度，且 x 很小）。

第二个重要极限

lim(x→∞) (1 + 1/x)ˣ = e          （等价形式）lim(x→0) (1 + x)^(1/x) = e

这里的 e ≈ 2.718281828… 是无理数、自然对数的底。这个极限可用「单调有界准则」证明存在：数列 (1 + 1/n)ⁿ 单调增加且有上界，故收敛，极限记为 e。

几何/物理含义：第二个重要极限是「连续复利」与「自然增长」的模型。本金 1、年利率 100%，若一年计息 n 次，本利和为 (1 + 1/n)ⁿ；计息次数 n 趋于无穷（每时每刻都在复利）时，本利和趋于 e。任何「按当前存量比例连续增长」的过程（细菌繁殖、放射性衰变、人口增长）都归结为 e 的幂，即指数函数 y = eᵏˣ 的增长率与自身成正比。

1.7 函数的连续性

连续的定义

设函数 f(x) 在 x₀ 的某邻域内有定义。若

lim(x→x₀) f(x) = f(x₀)

则称 f(x) 在点 x₀ 连续。这句话包含三个条件，缺一不可：

  1. f(x₀) 有定义（x₀ 在定义域内）；
  2. lim(x→x₀) f(x) 存在（左右极限存在且相等）；
  3. 极限值 = 函数值：lim(x→x₀) f(x) = f(x₀)。

用「增量语言」表述：设 Δx = x − x₀，Δy = f(x₀ + Δx) − f(x₀)，则 f 在 x₀ 连续等价于 lim(Δx→0) Δy = 0——自变量的微小改变只引起函数值的微小改变。

若 f 在区间 I 内每一点都连续，称 f 在 I 上连续；在区间端点处只要求相应一侧连续（左连续或右连续）。

间断点及其分类

不满足连续三条件之一的点 x₀ 称为间断点：

  • 第一类间断点（左右极限都存在）：
    • 可去间断点：左右极限存在且相等，但不等于 f(x₀)（或 f(x₀) 无定义）。几何上图像只有「一个小洞」，重新定义该点函数值即可「补上」。
    • 跳跃间断点：左右极限都存在但不相等。几何上图像「断成上下两截」，出现一个台阶式跳跃。
  • 第二类间断点（左右极限至少一个不存在）：
    • 无穷间断点：函数趋于 ∞，图像以 x = x₀ 为竖直渐近线（如 y = 1/x 在 x = 0）。
    • 振荡间断点：函数无限快速振荡、极限不存在（如 y = sin(1/x) 在 x = 0）。

连续函数的运算与性质

  • 连续函数的和、差、积、商（分母不为 0）仍连续；复合连续仍连续。
  • 初等函数在其定义区间内处处连续——这给出求极限的基本技巧：求初等函数在某点的极限，往往直接代入即可。
  • 闭区间 [a, b] 上连续函数的性质：
    1. 有界性：f 在 [a, b] 上有界。
    2. 最值定理：f 在 [a, b] 上必取得最大值与最小值。
    3. 介值定理：若 f(a) ≠ f(b)，μ 是介于 f(a) 与 f(b) 之间的任意数，则存在 ξ ∈ (a, b) 使 f(ξ) = μ。
    4. 零点定理（介值定理的特殊情形）：若 f(a)·f(b) < 0（两端异号），则至少存在 ξ ∈ (a, b) 使 f(ξ) = 0。
几何含义：连续 = 图像「一笔画成」——不断开、不跳跃、没有洞，笔不离纸就能画出整条曲线。可去间断 = 一个小洞；跳跃间断 = 台阶；无穷间断 = 竖直渐近线把曲线撕成两半；振荡间断 = 局部无限快速抖动。介值定理的几何画面是：一条连续曲线从 y = f(a) 连到 y = f(b)，它必然穿过介于两者之间的每一条水平线；零点定理即「曲线若一端在 x 轴上方、一端在下方，则必与 x 轴相交」。
物理含义：连续描述物理量「不突变」：位置、温度、电压、浓度随时间连续变化，不会从一个值瞬间跳到一个不相关的值。零点定理给出「解方程 f(x) = 0 有根」的依据，也是二分法求根的理论基础。介值定理说明：连续变化的量从 20℃ 降到 −5℃ 的过程，必然在某个时刻恰好经过 0℃。

典型例题（自测）

  1. 判断下列函数是否有界，并讨论其奇偶性：f(x) = x³ + x，g(x) = x² + cos x。
  2. 用 ε–N 语言证明：lim(n→∞) 1/n = 0。
  3. 求极限：lim(x→2) (x² − 4)/(x − 2)。（提示：分子因式分解约去 (x − 2)。）
  4. 求极限：lim(x→∞) (2x² + 3x − 1)/(x² + 1)。（提示：分子分母同除以 x²。）
  5. 讨论 f(x) = |x|/x 在 x = 0 处的左右极限，并判断极限是否存在。
  6. 利用等价无穷小求 lim(x→0) (1 − cos x)/x²，再利用第一个重要极限验证。
  7. 求 lim(x→∞) (1 + 2/x)ˣ。（提示：变形为第二个重要极限。）
  8. 判断 f(x) = (x² − 1)/(x − 1) 在 x = 1 处是哪种间断点，能否重新定义使之处处连续？
  9. 证明方程 x³ − 4x² + 1 = 0 在区间 (0, 1) 内至少有一个实根。

常见误区

  • ❌ 「无穷小是很小的数」 → ❌ 无穷小是极限为 0 的变量（函数/数列），不是某个固定的小数；0.000001 不趋于 0，不是无穷小。
  • ❌ 「lim(x→x₀) f(x) = f(x₀)」 → ❌ 极限只研究 x 无限接近 x₀ 但不等于 x₀ 的趋势，与 f(x₀) 无关；只有当「极限存在且等于函数值」时才叫连续。
  • ❌ 「无穷大是极限存在」 → ❌ lim f(x) = ∞ 表示 |f(x)| 无限增大，此时极限并不存在（不趋于有限常数），无穷大只是发散的一种记号。
  • ❌ 「有界数列一定收敛」 → ❌ 有界是收敛的必要条件而非充分条件，如 xₙ = (−1)ⁿ 有界但发散。
  • ❌ 「sin x / x → 1 对任何 x 都成立」 → ❌ 只在 x → 0（且用弧度）时成立；x 越大 sin x/x 越小并趋于 0。
  • ❌ 「求极限总是直接代入」 → ❌ 直接代入只对「连续点」成立；若代入出现 0/0、∞/∞ 等未定式，必须先变形（约分、有理化、等价替换、重要极限）。
  • ❌ 「极限运算法则中的商，分母极限为 0 也能拆」 → ❌ 商的极限要求分母极限 B ≠ 0；B = 0 时不能拆开，需另行处理。
  • ❌ 「左右极限都存在，极限就一定存在」 → ❌ 还必须左右极限相等；左右极限不等（跳跃）时极限不存在。

课本外 · 典故与思考

典芝诺悖论："跑得最快的英雄，为什么"永远追不上"一只乌龟"？（点击展开）

先看直觉：阿喀琉斯是希腊神话里跑得最快的英雄。芝诺（埃利亚的芝诺，约公元前 490–前 430 年）却提出：如果乌龟先爬出 10 米，阿喀琉斯以 10 倍的速度追赶，他永远追不上——因为当他跑到乌龟刚才的位置，乌龟又往前爬了一小段；等他再跑到那个新位置，乌龟又爬了一小段……要追的路段无穷多个，怎么能追得上呢？

直觉的陷阱在哪？路段无穷多个，不等于时间无穷多。设乌龟速度是 v，阿喀琉斯速度是 10v：

追上的路程 = 10 + 1 + 0.1 + 0.01 + … = 100/9 ≈ 11.1 米
追上的时间 = 10/(9v)，是有限的

前 10 米、前 1 米、前 0.1 米……每一段用的时间都在飞快地缩短，无穷多段的总和收敛到一个有限数。这正是本章数列极限的画面：1/2 + 1/4 + 1/8 + … → 1，部分和 0.9, 0.99, 0.999, … 步步逼近极限。

几何/物理含义：芝诺的困惑在于把"无限细分"等同于"无限时间"。现实中追及时间由速度差决定，是有限量；无穷多阶段只是把这段有限时间切分成越来越碎的片段——如同把 1 米尺子无限等分，尺子依然是 1 米。直到两千多年后，柯西、魏尔斯特拉斯用极限语言才把"无限逼近"从哲学争辩变成可验证的数学命题。
一句话总结：芝诺悖论是极限思想的第一个"直觉入口"：无穷多个阶段，可以对应有限的总和——极限研究的就是这种"无限过程收敛到有限结果"的规律。
史ε–δ 语言的来历：从"消失量的鬼魂"到魏尔斯特拉斯（点击展开）

先看直觉：牛顿和莱布尼茨发明微积分时，靠的是"无穷小量"——一个"比任何正数都小、却又不是 0"的量。这个量好用极了，但它到底是什么，谁也说不清。英国主教贝克莱（George Berkeley，1734 年在《分析学家》中）嘲讽：这些无穷小是"已消失量的鬼魂"——一个量先要有大小，又必须小到消失，实在自相矛盾。

问题：微积分结果全对，但基础建立在"幽灵"上。怎么把"越来越接近"这种动态的直觉，翻译成一句静态的、可检验的断言？

  • 柯西（1789–1857）：1821 年在《分析教程》中把极限、连续、导数都用"极限语言"重新定义，驱赶了"无穷小实体"，但"趋近"仍带运动色彩。
  • 魏尔斯特拉斯（1815–1897）：19 世纪中叶在柏林大学讲课，给出今天的形式：对任意 ε > 0，存在 δ > 0……——把"趋近"翻译成不等式的大小比较，不含任何"运动"或"无穷小"，数学分析从此"算术化"。
几何含义：ε–δ 的画面是"横带夹逼"：无论你画多窄的水平横带（2ε），我都能在 x₀ 附近划出一个足够小的竖条（2δ），让这竖条里的曲线点全部落进横带。你出题（ε），我应招（δ）——这是一场"可量化的逼近游戏"。
一句话总结：ε–δ 把"越来越近"的直觉变成了"任意给定精度都能保证"的静态断言——今天你写下的每个 |f(x) − A| < ε，都是对"消失量的鬼魂"的百年驱魔成果。
思0.999… 到底等不等于 1？——用本章的 ε–N 语言回答（点击展开）

先看直觉：0.999…（9 循环）看起来比 1"差那么一点点"——9 再多，似乎也差着"一个 0.00…01"。但用本章的数列极限语言，这个直觉需要被修正：

0.999… = lim(n→∞) 0.99…9（n 个 9）

记部分和 sₙ = 0.99…9（n 个 9），则 1 − sₙ = 1/10ⁿ。对任意 ε > 0，取 N 使 1/10ᴺ < ε（即 N > log₁₀(1/ε)），则 n > N 时 |sₙ − 1| = 1/10ⁿ < ε。这正是 ε–N 定义：部分和以 1 为极限。

于是：0.999… 作为数列的极限，精确地等于 1，不是"约等于"、不是"差一点点"。可以换一种写法验证：0.999… = 9/10 + 9/100 + 9/1000 + … = (9/10)/(1 − 1/10) = 1（等比级数求和，第 12 章会系统见到）。

几何含义：把 [0,1] 上的点看成一列逼近：0.9, 0.99, 0.999, … 这些点从左边越来越靠近 1，最终"挤进"1 的任何 ε 邻域。极限值就是这个"挤出无限多步骤之后仍能到达的归宿"——没有理由把它看成另一个略小的数，因为任何略小的数 c < 1 都会被这一列点超过。
一句话总结：0.999… = 1 不是诡辩，而是极限定义的直接结论：数列的极限等于 1，这个极限就是我们书写的 0.999… 本身——"无限个 9"不是停在某个"最后一位"，而是"永不结束地趋近"。

本章练习卷（含答案）

一、练习题

  1. 判断 f(x) = x³ 是奇函数还是偶函数，并说明其图像关于什么对称。
  2. 描述函数 y = 1/x 在 x = 0 附近的图像：当 x → 0 时它是不是无穷大？x = 0 是哪类间断点？
  3. 用「铅垂线检验」说明：单位圆 x² + y² = 1 的整体图像是不是某个函数的图像？为什么？
  4. 解释 lim(x→x₀) f(x) = A 与 f(x₀) 之间的关系：极限存在是否要求 f(x₀) 有定义？连续又需要哪些条件？
  5. 利用单位圆中的面积夹逼说明 lim(x→0) sin x / x = 1，并举一个现实中的「小角度近似」例子。
  6. 用零点定理证明：方程 x³ − 4x² + 1 = 0 在区间 (0, 1) 内至少有一个实根，并说明其几何含义。

二、参考答案（点击展开）

查看第1题答案

f(x) = x³ 是奇函数：因为 f(−x) = (−x)³ = −x³ = −f(x)。其图像关于原点对称。

查看第2题答案

y = 1/x 的图像是双曲线，两支分别位于 x > 0 与 x < 0 两个区域。当 x → 0 时 |1/x| 无限增大，故它是无穷大（此时极限不存在，是发散的一种记号）。x = 0 是第二类间断点中的无穷间断点，直线 x = 0 是竖直渐近线。

查看第3题答案

不是。铅垂线检验要求任一条竖直直线与图像至多交于一点；而圆的方程 x² + y² = 1 中，对任意 |x| < 1，竖直线 x = c 与圆交于上下两点（y = ±√(1 − c²)），违反「一个 x 只对应唯一 y」，故整体圆不是函数图像。若只取上半圆 y = √(1 − x²) 或下半圆 y = −√(1 − x²)，则各自都是函数图像。

查看第4题答案

lim(x→x₀) f(x) = A 研究的是 x 无限接近但不等于 x₀ 时 f(x) 的趋势，所以不要求 f(x₀) 有定义，也与 f(x₀) 的取值无关。而 f 在 x₀ 连续需要三个条件同时满足：① f(x₀) 有定义；② lim(x→x₀) f(x) 存在；③ 极限值 = f(x₀)。

查看第5题答案

在单位圆中取圆心角 x（0 < x < π/2），比较三角形与扇形面积得 sin x ≤ x ≤ tan x，整理后夹逼得 cos x ≤ sin x / x ≤ 1；x → 0⁺ 时 cos x → 1，故 sin x / x → 1（x → 0⁻ 时由奇偶性同样成立）。现实例子：单摆小幅摆动时 sin θ ≈ θ，把非线性的回复力 mg·sin θ 线性化为 mg·θ，从而得到简谐运动。

查看第6题答案

令 f(x) = x³ − 4x² + 1，则 f(0) = 1 > 0，f(1) = 1 − 4 + 1 = −2 < 0，两端异号；f 是多项式，在闭区间 [0, 1] 上连续，由零点定理，至少存在 ξ ∈ (0, 1) 使 f(ξ) = 0。几何含义：连续曲线在 x = 0 处位于 x 轴上方、在 x = 1 处位于 x 轴下方，中间必然与 x 轴相交。
