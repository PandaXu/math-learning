第2章 谓词逻辑

大学 / 离散数学

一句话总纲：谓词逻辑 = 用「谓词 + 量词」把对象、属性与对象间的关系形式化。它从命题逻辑的"整句真假"迈进到"谁、有什么性质、彼此什么关系"——学完本章，你要能在心里"看见"论域上的一块块区域：全称量词 ∀ 是"整块区域被填满"，存在量词 ∃ 是"区域内至少有一个点"。

2.1 谓词与量词

命题逻辑的局限：为什么需要谓词逻辑？

命题逻辑把每个陈述句当作一个不可再分的原子命题，只关心它的真假，不关心"谁"在里面、对象之间"什么关系"。于是经典三段论——

所有人都会死。        （前提 1）
苏格拉底是人。        （前提 2）
所以，苏格拉底会死。  （结论）

——在命题逻辑里只能写成 P, Q ⇒ R，看不出 P、Q、R 内部有任何联系，因而无法由 P、Q 的"结构"推出 R。谓词逻辑把句子拆成个体词 + 谓词 + 量词，让"会死"这种性质、"是人"这种属性在对象之间流通，推理才成为可能。

核心直觉：命题逻辑像"只给整句话盖章（真/假）"，谓词逻辑像"把句子拆成零件（主语、谓语、定语）再组装"，因此能表达"所有""存在""每一个对象都……"这类关于无穷多个对象的一句话。

个体词与个体域（论域）

  • 个体词：指代"对象"的词，是句子的主语。分两类：
    • 个体常元（用小写 a, b, c, … 或 s 表示）：确定的对象，如"苏格拉底""2""地球"。
    • 个体变元（用小写 x, y, z, … 表示）：取值范围待定的对象，如"任意一个人""某个数"。
  • 个体域（论域）：个体变元取值的全体对象集合，记作 D。例如"人""实数""自然数"都可以作为论域。论域不同，同一句话的真假可能完全不同。
几何含义：论域 D 就是一张"背景画布"（一条数轴、一个平面、乃至整个空间）。每个个体是画布上的一个点，个体常元是"被固定钉住的那个点"，个体变元是"可以在画布上滑动、尚未落点的游标"。

谓词：对象的性质与对象间的关系

谓词是"说什么"的部分，用来刻画个体的性质或个体之间的关系。含 n 个个体变元的谓词叫 n 元谓词，记作 P(x₁, x₂, …, xₙ)，其中 P 是谓词符号。注意：单独的 P(x₁,…,xₙ) 只是"命题函数"，还不是命题，因为变元尚未确定，它没有确定的真假值。

类别含义例子
0 元谓词不含变元，退化为命题"雪是白的"
一元谓词个体的性质（属性）F(x)：x 是人；M(x)：x 是偶数
二元谓词两个个体间的关系G(x,y)：x 大于 y；L(x,y)：x 爱 y
n 元谓词 (n≥2)多个个体间的关系Add(x,y,z)：x + y = z
几何含义（一元谓词 = 一块区域）：一元谓词 P(x) 在论域 D 上划出一块子集（区域）：P = { x ∈ D | P(x) 为真 }。说"x 满足 P"，就是说点 x 落在这块区域里。例如论域为全体实数、P(x) 表示 "x > 0"，则 P 对应数轴上原点的右侧半条直线。
几何含义（二元谓词 = 平面上的图形）：二元谓词 R(x,y) 是笛卡尔积 D×D 的一个子集，即坐标平面 xOy 上的一块图形。例如论域为实数、R(x,y) 表示 "x < y"，则 R 对应直线 y = x 上方的半平面（满足 y > x 的所有点）。
物理含义：一元谓词是"可检测的属性/状态"——"带电""导电""是金属""在运动"，就像给每个样本做一次实验，结果要么"是"要么"否"。二元谓词是"两体之间的相互作用或约束"——"大于""相吸""碰撞""A 传给 B 能量"，物理定律几乎都是"若 A 与 B 满足某关系，则……"。

量词：全称量词 ∀ 与存在量词 ∃

要让命题函数变成有确定真假的命题，有两种办法：代入具体个体（如 F(s)："苏格拉底是人"），或用量词约束变元。量词只有两个，却刻画了"关于全体对象的断言"的全部基本形式：

  • 全称量词 ∀（读"对任意""对一切""对所有"）：∀x P(x) 表示"对论域中的每一个 x，P(x) 都成立"。
  • 存在量词 ∃（读"存在""至少有一个"）：∃x P(x) 表示"论域中至少存在一个 x，使 P(x) 成立"。

例如论域为人类：∀x (M(x) → D(x)) 说"所有人都会死"；∃x (M(x) ∧ F(x))（F = 是哲学家）说"存在一个人是哲学家"。

几何含义：在"论域画布"上，∀x P(x) 说 P 的区域 覆盖了整个画布（P = D，区域外一个点都没有）；∃x P(x) 说 P 的区域 非空（至少有一个点落在区域里）。于是量词把"全称/存在"翻译成了最直观的"区域是否填满 / 区域是否有点"。
物理含义：∀ 对应普适定律——"对一切惯性系光速不变""对所有物体 F = ma"，这类断言要在一个字面上无穷大的样本空间上成立；∃ 对应存在性结论——"方程至少有一个解""存在这样一条路径""存在一个临界温度"，物理与数学中大量定理的目标正是证明"存在"某物。

2.2 谓词公式

合式公式（wff）的递归定义

谓词逻辑的合法表达式由以下规则递归生成（A、B 均指公式）：

1. 原子公式：P(x₁,…,xₙ) 是公式（P 是 n 元谓词，xᵢ 是个体变元或常元）。
2. 若 A、B 是公式，则 ¬A、(A∧B)、(A∨B)、(A→B)、(A↔B) 都是公式。
3. 若 A 是公式、x 是变元，则 ∀xA、∃xA 都是公式。
4. 只有经有限次使用规则 1–3 得到的符号串才是公式。

谓词公式中联结词的优先级约定与命题逻辑一致：¬ 最高，其次 ∧、∨，再是 →、↔；量词 ∀、∃ 的辖域尽量取"紧跟在后的最小公式"。

辖域、约束变元与自由变元

  • 在 ∀xA 或 ∃xA 中，量词后面的变元 x 叫指导变元，公式 A 叫该量词的辖域（作用域）。
  • 变元 x 在辖域 A 内、且与指导变元同名的一切出现，都叫约束出现（被量词"管住"）；不处于任何量词辖域内、或与指导变元不同名的出现，叫自由出现。
  • 在公式中自由出现过的变元叫自由变元，约束出现过的变元叫约束变元。一个变元可以既是自由的又是约束的（出现在不同位置）。
  • 闭式（句子）：没有自由变元的公式，它是一个有确定真假的命题；含自由变元的公式仍是命题函数。
例：∀x(P(x) → ∃y Q(x,y))
    x 在 P(x)、Q(x,y) 中的出现是约束出现；
    y 在 Q(x,y) 中的出现是约束出现；
    该公式无自由变元，是闭式。
几何含义：约束变元是被量词"圈定在辖域内"的哑变量/占位符，改个名字不影响含义（如同 ∫₀¹ x² dx 里的 x 与 ∫₀¹ t² dt 里的 t 完全等价）；自由变元则是"尚未被圈定、等待取值"的活动游标，它的位置决定了公式是否已成为命题。

约束变元的改名（换名）

为避免"同一个字母"既自由又约束、或不同量词互相干扰，可把约束变元及其辖域内的同名出现整体替换成新变元，只要不改变"哪个出现归哪个量词管"。改名后公式与原公式等值。

∀x(P(x) ∨ Q(y))  ⇔  ∀z(P(z) ∨ Q(y))   （把约束的 x 换成 z）
注意：自由出现的 y 不能跟着改。

2.3 等值式与前束范式

量词的否定（德摩根律的推广）

命题逻辑中 ¬(A∧B) ⇔ ¬A∨¬B 在"全体对象"上推广，得到最常用的两个等值式：

¬∀x P(x)  ⇔  ∃x ¬P(x)      "不是所有 x 都满足 P"  = "存在某个 x 不满足 P"
¬∃x P(x)  ⇔  ∀x ¬P(x)      "不存在满足 P 的 x"    = "所有 x 都不满足 P"
几何含义：这就是补集的直觉。说"不是整块画布都在区域 P 里"，等价于说"画布上至少有一个点在 P 的补集 ¬P 里"；说"区域 P 里一个点都没有"，等价于说"所有点都落在 P 的补集里"。量词否定 = 把"区域"和"区域外"互换。
物理含义："不是所有粒子都带电" = "存在（至少一个）不带电的粒子"；"不存在违反能量守恒的过程" = "一切过程都遵守能量守恒"。物理中的"反例思维"（想否定一条全称定律，只需找出一个反例）正是 ¬∀xP(x) ⇔ ∃x¬P(x)。

量词与联结词的分配

∀x(A(x) ∧ B(x))  ⇔  ∀xA(x) ∧ ∀xB(x)     （∀ 对 ∧ 可分配）
∃x(A(x) ∨ B(x))  ⇔  ∃xA(x) ∨ ∃xB(x)     （∃ 对 ∨ 可分配）

但以下只是"蕴含"，不是等值：
∀xA(x) ∨ ∀xB(x)  ⇒  ∀x(A(x) ∨ B(x))     （反过来不成立）
∃x(A(x) ∧ B(x))  ⇒  ∃xA(x) ∧ ∃xB(x)     （反过来不成立）
几何含义：∀ 对 ∧ 可分配：说"每个点既在区域 A 又在区域 B"，等于"区域 A 盖满画布，且区域 B 也盖满画布"。∃ 对 ∨ 可分配：说"有一个点落在 A 或 B"，等于"A 里有点，或 B 里有点"。反过来不成立的原因很直观：∀xA(x) ∨ ∀xB(x) 要求"整块画布全在 A"或"整块全在 B"（一刀切），而 ∀x(A(x)∨B(x)) 允许"画布一半归 A、一半归 B"（拼图也能盖满），后者更弱。

多重量词：顺序至关重要

∀x∀y P(x,y)  ⇔  ∀y∀x P(x,y)     （同号全称可交换）
∃x∃y P(x,y)  ⇔  ∃y∃x P(x,y)     （同号存在可交换）

但  ∀x∃y P(x,y)   与   ∃y∀x P(x,y)   不等值！
   ∀x∃y：每个 x 都有自己的 y（y 可以随 x 变化）
   ∃y∀x：存在同一个 y，对一切 x 都成立
几何/物理含义：∀x∃y P(x,y) 好比"每个人都有一个母亲"（母亲因人而异）；∃y∀x P(x,y) 好比"存在一个人，是所有人的母亲"。前者弱、几乎总成立，后者强、几乎总不成立。物理中 ∀x∃y 是"对每个时刻都存在一个速度"（速度可随时变化），∃y∀x 是"存在一个速度对所有时刻都成立"（匀速），二者物理图景完全不同。

前束范式（Prenex Normal Form）

定义：若一个谓词公式形如

Q₁x₁ Q₂x₂ … Qₙxₙ  A      （其中每个 Qᵢ ∈ {∀, ∃}，A 不含量词）

即"一串量词打头 + 一个不含量词的核心公式"，则称它处于前束范式，Q₁x₁…Qₙxₙ 叫前束词，A 叫母式。

求前束范式的四步：

  1. 消去 → 和 ↔：用 A→B ⇔ ¬A∨B、A↔B ⇔ (A→B)∧(B→A) 化为只含 ¬、∧、∨。
  2. ¬ 内移：用德摩根律和量词否定式，把 ¬ 压到原子公式前面。
  3. 约束变元改名：让不同量词的指导变元互不重名、且不与自由变元重名，避免"捕获"。
  4. 量词前移：利用辖域扩张把量词依次提到公式最前面。
例：把 ¬∀xP(x) → ∃xQ(x) 化为前束范式。
① 消 →：  ¬¬∀xP(x) ∨ ∃xQ(x)    即  ∀xP(x) ∨ ∃xQ(x)
② 无 ¬ 需再内移。
③ 改名避免冲突： ∀xP(x) ∨ ∃yQ(y)
④ 量词前移：  ∀x∃y (P(x) ∨ Q(y))
几何含义：前束范式把公式"拉直"成一条清晰的量词链，让"哪些点被全体扫过、哪些点被存在扫过"一目了然，便于在"画布"上逐层圈定区域。它就像把一条曲折的路径拍平成一张剖面图：先看最外层 ∀ 圈住整块画布，再看内层 ∃ 在每处打一个点。

2.4 推理理论

四条基本推理规则（量词规则）

命题逻辑的推理规则（假言推理 MP、拒取式 MT、合取、化简等）在谓词逻辑中照用，另需四条量词规则来"摘掉/加上"量词：

规则名称形式要点
UI / US全称例化（全称指定）∀xP(x) ⇒ P(c)c 是论域中任意个体常元
EI / ES存在例化（存在指定）∃xP(x) ⇒ P(c)c 必须是从未出现过的新常元
UG全称推广P(c) ⇒ ∀xP(x)c 必须任意（非特定、非由 EI 引入）
EG存在推广P(c) ⇒ ∃xP(x)由具体个体"推回"存在
几何含义：UI 是"从'整块画布都被 P 覆盖'里，任取一个点 c，它也一定在 P 里"。EG 是"我已经找到了一个落在 P 里的点 c，所以区域 P 非空"。EI 之所以要求新常元，是只承诺"有这么个点"却不说具体是谁——就像证明"存在一个解"却不必把这个解点名。
物理含义：UI = 把普适定律套到具体对象上（"F=ma 对一切物体成立" → "对这个滑块也成立"）；EI = 由"存在某物"姑且命名为 c 继续推导，但 c 代表"那个神秘的未知对象"，不能假设它还有别的身份；EG = 从"这个具体解"升华到"解存在"，正是存在性定理的收尾动作。

经典例题：三段论的严格推导

前提 1：∀x (M(x) → D(x))      （所有人都会死；M=是人，D=会死）
前提 2：M(s)                  （苏格拉底是人；s=苏格拉底）
结论：  D(s)                  （苏格拉底会死）

推导：
① ∀x(M(x)→D(x))        前提 1
② M(s) → D(s)          ① 用 UI（取 c = s）
③ M(s)                 前提 2
④ D(s)                 ②③ 假言推理 MP
为什么能推出：UI 把"所有 x"落到了具体的人 s 身上，于是全称命题"瘦身"成关于 s 的条件句，再用 MP 即可。整个过程把"无穷多个对象的一句话"收束到一个对象上完成。

含存在量词的推理

前提：∃x (P(x) ∧ Q(x))
结论：∃x P(x) ∧ ∃x Q(x)

推导：
① ∃x(P(x)∧Q(x))        前提
② P(c) ∧ Q(c)          ① 用 EI（c 为新常元）
③ P(c)                 ② 化简
④ Q(c)                 ② 化简
⑤ ∃xP(x)               ③ EG
⑥ ∃xQ(x)               ④ EG
⑦ ∃xP(x) ∧ ∃xQ(x)      ⑤⑥ 合取

注意顺序陷阱：EI 引入的新常元 c 必须"新"，且若同一证明中要先用 UI 再用 EI，应先做 EI（否则 UI 用到的常元可能与 EI 冲突，导致错误结论）。

推理理论小结

  • 消去量词（UI、EI）→ 用命题逻辑规则推 → 再加上量词（UG、EG），是谓词逻辑证明的标准三段式。
  • UI 与 EG 最安全、几乎无限制；EI 要求新常元；UG 要求变元任意，是出错高发区。
  • 前提集合 Γ 推出结论 C 记作 Γ ⇒ C（语义上即 Γ ⊨ C），一个证明序列就是从 Γ 到 C 的合法规则链。

典型例题（自测）

例题

  1. 设论域为全体实数。判断下列命题真假并说明：∀x(x² ≥ 0)；∃x(x² < 0)；∀x∃y(x + y = 0)；∃y∀x(x + y = 0)。
  2. 写出 ¬∀x∃y(x < y) 的等价式（把 ¬ 内移到原子公式）。
  3. 把 ∀xP(x) → ∃xQ(x) 化为前束范式。
  4. 判断 ∀x(P(x)∨Q(x)) 是否等值于 ∀xP(x) ∨ ∀xQ(x)，给出反例说明。
  5. 用推理规则证明：由 ∀x(P(x) → Q(x)) 与 P(a) 推出 Q(a)。

常见误区

小心这些坑

  • ❌ 把「量词辖域」看错 → 例：∀xP(x) ∧ Q(x) 中 Q(x) 的 x 是自由的，∀ 只管 P(x)；要管住两者须加括号 ∀x(P(x)∧Q(x))。
  • ❌ 认为 ¬∀xP(x) ⇔ ∀x¬P(x) → ❌ 应是 ∃x¬P(x)：否定"全称"变"存在"，量词和谓词都要翻。
  • ❌ 认为 ∀ 对 ∨、∃ 对 ∧ 可任意分配 → ❌ 只有蕴含方向成立，等值不成立（"整块同色" ≠ "每点都在 A 或 B"）。
  • ❌ 认为 ∀x∃y P(x,y) 与 ∃y∀x P(x,y) 等值 → ❌ 量词顺序改变语义（"每人有母亲" ≠ "存在众人之母"）。
  • ❌ 用 EI 引入的常元再套 UG 全称推广 → ❌ 由"存在某个 c"不能推广到"所有 x"。
  • ❌ EI 用了已出现过的常元 → ❌ 会偷换对象身份，导致错误结论。

本章练习卷（含答案）

一、练习题

  1. （判断题·入门）设论域为全体实数。判断 ∀x(x² ≥ 0) 与 ∃x(x² < 0) 的真假，并各用一句"区域/画布"的几何含义解释。
  2. （符号化）用谓词 M(x)=“x 是金属”、C(x)=“x 导电”，把“所有金属都导电”形式化；并说明为什么写成 ∀x(M(x) ∧ C(x)) 是错的（提示：那会断言"一切 x 都是金属"）。
  3. （量词否定）写出 ¬∀xP(x) 与 ¬∃xP(x) 的等值式，把 ¬ 内移到原子公式前；并用"反例思维"解释第一条的物理含义。
  4. （分配律判断）判断哪一组等值成立、哪一组不成立，并各说明理由（不成立的给出反例）：(1) ∀x(A(x)∧B(x)) 与 ∀xA(x) ∧ ∀xB(x)；(2) ∀x(A(x)∨B(x)) 与 ∀xA(x) ∨ ∀xB(x)。
  5. （多重量词顺序）设论域为全体实数，P(x,y) 表示 "x + y = 0"。判断 ∀x∃y P(x,y) 与 ∃y∀x P(x,y) 的真假，并指出哪个对应"每个 x 都有自己的 y"、哪个对应"存在同一个 y 对一切 x 成立"。
  6. （综合：前束范式＋推理）(a) 把 ¬∀xP(x) → ∃xQ(x) 化为前束范式；(b) 用推理规则（UI、MP）证明：由前提 ∀x(M(x) → D(x)) 与 M(s) 推出 D(s)。

二、参考答案（点击展开）

查看第1题答案

∀x(x²≥0) 为真：平方值落在非负半轴上，"非负"这块区域覆盖了整条数轴画布；∃x(x²<0) 为假："平方为负"这块区域里一个点都没有（空集）。所以 ∀ 真、∃ 假。

查看第2题答案

∀x(M(x) → C(x))。写成 ∀x(M(x)∧C(x)) 会读成"所有 x 都既是金属又导电"，连桌子、空气也被断言成金属，明显错误。通则：全称量词后接条件式（→），存在量词后接合取式（∧）。

查看第3题答案

¬∀xP(x) ⇔ ∃x¬P(x)；¬∃xP(x) ⇔ ∀x¬P(x)。物理含义：要否定"所有粒子都带电"这类全称定律，只需找出一个不带电的反例（∃x¬P(x)），这正是"反例思维"。

查看第4题答案

(1) 成立：∀ 对 ∧ 可分配，"每个点既在 A 又在 B" ⇔ "A 盖满且 B 盖满"。(2) 不成立：∀x(A(x)∨B(x)) 只要求每个点落在 A 或 B 之一，可"一半归 A、一半归 B"拼满画布；而 ∀xA(x)∨∀xB(x) 要求"整块全在 A"或"整块全在 B"（一刀切）。反例：论域为全体实数，A(x):"x ≥ 0"，B(x):"x < 0"，则 ∀x(A(x)∨B(x)) 真（每个数要么非负要么负），但 ∀xA(x) 假、∀xB(x) 也假，故右边为假。

查看第5题答案

∀x∃y(x+y=0) 为真：对任意实数 x，取 y = -x 即可，y 随 x 变化（"每个 x 都有自己的 y"）。∃y∀x(x+y=0) 为假：若存在同一个 y 使一切 x 都有 x+y=0，则 y = -x 须对一切 x 同时成立，这要求 y 同时等于所有数的相反数，不可能。

查看第6题答案

(a) ¬∀xP(x) → ∃xQ(x) ⇔ ¬¬∀xP(x) ∨ ∃xQ(x) ⇔ ∀xP(x) ∨ ∃xQ(x)；改名避免冲突得 ∀xP(x) ∨ ∃yQ(y)，量词前移得 ∀x∃y(P(x) ∨ Q(y))。(b) ① ∀x(M(x)→D(x)) 前提；② M(s)→D(s) 由①用 UI；③ M(s) 前提；④ D(s) 由②③用 MP。
