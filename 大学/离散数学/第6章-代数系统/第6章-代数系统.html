第6章 代数系统

大学 / 离散数学

一句话总纲：代数系统 = 「集合 + 运算」。群刻画对称，环刻画加减乘，域刻画四则运算，格刻画上下确界，布尔代数刻画逻辑与集合。学完本章，你要能把"运算"本身当成一个对象来研究——看见一个集合，先问：上面定义了哪些运算？满足哪些律？这些运算背后藏着怎样的对称与结构？

6.1 代数系统与二元运算

什么是二元运算？

二元运算：设 S 是非空集合，从 S×S 到 S 的映射 f 称为 S 上的二元运算。也就是说，任取 a, b ∈ S，运算结果 f(a, b) 仍然落在 S 里——这叫做封闭性（closure）。

记法：把 f(a, b) 写作 a * b、a + b、a × b、a ∘ b 等。"*"只是一个占位符号，代表"某种规则"，不一定是乘法。

反例辨析：普通减法在自然数 N 上不封闭（2 − 3 = −1 ∉ N），但在整数 Z 上封闭；普通除法在整数上不封闭（1 ÷ 2 ∉ Z），但在非零有理数上封闭。封闭性是"这套运算能不能一直算下去"的第一道门槛。

代数系统（代数结构）

代数系统：非空集合 S 连同其上若干运算组成的整体，记作 (S, *₁, *₂, …)。例如 (Z, +, ×) 是整数加法乘法系统，(P(S), ∪, ∩) 是集合的并交系统。

研究代数系统，本质是回答三个问题：

  1. 有哪些运算？（几元运算、封闭不封闭）
  2. 满足哪些运算律？（结合、交换、分配、幂等、吸收……）
  3. 存在哪些特殊元素？（幺元、零元、逆元）
几何/物理含义：代数系统是把"运算"当成一个整体对象来研究的框架。就像几何把"点、线、变换"抽象出来一样，代数系统把"数、集合、函数、矩阵、对称操作"上共同的运算规律抽象成同一种语言。一旦证明一个定理对"所有群"成立，它就同时适用于整数加法、矩阵乘法、魔方旋转——这是数学的一次"化归与统一"。

运算律

运算律表达式直观含义
结合律(a*b)*c = a*(b*c)先算哪一步结果都一样，括号可省略
交换律a*b = b*a两个操作数的顺序可交换
分配律a*(b∘c) = (a*b)∘(a*c)"乘"能"拆开"到"加"的每一项
幂等律a*a = a重复运算一次不改变结果（∪、∩、∨、∧）
吸收律a*(a∘b) = a一个运算能"吞掉"另一个运算

关键辨析：结合律 ≠ 交换律。矩阵乘法满足结合律但不满足交换律：(AB)C = A(BC) 恒成立，但一般 AB ≠ BA。这说明"运算顺序"与"操作数顺序"是两件独立的事。

特殊元素：幺元、零元、逆元

  • 幺元（单位元）e：对任意 a，有 e*a = a*e = a。如加法中的 0（a+0 = a）、乘法中的 1、矩阵乘法中的单位阵 I、集合并运算中的 ∅（A∪∅ = A）。
  • 零元θ：对任意 a，有 θ*a = a*θ = θ。如乘法中的 0（0×a = 0）、集合交运算中的 ∅（A∩∅ = ∅）。注意：加法的幺元 0 恰是乘法的零元，同一个元素在不同运算里身份不同。
  • 逆元：若 a*b = b*a = e，则 b 是 a 的逆元，记 a⁻¹。如加法中 a 的逆元是 −a，乘法中 a（≠0）的逆元是 1/a。
物理含义：幺元 = "什么都不做的操作"（恒等变换、加 0、乘 1、空操作）；逆元 = "撤销操作"（前进的反向是后退，旋转 90° 的逆是旋转 −90°）。一组操作若能"做"也能"撤销"，就逼近了群的雏形。

同态与同构（简要）

设 (A, *) 与 (B, ∘) 是两个代数系统，映射 φ : A → B 若满足 φ(a*b) = φ(a)∘φ(b)，则称 φ 为同态；若 φ 还是双射，则称同构。同构的两个系统"结构完全相同"，只是换了符号。例如 (R⁺, ×) 与 (R, +) 通过对数/指数 φ(x) = ln x 建立同构：ln(x·y) = ln x + ln y——乘法被"翻译"成了加法。

6.2 群：对称性的数学

从半群到群：四个条件的层层递进

结构满足条件例
半群封闭 + 结合律(N, +)，(Z, ×)
幺半群（独异点）半群 + 存在幺元(N, +) 幺元 0；(Z, ×) 幺元 1
群幺半群 + 每个元素有逆元(Z, +)，(Q∖{0}, ×)
阿贝尔群（交换群）群 + 交换律(Z, +)，(R, +)，模 n 加法群

群的定义

代数系统 (G, *) 称为群，如果满足四条：

① 封闭性：∀a, b ∈ G，有 a * b ∈ G
② 结合律：∀a, b, c ∈ G，(a*b)*c = a*(b*c)
③ 幺元：  ∃e ∈ G，∀a，e*a = a*e = a
④ 逆元：  ∀a ∈ G，∃a⁻¹ ∈ G，使 a*a⁻¹ = a⁻¹*a = e

若再满足 a*b = b*a，称为交换群（阿贝尔群，Abel 群）。

群的经典例子

  • (Z, +) 整数加法群：幺元 0，a 的逆元是 −a。这是最"朴素"的无限阿贝尔群。
  • (Q∖{0}, ×) 非零有理数乘法群：幺元 1，a 的逆元是 1/a。
  • (Zn, ⊕) 模 n 加法群：元素为 {0, 1, …, n−1}，运算 a ⊕ b = (a+b) mod n。例如 Z₄ 中 3 ⊕ 2 = 5 mod 4 = 1。
  • (Sn, ∘) n 个元素的置换群：元素是 n 个对象的排列置换，运算为置换的复合。它是有限群的"母版"——凯莱定理指出：任何有限群都同构于某个置换群的子群。
几何含义（本章的灵魂）：群就是"对称"的抽象定义。一个图形的对称变换，指"搬动图形后与原位置重合"的操作（旋转、翻转、镜像）。所有这些对称变换在"复合"运算下构成一个群——因为恒等变换是幺元、每个变换都有逆变换（能转过去就能转回来）、复合满足结合律。

例：正三角形的对称群含 6 个元素——恒等 e、旋转 120° 记 r、旋转 240° 记 r²、绕三条对称轴翻转记 f, fr, fr²。它记作二面体群 D₃，阶为 6。正方形有 8 个对称，D₄ 阶为 8。研究"一个图形有多对称"，等价于研究"它的对称群的阶有多大"。
物理含义：群在物理中是对称性与守恒律的语言。诺特定理（Noether's theorem）说：每个连续对称都对应一条守恒定律——时间平移对称 → 能量守恒；空间平移对称 → 动量守恒；旋转对称 → 角动量守恒。现代粒子物理用规范群描述基本力：电磁力对应 U(1)，弱力 SU(2)，强力 SU(3)。晶体的空间群决定晶格结构，魔方、鲁比克群、密码学（如 RSA 依赖群/环结构）都是群的应用。

子群、循环群、阶与拉格朗日定理

  • 子群：群 G 的非空子集 H 若在 G 的运算下也构成群，则 H 是 G 的子群。判定：H 对运算封闭、对取逆封闭，且含幺元。例：偶数集 2Z 是 (Z, +) 的子群。
  • 循环群：由一个元素 g 反复运算生成，记 ⟨g⟩ = {…, g⁻², g⁻¹, e, g, g², …}。例：(Z, +) = ⟨1⟩ 由 1 生成；Z₄ = ⟨1⟩（1, 1⊕1=2, 2⊕1=3, 3⊕1=0）。
  • 元素的阶：使 aⁿ = e 成立的最小正整数 n；若不存在则称无限阶。例：Z₄ 中元素 2 的阶为 2（2⊕2 = 0），元素 1 的阶为 4。
  • 群的阶：群的元素个数，记 |G|。
  • 拉格朗日定理：有限群 G 的任意子群 H 的阶 |H| 整除 |G|；进一步，任意元素的阶也整除 |G|。
几何含义：子群对应"对称的一部分"——正三角形的旋转群 C₃ = {e, r, r²} 是 D₃ 的子群（只保留旋转、丢掉翻转）。循环群对应"一个生成旋转反复作用"——像钟表指针：旋转 360°/n 的变换反复做 n 次回到原位，Zₙ 正是 n 等分的旋转群。拉格朗日定理的几何解释：对称的总数必是任何"对称子集"数量的整数倍，因为整个图形被均匀分成若干等价的部分。

6.3 环：可加减乘的数系

环的定义

代数系统 (R, +, ×) 称为环，如果满足：

① (R, +) 是阿贝尔群（加法：封闭、结合、交换、有幺元 0、有逆元）
② (R, ×) 是半群（乘法：封闭、结合）
③ 乘法对加法满足分配律：
   a×(b+c) = a×b + a×c      (左分配)
   (b+c)×a = b×a + c×a      (右分配)

直观理解：环是"能自由做加减、能结合地做乘，但不保证能除、不保证乘法交换"的结构。加法的幺元记 0（零元），乘法若交换则称交换环，乘法若有幺元 1 则称含幺环。

几何/物理含义：环的加法是"平移"（阿贝尔群），乘法是"缩放/旋转"（半群），分配律把两者绑在一起——先缩放再平移 = 先平移再缩放。这正是线性变换的核心：k(x + y) = kx + ky。矩阵环 Mₙ(R) 之所以是环，就因为"矩阵的线性变换"天然满足这三条。

零因子与整环

零因子：在环中，若 a ≠ 0 且 b ≠ 0，但 a×b = 0，则称 a、b 为零因子。有零因子的环里，"两个非零元素相乘得零"——这违反了熟悉的"数"的直觉。

  • 整环：交换含幺环 + 无零因子。即 a×b = 0 必推出 a = 0 或 b = 0。
  • 除环（体）：含幺环 + 每个非零元都有乘法逆元。除环不要求乘法交换（如四元数 H 是除环但非交换）。

环的经典例子

环交换？含幺？特点
(Z, +, ×) 整数环交换、含幺整环；2, −3 等不可"除"
多项式环 Z[x]交换、含幺整环；元素是整系数多项式
模 n 环 Zn交换、含幺n 为素数时是域；n 合数时有零因子
矩阵环 Mn(R)非交换、含幺有零因子；幺元是单位阵 I

零因子实例：在 Z₆ 中，2 × 3 = 6 ≡ 0 (mod 6)，但 2 ≠ 0、3 ≠ 0，所以 2 和 3 是 Z₆ 的零因子。在矩阵环中，A = [[0,1],[0,0]] 满足 A² = 0 但 A ≠ 0——矩阵是"零因子"的典型来源。

物理含义：多项式环是"函数/曲线的代数化"——两个多项式相加、相乘仍得多项式，对应信号与系统里的卷积与滤波（多项式系数相乘正是卷积系数）。矩阵环对应线性映射；矩阵乘法非交换对应"先旋转再拉伸 ≠ 先拉伸再旋转"的物理事实。零因子在物理中对应"非零操作的复合结果为零"——例如两个非零的投影算符相乘可能得零（投影到互相垂直的子空间）。

6.4 域：可四则运算的数系

域的定义

代数系统 (F, +, ×) 称为域，如果：

① (F, +) 是阿贝尔群，加法幺元记 0
② (F∖{0}, ×) 是阿贝尔群，乘法幺元记 1
③ 乘法对加法满足分配律

也就是说，域是"加、减、乘、除（除数非零）四种运算都封闭"的数系。域必然是交换含幺环，且每个非零元都有乘法逆元——所以域 = 交换除环。域里没有零因子：若 a×b = 0 且 a ≠ 0，两边乘 a⁻¹ 得 b = 0。

几何含义：域是"坐标系能够自由缩放的代数基础"。在域上，可以定义向量空间、线性代数、解析几何——因为坐标可以任意做除法（伸缩），直线、平面、内积、行列式都有意义。实数域 R 张成数轴（一维空间）；复数域 C 张成复平面（二维空间）——复数乘法 (a+bi)(c+di) 对应"旋转 + 缩放"：乘以 i 就是逆时针旋转 90°，乘以 e^{iθ} 就是旋转 θ 角。这正是"域的结构决定了空间能做哪些几何操作"。

域的例子与有限域

  • Q、R、C：有理数域、实数域、复数域，是无限域。它们的关系 Q ⊂ R ⊂ C 是域的扩张链。
  • 有限域 GF(p)：p 为素数时，模 p 环 Zp = {0, 1, …, p−1} 是域。例如 GF(5) 中 3 × 2 = 6 ≡ 1 (mod 5)，所以 3 的乘法逆元是 2。而 Z₆ 不是域（2、3 是零因子）。
  • GF(pⁿ)：元素个数为素数幂 pⁿ 的有限域（伽罗瓦域），是构造纠错码与密码的基础。
物理含义：域是现代信息技术的隐形地基。① 纠错码：二维码（QR 码）、CD/DVD、深空通信都依赖 GF(2⁸) 上的里德-所罗门（Reed–Solomon）码，在数据被划伤、沾污时仍能还原。② 密码学：AES 加密算法把字节看成 GF(2⁸) 的元素做运算；椭圆曲线密码（ECC）在有限域 GF(p) 上定义"曲线上的点"，实现超短密钥的高强度加密。③ 有限域的"循环"结构对应离散傅里叶变换（FFT 在有限域上的推广），是快速算法与信号处理的根基。

6.5 格：上下确界的结构

偏序集与哈斯图

偏序关系 ≼：满足自反（a ≼ a）、反对称（a ≼ b 且 b ≼ a ⇒ a = b）、传递（a ≼ b 且 b ≼ c ⇒ a ≼ c）的关系。偏序与全序的区别：偏序允许"两个元素不可比较"。

哈斯图（Hasse diagram）：偏序关系的几何表示——元素画成点，若 a ≺ b 且中间没有其他元素，则把 b 画在 a 上方并连线，省略传递边。

集合 {a,b,c} 的幂集按 ⊆ 排序的哈斯图：

                 {a,b,c}
                /   |   \
           {a,b}  {a,c}  {b,c}
            / \   / \   / \
          {a}    {b}    {c}
            \    |    /
                 ∅
几何含义：哈斯图把抽象的"谁包含谁 / 谁整除谁 / 谁比谁大"画成一张上下分层的图。偏序 = 有方向的层级；哈斯图 = 这个层级的"骨架"。看见哈斯图，就能一眼看出最大元、最小元、极大元、极小元、上界与下界。

格的定义（两个等价视角）

视角一（偏序）：偏序集 (L, ≼) 中，若任意两元素 a, b 都有最小上界（上确界，记 a ∨ b，读作 "a join b"）与最大下界（下确界，记 a ∧ b，读作 "a meet b"），则 L 是格。

视角二（代数）：(L, ∨, ∧) 是带两个二元运算的代数系统，满足交换律、结合律、吸收律（幂等律可由吸收律推出）：

交换律：a∨b = b∨a，        a∧b = b∧a
结合律：(a∨b)∨c = a∨(b∨c)，(a∧b)∧c = a∧(b∧c)
吸收律：a∨(a∧b) = a，      a∧(a∨b) = a

两个视角等价：a ≼ b 当且仅当 a∧b = a（等价于 a∨b = b）。

格的例子

  • 整除格 (N⁺, |)：正整数按整除关系构成格，a∧b = gcd(a, b)（最大公约数），a∨b = lcm(a, b)（最小公倍数）。
  • 幂集格 (P(S), ⊆)：A∧B = A∩B，A∨B = A∪B。
  • 子群格：群的所有子群按包含关系构成格。

分配格、有界格与有补格

  • 分配格：∨ 与 ∧ 互相满足分配律：a∨(b∧c) = (a∨b)∧(a∨c) 及对偶式。
  • 有界格：存在最大元 1（全上界）与最小元 0（全下界）。
  • 有补格：有界格中每个元素 a 都有补元 a'，满足 a∨a' = 1 且 a∧a' = 0。
几何/物理含义：格是"层级结构 + 上下确界"的数学。知识图谱、文件目录树、权限继承、信息分类都是格；两个概念的"共同祖先"是 ∧（最大下界），"最细的公共后代"是 ∨（最小上界）。整除格 gcd/lcm 是"约分与通分"的代数化：两个分数通分要找分母的 lcm（∨），约分要找 gcd（∧）。数据挖掘中的"概念格"（形式概念分析）正是用格的上下确界来挖掘数据中的概念层级。

6.6 布尔代数：逻辑与电路的代数

布尔代数的定义

布尔代数 = 有补分配格。即代数系统 (B, ∨, ∧, ′, 0, 1)，其中 (B, ∨, ∧) 是有界分配格，0 是最小元、1 是最大元，且每个元素 a 有补元 a′。它满足：

幂等律：a∨a = a，          a∧a = a
交换律：a∨b = b∨a，        a∧b = b∧a
结合律：(a∨b)∨c = a∨(b∨c)，(a∧b)∧c = a∧(b∧c)
吸收律：a∨(a∧b) = a，      a∧(a∨b) = a
分配律：a∨(b∧c) = (a∨b)∧(a∨c)，a∧(b∨c) = (a∧b)∨(a∧c)
补元律：a∨a′ = 1，         a∧a′ = 0
对合律：(a′)′ = a
德摩根律：(a∨b)′ = a′∧b′， (a∧b)′ = a′∨b′
同一律：a∨0 = a，a∧1 = a；a∨1 = 1，a∧0 = 0

布尔代数的三个"化身"（同构）

化身∨∧补 ′0 / 1
集合代数 (P(S), ∪, ∩, ¯, ∅, S)并集 ∪交集 ∩补集∅ / S
命题逻辑 ({T,F}, ∨, ∧, ¬)或 OR且 AND非 NOT假 F / 真 T
开关代数 ({0,1}, +, ·, ¯)逻辑或 +逻辑与 ·逻辑非0 / 1

这三个系统"结构完全相同"：把 ∪ ↔ ∨ ↔ OR、∩ ↔ ∧ ↔ AND、补集 ↔ 非 ↔ NOT 一一对应，所有定律逐条吻合。例如德摩根律在集合中是 overline{A∪B} = overline{A} ∩ overline{B}，在逻辑中是 ¬(p∨q) = ¬p ∧ ¬q，在电路中是"或非门 = 两个非门的与"。

几何含义：布尔代数是集合子集的格，可用文氏图（Venn diagram）完全可视化。∪ 是"区域合并"（并集），∩ 是"区域重叠"（交集），补集是"取反"（圈外区域）。三个集合的文氏图把整个区域分成 2³ = 8 块，恰好对应 n 个集合的幂集有 2ⁿ 个元素——布尔代数的元素个数必为 2ⁿ。德摩根律的几何解释："非(A 或 B)" = "非 A 且非 B"——即"不在 A∪B 里" = "既不在 A 里也不在 B 里"。
物理含义：布尔代数是数字电路与计算机芯片的数学根基。逻辑门电路正是布尔运算的物理实现：与门 AND（∧，串联开关）、或门 OR（∨，并联开关）、非门 NOT（′，反相器）。所有数字逻辑——加法器、存储器、CPU 指令——都能用这些门搭成。布尔代数还能化简逻辑表达式：ab + ab′ = a(b+b′) = a·1 = a，从而用更少的门、更省的芯片面积实现同一功能。它是"软件逻辑"与"硬件电路"之间那道桥梁。

典型例题（自测）

例题与解答

  1. 判断群：(Z, −)（整数减法的系统）是不是群？——不是：减法不满足结合律，如 (5−3)−1 = 1 而 5−(3−1) = 3；也没有幺元（不存在 e 使 a−e = e−a = a 恒成立）。
  2. 构造乘法表：写出 Z₄ = {0,1,2,3} 的模 4 加法表，并求每个元素的阶。——0 的阶为 1；1 与 3 的阶为 4（1⊕1⊕1⊕1 = 0）；2 的阶为 2。全部整除群的阶 4。
  3. 零因子：在 Z₆ 中求 2、3、4、5 哪些是零因子，哪些有逆元。——2×3 = 6 ≡ 0、4×3 = 12 ≡ 0，故 2、3、4 为零因子；5×5 = 25 ≡ 1，5 有逆元（就是 5 自身）。所以 Z₆ 不是域。
  4. 有限域：验证 GF(7) 中 3 的乘法逆元、2⁻¹、以及 4 × 5 mod 7。——3×5 = 15 ≡ 1 (mod 7)，故 3⁻¹ = 5；2×4 = 8 ≡ 1，故 2⁻¹ = 4；4×5 = 20 ≡ 6 (mod 7)。
  5. 格：对 a = 12, b = 18，在整除格中求 a∧b 与 a∨b。——a∧b = gcd(12,18) = 6，a∨b = lcm(12,18) = 36。
  6. 布尔化简：用布尔代数定律化简 F = ab + ab′ + a′b。——ab + ab′ = a(b+b′) = a·1 = a；故 F = a + a′b = (a + a′)(a + b) = 1·(a+b) = a + b（分配律）。
  7. 德摩根：写出 ¬(p ∧ q) 与 overline{A ∩ B} 的对偶式并解释。——¬(p∧q) = ¬p ∨ ¬q，overline{A∩B} = overline{A} ∪ overline{B}："不(A 且 B)" = "非 A 或非 B"。

常见误区

⚠️ 小心这些坑

  • ❌ "运算符号 * 一定是乘法" → ❌ * 只是任意二元运算的占位符，可代表加法、复合、取 gcd 等任何规则。
  • ❌ "封闭性自动满足" → ❌ 减在自然数上、除在整数上都不封闭，封闭性必须逐条验证。
  • ❌ "结合律就是交换律" → ❌ 矩阵乘法结合但不交换；减法既不结合也不交换。
  • ❌ "群一定满足交换律" → ❌ 群不要求交换；交换的群才叫阿贝尔群。置换群 S₃、矩阵群一般非交换。
  • ❌ "幺元就是零元" → ❌ 幺元是 e*a = a（不改变别人），零元是 θ*a = θ（吞掉别人）。乘法的幺元 1 与零元 0 完全不同。
  • ❌ "环一定能做除法" → ❌ 环只保证加减乘，除法需要"非零元有逆"，那是除环/域。整数环 Z 里 1÷2 无意义。
  • ❌ "域和整环是一回事" → ❌ 域 = 交换除环，比整环强：整环只是无零因子，未必每个非零元可逆（Z 是整环但不是域）。
  • ❌ "Zn 当 n 为任意数时都是域" → ❌ 只有 n 为素数时 Zn 才是域；Z₆ 有零因子，连整环都不是。
  • ❌ "格就是全序（任意两元素可比）" → ❌ 偏序允许不可比，格只要求任意两元素有上下确界；幂集格中 {a} 与 {b} 互不包含。
  • ❌ "布尔代数的补元可以不止一个" → ❌ 在布尔代数（有补分配格）中补元唯一；仅在一般有补格中补元才可能不唯一。
  • ❌ "布尔代数的 ∨/∧ 就是数的加减乘除" → ❌ ∨ 是并/或、∧ 是交/且，且满足幂等律 a∨a = a——这与数的加法 a+a = 2a 完全不同。

课本外 · 典故与思考

典伽罗瓦与五次方程：一场决斗换来的群论（点击展开）

三次、四次方程在 16 世纪就被解出来了，而一般的五次方程有没有"根式解"（只用开方就能写出的求根公式）悬置了二百多年。1824 年，22 岁的挪威人阿贝尔证明：一般的五次方程没有根式解。更年轻的法国人伽罗瓦（1811–1832）则走得更远。

伽罗瓦发明了"伽罗瓦群"：他把方程的根的对称置换组织成群，并证明——方程能否根式求解，取决于它的对称群是否"可解"。五次方程无解的本质，是它的对称群（五个根的全部置换群）不够可解。这是数学史上第一次把"解方程"翻译成"研究对称结构"。

他的命运令人唏嘘：两次向科学院投稿（经手人是柯西、傅里叶），手稿被遗忘或遗失；1832 年 5 月 30 日，年仅 20 岁的他在一场决斗中死去。决斗前夜，他把自己的数学发现整理成长信寄给朋友舍瓦利耶——这份手稿直到 1846 年才由刘维尔整理发表。群论由此诞生，并成为 20 世纪代数的核心语言。

一句话总结：一个 20 岁死于决斗的青年，用决斗前夜整理的笔记开启了现代代数——你今天学的"群"，来自他生命最后的十四年。
思群与对称：晶体学家如何"算"出所有晶体（点击展开）

6.2 节说"群就是对称的抽象定义"。这个概念最成功的应用之一是晶体学：晶体是原子在空间中周期排列的固体，它的对称性恰好构成群（平移、旋转、镜像的组合）。

  • 1891 年，俄罗斯结晶学家费奥多罗夫与德国数学家熊夫利斯几乎同时完成了一项惊人的工作：把三维空间中所有可能的周期对称方式全部枚举分类，得到 230 个"空间群"。
  • 关键点：那时还没有 X 射线衍射（1912 年才诞生），晶体学家看不见原子排列——这 230 个群完全是"用群论在纸上算出来的预言"。
  • 此后人们发现，自然界所有已知晶体的对称类型都精确落在这份名单里；今天的晶体学数据库、材料设计，第一步就是"查空间群表"。

另一个现代例子是魔方：所有转动构成"鲁比克群"，合法状态共有 4.3 × 10¹⁹ 种；2010 年研究者借助计算证明，任意状态至多 20 步就能复原（"上帝之数"= 20）——这个答案本身就是群与算法合作的产物。

一句话总结：晶体学家用群"算出"了宇宙中可能存在的一切晶体对称——这个预言比实验验证早了二十年。
趣1843 年的那座桥：哈密顿与四元数（点击展开）

复数可以表示平面上的旋转：乘以 i 就是转 90°（6.4 节那张图）。那么三维空间的旋转该用什么"数"？19 世纪的数学家们找了很久——三元数总是差一口气。1843 年 10 月 16 日，哈密顿与妻子散步经过都柏林的布鲁姆桥时，灵感突然降临：答案不是三元数，而是四元数——前提是放弃乘法交换律：

i² = j² = k² = ijk = −1

据说他当场用小刀把这个公式刻在了桥的石栏上；今天布鲁姆桥头立着纪念牌，刻的正是这个公式。

四元数的意义远超"三维旋转"本身：它是数学史上第一个被认真研究的非交换数系——i·j ≠ j·i，乘法不再可以随便换序。这打破了"数"必须服从运算直觉的千年惯例，迫使数学家接受：代数结构由公理定义，而不是由"数"决定。抽象代数的观念（本章 6.1 的"集合 + 运算"）由此萌芽。今天，四元数仍是航空航天、电子游戏里描述三维姿态的标准工具。

一句话总结：一座桥、一把小刀、一个放弃交换律的决定——四元数把代数从"数"解放成了"结构"。

本章练习卷（含答案）

一、练习题

  1. 封闭性（易）：在自然数集 N 上，减法是不是二元运算？在整数集 Z 上呢？由此说明"封闭性"在什么意义上决定了"这套运算能不能一直算下去"。
  2. 群的定义（易）：判断 (Z, −)（整数连同普通减法）是否构成群。若否，逐条指出它违反了群的哪一条公理。
  3. 对称群（中）：正三角形的所有对称变换（恒等、旋转 120°、旋转 240°、沿三条对称轴翻转）在"复合"运算下构成二面体群 D₃。请指出：这里的幺元是什么？"旋转 120°"的逆元是什么？为什么说"群就是对称的抽象定义"？
  4. 零因子（中）：在模 6 环 Z₆ = {0,1,2,3,4,5} 中，找出全部零因子；据此说明为什么 Z₆ 不是域。并用自己的话解释：零因子对应"两个非零操作复合得零"，例如哪类矩阵相乘会得零？
  5. 有限域（中偏难）：验证 GF(7) 中 3 的乘法逆元是 5（即 3 × 5 ≡ 1 (mod 7)），并计算 4 × 5 mod 7。结合"乘以 i 就是旋转 90°"，说明为什么"域的结构决定了空间能做哪些几何操作"。
  6. 布尔代数（难）：用布尔代数定律化简 F = ab + ab′ + a′b（提示：先提公因子，再吸收），并写出 (a∨b)′ 的德摩根对偶式。结合"与/或/非门"，说明化简对数字电路有什么现实意义。

二、参考答案（点击展开）

查看第1题答案

在 N 上减法不是二元运算，因为 2 − 3 = −1 ∉ N，不满足封闭性；在 Z 上是，因为任意两个整数之差仍是整数。封闭性保证"运算结果永远留在集合内"，一旦不封闭，算着算着就会"越出"这个数系，也就无法在它上面建立群、环等结构。

查看第2题答案

不是群。① 不满足结合律：(5−3)−1 = 1，而 5−(3−1) = 3；② 没有幺元：不存在 e 使 a − e = e − a = a 对一切 a 成立；③ 因而更谈不上每个元素有逆元。减法只封闭，但"运算顺序"与"操作数顺序"都乱，故连半群都不是。

查看第3题答案

幺元是恒等变换 e（什么都不做）；"旋转 120°"记 r，其逆元是"旋转 240°"r²，因为 r ∘ r² = r³ = e 回到原位（转过去还能转回来）。D₃ 满足封闭、结合、有幺元、每元素有逆元，所以是群；而"对称"的本质正是"一组能搬动图形、搬完又与原位重合、且能撤销的操作"，群的公理恰好把它形式化。

查看第4题答案

2×3 = 6 ≡ 0、4×3 = 12 ≡ 0（且 2、3、4 均非零），故零因子为 2、3、4。因为 Z₆ 中存在零因子，无法保证每个非零元有乘法逆元，所以不是域。零因子的"操作"含义：两个非零的投影算符若投影到互相垂直的子空间，相乘（复合）得零矩阵——例如 A = [[0,1],[0,0]] 满足 A² = 0 但 A ≠ 0。

查看第5题答案

3 × 5 = 15 ≡ 1 (mod 7)，所以 3⁻¹ = 5；4 × 5 = 20 ≡ 6 (mod 7)。域保证加、减、乘、除（除数非零）都封闭，于是在其上可以自由"缩放坐标"：实数域张成数轴，复数域张成复平面，乘以 i 即逆时针旋转 90°、乘以 e^{iθ} 即旋转 θ 角——域能做的运算决定了这个空间里哪些几何操作有意义。

查看第6题答案

化简：ab + ab′ = a(b+b′) = a·1 = a，故 F = a + a′b = (a+a′)(a+b) = 1·(a+b) = a+b。德摩根对偶式：(a∨b)′ = a′ ∧ b′（即"非(a 或 b) = 非 a 且非 b"）。现实意义：逻辑表达式越短，需要的逻辑门越少、芯片面积越小、功耗越低，同一功能可用更省的电路实现——布尔化简是数字电路设计的日常工序。
