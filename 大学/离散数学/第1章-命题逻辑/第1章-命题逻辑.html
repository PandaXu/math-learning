第1章 命题逻辑

大学 / 离散数学

一句话总纲：命题逻辑 = 把「能判断真假的陈述句」抽象成符号，用 ∧、∨、¬、→、↔ 五个联结词组合、演算、推理——它的几何形态是「布尔超立方体 {0,1}ⁿ 上的顶点与集合」，它的物理形态是「与/或/非门组成的开关电路」，学完本章你要能在"集合/几何图形"与"逻辑电路"之间自由翻译每一个公式。

1.1 命题与联结词

什么是命题？

命题：能判断真假的陈述句。一个命题要么为真，要么为假，二者必居其一且只居其一——这是逻辑学的两条根基：排中律（非真即假）与矛盾律（不能既真又假）。

  • 命题的真值：真（记作 T 或 1）、假（记作 F 或 0）。
  • 例：「2 + 3 = 5」是真命题；「地球是方的」是假命题；两者都是命题。
  • 不是命题的句子：疑问句（"你吃饭了吗？"）、祈使句（"请关门！"）、感叹句（"太好了！"），以及真值不确定的语句（"x + 1 = 2"，当 x 未指定时不是命题）。
  • 悖论不是命题：如"这句话是假的"——若它为真则它为假，若它为假则它为真，无法给出唯一真值。

简单命题与复合命题

  • 简单命题（原子命题）：不能再分解的命题，用 p, q, r, … 表示。
  • 复合命题：由简单命题通过联结词组合而成。

五个基本联结词

联结词符号读法含义（p∧q 为真当且仅当…）
否定¬p非 pp 为假
合取p ∧ qp 且 qp、q 同时为真
析取p ∨ qp 或 qp、q 至少一个为真（可同真）
蕴含p → q若 p 则 q不是"p 真而 q 假"
等价p ↔ qp 当且仅当 qp、q 真值相同

此外常用异或 p ⊕ q（"p 与 q 恰有一个为真"），它可由基本联结词定义：p ⊕ q = (p ∨ q) ∧ ¬(p ∧ q)。

真值表（用 1 表示真、0 表示假）

pq¬pp ∧ qp ∨ qp ⊕ qp → qp ↔ q
00100011
01101110
10001100
11011011
几何含义：联结词就是集合运算。把命题理解为"它在某个论域里划出的一块区域"（那块区域 = 使该命题为真的所有情形），则 ∧ = 交集、∨ = 并集、¬ = 补集：p∧q 是两圆重叠区，p∨q 是两圆合起来，¬p 是圆外全部区域。这正是文氏图（Venn 图）的语言。
物理含义：联结词就是逻辑门与开关：∧ 是串联（两个开关都闭合才通电）、∨ 是并联（任一开关闭合就通电）、¬ 是常闭触点（反向开关）。1938 年香农（Shannon）证明：布尔代数 ↔ 开关电路一一对应，这正是现代计算机芯片的起点。

蕴含 p → q 的真假为什么这样定？

设 p = "下雨"，q = "地湿"，则 p → q = "如果下雨，那么地湿"。它只在一种情况下为假：下了雨而地没湿（p 真 q 假）。

  • 下雨且地湿（p 真 q 真）：成立 ✓
  • 没下雨（p 假）：不管地湿不湿，"如果下雨就湿"这句话没有被违反，故按约定为真——这叫善意推定（空真/vacuous truth）。
p → q  ⇔  ¬p ∨ q   （"要么没下雨，要么地湿了"）
几何含义：p → q 等价于子集关系 p ⊆ q：使 p 为真的区域被包含在使 q 为真的区域里。"没下雨"落在 p 的区域之外，此时承诺自动兑现——这就是空真的几何来源。
物理含义：p → q 就是一个继电器/受控开关：信号 p 控制信号 q 的通断；¬p ∨ q 表明"要么控制端没通电（¬p），要么输出端已通电（q）"。

1.2 命题公式

命题常项、命题变项与合式公式

  • 命题常项：真值确定的命题（如"1 是真"，即真值 T 或 F）。
  • 命题变项：真值待定的命题符号 p, q, r, …，就像代数里的未知数。
  • 合式公式（wff）：由命题变项、联结词、括号按规则组成的合法符号串。

合式公式的递归定义：

(1) 单个命题变项 p（以及命题常项 0、1）是合式公式；
(2) 若 A 是合式公式，则 ¬A 是合式公式；
(3) 若 A、B 是合式公式，则 (A∧B)、(A∨B)、(A→B)、(A↔B) 是合式公式；
(4) 有限次使用 (1)(2)(3) 得到的符号串才是合式公式。

联结词优先级（从高到低）：¬ > ∧ > ∨ > → > ↔。故 ¬p ∧ q → r 即 ((¬p) ∧ q) → r。

真值表的构造

含 n 个命题变项的公式共有 2ⁿ 种赋值（每种变项可取 0/1）。构造步骤：

  1. 列出所有变项，按二进制顺序排出全部 2ⁿ 行赋值；
  2. 按优先级从小到大，逐列计算子公式的真值；
  3. 最后一列即公式的真值。

例：求 ¬(p ∧ q) ↔ (¬p ∨ ¬q) 的真值表（逐列）：

pqp ∧ q¬(p∧q)¬p¬q¬p ∨ ¬q¬(p∧q) ↔ (¬p∨¬q)
00011111
01011011
10010111
11100001

最后一列全为 1，说明该公式是重言式（恒真），这正是"德摩根律"的等价形式。

公式的三种分类

类别定义例
重言式（永真式）对所有赋值均为真p ∨ ¬p
矛盾式（永假式）对所有赋值均为假p ∧ ¬p
可满足式至少存在一种赋值使其为真p ∧ q、p ∨ ¬p

关系：重言式必可满足；矛盾式不可满足；既非重言式也非矛盾式的公式（如 p ∧ q）是可满足式。

几何含义：一个含 n 个变项的公式，就是一个定义在n 维布尔超立方体 {0,1}ⁿ 上的"黑白染色"：2ⁿ 个顶点每个染成 0（假）或 1（真）。重言式 = 全染 1（整块立方体全真）、矛盾式 = 全染 0、可满足式 = 至少一个顶点为 1。当 n=2 时它就是单位正方形的四个顶点 (0,0),(0,1),(1,0),(1,1)。
物理含义：这个公式就是一台组合逻辑电路：n 个输入引脚（变项）→ 输出引脚（真值），真值表就是它的"规格书"。重言式 = 无论输入如何输出恒为 1 的电路（恒高电平），矛盾式 = 输出恒为 0。

1.3 等值演算

等值的定义

设 A、B 是命题公式，若 A ↔ B 是重言式（即对所有赋值 A、B 真值完全相同），则称 A 与 B 等值（等价），记作 A ⇔ B。

注意区别：↔ 是公式内部的联结词；⇔ 是两个公式之间的关系（"恒等"）。

基本等值式（代换的"乘法口诀表"）

双重否定律   ¬¬p ⇔ p
幂等律       p ∨ p ⇔ p          p ∧ p ⇔ p
交换律       p ∨ q ⇔ q ∨ p      p ∧ q ⇔ q ∧ p
结合律       (p∨q)∨r ⇔ p∨(q∨r)   (p∧q)∧r ⇔ p∧(q∧r)
分配律       p∨(q∧r) ⇔ (p∨q)∧(p∨r)
             p∧(q∨r) ⇔ (p∧q)∨(p∧r)
德摩根律     ¬(p∨q) ⇔ ¬p∧¬q     ¬(p∧q) ⇔ ¬p∨¬q
吸收律       p∨(p∧q) ⇔ p        p∧(p∨q) ⇔ p
零律         p∨1 ⇔ 1            p∧0 ⇔ 0
同一律       p∨0 ⇔ p            p∧1 ⇔ p
排中律       p∨¬p ⇔ 1
矛盾律       p∧¬p ⇔ 0
蕴含等值式   p→q ⇔ ¬p∨q
等价等值式   p↔q ⇔ (p→q)∧(q→p) ⇔ (p∧q)∨(¬p∧¬q)
假言易位     p→q ⇔ ¬q→¬p
归谬论       (p→q)∧(p→¬q) ⇔ ¬p

置换规则与等值演算

置换规则：设 Φ(A) 是含子公式 A 的公式，若 A ⇔ B，则 Φ(A) ⇔ Φ(B)。即"等价可以代入替换"。用一连串等值式把一个公式逐步化到目标形式的过程叫等值演算。

示例：证明 ¬(p ∨ (¬p ∧ q)) ⇔ ¬p ∧ ¬q。

¬(p ∨ (¬p ∧ q))
⇔ ¬p ∧ ¬(¬p ∧ q)            （德摩根律：¬(x∨y) = ¬x∧¬y）
⇔ ¬p ∧ (¬¬p ∨ ¬q)           （德摩根律：¬(x∧y) = ¬x∨¬y）
⇔ ¬p ∧ (p ∨ ¬q)             （双重否定律）
⇔ (¬p ∧ p) ∨ (¬p ∧ ¬q)      （分配律）
⇔ 0 ∨ (¬p ∧ ¬q)             （矛盾律：¬p∧p = 0）
⇔ ¬p ∧ ¬q                   （同一律：0∨x = x）
几何含义：等值的两个公式在文氏图上画出同一块区域，在超立方体上染出同一种黑白图案。德摩根律 ¬(p∨q) ⇔ ¬p∧¬q 的几何本质是"并集的补 = 补集的交"：两个圆并起来之外的部分 = 圆 p 外与圆 q 外的公共部分，一眼即可在文氏图上看出。
物理含义：等值 = 功能相同的电路：两个内部结构不同的门网络，对所有输入给出完全相同的输出，即可互相替换（省钱、省门、降低延迟）。由德摩根律，NAND（与非）门或 NOR（或非）门单独即可搭出所有逻辑，所以芯片制造只需反复刻一种门——这是数字电路的根本工程事实。

1.4 范式

简单式、析取范式与合取范式

  • 文字：命题变项 p 或其否定 ¬p。
  • 简单合取式：若干文字的合取，如 p ∧ ¬q ∧ r。
  • 简单析取式：若干文字的析取，如 p ∨ ¬q ∨ r。
  • 析取范式（DNF）：若干简单合取式的析取，形如 (…) ∨ (…) ∨ …。
  • 合取范式（CNF）：若干简单析取式的合取，形如 (…) ∧ (…) ∧ …。

任何命题公式都可等值化为析取范式与合取范式（先消去 →、↔，再用德摩根律把 ¬ 压到文字上，最后用分配律展开/合并）。

极小项与极大项

含 n 个变项时，每个变项必须出现且只出现一次的"标准形式"：

  • 极小项：n 个文字的合取，共 2ⁿ 个，记作 m₀…m_{2ⁿ−1}。每个极小项只在一种赋值下为真。
  • 极大项：n 个文字的析取，共 2ⁿ 个，记作 M₀…M_{2ⁿ−1}。每个极大项只在一种赋值下为假。

两个变项 p、q 的极小项与极大项（下标 = 其二进制取值）：

极小项                           极大项
m0 = ¬p ∧ ¬q   (00 时为真)       M0 = p ∨ q      (00 时为假)
m1 = ¬p ∧ q    (01 时为真)       M1 = p ∨ ¬q     (01 时为假)
m2 = p ∧ ¬q    (10 时为真)       M2 = ¬p ∨ q     (10 时为假)
m3 = p ∧ q     (11 时为真)       M3 = ¬p ∨ ¬q    (11 时为假)

基本关系：mᵢ = ¬Mᵢ，Mᵢ = ¬mᵢ；任意两个不同极小项相矛盾（mᵢ∧mⱼ = 0），全部极小项相析取为 1。

主析取范式与主合取范式

  • 主析取范式（主 DNF）：由成真赋值对应的极小项析取而成，记 Σ(i₁, i₂, …)。
  • 主合取范式（主 CNF）：由成假赋值对应的极大项合取而成，记 Π(i₁, i₂, …)。

示例：求 p → q 的主范式。由真值表，p → q 在 00、01、11 时为真，在 10 时为假，故：

主析取范式：p → q ⇔ m0 ∨ m1 ∨ m3 ⇔ (¬p∧¬q) ∨ (¬p∧q) ∨ (p∧q)  = Σ(0,1,3)
主合取范式：p → q ⇔ M2 ⇔ ¬p ∨ q                                = Π(2)
几何含义：极小项 = 超立方体的一个顶点（n 维时 2ⁿ 个顶点，每顶点恰对应一个极小项）；主析取范式 = 把所有"染 1"的顶点取并——公式就是这些真顶点组成的集合；主合取范式 = 把所有"染 0"的顶点（以极大项形式）排除掉——即"除假顶点之外的全部区域"。两者是同一几何对象的两种描述：点集的正写（并）与补集的负写（交）。n=2、3、4 时把超立方体摊平，就是工程上著名的卡诺图（Karnaugh map）。
物理含义：主析取范式 = 与-或两级电路（第一级 AND 门产生顶点、第二级 OR 门汇总，即"积之和"）；主合取范式 = 或-与两级电路（"和之积"）。任何真值表都可用最多两级门实现，这正是只读存储器 ROM 与可编程逻辑 PLA 的原理：真值表 = 芯片的"接线图"。

1.5 推理理论

什么是有效推理？

推理：从一组前提（premises）推出结论（conclusion）的过程。推理的形式结构为：

前提：A₁, A₂, …, Aₙ    结论：B
       (A₁ ∧ A₂ ∧ … ∧ Aₙ) → B

有效推理（valid argument）：当且仅当 (A₁ ∧ A₂ ∧ … ∧ Aₙ) → B 是重言式——即"凡前提全真时，结论必真"。记作 A₁, A₂, …, Aₙ ⇒ B。

注意：推理的有效性只看形式（是否保证真从真导出），不看前提本身是否真的为真。前提若为假，推理仍可是有效的。

判断推理是否正确的三种方法

  • 真值表法：列出所有赋值，检查是否存在"前提全真而结论为假"的一行；若无，则推理有效。
  • 等值演算法：证明 (A₁∧…∧Aₙ) → B ⇔ 1。
  • 主析取范式法：若结论的成真赋值集合 ⊇ 前提的成真赋值集合，则有效。

常用推理规则（自然推理系统）

规则名形式说明
假言推理 MPp, p→q ⇒ q肯定前件（Modus Ponens）
拒取式 MT¬q, p→q ⇒ ¬p否定后件（Modus Tollens）
假言三段论p→q, q→r ⇒ p→r蕴含可传递
析取三段论p∨q, ¬p ⇒ q排除一支取另一支
附加规则p ⇒ p∨q真上加真
化简规则p∧q ⇒ p合取可拆开
合取引入p, q ⇒ p∧q两真可合并
构造性二难p∨q, p→r, q→r ⇒ r分情况讨论
破坏性二难¬r∨¬s, p→r, q→s ⇒ ¬p∨¬q否定后件之二难

构造证明示例：由前提 p → q、q → r、p 推出 r。

(1) p → q        前提引入
(2) q → r        前提引入
(3) p            前提引入
(4) q            假言推理 (1)(3)
(5) r            假言推理 (2)(4)      ∴ 结论 r 得证

反证法（归谬）示例：证明 p → q, ¬q ⇒ ¬p（拒取式）。

(1) p → q        前提引入
(2) ¬q           前提引入
(3) p            附加前提（反设结论的否定 ¬(¬p)=p 为真）
(4) q            假言推理 (1)(3)
(5) q ∧ ¬q       合取引入 (4)(2)  → 矛盾！
(6) ¬p           归谬：反设导致矛盾，故 ¬p 成立
几何含义：有效推理 = 子集链：使"所有前提同时为真"的区域（前提集合的交集）必须被包含在使"结论为真"的区域里。假言推理 p, p→q ⇒ q 就是"既然 p ⊆ q，且当前点落在 p 内，那么它必落在 q 内"；拒取式 ¬q, p→q ⇒ ¬p 就是"当前点在 q 外，而 p ⊆ q，所以它必在 p 外"。用文氏图画出两个圆，结论的真假一目了然。
物理含义：推理 = 信号的必然传播：前提为真的电压信号顺着门电路"流动"，结论就像电路输出端必然出现的电平；有效推理保证"输入全高电平 ⇒ 输出必为高电平"。电路设计中的形式验证（formal verification） 正是用逻辑推理证明：芯片在所有输入下都不会进入错误状态。

典型例题（自测）

  1. 判断下列哪些是命题，并指出真值：(a) 3 是偶数；(b) 请保持安静；(c) x > 5；(d) 2 是质数。
  2. 写出命题 "只有天下雨，我才带伞" 的符号化：设 p = 天下雨，q = 我带伞。（提示：p 是 q 的必要条件。）
  3. 构造公式 (p → q) ∧ p → q 的真值表，说明它是哪类公式（重言式 / 矛盾式 / 可满足式）。
  4. 用等值演算证明：p → (q → r) ⇔ (p ∧ q) → r。
  5. 求公式 (p ∧ q) ∨ (¬p ∧ r) 的主析取范式与主合取范式。
  6. 判断推理是否有效：前提 p → q, r → ¬q, r，结论 ¬p，并用自然推理写出证明。
  7. 用真值表判断 p ⊕ q 与 (p ∨ q) ∧ ¬(p ∧ q) 是否等值。

常见误区

  • ❌ "p → q 中 p 假时结果无所谓、随便填" → ❌ p 假时 p → q 约定为真（空真），这是定义的一部分，不是"无所谓"。
  • ❌ "p → q 为真 ⟺ p 真 q 真" → ❌ 漏了 p 假的情形；p → q 只在 p 真 q 假时为假，其余全真。
  • ❌ "p → q 与 q → p 等价" → ❌ 混淆了原命题与逆命题；正确的是 p → q ⇔ ¬q → ¬p（逆否命题）。
  • ❌ "析取 ∨ 是'二选一'" → ❌ 那是异或 ⊕；∨ 是相容或（可同真）。"他喜欢数学或物理"允许都喜欢。
  • ❌ "⇔ 与 ↔ 是一回事" → ❌ ↔ 是公式内的联结词，⇔ 是两公式间"恒等"的关系。
  • ❌ "矛盾式 p∧¬p 是假的所以没意义" → ❌ 矛盾式在归谬法/反证法中是核心工具，专门用来"推出矛盾以否定假设"。
  • ❌ "推理有效 = 结论是真的" → ❌ 有效只保证"前提全真 ⇒ 结论真"这一形式；前提若假，结论真假不定，推理仍可能有效。
  • ❌ "主析取范式与主合取范式是两种不同的公式" → ❌ 它们是同一个公式的两种等值写法（正写点集 / 负写补集），真值表完全相同。

本章练习卷（含答案）

一、练习题

  1. 判断下列语句是否是命题，若是请指出其真值：(a) 3 是偶数；(b) 请把门关上；(c) x + 1 = 3；(d) 5 大于 2。
  2. 设 p =「天下雨」，q =「我带伞」。将下列语句符号化：(a) 只有天下雨，我才带伞；(b) 除非天下雨，否则我不带伞；(c) 天下雨是我带伞的充分条件。并说明 (a) 与 (c) 在文氏图上的区别。
  3. 构造公式 (p → q) ∧ p → q 的真值表，判断它是重言式、矛盾式还是可满足式。
  4. 用等值演算证明：p → (q → r) ⇔ (p ∧ q) → r。
  5. 求公式 (p ∧ q) ∨ (¬p ∧ r) 的主析取范式与主合取范式（用 Σ / Π 表示，并给出其「真顶点」的几何含义）。
  6. 判断推理是否有效，并写出自然推理证明：前提 p → q、r → ¬q、r，结论 ¬p。再从几何与物理角度各用一句话解释其含义。

二、参考答案（点击展开）

查看第1题答案

(a) 是命题，真值为假；(b) 祈使句，不是命题；(c) 含自由变项 x，真值不确定，不是命题；(d) 是命题，真值为真。

查看第2题答案

(a)「只有 p 才 q」表示 p 是 q 的必要条件：q → p；(b)「除非 p 否则 ¬q」即 ¬p → ¬q，等价于 q → p；(c) 充分条件：p → q。几何上 (a) 是 q ⊆ p（带伞区域落在下雨区域内），(c) 是 p ⊆ q（下雨区域落在带伞区域内），两者包含方向相反。

查看第3题答案

按优先级 (p → q) ∧ p → q 即 ((p → q) ∧ p) → q。列真值表：使「前提 (p → q) ∧ p 为真」的只有 p=1、q=1 一行，此时结论 q=1 也为真；其余行前提为假，蕴含为真（空真）。故整列全为 1，是重言式（正是假言推理 MP 的有效性形式）。

查看第4题答案

p → (q → r) ⇔ ¬p ∨ (¬q ∨ r)（蕴含等值式，两次）⇔ (¬p ∨ ¬q) ∨ r（结合律）⇔ ¬(p ∧ q) ∨ r（德摩根律）⇔ (p ∧ q) → r（蕴含等值式）。

查看第5题答案

列三变项真值表，成真赋值为 001、011、110、111（即 (p∧q) 为真或 (¬p∧r) 为真）。故主析取范式 Σ(1,3,6,7) = (¬p∧¬q∧r)∨(¬p∧q∧r)∨(p∧q∧¬r)∨(p∧q∧r)；主合取范式 Π(0,2,4,5) = (p∨q∨r)∧(p∨¬q∨r)∧(¬p∨q∨r)∧(¬p∨q∨¬r)。几何上主析取范式就是布尔立方体 {0,1}³ 中这四个「染 1」顶点的并集。

查看第6题答案

推理有效。证明：(1) r → ¬q 前提引入；(2) r 前提引入；(3) ¬q 假言推理 (1)(2)；(4) p → q 前提引入；(5) ¬p 拒取式 (4)(3)，得证。几何：使三个前提同时为真的区域 ⊆ 结论 ¬p 的区域（p 的补集），即子集链成立；物理：r 为高电平 ⇒ ¬q 为高电平 ⇒ 由 p → q 知 q 为低迫使 p 为低，即 ¬p 必然为高电平。
