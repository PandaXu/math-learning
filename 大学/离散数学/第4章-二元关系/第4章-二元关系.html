第4章 二元关系

大学 / 离散数学

一句话总纲：二元关系 = 「两个集合元素之间的“连线”」。它可以用关系矩阵（方格纸上的打点）和关系图（顶点 + 箭头的有向图）来“看见”；关系一旦加上「自反、对称、传递」这些性质，就会分裂出两大重要结构——等价关系（把集合切成块）与偏序关系（把集合排成层）。学完本章，你要能在心里把每一个抽象的关系都画成一张“带箭头的图”。

4.1 关系的概念与表示

序偶与笛卡尔积

序偶（有序对）：由两个元素按固定次序组成的整体，记作 (a, b)。a 叫第一元素，b 叫第二元素。

  • 次序是本质：(a, b) = (c, d) 当且仅当 a = c 且 b = d。
  • 因此 (1, 2) ≠ (2, 1)——这是“序”偶与普通二元集合 {1,2} 的根本区别。

笛卡尔积：集合 A 与 B 的笛卡尔积是所有序偶组成的集合：

A × B = { (a, b) | a ∈ A, b ∈ B }
  • 元素个数：|A × B| = |A| · |B|。
  • 例：A = {1, 2}，B = {a, b, c}，则 A × B = {(1,a),(1,b),(1,c),(2,a),(2,b),(2,c)}，共 2 × 3 = 6 个元素。
  • 推广：n 重笛卡尔积 A₁ × A₂ × … × Aₙ 的每个元素就是一个 n 元组。
几何含义：笛卡尔积就是平面直角坐标系上的点阵——A × B 中每个序偶 (a, b) 对应一个横坐标取自 A、纵坐标取自 B 的格点；R × R 就是整个平面。物理/现实含义：笛卡尔积是“所有可能配对”的全集：扑克牌的花色 × 点数 = 52 张牌，坐标 (x, y) 定位一个位置，数据库两张表的连接（Join）本质也是笛卡尔积加筛选。

二元关系的定义

二元关系：A × B 的任意一个子集 R，就称为从 A 到 B 的一个二元关系，即 R ⊆ A × B。

  • 若 (a, b) ∈ R，记作 a R b（读作“a 与 b 有关系 R”）。
  • 当 A = B 时，称 R 为A 上的二元关系，这是本章讨论的重点。

例：A = {1, 2, 3}，定义 A 上的“小于”关系 R：

R = { (1,2), (1,3), (2,3) }   即  1R2, 1R3, 2R3

三个特殊关系（A 上的）：

  • 空关系：∅，任何两个元素都不相关。
  • 全域关系：EA = A × A，任何两个元素都相关。
  • 恒等关系：IA = { (x, x) | x ∈ A }，只有“自己和自己”相关。

关系的表示：集合、矩阵、图

同一个关系有三种等价写法，前两种“画”出了关系的形状：

① 关系矩阵：设 A = {a₁, a₂, …, aₙ}，定义 n 阶方阵 MR = (mij)：

m_ij = 1   当 (a_i, a_j) ∈ R
m_ij = 0   当 (a_i, a_j) ∉ R

例 A = {1, 2, 3}，R = “小于”关系，其关系矩阵为：

        1  2  3
   1 [  0  1  1 ]
   2 [  0  0  1 ]
   3 [  0  0  0 ]

② 关系图（有向图）：以 A 中每个元素为一个顶点（画成小圆圈）；若 (x, y) ∈ R，就从 x 画一条带箭头的边指向 y；若 (x, x) ∈ R，就在 x 上画一个自环（回到自己的小圈）。

几何含义：关系矩阵是一张方格纸上“打点”的 0-1 表——第 i 行第 j 列有点，就表示 a_i → a_j 有关系；关系图则是“顶点 + 箭头”的有向图，箭头就是“连线”。物理/现实含义：关系矩阵正是计算机存储图所用的邻接矩阵；关系图就是网络、社交图、流程图、电路——把“抽象的关系”翻译成“看得见的箭头”，是本章一切几何直觉的总开关。

4.2 关系的运算

集合运算（并、交、差、补）

关系既然是集合，就可以做集合运算，结果仍是关系：

  • 并 R ∪ S、交 R ∩ S、差 R − S。
  • 补：R 的补（关于全域关系）= EA − R = A × A − R，即“原来有关系的现在没有，原来没有的现在有”。

逆关系（把箭头反向）

R⁻¹ = { (y, x) | (x, y) ∈ R }
  • 例：R = {(1,2),(2,3)}，则 R⁻¹ = {(2,1),(3,2)}。
  • 显然 (R⁻¹)⁻¹ = R。
  • 关系矩阵上，MR⁻¹ = MRᵀ（转置）。
几何含义：逆关系就是把关系图中所有箭头的方向全部反过来（矩阵转置即“沿主对角线翻折”）。物理含义：“反过来”的关系——父子关系的逆是子父关系，“≤”的逆是“≥”，“喜欢”的逆是“被喜欢”。

复合关系（走两步）

设 R 是 A 到 B 的关系，S 是 B 到 C 的关系，定义复合关系：

R ∘ S = { (x, z) | 存在 y，使 (x, y) ∈ R 且 (y, z) ∈ S }
  • 例：R = {(1,2),(2,3)}，S = {(2,4),(3,5)}，则 R ∘ S = {(1,4),(2,5)}——先沿 R 到 2，再沿 S 从 2 到 4。
  • 注意复合顺序约定：本书约定 R ∘ S 表示“先 R 后 S”；有的教材符号相反，读题时先确认约定。
几何含义：复合关系 = 在关系图中“走两步”：先沿 R 的一条箭头，再沿 S 的一条箭头，能连通的起点—终点对就是 R ∘ S。其关系矩阵恰为布尔矩阵乘法 MR∘S = MR ⊙ MS（把普通乘加换成“与/或”：m = ∨k(rik ∧ skj)）。物理含义：“传递可达性”——“朋友的朋友”、航班中转（先坐 R 航线再转 S 航线）、供应链上下游。

关系的幂与传递闭包

  • 幂：R² = R ∘ R，Rⁿ = R ∘ Rⁿ⁻¹。Rⁿ 表示“沿 R 走 n 步可达”的所有起止对。
  • 传递闭包 R⁺ = R¹ ∪ R² ∪ R³ ∪ …（走任意正数步可达）。
  • 自反传递闭包 R* = R⁺ ∪ IA（含“原地不动”0 步）。
几何含义：R⁺ 是把关系图“补全所有捷径”——只要从 x 出发沿箭头能走到 z（不论几步），就直接在 x、z 之间连一条边。R* 再给每个顶点加一个自环（“待着不动也算一步”）。物理含义：一个通信网络里“谁能（经过若干跳）到达谁”；一个依赖系统里“谁（直接或间接）依赖谁”。

4.3 关系的性质

以下设 R 是集合 A 上的二元关系。三条核心性质构成后两节的基石。

自反性与反自反性

  • 自反：对每个 x ∈ A，都有 (x, x) ∈ R。
  • 反自反：对每个 x ∈ A，都有 (x, x) ∉ R。
几何含义：自反 = 关系矩阵主对角线全为 1，关系图里每个顶点都有一个自环；反自反 = 主对角线全为 0，任何顶点都无自环。物理含义：“自己和自己总成立”——x ≤ x（小于等于）、A ⊆ A（集合包含）、平面直线 l ∥ l（平行线含自身时）。注意：既不自反也不反自反完全可能，例如“x 整除 y 且 x≠y”，或者 A = {1,2} 上的 R = {(1,2)}。

对称性与反对称性

  • 对称：若 (x, y) ∈ R，则必有 (y, x) ∈ R。
  • 反对称：若 (x, y) ∈ R 且 (y, x) ∈ R，则必有 x = y。
几何含义：对称 = 关系矩阵关于主对角线对称（M = Mᵀ），关系图中箭头永远成对出现，等价于一条“无向边”；反对称 = 任意两个不同顶点之间至多只有一个方向的箭头（不允许成对的双向箭头，但允许自环）。物理含义：对称关系是“无方向”关系——同学、朋友、同龄、夫妻；反对称关系是“有方向/有次序”关系——≤、整除、祖先、包含。二者并不互斥：恒等关系 IA 既对称又反对称（只有自环）。

传递性

  • 传递：若 (x, y) ∈ R 且 (y, z) ∈ R，则必有 (x, z) ∈ R。
几何含义：关系图中只要存在“x → y → z”的两步路径，就必须有“x → z”的直达边（捷径）——任何间接可达都能被一条边“压缩”。物理含义：逻辑上的递推——a < b 且 b < c ⇒ a < c；x 整除 y 且 y 整除 z ⇒ x 整除 z；“a 是 b 的祖先且 b 是 c 的祖先 ⇒ a 是 c 的祖先”。判定口诀：“能两步走，就必有一跃直达”。

性质判定小结（矩阵 + 图一眼看）：

性质关系矩阵特征关系图特征
自反主对角线全为 1每个顶点都有自环
反自反主对角线全为 0任何顶点都无自环
对称矩阵对称（M = Mᵀ）箭头成对（无向边）
反对称i≠j 时 m_ij 与 m_ji 不同时为 1不同顶点间至多单向箭头
传递（需用 R² ⊆ R 判定）两步可达必有直达边

传递性的代数判据：R 传递 ⇔ R² ⊆ R（走两步的结果都包含在走一步里）。

4.4 等价关系与划分

等价关系的定义

同时满足自反 + 对称 + 传递的关系，称为等价关系，常记作 ~。

  • 例 1：恒等关系 IA。
  • 例 2：整数集 Z 上的模 n 同余：a ≡ b (mod n) 当且仅当 n 整除 (a − b)。
  • 例 3：平面图形集合上的“相似”；人群中的“同龄”“同班同学”。
几何含义：等价关系把集合“切成若干互不相交的块”——同一块内任意两点两两等价（块内两两有连线），不同块之间任何两点都不等价（块间无连线）。物理含义：“按某个特征分类”——模 n 同余就是钟表：13 点与 1 点在 12 小时制里是“同一个时刻”，因为 13 ≡ 1 (mod 12)；同龄、同余、同色都是“判定两个对象是否属于同一类”的准则。

等价类与商集

设 R 是 A 上的等价关系，对 x ∈ A：

[x]_R = { y ∈ A | (x, y) ∈ R }   称为 x 的等价类
  • x 称为该等价类的代表元；等价类中任何元素都可当代表元（[x] = [y] 当且仅当 (x,y) ∈ R）。
  • 商集：A/R = { [x]_R | x ∈ A }，即“所有等价类组成的集合”。

例：Z 上模 3 同余的等价类：

[0] = { …, -6, -3, 0, 3, 6, … }
[1] = { …, -5, -2, 1, 4, 7, … }
[2] = { …, -4, -1, 2, 5, 8, … }
商集 Z/≡₃ = { [0], [1], [2] }
几何含义：每个等价类就是“一整块”，把所有整数按“除以 3 的余数”归进三块；商集就是“这三块构成的整体”。物理含义：钟表（模 12）、星期（模 7）、身份证前几位相同则“同省同市”——等价类 = “同一特征的一类对象”。

划分及其与等价关系的一一对应

划分：集合 A 的一族非空子集 π = {A₁, A₂, …, Aₖ}，满足：

  1. 两两不相交：i ≠ j 时 Ai ∩ Aj = ∅；
  2. 并集覆盖全 A：A₁ ∪ A₂ ∪ … ∪ Aₖ = A。

每个 Ai 称为划分的一个块。

核心定理（等价关系 ⇔ 划分）：

  • 给定 A 上的等价关系 R，它的全体等价类 A/R 构成 A 的一个划分；
  • 反过来，给定 A 的一个划分，定义“x ~ y ⇔ x 与 y 在同一个块里”，则 ~ 是一个等价关系。
几何含义：划分 = 把一张纸切成互不重叠的碎片，碎片又拼回整张纸（不空、不交、并起来是全）。等价关系与划分是同一件事的两种说法：“等价”给出分类规则，“划分”给出分类结果。物理含义：聚类、按属性分组、等价分区（如磁盘分区、学生按班级分组）：每一个“类”就是一块，分类标准就是等价关系。

4.5 偏序关系

偏序与偏序集

同时满足自反 + 反对称 + 传递的关系，称为偏序关系，通常记作 ≼（读作“小于等于”的抽象推广）。集合 A 连同其上的偏序 ≼ 记为偏序集 (A, ≼)。

  • 例 1：实数集 R 上的 ≤。
  • 例 2：正整数集上的整除关系 |（a | b 表示 a 整除 b）。
  • 例 3：某集合的幂集上的包含关系 ⊆。

可比与不可比：若 x ≼ y 或 y ≼ x，称 x 与 y 可比；否则不可比。例：整除关系下，2 与 3 不可比（2 不整除 3，3 也不整除 2）。

全序（线性序）：若 A 中任意两个元素都可比，则称 ≼ 为全序。例：R 上的 ≤ 是全序；整除关系只是偏序、不是全序。

哈斯图（Hasse 图）

哈斯图是偏序的“精简关系图”，规则：

  1. 省略所有自环（自反隐含）；
  2. 省略所有传递边（传递隐含）；
  3. 箭头隐含为“自下而上”，只保留“覆盖关系”（x 直接覆盖 y：x ≺ y 且中间没有第三个元素）。

例：偏序集 ({1, 2, 3, 6}, |)（整除关系）的哈斯图：

         6
        / \
       2   3
        \ /
         1

读法：边都自下而上——1 | 2、1 | 3、2 | 6、3 | 6；2 与 3 不可比（它们之间无上下边相连）。

几何含义：哈斯图是一张“分层的层次图”：越往上元素“越大”，删去自环、传递边后只保留“直接覆盖”的连线，使层级关系一目了然。物理含义：表达层级 / 优先级 / 依赖顺序——任务之间的先后依赖、软件版本兼容链、生物分类层级（界—门—纲—目—科—属—种）、组织机构图。

偏序集中的特殊元素

设 (A, ≼) 是偏序集，B ⊆ A：

  • 极大元：A 中不存在比它“更大”的元素（不存在 y ≠ x 使 x ≼ y）；极小元：不存在比它更小的元素。
  • 最大元：A 中所有元素都比它小（∀y∈A, y ≼ x）；最小元：所有元素都比它大（∀y∈A, x ≼ y）。
  • 上界：a ∈ A 若 ∀b∈B 有 b ≼ a，则 a 是 B 的上界；下界同理（∀b∈B 有 a ≼ b）。
  • 上确界（最小上界）：B 的所有上界中最小的那个；下确界（最大下界）：B 的所有下界中最大的那个。

例：({1, 2, 3, 6}, |) 中，极大元 = 最大元 = 6，极小元 = 最小元 = 1；对 B = {2, 3}，上界 = {6}，下界 = {1}，上确界 = 6（即 lcm(2,3)），下确界 = 1（即 gcd(2,3)）。

例（极大元 ≠ 最大元）：({2, 3, 6, 12, 18}, |) 中，极大元 = {12, 18}（二者都无更大的倍数），但没有最大元（12 与 18 不可比）；极小元 = {2, 3}，无最小元。

几何含义：在哈斯图中，极大元 = “最顶层、没有向上边”的顶点，极小元 = “最底层、没有向下边”的顶点；最大元是“比所有人都高”的唯一顶点。物理含义：极大元 = 依赖链的“顶端任务/最终目标”（没有谁排在它后面）；上下确界 = 若干元素共同的“最小公共上界 / 最大公共下界”——整除关系里就是最小公倍数 lcm / 最大公约数 gcd，依赖系统里就是“完成所有前置任务的最早时间点”。

关键结论：最大元、最小元若存在必唯一；极大元、极小元可以不唯一。全序中极大元 = 最大元；偏序中二者可能不同（如上例）。

典型例题（自测）

  1. 设 A = {1, 2, 3}，R = {(1,1),(1,2),(2,3)}。写出 R 的关系矩阵，画出关系图；求 R⁻¹、R∘R；判断 R 是否自反、反自反、对称、反对称、传递。
  2. 分别判断下列关系各满足哪些性质（自反/反自反/对称/反对称/传递）：(a) 实数集上的 ≤；(b) 正整数集上的整除 |；(c) 平面直线上的“垂直”；(d) 空关系 ∅。
  3. 证明：整数集 Z 上的“模 4 同余”a ≡ b (mod 4) 是等价关系；写出它的全部等价类与商集 Z/≡₄。
  4. 设 R 是 A 上的等价关系，证明：全体等价类 {[x]_R | x ∈ A} 构成 A 的一个划分。
  5. 画出偏序集 ({1, 2, 3, 6}, |) 的哈斯图；指出极大元、极小元、最大元、最小元；对子集 B = {2, 3}，求其上界、下界、上确界、下确界。
  6. 构造一个偏序集，使它有两个极大元但没有最大元，并说明理由。

常见误区

  • ❌ “对称与反对称是互斥的对立面” → ❌ 恒等关系 IA 既对称又反对称；二者只是“允许/禁止双向箭头”，并不互相排斥。
  • ❌ “一个关系不是自反就一定是反自反” → ❌ 二者都可能不成立：A = {1,2} 上 R = {(1,2)} 既不自反（缺 (1,1),(2,2)）也不反自反（(1,1)∉R 但 (1,2)∈R 与反自反无关，关键是缺自环又不全缺）。
  • ❌ “复合关系 R∘S = S∘R” → ❌ 复合一般不满足交换律，方向与次序都要核对约定。
  • ❌ “传递性只检查相邻两项” → ❌ 只要存在 (x,y)、(y,z) 就必须有 (x,z)，不管 y 是否“相邻”；空关系、单元素关系因“前提不出现”而空真地满足传递。
  • ❌ “等价类只有一个固定代表元” → ❌ 等价类中任何元素都可作代表元：[x] = [y] ⇔ (x,y) ∈ R。
  • ❌ “偏序 = 全序” → ❌ 偏序允许不可比元素：整除关系下 2 与 3 不可比；只有任意两元素都可比的偏序才是全序。
  • ❌ “极大元就是最大元” → ❌ 极大元是“没有比它更大的”，可多个；最大元是“比所有都大”，若存在必唯一。例：({2,3,6,12,18},|) 有两个极大元 12、18，却无最大元。
  • ❌ “上界一定属于子集 B 或一定唯一” → ❌ 上界是 A 中“压住 B 的所有元素”的集合，可多个、可不属于 B；上确界才是其中最小者。
  • ❌ “关系矩阵主对角线全 1 就传递” → ❌ 传递性要看“路径与捷径”，矩阵判据是 R² ⊆ R，不能只盯主对角线。

课本外 · 典故与思考

思等价关系与"分类"：人类认识世界的第一个动作（点击展开）

本章 4.4 的核心定理"等价关系 ⟺ 划分"说的是一件朴素而深刻的事：分类规则与分类结果是同一件事。你定义"怎样算同一类"，就等于把集合切成块；反过来，任何一盒互不相交的块，都自动定义了一个等价关系。

历史上最伟大的分类工程之一是林奈（1707–1778）的生物分类学：他在 18 世纪中叶的《自然系统》中建立"属 + 种"的双名法和界门纲目科属种的层级——每一层都是一次"按等价类合并"，把当时已知的几十万种生物理成一座层级树。

现代世界里这条定理无处不在：

  • 数据库的 GROUP BY 按字段把记录归成等价类，再对每个类做统计；
  • 程序语言的"类型系统"把值按行为等价分类——类型就是商集的别称；
  • 本章 4.4 的"模 n 同余"把全体整数切成 n 个等价类，整个同余算术都在这张商集上运行（还记得钟表吗？）。
一句话总结：等价关系 = "什么算同一类"的规则；林奈的分类学、数据库的分组、语言的类型系统，全都是同一条定理的实例。
典偏序与拓扑排序：谁先做、谁后做（点击展开）

本章 4.5 的偏序允许"不可比"：整除关系下 2 和 3 无法比较大小。而现实世界里的"依赖"几乎都是偏序——课程先修、编译依赖、施工工序、菜谱步骤，它们的共同问题不是"比大小"，而是"能不能排出先后、怎么排"。

1962 年，A. B. Kahn 在一篇关于大型网络排序的论文里给出了经典的拓扑排序算法：不断找出"没有前驱"（所有前置已完成）的任务先做，做完删掉它，反复直到全部排完。它和你头脑中的直觉完全一致——就像考试周排复习计划：先复习没有前置的科目，再复习被它们支撑的科目。

三个值得记住的结论：

  • 同一个偏序可以有多个合法拓扑序（先修顺序往往不唯一）；
  • 依赖图无环是"能排出来"的充要条件；
  • 一旦出现环，就意味着互相等待——操作系统里的死锁就是任务依赖成环的经典下场。

所以编译器的头文件顺序、工程项目的关键路径、甚至你早上"先穿袜还是先穿鞋"的困扰，本质都是同一个问题：在偏序里找一条不违背任何依赖的线性队伍。

一句话总结：偏序回答"谁先谁后"，拓扑排序回答"能不能排、怎么排"——工程里的任务调度就是最日常的偏序运算。

本章练习卷（含答案）

一、练习题

  1. 设 A = {1, 2, 3}，R = {(1,2),(2,1),(2,2),(3,3)}。写出 R 的关系矩阵并画出关系图；分别判断 R 是否自反、反自反、对称、反对称、传递。
  2. 设 A = {a, b, c}，R = {(a,b),(b,c)}。求 R ∘ R，并用“关系图走两步”的几何含义解释结果。
  3. 设 A = {1, 2, 3}，R = {(1,2),(1,3),(2,3)}。写出逆关系 R⁻¹，并说明 R⁻¹ 的关系矩阵与 R 的关系矩阵之间的几何关系（转置）。
  4. 分别判断实数集 R 上的“<”关系与“≤”关系各满足哪些性质（自反/反自反/对称/反对称/传递）；其中哪一个是全序？
  5. 证明整数集 Z 上的“模 4 同余”（a ≡ b (mod 4)）是等价关系，写出它的全部等价类与商集 Z/≡₄。
  6. 画出偏序集 ({2, 3, 6, 12, 18}, |)（整除关系）的哈斯图；指出极大元、极小元、最大元、最小元；并解释为什么它“有极大元却没有最大元”。

二、参考答案（点击展开）

查看第1题答案

关系矩阵（按 1,2,3 排序）：第1行 [0 1 0]，第2行 [1 1 0]，第3行 [0 0 1]。关系图：顶点 1→2、2→1 成对箭头，顶点 2、3 各有自环，顶点 1 无自环。判定：不自反（缺 (1,1)）；不反自反（有 (2,2)、(3,3)）；对称（(1,2) 与 (2,1) 成对，其余为自环）；不反对称（(1,2)、(2,1) 同在 R 但 1≠2）；不传递（有 1→2→1，却没有直达的 1→1，即缺 (1,1)）。

查看第2题答案

R ∘ R = {(a,c)}。步骤：要 (x,z) ∈ R∘R，须存在中间 y 使 (x,y)∈R 且 (y,z)∈R；取 (a,b) 再 (b,c)，中间元素 b 连接起 a 与 c，得 (a,c)；没有其它以 c 开头的序偶可继续，故只有这一个。几何含义：关系图上“走两步”——从 a 沿箭头到 b，再沿箭头到 c，两段路径拼接后 a 与 c 连通，即 R² 表示“两步可达”。

查看第3题答案

R⁻¹ = {(2,1),(3,1),(3,2)}（把每个序偶的两个元素对调）。R 的关系矩阵为 [0 1 1; 0 0 1; 0 0 0]，R⁻¹ 的关系矩阵是它的转置 [0 0 0; 1 0 0; 1 1 0]，即沿主对角线翻折。几何上：逆关系就是把关系图中所有箭头方向全部反过来。

查看第4题答案

“<”：反自反（x<x 不成立）、反对称（x<y 与 y<x 不可能同时成立，条件前提为空而空真地成立）、传递（x<y 且 y<z ⇒ x<z）；不自反、不对称。“≤”：自反（x≤x）、反对称（x≤y 且 y≤x ⇒ x=y）、传递（x≤y 且 y≤z ⇒ x≤z）；不反自反、不对称。“≤”是全序（任意两实数都可比较），而“<”在教科书上通常看作严格偏序；本题重点是 ≤ 为全序。

查看第5题答案

对任意整数 a，a−a=0 被 4 整除 ⇒ 自反；若 a≡b(mod 4)，则 4|(a−b) ⇒ 4|(b−a) ⇒ b≡a(mod 4)，对称；若 a≡b 且 b≡c(mod 4)，则 4|(a−b)、4|(b−c) ⇒ 4|((a−b)+(b−c))=4|(a−c) ⇒ a≡c(mod 4)，传递。故为等价关系。等价类：[0]={…,−8,−4,0,4,8,…}，[1]={…,−7,−3,1,5,9,…}，[2]={…,−6,−2,2,6,10,…}，[3]={…,−5,−1,3,7,11,…}。商集 Z/≡₄ = {[0],[1],[2],[3]}。

查看第6题答案

整除覆盖关系：2 直接覆盖于 6、3 直接覆盖于 6，6 直接覆盖于 12 与 18（2、3 也都整除 12、18，但经 6 传递，故不画直达边）。哈斯图自下而上：底层并排 2 与 3，向上连到 6，6 再向上分叉连到 12 与 18。元素：极小元 = {2, 3}，极大元 = {12, 18}；无最小元（2 与 3 不可比）、无最大元（12 与 18 互不整除、不可比，不存在一个元素被所有元素整除）。这正说明“极大元（没有比它更大的）可以有多个，而最大元（比所有元素都大）若存在必唯一”。
