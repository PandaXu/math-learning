第8章 树

大学 / 离散数学

一句话总纲：树 = 连通且无回路的图，是"用 n−1 条边把 n 个点连成整体"的最省骨架。本章从无向树出发，层层建立生成树 → 最小生成树 → 根树/二叉树 → 哈夫曼树，让你能在心里"看见"每条边如何像树枝一样分叉而不打结，并理解它在布线、网络、数据结构与数据压缩中的物理意义。

8.1 无向树

定义与等价刻画

无向树（tree）：连通且无回路的无向图。只有 1 个顶点、0 条边的树叫平凡树。由若干棵互不相连的树组成的图（即无回路但可能不连通的图）叫森林（forest）——森林的每个连通分支都是一棵树。

几何含义："无回路"意味着图中没有封闭的环；"连通"意味着从任何一点出发能走到任何另一点。于是树的形状必然像一株倒挂的树枝：从任意一个分叉出去，只会越走越开、永不绕回，任意两点之间有且仅有一条简单通路。

树有多种等价定义，它们从不同角度刻画同一个对象（设 T 是 n 阶 m 边的无向图）：

  • ① T 连通且无回路（原始定义）。
  • ② T 无回路，且 m = n − 1。
  • ③ T 连通，且 m = n − 1。
  • ④ T 无回路，但在任意两个不相邻顶点之间加一条边，恰好形成一条回路。
  • ⑤ T 连通，但删去任意一条边后都不再连通（每条边都是"桥"）。
  • ⑥ T 中任意两个顶点之间存在唯一的简单路径。
关键等式：  一棵 n 阶树  恰好有  m = n − 1  条边
物理含义：m = n − 1 是"连通"的下限——边数再少就连不起来了。所以树是连接 n 个点的最省材料方案：用最少的边（线、管道、导线）把所有人连成一张网。但它没有冗余，任何一条边断了，网络就分裂成两半（单点故障）。

叶与森林

  • 叶（leaf）：度数为 1 的顶点，也叫悬挂点；度数 ≥ 2 的顶点叫分支点（内部结点）。
  • 定理：任何非平凡树至少有 2 个叶。直观地想：树枝的末端一定存在，而且一棵非平凡树至少有两个末端。
  • 森林：无回路的无向图；每个连通分支是一棵树。森林的边数 = 顶点数 − 连通分支数。
        A
       / \
      B   C
     / \   \
    D   E   F

  6 个顶点，5 条边；叶 = { D, E, F }，分支点 = { A, B, C }
几何 + 物理含义：叶是"路的尽头"，分支点是"岔路口"。一张树形网络里，叶就是终端用户（末端节点），分支点就是中转站/交换节点；森林则对应多片彼此独立的网络。

8.2 生成树

定义

若图 G 的一个生成子图（包含 G 全部顶点的子图）T 是树，则称 T 为 G 的生成树（spanning tree）。

存在性定理：无向图 G 有生成树 当且仅当 G 连通。直观地说，把图中每个回路"剪开"一条边，反复剪，直到无回路，剩下的就是生成树。

树枝与弦、基本回路

  • 生成树 T 的边叫树枝（树枝边），共 n − 1 条。
  • G 中不在 T 里的边叫弦，共 m − (n − 1) = m − n + 1 条。
  • 给 T 加上任意一条弦，就会形成唯一的一条回路，称为关于该弦的基本回路。所有 m − n + 1 条弦产生的基本回路构成基本回路系统，其数目 m − n + 1 叫做图的圈秩（cyclomatic number），等于"图里到底有多少个独立的环"。
n 阶 m 边连通图：  树枝 = n − 1 条，  弦 = m − n + 1 条
生成树 = 覆盖所有顶点、只保留 n − 1 条边、没有回路

Cayley 公式

Cayley 公式：n 阶完全图 Kn 的生成树共有 nn−2 棵。

  • K3：31 = 3 棵；K4：42 = 16 棵；K5：53 = 125 棵；K6：64 = 1296 棵。
几何含义：生成树就是从一张密密麻麻的网里抽出一棵覆盖所有结点的"骨架"——把每个环都剪开一条边，剩下 n − 1 条边而不出现任何环。物理含义：现实中网络往往有冗余（备用线路、环状供电），生成树就是其中必须保留的最少骨干线路；弦则是"备用的、剪掉也不影响连通"的冗余边。电网的环网、地铁的环线都可"剪"成一棵生成树来分析与故障定位。

8.3 最小生成树

定义

给图 G 的每条边赋一个权 w(e)（理解为长度、成本、时间），得到带权图。一棵生成树 T 的权 W(T) 定义为它所有边权之和：

W(T) = Σ w(e)   (对 T 的所有边 e 求和)

在所有生成树中，使 W(T) 最小的那棵叫最小生成树（MST，Minimum Spanning Tree）。

几何含义：平面上给定 n 个点，用线段把它们全部连成一个整体，且总长度最短——最小生成树就是"最短连线网络"。物理含义：铺设光缆/管道/电线连接 n 个站点、建设通信网或供水网时，总成本最低的方案就是 MST。

Kruskal 算法（从边入手，贪心）

  1. 把所有边按权从小到大排序。
  2. 依次考察每条边：若把它加进去不形成回路，就选入；否则丢弃。
  3. 重复，直到选出 n − 1 条边为止。

判环通常用并查集（disjoint set / union-find）实现，总复杂度主要花在排序上：O(m log m)。

例：顶点 A,B,C,D,E，边权如下，求 MST。

边：  A-B:1   B-C:3   A-C:4   C-D:2   B-D:5   D-E:1   C-E:6
排序：A-B(1)  D-E(1)  C-D(2)  B-C(3)  A-C(4)  B-D(5)  C-E(6)
选入：A-B(1) → D-E(1) → C-D(2) → B-C(3)   （共 4 = 5−1 条，停止）
MST 边 = { A-B, B-C, C-D, D-E }，总权 = 1+3+2+1 = 7

Prim 算法（从点入手，贪心）

  1. 任选一个顶点作为"已选点集" S 的初始内容。
  2. 每次在所有横跨 S 与 (V−S) 的边中，选权最小的一条，把对端顶点并入 S。
  3. 重复 n − 1 次，直到所有顶点并入。

对上面的例子从 A 出发：A→B(1)，B→C(3)，C→D(2)，D→E(1)，得到同一棵总权为 7 的 MST。

破圈法（Cycle-breaking）

在图中任取一个回路，删去该回路上权最大的那条边；反复进行，直到图中无回路。剩下的就是一棵最小生成树。

为什么贪心是对的？唯一性

贪心正确性的两大支柱：

  • 割性质（cut property）：设 S 是顶点集的任意真子集，e 是横跨割 (S, V−S) 的权最小边，则存在一棵 MST 包含 e。
  • 回路性质（cycle property）：设 C 是图中一个回路，e 是 C 上权最大的边，则存在一棵 MST 不含 e。

唯一性：若所有边权互不相同，则最小生成树唯一；若存在相同边权，则 MST 可能不唯一，但最小总权是唯一的。

8.4 根树与二叉树

根树及其术语

若有向图满足：恰有一个顶点入度为 0（称为根），其余每个顶点入度均为 1，则称它为根树（rooted tree）。把每条边的方向都看作"从父指向子、远离根"，一棵无向树只要指定一个根，就唯一地确定了方向，成为根树。

  • 根：入度为 0 的唯一顶点；叶：出度为 0 的顶点；内部结点/分支点：出度 > 0 的顶点。
  • 父、子、兄弟：有向边 (u,v) 中 u 是 v 的父亲，v 是 u 的儿子；同一父亲的儿子互为兄弟。
  • 祖先、后代：沿"父亲"方向向上走到的都是祖先；沿"儿子"方向向下走到的都是后代。
  • 层、高：约定根在第 1 层；顶点所在层数 = 根到它的路径长度 + 1；树的高度 = 最大层数。
  • 子树：以某个顶点为根的根树；删去根后，剩下的每棵根子树构成森林。
几何含义：根树把顶点按"代"分层，是一株有明确上下方向的倒挂树。物理含义：家谱、组织机构图、文件目录、菜单层级、分子结构，都是根树——根是最高祖先/最顶层，叶是最末端的个体/文件。

m 叉树

若根树中每个顶点至多有 m 个儿子，称为 m 叉树；若每个内部结点恰好有 m 个儿子，称为正则 m 叉树（完全 m 叉树）。

定理：正则 m 叉树中，叶子数 t 与内部结点数 i 满足：

t = (m − 1)·i + 1      （m = 2 时退化为 叶子数 = 内部结点数 + 1）

二叉树

二叉树：每个结点至多有 2 个子结点，且左、右子树有顺序之分（可以有右子树而没有左子树）。注意：二叉树不是"度 ≤ 2 的树"，它是有序结构。

基本性质（约定根在第 1 层，深度为最大层数）：

① 第 i 层最多有  2^(i−1)  个结点（i ≥ 1）
② 深度为 k 的二叉树最多有  2^k − 1  个结点
③ 叶子数 n0 = 度2结点数 n2 + 1     即  n0 = n2 + 1
④ 含 n 个结点的完全二叉树，深度 = ⌊log₂ n⌋ + 1
  • 满二叉树（full binary tree）：深度为 k 且有 2k − 1 个结点的二叉树（每一层都满）。
  • 完全二叉树（complete binary tree）：只有最下面两层结点的度数可以小于 2，且最下层的结点都靠左连续排列。

遍历（先序 / 中序 / 后序 / 层序）

  • 先序（preorder）：根 → 左子树 → 右子树。
  • 中序（inorder）：左子树 → 根 → 右子树。
  • 后序（postorder）：左子树 → 右子树 → 根。
  • 层序（level order）：从上到下、从左到右逐层访问。

表达式树：把算式画成二叉树，运算符在内部分支点、运算对象在叶。对表达式 (a + b) × (c − d)：

先序：* + a b − c d      → 前缀式（波兰记法）
中序：a + b × c − d      → 中缀式（还原时需按优先级加括号）
后序：a b + c d − *      → 后缀式（逆波兰记法，计算机求值用它）
几何含义：二叉树的"每个分叉最多两路"使它天然对应二分：左/右、是/否、小/大。物理含义：二叉树是计算机中最重要的结构之一——表达式求值、二叉搜索树（查找）、二叉堆（优先队列）、决策树（分类）、Huffman 编码，全都建立在"左右两分"之上。

8.5 哈夫曼树

带权路径长度 WPL

设一棵二叉树有 n 个带权叶结点，权分别为 w1, …, wn，第 i 个叶到根的路径长度（= 经过的边数 = 编码位数）为 li，定义带权路径长度：

WPL = Σ w_i · l_i   （i = 1 … n）

哈夫曼树（最优二叉树）：给定一组叶的权值，在所有二叉树中使 WPL 最小的那棵。

几何含义：WPL 是"加权深度之和"。要让 WPL 最小，就要让权大的叶子离根近（路径短）、权小的叶子离根远——整棵树像被大权重"压"得重心下沉。哈夫曼树就是"最重心下沉"的带权二叉树。

哈夫曼算法（贪心构造）

  1. 把每个权值各自作为一棵单结点树，构成一个森林。
  2. 反复取出根权最小的两棵树，合并成一棵新树，新树根的权 = 两棵根权之和。
  3. 直到森林只剩一棵树，即得哈夫曼树。
合并规则：  每次取 权最小 的两棵 → 合成一棵（权相加）
新结点权 = 左孩子权 + 右孩子权

前缀码与哈夫曼编码

把每个字符对应到叶结点，其出现频率作为权；从根到叶的路径上，向左走记 0、向右走记 1，得到的 0/1 串就是该字符的哈夫曼编码。因为每个字符都在叶上，任何一个码都不会是另一个码的前缀（这叫前缀码），解码时从左到右读就不会产生歧义。

例：字符频率 a:45, b:13, c:12, d:16, e:9, f:5（共 100 个字符）。

合并过程：
 5(f)+ 9(e)=14 → 12(c)+13(b)=25 → 14+16(d)=30 → 25+30=55 → 45(a)+55=100

              (100)
             /     \
          a(45)   (55)
                 /    \
              (25)   (30)
              / \     / \
           c(12) b(13) (14) d(16)
                       / \
                    f(5) e(9)

编码（左 0 右 1）：a=0  b=101  c=100  d=111  e=1101  f=1100
WPL = 45·1 + 13·3 + 12·3 + 16·3 + 9·4 + 5·4 = 224 比特
平均码长 = 224 / 100 = 2.24 位/字符
物理含义：哈夫曼编码是数据压缩的核心思想——高频字符给短码、低频字符给长码，使平均码长最短。它广泛用于文件压缩（如 ZIP）、图像编码（JPEG 的熵编码）、通信传输等。更深一层，哈夫曼树是信息论中"最优前缀码"的构造方法，是最小化编码长度的贪心解。

典型例题（自测）

  1. 一棵树有 5 个顶点，问它有多少条边？最多、最少各有多少个叶？（答：4 条边；叶最少 2 个，最多 4 个。）
  2. 判断正误：若 n 阶 m 边无向图满足 m = n − 1 且无回路，它一定是树吗？若只满足 m = n − 1 呢？（答：前者是（等价定义）；后者未必，还需连通。）
  3. 求完全图 K4 的生成树棵数。（答：42 = 16。）
  4. 对 8.3 节的带权图，分别用 Kruskal、Prim、破圈法求最小生成树，验证总权均为 7。
  5. 深度为 4 的满二叉树有多少个结点？第 4 层最多有多少个结点？（答：24 − 1 = 15；23 = 8。）
  6. 某二叉树有 5 个叶，问度为 2 的结点有多少个？（答：n0 = n2 + 1 ⇒ n2 = 4。）
  7. 给定权 {2, 3, 4, 6}，构造哈夫曼树并求 WPL。（答：先并 2+3=5，再并 4+5=9，再并 6+9=15；WPL = 2·3 + 3·3 + 4·2 + 6·1 = 29。）
  8. 对频率 a:45, b:13, c:12, d:16, e:9, f:5 求哈夫曼编码，并写出 "ab" 的编码与平均码长。（答：a=0, b=101；"ab"=0101；平均码长 2.24。）

常见误区

  • ❌ "树就是没有回路的图" → ❌ 还要连通；无回路但不连通的图是森林。
  • ❌ "有 n − 1 条边就是树" → ❌ 只有 m = n − 1 且连通（或且无回路）才是树，二者缺一不可。
  • ❌ "最小生成树一定唯一" → ❌ 边权有重复时 MST 可能不唯一；只有边权互异时才唯一。
  • ❌ "二叉树就是每个结点度 ≤ 2 的树" → ❌ 二叉树区分左、右，允许只有右子树而无左子树，是有序结构。
  • ❌ "哈夫曼树中权最大的结点离根最远" → ❌ 恰好相反，权越大离根越近（路径越短）；权最小者才最深。
  • ❌ "知道先序和后序就能唯一还原二叉树" → ❌ 先序 + 后序不能唯一确定；必须要有中序（先序+中序 或 后序+中序 才行）。
  • ❌ "哈夫曼编码中高频字符的码更长" → ❌ 高频字符给短码，这才是压缩的关键。
  • ❌ "满二叉树和完全二叉树是一回事" → ❌ 满二叉树每层都满；完全二叉树只要求最下层靠左排列，前面各层满即可。

一、练习题

  1. 一棵树有 8 个顶点。它有几条边？它至少有几个叶？请用本章的等价定义解释为什么边数一定是 7。
  2. 下面哪句话说的是「树」，哪句话说的是「森林」？为什么？(a) 连通且无回路；(b) 无回路但可以不连通。并用「剪断一条边就分裂」这个物理感受，说明树为什么没有冗余。
  3. 一个连通的带权图有 6 个顶点、9 条边。它的任意一棵生成树有几条边？对应有几条「弦」？请结合「骨架 vs 备用线路」的物理含义说一句。
  4. 给定边权：A-B:2，B-C:3，A-C:1，C-D:4，B-D:5。用 Kruskal 算法（从小到大选边、不构成回路）求最小生成树，写出选边顺序与总权。
  5. 某正则 2 叉树（满二叉树）有 7 个内部结点，问它有多少个叶子？并用公式 t = (m−1)·i + 1 验证。
  6. 字符频率为 a:0.4，b:0.2，c:0.2，d:0.1，e:0.1。构造哈夫曼树并求 WPL（以 100 个字符为总频，即 40/20/20/10/10），再说明为什么「高频字符给短码」能压缩数据。

二、参考答案（点击展开）

查看第1题答案

边数 m = n − 1 = 7 条。理由：树的等价定义②说「无回路且 m = n − 1」，等价定义③说「连通且 m = n − 1」，所以任何一棵 n 阶树的边数固定为 n − 1。叶至少 2 个（非平凡树至少有两个叶），本题最多可有 7 个叶（退化成一条链时两端各 1 个叶，中间点度数均为 2，故叶 = 2；要叶最多，需尽量多度数为 1 的点，8 个顶点连成一条链时恰有 2 个叶）。注意：任意 8 阶树的叶数在 2 与 7 之间。

查看第2题答案

(a) 是树：树的原始定义就是「连通且无回路」；(b) 是森林：森林是「无回路但可以不连通」的图，每个连通分支是一棵树。物理含义：树用最少的 n−1 条边把 n 个点连成整体，因此没有冗余——任何一条边都是「桥」，剪断它整张网就裂成两半（单点故障），这正是「没有冗余」的代价。

查看第3题答案

生成树边数（树枝）= n − 1 = 5 条；弦 = m − (n − 1) = 9 − 5 = 4 条。物理含义：生成树是从 9 条边的密网里抽出的、覆盖全部 6 个顶点的 5 条「必留骨干线路」；剩下的 4 条弦是「备用冗余线路」，剪掉也不影响连通，加回去每条都会形成一个基本回路。

查看第4题答案

按权从小到大排序：A-C(1)、A-B(2)、B-C(3)、C-D(4)、B-D(5)。依次选：A-C(1) 选入 → A-B(2) 选入 → B-C(3) 会与 A-C、A-B 构成回路 A-B-C-A，丢弃 → C-D(4) 选入 → B-D(5) 会与已选边构成回路，丢弃（已凑满 3 = 4−1 条边，停止）。最小生成树边 = {A-C, A-B, C-D}，总权 = 1 + 2 + 4 = 7。（用 Prim 或破圈法可得同样总权 7。）

查看第5题答案

正则 m 叉树公式 t = (m−1)·i + 1。m = 2 时退化为 t = i + 1，故叶子数 t = 7 + 1 = 8。验证：t = (2−1)·7 + 1 = 8，即叶子数 = 内部结点数 + 1。物理含义：二叉树每个内部结点「分叉两路」，每多一个分叉点就多出一个末端，所以叶子永远比内部结点多 1。

查看第6题答案

以总频 100 计：a:40, b:20, c:20, d:10, e:10。哈夫曼算法：10(d)+10(e)=20 → 20+20(b)=40（或 20+20(c)）→ 20(c)+40=60 → 40(a)+60=100。令 a 码长为 1、b 与 c 码长为 3、d 与 e 码长为 4（一种最优安排），则 WPL = 40·1 + 20·3 + 20·3 + 10·4 + 10·4 = 40 + 60 + 60 + 40 + 40 = 240 比特，平均码长 = 240/100 = 2.4 位/字符。物理含义：频率高的字符离根近、码短，频率低的字符离根远、码长，使总码长（加权和）最短，这就是「高频短码」实现数据压缩的本质。
