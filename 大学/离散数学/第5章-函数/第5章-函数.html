第5章 函数

大学 / 离散数学

一句话总纲：函数 = 「两个集合之间确定性的对应规则」。学完本章，你要能在心里"看见"两堆点之间的箭头：每个定义域元素恰好射出一支箭；而单射、满射、双射分别回答"陪域里每个点最多 / 至少 / 恰好收到几支箭"；复合函数是箭头路径的首尾串联，反函数是把双射的箭头倒过来；基数则是拿"一一配对"当尺子，去量无穷集合的"大小"。
本章目录 5.1 函数的概念5.2 单射、满射、双射5.3 复合函数与反函数5.4 集合的基数含义总结典型例题常见误区

5.1 函数的概念

定义

设 A、B 是两个非空集合。若存在一个规则 f，使 A 中的每一个元素 x 都对应 B 中唯一确定的元素 y，则称 f 为从 A 到 B 的函数（又称映射），记作：

f : A → B ,   y = f(x)

其中 x 称为自变量（原像），y = f(x) 称为 x 在 f 下的像。

三个核心术语

术语记法含义
定义域dom(f) = A所有"输入"的集合，函数必须对它处处有定义
陪域（到达域）cod(f) = B所有"可能输出"所在的目标集合
值域ran(f) = { f(x) | x ∈ A }所有"实际被射中"的输出构成的集合，值域 ⊆ 陪域

成为函数的两条铁律：① 处处有定义——定义域 A 里每个元素都必须有像，不许"漏人"；② 单值性——每个 x 只能对应唯一一个 y，不许"一对多"。

几何含义：把 A、B 画成两个圈（文氏图），函数就是从 A 出发、指向 B 的一族箭头。铁律①说"A 里每个点都必须射出一支箭"；铁律②说"每个点只能射出一支箭"。方向是单向的：A 的每个点必射出一支箭，但 B 的点可以收到 0 支、1 支或多支箭——这就是"多对一允许，一对多禁止"。判断一个箭头图是不是函数，只看 A 侧是否每点恰好出一箭，完全不用管 B 侧。
物理含义：函数是一台确定性机器（黑箱）：喂进一个输入，吐出一个唯一输出。同一种输入必须产生同一种输出（可重复、可预测），但不同输入可以产出相同输出。例如"身份证号"是一个函数 f(公民) = 号码——每个公民有且仅有一个号码；"考试分数"也是一个函数 f(学生) = 分数，不同学生可以同分（多对一）。而"学生 ⟶ 他的任课老师"就不是函数（一对多）。

相等函数

两个函数 f 与 g 相等，当且仅当三者全同：定义域相同、陪域相同、且对每个 x 都有 f(x) = g(x)。例：f(x) = x² 与 g(t) = t² 在相同定义域、陪域下是同一个函数——变量叫什么名字无关紧要，对应规则才是本质。

5.2 单射、满射、双射

有了函数，进一步按"箭头的落点情况"给函数分类。设 f : A → B。

单射（injective，一对一）

定义：若 A 中不同的元素必有不同的像，即

x₁ ≠ x₂  ⟹  f(x₁) ≠ f(x₂)
（等价于： f(x₁) = f(x₂)  ⟹  x₁ = x₂）

则称 f 为单射。口诀：不重复——没有两个不同的输入撞到同一个输出上。

几何含义：单射 = B 中每个点"至多"收到一支箭。换句话说，箭头落点互不重合、绝不"撞车"。用"水平线测试"看实数函数图像：任意一条水平线至多与图像相交一次。
物理含义：单射 = 信息无损、可逆。因为每个输出都能唯一追溯到输入，所以"看到结果就能反推出原因"。指纹、身份证号、二维码编号、坐标编码都设计成单射——保证不把两个不同对象混淆成同一个。

满射（surjective，映上）

定义：若值域填满整个陪域，即 ran(f) = B，也就是每个 b ∈ B 都至少存在一个 a ∈ A 使 f(a) = b，则称 f 为满射。口诀：不遗漏——B 里没有"空着没人射中"的点。

几何含义：满射 = B 中每个点"至少"收到一支箭。值域恰好等于陪域，箭头把 B 铺得满满的、没有任何漏网之点。水平线测试：任意一条水平线至少与图像相交一次。
物理含义：满射 = 全覆盖、无死角。每个目标状态都"能被达到"。例如"航班 f(出发城市) = 可到达的目的地集合"若要覆盖全国，就需要每个城市都在某条航线终点；又如"哈希桶分配"希望每个桶都能被命中的那种满射性。

双射（bijective，一一对应）

定义：既单射又满射的函数称为双射，也叫一一对应。此时 A 与 B 的元素两两配成对，不多不少。

几何含义：双射 = B 中每个点"恰好"收到一支箭（既是"至多"又是"至少"）。两个集合之间建立了一张完美、无重复、无遗漏的配对表。实数函数图像上：任意一条水平线恰好与图像相交一次。
物理含义：双射 = 可逆变换 / 完美配对。每个输入↔输出唯一互指，可以无损地"正着做"也能"倒着做"：加密与解密、编码与解码、坐标系的来回变换、元素周期表编号与化学元素的对应，本质都是双射。

实例辨析

函数单射？满射？双射？
f : ℤ→ℤ , f(x)=2x✔（2x₁=2x₂⟹x₁=x₂）✘（奇数 3 无原像）✘
f : ℝ→ℝ , f(x)=x²✘（f(1)=f(−1)=1）✘（负数无原像）✘
f : ℝ→[0,+∞) , f(x)=x²✘✔（非负实数都被射中）✘
f : ℝ→ℝ , f(x)=x³✔✔✔
f : ℤ→ℤ , f(x)=x+1✔✔✔
关键点：单射/满射与定义域、陪域的选取强相关。f(x)=x² 把陪域从 ℝ 换成 [0,+∞) 就从"不满射"变成"满射"——判断性质前，先看清楚函数到底是谁到谁。

有限集合的计数结论（为 5.4 铺垫）：若 A、B 都是有限集，则存在 f:A→B 且

  • 单射存在 ⟹ |A| ≤ |B|；
  • 满射存在 ⟹ |A| ≥ |B|；
  • 双射存在 ⟹ |A| = |B|。

直觉：A 每点射一箭、且不撞车，则 B 至少得装下 |A| 个点；B 每点都被射中，则 A 至少得派出 |B| 支箭。

5.3 复合函数与反函数

复合函数（composition）

设 f : A → B、g : B → C（注意 f 的陪域恰是 g 的定义域，才能"接得上"），定义复合：

(g ∘ f) : A → C ,   (g ∘ f)(x) = g( f(x) )

顺序：先作用 f（内层），再作用 g（外层）——从右往左读。
几何含义：复合就是把箭头路径首尾相接：先沿 x → f(x) 这支箭走到 B，再沿 f(x) → g(f(x)) 这支箭走到 C，两步合成一步直达。直观上就是"走完整条流水线"。
物理含义：复合 = 级联系统 / 流水线：先经过一道工序再经过下一道。例如先"加热"再"压缩"是一个复合过程；"摄氏转华氏"与"华氏转开尔文"复合起来就是"摄氏转开尔文"。注意工序顺序不可颠倒——先加热后压缩 ≠ 先压缩后加热。

性质：

  • 结合律：(h ∘ g) ∘ f = h ∘ (g ∘ f)——三台机器串起来，括号怎么加结果一样。
  • 一般不交换：g ∘ f ≠ f ∘ g（甚至 f ∘ g 可能根本没定义）。例：f(x)=x+1、g(x)=x² 时 (g∘f)(x)=(x+1)²，而 (f∘g)(x)=x²+1，两者不同。
  • 复合保持"好性质"：两个单射复合仍是单射；两个满射复合仍是满射；两个双射复合仍是双射。

恒等函数（identity）

函数 idA : A → A 定义为 idA(x) = x——每个点射向它自己。

几何含义：恒等函数是"原地不动"的箭头：A 里每个点都画一支指向自己的小环。它是复合运算里的"乘法单位元"——任何函数先/后复合恒等函数都等于它自己：f ∘ idA = f = idB ∘ f。
物理含义：恒等变换 = 空操作 / 原样输出，像把文件"原样拷贝"一遍、坐标不动的"零位移"。

反函数（inverse function）

定义：若 f : A → B 是双射，则存在唯一函数 f⁻¹ : B → A，满足：

f⁻¹ ∘ f = idA   且   f ∘ f⁻¹ = idB

即：f⁻¹(f(x)) = x（∀x∈A），  f(f⁻¹(y)) = y（∀y∈B）

f⁻¹ 称为 f 的反函数。求法：由 y = f(x) 把 x 解成 y 的表达式，再交换 x 与 y。

核心定理：f 有反函数 ⟺ f 是双射。单射保证"倒过来的箭头不撞车"，满射保证"倒过来的箭头不漏发"——二者缺一不可。

几何含义：反函数 = 把每支箭头倒过来。双射保证倒转后仍然是一组合法的箭头（B 每点恰好射出一支、A 每点恰好收到一支）。对实数函数，y = f(x) 与 y = f⁻¹(x) 的图像关于直线 y = x 对称——因为反函数就是"把 x 轴角色与 y 轴角色对调"。
物理含义：反函数 = 逆过程 / 解码。编码的逆是解码、加密的逆是解密、压缩的逆是解压。例：摄氏↔华氏互为反函数：F = (9/5)C + 32，其反函数 C = (5/9)(F − 32)；"先把东西放进盒子"与"再从盒子取出"互为反操作。

性质：f⁻¹ 也是双射，且 (f⁻¹)⁻¹ = f；(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹（复合取反要倒序，如同"先穿袜子后穿鞋"的逆是"先脱鞋后脱袜子"）。

5.4 集合的基数

等势与基数（cardinality）

定义：若存在双射 f : A → B，则称 A 与 B 等势（基数相同），记 |A| = |B|。基数就是"集合大小的度量"：有限集合的基数 = 元素的个数；无限集合则用"能否一一配对"来比较。

|A| = |B|  ⟺  存在双射 f : A → B
|A| ≤ |B|  ⟺  存在单射 f : A → B
|A| ≥ |B|  ⟺  存在满射 f : A → B

康托—伯恩斯坦—施罗德定理：若 |A| ≤ |B| 且 |B| ≤ |A|，则 |A| = |B|。这给了我们"双向比较、得出相等"的有力工具。

几何含义：基数就是拿"一一配对"当尺子量集合。两个集合能配对到"一支不多、一支不少"，就一样大；不必真的去"数个数"——这正是它适用于无穷集合的原因：无穷也可以比大小。
物理含义：基数 = 集合的"容量 / 势"。有限集是"能数完的库存量"，无限集则分层次：有的无限"能列成一张无穷清单"，有的无限"稠密到连清单都写不下"。

可数集（countable）

与自然数集 ℕ 等势的集合称为可数（可列）集，其基数记作 ℵ₀（读"阿列夫零"）。等价地说：能把集合所有元素排成一列 a₁, a₂, a₃, …（给每个元素编上自然数号）。

ℤ 可数：0, 1, −1, 2, −2, 3, −3, …      （交错编号）

ℚ 可数：按"分子+分母之和"分层、康托对角线法逐一编号
（把每个有理数 p/q 写进一张无限表格，沿斜线 zigzag 走位，逐个数到）

惊人结论：|ℕ| = |ℤ| = |ℚ| = ℵ₀——整数、有理数虽然"看起来比自然数多"，但都能与自然数一一配对，属于同一个"无穷"层级。直观原因：无穷集合的"整体可以等于它的一部分"——希尔伯特旅馆：一家有无限个房间、且已客满的旅馆，只要让 1 号房客搬到 2 号、2 号搬到 3 号…… 就总能腾出 1 号房塞进新客人，人数却"没变多"。

不可数集（uncountable）

实数集 ℝ 不可数——不存在从 ℕ 到 ℝ 的双射。康托用对角线法证明（以区间 (0,1) 为例）：

假设 (0,1) 可数，把所有小数排成一行一行：

  0.a₁₁ a₁₂ a₁₃ a₁₄ …
  0.a₂₁ a₂₂ a₂₃ a₂₄ …
  0.a₃₁ a₃₂ a₃₃ a₃₄ …
     ⋮

取"对角线"上的数字 a₁₁, a₂₂, a₃₃, …，
把每一位都换成一个不同的数字，得到一个新小数 0.b₁b₂b₃…。
它与表中每一行都在"第 i 位"上不同 → 不在表中 → 矛盾！

因此 (0,1)（进而 ℝ）不可数，其基数记作 c（连续统的势，c = |ℝ|）。且有 |ℝ| > |ℕ|，即 ℵ₀ < c——存在严格更大的无穷。

(0,1) 与 ℝ 等势：f(x) = tan( π·(x − 1/2) )
（把有界区间"拉长"成整条实数轴，是一条双射）
几何含义：可数集 = 点能"一个一个排成队伍编号"（离散、可枚举）；不可数集 = 点稠密到无法编号——实数轴上的点比自然数多出整整一个层级，无论怎么排队编号都必有漏网之鱼。
物理含义：可数 ↔ "离散可计数"（自然数、整数、有理数——信息上可编号存储）；不可数 ↔ "连续体"（时间轴、空间位置、温度读数的连续取值——无法用一张无穷编号表穷尽）。这正是物理里"离散量 vs 连续量"的数学根基。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
函数从定义域出发、指向陪域的一族箭头（每点恰好一箭）确定性黑箱：同输入必同输出
单射落点不重合——B 每点至多收到一支箭信息无损、可逆（指纹、编号）
满射箭头铺满 B——B 每点至少收到一支箭全覆盖、每个状态都能被达到
双射完美配对——B 每点恰好收到一支箭可逆变换：加密↔解密、编码↔解码
复合函数箭头路径首尾相接（走完整条链）级联流水线：多道工序顺序叠加
反函数把双射的箭头倒过来（关于 y=x 对称）逆过程 / 解码、解压、逆变换
恒等函数每点指向自己的小环（不动）空操作、原样输出
基数 / 等势用"一一配对"当尺子量大小集合的容量 / 势（含无穷的分层）
可数集点可排成一列、逐个编号离散、可枚举、可编号存储
不可数集稠密到无法编号连续体（时间、空间的连续取值）

典型例题（自测）

  1. 设 f : ℤ→ℤ, f(x)=2x+1。判断 f 是否为单射、满射、双射，并说明理由。
  2. 设 f : ℝ→ℝ, f(x)=x²−4x+3。它是不是单射/满射？若把定义域、陪域适当限制，能否让它成为双射？（提示：配方）
  3. 求 f(x)=2x+3（ℝ→ℝ）的反函数，并验证 f∘f⁻¹ = id 与 f⁻¹∘f = id。
  4. 设 f(x)=x+1、g(x)=x²（都是 ℝ→ℝ）。求 (g∘f)(x) 与 (f∘g)(x)，并说明两者为何不同。
  5. 证明：全体偶数集 E={0,2,4,6,…} 与 ℕ 等势（写出一个双射）；再说明为何 ℝ 不可数。
  6. 设 A={1,2,3}、B={a,b,c,d}。回答：存在 A→B 的单射吗？满射吗？双射吗？A 与 B 基数关系如何？

常见误区

  • ❌ "函数就是一个公式或一张图像" → ❌ 函数的本质是集合间的确定性对应，完全可以用表格、箭头图、程序表示；公式和图像只是其中两种写法。
  • ❌ "值域 = 陪域" → ❌ 只有满射时值域才等于陪域；一般情况下 ran(f) ⊆ cod(f)。
  • ❌ "单射就是值域填满陪域" → ❌ 那是满射。单射说的是"不同输入给不同输出（落点不重合）"。
  • ❌ "任何函数都有反函数" → ❌ 只有双射才有反函数；f(x)=x²（ℝ→ℝ）没有反函数，限制到 [0,+∞)→[0,+∞) 后才有。
  • ❌ "复合函数满足交换律 g∘f = f∘g" → ❌ 复合一般不交换，甚至 f∘g 可能没定义；顺序从右往左：先 f 后 g。
  • ❌ "复合取反 = 直接各自取反" → ❌ (g∘f)⁻¹ = f⁻¹∘g⁻¹，顺序要倒过来（先脱鞋后脱袜子）。
  • ❌ "所有无穷集合一样大" → ❌ |ℝ| > |ℕ|，无穷也有不同层级（可数 vs 不可数）。
  • ❌ "判断单射满射与定义域陪域无关" → ❌ 同一规则换定义域/陪域，性质会变（如 x² 换陪域后变满射）。

一、练习题

  1. 判断下列对应是否为从 A 到 B 的函数，并指出违反了哪条"铁律"（处处有定义 / 单值性）：① 每个公民 → 他的身份证号；② 每个学生 → 他选修的所有课程；③ 每个自然数 n → n²。用"箭头图"的语言说明理由。
  2. 设 A={1,2,3}、B={a,b,c,d}，箭头规则 f：1→a, 2→b, 3→c。判断 f 是否为单射、满射、双射，并用"B 中每个点收到几支箭"的几何含义解释。
  3. 分别判断 f:ℝ→ℝ, f(x)=x²、f:ℝ→[0,+∞), f(x)=x²、f:ℝ→ℝ, f(x)=x³ 的单射性、满射性、双射性，并结合"水平线测试"的几何含义说明。
  4. 设 f(x)=x+1、g(x)=x²（均为 ℝ→ℝ）。求 (g∘f)(x) 与 (f∘g)(x)，说明两者为何不同，并用"流水线 / 工序顺序"的物理含义解释复合函数顺序不可颠倒。
  5. 求 f(x)=2x+3（ℝ→ℝ）的反函数，并验证 f⁻¹∘f = id 与 f∘f⁻¹ = id。说明为什么只有双射才有反函数（结合"把箭头倒过来"的几何含义）。
  6. 证明全体偶数集 E={0,2,4,6,…} 与 ℕ 等势（写出一个双射）；再概述康托对角线法证明 ℝ 不可数的思路，并用"拿一一配对当尺子"的含义解释可数集与不可数集的本质区别。

二、参考答案（点击展开）

查看第1题答案

① 是函数：每个公民有且仅有一个身份证号，满足"处处有定义"且"单值"；② 不是函数：一个学生可能对应多门课程（一对多），违反单值性——箭头图里该点射出了多支箭；③ 是函数：每个自然数 n 有唯一平方 n²。几何上判断只看定义域一侧：每个点是否恰好射出一支箭。

查看第2题答案

单射（是）：1、2、3 的像 a、b、c 两两不同，落点不撞车；满射（否）：d 没有原像，收到了 0 支箭，不满足"每个点至少一支"；故不是双射。几何含义：B 中 a、b、c 各收到恰好一支箭、d 收到 0 支——每点"至多"一支（单射）成立，但并非每点"至少"一支（满射）不成立。有限集结论也印证：|A|=3 < |B|=4，只能有单射、不可能有满射/双射。

查看第3题答案

① f:ℝ→ℝ, f(x)=x²：非单射（f(1)=f(−1)=1 落点撞车）、非满射（负数无原像）；水平线 y=1 与图像交两点，y=−1 交 0 点。② f:ℝ→[0,+∞), f(x)=x²：仍非单射（±x 同像），但满射——每个 y≥0 都有原像 ±√y，值域 = 陪域；说明换陪域后性质改变。③ f:ℝ→ℝ, f(x)=x³：单射（x₁³=x₂³⟹x₁=x₂）且满射（每个实数有唯一立方根），故双射；每条水平线恰好与图像相交一次。

查看第4题答案

(g∘f)(x)=g(f(x))=g(x+1)=(x+1)²=x²+2x+1；(f∘g)(x)=f(g(x))=f(x²)=x²+1。两者不同，因为复合一般不交换，顺序从右往左读：先作用内层 f、再作用外层 g。物理含义如同流水线："先 +1 再平方"与"先平方再 +1"是两道工序顺序相反的两条流水线，最终产品不同；几何上是箭头路径首尾相接，路径的先后次序变了，终点就不同。

查看第5题答案

由 y=2x+3 解出 x=(y−3)/2，交换 x、y 得 f⁻¹(x)=(x−3)/2。验证：f⁻¹(f(x))=(2x+3−3)/2=x；f(f⁻¹(x))=2·(x−3)/2+3=x，故 f⁻¹∘f=id 且 f∘f⁻¹=id。只有双射才有反函数：单射保证"倒转箭头不撞车"（每点至多一箭），满射保证"倒转箭头不漏发"（每点至少一箭），二者合起来才能把每支箭头原样倒过来仍是一组合法箭头；f(x)=x²（ℝ→ℝ）非双射，所以没有反函数。

查看第6题答案

双射 f:ℕ→E, f(n)=2n：每个自然数 n 恰好对应一个偶数 2n，每个偶数又恰好对应其一半，两两配对无重复无遗漏，故 |E|=|ℕ|=ℵ₀。ℝ 不可数：假设 (0,1) 可数并排成一张无限表，取"对角线"上的数字 a₁₁,a₂₂,a₃₃,… 并逐位改成一个不同数字，得到新小数 0.b₁b₂b₃…；它与表中第 i 行在第 i 位都不同，故不在表中，产生矛盾。含义：可数集能"排成一列逐个编号"（离散、可枚举），不可数集稠密到"连无穷清单都写不下"（连续体）；"一一配对"这把尺子量出无穷也有层级，ℵ₀ < c。
