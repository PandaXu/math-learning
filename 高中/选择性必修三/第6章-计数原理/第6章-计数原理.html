第6章 计数原理

高中 / 选择性必修第三册

一句话总纲：计数原理 = 「把可能性一五一十数清楚」的科学。加法原理数「并列的选择」，乘法原理数「串联的步骤」，排列管「顺序」，组合管「搭配」，二项式定理把它们统一成 (a+b)ⁿ 的展开——几何上是「网格、树形图与超立方体」，物理上是「并联/串联路径、抽样与分布」。

6.1 分类加法计数原理与分步乘法计数原理

计数原理是整章的地基。它的任务只有一个：不重、不漏地数出「完成一件事」共有多少种方法。完成一件事的路径，要么是「并列」的（走这条或那条），要么是「串联」的（先走这步再走那步）——前者用加法，后者用乘法。这就是两个基本原理的全部。

分类加法计数原理（加法原理）

完成一件事有两类不同办法：第 1 类办法中有 m₁ 种方法，第 2 类办法中有 m₂ 种方法，且两类办法彼此独立、互不重复，那么完成这件事共有

N = m₁ + m₂

种方法。推广到 n 类办法：

N = m₁ + m₂ + … + mₙ

使用条件（关键！）：

  • 各类办法是相互独立的——用其中任何一类都能「独立完成」这件事（类类独立，用加法）。
  • 各类办法之间没有交叉——任意两种方法不会重复计数（互斥）。
几何含义：不相交集合的并。把「第 i 类办法的所有方法」看成一个点集 Aᵢ。互斥 = 这些集合两两不相交（Aᵢ ∩ Aⱼ = ∅）。加法原理说的就是：不相交集合并集的元素个数 = 各集合元素个数之和，即 |A ∪ B| = |A| + |B|。在平面上画两块不重叠的区域，总点数就是两块点数相加——这就是「并」的几何直观。
物理含义：并联路径的求和。从甲地到乙地，可以坐 3 班火车，也可以坐 2 班飞机，火车和飞机是互斥的两种交通方式，共有 3 + 2 = 5 种走法。电路里的并联：电流可以从 R₁ 走也可以从 R₂ 走，两条支路互不影响，总通路数 = 各支路通路数之和。

分步乘法计数原理（乘法原理）

完成一件事需要两个步骤：第 1 步有 m₁ 种方法，第 2 步（在第 1 步完成后）有 m₂ 种方法，那么完成这件事共有

N = m₁ × m₂

种方法。推广到 n 个步骤：

N = m₁ × m₂ × … × mₙ

使用条件（关键！）：

  • 各步骤相互依存、缺一不可——只有所有步骤都完成，这件事才算完成（步步相关，用乘法）。
  • 每一步的方法数只与「这一步之前已做的选择」有关，第 2 步的方法数 m₂ 是在第 1 步任意一种选择之后都能取的。
几何含义：笛卡尔积与矩形网格。第 1 步的方法集合 A、第 2 步的方法集合 B，它们的有序配对（a, b）构成笛卡尔积 A × B，其元素个数 |A × B| = |A| × |B|。画成坐标网格：横轴是第 1 步的 m₁ 种选择，纵轴是第 2 步的 m₂ 种选择，交点就是「一种完整做法」，共 m₁ × m₂ 个格子——这正是 长 × 宽 = 面积 的几何本质。三步推广到三维，m₁ × m₂ × m₃ = 长方体的体积（格点数）；n 步则是 n 维超矩形网格的格点数。
物理含义：串联步骤的组合。穿衣：3 件上衣 × 2 条裤子 = 6 种完整搭配，上衣和裤子必须同时选定才构成「一套」。电路里的串联：电流要流完整条电路，必须依次通过每一段电阻，任何一个环节断了整条路都不通——所以串联的「完成」是各段选择相乘。

两个原理的统一：树形图（决策树）

把「完成一件事」画成一棵分叉的树：

  • 同一层上的并列分叉（走这根或那根）= 相加。
  • 沿一条路径逐层深入（先这根再那根）= 相乘。

例：从 A 到 B 有 2 条路，从 B 到 C 有 3 条路。树形图第一层 2 叉，第二层每个叉再 3 叉，叶子（终点）共有 2 × 3 = 6 个。可见乘法原理数的是树的叶子数 = 各层分叉数的乘积。

几何含义：树形图把「互斥选择」画成同层分支（并集），把「顺序步骤」画成不同层级（乘积）。加法对应同一层分支求和，乘法对应跨层分支求积——这就是把两个原理统一在一张图里的方法。

6.2 排列

排列的定义

从 n 个不同元素中取出 m 个（m ≤ n），按照一定的顺序排成一列，叫做从 n 个不同元素中取出 m 个元素的一个排列。

「排列」两个字一拆就懂：排（有先后次序）+ 列（排成一列）。顺序不同，就是不同的排列。

排列数公式

从 n 个不同元素中取出 m 个元素的所有不同排列的个数，叫排列数，记作 A(n,m)（课本记作 A_n^m）。

A(n,m) = n·(n−1)·(n−2)·…·(n−m+1) = n!/(n−m)!

为什么这么乘？用乘法原理填 m 个「有编号的位置」：第 1 个位置有 n 种放法，第 2 个位置只剩 n−1 种放法，……，第 m 个位置有 n−m+1 种放法。共 n(n−1)…(n−m+1) 种。

当 m = n 时，是全排列：

A(n,n) = n·(n−1)·…·2·1 = n!

约定 0! = 1（这样 m = n 时 n!/(n−n)! = n!/0! = n! 仍成立）。

几何含义：有序「占位」= 位置与元素的对应。排列的本质是把 m 个不同元素放进 m 个有编号的位置：给 n 个座位安排 m 个人（站成一排），或平面上 n 个不同的点连成「有方向的一串」。全排列 n! 更有深刻的几何意义：n 个顶点的对称群 Sₙ 的阶 = n!——正 n 边形（乃至多面体）的 n 个顶点可以重新贴标签，总共有 n! 种贴法，每一种都是「保持顶点集合不变的重排」。
物理含义：顺序有意义的配置。凡是「换了顺序结果就不同」的物理场景都用排列：运动会 8 人取前 3 名，冠亚季军的排法有 A(8,3) = 8×7×6 = 336 种（第 1 名和第 2 名不能互换）；手机 6 位数字密码的排列；有机分子中原子沿碳链的连接顺序（如丁烷的正丁烷与异丁烷，是碳骨架的连接顺序不同）。

6.3 组合

组合的定义

从 n 个不同元素中取出 m 个元素，不考虑顺序合成一组，叫做从 n 个不同元素中取出 m 个元素的一个组合。

与排列的唯一区别：组合不管顺序。{甲,乙} 与 {乙,甲} 是同一个组合，却是两个不同的排列。

组合数公式

从 n 个不同元素中取出 m 个元素的所有不同组合的个数，叫组合数，记作 C(n,m)（课本记作 C_n^m）。

C(n,m) = A(n,m) / m! = n!/[m!·(n−m)!]

为什么是「排列数 ÷ m!」？先按排列数 A(n,m) 排出所有有序序列，但同一个组合里的 m 个元素可以排成 m! 种不同顺序，这些顺序只对应同一个组合，所以每个组合被重复算了 m! 次，除以 m! 即得组合数。

组合数的两个基本性质

C(n,m) = C(n, n−m)            （对称性）
C(n,m) = C(n−1, m) + C(n−1, m−1)   （递推/帕斯卡恒等式）
  • 对称性：C(n,m) = C(n,n−m)。例：C(10,7) = C(10,3)。
  • 递推：把 n 个元素分成「取某一固定元素」与「不取它」两类——取它的有 C(n−1, m−1) 种，不取它的有 C(n−1, m) 种，相加即得。
几何含义：无序选取 = 子集。C(n,m) 就是 n 元集合的 m 元子集个数。对称性 C(n,m)=C(n,n−m) 的几何意义是「选 m 个 = 选剩下的 n−m 个」——每个 m 元子集与其补集一一对应，所以个数相等。递推公式则对应杨辉三角（帕斯卡三角形）：C(n,m) 恰好是杨辉三角第 n 行第 m 个数，每个数 = 左上方两数之和，这一「加法生成」正是帕斯卡恒等式的几何形状。
物理含义：顺序无意义的取样。凡是「只看抽到了谁、不看抽的先后」的场景都用组合：从 10 人中抽 3 人开会 = C(10,3)；n 个人两两握手的次数 = C(n,2)；n 个粒子之间两两相互作用的对数 = C(n,2)；彩票「任选 m 个号码」的中奖组合数也用组合。

排列 vs 组合：一句话区分

区别排列 A(n,m)组合 C(n,m)
是否看顺序看顺序（甲乙 ≠ 乙甲）不看顺序（{甲,乙} = {乙,甲}）
本质有序占位（位置+顺序）无序选子集
关系A(n,m) = C(n,m) × m!　→　先组合选出 m 个，再对这 m 个排序
典型题排队、名次、密码、信号抽签、握手、集合子集、抽样
核心心法：判断用排列还是组合，问一句「交换两个元素，结果变了吗？」变了→排列；没变→组合。

6.4 二项式定理

把 (a+b) 连乘 n 次展开，就得到二项式定理——它是乘法原理与组合数的一次「会师」。

(a+b)ⁿ = C(n,0)·aⁿ + C(n,1)·aⁿ⁻¹b + C(n,2)·aⁿ⁻²b² + … + C(n,k)·aⁿ⁻ᵏbᵏ + … + C(n,n)·bⁿ

即

(a+b)ⁿ = Σ_{k=0}^{n} C(n,k) · aⁿ⁻ᵏ · bᵏ

通项公式（第 k+1 项）：

T_{k+1} = C(n,k) · aⁿ⁻ᵏ · bᵏ        (k = 0, 1, 2, …, n)

展开式共有 n+1 项；C(n,k) 叫二项式系数。

为什么系数是 C(n,k)？把 (a+b)ⁿ 看成 n 个括号 (a+b)(a+b)…(a+b) 相乘，展开时每一项都要从每个括号里二选一：选 a 或选 b。若在 k 个括号里选了 b（其余 n−k 个选 a），就得到 aⁿ⁻ᵏbᵏ。在 n 个括号中选出哪 k 个「取 b」的方法数是 C(n,k)——所以它的系数就是 C(n,k)。这是乘法原理与组合数的直接应用。

二项式系数的性质

  1. 对称性：C(n,k) = C(n,n−k)，展开式系数左右对称。
  2. 增减性与最值：当 k < (n+1)/2 时，C(n,k) 随 k 增大而增大；当 k > (n+1)/2 时随 k 增大而减小。中间项（n 为偶数时恰有一项，n 为奇数时有相邻两项）的二项式系数最大。
  3. 系数和：令 a = b = 1，得 C(n,0)+C(n,1)+…+C(n,n) = 2ⁿ。
  4. 奇偶项系数和相等：令 a = 1, b = −1，得 C(n,0)+C(n,2)+… = C(n,1)+C(n,3)+… = 2ⁿ⁻¹。
几何含义：n 维超立方体的分层。把 (a+b)ⁿ 看作 n 维超立方体——每个因子 (a+b) 是一个维度，该维度「取 a 还是取 b」对应沿这条边走两个方向之一。这个超立方体共有 2ⁿ 个顶点；按「有多少个坐标取 b」分层，恰有 k 个坐标取 b 的顶点共有 C(n,k) 个。于是 aⁿ⁻ᵏbᵏ 的系数 = C(n,k)，而所有系数之和 2ⁿ = 顶点总数。二维看：正方形 (a+b)² 有 2² = 4 个顶点，1 个 a²、2 个 ab、1 个 b²；三维看：正方体 (a+b)³ 有 2³ = 8 个顶点，系数 1、3、3、1 恰好对应「0、1、2、3 个坐标取 b」的顶点个数。杨辉三角就是把每一层超立方体的顶点数逐行摆出来的几何图案。
物理含义：抽样与分布、小量近似。 (1) 二项分布：n 次独立重复试验中「恰好成功 k 次」的概率是 C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ，其系数正是二项式系数——抛 n 枚硬币、放射性物质 n 个原子在时间 t 内衰变 k 个、理想气体分子分布在两半个容器中的方式数，都由它描述。 (2) 小量近似：当 |x| 很小时 (1+x)ⁿ ≈ 1 + nx，这是物理中「线性近似」的源头（如相对论能量 E = mc²·(1 − v²/c²)^(−1/2) ≈ mc² + (1/2)mv² 的展开）。 (3) 广义二项式：把指数 n 推广到任意实数 α，得到无穷级数 (1+x)^α = 1 + αx + α(α−1)/2!·x² + …，是物理中大量幂级数展开的统一工具。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
分类加法原理不相交集合的并：|A∪B|=|A|+|B|互斥路径求和（并联、火车或飞机）
分步乘法原理笛卡尔积与矩形网格：长×宽=面积串联步骤相乘（穿衣搭配、串联电路）

组合无序子集；对称性=子集与补集一一对应顺序无意义的取样（抽签、握手、相互作用对数）
杨辉三角组合数的逐行几何排列（帕斯卡三角形）递推计数的加法生成表
二项式定理n 维超立方体的顶点分层，系数和 2ⁿ=顶点数二项分布、小量近似、广义幂级数展开

典型例题（自测）

  1. 书架上层有 4 本数学书，下层有 5 本语文书。任取一本，共有多少种取法？（加法：4+5=9）
  2. 从甲地到乙地有 2 条路，从乙地到丙地有 3 条路。从甲经乙到丙共有多少种走法？（乘法：2×3=6）
  3. 5 人排队照相，有多少种排法？（全排列 A(5,5)=5!=120）
  4. 从 8 人中选 3 人（a）排成一列领奖；（b）组成一个小组，各有多少种？（a 排列 A(8,3)=336；b 组合 C(8,3)=56）
  5. 求 (x+2)⁴ 展开式中 x² 项的系数。（通项 T_{k+1}=C(4,k)·x⁴⁻ᵏ·2ᵏ，令 4−k=2 得 k=2，系数 C(4,2)·2²=6×4=24）
  6. 证明：C(10,3) = C(10,7)；并计算 C(10,0)+C(10,1)+…+C(10,10)。（对称性；系数和=2¹⁰=1024）

常见误区

  • ❌ 「看到『取』就用组合」 → ❌ 要先判断顺序是否有意义：取了之后还要「排成一列」就用排列，只「合成一组」才用组合。
  • ❌ 「加法原理和乘法原理随便用」 → ❌ 分类要互斥、类类独立才相加；分步要缺一不可、步步相关才相乘。既分不了类又分不了步，往往是题目理解错了。
  • ❌ 「A(n,m) 的连乘有 m 项还是 n 项分不清」 → ❌ 连乘恰好 m 个因子，从 n 一直乘到 n−m+1；不是乘到 1（乘到 1 是全排列 n!）。
  • ❌ 「C(n,m) = A(n,m) 忘除 m!」 → ❌ 组合去掉了顺序，必须除以 m!；「先选后排」时 A(n,m) = C(n,m) × m!。
  • ❌ 「二项式系数 = 项的系数」 → ❌ 二者不同：(x+2)⁴ 中 x² 项的二项式系数是 C(4,2)=6，但项的系数还要乘 2²，等于 24。
  • ❌ 「通项是第 k 项」 → ❌ T_{k+1} 是第 k+1 项（k 从 0 起），求「第 r 项」要令 k = r−1。
  • ❌ 「0! 没有意义」 → ❌ 约定 0! = 1，它让公式 n!/(n−m)! 在 m=n 时保持一致。

课本外 · 典故与思考

趣生日悖论：直觉与数学打架（点击展开）

问题：一间屋子里至少有多少人，才能让"至少有两人生日相同"的概率超过 50%？

直觉会说：一年 365 天，怎么也得一百来人吧？——答案是 23 人。只要 23 人，这个概率就超过了 50%；50 人时已超过 97%。这就是著名的生日悖论（不是逻辑矛盾，只是反直觉）。

用本章的乘法原理一算就懂：先算反面——"没有人生日相同"。第 1 人随便挑一天；第 2 人要避开他，概率 364/365；第 3 人要避开前两人，363/365；……第 n 人 (365−n+1)/365。分步相乘（乘法原理！）再 1 减：

P = 1 − (364/365)·(363/365)·…·(343/365) ≈ 0.507   （n = 23 时）

直觉错在哪：大多数人算的是"有没有人跟我同一天生日"（23 人时约 6%），而问题问的是"任意两人之间有没有相同的"——23 个人两两配对有 C(23,2) = 253 对，基数完全不同。数清楚"数的是什么"，正是本章的看家本领。

一句话总结：23 人同生日概率超过 50%——不是数学疯了，是"两两配对"的计数方式超出了直觉。
典帕斯卡：一场赌局催生了概率论（点击展开）

1654 年，法国赌徒梅雷（Chevalier de Méré）给数学家帕斯卡（Blaise Pascal，1623—1662）写信，请教一个"分赌注问题"：两人赌局因故中断，已经领先的人该按什么比例分走赌注？

帕斯卡与费马通过通信讨论了这个问题，核心办法就是用组合数数出"假如继续赌下去，各种结果各有多少种"，再按比例分钱。这组通信后来被公认为概率论诞生的标志——而"数清结果数"，正是本章的排列与组合。帕斯卡还写了《论算术三角形》（1665 年出版），把组合数与二项式系数系统化——本章 6.3、6.4 节的 C(n,m) 与帕斯卡恒等式，源头都在那里。

一个名不副实的澄清："帕斯卡三角形"并不是帕斯卡首创的。在中国，贾宪（约 11 世纪）早已用"开方作法本源"图求高次开方，杨辉在 1261 年《详解九章算法》中载录并注明出自贾宪，所以它在中国叫"杨辉三角"；波斯数学家欧玛尔·海亚姆（约 1048—1131）也研究过展开式系数。帕斯卡的贡献，是把这张三角表与组合数、概率计算系统地连在了一起。

一句话总结：一场没赌完的赌局，逼出了用组合数计算可能性的概率论；而"帕斯卡三角形"其实姓"杨"。
问洗牌：52! 到底有多大？（点击展开）

把 52 张扑克牌洗乱，得到的顺序有多少种可能？全排列：52! = 52 × 51 × … × 1 ≈ 8.07 × 10⁶⁷。

这个数有多大？地球上所有沙子的总数估计在 10¹⁸ 到 10²¹ 之间，52! 比它大得多得多。哪怕全人类从古至今每秒洗一次牌，洗出的次数也只是 52! 的一个零头——几乎可以断定，世界上从未有过两副完全相同的洗牌顺序（按同样的叠法）。

为什么增长这么快？因为每乘一次，乘数都在变大（1、2、3、…、52），阶乘的"加速"比任何等比数列都猛烈。这提醒我们：

  • 计数不是小事："只多 1 个元素"，全排列就从 51! 变成 52!，扩大了 52 倍；
  • 物理含义：这正是密码、加密系统的安全根基——在极大的排列/组合空间里，暴力枚举是不可能的。
一句话总结：阶乘的增长快得离谱——52 张牌的顺序数，就足以让"撞上相同洗牌"成为几乎不可能的事。

本章练习卷（含答案）

一、练习题

  1. （加法原理）从 A 城到 B 城，可以乘 3 班火车、2 班汽车或 1 班飞机，三种交通方式互不影响。问共有多少种不同的走法？
  2. （乘法原理）某同学有 3 件上衣、4 条裤子、2 双鞋，每次必须同时穿齐上衣、裤子和鞋。问一共能搭配出多少套不同的服装？
  3. （排列）5 位同学站成一排照相，问有多少种不同的排队顺序？
  4. （排列 vs 组合）从 7 名同学中：(a) 选出 3 人组成一个小组（不分先后）；(b) 选出 3 人分别担任班长、副班长、学习委员（职务不同）。问各有多少种选法？并说明为什么 (b) 比 (a) 多。
  5. （二项式定理）求 (2x − 1)⁵ 展开式中 x³ 项的系数。
  6. （几何/物理含义）为什么任意 n 元集合的子集总数等于 2ⁿ？它和二项式系数之和 C(n,0)+C(n,1)+…+C(n,n)=2ⁿ 以及 n 维超立方体的顶点数之间是什么关系？

二、参考答案（点击展开）

查看第1题答案

共有 3 + 2 + 1 = 6 种走法。三种交通方式彼此独立、互斥（坐火车就不会同时坐飞机），属于「类类独立」，用加法原理。

查看第2题答案

共 3 × 4 × 2 = 24 套。上衣、裤子、鞋必须同时选定才算一套完整服装，是「缺一不可」的串联步骤，用乘法原理。

查看第3题答案

A(5,5) = 5! = 5×4×3×2×1 = 120 种。位置有先后次序，交换任意两人的位置结果就不同，所以用全排列。

查看第4题答案

(a) 组合：C(7,3) = 7×6×5/(3×2×1) = 35 种。(b) 排列：A(7,3) = 7×6×5 = 210 种。(b) 比 (a) 多的原因是职务不同、顺序有意义：同一组 3 个人担任不同职务是 3! = 6 种不同安排，所以 A(7,3) = C(7,3)×3! = 35×6 = 210。

查看第5题答案

通项 Tk+1 = C(5,k)·(2x)5−k·(−1)k。要 x³ 项，令 5−k = 3，得 k = 2。系数 = C(5,2)·2³·(−1)² = 10 × 8 × 1 = 80。

查看第6题答案

每个元素都有「取」或「不取」两种选择，n 个元素依次做决定是 n 步乘法，故子集总数为 2×2×…×2 = 2ⁿ。按「取了 k 个元素」把子集分类，含 k 个元素的子集有 C(n,k) 个（k=0,1,…,n），各类互斥、相加得到 C(n,0)+C(n,1)+…+C(n,n)，所以它等于 2ⁿ。几何上，把 (a+b)ⁿ 看成 n 维超立方体：每个维度「取 a 还是取 b」对应沿一条边走两个方向之一，2ⁿ 就是它的顶点总数，而「恰有 k 个坐标取 b」的顶点恰有 C(n,k) 个——这正是二项式定理系数按层分布（杨辉三角）的几何图景。
