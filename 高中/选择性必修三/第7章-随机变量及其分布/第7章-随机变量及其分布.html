第7章 随机变量及其分布

高中 / 选择性必修第三册

一句话总纲：随机变量 = 「把随机结果翻译成数字」。学完本章，你要能在心里"看见"三幅图：一张把样本空间切成互斥小块、再按比例加权求和的全概率图；一根在数轴上挂着概率质量的杆（分布列，期望是它的重心、方差是它绕重心的离散度）；一条关于均值对称、由 σ 决定胖瘦的钟形曲线（正态分布）。一切分布的本质，都是「总质量为 1 的概率，如何在实数轴上摆放」。

7.1 条件概率与全概率公式

7.1.1 先回到「样本空间」

随机试验的所有可能结果构成样本空间 Ω；事件就是 Ω 的某个子集，概率 P(A) 度量事件 A 发生的"可能性大小"。本章的第一张图：把整个样本空间 Ω 看成一块"总面积 = 1"的区域，任何一个事件 A 就是其中的一块子区域，P(A) 就是 A 的面积占比。后面的"几何含义"，全都在这个"面积 / 质量"图像上展开。

7.1.2 条件概率：把范围缩小到 A

定义：设 A、B 是两个事件，且 P(A) > 0。在"A 已经发生"的条件下，B 发生的概率记为 P(B|A)，定义为

P(B|A) = P(AB) / P(A)     (P(A) > 0)

其中 AB = A∩B 表示事件 A 与 B 同时发生。

几何含义：条件概率的本质是"换分母"。原来分母是全图 Ω（面积 1），条件概率把分母换成 A 的面积 P(A)，分子换成 A、B 的重叠部分 P(AB)。所以 P(B|A) 回答的不是"B 有多大"，而是"当世界已经收缩到 A 内部时，B 还占多大分量"。
物理含义：这是"信息带来的概率修正"。例：掷一枚均匀骰子，Ω = {1,2,3,4,5,6}。已知"点数为奇数"(A={1,3,5})，求"点数大于 2"(B={3,4,5,6}) 的条件概率：在 A 的三个结果 {1,3,5} 里，大于 2 的有 {3,5} 两个，故 P(B|A)=2/3。知道"是奇数"后，我们把 4、6 排除，概率从 4/6 修正为 2/3。

7.1.3 乘法公式

P(AB) = P(A)·P(B|A) = P(B)·P(A|B)

推广到多事件（链式法则）：

P(A₁A₂…Aₙ) = P(A₁)·P(A₂|A₁)·P(A₃|A₁A₂)·…·P(Aₙ|A₁…Aₙ₋₁)

物理含义：分步完成一件事，每一步的概率都以前面各步已经发生为条件，逐段相乘。

例：袋中有 3 个红球、2 个白球，不放回地连取两球，求两次都取到红球的概率：P = P(第一红)·P(第二红|第一红) = 3/5 × 2/4 = 3/10。

7.1.4 全概率公式：分块求和

若事件 A₁, A₂, …, Aₙ 两两互斥（Ai∩Aj=∅, i≠j）且并集为 Ω（构成 Ω 的一个"划分 / 完备事件组"），且 P(Aᵢ) > 0，则对任意事件 B：

P(B) = P(A₁)P(B|A₁) + P(A₂)P(B|A₂) + … + P(Aₙ)P(B|Aₙ) = Σᵢ P(Aᵢ)·P(B|Aᵢ)
几何含义：把 Ω 沿 A₁,…,Aₙ 切成互不重叠、拼满全图的若干块。B 的总面积 = 它在每一块里的面积之和；而"B 在 Aᵢ 里的面积" = Aᵢ 的面积 × B 在 Aᵢ 中的占比 = P(Aᵢ)·P(B|Aᵢ)。于是 P(B) = 各块贡献之和。全概率公式就是"把大问题切成互斥的小块，分块计算再加权求和"。
物理含义：经典的"三工厂次品率"问题。某厂产品来自三条产线 A₁、A₂、A₃，产量占比分别是 60%、30%、10%，次品率分别是 1%、2%、3%。任取一件为次品的总概率： P(B) = 0.6×0.01 + 0.3×0.02 + 0.1×0.03 = 0.006 + 0.006 + 0.003 = 0.015 = 1.5%。 本质是"按来源比例加权平均各来源的次品率"——来源 Aᵢ 的权重就是它的产量占比 P(Aᵢ)。

7.1.5 贝叶斯公式（由果溯因，进阶）

P(Aᵢ|B) = P(Aᵢ)·P(B|Aᵢ) / Σⱼ P(Aⱼ)·P(B|Aⱼ)  =  P(Aᵢ)·P(B|Aᵢ) / P(B)

物理含义：已知"结果 B 发生了"，反推"它是哪个原因 Aᵢ 造成的"。接上例：任取一件发现是次品，求它来自三号产线的概率：P(A₃|B) = 0.1×0.03 / 0.015 = 0.2 = 20%。医疗诊断（已知检测阳性，反推患病概率）、信号溯源都靠它。

7.1.6 事件的独立性

若 P(AB) = P(A)·P(B)，称 A、B 相互独立；等价于 P(B|A) = P(B)（A 的发生不影响 B 的概率）。物理含义：两次互不影响的试验（如先后抛两次硬币）。独立时条件概率退化为普通概率。

7.2 离散型随机变量及其分布列

7.2.1 随机变量：把随机结果翻译成数

定义：对随机试验的每个结果 ω，都指定一个实数 X(ω)，就得到一个随机变量 X——它是"样本空间 Ω → 实数 R"的函数。有了它，就能把"事件"用数字表示，进而用求和、期望、方差等数学工具研究随机现象。例：掷两枚硬币，令 X = "正面朝上的枚数"，则 X 取值 0、1、2；"恰好一正一反"这个事件就是 {X=1}。

若 X 的取值是有限个或可列无限个，则称 X 为离散型随机变量。

7.2.2 分布列：概率质量在数轴上的分布

若 X 的取值为 x₁, x₂, …, xₙ，且 P(X=xᵢ)=pᵢ，可列成下表：

Xx₁x₂…xₙ
Pp₁p₂…pₙ

两条性质：

  1. pᵢ ≥ 0（概率非负）；
  2. p₁ + p₂ + … + pₙ = 1（全部可能取值的概率之和为 1）。
几何含义：把总概率 1 想象成"总质量 = 1"，在数轴每个点 xᵢ 处放一个"质量为 pᵢ 的质点"。分布列就是这些质点在实数轴上的摆放图——一根总质量恰为 1 的"概率杆"。后面的期望、方差，全都可以在这根杆上解释为重心与转动惯量。

7.2.3 两点分布（0-1 分布）

只有两个取值 0 与 1，P(X=1)=p，P(X=0)=1-p。物理含义：一次"成功 / 失败"试验——抛一次硬币、抽检一件产品、一次投篮。

7.2.4 数学期望 E(X)：分布的重心

定义：

E(X) = x₁p₁ + x₂p₂ + … + xₙpₙ = Σᵢ xᵢpᵢ
几何含义：把数轴看成一根无质量的杆，在 xᵢ 处挂质量 pᵢ（总质量 1），则 E(X) 恰好是这组质点的重心（质心）坐标——杆在该点处能保持平衡。所以期望也叫"均值"，它刻画分布列的"中心位置"。
物理含义：期望是"长期平均"：把同一试验重复很多很多次，结果的平均值会稳定在 E(X)。例：掷骰子点数的期望 = 1×1/6 + 2×1/6 + … + 6×1/6 = 3.5——虽然骰子永远掷不出 3.5，但大量次数的平均是 3.5。

期望的性质：

E(aX+b) = a·E(X) + b
E(X+Y)  = E(X) + E(Y)      （线性性，恒成立，不要求 X、Y 独立）
若 X、Y 相互独立：E(XY) = E(X)·E(Y)

7.2.5 方差 D(X) 与标准差 σ

定义：

D(X) = Σᵢ [xᵢ − E(X)]² · pᵢ  =  E(X²) − [E(X)]²
σ = √D(X)
几何含义：方差 = 各质点到重心 E(X) 的"距离平方"的加权平均，度量分布列围绕重心的离散（散开）程度。概率质量都挤在重心附近 → 方差小；在两侧摊得很开 → 方差大。
物理含义：方差精确类比转动惯量 I = Σ mᵢ·rᵢ²（质量 × 到转轴距离的平方之和）。方差大 = 质量分散、转动惯性大 = 数据波动大；标准差 σ 是与 X 同量纲的"平均偏离幅度"，更方便与 X 本身比较。

方差的性质：

D(aX+b) = a²·D(X)          （加常数不平移波动，乘 a 把波动放大 a² 倍）
若 X、Y 相互独立：D(X+Y) = D(X) + D(Y)

7.3 二项分布

7.3.1 n 重伯努利试验

伯努利试验 = 只有两个结果（成功 S / 失败 F）的试验，P(S)=p，P(F)=1−p。把同一伯努利试验独立地重复 n 次，就是 n 重伯努利试验。物理含义：连抛 n 次硬币、n 次独立抽检、n 次独立投篮。

7.3.2 二项分布 B(n, p)

设 X = n 重伯努利试验中"成功"的次数，则 X 服从二项分布，记 X ~ B(n, p)：

P(X=k) = C(n,k) · p^k · (1-p)^(n-k) ,   k = 0,1,2,…,n
其中  C(n,k) = n! / [k!·(n-k)!]    （组合数）

推导：某个具体序列"前 k 次成功、后 n−k 次失败"的概率为 p^k(1−p)^(n−k)；而"恰有 k 次成功"的序列共有 C(n,k) 种（从 n 个位置里挑 k 个放成功），它们两两互斥，故概率相加。

几何含义（系数）：这列概率的系数 C(n,k) 正是帕斯卡三角形（杨辉三角）第 n 行的数。把全部 k 的概率加起来，正是二项式定理： [p + (1−p)]ⁿ = Σₖ C(n,k) p^k (1−p)^(n−k) = 1ⁿ = 1 所以二项分布的名字来自"二项式展开"，它的分布列天然满足总概率为 1。
几何含义（形状）：p = 0.5 时分布列关于中点 k = n/2 对称；p ≠ 0.5 时向一侧偏斜；n 越大，柱形图越接近一条光滑的钟形曲线——这正是 7.4 节正态分布的来源。

7.3.3 期望与方差

E(X) = n·p
D(X) = n·p·(1−p)

物理含义：期望 np = "单次成功概率 × 次数"，即平均成功次数；方差 np(1−p) 反映波动——p = 0.5 时波动最大（最不确定），p 越接近 0 或 1 波动越小（结果越可预测）。

7.3.4 最可能成功次数

当 (n+1)p 是整数时，k=(n+1)p 与 k=(n+1)p−1 处概率并列最大；否则在 k = ⌊(n+1)p⌋ 处最大。例：n=20、p=0.5，则 (n+1)p=10.5，最可能 k=10。

7.3.5 与两点分布的关系

两点分布就是 n=1 的二项分布 B(1,p)。二项分布 = 把 n 个独立的两点分布相加（X = X₁ + X₂ + … + Xₙ，每个 Xᵢ ~ B(1,p)）。

7.4 正态分布

7.4.1 正态曲线与正态分布

若随机变量 X 的概率密度函数为

f(x) = 1/(σ·√(2π)) · e^[ −(x−μ)² / (2σ²) ] ,   x ∈ R    (σ > 0)

则称 X 服从参数为 μ、σ² 的正态分布，记 X ~ N(μ, σ²)。连续型随机变量在区间 (a,b) 取值的概率 = 曲线下该区间上的面积：

P(a < X < b) = ∫_a^b f(x) dx
几何含义：正态曲线是一条"钟形曲线"：关于直线 x=μ 对称；在 x=μ 处取到最高点（峰）；向左右两侧无限延伸且逐渐逼近 x 轴但永不相交；整条曲线与 x 轴围成的总面积恰为 1（全概率）。参数 μ 决定峰的位置（左右平移），参数 σ 决定胖瘦（σ 越大越矮胖、越分散；σ 越小越瘦高、越集中）。曲线在 x = μ±σ 处有拐点。
物理含义：大量独立且微小的随机因素叠加后的结果，往往服从正态分布——这是中心极限定理给出的普遍规律。典型例子：测量同一长度的随机误差（小误差多、大误差少、正负对称）、同龄人的身高体重、工业零件的尺寸、考试成绩的分布。以真值 μ 为中心，误差"越靠近 μ 越常见，越远离越罕见"。

7.4.2 参数 μ 与 σ 的几何、物理意义

参数几何含义物理含义
μ对称轴、峰的位置（左右平移量）数据的平均水平（期望）
σ曲线的胖瘦（离散程度）数据的波动幅度（标准差）

7.4.3 标准正态分布 N(0,1) 与标准化

μ=0、σ=1 的正态分布称为标准正态分布，密度为

φ(x) = 1/√(2π) · e^( −x²/2 )

若 X ~ N(μ, σ²)，令

Z = (X − μ) / σ    ⟹   Z ~ N(0,1)

这个"减 μ 再除以 σ"的操作叫标准化。

几何含义：标准化 = 先把曲线平移 μ 个单位让对称轴回到 0，再缩放 1/σ 倍让胖瘦统一成标准形状。于是任意正态分布都能压缩成同一条标准曲线，只需查一张 N(0,1) 表。

7.4.4 3σ 原则（68–95–99.7 规则）

P(μ−σ  < X < μ+σ )  ≈ 0.6827
P(μ−2σ < X < μ+2σ)  ≈ 0.9545
P(μ−3σ < X < μ+3σ)  ≈ 0.9973
物理含义：数据落在均值 ±1σ 内约占 68.3%，±2σ 内约 95.4%，±3σ 内约 99.7%。也就是说几乎全部数据（99.7%）都在均值 ±3σ 之内，超出 3σ 是极罕见的小概率事件——这正是质量管理（六西格玛）与异常检测的依据。

7.4.5 正态分布与二项分布的联系

当 n 很大、p 不极端时，二项分布 B(n,p) 可用正态分布 N(np, np(1−p)) 近似（德莫弗—拉普拉斯中心极限定理）。这正是"二项分布的柱形图 n 越大越像钟形"的数学本质，也是正态分布如此普遍的根本原因。

典型例题（含解答）

例题 1 · 条件概率

掷两枚均匀硬币，已知"至少一枚正面朝上"，求"两枚都正面朝上"的概率。

解：Ω={(正,正),(正,反),(反,正),(反,反)}。A=至少一枚正面={(正,正),(正,反),(反,正)}，P(A)=3/4；B=两枚都正={(正,正)}，AB=B，P(AB)=1/4。故 P(B|A)=P(AB)/P(A)=(1/4)/(3/4)=1/3。

例题 2 · 全概率 + 贝叶斯

某厂三条产线 A₁、A₂、A₃ 产量占比 60%、30%、10%，次品率 1%、2%、3%。(1) 任取一件为次品的概率？(2) 已知取到次品，求它来自三号产线的概率。

解：(1) P(B)=0.6×0.01+0.3×0.02+0.1×0.03=1.5%；(2) P(A₃|B)=0.1×0.03/0.015=20%。

例题 3 · 分布列、期望、方差

袋中有 3 个红球、2 个白球，不放回取 2 球，X=红球数。求 X 的分布列、E(X)、D(X)。

解：P(X=0)=C(2,2)/C(5,2)=1/10；P(X=1)=C(3,1)C(2,1)/C(5,2)=6/10=3/5；P(X=2)=C(3,2)/C(5,2)=3/10。E(X)=0×1/10+1×6/10+2×3/10=12/10=6/5；E(X²)=0×1/10+1×6/10+4×3/10=18/10=9/5；D(X)=9/5−(6/5)²=9/5−36/25=45/25−36/25=9/25。

例题 4 · 二项分布

抛一枚均匀硬币 10 次，X=正面朝上的次数。(1) 求恰有 3 次正面的概率；(2) 求 E(X)、D(X)。

解：X~B(10, 1/2)。(1) P(X=3)=C(10,3)(1/2)¹⁰=120/1024≈0.1172；(2) E(X)=10×0.5=5，D(X)=10×0.5×0.5=2.5。

例题 5 · 二项分布（至少型）

某射手命中率 0.8，独立射击 5 次，求至少命中 4 次的概率。

解：P(X≥4)=P(X=4)+P(X=5)=C(5,4)(0.8)⁴(0.2)+(0.8)⁵=5×0.4096×0.2+0.32768=0.4096+0.32768=0.73728。

例题 6 · 正态分布

某考试成绩 X~N(70, 10²)。求成绩落在 60~80 分之间的概率，并说明 σ 的作用。

解：60=μ−σ，80=μ+σ，故 P(60<X<80)=P(μ−σ<X<μ+σ)≈0.6827。标准化 Z=(X−70)/10，即 P(−1<Z<1)≈0.6827。σ=10 决定分布胖瘦：σ 越大，60~80 这个区间越"宽"、覆盖比例不变，说明数据越分散。

常见误区

  • ❌ "P(B|A) = P(B)/P(A)" → ❌ 分子是 P(AB)（交集），不是 P(B)。只有 A、B 相互独立时才有 P(B|A)=P(B)。
  • ❌ "全概率公式里 Aᵢ 可以随便分、可以有重叠" → ❌ 必须两两互斥且并集为 Ω（完备划分），否则会重复或漏算。
  • ❌ "期望就是概率最大的那个取值" → ❌ 期望是加权平均（重心），可能根本取不到（骰子期望 3.5）。
  • ❌ "方差也满足 D(X+b)=D(X)+b" → ❌ D(X+b)=D(X)（加常数不平移波动）；但 D(aX)=a²D(X)，别忘了平方。
  • ❌ "二项分布 P(X=k) 忘了乘组合数 C(n,k)" → ❌ 恰有 k 次成功有 C(n,k) 种不同顺序，必须相加。
  • ❌ "正态分布里 σ 越大曲线越瘦高" → ❌ σ 越大越矮胖（越分散）；σ 越小越瘦高（越集中）。
  • ❌ "正态曲线在 x=μ±σ 处与 x 轴相交" → ❌ 曲线永远不与 x 轴相交，只无限逼近；μ±σ 是拐点，不是零点。
  • ❌ "D(X+Y)=D(X)+D(Y) 恒成立" → ❌ 需要 X、Y 相互独立才成立。

本章练习卷（含答案）

一、练习题

  1. 掷两枚均匀硬币，已知「至少一枚正面朝上」，求「两枚都是正面朝上」的概率。（条件概率）
  2. 某厂产品来自三条产线 A₁、A₂、A₃，产量占比分别为 60%、30%、10%，次品率分别为 1%、2%、3%。任取一件，求它是次品的概率。（全概率公式）
  3. 袋中有 3 个红球、2 个白球，不放回地取 2 球，令 X 为取到的红球数。写出 X 的分布列，并求 E(X) 与 D(X)。（分布列、期望、方差）
  4. 抛一枚均匀硬币 8 次，令 X 为正面朝上的次数。求 P(X=3)、E(X)、D(X)。（二项分布）
  5. 某射手命中率为 0.6，独立射击 4 次，求至少命中 3 次的概率。（二项分布「至少型」）
  6. 某考试成绩 X ~ N(80, 5²)。求成绩落在 70~90 分之间的概率，并说明 σ=5 在其中的作用。（正态分布与 3σ 原则）

二、参考答案（点击展开）

查看第1题答案

Ω={(正,正),(正,反),(反,正),(反,反)}。A=「至少一枚正面」={(正,正),(正,反),(反,正)}，P(A)=3/4；B=「两枚都正」={(正,正)}，AB=B，P(AB)=1/4。故 P(B|A)=P(AB)/P(A)=(1/4)/(3/4)=1/3。

查看第2题答案

设 B=「任取一件为次品」。由全概率公式：P(B)=P(A₁)P(B|A₁)+P(A₂)P(B|A₂)+P(A₃)P(B|A₃)=0.6×0.01+0.3×0.02+0.1×0.03=0.006+0.006+0.003=0.015=1.5%。

查看第3题答案

P(X=0)=C(2,2)/C(5,2)=1/10；P(X=1)=C(3,1)C(2,1)/C(5,2)=6/10=3/5；P(X=2)=C(3,2)/C(5,2)=3/10。校验：1/10+6/10+3/10=1。E(X)=0×1/10+1×6/10+2×3/10=12/10=6/5；E(X²)=0×1/10+1×6/10+4×3/10=18/10=9/5；D(X)=E(X²)−[E(X)]²=9/5−(6/5)²=9/5−36/25=45/25−36/25=9/25。

查看第4题答案

X ~ B(8, 1/2)。P(X=3)=C(8,3)(1/2)⁸=56/256=7/32≈0.2188。E(X)=np=8×1/2=4；D(X)=np(1−p)=8×1/2×1/2=2。

查看第5题答案

X ~ B(4, 0.6)。P(X≥3)=P(X=3)+P(X=4)=C(4,3)(0.6)³(0.4)+C(4,4)(0.6)⁴=4×0.216×0.4+0.1296=0.3456+0.1296=0.4752。

查看第6题答案

70=μ−2σ，90=μ+2σ，故 P(70<X<90)=P(μ−2σ<X<μ+2σ)≈0.9545。σ=5 决定分布的胖瘦：σ 越大曲线越矮胖、数据越分散；此处 70~90 恰好是「均值 ±2σ」，覆盖约 95.4% 的数据。
