第8章 立体几何初步

高中 / 必修第二册

一句话总纲：立体几何初步 = 把平面几何的「点、线、面」升到空间——用 基本立体图形 刻画形状、用 表面积与体积 刻画大小、用 平行与垂直 刻画位置关系。学完本章，你要能在脑子里"看见"一个立体，再把它算出来。

8.1 基本立体图形

立体几何研究的对象是空间图形——由点、线、面在空间中组织起来的形体。最基础的一类叫基本立体图形，分两大族：多面体与旋转体。

一、多面体：由平面多边形"拼接"而成

多面体：由若干个平面多边形围成的几何体。围成多面体的多边形叫面，两个面的公共边叫棱，棱与棱的公共点叫顶点。

  • 棱柱：有两个面互相平行（称为底面），其余各面都是四边形，且每相邻两个四边形的公共边（侧棱）都互相平行。
  • 棱锥：有一个面是多边形（底面），其余各面都是有一个公共顶点的三角形（侧面）。
  • 棱台：用一个平行于棱锥底面的平面去截棱锥，底面与截面之间的部分。

按底面形状分类：三棱柱/三棱锥/三棱台、四棱柱/四棱锥/四棱台…… 其中长方体、正方体是特殊的四棱柱；正棱柱是底面为正多边形且侧棱垂直于底面的棱柱；正棱锥是底面为正多边形且顶点在底面的射影恰为底面中心的棱锥。

二、旋转体：由平面图形"绕轴旋转"扫出

  • 圆柱：以矩形的一边所在直线为旋转轴，其余三边旋转形成的面所围成的旋转体。
  • 圆锥：以直角三角形的一条直角边所在直线为旋转轴，其余两边旋转形成的面所围成的旋转体。
  • 圆台：以直角梯形垂直于底边的腰所在直线为旋转轴，其余各边旋转形成的面所围成的旋转体。
  • 球：以半圆的直径所在直线为旋转轴，半圆面旋转一周形成的旋转体。球心到球面上任意一点的距离都等于半径。

旋转体的公共元素：轴（旋转所绕的直线）、底面（旋转出的圆面）、侧面（旋转出的曲面）、母线（侧面上与轴平行的线段，如圆柱/圆锥侧面展开图中的线段）。

几何含义：多面体 = "平面多边形一块块拼起来"（面是平的、棱是直的）；旋转体 = "一个平面图形绕定轴转一圈扫过的轨迹"（侧面是曲面）。
物理/现实含义：易拉罐是圆柱、冰淇淋筒是圆锥、漏斗是圆台、篮球是球、金字塔是正四棱锥、三脚架张开的帐篷是棱锥——现实中几乎每个物体都能抽象成某个基本立体图形，这是把世界"建模"的第一步。

8.2 直观图（斜二测画法）

立体图形是三维的，但要画在纸上（二维），必须借助一种约定的"投影"方法，画出来的图叫直观图。

投影的两种方式

  • 中心投影：从一个点（如灯泡、相机）发出的光线投影，如人眼看到的近大远小。
  • 平行投影：平行光线下的投影，又分正投影（光线垂直投影面）与斜投影（光线斜着照）。斜二测画法属于平行投影的一种。

斜二测画法：画水平放置的平面图形

  1. 建系：在已知图形中取互相垂直的 x 轴、y 轴，交于 O。
  2. 画轴：画对应的 x′ 轴、y′ 轴，交于 O′，使 ∠x′O′y′ = 45°（或 135°）。
  3. 定长：平行于 x 轴的线段，长度不变；平行于 y 轴的线段，长度取原来的一半。
直观图中：  x 方向 原长不变（1:1）
            y 方向 缩短一半（1:2）
            夹角 90° → 45°（或 135°）

画空间几何体的直观图时，先画底面（斜二测），再画侧棱——通常加一条 z 轴与 xOy 平面垂直，平行于 z 轴的线段长度保持不变。

几何含义：斜二测是把"正对着看的直角坐标"斜着压扁——纵向缩一半、直角变成 45°，好让眼睛"斜着"也能感受到第三维的深度。
物理/现实含义：工程制图、建筑图纸、CAD 软件把立体零件画到平面，用的正是同一套"投影 + 缩短"思想；你看到的立体素描的"透视感"，本质上也是一种约定投影。

8.3 表面积与体积

研究立体图形的"大小"，就是求表面积（表面积 = 侧面积 + 底面积）与体积。

一、表面积：把侧面"展开"成平面

核心思想是侧面展开图：把曲面/侧面剪开摊平，变成平面图形再求面积。

  • 圆柱：侧面展开是矩形（宽 = 底面周长 2πr，高 = h），S侧 = 2πrh，S = 2πr(r + h)。
  • 圆锥：侧面展开是扇形（半径 = 母线 l，弧长 = 2πr），S侧 = πrl，S = πr(r + l)。
  • 圆台：侧面展开是扇环，S侧 = π(r + r′)l。
  • 球：S = 4πR²（无法展开成平面，用极限法求得）。

直棱柱 S侧 = 底面周长 × 高；正棱锥 S侧 = ½ × 底面周长 × 斜高。

二、体积：底面积 × 高的"累积"

柱体   V = S·h            （圆柱 V = πr²h）
锥体   V = (1/3)·S·h      （圆锥 V = (1/3)πr²h）
台体   V = (1/3)h·(S上 + S下 + √(S上·S下))
球     V = (4/3)πR³

祖暅原理（等积原理）：夹在两个平行平面之间的两个几何体，被平行于这两个平面的任意平面所截，如果截得的截面面积总相等，那么这两个几何体的体积相等。

几何含义：体积 = "截面面积沿高度方向的累积"；祖暅原理说明体积只由"等高处的截面大小"决定，与形体如何倾斜、扭曲无关。锥体是同底等高柱体体积的 1/3（可用三个可拼合的锥体或祖暅原理证明）。
物理/现实含义：容积（杯子能装多少水）、排水法测体积（阿基米德称皇冠）、质量 = 密度 × 体积——体积是把"占多大空间"量化的数字。

8.4 空间点、直线、平面的位置关系

从"形状"转到"位置"：空间图形由点、直线、平面三大基本元素组成，它们之间的相对位置是本章后半部分的基石。

一、平面及其基本性质（三个公理）

平面是无限延展、无厚度的。描述平面（以及空间的点线关系）最基本的依据是三条公理：

  1. 公理1：如果一条直线上的两点在一个平面内，那么这条直线在此平面内。（判断直线在平面内的依据）
  2. 公理2：过不在一条直线上的三点，有且只有一个平面。（"不共线三点确定一个平面"）
  3. 公理3：如果两个不重合的平面有一个公共点，那么它们有且只有一条过该点的公共直线。（两个平面相交于一条直线）

由公理2可推出：经过一条直线和直线外一点、经过两条相交直线、经过两条平行直线，都有且只有一个平面。

物理/现实含义：三脚架、照相机支架为什么用三条腿？因为不共线的三点唯一确定一个平面，三条腿无论地面是否平整都稳稳撑起一个平面；把直尺放在桌面上，只要尺上两点贴桌，整把尺都在桌面内（公理1）。

二、空间两条直线的位置关系

  • 相交：有且只有一个公共点。
  • 平行：在同一平面内，没有公共点。
  • 异面：不同在任何一个平面内，既不相交也不平行。

公理4（平行传递性）：平行于同一条直线的两条直线互相平行。
等角定理：空间中，如果两个角的两条边分别对应平行，那么这两个角相等或互补。

异面直线所成的角：把两条异面直线平移到相交，所成的锐角（或直角）即异面直线所成的角，范围 0° < θ ≤ 90°。这个角是"用平面角度量空间两条不相交直线的夹角"。

三、直线与平面、平面与平面的位置关系

对象位置关系判断标志
直线与平面直线在平面内 / 相交 / 平行有无公共点：无数个 / 一个 / 零个
平面与平面平行 / 相交无公共点 / 有一条公共直线
几何含义：点动成线、线动成面、面动成体；"位置关系"本质是问两个图形有多少个公共点——0 个是平行（或异面）、1 个是相交、无数个是重合/包含。异面直线是空间特有的新现象（平面上不存在），是"升维"带来的关键新概念。

8.5 平行的判定与性质

这一节解决两类问题：如何证明"平行"（判定），以及已知"平行"能得到什么（性质）。思想主线是"降维"——把空间问题化到平面问题。

一、直线与平面平行

判定定理（线线平行 ⇒ 线面平行）：如果平面外一条直线与此平面内的一条直线平行，那么该直线与此平面平行。

a ⊄ α，b ⊂ α，且 a ∥ b   ⟹   a ∥ α

性质定理（线面平行 ⇒ 线线平行）：一条直线与一个平面平行，如果过该直线的平面与此平面相交，那么该直线与交线平行。

a ∥ α，a ⊂ β，α ∩ β = b   ⟹   a ∥ b

二、平面与平面平行

判定定理（线面平行 ⇒ 面面平行）：如果一个平面内的两条相交直线都与另一个平面平行，那么这两个平面平行。

a ⊂ α，b ⊂ α，a ∩ b = P，a ∥ β，b ∥ β   ⟹   α ∥ β

性质定理（面面平行 ⇒ 线线平行）：两个平面平行，如果另一个平面与这两个平面相交，那么两条交线平行。

α ∥ β，γ ∩ α = a，γ ∩ β = b   ⟹   a ∥ b
几何含义：判定的本质是"降维"——要证线面平行，只需在平面内找到一条与之平行的线；要证面面平行，只需找到两条相交的线都平行即可（两条相交直线"代表"了整个平面，这是公理2的威力）。性质的本质是"升维"——由高维平行反推低维平行。
物理/现实含义：楼房的每一层楼板互相平行（面面平行）；推拉门滑轨与地面平行（线面平行）；测量一条直线是否与墙面平行，只需看它是否与墙上某条水平线平行——工程上的"找参照线"就是判定定理。

8.6 垂直的判定与性质

垂直是比平行更"强"、也更常见的位置关系（重力、铅垂线无处不在）。同样分判定与性质两组。

一、直线与平面垂直

定义：如果直线 l 与平面 α 内的任意一条直线都垂直，就说直线 l 与平面 α 互相垂直，记作 l ⊥ α，l 叫平面 α 的垂线。

判定定理（线线垂直 ⇒ 线面垂直）：如果一条直线与一个平面内的两条相交直线都垂直，那么该直线与此平面垂直。

m ⊂ α，n ⊂ α，m ∩ n = P，l ⊥ m，l ⊥ n   ⟹   l ⊥ α

性质定理：垂直于同一个平面的两条直线平行。

a ⊥ α，b ⊥ α   ⟹   a ∥ b

直线与平面所成的角：斜线 l 与其在平面内的射影所成的锐角，范围 0° ≤ θ ≤ 90°（斜足与垂足连线即射影）。
三垂线定理：平面内的一条直线，如果和这个平面的一条斜线的射影垂直，那么它也和这条斜线垂直；逆命题也成立。

二、平面与平面垂直

先引入二面角：从一条直线出发的两个半平面所组成的图形。在棱上任取一点，在两半平面内分别作垂直于棱的射线，所成的角叫二面角的平面角，范围 0° ≤ θ ≤ 180°。

定义：两个平面相交，如果所成的二面角是直二面角（90°），就说这两个平面互相垂直。

判定定理（线面垂直 ⇒ 面面垂直）：一个平面经过另一个平面的垂线，那么这两个平面垂直。

性质定理：两个平面垂直，则一个平面内垂直于交线的直线与另一个平面垂直。

几何含义：线面垂直是"直线与平面内所有直线都垂直"——最强的位置关系；判定再次体现"降维"：只需与两条相交直线垂直即可（两条相交直线足以撑起整个平面）。面面垂直用"二面角 = 90°"来度量，而线面角、二面角都把空间角化成了平面角。
物理/现实含义：铅垂线（重力方向）垂直于水平面，是一切测量的基准；建筑中墙体要垂直于地面、天线杆要垂直于屋顶，靠的就是"与平面内两条相交基线都垂直"来校直；斜面问题中物体受的力沿斜面和垂直斜面分解，正是"线面垂直 + 射影"的应用。

典型例题（自测）

  1. 说出下列实物各近似于哪种基本立体图形：易拉罐、漏斗、足球、金字塔、三角板绕一直角边旋转一周。
  2. 用斜二测画法画边长为 2 的正方形的直观图，求直观图中 y 方向线段的长度，并判断直观图的面积是原图的多少倍。
  3. 已知正方体棱长为 2，求其表面积、体积、外接球的半径与体积。
  4. 一个圆锥的底面半径 r = 3，母线 l = 5，求它的侧面积、全面积和体积（高用勾股定理求）。
  5. 如图，正方体 ABCD–A′B′C′D′ 中，判断：AB 与 CC′ 是何种位置关系？A′B′ 与 CC′ 呢？并求异面直线 A′B 与 B′C 所成的角。
  6. 证明：若一条直线平行于一个平面，则过这条直线的任一平面与该平面的交线平行于这条直线。
  7. 证明：如果一条直线垂直于一个平面内的两条相交直线，那么它垂直于这个平面；并说明为什么"两条相交"不能改成"两条平行"。
  8. 正四棱锥的底面边长为 a，高为 h，求其侧面积与体积。

常见误区

  • ❌ "棱台的上、下底面相似但侧棱必交于一点" → 反过来记反了：棱台由棱锥截得，各侧棱延长后必交于同一点（原棱锥顶点）。
  • ❌ "圆锥的侧面展开图是三角形" → ❌ 是扇形（半径 = 母线，弧长 = 底面周长）。
  • ❌ "斜二测画法中所有线段都缩短一半" → ❌ 只有平行于 y 轴的线段缩短一半，平行于 x 轴（和 z 轴）的长度不变。
  • ❌ "锥体体积 = Sh" → ❌ 锥体是柱体的 1/3：V = (1/3)Sh。
  • ❌ "空间中垂直于同一直线的两条直线互相平行" → ❌ 它们可能相交、平行或异面；正确结论是"垂直于同一平面的两条直线平行"。
  • ❌ "平行于同一平面的两条直线互相平行" → ❌ 不一定，可能相交或异面；平行的传递性只对同一直线成立（公理4）。
  • ❌ "线面垂直只需垂直于平面内一条直线" → ❌ 必须垂直于两条相交直线。
  • ❌ "二面角就是两个平面所成的夹角且一定小于90°" → ❌ 二面角范围是 0° ≤ θ ≤ 180°，可为钝角。

本章练习卷（含答案）

一、练习题

  1. 说出下列实物各近似于哪种基本立体图形：课本、漏斗、篮球、帐篷（四棱锥形），并指出它们的共同特征。
  2. 用斜二测画法画一个边长为 4 的正方形的直观图。平行于 y 轴的线段长度变为多少？直观图面积是原图面积的多少倍？
  3. 一个圆柱的底面半径 r = 2，高 h = 5，求它的侧面积、全面积和体积。
  4. 一个圆锥的底面半径 r = 3，高 h = 4，求它的母线长、侧面积、全面积和体积。
  5. 在正方体 ABCD–A′B′C′D′ 中：① AB 与 CC′ 是何种位置关系？② A′B′ 与 CD 呢？③ 求异面直线 A′B 与 B′C 所成的角。
  6. 证明：若一条直线 l 与平面 α 平行，则过 l 的任一平面 β 与 α 的交线 m 必与 l 平行（线面平行的性质定理）。

二、参考答案（点击展开）

查看第1题答案

课本 ≈ 长方体（特殊四棱柱），漏斗 ≈ 圆台，篮球 ≈ 球，帐篷 ≈ 四棱锥。共同特征：都是封闭的几何体，都由面（平面或曲面）围成；其中长方体、四棱锥是多面体（面为平面多边形），圆台、球是旋转体（由平面图形绕轴旋转而成）。

查看第2题答案

平行于 y 轴的线段缩短为原来的一半，即 4 → 2；平行于 x 轴的线段长度不变，仍为 4。直观图是一个夹角 45° 的平行四边形，其面积 = 底 × 高 = 4 × (2·sin45°) = 4√2，而原正方形面积为 16，所以直观图面积是原图的 4√2/16 = √2/4 倍。

查看第3题答案

侧面积 S侧 = 2πrh = 2π·2·5 = 20π；底面积 2 个 = 2·πr² = 8π；全面积 S = 20π + 8π = 28π。体积 V = πr²h = π·4·5 = 20π。

查看第4题答案

母线 l = √(r² + h²) = √(3² + 4²) = 5。侧面积 S侧 = πrl = π·3·5 = 15π；全面积 S = πr(r + l) = π·3·(3 + 5) = 24π；体积 V = (1/3)πr²h = (1/3)π·9·4 = 12π。

查看第5题答案

① AB 与 CC′ 异面（不同在任何一个平面内，既不相交也不平行）。② A′B′ 与 CD 平行（都在底面内且同为棱，方向一致、无公共点）。③ 平移 B′C 到 A′D（或平移 A′B 到 DC′），则 A′B 与 B′C 所成的角等于正三角形 A′BD（或 A′C′B）的内角，故为 60°。

查看第6题答案

证明：设 l ∥ α，β 为过 l 的任一平面，β ∩ α = m。要证 l ∥ m。反证：若 l 与 m 相交于 P，则 P ∈ m ⊂ α，又 P ∈ l，于是 l 与 α 有公共点 P，与 l ∥ α（无公共点）矛盾。又 l 与 m 同在平面 β 内、无公共点，故 l ∥ m。这正说明“线面平行 ⇒ 线线平行”：过该直线的平面与已知平面的交线必与它平行。
