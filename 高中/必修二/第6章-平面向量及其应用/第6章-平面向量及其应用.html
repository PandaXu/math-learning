第6章 平面向量及其应用

高中 / 必修第二册

一句话总纲：向量 = 「既有大小又有方向、可以自由平移的箭头」。学完本章，你要能把"平移、旋转、伸缩"这些几何变换，以及"位移、力、速度、功"这些物理量，统一成向量的加减、数乘与数量积运算，并最终用向量推导出余弦定理与正弦定理，去解任意三角形。

6.1 向量的概念

为什么需要向量（物理含义）

物理量分两类：

类别定义例子
标量只有大小、没有方向的量质量、温度、时间、功、长度、面积
向量既有大小又有方向的量位移、力、速度、加速度、电场强度
核心直觉：只说"走了 5 米"没有意义，必须说"向东走 5 米"；只说"推了 10 牛的力"不够，必须说"向右推 10 牛"。向量 = 大小 + 方向，方向正是它区别于普通数字的本质。

向量的表示与模

  • 定义：既有大小又有方向的量叫做向量。
  • 几何表示：用有向线段表示——带箭头的线段，箭头所指为方向，线段长度为大小（叫模）。
  • 符号表示：起点为 A、终点为 B 的向量记作 AB→（方向从 A 指向 B）；也常用一个小写字母加箭头表示，如 a→、b→、v→。（印刷体用黑体 a，手写体在字母上方画箭头 a⃗。）
  • 模：向量 a→ 的大小记作 |a→|，恒有 |a→| ≥ 0。
几何含义：向量是"带方向的长度"。有向线段的起点位置不重要，决定向量的是长度（模）与方向。同一个向量可以平移到任何位置而不改变，这是向量与"线段"最大的不同：向量是自由的、可以平移。

零向量与单位向量

  • 零向量：长度为 0 的向量，记作 0→。它的方向是任意的（规定零向量与任何向量平行）。
  • 单位向量：长度为 1 的向量。与 a→ 同方向的单位向量是 a→ / |a→|（把 a→ 缩短到长度为 1 而不改变方向）。
物理含义：单位向量就是"只给方向、不关心大小"的箭头，例如表示"正东方向"的单位向量 e→。任何一个力 F→ 都能写成 F→ = |F→|·e→，即"大小 × 方向"，这是后面所有分解与投影的起点。

相等向量、相反向量、共线向量

  • 相等向量：长度相等且方向相同的向量。几何上，两个相等向量经平移后可以完全重合，记作 a→ = b→。
  • 相反向量：长度相等、方向相反的向量，a→ 的相反向量是 −a→。
  • 平行（共线）向量：方向相同或相反的向量，记作 a→ ∥ b→。它们经平移后能落在同一条直线上，所以也叫共线向量。
几何含义："共线向量"不要求真的在同一直线上——它们只是方向相同或相反，平移后能共线即可。反之，不共线（不平行）的两个向量才能"撑起"整个平面，这正是 6.4 节"平面向量基本定理"的伏笔。

6.2 向量的加减法与数乘

加法：三角形法则与平行四边形法则

三角形法则（首尾相接）：把 b→ 的起点移到 a→ 的终点，则从 a→ 的起点到 b→ 的终点的向量就是 a→ + b→。

三角形法则（首尾相接）：
        C
       / \
 a→+b→/   \ b→
     /     \
    A ——→ B
      a→

平行四边形法则（共起点）：让 a→ 与 b→ 有共同起点，以它们为邻边作平行四边形，对角线（从公共起点出发的那条）就是 a→ + b→。

平行四边形法则（共起点 O）：
    D ───── C
    │  ↗    │
  b→│ / a→+b→
    │/      │
    O ───── A
      a→
物理含义（位移与力的合成）：先向东走 3 km（a→）再向北走 4 km（b→），总位移就是 a→ + b→，大小 = √(3² + 4²) = 5 km。力的合成同理：互成角度的两个力 F1→、F2→ 的合力 = F1→ + F2→，这正是平行四边形定则。

加法运算律：

交换律：a→ + b→ = b→ + a→
结合律：(a→ + b→) + c→ = a→ + (b→ + c→)
几何含义：交换律说明"先走 a→ 再走 b→"与"先走 b→ 再走 a→"到达同一个终点（平行四边形的两条不同路线）；结合律说明多段位移无论怎样分组合成，结果相同。

减法：加相反向量

定义：a→ − b→ = a→ + (−b→)，减去一个向量等于加上它的相反向量。

几何（共起点时）：让 a→、b→ 起点相同，则 a→ − b→ 是从 b→ 的终点指向 a→ 的终点的向量——"终减起"，指向被减向量。

物理含义：减法表示"相对"与"差"。两个物体的速度 v1→、v2→，则 v1→ − v2→ 是物体 1 相对物体 2 的速度（从 v2→ 末端指向 v1→ 末端）；位移之差同样如此。

数乘（伸缩 + 方向控制）

定义：实数 λ 与向量 a→ 的乘积 λa→ 是一个向量：

  • 模：|λa→| = |λ|·|a→|（长度伸缩 |λ| 倍）；
  • 方向：λ > 0 时与 a→ 同向；λ < 0 时与 a→ 反向；λ = 0 时 λa→ = 0→。
几何含义：数乘 = 伸缩 + （可能）反转。2a→ 是拉长到 2 倍；½a→ 是缩短到一半；−a→ 是"翻转方向"（即相反向量）；−2a→ 是先翻转再拉长 2 倍。这正对应初中"乘以负数 = 翻转 + 拉伸"的直觉，如今推广到了整个平面。

数乘运算律：

λ(μa→) = (λμ)a→          （结合律）
(λ + μ)a→ = λa→ + μa→     （对实数分配）
λ(a→ + b→) = λa→ + λb→    （对向量分配）

向量共线定理

定理：向量 a→ 与 b→（b→ ≠ 0→）共线，当且仅当存在唯一实数 λ，使 a→ = λb→。

几何含义：共线 ⇔ 一个向量是另一个的"伸缩"（可含反向）。这是判断三点共线的利器：A、B、C 三点共线 ⇔ AB→ 与 AC→ 共线 ⇔ 存在 λ 使 AB→ = λ·AC→。

6.3 向量的数量积

向量的夹角

把 a→、b→ 平移到同一起点，它们所成的角 θ 叫做 a→ 与 b→ 的夹角，规定 0 ≤ θ ≤ π。

  • θ = 0：同向；θ = π：反向；θ = π/2：垂直，记作 a→ ⊥ b→。

数量积的定义（点乘）

a→ · b→ = |a→| · |b→| · cos θ

结果是一个数（标量），不是向量，所以叫"数量"积，又称点乘、内积。

物理含义（功）：恒力 F→ 作用在物体上产生位移 s→，则力做的功 W = F→ · s→ = |F→||s→|cos θ。cos θ 就是"力在位移方向上的有效分量"：θ = 0 时全力做功；θ = 90° 时（力与位移垂直）不做功。
几何含义（投影）：|a→|cos θ 是 a→ 在 b→ 方向上的投影（数量）。所以 a→·b→ = |b→| × (a→ 在 b→ 方向上的投影)，即"一个向量的模 × 另一个向量在其方向上的投影"。θ 为锐角时投影为正，钝角时投影为负。

数量积的运算律与重要结论

交换律：a→ · b→ = b→ · a→
分配律：(a→ + b→) · c→ = a→ · c→ + b→ · c→
数乘结合：(λa→) · b→ = λ(a→ · b→) = a→ · (λb→)
自身点乘：a→ · a→ = |a→|² ，即 |a→| = √(a→ · a→)
垂直判定：a→ ⊥ b→  ⇔  a→ · b→ = 0

注意

数量积不满足结合律：(a→·b→)·c→ 中的 (a→·b→) 是标量，再乘向量是数乘；而 a→·(b→·c→) 是向量与标量点乘，两者一般不等。消去律也不成立：由 a→·b→ = a→·c→ 且 a→ ≠ 0→，不能推出 b→ = c→（因为"投影相等"不等于"向量相等"）。

夹角公式：cos θ = (a→·b→) / (|a→||b→|)，据此可判断夹角是锐角（cos θ > 0）、直角（= 0）还是钝角（cos θ < 0）。

6.4 平面向量基本定理与坐标表示

平面向量基本定理（平面内一切向量的"地基"）

如果 e1→、e2→ 是同一平面内不共线的两个向量，那么该平面内任一向量 a→ 都能被唯一地表示为：

a→ = x·e1→ + y·e2→
几何含义：两个不共线的向量就像平面上"两把不重合的尺子"，它们的线性组合 x·e1→ + y·e2→ 能"张成"整个平面，且每一点的坐标 (x, y) 唯一。这就是"二维平面需要两个独立方向"的根本原因。

正交分解与坐标表示

取互相垂直的单位向量 i→（沿 x 轴正向）、j→（沿 y 轴正向）为基，则任一向量可唯一写成：

a→ = x·i→ + y·j→  =  (x, y)

(x, y) 就是向量 a→ 的坐标。若 A(x₁, y₁)、B(x₂, y₂)，则 AB→ = (x₂ − x₁, y₂ − y₁)（终点坐标减起点坐标）。

坐标运算（把几何问题化为代数）

设 a→ = (x₁, y₁)、b→ = (x₂, y₂)，则：

加法：a→ + b→ = (x₁ + x₂, y₁ + y₂)
减法：a→ − b→ = (x₁ − x₂, y₁ − y₂)
数乘：λa→ = (λx₁, λy₁)
模：  |a→| = √(x₁² + y₁²)；|AB→| = √((x₂−x₁)² + (y₂−y₁)²)
数量积：a→ · b→ = x₁x₂ + y₁y₂
夹角：cos θ = (x₁x₂ + y₁y₂) / (√(x₁²+y₁²) · √(x₂²+y₂²))
垂直：a→ ⊥ b→  ⇔  x₁x₂ + y₁y₂ = 0
平行（共线）：a→ ∥ b→  ⇔  x₁y₂ − x₂y₁ = 0
核心思想：向量一旦有了坐标，长度、夹角、垂直、平行、共线这些几何问题，全部变成代数计算。这就是解析几何"以数解形"的威力——向量的坐标运算是一座"几何 ↔ 代数"的桥梁。

6.5 正弦定理与余弦定理（向量的应用）

在 △ABC 中，设角 A、B、C 所对的边分别为 a、b、c（a = BC，b = CA，c = AB）。

余弦定理（用数量积推导）

取 A 为起点，设 AB→ = c→、AC→ = b→，则 BC→ = AC→ − AB→ = b→ − c→。两边平方（数量积）：

a² = |BC→|² = (b→ − c→)·(b→ − c→)
   = b→·b→ + c→·c→ − 2·b→·c→
   = b² + c² − 2bc·cos A

余弦定理：

a² = b² + c² − 2bc·cos A
b² = a² + c² − 2ac·cos B
c² = a² + b² − 2ab·cos C

变形求角：cos A = (b² + c² − a²) / (2bc)（其余同理）。

几何含义：余弦定理是勾股定理的推广。当 A = 90° 时 cos A = 0，得 a² = b² + c² 回到勾股定理；A 为锐角时 a² < b² + c²，A 为钝角时 a² > b² + c²。用途：已知两边及夹角求第三边，或已知三边求角。

正弦定理（用面积推导）

三角形面积 S = ½·bc·sin A = ½·ac·sin B = ½·ab·sin C。由此推出：

½bc·sin A = ½ac·sin B   ⇒   b·sin A = a·sin B   ⇒   a/sin A = b/sin B
½ac·sin B = ½ab·sin C   ⇒   c·sin B = b·sin C   ⇒   b/sin B = c/sin C
∴  a/sin A = b/sin B = c/sin C

正弦定理：a/sin A = b/sin B = c/sin C = 2R（R 为外接圆半径）。

几何含义：正弦定理说明"边与其对角正弦之比恒定"，这个比值 = 外接圆直径 2R，是三角形外接圆的一个漂亮性质。用途：已知两角一边，或两边及其中一边的对角，求其余边角。
物理含义（力的分解）：斜面上的物体所受重力 G 可沿斜面方向与垂直斜面方向分解为两个分力，各分力的大小由"力三角形"的正弦（或余弦）关系给出。绳拉物体、船渡河、飞机航线等实际问题，本质都是"用正弦/余弦定理解力三角形或位移三角形"。

解三角形的四种基本情形

已知条件适用定理说明
两边及夹角 (SAS)余弦定理求第三边唯一确定
三边 (SSS)余弦定理求角唯一确定
两角及一边 (AAS/ASA)正弦定理唯一确定
两边及一边对角 (SSA)正弦定理可能两解、一解或无解（需讨论）

典型例题（自测）

例 1（数量积与模）

已知 |a→| = 3、|b→| = 4，夹角 θ = 60°，求 a→·b→、|a→ + b→|、|a→ − b→|。

解：a→·b→ = 3 × 4 × cos 60° = 6；|a→+b→|² = 9 + 16 + 2×6 = 37 ⇒ |a→+b→| = √37；|a→−b→|² = 9 + 16 − 2×6 = 13 ⇒ |a→−b→| = √13。

例 2（坐标运算）

已知 a→ = (2, 1)、b→ = (−1, 3)，求 a→+b→、a→−b→、2a→−3b→、|a→|、a→·b→ 及夹角的余弦，并判断二者是否垂直、是否平行。

解：a→+b→ = (1, 4)，a→−b→ = (3, −2)，2a→−3b→ = (4+3, 2−9) = (7, −7)；|a→| = √5；a→·b→ = 2×(−1) + 1×3 = 1；cos θ = 1 / (√5 · √10) = 1/(5√2) = √2/10。因 a→·b→ = 1 ≠ 0 不垂直；因 x₁y₂ − x₂y₁ = 2×3 − 1×(−1) = 7 ≠ 0 不平行。

例 3（余弦定理）

在 △ABC 中，a = 7，b = 8，c = 5，求角 A。

解：cos A = (b² + c² − a²) / (2bc) = (64 + 25 − 49) / (2×8×5) = 40/80 = 1/2，故 A = 60°。

例 4（正弦定理）

在 △ABC 中，A = 30°，B = 45°，a = 2，求 b。

解：由 a/sin A = b/sin B 得 2/sin30° = b/sin45°，即 2/(1/2) = b/(√2/2) ⇒ 4 = b·√2 ⇒ b = 2√2。

例 5（力的合成——物理应用）

两个力 F1→ = 3 N（向东）、F2→ = 4 N（向北）同时作用于一点，求合力的大小与方向。

解：合力 F→ = F1→ + F2→，两力垂直，|F→| = √(3² + 4²) = 5 N；方向东偏北，tan α = 4/3。

例 6（三点共线）

判断 A(1, 2)、B(3, 6)、C(4, 8) 是否共线。

解：AB→ = (2, 4)，AC→ = (3, 6)，因 2×6 − 4×3 = 0（且 AC→ = (3/2)·AB→），故三点共线。

常见误区

  • ❌ "向量有大小又有方向，所以两个向量可以比大小" → ❌ 向量不能比较大小（方向无从比起），只有模（长度）可以比大小。
  • ❌ "零向量没有方向" → ❌ 零向量的方向是任意的，规定它与任何向量平行。
  • ❌ "共线向量一定在同一条直线上" → ❌ 共线 = 平行，只需方向相同或相反，平移后能共线即可，与位置无关。
  • ❌ "a→·b→ = |a→||b→|" → ❌ 只有同向（θ = 0）时才相等，一般要乘 cos θ；垂直时点积为 0。
  • ❌ "数量积满足结合律：(a→·b→)·c→ = a→·(b→·c→)" → ❌ 不成立，因为 (a→·b→) 是标量，左边是数乘、右边是点乘。
  • ❌ "由 a→·b→ = a→·c→ 且 a→ ≠ 0→ 可得 b→ = c→" → ❌ 消去律不成立，投影相等 ≠ 向量相等。
  • ❌ "由 a→·b→ = 0 得 a→ = 0→ 或 b→ = 0→" → ❌ 也可能 a→ ⊥ b→（两个非零向量垂直时点积也为 0）。
  • ❌ "正弦定理、余弦定理只能用于直角三角形" → ❌ 它们对任意三角形都成立（勾股定理只是余弦定理在 90° 时的特例）。
  • ❌ "两向量平行 ⇔ x₁/x₂ = y₁/y₂" → ❌ 当 x₂ 或 y₂ 为 0 时比例式无意义，应写交叉相乘 x₁y₂ − x₂y₁ = 0。

两个模相等的向量不一定相等：相等向量要求长度相等且方向相同，仅模相等时方向可能不同。两个方向相同的向量也不一定相等，长度还可能不同。零向量的方向是任意的，规定它与任何向量平行。

设向东为 a→、向北为 b→，总位移 s→ = a→ + b→。两段位移垂直，故 |s→| = √(3² + 4²) = 5 km；方向为东偏北，tan α = 4/3。

查看第3题答案

由平面向量基本定理，不共线的 a→、b→ 的线性组合表示唯一，故 λ + 2μ = 0 且 3λ − μ = 0，解得 λ = 0、μ = 0。这说明：不共线向量的线性组合若为 0→，则所有系数必为 0（线性无关），即"两把不重合的尺子"能独立张成整个平面。

查看第4题答案

功 W = F→·s→ = |F→||s→|cos θ = 10 × 5 × cos 60° = 25 J。若力与位移垂直（θ = 90°），cos 90° = 0，故 W = 0，不做功。

查看第5题答案

|a→| = √(3² + 4²) = 5；a→·b→ = 3×2 + 4×(−1) = 2；|b→| = √(2² + (−1)²) = √5；cos θ = 2 / (5·√5) = 2√5/25。因 a→·b→ = 2 ≠ 0 不垂直；因 x₁y₂ − x₂y₁ = 3×(−1) − 4×2 = −11 ≠ 0 不平行。

查看第6题答案

正弦定理：a/sin A = b/sin B，即 4/sin30° = b/sin75°，得 b = 8·sin75° = 8·(√6+√2)/4 = 2(√6+√2)。余弦定理：a² = b² + c² − 2bc·cos A = 64 + 25 − 2×8×5×cos60° = 89 − 40 = 49，故 a = 7。
