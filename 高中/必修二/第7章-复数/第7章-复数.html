第7章 复数

高中 / 必修第二册

一句话总纲：复数 = 「平面上的数」。实数只够填满一条线（数轴），而复数用一个点 (a, b) 填满整个平面：横轴是实轴、纵轴是虚轴，中间的 “+” 把两条轴「缝」成一个二维的数。学完本章，你要能在脑中的复平面上“看见”每一个复数——加法是向量平移、乘法是旋转+伸缩、共轭是关于实轴的镜像、模是到原点的距离。

7.1 复数的概念

为什么要发明复数？（历史的动机）

解一元二次方程 x² = −1 时，任何实数的平方都 ≥ 0，所以在实数范围内它无解。为了让「开平方」对一切数都成立——也为了让三次方程求根公式里的中间量能被统一处理——数学家引入了一个新数：

虚数单位 i：  i² = −1      （即 i = √−1）

于是 x = ±i 就是方程 x² = −1 的两个解。把实数与 i 的「实倍」拼起来，就得到一般的复数：

复数：  z = a + bi    （a、b 都是实数，i 是虚数单位）

实部  Re(z) = a       虚部  Im(z) = b

全体复数组成的集合记作 C（complex）。显然 实数集 R ⊂ 复数集 C：当 b = 0 时，z = a 就是原来的实数。

几何含义：一个复数 a + bi 就是平面上的一个点 (a, b)。实数「躺」在横轴上（b = 0），纯虚数「立」在纵轴上（a = 0），而 i 就是「从原点竖直向上走一个单位」的那一步。复数的 “+” 不是大小相加，而是把「横着的实部」与「竖着的虚部」组合成一个二维位置。
物理含义：一个复数同时携带两个独立信息（实部 + 虚部），天然适合描述「有大小、又有方向/相位」的量——交流电的电压、机械振动、电磁波、量子力学波函数，全都用复数表示：实部记「与参考同相的分量」，虚部记「相位超前/滞后 90° 的分量」。

复数的分类

类型条件例在复平面上的位置
实数b = 03、−2、0横轴（实轴）上
虚数b ≠ 02 + 3i、−i不在实轴上
纯虚数a = 0 且 b ≠ 03i、−i纵轴（虚轴）上

注意：0 = 0 + 0i 是实数（也是唯一的「既实又虚的分界点」，位于原点）。

复数相等的充要条件

a + bi = c + di   ⟺   a = c 且 b = d

两个复数相等，当且仅当它们的实部相等、虚部也相等。特别地：

a + bi = 0   ⟺   a = 0 且 b = 0
为什么不能给复数「比大小」？实数是「一条线」，天然有前后（大小）；复数是「一张面」，点与点之间只有距离、没有先后。所以「3 + 4i 和 5 谁大」是无意义的问题——只有实数才可比较大小。

共轭复数（实轴的“镜像”）

把虚部变号，得到 z = a + bi 的共轭复数，记作 z̄（读作「z 共轭」）：

z = a + bi   ⟶   z̄ = a − bi
  • z + z̄ = 2a（两倍的实部，是实数）；z − z̄ = 2bi（两倍的虚部，是纯虚数）
  • z · z̄ = a² + b² = |z|²（这个结论贯穿全章，务必记住）
  • z = z̄ ⟺ z 是实数；z = −z̄ ⟺ z 是纯虚数
几何含义：共轭就是关于实轴（横轴）的镜像。点 (a, b) 与点 (a, −b) 上下对称，实轴是它们的对称轴。
物理含义：共轭对应「相位取反」。一个沿正向旋转的矢量，其共轭沿反向旋转；在电路里，取共轭常用来消掉虚部、得到实的有功功率（P = Re(V·Ī)）。

7.2 复数的代数运算

复数的运算规则只有一条总原则：把 i 当作一个普通的字母，按多项式运算法则去做，最后用 i² = −1 化简。

加减法：实部加实部，虚部加虚部

(a + bi) ± (c + di) = (a ± c) + (b ± d)i

例：(3 + 2i) + (1 − 4i) = 4 − 2i；(3 + 2i) − (1 − 4i) = 2 + 6i。

几何含义：复数加法 = 两个向量的相加（平行四边形法则）。把 z₁、z₂ 的对应向量首尾相接，和向量就是 z₁ + z₂。减法 = 向量相减，即 z₁ − z₂ 是从 z₂ 指向 z₁ 的向量。
物理含义：同频率的两个正弦信号叠加（干涉、波的叠加），其「振幅+相位」恰好按复数加法合成——这就是为什么交流电路里可用复数（相量）直接相加算合成电压/电流。

乘法：多项式展开 + i² = −1

(a + bi)(c + di) = ac + adi + bci + bdi²
                = (ac − bd) + (ad + bc)i

例：(3 + 2i)(1 − 4i) = 3 − 12i + 2i − 8i² = 3 − 10i + 8 = 11 − 10i。

几何含义（本章核心）：两个复数相乘 = 模相乘、辐角相加，也就是「旋转 + 伸缩」。设 z₁ = r₁(cos θ₁ + i sin θ₁)、z₂ = r₂(cos θ₂ + i sin θ₂)，则
z₁z₂ = r₁r₂ [ cos(θ₁+θ₂) + i sin(θ₁+θ₂) ]。长度变为 r₁r₂，角度变为 θ₁+θ₂。
物理含义：「辐角相加」就是相位相加。信号通过一个电路或滤波环节，输出相对输入的相位差 θ 用「乘一个单位模复数 e^(iθ)」来表示；而「模相乘」表示增益（放大或衰减）。乘法把「放大/衰减」与「移相」一次完成。

i 的幂：周期为 4 的循环

i¹ = i，  i² = −1，  i³ = −i，  i⁴ = 1，  然后 i⁵ = i … 每 4 次循环一次

因此求 iⁿ，只需看 n 除以 4 的余数：i²⁰²⁵：2025 ÷ 4 余 1，所以 i²⁰²⁵ = i。

几何含义：每乘一次 i，就把向量逆时针旋转 90°。乘 4 次正好转回原位（旋转 360°），所以 i 的幂以 4 为周期循环。

共轭运算的性质（共轭“穿过”四则运算）

z₁ ± z₂ 的共轭 = z̄₁ ± z̄₂
z₁ · z₂ 的共轭 = z̄₁ · z̄₂
(z₁ / z₂) 的共轭 = z̄₁ / z̄₂     (z₂ ≠ 0)
z̄̄ = z（取两次共轭回到自身）

除法：分母实数化（乘分母的共轭）

 (a + bi)      (a + bi)(c − di)     (ac + bd) + (bc − ad)i
---------- = ------------------- = ------------------------
 (c + di)      (c + di)(c − di)          c² + d²

核心手法：分子分母同乘分母的共轭 c − di，使分母变成实数 c² + d²。

例：(3 + 2i)/(1 − 4i) = (3 + 2i)(1 + 4i)/(1² + 4²) = (3 + 12i + 2i + 8i²)/17 = (−5 + 14i)/17。

几何含义：除法是乘法的逆：模相除、辐角相减。z₁/z₂ = (r₁/r₂)[ cos(θ₁−θ₂) + i sin(θ₁−θ₂) ]——长度缩小到 r₁/r₂，角度减去 θ₂（即反向旋转）。

复数的模（到原点的距离）

|z| = √(a² + b²)      （z = a + bi）
  • |z| ≥ 0，且 |z| = 0 ⟺ z = 0
  • |z| = |z̄|（镜像不改变距离）
  • |z|² = z · z̄ = a² + b²（是实数，不是复数！）
  • |z₁z₂| = |z₁|·|z₂|；|z₁/z₂| = |z₁|/|z₂|（模乘除 = 长度乘除）
  • 三角不等式：|z₁ + z₂| ≤ |z₁| + |z₂|（两边之和 ≥ 第三边）
几何含义：模 = 复数对应的向量长度 = 该点到原点的距离。它是「绝对值」从一维数轴到二维平面的推广。
物理含义：模就是振幅/幅值。交流电 u = U cos(ωt + φ) 用相量表示时，模 U 即峰值；信号的能量、功率正比于模的平方 |z|²。

7.3 复平面与几何意义

复平面（高斯平面 / 阿尔冈图）：数与形的第二次统一

建立平面直角坐标系，让横轴表示实部（实轴）、纵轴表示虚部（虚轴），这个平面叫复平面。于是：

复数 z = a + bi  ↔  点 (a, b)  ↔  向量 (a, b)（起点在原点）
       虚轴
        ↑
    2i  |     ● (3, 2) = 3 + 2i
        |     |
     i  |     |      r = |z| = √13
        |     |    /
        |     |  /  θ = arg z
   -----+-----|----|---------→ 实轴
        |   O  3
        |
      ● (1, −1) = 1 − i
        |
  • 复数的模 r = |z| = √(a² + b²) 就是向量长度（点到原点距离）。
  • 复数的辐角 θ = arg z 就是向量与实轴正方向之间的夹角（逆时针为正）。
  • 这一一对应关系，让复数的运算全部可以翻译成平面几何的运动——这是复数最深刻的威力所在。
几何含义：这是继「实数 ↔ 数轴」之后，数与形的第二次统一：一次函数、向量、旋转变换、平面几何，全部可以用复数语言改写。旋转、平移、缩放这些几何操作，都变成了复数的乘与加。

三角形式与欧拉公式（极坐标表示）

z = r (cos θ + i sin θ)      r = |z| ≥ 0， θ = arg z

这正是「长度 + 方向」的极坐标写法。由欧拉公式：

e^(iθ) = cos θ + i sin θ    ⟹    z = r · e^(iθ)

三角形式让乘除的几何含义一目了然（见 7.2 节）：乘 = 模乘、角加；除 = 模除、角减。

几个“标志性”复数的几何动作

复数模/辐角几何动作物理动作
1r=1, θ=0不动同相（相位差 0）
ir=1, θ=90°逆时针旋转 90°相位超前 π/2
−1r=1, θ=180°旋转 180°（中心对称）反相（相位差 π）
−ir=1, θ=270°顺时针旋转 90°相位滞后 π/2
1 + ir=√2, θ=45°旋转 45° 并放大 √2 倍相位 +45° 且增益 √2
几何含义：「乘以 i」是整章最漂亮的几何动作——它把任意复数绕原点逆时针转 90°，长度不变。正因如此，虚数单位 i 的本质就是「旋转 90° 的算子」，而不是什么“神秘”的数。
物理含义（旋转矢量法 / 相量法）：交流电 u(t) = U·cos(ωt + φ) 可看作一个以角速度 ω 逆时针旋转的矢量在实轴上的投影。把它冻结在 t=0 时刻，就得到相量 U∠φ = U(cos φ + i sin φ)。复数乘法「模乘、角加」= 物理上「振幅相乘、相位相加」；复数加法 = 同频信号的叠加。

乘方与棣莫弗定理（旋转的加速）

[r(cos θ + i sin θ)]ⁿ = rⁿ [ cos(nθ) + i sin(nθ) ]

即：n 次方 = 模取 n 次方、辐角乘 n。例：(1 + i)² = 2i，把 1 + i（模 √2、辐角 45°）平方后模变 2、辐角变 90°——正好落在正虚轴上的 2i。

几何含义：乘方把「旋转」不断叠加：zⁿ 相当于把 z 的向量连续旋转 n 次 θ、每次同时放大 r 倍。当 r = 1 时，zⁿ 只是绕着单位圆转圈——这正是cos、sin的倍角公式与 n 次方根背后的同一件事。

典型例题（自测）

  1. 设 z₁ = 3 + 2i、z₂ = 1 − 4i，求 z₁ + z₂、z₁ − z₂、z₁·z₂、z₁ / z₂。
  2. 求 i²⁰²⁵ 的值；再求 (1 + i)⁴。
  3. 已知 z = 1 + i，求 |z|、z̄、z · z̄、z / z̄，并在复平面上标出 z 与 z̄ 的位置关系。
  4. 解释为什么「乘以 1 + i」等价于「旋转 45° 并放大 √2 倍」，并算出 (1 + i)² 验证。
  5. 若 z = 2(cos 60° + i sin 60°)，用棣莫弗定理求 z³ 及其模与辐角。
  6. 两个同频交流信号用相量 3 + 4i 和 5 − 12i 表示，求合成信号的相量、模（幅值）与辐角（相位）。

常见误区

  • ❌ 「虚数是“不存在”的数」 → ❌ 虚数只是不在实轴（数轴）上，它活在纵轴方向，和实数同样真实，只是维度多了一维。
  • ❌ 「复数可以比大小」 → ❌ 复数不能比较大小，只有实数才有次序；「3+4i 和 5 谁大」是无意义的问题。
  • ❌ 乘法时忘记 i² = −1 → ❌ 例：(3+2i)(1−4i) 中间会出现 2i·(−4i) = −8i² = +8，漏掉这一项就错。
  • ❌ 除法直接「约分」 → ❌ 必须分子分母同乘分母的共轭把分母实数化，不能把 (a+bi)/(c+di) 当作 a/c + (b/d)i。
  • ❌ 混淆共轭与相反数 → ❌ 共轭 z̄ = a − bi（只虚部变号），相反数 −z = −a − bi（实部虚部都变号），两者几何上分别是「关于实轴镜像」和「关于原点中心对称」。
  • ❌ 以为 |z|² = z² → ❌ |z|² = z·z̄ = a² + b² 是非负实数；而 z² 一般仍是复数。例：z = 1 + i 时 |z|² = 2，但 z² = 2i。
  • ❌ 求 iⁿ 时硬算 → ❌ 直接看 n 除以 4 的余数即可：余 0→1、余 1→i、余 2→−1、余 3→−i。

课本外 · 典故与思考

史复数是被"三次方程"逼出来的——卡丹与邦贝利（点击展开）

课本说"为了让三次方程求根公式里的中间量能被统一处理"，数学家引入了虚数——这不是一句空话，它是一段真实的"事故"。

1545 年，意大利数学家卡尔达诺（Girolamo Cardano，1501–1576）出版了《大术》（Ars Magna），书中公布了三次方程的求根公式。这段历史本身就有争议：公式最早是另一位意大利数学家塔尔塔利亚（Tartaglia）发现的，卡丹在承诺保密后还是把它发表了（并注明了出处），由此引发著名的"卡丹–塔尔塔利亚之争"。

更要命的是，这个公式在碰到一类方程时"卡壳"了。以方程 x³ = 15x + 4 为例，它明明有三个实根（4 和 −2±√3），可代入求根公式后，中间过程却出现根号下是负数的表达式 √(−121)——按当时的规则，这样的中间量"不存在"，公式却偏偏要靠它才能算出实根。这一疑难情形（后来叫"不可约情形"）让数学家们如坐针毡。

真正动手解决的是邦贝利（Rafael Bombelli，1526–1572）。他在 1572 年出版的《代数学》（L'Algebra）中，大胆地把 √−1 当作一个普通数来运算，发现 (2 + i)³ = 2 + 11i，于是 √(−121) = 11i，中间量一开方、再抵消，实根 4 就"干干净净"地出来了。邦贝利因此被称为"第一个系统地用虚数做运算的人"——虚数不是被人想出来的，是被公式逼出来的。

一句话总结：为了算出三个真实的根，数学家不得不先走进虚数的"迷宫"——复数从一开始就生在了"实用"之中。
思"虚数"：一个带着羞辱出生的名字（点击展开）

"虚数"（imaginary number）这个名字，最初是贬称。

  • 笛卡尔（Descartes，1596–1650）在 1637 年的《几何学》中首次使用"imaginaires"（想象的数）一词，语气里满是怀疑——负数的平方根在他看来"并不真实"；
  • 莱布尼茨（Leibniz）的形容更刻薄：√−1 是"介于存在与不存在之间的两栖动物"；
  • 大数学家欧拉也把 √−1 称为"既非无也非有"的数（虽然正是他把记号 i 定了下来，并率先研究它）。

转折点在 高斯（Gauss）：1799 年，年仅 22 岁的他在博士论文中就用复数证明了代数基本定理；1831 年，他系统地提出用平面上的点表示复数（复平面，所以也叫"高斯平面"），并指出：复数完全可以由"一对实数"定义，根本不是"想象"出来的神秘之物。从此，复数获得了完整的"合法性"。

今天回头看："虚"字描述的只是"不在实轴上"，它和实数同样真实——第 7 章课本用复平面把这点说得明明白白：i 就是"从原点竖直向上走一步"。

一句话总结：从"两栖动物"到平面上的点，虚数用了两百年才洗去名字里的羞辱。
典欧拉公式：五个常数的一场聚会（点击展开）

1748 年，欧拉在《无穷小分析引论》中写下了一个日后被反复吟诵的公式：

e^(iθ) = cos θ + i sin θ

把它代入 θ = π，便得到：

e^(iπ) + 1 = 0

这个式子被许多人称为"最美的数学公式"（物理学家费曼也盛赞它是"我们这一行的珍宝"）：

  • 它让 e（自然对数的底，来自指数）、π（来自圆周）、i（来自代数）、1 和 0（来自算术的起点）——五个看似毫不相干的常数同台出现；
  • 它把指数（乘法的连续化）与三角函数（圆的几何）连成一体：复平面上的"旋转"原来就是指数函数的"增长"；
  • 它是量子力学波函数、交流电路相量法、信号处理中"旋转因子"的共同来源。

从课堂的角度看，欧拉公式就是第 7 章"三角形式 z = r(cos θ + i sin θ)"的另一种写法 z = r·e^(iθ)——同一个圆上的点，两种语言，一通百通。

一句话总结：e^(iπ)+1=0 把数学里最著名的五个常数请到了一张桌上——这就是"最美公式"的分量。

本章练习卷（含答案）

一、练习题

  1. 设 z = 4 − 3i，写出它的实部、虚部、共轭 z̄ 与模 |z|；判断它是实数、虚数还是纯虚数，并说明 z 与 z̄ 在复平面上的位置关系。
  2. 求 i²⁰²⁶ 与 i²⁰²⁷ 的值，并说明理由。
  3. 已知 (x + y) + (x − y)i = 5 + i，求实数 x、y。
  4. 设 z₁ = 1 + i、z₂ = 3 − 4i，求 z₁·z₂ 与 z₁ / z₂（写成 a + bi 形式）；并结合几何意义解释为什么「乘以 1 + i」相当于「旋转 45° 并放大 √2 倍」。
  5. 在复平面上用旋转解释 i³ = −i 和 (1 + i)² = 2i 的几何过程。
  6. 两个同频信号用相量 u₁ = 3 + 4i、u₂ = 5 − 12i 表示，求合成相量 u = u₁ + u₂ 及其模与辐角正切；又设 z = 2(cos 60° + i sin 60°)，用棣莫弗定理求 z³ 的模与辐角。

二、参考答案（点击展开）

查看第1题答案

实部 Re(z) = 4、虚部 Im(z) = −3；z̄ = 4 + 3i；|z| = √(4² + (−3)²) = 5。因为 b = −3 ≠ 0 且 a = 4 ≠ 0，它是虚数（但不是纯虚数）。几何上，z 与 z̄ 关于实轴（横轴）上下对称。

查看第2题答案

i 的幂以 4 为周期循环。2026 ÷ 4 余 2，故 i²⁰²⁶ = i² = −1；2027 ÷ 4 余 3，故 i²⁰²⁷ = i³ = −i。

查看第3题答案

由复数相等的充要条件，实部相等、虚部相等：x + y = 5，x − y = 1。两式相加得 2x = 6，故 x = 3；代回得 y = 2。

查看第4题答案

z₁·z₂ = (1+i)(3−4i) = 3 − 4i + 3i − 4i² = 3 − i + 4 = 7 − i。
z₁/z₂ = (1+i)(3+4i)/(3²+4²) = (3 + 4i + 3i + 4i²)/25 = (−1 + 7i)/25 = −1/25 + (7/25)i。
几何意义：1 + i 的模为 √(1²+1²) = √2、辐角为 45°，故「乘以 1+i」就是把向量模放大 √2 倍、辐角加 45°，即旋转 45° 并放大 √2 倍。

查看第5题答案

每乘一次 i 即绕原点逆时针旋转 90°。i³ 从 1 出发连续乘三次 i：转 90° 到 i，再转 90° 到 −1，再转 90° 到 −i，故 i³ = −i。
(1+i)² = 1 + 2i + i² = 2i；几何上 1+i 模为 √2、辐角 45°，平方后模变 2、辐角变 90°，正好落在正虚轴上，即 2i。

查看第6题答案

合成相量 u = (3+5) + (4−12)i = 8 − 8i；模 |u| = √(8² + (−8)²) = 8√2；tan θ = −8/8 = −1，且 u 在第四象限，故 θ = −45°（即 315°）。
由棣莫弗定理：z³ 的模为 2³ = 8、辐角为 3 × 60° = 180°，故 z³ = 8(cos 180° + i sin 180°) = −8。
