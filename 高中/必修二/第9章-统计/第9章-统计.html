第9章 统计

高中 / 必修第二册

一句话总纲：统计 = 「用一小撮样本，去还原一大群总体的分布模样」。学完本章，你要能在心里"看见"两条线——一条是把数据从小到大排开的数轴（百分位数就是它上面的"切点"），一张是把数据按区间"装箱"的面积图（频率分布直方图里，面积才是频率）。抽样、画图、算数、估计，每一步都是"从局部推整体"的几何度量。

9.1 随机抽样：简单随机抽样与分层随机抽样

为什么要抽样？（从"全体"到"样本"）

统计研究的是总体（要考察对象的全体，含 N 个个体）。但总体往往太大、太贵、或不可全测（比如检验灯泡寿命会把灯泡烧坏），于是我们从总体中抽取一部分个体作为样本，用样本的规律去推断总体。

抽样的核心原则只有一条：样本要有代表性、每个个体被抽到的机会要可控制。抽样方法决定了样本"长得像不像总体"。

物理含义：总体 = 一大桶混合溶液；抽样 = 舀一小勺去化验。简单随机抽样相当于先把桶搅匀再随机舀一勺（每一点被舀到的机会相同）；分层抽样相当于按不同密度/成分分成几层，再逐层按比例舀，保证每一层都被代表到。

简单随机抽样

定义：设总体含 N 个个体，从中逐个、不放回地抽取 n（1 ≤ n < N）个个体作为样本，且每次抽取时总体内每个个体被抽到的机会都相等，这样的抽样叫简单随机抽样。

  • 最常用的两种实现：抽签法（编号→制签→搅匀→逐个不放回抽取）、随机数法（用随机数表或计算机生成的随机数挑编号）。
  • 等可能性：每个个体被抽中的概率都等于 n/N。这是"公平"的数学保证。
  • 特点：不放回 + 逐个 + 等机会。放回抽样（每次抽完放回）也叫简单随机抽样的一种，但课本默认不放回。
几何含义：把总体 N 个个体看成数轴或平面上 N 个等权重的点。简单随机抽样 = 在这一点集上"均匀随机取 n 个点"，任何一点都不被偏爱、任何一块区域被取到的概率只与它包含的点数成正比——这是"等概率测度"的直接体现。
物理含义：把总体搅"均匀"后随机取样。搅匀 = 抹掉所有个体间的差异权重，让每一份被取中的机会一致；这正对应"随机"的物理本义——无偏、无记忆。

分层随机抽样

当总体内部差异明显时（如不同年级、不同车间），先按一个或多个变量把总体划分为若干互不相交的子总体（每个个体属于且仅属于一个子总体），每个子总体叫一个层；然后在每一层内独立进行简单随机抽样，最后把各层样本合起来作为总样本。这就是分层随机抽样。

按比例分配：各层抽取的样本量 n_i 与该层个体数 N_i 成正比——

n_i = (N_i / N) × n    （N = N₁ + N₂ + … + N_k 为总体容量，n 为总样本量）

例：全校共 1000 人，其中高一 400、高二 300、高三 300，抽 100 人的样本，则各层抽 400/1000×100=40、30、30 人。

几何含义：把总体的"点集"沿某个特征轴切成若干互不重叠的区间段（层），再在每段内按"该段长度占总长度的比例"均匀取点。比例分配 = 每一层内部的抽样密度与全局一致，于是样本点在各区间的分布自动复刻总体结构，不会"漏掉"或"挤爆"某一段。
物理含义：像从一瓶分层的液体（油浮在上、水沉在下）里取样——若只搅表面会错过底层，必须先按层分别取样、再按体积比合并，才能还原整瓶的成分比例。分层抽样的"层"就是物理上的"不同相/不同浓度区"。

分层样本的总体均值：设第 i 层样本量为 n_i、样本平均数为 x̄_i，则总样本平均数等于各层平均数按样本量的加权平均：

x̄ = (n₁x̄₁ + n₂x̄₂ + … + n_kx̄_k) / (n₁ + n₂ + … + n_k)
这其实是物理中的"重心公式"：x̄ 是把各层"质心" x̄_i 按质量 n_i 加权后求出的总质心位置。

9.2 频率分布直方图

拿到一大堆原始数据，要先"整理出形状"。频率分布直方图就是把数据分布的"形"画出来的标准工具。

画图五步

  1. 求极差：R = 最大值 − 最小值，它刻画数据的"总跨度"。
  2. 定组距与组数：组数一般取 5～12 组；组距 ≈ R ÷ 组数，通常取"方便的数"（如 1、2、5、10）。
  3. 分组：常用左闭右开区间 [a, b) 分组，保证每点恰属一组。
  4. 列频率分布表：统计每组频数（个数），再算频率 = 频数 ÷ 样本容量 n。
  5. 画图：横轴 = 数据，纵轴 = 频率/组距；以组距为宽、频率/组距为高画小矩形。
几何含义（本章最重要的几何直觉！）：频率分布直方图中，小矩形的面积 = 组距 × (频率/组距) = 频率。所以直方图是用面积而不是高度来表示频率——所有小矩形面积之和恰好等于 1（即"总概率 = 1"）。每个小矩形可以理解为数轴上一个区间上方"铺出的一块面积"，面积大小就是落在这个区间里的概率。
物理含义：把 n 个数据点看成撒在数轴上的一堆"沙粒"。分组 = 用若干箱子接住不同区间的沙粒；纵轴（频率/组距）= 沙粒的"线密度"（单位长度内的相对沙量），矩形面积 = 该箱里的沙量（频率）。箱子越宽、密度越高，装进的沙越多——"密度 × 宽度 = 质量"，这正是密度概念的统计翻版。

几个必须记牢的换算

频率 = 频数 / 样本容量 n
小矩形面积 = 组距 × 纵轴值 = 频率
所有小矩形面积之和 = 1
组中值 = (左端点 + 右端点) / 2   （代表该组数据的"中心"）

用直方图还可以估算总体特征：

  • 平均数估计：x̄ ≈ Σ(每组组中值 × 该组频率)
  • 方差估计：s² ≈ Σ[(组中值 − x̄)² × 该组频率]
  • 中位数/百分位数估计：找"面积累计到 50%（或 p%）"的那条竖线（见 9.3）。

频率分布折线图与总体密度曲线

把每个小矩形上边的中点顺次连接，得到频率分布折线图。当样本量越来越大、组距越来越小时，这条折线会越来越接近一条光滑曲线，称为总体密度曲线——它刻画了总体数据分布的"理想形状"（如"钟形"的正态曲线）。

几何含义：折线 → 光滑曲线的过程，是用越来越多、越来越细的矩形去逼近一条曲线下方区域的面积——本质上就是"积分/黎曼和"思想的雏形：面积（频率）和曲线（密度）互为表里。

9.3 百分位数

百分位数回答的问题是："从小到大排，落在前 p% 位置的那个值是多少？"它是刻画数据位置（尤其是"排名/分数线"）的最直接工具。

定义

一般地，一组数据的第 p 百分位数是这样的一个值，它使得这组数据中至少有 p% 的数据小于或等于它，且至少有 (100 − p)% 的数据大于或等于它。

计算步骤（务必先排序！）

  1. 把 n 个数据从小到大排列：x₁ ≤ x₂ ≤ … ≤ x_n。
  2. 计算 i = n × p%。
  3. 若 i 不是整数：取大于 i 的最小整数 j，第 p 百分位数 = 第 j 项数据 x_j。
  4. 若 i 是整数：第 p 百分位数 = 第 i 项与第 i+1 项数据的平均数 (x_i + x_{i+1}) / 2。

四分位数：第 25、50、75 百分位数分别叫第一、第二、第三四分位数（记 Q₁、Q₂、Q₃）。其中第二四分位数就是中位数。它们把有序数据分成四等份。

几何含义：把 n 个数据点按顺序排在数轴上，第 p 百分位数就是把这条有序点链切成"左 p%、右 (100−p)%"的那一刀的位置。中位数 = 第 50 百分位数，是正中间那一刀；四分位数 = 三刀，把点集等分成四段。计算中的"向上取整 / 两项取平均"正是为了让切点落在"至少 p% 在左、至少 (100−p)% 在右"的平衡点上。
物理含义：百分位数就是排名线/分数线。某同学成绩处于第 90 百分位数，意味着他高于（或等于）90% 的考生——就像一根横在成绩数轴上的"刻度杆"，把这批人按高低切成 90% 与 10% 两段。

箱线图（百分位数的几何画像）

用最小值、Q₁、中位数 Q₂、Q₃、最大值五个数画出的"箱子 + 须"图形叫箱线图：箱子从 Q₁ 到 Q₃（箱长 = 四分位距 IQR = Q₃ − Q₁），箱内一条线标中位数，两端"须"延伸到最小值与最大值。它一眼给出数据的中心、跨度、偏斜。

9.4 样本估计总体

抽样的最终目的，是用样本统计量去估计总体参数。最核心的两个估计：用样本平均数 x̄ 估计总体平均数 μ，用样本方差 s² 估计总体方差 σ²。

样本平均数（估计"中心"）

x̄ = (x₁ + x₂ + … + x_n) / n
几何含义：x̄ 是这 n 个数据点在数轴上的重心 / 平衡点。关键性质：各数据到 x̄ 的偏差之和为 0，即 Σ(x_i − x̄) = 0——正偏差与负偏差互相抵消，x̄ 正是让点集"左右力矩平衡"的那个支点。
物理含义：把每个数据点看成数轴上质量为 1 的小球，x̄ 就是这排小球的质心。平均数两侧"距离之和"相等，像跷跷板两端坐人的平衡位置；若一侧数据普遍更大，质心就朝那一侧偏移。

样本方差与标准差（估计"离散程度"）

s² = (1/n) Σ (x_i − x̄)²   （i = 1, 2, …, n）
s  = √(s²)                （标准差 = 方差的算术平方根）
几何含义：方差 = 各数据点到重心 x̄ 的"平均平方距离"（先算每个点到重心的距离，再平方求平均）。它度量的是点集围绕重心散开的半径有多大：方差小 → 点紧贴重心（分布集中）；方差大 → 点远离重心（分布分散）。标准差 s 则把这个"距离"还原到与数据同单位。
物理含义：方差/标准差对应物理中的"转动惯量/离散度"：质量越远离转轴，转动惯量越大；数据越偏离均值，方差越大。标准差小 = 数据"质量集中、稳定"（如零件尺寸一致）；标准差大 = 数据"质量分散、波动大"（如成绩两极分化）。

补充：统计中常把样本方差写成 1/(n−1) 的形式（称为无偏估计），是为了让"样本方差的平均值"恰好等于总体方差 σ²。课本正文通常用 1/n 定义样本方差，二者在 n 较大时差别很小；做题时以题目要求为准。

分层抽样的样本估计

若按 9.1 分层抽样，总体平均数的估计 = 各层平均数按层权加权（即前述重心公式）；总体方差的估计可拆为"层内方差"与"层间方差"两部分，这就是方差分解：

总方差 = 层内方差的加权平均 + 层间方差
（层间方差 = 各层均值相对总均值的离散程度）
物理含义：方差分解就像"总能量 = 内部能量 + 质心运动能量"——把总波动拆成"各层内部各自的晃动"与"各层质心之间的彼此拉开"两股来源。分层抽样的优势正在于：它把"层间差异"主动纳入控制，使估计更稳定、更有代表性。

典型例题（自测）

例题

  1. 抽样：某校高一 900 人、高二 700 人、高三 400 人，用分层抽样抽 200 人，问各年级各抽多少人？
  2. 百分位数：数据 3, 7, 8, 10, 12, 15, 18, 20, 22, 25（n=10），求中位数、第 25 百分位数、第 80 百分位数。
  3. 频率分布直方图：某组数据直方图中，某小组组距为 4、纵轴（频率/组距）为 0.075，求该组频率与频数（样本容量 n=80）；并说明如何由面积估算中位数。
  4. 平均数与方差：样本 2, 4, 4, 6，求平均数 x̄、方差 s²、标准差 s。
  5. 分层均值：甲层样本量 30、平均数 80；乙层样本量 20、平均数 60，求总样本平均数。

常见误区

警惕这些坑

  • ❌ "频率分布直方图的纵轴是频率" → ❌ 纵轴是频率/组距；频率要用面积（组距 × 纵轴）来算。
  • ❌ "直方图里柱越高频率越大" → ❌ 只在组距相等时成立；组距不同时，面积才是频率。
  • ❌ "求百分位数不用排序" → ❌ 必须先从小到大排序再算 i = n×p%，否则位置错乱。
  • ❌ "第 50 百分位数一定是某个数据本身" → ❌ 当 n×50% 是整数时，中位数是中间两项的平均数，可能不是原数据。
  • ❌ "方差可以小于 0" → ❌ 方差是平方的平均，恒 ≥ 0；标准差是它的算术平方根，也 ≥ 0。
  • ❌ "分层抽样各层抽样方法可以随便" → ❌ 每一层内应独立进行简单随机抽样，各层样本量按比例（n_i = N_i/N × n）。
  • ❌ "样本平均数一定等于总体平均数" → ❌ x̄ 只是 μ 的估计，受抽样随机性影响会有偏差；样本量越大通常越接近。

本章练习卷（含答案）

一、练习题

  1. 抽样理解：某校高一年级有 1200 人、高二 800 人、高三 400 人。现用分层随机抽样抽取 120 人的样本，问三个年级各应抽取多少人？并说明这样分配能保证样本"长得像总体"的几何道理。
  2. 百分位数：某班 10 名同学的数学成绩从小到大排列为 55, 62, 68, 70, 74, 78, 82, 85, 90, 96。求中位数、第 25 百分位数、第 80 百分位数。
  3. 频率分布直方图：某组样本数据的频率分布直方图中，某一小组的组距为 5，纵轴（频率/组距）为 0.06。若样本容量 n = 100，求该小组的频率与频数；并解释"直方图里为什么用面积而不用高度表示频率"。
  4. 平均数与方差：样本数据为 4, 6, 6, 8, 8, 8。求平均数 x̄、方差 s² 与标准差 s（用 1/n 定义），并说明方差刻画的几何含义是什么。
  5. 分层均值（重心公式）：甲层样本量 40、样本平均数 75；乙层样本量 60、样本平均数 90。求总样本平均数，并说明它为什么是"按质量加权的质心"。
  6. 综合（用样本估计总体）：为估计一批灯泡的平均寿命，随机抽取 5 只测得寿命为 980, 1000, 1020, 1010, 990（小时）。求样本平均数作为总体平均寿命的估计值，并计算这组样本的方差，说明方差小意味着什么。

二、参考答案（点击展开）

查看第1题答案

各年级抽取人数按 n_i = (N_i/N)×n 分配，N = 1200+800+400 = 2400，n = 120。高一：1200/2400×120 = 60 人；高二：800/2400×120 = 40 人；高三：400/2400×120 = 20 人。几何道理：把总体看成一条按年级分成的三段数轴（长度比为 1200:800:400 = 3:2:1），每段按"该段长度占总长度的比例"均匀取点，使每段内的抽样密度与全局一致，样本点分布自动复刻总体结构，不会漏掉或挤爆某一段。

查看第2题答案

n = 10。中位数（第 50 百分位数）：i = 10×50% = 5 为整数，取第 5、6 项平均数 = (74+78)/2 = 76。第 25 百分位数：i = 10×25% = 2.5 非整数，取大于 2.5 的最小整数 3，即第 3 项 = 68。第 80 百分位数：i = 10×80% = 8 为整数，取第 8、9 项平均数 = (85+90)/2 = 87.5。注意必须先从小到大排序（本题已排好），再按"整数取两项平均、非整数向上取整"的规则定位。

查看第3题答案

频率 = 组距 × 纵轴值 = 5 × 0.06 = 0.30；频数 = 频率 × 样本容量 = 0.30 × 100 = 30。直方图用面积表示频率：小矩形面积 = 组距 ×（频率/组距）= 频率，所有小矩形面积之和恰为 1（总概率 = 1）。若只看高度，当各组组距不同时会产生误导——组距宽的小矩形即使频率大也可能"矮"；面积才真正等于落入该区间的数据占比，相当于数轴上区间上方"铺出的一块面积"。

查看第4题答案

x̄ = (4+6+6+8+8+8)/6 = 40/6 ≈ 6.67。方差 s² = (1/n)Σ(x_i − x̄)²：各偏差平方为 (4−6.67)²≈7.11、(6−6.67)²≈0.44、(6−6.67)²≈0.44、(8−6.67)²≈1.78、(8−6.67)²≈1.78、(8−6.67)²≈1.78，合计约 13.33，s² ≈ 13.33/6 ≈ 2.22。标准差 s = √2.22 ≈ 1.49。几何含义：方差是各数据点到重心（平均数）x̄ 的"平均平方距离"，度量点集围绕重心散开的半径——方差小则数据紧贴重心、分布集中，方差大则数据远离重心、分布分散。

查看第5题答案

总样本平均数 x̄ = (n₁x̄₁ + n₂x̄₂)/(n₁+n₂) = (40×75 + 60×90)/(40+60) = (3000 + 5400)/100 = 8400/100 = 84。它相当于把各层的样本平均数 x̄_i 看作该层的"质心"，把样本量 n_i 看作"质量"，做加权平均后得到的总质心位置——这正是物理中的重心公式。因为乙层样本量更大（质量更大），总平均数 84 更靠近乙层均值 90 而不是两者的简单平均 (75+90)/2 = 82.5。

查看第6题答案

样本平均数 x̄ = (980+1000+1020+1010+990)/5 = 5000/5 = 1000 小时，故总体平均寿命的估计值为 1000 小时。方差 s² = (1/n)Σ(x_i − x̄)² = [(980−1000)²+(1000−1000)²+(1020−1000)²+(1010−1000)²+(990−1000)²]/5 = (400 + 0 + 400 + 100 + 100)/5 = 1000/5 = 200（小时²），标准差 s = √200 ≈ 14.14 小时。方差小意味着各灯泡寿命都紧紧贴着平均数 1000 小时、彼此差异不大，说明这批灯泡质量稳定、波动小；若方差很大，则寿命两极分化、质量不稳定。
