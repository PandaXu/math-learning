第10章 概率

高中 / 必修第二册

一句话总纲：概率 = 「事件区域的面积占样本空间总面积的比例」。把一次试验的所有可能结果画成一张"地图"（样本空间 Ω），随机事件就是地图上的一块区域（子集），概率就是"有利区域 ÷ 全体区域"的度量——古典概型是"每个格子一样大"的均匀度量，概率性质是面积的加减（容斥），独立性是"两维面积 = 长 × 宽"的可分离相乘。

10.1 随机事件与概率（样本空间 · 随机事件 · 事件的关系与运算）

随机现象与随机试验

先分清两类现象：

  • 确定性现象：在一定条件下必然发生（或必然不发生）的现象。例：标准大气压下，水加热到 100℃ 一定沸腾；实数的平方一定非负。
  • 随机现象：在一定条件下，结果事先不能确定、但可以重复观察的现象。例：抛一枚硬币落下后哪面朝上、掷一颗骰子出现的点数、明天是否下雨。

随机试验（简称试验）是对随机现象的实现与观察，需满足：① 可在相同条件下重复进行；② 试验的所有可能结果是事先已知的，但不止一个；③ 每次试验恰好出现其中一个结果，事先无法断定是哪一个。

样本点与样本空间

  • 样本点：随机试验的每一个可能结果，通常记作 ω。
  • 样本空间：全体样本点组成的集合，记作 Ω。

例：抛一枚硬币，Ω = {正面，反面}；掷一颗骰子，Ω = {1，2，3，4，5，6}；掷两枚骰子，Ω = {(i，j) | 1 ≤ i ≤ 6，1 ≤ j ≤ 6}，共 6 × 6 = 36 个样本点。

几何含义：样本空间就是"所有可能结果的完整地图"——一张把试验的每一个可能结局都标出来的点集。样本点是地图上的一个点，样本空间是这些点组成的全集。物理含义：它是"对试验的一次完整描述"——做试验之前，你知道落点一定在这张地图上，但不知道具体落在哪个点。

随机事件、基本事件、必然事件、不可能事件

  • 随机事件（简称事件）：样本空间 Ω 的一个子集，用大写字母 A、B、C 表示。
  • 基本事件：只含一个样本点的事件。
  • 必然事件：样本空间 Ω 本身，每次试验一定发生。
  • 不可能事件：空集 ∅，每次试验一定不发生。

事件 A 发生：当且仅当试验中出现的样本点属于 A。例：掷骰子，设事件 A = "出现偶数点"，则 A = {2，4，6}；若掷出点数 4（∈ A），就说 A 发生了。

几何含义：随机事件 = 样本空间这张地图上的一块区域；事件发生 = 试验结果落进这块区域。基本事件是"一个格子"，必然事件是"整张地图"，不可能事件是"空区域"。

事件的关系与运算（用集合语言描述）

事件的关系与运算，本质上就是集合的关系与运算，可用韦恩图（Venn diagram）直观表示。

名称记法含义
包含A ⊆ BA 发生必然导致 B 发生；若 A ⊆ B 且 B ⊆ A，则 A = B
并事件（和事件）A ∪ B（或 A + B）A 与 B 至少有一个发生
交事件（积事件）A ∩ B（或 AB）A 与 B 同时发生
互斥事件A ∩ B = ∅A 与 B 不能同时发生
对立事件A ∩ B = ∅ 且 A ∪ B = ΩA 与 B 有且仅有一个发生，记 B = Ā（A 的补集）

例（掷一颗骰子，Ω = {1，2，3，4，5，6}）：设 A = {2，4，6}（偶数点），B = {1，3，5}（奇数点），C = {4，5，6}（大于 3）。则 A 与 B 互斥且对立；A ∩ C = {4，6}，A ∪ C = {2，4，5，6}。

几何含义（重要）：并事件 A ∪ B 是两块区域的并集，交事件 A ∩ B 是两区域的公共重叠部分，互斥事件是两块不相交的区域，对立事件是"A 区域 + 地图上其余全部区域"恰好铺满整张地图（即 B 是 A 的补集）。物理含义：对立事件就是"非此即彼"——要么 A 发生、要么 A 不发生，二者必居其一（如"命中"与"未命中"）。

两个易混点：① 对立事件一定是互斥事件，但互斥事件不一定对立（互斥只要求"不能同时发生"，还须"并起来是全集"才是对立）。② 三个及以上的事件"两两互斥"与"互斥"要注意：两两互斥指任意两个都互斥。

10.2 古典概型（等可能概型）

定义

若一个试验同时满足两个条件：

  1. 有限性：样本空间 Ω 只含有限个样本点；
  2. 等可能性：每个样本点发生的可能性相等。

则称该试验为古典概型（等可能概型）。设事件 A 包含 n(A) 个样本点，样本空间 Ω 含 n(Ω) 个样本点，则：

P(A) = n(A) / n(Ω) = 事件A包含的样本点数 / 样本空间样本点总数
几何含义：古典概型的本质是均匀度量（等面积格子）。把每个样本点看成一块面积相等的格子（等可能性 = "每格一样大"），事件 A 的概率就是 A 所占格子数占总格子数的比例，即"A 的面积 ÷ 总面积"。物理含义：均匀硬币（两面对称）、均匀骰子（六面对称）、抽签、摸球等"公平"场景——物理上的对称性保证了数学上的等可能性，这正是均匀分布（离散版）的来源。

古典概型的计算：核心是"数数"

求 n(Ω) 与 n(A) 的方法：列举法（树状图、列表格）与排列组合。关键规则：分子与分母的计数口径必须一致——要么都"按顺序"数，要么都"不按顺序"数。

  • 抛一枚均匀硬币，正面朝上的概率：n(Ω) = 2，n(A) = 1，P = 1/2。
  • 掷一颗均匀骰子，"点数不大于 2"：n(Ω) = 6，A = {1，2}，P = 2/6 = 1/3。
  • 掷两枚均匀骰子，"点数和为 7"：36 个样本点中，和为 7 的有 (1,6)(2,5)(3,4)(4,3)(5,2)(6,1) 共 6 个，P = 6/36 = 1/6。
为什么掷两枚骰子要区分"第一枚、第二枚"（把 (1,6) 与 (6,1) 看作两个样本点）？几何上，把两个骰子分别对应横、纵两维，样本空间是 6 × 6 的方格点阵，每个格子等面积；(1,6) 与 (6,1) 是点阵中两个不同的格子，故都要数。若把它们合并成一个，格子就不再等面积，等可能性被破坏，结果必然出错。

10.3 概率的性质（公理化定义 + 统计含义）

概率的公理化定义

对样本空间 Ω 中的每个事件 A，都赋予一个实数 P(A)（A 的概率），且满足：

(1) 非负性：P(A) ≥ 0
(2) 规范性：P(Ω) = 1
(3) 可加性：若 A、B 互斥，则 P(A ∪ B) = P(A) + P(B)

由这三条公理可推出全部概率性质：

  1. P(∅) = 0（不可能事件的概率为 0）；
  2. 0 ≤ P(A) ≤ 1（任何事件的概率都在 0 到 1 之间）；
  3. 若 A ⊆ B，则 P(A) ≤ P(B)；
  4. 对立事件：P(Ā) = 1 − P(A)；
  5. 互斥事件的加法（有限可加）：若 A₁，A₂，…，Aₙ 两两互斥，则 P(A₁ ∪ A₂ ∪ … ∪ Aₙ) = P(A₁) + P(A₂) + … + P(Aₙ)；
  6. 一般加法公式（不要求互斥）：P(A ∪ B) = P(A) + P(B) − P(A ∩ B)。
几何含义（关键）：把概率看成事件区域的"面积（测度）"。非负性 = 面积不会为负；规范性 = 整张地图面积记为 1；可加性 = 两块不相交区域的面积 = 各自面积之和；一般加法公式 = 两区域并集的面积 = 面积A + 面积B − 重叠部分（重叠被加了两次，故减一次），这正是韦恩图的容斥原理；对立事件公式 = "阴影外的面积 = 1 − 阴影面积"。

统计定义（物理含义）：在大量重复试验中，事件 A 发生的频率 fₙ(A) = n_A / n（n 次试验中 A 发生了 n_A 次）会稳定在某个常数附近，这个常数就是概率 P(A)。频率是概率的"测量值 / 近似值"，概率是频率的"理论稳定值 / 极限"——概率刻画随机现象的长期统计规律。

物理含义：频率与概率的关系，像"多次测量取平均"逼近真实值：单次试验随机，但大量重复后规律显现（大数定律的直观）。例如抛硬币，抛 10 次可能 7 次正面（频率 0.7），抛 10000 次正面频率就非常接近 0.5。

10.4 事件的独立性

定义

设 A、B 是同一试验中的两个事件，若

P(A ∩ B) = P(A) · P(B)

则称事件 A 与 B 相互独立（简称独立）。直观含义：A 发生与否不影响 B 发生的概率，反之亦然。

如何判断独立性

  1. 定义法：验证 P(A ∩ B) = P(A) · P(B) 是否成立。
  2. 实际情境法：两次试验互不影响（有放回摸球、不同的人独立射击、两台独立设备、先后抛两次硬币等）时，通常认为相互独立。

重要性质：若 A 与 B 独立，则 A 与 B̄、Ā 与 B、Ā 与 B̄ 也都独立。

独立 ≠ 互斥

独立与互斥是两个完全不同的概念：

  • 互斥：P(A ∩ B) = 0，A、B 不能同时发生；
  • 独立：P(A ∩ B) = P(A) · P(B)，A、B 可以同时发生，且"一个发生不影响另一个"。

若 P(A) > 0 且 P(B) > 0，则 A、B 互斥 ⇒ A、B 不独立；A、B 独立 ⇒ A、B 不互斥（独立且概率都为正的两个事件，其交事件概率 P(A)·P(B) > 0，故必能同时发生）。

几何含义：独立性 = 概率上的"乘积结构 / 正交可分离"。把 A 对应横轴上长度为 P(A) 的区间、B 对应纵轴上长度为 P(B) 的区间，则 A ∩ B 对应一个矩形，其"面积" = 长 × 宽 = P(A) · P(B)。独立性就是"两维之间无关联，可以分离开来相乘"——正如面积 = 底 × 高，两方向各自独立。物理含义：独立 = 两次试验互不干扰：抛第一次硬币的结果不影响抛第二次；有放回摸球第二次与第一次无关；两台设备是否故障互不影响。

经典例子：

  • 连抛两次均匀硬币，两次都正面朝上：P = (1/2) × (1/2) = 1/4。
  • 甲命中率 0.6、乙命中率 0.7，二人独立射击同一目标：都命中 P = 0.6 × 0.7 = 0.42；至少一人命中 P = 1 − (1 − 0.6)(1 − 0.7) = 1 − 0.4 × 0.3 = 0.88；恰有一人命中 P = 0.6 × 0.3 + 0.4 × 0.7 = 0.46。
"至少一个发生"的口诀：直接算"至少一个"常常要分多类，改用对立事件更省力——"至少一人命中" = 1 − "两人都不命中" = 1 − P(Ā)·P(B̄)。这是"面积 = 1 − 空白面积"的独立性版本。

典型例题（自测）

题目

  1. 抛两枚均匀硬币，写出样本空间 Ω，并求"至少一枚正面朝上"的概率。
  2. 掷一颗均匀骰子，A = "出现偶数点"，B = "出现点数大于 3"。求 P(A)、P(B)、P(A ∩ B)、P(A ∪ B)。
  3. 袋中有 3 个红球、2 个白球（除颜色外完全相同），不放回地依次摸出 2 个，求摸出的 2 个都是红球的概率。
  4. 甲、乙独立射击同一目标，命中率分别为 0.6 与 0.8。求：（1）两人都命中；（2）至少一人命中；（3）恰有一人命中。
  5. 从 1、2、3、4 中任取两个不同数字组成一个两位数，求：（1）这个两位数是偶数；（2）这个两位数大于 30。
  6. 已知 P(A) = 0.5，P(B) = 0.4。若 A 与 B 互斥，求 P(A ∪ B)；若 A 与 B 独立，求 P(A ∪ B)。

参考答案

  1. Ω = {正正，正反，反正，反反}；"至少一枚正面" = {正正，正反，反正}，P = 3/4。
  2. Ω = {1，…，6}，A = {2，4，6}，P(A) = 1/2；B = {4，5，6}，P(B) = 1/2；A ∩ B = {4，6}，P(A ∩ B) = 1/3；A ∪ B = {2，4，5，6}，P(A ∪ B) = 2/3（也可 1/2 + 1/2 − 1/3 = 2/3）。
  3. 按顺序：n(Ω) = 5 × 4 = 20，都是红球 n(A) = 3 × 2 = 6，P = 6/20 = 3/10（也可 C(3,2)/C(5,2) = 3/10）。
  4. （1）0.6 × 0.8 = 0.48；（2）1 − 0.4 × 0.2 = 0.92；（3）0.6 × 0.2 + 0.4 × 0.8 = 0.44。
  5. 共 4 × 3 = 12 个两位数。（1）偶数：个位为 2 或 4，各有 3 种十位，共 6 种，P = 6/12 = 1/2；（2）大于 30：十位为 3 或 4，各有 3 种个位，共 6 种，P = 6/12 = 1/2。
  6. 互斥：P(A ∪ B) = 0.5 + 0.4 = 0.9；独立：P(A ∪ B) = 0.5 + 0.4 − 0.5 × 0.4 = 0.7。

常见误区

避坑清单

  • ❌ "互斥就是对立" → ✔ 对立是特殊的互斥：还须满足"并起来等于全集"。
  • ❌ "独立就是互斥" → ✔ 独立与互斥是两个不同概念，独立事件（概率均正）是能同时发生的。
  • ❌ "古典概型只要有有限个样本点就行" → ✔ 还必须等可能；不均匀骰子不满足等可能性，不是古典概型。
  • ❌ "P(A ∪ B) = P(A) + P(B) 永远成立" → ✔ 只有 A、B 互斥时才成立，一般要减去 P(A ∩ B)。
  • ❌ "概率可以小于 0 或大于 1" → ✔ 任何事件都有 0 ≤ P(A) ≤ 1。
  • ❌ "不放回摸球也独立" → ✔ 不放回抽样前后结果有关联、不独立；有放回才独立。
  • ❌ "掷两枚骰子把 (1,6) 与 (6,1) 当成同一个样本点" → ✔ 两枚骰子要区分先后，点阵是 6 × 6 = 36 个不同格子。
  • ❌ "分子分母计数口径不一致" → ✔ 数 n(A) 与 n(Ω) 必须同按顺序或同不按顺序，否则比例错。

本章练习卷（含答案）

一、练习题

  1. 掷一颗均匀骰子，写出样本空间 Ω。设 A = {1，2，3}（点数不大于 3），B = {2，3，4}，求 A ∩ B 与 A ∪ B，并判断 A 与 B 是否互斥。
  2. 袋中有 4 个红球、3 个白球、1 个蓝球（除颜色外完全相同），随机摸出 1 个球，求摸到红球的概率，并用「有利格子数 ÷ 总格子数」解释其几何含义。
  3. 某班学生中，喜欢数学的概率 P(A) = 0.6，喜欢物理的概率 P(B) = 0.5，两科都喜欢的概率 P(A ∩ B) = 0.3。求至少喜欢一科的概率 P(A ∪ B)，并说明为什么不能直接写成 0.6 + 0.5（结合韦恩图的面积容斥）。
  4. 掷一颗均匀骰子，求「点数不小于 2」的概率。说明为什么用「1 − 点数等于 1 的概率」来算更省力（结合对立事件的几何含义）。
  5. 一枚均匀硬币连抛两次，设 A =「第一次正面朝上」，B =「第二次正面朝上」。写出样本空间 Ω，求 P(A)、P(B)、P(A ∩ B)，并验证 P(A ∩ B) = P(A)·P(B)，说明这如何体现「两次试验互不影响」。
  6. 甲、乙两人独立射击同一目标，命中率分别为 0.7 与 0.8。求：（1）两人都未命中；（2）至少一人命中；（3）恰有一人命中。

二、参考答案（点击展开）

查看第1题答案

Ω = {1，2，3，4，5，6}。A ∩ B = {2，3}（同时属于 A、B 的公共部分）；A ∪ B = {1，2，3，4}（两块区域的并集）。因为 A ∩ B = {2，3} ≠ ∅，A 与 B 有公共样本点，能同时发生，所以不互斥。

查看第2题答案

样本空间共 8 个样本点（红×4、白×3、蓝×1），每个球等可能。红球占 4 个「格子」，故 P = 4/8 = 1/2。几何含义：把每个球看成地图上一个等面积的格子，「有利区域（红球）的面积 ÷ 总面积」= 4 ÷ 8 = 1/2。

查看第3题答案

P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = 0.6 + 0.5 − 0.3 = 0.8。不能直接相加，是因为「两科都喜欢」的人在 P(A) 与 P(B) 里被算了两次，须减去一次重叠部分——正如两区域并集的面积 = 面积A + 面积B − 重叠面积（容斥原理）。

查看第4题答案

「点数不小于 2」= {2，3，4，5，6}，其对立事件是「点数等于 1」= {1}。P(不小于 2) = 1 − P(点数等于 1) = 1 − 1/6 = 5/6。几何含义：直接数「有利区域」要数 5 格，而「空白区域（补集）只有 1 格」，用「1 − 阴影外面积」更快。

查看第5题答案

Ω = {正正，正反，反正，反反}，共 4 个样本点。P(A) = 2/4 = 1/2，P(B) = 2/4 = 1/2，A ∩ B = {正正}，P(A ∩ B) = 1/4。验证：P(A)·P(B) = 1/2 × 1/2 = 1/4 = P(A ∩ B)，故 A 与 B 相互独立。几何含义：第一次结果对应横轴、第二次对应纵轴，A ∩ B 是长 × 宽 = 1/2 × 1/2 的矩形，两维正交可分离相乘，正是「两次试验互不影响」。

查看第6题答案

甲未命中 = 0.3，乙未命中 = 0.2，且独立。（1）都未命中 = 0.3 × 0.2 = 0.06；（2）至少一人命中 = 1 − 都未命中 = 1 − 0.06 = 0.94（用对立事件，避开分类）；（3）恰有一人命中 = 甲中乙不中 + 甲不中乙中 = 0.7 × 0.2 + 0.3 × 0.8 = 0.14 + 0.24 = 0.38。
