第2章 一元二次函数、方程和不等式

高中 / 必修第一册

一句话总纲：函数、方程、不等式是同一条抛物线的三种语言——二次函数是"图象"（抛物线）、一元二次方程的根是抛物线与 x 轴的"交点"、一元二次不等式的解集是抛物线在 x 轴"上方/下方"的部分；而基本不等式则告诉你"两个正数的算术平均不小于几何平均"，本质是"圆的半弦长不超过半径"。

2.1 等式与不等式的性质

实数的大小：作差法（一切比较的根基）

实数与数轴上的点一一对应，且右边的点表示的数更大。判断两个实数 a、b 的大小，最根本的方法是作差法：

a − b > 0   ⇔   a > b
a − b = 0   ⇔   a = b
a − b < 0   ⇔   a < b
几何含义：a − b 就是数轴上从点 b 到点 a 的有向位移。若 a − b > 0，说明从 b 出发要向右走才能到达 a，所以 a 在 b 的右边，即 a > b；反之则 a 在 b 的左边。
物理含义：作差法相当于把两个量放到同一把"尺子"上对齐比较——两次温度之差、两段路程之差、两座山峰海拔之差，差的正负号直接表示"谁比谁高 / 多 / 大"。

等式的基本性质

  • 对称性：若 a = b，则 b = a。
  • 传递性：若 a = b 且 b = c，则 a = c。
  • 可加性：若 a = b，则 a + c = b + c。
  • 可乘性：若 a = b，则 ac = bc。
几何 / 物理含义：等式两边同加 c，等于把数轴上两个点同时平移 c 个单位，两点间的距离不变，仍重合；两边同乘 c，等于对两点做同样的拉伸或压缩（c 为负时再整体翻转），重合关系依旧。类比：天平两边同时加上或成倍增加同样的砝码，天平仍平衡。

不等式的基本性质（七条）

  1. 对称性：a > b ⇔ b < a。
  2. 传递性：a > b 且 b > c ⇒ a > c。
  3. 可加性：a > b ⇒ a + c > b + c（同加一个数，不等号方向不变）。
  4. 可乘性：a > b 且 c > 0 ⇒ ac > bc；a > b 且 c < 0 ⇒ ac < bc（乘正数方向不变，乘负数方向反转）。
  5. 同向可加性：a > b 且 c > d ⇒ a + c > b + d。
  6. 同向同正可乘性：a > b > 0 且 c > d > 0 ⇒ ac > bd。
  7. 可乘方性 / 可开方性：a > b > 0 ⇒ aⁿ > bⁿ（n ∈ N*，n ≥ 2）；a > b > 0 ⇒ √a > √b。
几何含义（为什么乘负数要"掉头"？）：数轴上乘以 −1 就是关于原点的镜像翻转。若 a > b（a 在 b 的右边），翻转后 −a 跑到 −b 的左边，于是 −a < −b。所以乘负数 = 翻转方向 = 不等号反向；而"同加一个数"只是整体平移，两点相对位置不变，不等号方向当然不变。
物理含义：例如海拔：若甲比乙高（a > b），两人同时再上升相同高度 c，甲仍比乙高（方向不变）；但若把"高"重新定义为"向下为正"（相当于乘 −1），则甲反而比乙"低"（方向反转）。

2.2 基本不等式

基本不等式的内容

对任意两个正数 a、b，有：

√(ab) ≤ (a+b)/2      （a > 0，b > 0）

当且仅当 a = b 时，等号成立。

读作：两个正数的算术平均数不小于它们的几何平均数。其中 (a+b)/2 叫算术平均数，√(ab) 叫几何平均数。

它是怎么来的？（由完全平方推出）

(a − b)² ≥ 0
⟹  a² − 2ab + b² ≥ 0
⟹  a² + b² ≥ 2ab

令 a、b 为正数，以 √a、√b 代入：
a + b ≥ 2√(ab)，即 √(ab) ≤ (a+b)/2
几何含义（圆中的弦，最直观！）：在圆 O 的直径 AB 上取一点 C，使 AC = a、CB = b，过 C 作 AB 的垂线交圆于 D、E 两点。则：半径 OD = (a+b)/2（直径的一半）；由射影定理（相交弦定理）知半弦 CD = CE = √(AC·CB) = √(ab)。而半弦长永远不超过半径，所以 √(ab) ≤ (a+b)/2；当且仅当 C 与圆心 O 重合（即 a = b）时，半弦"长到"成为半径，等号成立。
另一个几何含义（矩形）：周长一定的矩形中，正方形面积最大。设长、宽为 a、b，则 a + b = 定值 p，面积 S = ab ≤ (p/2)²，当且仅当 a = b（正方形）时面积最大。反过来，面积一定时，正方形周长最短。
物理 / 现实含义：用同样长的篱笆围地，围成正方形面积最大；制造同样容积、开口面积一定的容器，长宽相等最省材料；此外"均值不等式"也是许多最小成本、最快到达、最大收益优化问题的数学引擎。

用基本不等式求最值：一正、二定、三相等

例：已知 x > 0，求 x + 1/x 的最小值。

x + 1/x ≥ 2√(x · 1/x) = 2

当且仅当 x = 1/x，即 x = 1 时取等号。
∴ 最小值为 2。
关键口诀：一正（两数都为正，才能用）、二定（乘积为定值，和才有最小；和为定值，积才有最大）、三相等（必须验证等号能否取到，取不到就不能说"最小/最大"）。

2.3 二次函数与一元二次方程、不等式

二次函数 y = ax² + bx + c（a ≠ 0）的图象

  • 图象是一条抛物线：a > 0 开口向上，a < 0 开口向下。
  • 对称轴：直线 x = −b/(2a)。
  • 顶点：(−b/(2a), (4ac − b²)/(4a))，它是抛物线的最高点或最低点。
  • |a| 越大，开口越窄（"越陡"）；|a| 越小，开口越宽。
物理含义：抛物线正是抛体运动的轨迹——y 是高度、x 是水平位移。顶点就是最高点（最大高度），对称轴两侧的运动"上升—下降"完全对称。

一元二次方程 ax² + bx + c = 0 的根

判别式 Δ = b² − 4ac 决定根的情况：

判别式根的情况抛物线与 x 轴
Δ > 0两个不相等实根有两个交点（穿过 x 轴）
Δ = 0两个相等实根（重根）一个交点（与 x 轴相切）
Δ < 0没有实根没有交点（够不着 x 轴）

求根公式：

x = (−b ± √(b² − 4ac)) / (2a)

根与系数的关系（韦达定理）：若 x₁、x₂ 是 ax² + bx + c = 0 的两根，则 x₁ + x₂ = −b/a，x₁ · x₂ = c/a。

三个"二次"的统一（本章核心！）

把方程、函数、不等式放到同一条抛物线上看，一切都清楚了：

  • 方程 ax² + bx + c = 0 的根 ⇔ 抛物线 y = ax² + bx + c 与 x 轴交点的横坐标。
  • 不等式 ax² + bx + c > 0 的解集 ⇔ 抛物线在 x 轴上方的点的横坐标范围。
  • 不等式 ax² + bx + c < 0 的解集 ⇔ 抛物线在 x 轴下方的点的横坐标范围。

（以下讨论 a > 0，即开口向上的情形）

判别式图象与 x 轴ax²+bx+c > 0 的解集ax²+bx+c < 0 的解集
Δ > 0交于 x₁ < x₂ 两点{ x | x < x₁ 或 x > x₂ }{ x | x₁ < x < x₂ }
Δ = 0相切于 x₀ 一点{ x | x ≠ x₀ }∅（空集）
Δ < 0无交点（全在 x 轴上方）R（全体实数）∅（空集）
几何含义：抛物线与 x 轴的交点就是不等式解集的"分界点"；"大于 0"就是图象在 x 轴上方，"小于 0"就是图象在 x 轴下方。判别式 Δ 的几何意义是"抛物线够不够得着 x 轴"：Δ > 0 穿过、Δ = 0 相切、Δ < 0 够不着。
物理含义：把 y = ax² + bx + c 看成抛体高度：方程 ax² + bx + c = 0 求的是"什么时候落地（高度为 0）"；不等式 ax² + bx + c > 0 求的是"在哪些水平位置物体还在空中（高度为正）"。Δ < 0 意味着"物体从头到尾都够不着地面"（或一直高于地面）。

解一元二次不等式的标准步骤

  1. 化标准形：把二次项系数化为正（若 a < 0，两边同乘 −1，同时不等号反向）。
  2. 求根：解方程 ax² + bx + c = 0，得根（或判定 Δ 符号）。
  3. 画草图：画出开口向上（或向下）的抛物线，标出与 x 轴的交点。
  4. 写解集：a > 0 时——"大于 0 取两边，小于 0 取中间"。

例：解不等式 x² − 3x + 2 > 0。

x² − 3x + 2 = (x − 1)(x − 2) > 0
两根 x₁ = 1，x₂ = 2；开口向上。
图象在 x 轴上方（两侧）：
∴ 解集为 { x | x < 1 或 x > 2 }

概念几何含义物理 / 现实含义
作差法比大小数轴上有向位移的正负两个量相差多少、谁大谁小
等式性质同时平移 / 拉伸不改变重合关系天平两边同加同乘仍平衡

判别式 Δ抛物线与 x 轴交点的个数抛体是否落地、几次落地

典型例题（自测）

  1. 已知 a > b，c < 0，求证 ac < bc，并在数轴上解释为什么"乘负数要掉头"。
  2. 已知 x > 0，求 x + 4/x 的最小值，并指出等号成立的条件。
  3. 用基本不等式证明：周长一定的矩形中，正方形面积最大。
  4. 解不等式 x² − 3x + 2 > 0 与 x² − 3x + 2 < 0，并画出抛物线草图。
  5. 已知二次函数 y = x² − 2x − 3，求它与 x 轴的交点、顶点、对称轴，并写出 y > 0 的解集。
  6. 解不等式 −x² + 4x − 3 > 0（注意二次项系数为负，先化正）。
  7. 若关于 x 的方程 x² + 2x + k = 0 有两个不相等的实根，求 k 的取值范围。

常见误区

  • ❌ "不等式两边乘负数，不等号方向不变" → 乘负数（或除负数）必须反向，本质是数轴上的镜像翻转。
  • ❌ 用基本不等式时忽略"一正" → a、b 必须为正，负数情形不能直接套用。
  • ❌ 求最值只写"≥"，不验证"三相等" → 等号取不到时，那个"≥"不能说明真的能取到最值。
  • ❌ 二次项系数为负时直接套"取两边 / 取中间" → 必须先化成正（同时反号），否则结论相反。
  • ❌ 把 Δ = 0 时"ax²+bx+c > 0 的解集"写成全体实数 → 应剔除顶点 x₀：{ x | x ≠ x₀ }。
  • ❌ 混淆"方程的根"与"不等式的解集" → 根是单个点，解集是区间，一元二次不等式常是"两段"或"中间一段"。

本章练习卷（含答案）

一、练习题

  1. 用作差法比较 2x² − x + 1 与 x² + x 的大小（x 为任意实数），并说明“作差”在数轴上代表什么几何含义。
  2. 判断下列说法的对错，并简要说明理由（重点体会“乘负数”带来的变化）：① 若 a > b，则 ac² > bc²；② 若 ac > bc，则 a > b；③ 若 a > b 且 c < 0，则 ac < bc。
  3. 已知 x > 0，求 x + 9/x 的最小值并指出等号成立的条件；再结合“圆中半弦长不超过半径”解释基本不等式 √(ab) ≤ (a+b)/2 的几何意义。
  4. 设矩形的长为 a、宽为 b（a > 0，b > 0），且半周长 a + b = p 为定值，用基本不等式证明：周长一定时，正方形面积最大。
  5. 解不等式 −x² + 4x − 3 > 0（先化二次项系数为正），并说明解集对应抛物线的哪一段（x 轴上方还是下方）。
  6. 已知二次函数 y = x² − 2x − 3：① 求它与 x 轴的交点、顶点、对称轴；② 写出 y > 0 与 y < 0 的解集；③ 若把 y 看作“高度”、x 看作“水平位移”，方程 x² − 2x − 3 = 0 与不等式 x² − 2x − 3 < 0 分别回答了什么实际问题？

二、参考答案（点击展开）

查看第1题答案

作差：(2x² − x + 1) − (x² + x) = x² − 2x + 1 = (x − 1)² ≥ 0，所以 2x² − x + 1 ≥ x² + x，当且仅当 x = 1 时取等号。几何含义：a − b 是数轴上从点 b 到点 a 的有向位移，差为正表示结果在右边（大），差为负表示在左边（小），差为 0 表示两点重合。

查看第2题答案

① 错。当 c = 0 时 ac² = bc² = 0，不成立（“乘平方”未必保序，c = 0 时变成相等）。② 错。若 c < 0，两边同除负数要反向，应得 a < b。③ 对。乘负数等于在数轴上做关于原点的镜像翻转，两点左右位置对调，不等号必须反向。

查看第3题答案

x + 9/x ≥ 2√(x · 9/x) = 6，当且仅当 x = 9/x 即 x = 3 时取等号，最小值为 6。几何意义：在圆直径 AB 上取点 C，令 AC = a、CB = b，半径等于 (a+b)/2，过 C 作垂线交圆所得半弦长等于 √(ab)；半弦永远不超过半径，故 √(ab) ≤ (a+b)/2，且当 C 与圆心重合（a = b）时等号成立。

查看第4题答案

面积 S = ab，由基本不等式 ab ≤ ((a+b)/2)² = (p/2)²（两正数 a、b 的几何平均数不超过算术平均数）。等号当且仅当 a = b 时成立，即长宽相等（正方形）时面积最大，最大值为 p²/4。

查看第5题答案

两边同乘 −1（不等号反向）：x² − 4x + 3 < 0，即 (x − 1)(x − 3) < 0，得 1 < x < 3。抛物线 y = −x² + 4x − 3 开口向下，与 x 轴交于 1、3 两点，故在两交点之间的这段图象位于 x 轴上方，解集正是这段横坐标范围 { x | 1 < x < 3 }。

查看第6题答案

① x² − 2x − 3 = (x − 3)(x + 1)，与 x 轴交点为 (−1, 0) 与 (3, 0)；对称轴 x = 1；顶点 (1, −4)。② 开口向上，y > 0 的解集为 { x | x < −1 或 x > 3 }，y < 0 的解集为 { x | −1 < x < 3 }。③ 方程求的是“何时落地”（高度为 0 时的水平位置 x = −1 或 x = 3）；不等式 y < 0 求的是“在哪些水平位置物体低于出发水平面（高度为负）”，即 −1 到 3 之间。
