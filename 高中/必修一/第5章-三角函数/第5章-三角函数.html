第5章 三角函数

高中 / 必修第一册

一句话总纲：三角函数 = 「单位圆上周而复始的旋转运动」在坐标轴上的投影。角的终边在单位圆上旋转一圈，横坐标是余弦、纵坐标是正弦——三角函数的全部公式，本质上都是"圆上的旋转与对称"的代数表达。学完本章，你要能在心里"看见"一个点沿着单位圆匀速转圈，正弦、余弦就是它的纵、横坐标随时间往返振荡，诱导公式就是"转半圈/翻镜像"的位置关系，而 y = A sin(ωx+φ) 就是描述振动与波动的通用语言。

5.1 任意角与弧度制

角的新定义：旋转出来的角

初中把角看成"两条射线夹出的图形"，范围是 0° 到 360°。但现实中的运动是连续、可以超过一圈、也可以反向的：秒针转 3 分钟是 18 圈，即 6480°；拧螺丝既可以顺时针也可以逆时针。于是我们把角重新定义为：

  • 角：一条射线从始边出发，绕端点旋转到终边所成的图形。旋转的量就是角的大小。
  • 正角：按逆时针方向旋转得到的角。
  • 负角：按顺时针方向旋转得到的角。
  • 零角：没有旋转（始边与终边重合）。
物理含义：角 = 旋转的"位移量"。正负号记录的是旋转方向（逆时针为正、顺时针为负），角度的大小记录转了多少。这和"位移"有方向有大小完全同理——角就是圆周运动里的"位移"。

象限角与终边相同的角

把角的顶点放在坐标原点，始边与 x 轴正半轴重合，则终边落在第几象限，就称这个角是第几象限角（终边在坐标轴上的角叫轴线角，不属于任何象限）。

终边相同的角：相差整数个整圈（360°）的角，终边完全相同。所有与角 α 终边相同的角可以统一写成：

β = α + k·360°   (k ∈ Z)    或     β = α + 2kπ   (k ∈ Z)
几何含义："终边相同的角"就是转了整数圈后又回到同一条射线。一个终边位置对应无穷多个角，它们之间只差 360° 的整数倍——几何上"位置"唯一，代数上"数值"不唯一。

弧度制：用"弧长"量角

角度制以 1/360 圆周为单位，是人为规定。弧度制则从几何本身出发：

定义（几何本质）：在圆上取一段弧，若弧长等于半径，则这段弧所对的圆心角就是 1 弧度（1 rad）。弧度 = 弧长 ÷ 半径，即
|α| = l / r   （l 为弧长，r 为半径，α 为圆心角的弧度数）

因为整圆的周长是 2πr，所以整圆所对的圆心角是 2πr / r = 2π 弧度，即：

360° = 2π rad        180° = π rad        1° = π/180 rad ≈ 0.01745 rad        1 rad ≈ 57.3°

弧长公式与扇形面积公式（弧度制下变得极其简洁）：

弧长  l = α·r
扇形面积  S = ½ l·r = ½ α·r²   （α 用弧度）
物理/工程含义：弧度制的核心好处是"角 × 半径 = 弧长"这个线性关系。线速度与角速度之间才有简洁关系 v = ω·r、向心加速度 a = ω²r，简谐振动、交流电、波动方程里所有 ω 都是弧度制。用弧度制，三角函数求导公式 sin'x = cos x 才成立（没有任何系数污染），因此高等数学几乎只用弧度制。

5.2 三角函数的概念

从"直角三角形的边比"到"单位圆上的坐标"

初中在直角三角形里定义：sin A = 对边/斜边，cos A = 邻边/斜边，tan A = 对边/邻边。这只能处理 0°～90° 的锐角。高中用单位圆把它推广到任意角：

  • 以坐标原点为圆心、半径 1 的圆叫单位圆。
  • 设角 α 的终边与单位圆交于点 P(x, y)，则定义：
sin α = y        cos α = x        tan α = y / x   (x ≠ 0)

也就是：正弦 = 终边与单位圆交点的纵坐标；余弦 = 横坐标；正切 = 纵坐标/横坐标（即直线 OP 的斜率）。

几何含义（本章最重要的图景）：点 P 在单位圆上，角 α 变，P 就沿圆周旋转。P 的纵坐标就是 sin α，P 的横坐标就是 cos α。因为 P 永远在圆上，所以 |x| ≤ 1、|y| ≤ 1，即 |sin α| ≤ 1、|cos α| ≤ 1，且恒有 x² + y² = 1，这正是同角关系 sin²α + cos²α = 1 的几何来源。

如果角的终边与以原点为圆心、r 为半径的圆交于 P(x, y)，则（比值定义，与半径无关）：

sin α = y / r        cos α = x / r        tan α = y / x        r = √(x² + y²)
为什么比值与半径无关？因为任意两个半径不同的同心圆上，同一角对应的点是"位似"的：坐标按同一比例放大缩小，y/r、x/r 的比值不变。这就是"相似三角形对应边成比例"的推广——三角函数是"方向"的函数，与"距离"无关。

三角函数值的符号（由坐标决定）

sin α 看纵坐标 y，cos α 看横坐标 x，tan α 看 y/x，所以各象限符号为：

象限sin（纵坐标）cos（横坐标）tan（斜率）
第一象限+++
第二象限+−−
第三象限−−+
第四象限−+−

口诀："一全正，二正弦，三正切，四余弦"——第一象限全正，第二象限只有 sin 正，第三象限只有 tan 正，第四象限只有 cos 正。

特殊角的三角函数值（必须烂熟）

角（度/弧度）0° (0)30° (π/6)45° (π/4)60° (π/3)90° (π/2)
sin01/2√2/2√3/21
cos1√3/2√2/21/20
tan0√3/31√3不存在
记忆的几何来源：30°(π/6) 对应"半个等边三角形"（30°-60°-90°，三边比 1:√3:2），45°(π/4) 对应"等腰直角三角形"（45°-45°-90°，三边比 1:1:√2）。把这些直角三角形"塞进"单位圆，坐标就一目了然，不必死记。

三角函数线（把"比值"画成"线段"）

  • 正弦线 MP：过 P 作 x 轴的垂线，垂足 M，有向线段 MP 的长（带符号）就是 sin α。
  • 余弦线 OM：从原点 O 到 M 的有向线段，就是 cos α。
  • 正切线 AT：过单位圆与 x 轴正半轴交点 A(1,0) 作切线，与终边延长线交于 T，有向线段 AT 就是 tan α。
几何含义：三角函数线把抽象的"比值"还原成圆上一条条有方向的线段，是研究三角函数性质（单调性、最值、解三角不等式）最直观的工具。

同角三角函数的基本关系

平方关系：  sin²α + cos²α = 1
商数关系：  tan α = sin α / cos α    (cos α ≠ 0)
几何含义：平方关系就是"点 P 在单位圆上满足 x² + y² = 1"；商数关系就是"tan = 终边斜率 = y/x = sin/cos"。这两条关系把三个函数"锁"在一起：知其一可求其余（需结合象限定符号）。

5.3 诱导公式

诱导公式回答一个问题：任意角的三角函数，如何化成锐角（0～π/2）的三角函数？它的全部来源是"角的终边经过旋转与对称后，坐标如何变化"。

公式一：终边相同（绕整圈）

sin(α + 2kπ) = sin α      cos(α + 2kπ) = cos α      tan(α + 2kπ) = tan α   (k ∈ Z)
几何含义：转整数圈回到原位，坐标不变，函数值当然不变——这就是三角函数的周期性的源头。

公式二：关于原点对称（π + α）

sin(π + α) = −sin α      cos(π + α) = −cos α      tan(π + α) = tan α
几何含义：角 α 的终边绕原点转半圈（加 π），终点 P 变成关于原点对称的点 P'，坐标由 (x, y) 变 (−x, −y)。所以 sin、cos 都变号，而 tan = y/x = (−y)/(−x) 不变。

公式三：关于 x 轴对称（−α）

sin(−α) = −sin α      cos(−α) = cos α      tan(−α) = −tan α
几何含义：−α 与 α 的终边关于 x 轴对称，P(x, y) 变为 P'(x, −y)。纵坐标变号（sin 变号）、横坐标不变（cos 不变）。这说明：sin 是奇函数、cos 是偶函数，根源就在这条对称。

公式四：关于 y 轴对称（π − α）

sin(π − α) = sin α      cos(π − α) = −cos α      tan(π − α) = −tan α
几何含义：π − α 与 α 的终边关于 y 轴对称，P(x, y) 变为 P'(−x, y)。纵坐标不变（sin 不变）、横坐标变号（cos 变号）。

公式五、六：关于直线 y = x 对称（π/2 ∓ α）

sin(π/2 − α) = cos α      cos(π/2 − α) = sin α
sin(π/2 + α) = cos α      cos(π/2 + α) = −sin α
几何含义：π/2 − α 与 α 的终边关于直线 y = x 对称，交换横纵坐标，(x, y) → (y, x)，所以 sin、cos 互换。这正是"余角"：两角互余时，一个角的正弦等于另一个角的余弦——"co-"（余）的来历。

统一记忆：奇变偶不变，符号看象限

  • 把任意角写成 k·(π/2) ± α 的形式（α 视为锐角）。
  • 奇变偶不变：k 为奇数时，函数名变（sin ↔ cos，tan ↔ cot）；k 为偶数时，函数名不变。
  • 符号看象限：把 α 看作锐角，看 k·(π/2) ± α 落在第几象限，取原函数在该象限的符号。
本质：诱导公式没有引入任何新运算，它只是"对称变换改变坐标符号"的记账：转整圈、翻转关于 x 轴/y 轴/原点/对角线，共四类对称，对应四组公式。理解了"终边对称 → 坐标变号"，全部诱导公式可以现场推出来。

5.4 三角函数的图象与性质

正弦曲线：旋转投影在时间轴上的展开

把角 α 当作自变量 x（用弧度），把 sin x 的值画成曲线，就得到正弦曲线。它可以用"五点法"作出一个周期内的图象：

关键五点： (0,0)  (π/2,1)  (π,0)  (3π/2,−1)  (2π,0)
物理图景：想象一个点 P 在单位圆上逆时针匀速转动，它的纵坐标（高度）随时间的变化就是正弦曲线——圆周运动"投影"到竖直方向，就成了往返的简谐振动。sin x 是一条"沿水平方向无限重复的波浪线"。

余弦曲线：正弦曲线向左平移 π/2

cos x = sin(x + π/2)
几何含义：余弦就是正弦"提前了 π/2 相位"。从单位圆看，横坐标 x（余弦）与纵坐标 y（正弦）在圆上永远相差 90° 的位置，所以两条曲线形状完全相同，只是左右错开 π/2。

物理含义：值域 [−1,1] 是"投影长度不超过半径"；周期 2π 是"转一整圈回到原状态"；奇偶性对应"波的对称性"（正弦波关于原点反对称、余弦波关于 y 轴对称）；单调区间就是"上升沿/下降沿"。

正切函数 y = tan x 的图象与性质

定义域：x ≠ π/2 + kπ   值域：R   最小正周期：π   奇函数
几何含义：tan x 是终边的斜率，当终边接近竖直（x → π/2）时斜率趋于无穷，所以图象在 x = π/2 + kπ 处有竖直渐近线，曲线被切成一支支无限上升的"S 形"。周期是 π 而非 2π：因为终边反向（加 π）斜率不变。

周期性、奇偶性与对称性的深层联系

  • 周期函数：f(x + T) = f(x) 对一切 x 成立，最小正 T 叫最小正周期。
  • sin、cos 的周期 2π 来自"整圈"；tan 的周期 π 来自"反向斜率不变"。
物理含义：周期性 = 运动的重复性（钟摆、交流电、四季），是三角函数区别于其它函数的最核心特征，也是它能描述"周期现象"（振动、波、交变电流、声光信号）的根本原因。

5.5 三角恒等变换

恒等变换解决"角的运算"问题：已知 α、β 的三角函数，求 α±β、2α、α/2 等的三角函数。

两角和与差的正弦、余弦、正切

cos(α − β) = cos α cos β + sin α sin β
cos(α + β) = cos α cos β − sin α sin β
sin(α + β) = sin α cos β + cos α sin β
sin(α − β) = sin α cos β − cos α sin β
tan(α + β) = (tan α + tan β) / (1 − tan α tan β)
tan(α − β) = (tan α − tan β) / (1 + tan α tan β)
几何含义（cos(α−β) 的证明核心）：在单位圆上取角 α、β 的终边，它们对应的两个点 A、B 间的弦长，可以用两种方式计算：一是两点间距离公式（含 cos(α−β)），二是"把角 α−β 摆正"后直接读坐标。弦长不变 → 两边相等 → 得到 cos(α−β) 公式。一句话：两角差的余弦 = "圆上两点距离"在两种坐标系下的等量表达。

二倍角公式（令 β = α）

sin 2α = 2 sin α cos α
cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α
tan 2α = 2 tan α / (1 − tan²α)
物理含义：二倍角公式是"倍频"：把一个频率的信号 sin 2α 拆成两个同频 sin α 与 cos α 的乘积（调制、混频、谐波分析的基础）。sin 2α = 2 sin α cos α 是波动与信号处理里最常用的"倍角→乘积"桥梁。

降幂公式与半角公式（由 cos 2α 变形）

sin²α = (1 − cos 2α) / 2        cos²α = (1 + cos 2α) / 2
sin(α/2) = ±√((1 − cos α)/2)    cos(α/2) = ±√((1 + cos α)/2)
tan(α/2) = sin α / (1 + cos α) = (1 − cos α) / sin α
几何/物理含义：降幂公式把"平方"变成"一次 + 倍角"，是求积分、算功率（平均功率 ∝ 均值 sin² = 1/2）的关键——交流电的有效值 Ieff = Imax/√2 就来自 sin² 的平均值等于 1/2。

辅助角公式（化一公式，极其重要）

a sin x + b cos x = √(a² + b²) · sin(x + φ)
其中  cos φ = a / √(a² + b²)， sin φ = b / √(a² + b²)，  tan φ = b / a
几何含义：把 (a, b) 看作平面向量，√(a²+b²) 是它的长度，φ 是它的方向角。辅助角公式就是"两个相差 90° 相位的振动，合成为一个同频率、振幅为 √(a²+b²)、初相为 φ 的振动"——同频振动的叠加仍是同频振动。这是声学干涉、电路交流分析的数学基石。

积化和差、和差化积（了解即可）

sin α cos β = ½[sin(α+β) + sin(α−β)]        cos α cos β = ½[cos(α+β) + cos(α−β)]
sin α sin β = ½[cos(α−β) − cos(α+β)]
sin α + sin β = 2 sin((α+β)/2) cos((α−β)/2)   sin α − sin β = 2 cos((α+β)/2) sin((α−β)/2)
cos α + cos β = 2 cos((α+β)/2) cos((α−β)/2)   cos α − cos β = −2 sin((α+β)/2) sin((α−β)/2)
物理含义：积化和差把"两个频率的乘积"写成"频率的和与差"（收音机的混频原理）；和差化积把"两列波的叠加"写成"拍频包络"——两个接近的频率合成后会出现拍（声音忽强忽弱的"嗡嗡"声）。

5.6 函数 y = A sin(ωx + φ)

这是整个三角函数的"总装"：把振幅、频率、初相三个物理参数都放进一个函数里。

三个参数的意义

y = A·sin(ωx + φ)   （A > 0， ω > 0）

A  —— 振幅（最大偏离平衡位置的距离），值域为 [−A, A]
ω  —— 角频率（角速度），决定周期  T = 2π/ω， 频率  f = 1/T = ω/(2π)
φ  —— 初相（t=0 时的相位），图象由 y = A sin(ωx) 向左(φ>0)或向右平移 |φ|/ω
物理含义（简谐振动）：弹簧振子、单摆的位移可写成 x(t) = A sin(ωt + φ)。A 是"摆幅多大"，ω 是"摆得多快"（由系统本身决定，如单摆 ω = √(g/l)），φ 由"起始时刻从哪开始"决定。交流电 u = Um sin(ωt + φ) 中，Um 是峰值电压、ω = 2πf（f=50Hz 市电则 ω = 100π）、φ 是初相位。

图象变换：从 y = sin x 出发

  • 相位变换（平移）：y = sin(x + φ)，图象向左(φ>0)或向右平移 |φ| 个单位。
  • 周期变换（横向伸缩）：y = sin(ωx)，横坐标变为原来的 1/ω（ω>1 压缩，0<ω<1 拉伸）。
  • 振幅变换（纵向伸缩）：y = A sin x，纵坐标变为原来的 A 倍。

综合顺序（常见规范）：先平移，后伸缩，即

y = sin x  →（左/右平移 |φ|）→ y = sin(x + φ) →（横坐标变 1/ω）→ y = sin(ωx + φ) →（纵坐标变 A 倍）→ y = A sin(ωx + φ)
易错点（几何）："y = sin(x + φ) 到 y = sin(ωx + φ)"，自变量 x 被整体替换成 ωx，是横向伸缩，不是平移 |φ|。若从 y = sin(ωx) 直接平移，则需平移 |φ|/ω 个单位（因为要把 ωx + φ 提成 ω(x + φ/ω)）。平移量永远是"对 x 本身"的，必须先把系数提出来。

五点法作 y = A sin(ωx + φ) 的图象

令 ωx + φ 依次等于 0, π/2, π, 3π/2, 2π，解出对应的 x 和函数值 0, A, 0, −A, 0，描点连线即可。

物理含义：这五点对应振动在一个周期内的五个关键状态：平衡位置 → 正向最大位移 → 平衡位置 → 负向最大位移 → 平衡位置，完整刻画了一次"往返"。

典型例题（自测）

  1. 把 −570° 化成弧度，并写成 0 ≤ θ < 2π 的形式；求与 750° 终边相同的角的集合。
  2. 已知角 α 的终边过点 P(−3, 4)，求 sin α、cos α、tan α。
  3. 已知 sin α = 3/5，且 α 在第二象限，求 cos α 与 tan α。
  4. 化简：sin(π + α)·cos(−α) + sin(π/2 − α)·cos(π − α)。
  5. 求 y = 2 sin(3x − π/6) 的振幅、周期、初相，并用五点法作一个周期内的图象。
  6. 求 f(x) = √3 sin x + cos x 的最大值，并化为 y = A sin(x + φ) 的形式。

常见误区

  • ❌ "角度制也能直接代入三角函数公式运算" → ❌ 诱导、和差、求导等公式只在弧度制下成立（如 sin(π/2 − α) = cos α，π 是弧度），遇到度数先换成弧度。
  • ❌ "sin(α+β) = sin α + sin β" → ❌ 正弦不是线性的，正确公式是 sin α cos β + cos α sin β。
  • ❌ "y = sin(x + φ) 到 y = sin(ωx + φ) 是向左平移 |φ|" → ❌ 这是横向伸缩（横坐标变 1/ω），平移量需先提系数算 |φ|/ω。
  • ❌ "周期由 A 决定" → ❌ A 只决定振幅（纵的伸缩），周期 T = 2π/ω 由 ω 决定。
  • ❌ "sin 在任意区间都单调" → ❌ sin 只在 [−π/2+2kπ, π/2+2kπ] 递增，须先看区间。
  • ❌ "知 sin α 即可唯一确定 α" → ❌ 同一边比对应两个象限的角（sin 为正在一、二象限），需象限或 cos 的符号辅助确定。
  • ❌ "tan 的周期是 2π" → ❌ tan 周期是 π（终边反向斜率不变）。
  • ❌ "把 φ 当平移距离直接读" → ❌ y = A sin(ωx + φ) 中相位平移量是 |φ|/ω，不是 |φ|。

本章练习卷（含答案）

一、练习题

  1. 把 −570° 化成弧度，并写成 0 ≤ θ < 2π 的形式；再写出所有与 750° 终边相同的角的集合。
  2. 已知角 α 的终边经过点 P(−3, 4)，求 sin α、cos α、tan α 的值。
  3. 已知 sin α = 3/5，且 α 是第二象限角，求 cos α 与 tan α。
  4. 化简：sin(π + α)·cos(−α) + sin(π/2 − α)·cos(π − α)。
  5. 求函数 y = 2 sin(3x − π/6) 的振幅、周期、初相，并用五点法写出一个周期内五个关键点的坐标。
  6. 把 f(x) = √3 sin x + cos x 化为 y = A sin(x + φ) 的形式，并求它的最大值与取得最大值时的 x 的集合。

二、参考答案（点击展开）

查看第1题答案

−570° = −570 × π/180 = −19π/6。加 2π（即 12π/6）的整数倍化到 [0, 2π)：−19π/6 + 4π = −19π/6 + 24π/6 = 5π/6，所以 θ = 5π/6。与 750° 终边相同的角：750° − 360° × 2 = 30°，故集合为 { β | β = 30° + k·360°, k ∈ Z }（弧度制为 β = π/6 + 2kπ）。

查看第2题答案

先求 r = √((−3)² + 4²) = 5。由比值定义：sin α = y/r = 4/5，cos α = x/r = −3/5，tan α = y/x = 4/(−3) = −4/3。几何含义：点 P 在第二象限，纵坐标为正、横坐标为负，故 sin 正、cos 负、tan 负，与符号口诀"二正弦"一致。

查看第3题答案

由平方关系 sin²α + cos²α = 1 得 cos²α = 1 − (3/5)² = 16/25，即 cos α = ±4/5。因 α 在第二象限，cos α < 0，故 cos α = −4/5；再由商数关系 tan α = sin α / cos α = (3/5) / (−4/5) = −3/4。几何含义：第二象限横坐标（cos）为负、纵坐标（sin）为正。

查看第4题答案

逐项用诱导公式：sin(π + α) = −sin α；cos(−α) = cos α（cos 是偶函数）；sin(π/2 − α) = cos α（余角互换）；cos(π − α) = −cos α。原式 = (−sin α)·cos α + cos α·(−cos α) = −sin α cos α − cos²α = −cos α (sin α + cos α)。（若按教材常见版本取 sin(π/2 − α)·cos(π − α) = cos α·(−cos α)，结果即 −cos α(sin α + cos α)。）

查看第5题答案

对照 y = A sin(ωx + φ)：振幅 A = 2；ω = 3，周期 T = 2π/ω = 2π/3；初相 φ = −π/6。五点法：令 3x − π/6 依次取 0, π/2, π, 3π/2, 2π，解得 x 依次为 π/18, 2π/9, 7π/18, 5π/9, 13π/18，对应函数值 0, 2, 0, −2, 0。五点为 (π/18,0)、(2π/9,2)、(7π/18,0)、(5π/9,−2)、(13π/18,0)。

查看第6题答案

辅助角公式：a = √3, b = 1，则 √(a² + b²) = √(3 + 1) = 2，tan φ = b/a = 1/√3，取 φ = π/6（此时 cos φ = √3/2、sin φ = 1/2）。故 f(x) = 2 sin(x + π/6)。最大值 2，在 x + π/6 = π/2 + 2kπ，即 x = π/3 + 2kπ (k ∈ Z) 时取得。几何含义：两个相差 90° 相位的振动合成为一个振幅为 2、初相为 π/6 的同频振动。
