第3章 函数的概念与性质

高中 / 必修第一册

一句话总纲：函数 = 两个数集之间的"唯一对应关系"——定义域是"输入"的范围、值域是"输出"的范围，单调性描述图像"上升还是下降"、奇偶性描述图像"关于谁对称"；学完本章，你要能在心里同时"看见"一条函数曲线，并把它翻译成物理量随时间、随位置变化的规律。

3.1 函数的概念

从初中的"变量说"到高中的"对应说"

初中我们对函数的理解是变量说：在一个变化过程中有两个变量 x 与 y，x 每取一个值，y 都有唯一确定的值与之对应，就说 y 是 x 的函数。高中的要求更进一步——把"变化过程"这个含糊的说法，换成集合与对应的精确语言，并由此引出定义域、值域、图像、性质这一整套体系。

函数的定义（集合对应说）

设 A、B 是两个非空的数集。如果按某种确定的对应关系 f，使对于集合 A 中的任意一个数 x，在集合 B 中都有唯一确定的数 y与之对应，那么就称 f : A → B 为从集合 A 到集合 B 的一个函数，记作：

y = f(x),   x ∈ A

其中：

  • x 叫自变量，x 的取值范围 A 叫函数的定义域；
  • 与 x 的值相对应的 y 值叫函数值，函数值的集合 { f(x) | x ∈ A } 叫函数的值域。
逐字拆解定义中的关键词："任意一个 x" 保证每个输入都有输出（定义域内的数必须全部有对应）；"唯一确定的 y" 保证一个输入只对应一个输出（不能一个 x 既对应 y₁ 又对应 y₂）。这两条合起来就是"函数是一个单值对应"。反过来，同一个 y 可以被多个 x 对应——这是允许的。

函数的三要素

  • 定义域：自变量 x 的取值范围 A。
  • 对应关系 f：把 x 变成 y 的规则（解析式、图像、表格都可以表达）。
  • 值域：所有函数值构成的集合。

两个函数相等（是同一个函数）当且仅当：定义域相同 且 对应关系完全一致（值域自动相同）。例：f(x) = x 与 g(x) = √(x²) 不是同一个函数——虽然化简后都像 "x"，但 g 的值域是 [0, +∞)，对应关系本质是"取绝对值"；而 f(x) = x² 与 g(x) = t² 是同一个函数（自变量用哪个字母无关紧要）。

区间的表示

集合区间表示含义
{ x | a ≤ x ≤ b }[a, b]闭区间，含两端点
{ x | a < x < b }(a, b)开区间，不含两端点
{ x | a ≤ x < b }[a, b)左闭右开
{ x | a < x ≤ b }(a, b]左开右闭
{ x | x ≥ a }[a, +∞)到正无穷
{ x | x < b }(−∞, b)到负无穷

注意：+∞、−∞ 不是数，是"方向"的符号，所以无穷一端永远写开括号。

f(x) 与 f(a) 的区别

  • f(x)：表示"以 x 为自变量的函数"，x 是变量，f(x) 随 x 变而变。
  • f(a)：表示"当 x = a 时的函数值"，是一个确定的数（把 a 代入 f 的结果）。

函数的图像（几何含义的核心）

函数 y = f(x) 的图像，是平面直角坐标系中所有点 (x, f(x)) 构成的图形，其中 x 取遍定义域。这标志着数与形的第二次统一：第一次（有理数）用数轴把"数"和"点"对应起来，这一次用坐标系把"对应关系"和"曲线"对应起来。

几何含义：函数的图像就是"对应关系 f 的相片"。定义域决定了图像在 x 轴方向铺多宽，值域决定了图像在 y 轴方向爬多高，f 的规则决定了曲线的"长相"。于是所有关于函数的抽象性质（单调、对称、最大最小），都能在图上用眼睛读出来。

竖直直线检验法：一条竖直直线与图形至多交于一个点时，该图形才是某个函数的图像。因为若竖直线 x = x₀ 与图形交于两点，就意味着同一个 x₀ 对应两个不同的 y——违背"唯一确定"。（圆、抛物线"横放"都不是函数图像。）

函数的表示法

  • 解析法：用式子表示，如 f(x) = 2x + 1。最精确，便于运算。
  • 列表法：用表格列出 x 与 y 的对应值。直观，但不连续、不完整。
  • 图像法：画出图像。最直观，能从趋势上读出性质。
物理含义：函数是"输入—输出"的黑箱（映射器）。你往 f 里丢进一个 x，它按规则吐出一个唯一的 y。比如摄氏温度转华氏温度 F = (9/5)·C + 32：输入摄氏温度 C，输出华氏温度 F；自由落体 h = ½gt²：输入时间 t，输出下落高度 h；匀速运动 s = vt：输入时间，输出位移。凡是一个量由另一个量唯一决定，两者之间就存在一个函数关系。

3.2 定义域与值域

定义域：自变量的"合法范围"

定义域是使函数有意义的自变量 x 的全体。分两类：

  • 自然定义域：仅由解析式本身"能不能算"决定。
  • 实际定义域：由实际问题的物理/现实意义决定，往往比自然定义域更小。

求定义域的几条铁律

  • 分式的分母 ≠ 0：y = 1/(x − 2) 中要求 x ≠ 2。
  • 偶次根式的被开方数 ≥ 0：y = √(x + 1) 中要求 x + 1 ≥ 0，即 x ≥ −1。（奇次根式无此限制，³√x 对一切实数都有意义。）
  • 零次幂 / 负指数幂的底数 ≠ 0：y = (x − 1)⁰ 中要求 x ≠ 1。
  • 实际问题要符合实际：时间是 t ≥ 0，长度、面积、人数等都是非负整数，圆的面积 S = πr² 要求 r > 0。

同时满足多条限制时，把每条限制解出来取交集。

复合函数的定义域（求"外层允许的 x"）

若 y = f(g(x))，则 x 必须满足：g(x) 落在 f 的定义域内。典型题型：已知 f(x) 的定义域为 [0, 1]，求 f(x + 2) 的定义域——令 0 ≤ x + 2 ≤ 1，得 −2 ≤ x ≤ −1。注意：f 的定义域是"f 后面整个括号"的取值范围，而不是 x 直接的范围。

值域：函数值的"全体结果"

值域 = 自变量取遍定义域时，函数值 y 所能达到的所有值的集合。常用求法：

  • 观察法：直接看出范围。如 y = x²，因为 x² ≥ 0，值域为 [0, +∞)。
  • 配方法：配成完全平方式。如 y = x² + 2x + 3 = (x + 1)² + 2，因 (x + 1)² ≥ 0，故 y ≥ 2，值域 [2, +∞)。
  • 图像法 / 端点法：对一次函数在闭区间上，值域就是两端点函数值之间的范围。如 y = 2x + 1, x ∈ [1, 3]，值域 [3, 7]。
  • 分离常数法：对分式型，如 y = (2x + 1)/(x + 1) = 2 − 1/(x + 1)，因 1/(x + 1) ≠ 0，故 y ≠ 2，值域为 { y | y ≠ 2 }。
  • 换元法：对含根式的式子设 t = √(…)，化为二次函数再求。
几何含义（投影！）：把函数图像沿竖直方向"压扁"到 x 轴上，得到的区间就是定义域（图像在 x 轴上的投影）；把图像沿水平方向"压扁"到 y 轴上，得到的区间就是值域（图像在 y 轴上的投影）。定义域 = "横着看图像铺到哪"，值域 = "竖着看图像长到哪"。
物理含义：定义域 = 自变量在物理上允许的取值范围（时间 t ≥ 0、高度 h ≥ 0、质量 m > 0）；值域 = 因变量在物理上可能达到的所有取值（下落的深度、能达到的速度范围、温度区间）。求值域本质上是在问：这个物理量在整个过程中最高能到多少、最低能到多少、能不能取到中间的一切值。

3.3 单调性与最大（小）值

增函数与减函数的定义

设函数 f(x) 的定义域为 I，区间 D ⊆ I：

增函数（单调递增）：对任意 x₁, x₂ ∈ D，当 x₁ < x₂ 时，都有 f(x₁) < f(x₂)，则称 f(x) 在区间 D 上单调递增，D 叫 f(x) 的增区间。

减函数（单调递减）：对任意 x₁, x₂ ∈ D，当 x₁ < x₂ 时，都有 f(x₁) > f(x₂)，则称 f(x) 在区间 D 上单调递减，D 叫 f(x) 的减区间。

几何含义：单调递增 = 图像从左到右一路上升（x 越大 y 越大）；单调递减 = 图像从左到右一路下降（x 越大 y 越小）。"单调"一词的本意就是"图像不拐弯、不反复"。物理含义：单调递增 = 一个量随时间/位置持续增大，如自由落体下落过程中速度 v = gt 不断增大；单调递减 = 一个量持续减小，如热水自然冷却时温度 T 随时间递减。

定义里两个关键词："任意"——必须是区间内每一对满足 x₁ < x₂ 的数都成立，不能只挑两三个点验证；"区间 D"——单调性是局部性质，必须说清"在哪个区间上"单调。比如 f(x) = x² 在 (−∞, 0] 上单调递减，在 [0, +∞) 上单调递增，却不能说"f(x) 在 R 上单调"。

用定义证明单调性的标准步骤

以证明 f(x) = x² 在 [0, +∞) 上单调递增为例，五步走：

  1. 取值：任取 x₁, x₂ ∈ [0, +∞)，且 x₁ < x₂；
  2. 作差：f(x₁) − f(x₂) = x₁² − x₂²；
  3. 变形：= (x₁ − x₂)(x₁ + x₂)；
  4. 定号：由 x₁ < x₂ 得 x₁ − x₂ < 0；又 x₁, x₂ ≥ 0，故 x₁ + x₂ > 0；于是 (x₁ − x₂)(x₁ + x₂) < 0；
  5. 下结论：f(x₁) − f(x₂) < 0，即 f(x₁) < f(x₂)，所以 f(x) = x² 在 [0, +∞) 上单调递增。
作差的本质：f(x₁) − f(x₂) 的符号 = "图像在两点间是升还是降"的代数判据。差为负 → x 增大时 y 也增大 → 上升；差为正 → 下降。把代数式子因式分解、配方，就是为了让"差的正负"一目了然。

单调区间与最值的关系

单调性直接决定最值位置：若 f(x) 在闭区间 [a, b] 上单调递增，则最小值在左端点 f(a)、最大值在右端点 f(b)；若单调递减则相反。若函数"先增后减"，则最大值在"转折点"（顶点）处取得。

最大值与最小值的定义

设函数 f(x) 的定义域为 I：

  • 若存在 x₀ ∈ I，使 f(x₀) = M，且对任意 x ∈ I 都有 f(x) ≤ M，则称 M 是 f(x) 的最大值；
  • 若存在 x₀ ∈ I，使 f(x₀) = m，且对任意 x ∈ I 都有 f(x) ≥ m，则称 m 是 f(x) 的最小值。

定义的两个要求缺一不可：① 能取到（存在 x₀ 使函数值恰好等于 M）；② 不会超过（所有函数值都不大于 M）。

几何含义：最大值 = 图像最高点的纵坐标，最小值 = 图像最低点的纵坐标。一个函数在给定区间上可能没有最值——如 f(x) = 1/x 在 (0, +∞) 上既无最大值也无最小值（它无限逼近 0 却取不到 0，也无限增大）。物理含义：最值 = 物理量的峰值与谷值：斜抛运动中弹丸达到的最大高度、某段时间内的最低温度、生产中的最大利润、汽车行驶的最短时间，都是"最值问题"在现实中的化身。

3.4 奇偶性

前提：定义域必须关于原点对称

讨论奇偶性之前，必须先检查定义域是否关于原点对称（即若 x 在定义域内，则 −x 也必须在定义域内）。定义域如 (−∞, +∞)、[−1, 1]、(−∞, 0) ∪ (0, +∞) 都关于原点对称；而 [0, +∞)、[1, 2] 不关于原点对称，此时函数既不是奇函数也不是偶函数。

偶函数与奇函数的定义

偶函数：对定义域内任意 x，都有 f(−x) = f(x)。

奇函数：对定义域内任意 x，都有 f(−x) = −f(x)。

几何含义：偶函数的图像关于 y 轴对称——把图像沿 y 轴对折，左右完全重合（镜像对称）；奇函数的图像关于原点对称——把图像绕原点旋转 180°，图形与自身完全重合（中心对称）。这就是"偶 = 偶次幂的对称"、"奇 = 奇次幂的对称"背后的几何事实。
物理含义：偶函数 = 正负输入给出相同输出，即现象与"方向的正负"无关，只与"距离/大小"有关：y = x²（离原点越远越大，左右一样）、y = |x|（只关心到原点的距离）、光的照度与距离平方成反比、弹簧的弹性势能 E = ½kx²（拉伸还是压缩，只要形变量 |x| 相同，能量相同）。奇函数 = 正负输入给出相反输出，即现象随方向"翻转"而"翻转"：y = x³、y = 1/x、弹簧的回复力 F = −kx（向右拉 x > 0 时弹力向左 F < 0，方向相反）、关于中点对称的位移。

判断奇偶性的标准步骤

  1. 求出定义域，判断是否关于原点对称（不对称 → 非奇非偶，直接结束）；
  2. 计算 f(−x)，与 f(x) 比较：若 f(−x) = f(x) → 偶函数；若 f(−x) = −f(x) → 奇函数；两者都不满足 → 非奇非偶。

常见例子（先记住，再理解）

函数奇偶性理由
y = x²、y = |x|、y = x⁴、y = c（常数）偶函数f(−x) = f(x)，图像关于 y 轴对称
y = x、y = x³、y = 1/x奇函数f(−x) = −f(x)，图像关于原点对称
y = x + 1非奇非偶f(−x) = −x + 1，既不等于 f(x) 也不等于 −f(x)
y = x² + x非奇非偶偶项 + 奇项混合，两种对称都被破坏

奇偶性的运算性质

奇 ± 奇 = 奇      偶 ± 偶 = 偶
奇 × 奇 = 偶      偶 × 偶 = 偶      奇 × 偶 = 奇
奇 ÷ 奇 = 偶      偶 ÷ 偶 = 偶      奇 ÷ 偶 = 奇   （分母不为 0）

例：f(x) = x³ + x 是奇函数（奇 + 奇 = 奇）；g(x) = x² + x⁴ 是偶函数（偶 + 偶 = 偶）；h(x) = x·x² = x³ 是奇函数（奇 × 偶 = 奇）。

对称性的力量：知道函数是奇/偶函数，就只需研究 x ≥ 0 的半边图像，另一半由对称性免费得到。例如已知偶函数在 [0, +∞) 上的图像，把它沿 y 轴翻折即得全图；已知奇函数在 [0, +∞) 上的图像，把它绕原点旋转 180° 即得全图。这是"利用对称减少工作量"的核心思想。

本章 · 几何与物理含义总结

概念几何含义物理含义
函数平面直角坐标系中的曲线/点集（数与形的第二次统一）输入到输出的唯一对应（映射器/黑箱）
定义域图像在 x 轴上的投影（横着铺多宽）自变量在物理上允许的取值范围
值域图像在 y 轴上的投影（竖着长多高）因变量在整个过程中可能达到的所有值
单调递增图像从左到右一路上升一个量随时间/位置持续增大
单调递减图像从左到右一路下降一个量随时间/位置持续减小
最大值图像最高点的纵坐标物理量的峰值（最大高度、最大利润）
最小值图像最低点的纵坐标物理量的谷值（最低温度、最短时间）
偶函数图像关于 y 轴对称（镜像对称）正负输入给出相同输出（只关心大小，如 |x|、x²）
奇函数图像关于原点对称（中心对称，旋转 180° 重合）正负输入给出相反输出（随方向翻转，如 F = −kx）

典型例题（自测）

  1. 求下列函数的定义域（用区间表示）：f(x) = 1/(x − 2)；g(x) = √(x + 1)；h(x) = √(x − 1) + 1/(x − 3)。
  2. 已知 f(x) 的定义域为 [0, 2]，求 f(x − 1) 与 f(2x) 的定义域。
  3. 求值域：y = x² − 4x + 7（配方法）；y = (3x + 2)/(x + 1)（分离常数法）。
  4. 用定义证明 f(x) = −x³ 在 R 上单调递减（提示：x₁³ − x₂³ = (x₁ − x₂)(x₁² + x₁x₂ + x₂²)）。
  5. 判断奇偶性：f(x) = x³ + x、f(x) = |x| + 1、f(x) = x + 1/x、f(x) = x² + x、f(x) = 0（零函数是既奇又偶的唯一函数）。
  6. 已知 f(x) 是定义在 R 上的偶函数，且在 [0, +∞) 上单调递增，试比较 f(−3)、f(2)、f(−1) 的大小。

常见误区

  • ❌ "定义域、值域都相同的两个函数就是同一个函数" → ❌ 还要求对应关系一致。例 f(x) = x 与 g(x) = |x| 在 R 上值域不同；而 f(x) = x 与 g(x) = √(x²) 定义域同、值域不同，都不是同一函数。判断同一函数只认"定义域 + 对应关系"。
  • ❌ "求定义域时只看分母，忘了偶次根式" → ❌ 所有限制要同时满足并取交集：分母 ≠ 0、偶次根号内 ≥ 0、零次幂底数 ≠ 0，一条都不能漏。
  • ❌ "f(x + 2) 的定义域就是 f(x) 的定义域" → ❌ 定义域是最外层自变量 x 的范围；要先让括号整体落进 f 的定义域，再反解 x。
  • ❌ "图像关于原点对称的就是偶函数" → ❌ 关于 y 轴 对称才是偶函数，关于原点对称的是奇函数，两者别记反。
  • ❌ "不先看定义域就代 f(−x) 判断奇偶" → ❌ 定义域不关于原点对称时，函数直接非奇非偶，无需再算。
  • ❌ "单调性 = 整个定义域上的性质" → ❌ 单调性是区间性质，必须指明区间。f(x) = x² 在 R 上不单调，但在 (−∞, 0] 递减、[0, +∞) 递增。
  • ❌ "用定义证单调性只举两三个点就说成立" → ❌ 必须对任意 x₁ < x₂ 成立；举具体点不构成证明，要用作差、因式分解、定号。
  • ❌ "闭区间上的函数一定有最大最小值" → ❌ 不一定。f(x) = 1/x 在 (0, +∞) 上无最值；即便在闭区间上，若函数在该区间有间断也可能无最值。

课本外 · 典故与思考

典"函数"这个词：莱布尼茨造词、欧拉造记号、李善兰造译名（点击展开）

我们今天随口说的"函数"，是三个时代、三种语言接力完成的：

  • 莱布尼茨造词（1673 年）：德国数学家莱布尼茨（Leibniz，1646–1716）在一份研究几何曲线的手稿中首次使用 function 一词，它来自拉丁语 functio，本义是"执行、完成、发挥作用"——他把"随曲线上的点而变化的量"叫作 function，意为"这个量在'执行'某种对应任务"。
  • 欧拉造记号（1734 年）：瑞士数学家欧拉（Euler，1707–1783）首先引入记号 f(x)——f 是 function 的首字母，括号里装自变量，从此"函数"有了今天这副面孔。欧拉还给出了教科书沿用至今的定义：y 是 x 的函数，如果 x 取定时 y 有唯一确定的值。
  • 李善兰造译名（1859 年）：清代数学家李善兰与英国传教士伟烈亚力合译《代微积拾级》时，首次把 function 译成"函数"，并加注："凡此变数中函彼变数者，则此为彼之函数。"这里的"函"是古汉语中"包含"的意思——"函数"就是"被包含在式子里的数"，一如信封（函）里装着信。

所以"函数"这两个字，字面意思是"装在式子里的数"——今天读来略显古老，但细想与"唯一对应"的定义居然很贴切。

一句话总结：一个拉丁词"执行"，加一个字母记号 f(x)，加一个中文"函"字，凑齐了"函数"的完整身世。
思狄利克雷函数：一个画不出图像的函数（点击展开）

函数一定要有"解析式"、能画出"图像"吗？德国数学家狄利克雷（Peter Gustav Lejeune Dirichlet，1805–1859）给出了一个让人目瞪口呆的答案——他定义了一个函数 D(x)：

D(x) = 1，当 x 是有理数；
D(x) = 0，当 x 是无理数。

这个函数：

  • 满足函数的全部要求：定义域是全体实数 R，每个 x 都有唯一确定的函数值（有理数给 1、无理数给 0），完全是教科书定义下的合法函数；
  • 却画不出图像：因为有理数和无理数在数轴上"你中有我、我中有你"地紧紧挤在一起，D(x) 的图像将在"高度 1"和"高度 0"之间无限密集地跳动——任何一支笔都无法描出它；
  • 处处不连续：在任何一个点 x₀ 附近，都既有有理数又有无理数，函数值在 0 和 1 之间来回"瞬移"，永远无法稳定在某个值上。

狄利克雷用这个例子告诉数学界："对应关系"才是函数的本质，能不能写出公式、能不能画出图像，都是其次的。他还提出了著名的抽屉原理（鸽笼原理：把 n + 1 个物体放进 n 个抽屉，必有一个抽屉至少装两个）——这位数学家专门负责"把常识变成定理"。

一句话总结：狄利克雷函数的存在，证明"函数"的本质是规则不是图形——第 3 章"对应说"定义的底气，正来自这里。

本章练习卷（含答案）

一、练习题

  1. 圆的方程 x² + y² = 1 对应的图形是不是某个函数的图像？请用竖直直线检验法说明理由，并体会“唯一对应”的几何含义。
  2. 求函数 f(x) = √(x − 1) + 1/(x − 3) 的定义域（用区间表示）。
  3. 已知 f(x) 的定义域为 [0, 2]，求 f(x + 1) 的定义域，并说明“f 后面整个括号”的取值范围是什么。
  4. 用配方法求 y = x² − 4x + 7 的值域，并指出其图像顶点（几何上对应图像的最低点）。
  5. 用定义证明 f(x) = x² 在 (0, +∞) 上单调递增，并解释“作差 f(x₁) − f(x₂)”的几何意义。
  6. 弹簧弹性势能 E(x) = ½kx²（k > 0，x 为形变量）是奇函数还是偶函数？请从物理含义解释；又已知 f(x) 是偶函数且在 [0, +∞) 上单调递增，比较 f(−3)、f(2)、f(−1) 的大小。

二、参考答案（点击展开）

查看第1题答案

不是函数图像。竖直直线 x = 0 与圆交于 (0, 1) 和 (0, −1) 两点——同一个 x 对应两个不同的 y，违背“任意 x 有唯一确定的 y”这一条，所以圆不是任何函数的图像。

查看第2题答案

偶次根式要求 x − 1 ≥ 0，得 x ≥ 1；分式要求 x − 3 ≠ 0，得 x ≠ 3；取交集得定义域 [1, 3) ∪ (3, +∞)。

查看第3题答案

令 0 ≤ x + 1 ≤ 2，解得 −1 ≤ x ≤ 1，所以定义域是 [−1, 1]。f 的定义域 [0, 2] 指的是“f 后面整个括号（这里即 x + 1）”的取值范围，而不是 x 直接的范围。

查看第4题答案

y = x² − 4x + 7 = (x − 2)² + 3。因 (x − 2)² ≥ 0，故 y ≥ 3，值域为 [3, +∞)。配方后顶点为 (2, 3)，即图像最低点的纵坐标是 3，这就是最小值。

查看第5题答案

任取 x₁, x₂ ∈ (0, +∞) 且 x₁ < x₂，作差 f(x₁) − f(x₂) = x₁² − x₂² = (x₁ − x₂)(x₁ + x₂)。由 x₁ < x₂ 得 x₁ − x₂ < 0，又 x₁, x₂ > 0 得 x₁ + x₂ > 0，故差为负，即 f(x₁) < f(x₂)，所以 f(x) 在 (0, +∞) 上单调递增。作差 f(x₁) − f(x₂) 的正负，就是“图像在 x₁、x₂ 两点之间是升还是降”的代数判据：差为负表示 x 增大时 y 也增大，图像上升。

查看第6题答案

E(−x) = ½k(−x)² = ½kx² = E(x)，故 E(x) 是偶函数；物理上拉伸（x > 0）和压缩（x < 0）只要形变量 |x| 相同，储存的弹性势能就相同，与方向无关，所以图像关于 y 轴对称。比较大小：因 f 是偶函数，f(−3) = f(3)、f(−1) = f(1)；又 f 在 [0, +∞) 上单调递增且 0 ≤ 1 < 2 < 3，故 f(1) < f(2) < f(3)，即 f(−1) < f(2) < f(−3)。
