第4章 指数函数与对数函数

高中 / 必修第一册

一句话总纲：指数与对数是一对互为逆运算的"镜像"。指数函数 y = aˣ 描述"每步按固定倍数变化"的增长或衰减（复利、衰变、繁殖），对数函数 y = logₐx 是它的反函数——回答"增长到这个程度，用了多少步"。学完本章，你要能在心里同时"看见"两条曲线：它们关于直线 y = x 对称，一个越跑越快冲向天空、一个越来越慢贴向地面。

4.1 指数与指数运算

从"整数次幂"到"实数次幂"

初中学过 aⁿ = a·a·…·a（n 个 a 相乘），底数 a、指数 n 都是看得见的"个数"。但现实中很多变化是"连续"的：细菌每小时翻 1.5 倍，问 2.5 小时后是多少？这就需要把指数从整数推广到任意实数，即引入分数指数幂。

n 次方根（几何：开方 = 反向的乘方）

若 xⁿ = a（n 为大于 1 的整数），则 x 叫 a 的 n 次方根：

  • n 为奇数时：a 的 n 次方根唯一，记作 ⁿ√a（读作 a 的 n 次根）。如 ³√8 = 2，³√(−8) = −2。
  • n 为偶数时：正数 a 有两个互为相反数的 n 次方根，正的那个记作 ⁿ√a（算术根）。如 ⁴√16 = 2，另一个是 −2。
  • 负数没有偶次方根（因为任何实数的偶次幂都非负）；0 的任何次方根都是 0。
若 xⁿ = a：
  n 为奇数  →  x = ⁿ√a      （唯一）
  n 为偶数，a > 0  →  x = ±ⁿ√a
  n 为偶数，a < 0  →  无实数根
几何含义：乘方是"把边从 1 维拉伸到 n 维"（平方→面积、立方→体积），开方是"从 n 维体积反推回 1 维边长"。²√a 就是"面积为 a 的正方形的边长"，³√a 是"体积为 a 的正方体的棱长"。这就是为什么负数没有偶次根——边长平方后不可能是负面积。

分数指数幂（指数从"个数"变成"缩放倍率"）

a^(m/n) = ⁿ√(a^m) = (ⁿ√a)^m     （a > 0，m、n ∈ N*，n > 1）
a^(−m/n) = 1 / a^(m/n)

规定：0 的正分数指数幂等于 0，0 的负分数指数幂没有意义；底数 a > 0 是保证分数指数幂（含无理指数）有意义的前提。

无理数指数幂（如 2^√2）由有理数指数幂"无限逼近"定义，从而指数的取值范围扩展到了全体实数，且幂的运算性质在实数范围内全部成立。

指数运算性质（核心公式）

a^r · a^s = a^(r+s)        （同底相乘，指数相加）
(a^r)^s   = a^(r·s)        （幂的幂，指数相乘）
(ab)^r    = a^r · b^r      （积的幂，分别乘方）
a^r ÷ a^s = a^(r−s)        （同底相除，指数相减）
几何/物理含义：指数相加 = "先后两段倍率叠乘"。若长度先放大 a^r 倍、再放大 a^s 倍，总倍率是 a^(r+s)；而 (a^r)^s 表示"放大 a^r 倍"这件事连续做 s 次。这些性质是后面所有指数、对数计算的根基。

4.2 指数函数

定义

形如 y = aˣ（a > 0 且 a ≠ 1）的函数叫指数函数，其中 x 是自变量（定义域为 R），a 是底数（常数）。

  • 要求 a > 0：保证 aˣ 对一切实数 x 都有意义（含 x = 1/2、x = √2 这类分数/无理指数）。
  • 要求 a ≠ 1：否则 y = 1ˣ = 1 退化成常数函数，失去"增长/衰减"的意义。

图像与性质

底数范围a > 1（增长型）0 < a < 1（衰减型）
图像走势从左到右一路上升（指数增长）从左到右一路下降（指数衰减）
定义域R（全体实数）
值域(0, +∞)，图像恒在 x 轴上方
过定点恒过 (0, 1)：a⁰ = 1
单调性单调递增单调递减
x 轴关系x 轴（y = 0）是水平渐近线，永不相交
y = aˣ 的图像：

 y ↑            y ↑
  |        ╱     |  ╲
  |      ╱       |    ╲
  |    ╱         |      ╲
  |  ╱           |        ╲
  |╱             |          ╲
──┼──────── x   ──┼────────── x
  |(0,1)  a>1    |(0,1)  0<a<1
几何含义：两条曲线都经过"生命起点" (0, 1)，都以 x 轴为"永远够不到的地平线"（渐近线）。a > 1 时曲线像"起飞"，越向右越陡；0 < a < 1 时曲线像"滑落"，越向右越平。底数 a 决定了这条"指数滑梯"是向上还是向下。
物理含义：指数函数刻画每一步都按同一比率变化的量，是"复利"的数学化身：银行年利率 3%，n 年后本息 A = P(1.03)ⁿ；放射性物质每过一个半衰期剩一半，t 个半衰期后剩 N = N₀·(1/2)^t；细菌每 20 分钟翻倍，t 分钟后数量 N = N₀·2^(t/20)。a > 1 是"正反馈增长"，0 < a < 1 是"持续衰减"。

指数函数的图像变换

  • 平移：y = a^(x+h) 左移 h 个单位；y = aˣ + k 上移 k 个单位。
  • 对称：y = a^(−x) 与 y = aˣ 关于 y 轴对称；y = −aˣ 关于 x 轴对称。
  • 底数互为倒数：y = aˣ 与 y = (1/a)ˣ 关于 y 轴对称。

4.3 对数与对数运算

对数的定义（指数问题的"反向提问"）

若 aˣ = N（a > 0 且 a ≠ 1），则 x 叫做以 a 为底 N 的对数，
记作  x = logₐN   （读作"以 a 为底 N 的对数"）

其中 a 叫底数，N 叫真数（N > 0）。

对数就是"指数方程的反解"：指数回答"a 的 x 次方是多少"，对数回答"a 的多少次方等于 N"。两者是同一个关系 aˣ = N ⇔ x = logₐN 的两种写法。

几何含义：如果指数是"把 1 反复放大 a 倍，放大 x 次得到 N"，那么对数 logₐN 就是"从 1 到 N，需要放大多少个 a 倍"——它是用乘法步数来度量一个数的大小的标尺。几何上，logₐN 是数轴上一段"按比例压缩"后的刻度。
物理含义：对数把"天文数字"压成"小数字"，用来度量跨越多个数量级的量：声音分贝 dB = 10·lg(I/I₀)，地震震级 M = lg(A/A₀)，酸碱度 pH = −lg[H⁺]，星等、信息量（比特）也都用对数。因为人耳、人眼对"倍数"的感知是对数式的：声音能量放大 100 倍，听感只强 2 档。

常用对数与自然对数

  • 常用对数：以 10 为底，记作 lg N，即 lg N = log₁₀N。
  • 自然对数：以无理数 e ≈ 2.71828… 为底，记作 ln N，即 ln N = logₑN。e 是"连续复利"的极限，是描述连续增长最自然的底数。

对数的运算性质

logₐ(M·N) = logₐM + logₐN      （乘 → 加）
logₐ(M/N) = logₐM − logₐN      （除 → 减）
logₐ(Mⁿ)  = n·logₐM            （幂 → 系数）
logₐ1 = 0，logₐa = 1
a^(logₐN) = N                  （对数恒等式）
几何含义：对数运算"降级"了运算等级——乘法降成加法、除法降成减法、乘方降成乘法。它把数轴上乘法式的比例刻度变成加法式的等距刻度：这正是一把"对数标尺"（计算尺）的原理——把两根对数刻度尺对齐滑动，就能用"长度的相加"完成"真数的相乘"。

换底公式

logₐb = log꜀b / log꜀a    （c > 0 且 c ≠ 1，常用 c = 10 或 c = e）

推论：logₐb · log_b a = 1（互为倒数）；logₐⁿ bᵐ = (m/n)·logₐb。

4.4 对数函数

定义

形如 y = logₐx（a > 0 且 a ≠ 1）的函数叫对数函数，定义域为 (0, +∞)，值域为 R。它是指数函数 y = aˣ 的反函数。

图像与性质

底数范围a > 10 < a < 1
图像走势单调递增（上升）单调递减（下降）
定义域(0, +∞)，图像恒在 y 轴右侧
值域R（全体实数）
过定点恒过 (1, 0)：logₐ1 = 0
y 轴关系y 轴（x = 0）是垂直渐近线，永不相交
y = logₐx 的图像：

 y ↑            y ↑
  |       ╱      |  ╲
  |     ╱        |    ╲
  |   ╱          |      ╲
  | ╱            |        ╲
  |╱             |          ╲
──┼──────── x   ──┼────────── x
  |(1,0) a>1     |(1,0)  0<a<1
几何含义：对数函数的图像与指数函数图像关于直线 y = x 对称——把指数曲线沿 y = x "翻折"就得到对数曲线。这正体现了反函数的意义：指数函数把 x（时间/步数）映到 y（数量），对数函数把 x（数量）映回 y（时间/步数），两者是同一个关系的"正读"与"倒读"。
物理含义：对数函数把"爆炸式增长的量"拉回"线性可读的刻度"——y 轴按倍数走，x 轴按步数走。分贝刻度、震级、pH、星等都是对数函数的直接应用：能量 10 倍、100 倍、1000 倍，对应分贝只增加 10、20、30，让人能在一张纸上同时看清从耳语到喷气机的巨大跨度。

指数函数与对数函数的对应关系（反函数）

单调性随 a：a>1 增，0<a<1 减单调性随 a：a>1 增，0<a<1 减
a 越大，越陡a 越大，越平缓

4.5 函数的应用（指数与对数的现实模型）

指数增长/衰减模型

增长：N(t) = N₀ · a^t   （a > 1，如复利、人口、细菌繁殖）
衰减：N(t) = N₀ · a^t   （0 < a < 1，如放射性衰变、降温、药物代谢）

连续复利与自然增长可用 N(t) = N₀·e^(kt) 表示：k > 0 为增长、k < 0 为衰减。半衰期 T 满足 (1/2) = a^T，解得 T = logₐ(1/2)。

几何含义：指数模型在"半对数坐标系"（y 轴取对数）里是一条直线——因为 ln N = ln N₀ + t·ln a 是 t 的一次函数。这提供了判断一个过程是否为指数变化的几何判据：在对数纸上成直线，就是指数变化。
物理含义：这一思想贯穿科学：放射性测年（碳-14 半衰期 5730 年，用剩量反推年代）、传染病的指数扩散、冷却定律、人口增长模型。用对数把"倍数问题"变成"加减问题"，是处理跨数量级物理量的通用工具。

反函数与对数尺度的应用

  • 解指数方程/不等式：两边取对数，把指数"拉下来"。如 2ˣ = 10 ⇒ x = log₂10。
  • 比较大小：利用单调性。a > 1 时 x₁ > x₂ ⇒ a^(x₁) > a^(x₂)、logₐx₁ > logₐx₂。
  • 对数尺度：pH = −lg[H⁺]、震级、分贝、星等，把跨 10 的若干次方的量压到小整数区间。

典型例题（自测）

  1. 化简：(2^(1/2))⁴、27^(2/3)、16^(−3/4) 各等于多少？
  2. 解方程：2ˣ = 32；3^(x+1) = 27；log₂x = 5；lg x = 2。
  3. 计算：log₂8 + log₂4、log₅50 − log₅2、log₃9⁴、2^(log₂5)。
  4. 利用换底公式求 log₂3 · log₃4（结果化为最简）。
  5. 某放射性元素半衰期为 10 年，初始 80 g，问 30 年后还剩多少克？（用 N = 80·(1/2)^(t/10)）
  6. 比较大小：0.3⁰·⁵ 与 0.3²；log₂3 与 log₂5；2^0.3 与 1。

常见误区

❌ 高频错误与纠正

  • ❌ "logₐ(M+N) = logₐM + logₐN" → ❌ 对数只能"乘除→加减"，加法和不能拆；正确的加法是 logₐ(M·N) = logₐM + logₐN。
  • ❌ "logₐM / logₐN = logₐ(M/N)" → ❌ 换底公式是 logₐb = log꜀b / log꜀a，两对数相除不等于真数相除的对数。
  • ❌ "aˣ = 0 有解" → ❌ 指数函数值域是 (0, +∞)，aˣ 恒为正，永远不等于 0（也不会为负）。
  • ❌ "负数和 0 可以取对数" → ❌ 真数必须 > 0，logₐ0 与 logₐ(−3) 都无意义。
  • ❌ "lg 100 = 2，所以 lg(1000) = 3，于是 lg(100×1000) = 5 但 lg(100) + lg(1000) = 2+3 = 5 却与 lg 100000 = 5 一致——所以直接加没问题" → ⚠️ 这只在"乘"时对：lg(100+1000) = lg 1100 ≠ 5，务必区分加法与乘法。
  • ❌ "(aˣ)ʸ = aˣ·aʸ" → ❌ 幂的幂是指数相乘 (aˣ)ʸ = a^(x·y)；指数相加的是 aˣ·aʸ = a^(x+y)，两者别混。
  • ❌ "所有指数函数/对数函数都过原点" → ❌ 指数函数过 (0, 1)，对数函数过 (1, 0)，都不经过原点 (0, 0)。

课本外 · 典故与思考

典纳皮尔与对数：一次为了"天文学家"的发明（点击展开）

16 世纪末，天文学正处于大航海时代的高光时刻，可天文学家们却苦不堪言——计算行星轨道要用到大量的乘法与除法，一次计算要耗去数天甚至数周，还极易出错。

约翰·纳皮尔（John Napier，1550–1617），一位苏格兰地主、神学家兼业余数学家，花了约 20 年时间，在 1614 年出版了《奇妙的对数表的描述》，为世界奉上了"对数"。其核心思想只有一句话：

把"乘法"降级成"加法"——既然 a^m · a^n = a^(m+n)，那么只要提前造好"每个数的指数表"，两个大数相乘就能变成"查指数 → 指数相加 → 再查表"三个步骤。

纳皮尔把这种数叫作 logarithm，由希腊语 logos（比）与 arithmos（数）合成，意为"比之数"——因为天文学里最烦人的正是求两数的比。开普勒用它完成了《鲁道夫星表》的巨量计算；数学家拉普拉斯后来盛赞："对数把几个月的工作压缩到几天，等于延长了天文学家的寿命。"20 世纪电子计算器诞生前，"查对数表做乘法"曾是全世界工程师与科学家的日常手艺。

顺带一提：中文"对数"译名同样出自李善兰（详见第 3 章典故），取"对"即"成对、相对"之意——指数与对数本就是一对互逆的搭档。

一句话总结：对数不是书斋里的空想，而是为了给天文学家的双手减负——它把"乘除"换成了"加减"。
趣棋盘放米：2⁶⁴ 粒麦子，一个国家也付不起（点击展开）

传说（版本众多，正式史料无考，故称"传说"）：古印度的国王要赏赐国际象棋的发明者。发明者指着 8×8 的棋盘说："只求按麦粒给赏：第 1 格放 1 粒，第 2 格放 2 粒，第 3 格放 4 粒……以后每格都是前一格的两倍，放满 64 格即可。"国王一听，觉得这赏赐太容易了，立刻应允。

结果呢？放满棋盘需要的麦粒总数是：

1 + 2 + 4 + … + 2⁶³ = 2⁶⁴ − 1 ≈ 1.84 × 10¹⁹ 粒

这是什么概念？

  • 大约相当于两千多亿吨小麦——按全球年产量估算，够全世界吃上两千年；
  • 把麦粒排成一列，可以在地球和太阳之间铺很多个来回；
  • 仅仅是第 64 格那一格，就有 2⁶³ ≈ 9.2 × 10¹⁸ 粒，已是第 1 格的"天文数字倍"。

这个传说正是 y = 2ˣ 指数函数最生动的写照：前面的格子看着不起眼（第 10 格才 512 粒），可"每步翻倍"的机器一旦运转起来，很快就把一切"线性直觉"甩在身后。指数增长前期像爬楼梯，后期像坐火箭。

一句话总结：棋盘与麦粒的故事，就是指数函数"前期缓慢、后期爆发"的天性——连国王都输给了 2⁶⁴。
史e 的来历：一个被"存款利率"逼出来的数（点击展开）

课本说自然对数以 e ≈ 2.71828… 为底。这个 e 是怎么冒出来的？答案出人意料：从银行的复利计算中长出来的。

1683 年，瑞士数学家雅各布·伯努利（Jacob Bernoulli）研究了一个问题：本金 1 元，年利率 100%，一年结算一次，一年后本息为 (1 + 1/1)¹ = 2 元；如果半年结算一次呢？每半年利率 50%，一年后是 (1 + 1/2)² = 2.25 元；每月结算一次，是 (1 + 1/12)¹² ≈ 2.6130 元；每秒结算一次，则逼近 (1 + 1/n)ⁿ（n 趋向无穷）——这个极限恰好收敛于一个确定的无理数：

(1 + 1/n)ⁿ  →  e ≈ 2.718281828…   （n → ∞）

也就是说：利率再高、结算再勤，1 元本金一年也翻不出 2.71828… 倍——这就是"连续复利"的极限，一个由实际问题逼出来的数学常数。

命名者是欧拉（Euler）：他在 1727 年前后开始用字母 e 表示它，并写入 1748 年的名著《无穷小分析引论》而流传至今。至于为什么偏偏选字母 e，学界普遍认为取自他姓氏 Euler 的首字母（欧拉本人从未解释，故这一点仍属推测）。从此，指数函数 eˣ 成了"变化率等于自身"的天然增长底数——见第 5 章之后，你会一次又一次遇见它。

一句话总结：银行利息算得再勤，也最多让 1 元变成 e 元——e 是"复利的天花板"，也是连续变化的天然标尺。

本章练习卷（含答案）

一、练习题

  1. 计算 8^(2/3) 与 25^(−1/2)，并说明 8^(2/3) 对应的几何含义。
  2. 判断 4^(−1/2) 是否有意义；为什么负数没有偶次方根？请结合"边长的平方不可能是负面积"说明。
  3. 指数函数 y = 2ˣ 与 y = (1/2)ˣ 的图像是什么关系？分别过哪个定点、以哪条直线为渐近线？哪个表示"增长"、哪个表示"衰减"？
  4. 解方程 3ˣ = 81 与 log₅x = 3；并说明"对数"在几何上回答了什么问题。
  5. 计算 log₄8 + log₄2、log₂48 − log₂3，并利用换底公式求 log₂5 · log₅8。
  6. 某放射性元素半衰期为 8 年，初始质量为 64 g：① 16 年后还剩多少克？② 多少年后剩 4 g？（写出完整过程）并解释"在半对数坐标系里成直线即指数变化"的几何判据。

二、参考答案（点击展开）

查看第1题答案

8^(2/3) = (³√8)² = 2² = 4；25^(−1/2) = 1/√25 = 1/5。几何含义：³√8 = 2 是"体积为 8 的正方体的棱长"，再平方得到面积 4，即"先由体积反推边长，再求面积"。

查看第2题答案

4^(−1/2) = 1/√4 = 1/2，有意义（正数的负分数指数幂等于其正分数指数幂的倒数）。负数没有偶次方根，因为任何实数的偶次幂都非负——"边长"平方后不可能是负面积，故 √(−4) 无实数根。

查看第3题答案

二者底数互为倒数，图像关于 y 轴对称；都过定点 (0, 1)，都以 x 轴（y = 0）为水平渐近线。y = 2ˣ（a > 1）表示增长、从左到右一路上升；y = (1/2)ˣ（0 < a < 1）表示衰减、一路下降。

查看第4题答案

3ˣ = 81 = 3⁴ ⇒ x = 4；log₅x = 3 ⇒ x = 5³ = 125。对数在几何上回答"从 1 放大到 N 需要多少个 a 倍"，即用"乘法步数"度量一个数大小的标尺。

查看第5题答案

log₄8 + log₄2 = 3/2 + 1/2 = 2（因为 4^(3/2) = 8、4^(1/2) = 2）。log₂48 − log₂3 = log₂(48/3) = log₂16 = 4。换底：log₂5 · log₅8 = log₂5 · (log₂8 / log₂5) = log₂8 = 3。

查看第6题答案

模型 N = 64·(1/2)^(t/8)。① t = 16 ⇒ N = 64·(1/2)² = 16 g。② 4 = 64·(1/2)^(t/8) ⇒ (1/2)^(t/8) = 1/16 = (1/2)⁴ ⇒ t/8 = 4 ⇒ t = 32 年。几何判据：两边取对数得 ln N = ln 64 + (t/8)·ln(1/2)，是 t 的一次函数，故在以对数为纵轴的"半对数坐标系"里图像为一条直线。
