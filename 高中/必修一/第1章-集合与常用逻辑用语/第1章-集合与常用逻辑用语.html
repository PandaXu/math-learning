第1章 集合与常用逻辑用语

高中 / 必修第一册

一句话总纲：集合 = 「用一个圈把具有共同属性的对象圈在一起」；逻辑用语 = 「用集合的包含关系读懂"如果…就…"与"所有/存在"」。学完本章，你要能看见一张 Venn 图（韦恩图）——每个命题都是一块区域，充分条件、必要条件、并集交集补集、全称与存在，全部都能还原成"圈与圈之间的包含、重叠、相减"。

1.1 集合的概念与表示

什么是集合？（物理含义：分类与归档）

把一些确定的、互不相同的对象看成一个整体，这个整体就叫集合，其中的每个对象叫元素。例如"全班同学"是一个集合，"所有自然数"是一个集合，"所有电子"也是一个集合。

元素的三特性：

  • 确定性：一个对象要么属于这个集合，要么不属于，二者必居其一、不能含糊。所以"个子高的人"不是集合（多高算高没有标准），而"身高超过 1.8m 的人"是集合。
  • 互异性：集合中的元素互不相同，{1, 1, 2} 只能写成 {1, 2}。
  • 无序性：元素排列顺序无关，{1, 2} = {2, 1}。
物理含义：集合的本质是"按共同属性分类/归档"。你给抽屉贴标签，把同一类物体放进同一个抽屉——那个抽屉就是集合，物体就是元素。"属于"就是"被归进了这一类"。

元素与集合的关系：属于 ∈ 与不属于 ∉

若 a 是集合 A 的元素，记作 a ∈ A；若不是，记作 a ∉ A。∈ 只用于"元素与集合"之间，不能用在两个集合之间。

常用数集（固定的"抽屉"）

记号名称内容
N自然数集0, 1, 2, 3, …
N* 或 N₊正整数集1, 2, 3, …（不含 0）
Z整数集…, −2, −1, 0, 1, 2, …
Q有理数集整数与分数
R实数集有理数与无理数

集合的三种表示法

① 列举法：把元素一一列出，写在花括号内。例：{1, 2, 3}、{a, b, c}。元素较多或有规律时可用省略号，如 {1, 2, 3, …, 100}。

② 描述法：用"元素 + 竖线 + 共同性质"表示：

{ x | x 满足的性质 P }

例：不大于 3 的自然数集 = { x | x ∈ N, x ≤ 3 }；所有偶数 = { x | x = 2k, k ∈ Z }。竖线左边写"代表元素"，右边写"它满足的条件"。

③ 图示法（Venn 图）：用一个闭合曲线（圆）圈出集合，曲线内写元素或标上集合名——这是几何含义的核心载体。

几何含义：集合 ⟷ 一个圈（闭合曲线围成的区域），元素 ⟷ 区域内的点。"a ∈ A"就是"点 a 落在圈 A 的内部"，"a ∉ A"就是"点 a 在圈 A 的外部"。从此，抽象的"属于"关系变成了一目了然的"点在不在圈里"。

空集

不含任何元素的集合叫空集，记作 ∅。规定：空集是任何集合的子集。

1.2 集合间的关系

子集、真子集、相等

  • 子集：若集合 A 中每一个元素都在集合 B 中，称 A 是 B 的子集，记作 A ⊆ B（或 B ⊇ A）。读作"A 包含于 B"。
  • 真子集：若 A ⊆ B 且 B 中存在 A 没有的元素，称 A 是 B 的真子集，记作 A ⊂ B（严格包含）。
  • 相等：A = B 当且仅当 A ⊆ B 且 B ⊆ A。即"你有的我都有，我有的你都有"。

例：{1, 2} ⊆ {1, 2, 3}；{1, 2} ⊂ {1, 2, 3}；{x | x² = 1} = {1, −1}。

几何含义：子集 = A 的圈完全套在 B 的圈里面；真子集 = A 的圈严格在 B 内部且 B 还多出一块；相等 = 两个圈完全重合。判断集合关系，本质就是比"圈谁大、谁套住谁"。
物理含义：子集 = "部分与整体"或"更细的分类"。例：金属 ⊆ 导体（金属都导电，是导体的一部分）；哺乳动物 ⊆ 动物。"相等" = 两个分类标准圈出了同一批对象，只是叫法不同。

几个关键结论

  • 任何集合都是它自身的子集：A ⊆ A。
  • 空集是任何集合的子集：∅ ⊆ A（对任意 A）。
  • 含 n 个元素的集合，共有 2ⁿ 个子集，2ⁿ − 1 个真子集（每个元素"取或不取"两种选择）。

1.3 并集、交集、补集

三种运算的定义

  • 并集：A ∪ B = { x | x ∈ A 或 x ∈ B }——由所有属于 A 或属于 B 的元素组成（"或"是可兼的：两者都算）。
  • 交集：A ∩ B = { x | x ∈ A 且 x ∈ B }——由同时属于 A 和 B 的公共元素组成。
  • 补集：设全集为 U，∁UA = { x | x ∈ U 且 x ∉ A }——在全集中去掉 A 剩下的部分。
几何含义：并集 = 两个圈全部盖住的区域；交集 = 两个圈的公共重叠部分；补集 = 在大圈（全集 U）里挖去 A 之后剩下的月牙形区域。Venn 图上用阴影涂出来，三种运算立刻分明。
物理含义：并集 = "任一满足即可"（并联电路：开关甲 或 乙闭合，灯就亮）；交集 = "同时满足才行"（串联电路：甲 且 乙都闭合，灯才亮）；补集 = "否定/排除"（全集是全体研究对象，补集就是"不是 A 的那批"）。

运算性质

交换律：A ∪ B = B ∪ A，A ∩ B = B ∩ A

结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)，(A ∩ B) ∩ C = A ∩ (B ∩ C)

分配律：A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)，A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

德摩根律（补集与并/交的互换，最重要！）：

∁U(A ∪ B) = ∁U A ∩ ∁U B
∁U(A ∩ B) = ∁U A ∪ ∁U B

记忆口诀："并的补 = 补的交，交的补 = 补的并"。补集进去，∪ 与 ∩ 互换。

例：U = {1,2,3,4,5}，A = {1,2,3}，B = {3,4}。则 A ∪ B = {1,2,3,4}，A ∩ B = {3}，∁UA = {4,5}。

1.4 充分条件与必要条件

命题与推出关系 ⇒

若命题"若 p，则 q"为真，记作 p ⇒ q（读作 p 推出 q）。此时：

  • p 是 q 的充分条件——有 p 就足够保证 q。
  • q 是 p 的必要条件——要 p 成立，q 必不可少（q 若不成立，p 必不成立）。

充要条件：若 p ⇒ q 且 q ⇒ p，记作 p ⇔ q，称 p 与 q 互为充要条件（p 与 q 等价）。

几何含义（本章最重要的"数形结合"）：设 P = { x | x 满足 p }，Q = { x | x 满足 q }，则
p ⇒ q ⟺ P ⊆ Q。
"推出"就是"小圈套大圈"：p 的范围小，q 的范围大，落在 P 里必然落在 Q 里。于是——充分条件是小圈，必要条件是大圈，充要条件是两圈重合。判断条件类型，就是比两个集合"谁包含谁"。
物理含义：充分条件 = "有它就够"（例：下雨 ⇒ 地面湿，下雨是地面湿的充分条件）；必要条件 = "没它不行"（例：灯泡发光 ⇒ 有电流通过，通电是发光的必要条件，但只有通电还不够，还要灯泡完好，所以不充分）；充要条件 = "完全等价"（例：一个数是偶数 ⇔ 它能被 2 整除）。

四种条件类型（用集合大小判断）

条件集合关系例子
充分不必要P ⊂ Q（P 真子集于 Q）p: x > 1，q: x > 0
必要不充分Q ⊂ P（Q 真子集于 P）p: x > 0，q: x > 1
充要条件P = Q（两圈重合）p: x² = 1，q: |x| = 1
既不充分也不必要P 与 Q 互不包含（有交无套）p: x > 0，q: x < 0

例："x > 1 是 x > 0 的什么条件？"——集合 {x | x > 1} ⊂ {x | x > 0}，故是充分不必要条件。

1.5 全称量词与存在量词

两个量词

  • 全称量词 ∀：表示"所有、任意、每一个"。含 ∀ 的命题叫全称命题：∀x ∈ M, p(x)。
  • 存在量词 ∃：表示"存在、至少有一个"。含 ∃ 的命题叫特称（存在）命题：∃x ∈ M, p(x)。

例：∀x ∈ R, x² ≥ 0（所有实数的平方非负，真）；∃x ∈ R, x² < 0（存在实数的平方为负，假）。

几何含义：∀ 要求整个区域里的每一个点都满足性质 p（一个不漏）；∃ 只要求区域里至少有一个点满足 p（找到一个就行）。全称命题的真假 = "整片区域全涂满"；存在命题的真假 = "区域内有没有打上一个点"。
物理含义：全称命题对应"普遍规律"（例：一切物体都受重力、所有电子都带负电）；存在命题对应"存在实例/反例"（例：存在一种材料在常温下超导、存在比 0 小的负数）。检验全称命题要"证遍所有"，检验存在命题"举一个例子"即可。

量词命题的否定（务必记牢的互换规则）

¬(∀x ∈ M, p(x))  ⟺  ∃x ∈ M, ¬p(x)
¬(∃x ∈ M, p(x))  ⟺  ∀x ∈ M, ¬p(x)

口诀："全称否定变存在，存在否定变全称，结论也要一起否"。既要换量词，又要否定结论，二者缺一不可。

例：命题"∀x ∈ R, x² > 0"的否定是"∃x ∈ R, x² ≤ 0"（x = 0 时成立，故原命题为假）。

典型例题（自测）

  1. 用列举法写出集合 { x | x ∈ N, x ≤ 5 }；再用描述法表示"所有正偶数"。
  2. 设 A = {1, 2, 3}，B = {3, 4, 5}，求 A ∪ B、A ∩ B；若全集 U = {1,2,3,4,5,6}，求 ∁UA。
  3. 判断：{1, 2} 与 {2, 1} 是否相等？{0} 与 ∅ 是否相等？0 与 {0} 是否相等？
  4. 判断"x > 2"是"x > 1"的什么条件（充分/必要/充要），并用集合包含关系说明。
  5. 写出命题"∀x ∈ R, x² ≥ 0"与"∃x ∈ Z, x² = 2"的否定，并判断原命题真假。
  6. 设 U = R，A = { x | x < 3 }，B = { x | x > 1 }，求 A ∩ B、A ∪ B，并验证德摩根律 ∁U(A ∩ B) = ∁UA ∪ ∁UB。

常见误区

  • ❌ "∅ 与 {∅} 一样" → ❌ ∅ 是不含任何元素的集合；{∅} 是含一个元素（那个元素叫"空集"）的集合，二者完全不同。
  • ❌ "0 与 {0} 一样" → ❌ 0 是元素，{0} 是含元素 0 的集合。0 ∈ {0}，但 0 ≠ {0}。
  • ❌ "属于 ∈ 与包含 ⊆ 混用" → ❌ ∈ 用于"元素与集合"（1 ∈ {1,2}），⊆ 用于"集合与集合"（{1} ⊆ {1,2}）。写成 1 ⊆ {1,2} 或 {1} ∈ {1,2} 都是错的。
  • ❌ "空集不是任何集合的子集" → ❌ 规定 ∅ 是任何集合的子集，但 ∅ 不一定是其他集合的元素。
  • ❌ "A ⊆ B 说明 A 的元素比 B 少" → ❌ 子集允许相等：A = B 时也有 A ⊆ B。只有真子集 A ⊂ B 才要求 B 多出元素。
  • ❌ "充分条件与必要条件方向搞反" → ❌ 记"推出箭头尾巴是充分、箭头指向是必要"：p ⇒ q 中 p 是充分、q 是必要；对应 P ⊆ Q（小圈是充分）。
  • ❌ "全称命题否定只换量词不否结论" → ❌ 必须量词互换 + 结论取反："∀x, p(x)"的否定是"∃x, ¬p(x)"，漏掉结论取反就错。
  • ❌ "描述法竖线两边随意写" → ❌ 竖线左边必须是"代表元素"，右边是它的性质；且性质要能确定元素，像"好人"这类模糊标准不能构成集合。

本章练习卷（含答案）

一、练习题

  1. 用列举法表示集合 { x | x ∈ N, 1 ≤ x ≤ 5 }，写出它的元素；该集合有多少个子集？并判断 0 是否属于它、∅ 是否是它的子集。
  2. 设 A = { a, b }，写出 A 的所有子集与所有真子集，并用"每个元素取或不取"的几何直觉验证子集个数。
  3. 设全集 U = { 1, 2, 3, 4, 5, 6 }，A = { 1, 2, 3 }，B = { 3, 4, 5 }，求 A ∪ B、A ∩ B、∁UA、∁U(A ∩ B)，并用 Venn 图（圈的重叠 / 挖去）解释。
  4. 判断"x > 2"是"x > 1"的什么条件，并用"小圈套大圈"的集合包含关系说明；反过来"x > 1"又是"x > 2"的什么条件？
  5. 用集合包含关系判断"两个三角形全等"与"两个三角形面积相等"的条件关系，并联系"下雨 ⇒ 地面湿"的物理含义说明充分 / 必要的方向。
  6. 写出下列命题的否定并判断真假：① ∀x ∈ R, x² ≥ 0；② ∃x ∈ Z, x² = 2；③ "所有自然数都大于 0"。并用"全称否定变存在、结论一起否"的口诀解释。

二、参考答案（点击展开）

查看第1题答案

列举法：{1, 2, 3, 4, 5}。子集个数 2⁵ = 32（每个元素"取或不取"两种选择）。0 ∉ 该集合（0 不满足 1 ≤ x ≤ 5，也不在 {1..5} 中）。∅ 是它的子集（空集是任何集合的子集）。

查看第2题答案

所有子集：∅、{a}、{b}、{a, b}，共 4 个；所有真子集：∅、{a}、{b}，共 3 个。几何直觉：元素 a 有"取 / 不取"两种选择，元素 b 也两种，故 2×2 = 4 个子集；去掉 A 自身即得真子集 4 − 1 = 3。

查看第3题答案

A ∪ B = {1, 2, 3, 4, 5}（两个圈全部盖住的区域）；A ∩ B = {3}（两个圈的公共重叠部分）；∁UA = {4, 5, 6}（全集大圈挖去 A 后剩下的月牙）；∁U(A ∩ B) = ∁U{3} = {1, 2, 4, 5, 6}。

查看第4题答案

设 P = {x | x > 2}，Q = {x | x > 1}，有 P ⊂ Q（P 是小圈、Q 是大圈，小圈完全套在大圈内）。故"x > 2"是"x > 1"的充分不必要条件（有 x > 2 必有 x > 1，反之不行）；反过来"x > 1"是"x > 2"的必要不充分条件。

查看第5题答案

"全等 ⇒ 面积相等"（全等三角形面积必相等），但"面积相等 ⇏ 全等"（底与高不同、乘积相同的三角形面积相等）。所以"全等"是"面积相等"的充分不必要条件。物理类比："下雨 ⇒ 地面湿"，下雨是充分条件（有它够）、地面湿是必要条件（没它不行），方向与"全等 ⇒ 面积相等"一致。

查看第6题答案

① 否定：∃x ∈ R, x² < 0，为假（原命题真：任何实数的平方 ≥ 0）。② 否定：∀x ∈ Z, x² ≠ 2，为真（原命题假：√2 不是整数）。③ 原命题"所有自然数都大于 0"为假（0 是自然数但不大于 0），其否定"存在一个自然数不大于 0"为真。规则：量词 ∀ ↔ ∃ 互换，同时结论取反，二者缺一不可。
