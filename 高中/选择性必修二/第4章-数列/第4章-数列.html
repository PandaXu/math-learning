第4章 数列

高中 / 选择性必修第二册

一句话总纲：数列 = 「正整数集上的函数」，图像是一串离散的点——等差看"差"（等步长的直线）、等比看"比"（等倍率的指数曲线），求和就是把这一串点"累加"成面积与总量。

4.1 数列的概念

定义与基本术语

按一定顺序排列的一列数称为数列，记作 a1, a2, a3, …, an, …，简记为 {an}。其中的每一个数叫做数列的项：

  • 首项 a1，第 2 项 a2，…，第 n 项 an 也叫通项。
  • 项数 n 是"第几个"，an 是"这个数的值"——项数 ≠ 项，这是初学者最容易混淆的地方。
  • 数列强调顺序：同样几个数，顺序不同就是不同的数列。例如 1, 2, 3 与 3, 2, 1 是两个不同数列（这一点与"集合"截然不同）。

数列的分类

  • 按项数分：有穷数列（项数有限）与无穷数列（项数无限）。
  • 按大小变化分：递增数列（an+1 > an）、递减数列（an+1 < an）、摆动数列（正负或大小交替）、常数列（各项相等）。

通项公式与递推公式

通项公式：如果第 n 项 an 与序号 n 之间的关系可以用一个公式表示，即 an = f(n)，这个式子就是通项公式。例如 1, 3, 5, 7, … 的通项是 an = 2n − 1。

递推公式：给出首项（或前几项），再给出相邻项之间的关系。例如 a1 = 1, an+1 = an + 2，由首项一步步"递推"出整个数列。

几何含义（本章的"灵魂"）：数列 an = f(n) 本质是定义在正整数集 N* 上的函数。把它画在坐标平面里——横轴是项数 n、纵轴是项的值 an——得到的不是连续曲线，而是一串孤立的点：(1, a1), (2, a2), (3, a3), …。因为自变量 n 只能取 1, 2, 3, …，所以"连续函数"与"数列"的关系 = 整条曲线 与 曲线上按整数横坐标取出的离散点。数列的单调性，就是这些点从左到右"节节上升"还是"节节下降"。
物理含义：数列是"等时间间隔采样"的记录，是连续过程的离散快照。例如每隔 1 秒记录一次小车的位置 → 位置序列 x1, x2, x3, …；每隔一年记录一次存款余额 → 本利和序列；每天记录一次气温 → 温度序列。物理世界是连续的，而"测量/记账"总是离散的，数列正是这种离散化之后的数学模型。

4.2 等差数列

定义

从第 2 项起，每一项与它前一项的差等于同一个常数，这个数列叫等差数列，这个常数叫公差 d：

aₙ₊₁ − aₙ = d   (n ∈ N*)    即  aₙ₊₁ = aₙ + d

例如 2, 5, 8, 11, …：每一项都比前一项大 3，公差 d = 3；再如 10, 7, 4, 1, …：公差 d = −3（负公差表示递减）。

通项公式

由定义用累加法：a2 − a1 = d，a3 − a2 = d，…，an − an−1 = d，左右各相加得：

aₙ = a₁ + (n − 1)d

注意是 (n − 1)d 而不是 nd：首项到第 n 项共"跨了 n − 1 步"。

几何含义：把 an = a1 + (n−1)d 改写成 an = dn + (a1 − d)，它是关于 n 的一次函数，图像上的离散点全部落在斜率为 d 的直线上。公差 d = 相邻两点"纵坐标差 ÷ 横坐标差" = 这条直线的斜率 = 每一步的固定"步长"：
  • d > 0：直线向右上倾斜，点节节升高（递增数列）；
  • d < 0：直线向右下倾斜，点节节下降（递减数列）；
  • d = 0：水平直线，所有点等高（常数列）。
等差数列因此可以理解为"一条直线上按相等横坐标间隔取出的等距点列"。
物理含义：等差数列 = "匀速直线运动"的等时采样。速度 v 恒定，每隔相同时间 Δt，位置就增加相同的位移 v·Δt，于是位置序列 x1, x2, x3, … 是等差数列，公差就是每一段时间内的恒定位移。它也是"等额"过程的模型：每天固定存 10 元、每层楼高相同、钟摆每次摆动耗时相同。

等差中项

若 a、A、b 成等差数列，则 A 是 a 与 b 的等差中项：

A = (a + b) / 2
几何含义：A 是 a、b 在数轴上的中点（算术平均），恰好"居中"。等差数列中任意一项都是它前后两项的等差中项：an = (an−1 + an+1) / 2。

重要性质

下标和相等 ⇒ 项和相等：若 m + n = p + q，则 am + an = ap + aq。特例：首尾等距的两项和相等（a1 + an = a2 + an−1 = …）。这正是"倒序相加"求和法的依据。

前 n 项和公式

Sₙ = a₁ + a₂ + … + aₙ = n(a₁ + aₙ)/2 = n·a₁ + n(n−1)d/2

推导（倒序相加法）：把 Sn 正着写一遍、倒着写一遍，上下对齐逐对相加，每一对都等于 a1 + an，共 n 对，故 2Sn = n(a1 + an)。高斯小学时算 1+2+…+100 = 5050 用的正是此法。

几何含义（求和）：Sn 可以看成梯形面积。把每一项 ai 看成"宽度 1、高度 ai"的矩形，n 个矩形首尾相连排成一排，面积之和就是 Sn；当 d 很小、点很密时，这排矩形趋近一个梯形，上底 a1、下底 an、高 n，于是 Sn = (上底 + 下底) × 高 ÷ 2 = n(a1 + an)/2。
物理含义（求和）：匀加速（匀减速）直线运动中，位移 = 平均速度 × 时间：s = (v₀ + vₜ)/2 · t。这与 Sn = (a1 + an)/2 · n 完全同构——首项、末项的平均值 × 项数。在速度—时间图像里，位移正是速度曲线下的梯形面积，等差求和就是这条"速度折线"下的面积。

4.3 等比数列

定义

从第 2 项起，每一项与它前一项的比等于同一个非零常数，这个数列叫等比数列，这个常数叫公比 q（要求 a1 ≠ 0，q ≠ 0）：

aₙ₊₁ / aₙ = q   (n ∈ N*)    即  aₙ₊₁ = aₙ · q

例如 2, 6, 18, 54, …：每一项 ×3 得到下一项，公比 q = 3；再如 16, 8, 4, 2, …：公比 q = 1/2（每项减半）。

通项公式

aₙ = a₁ · q^(n − 1)
几何含义：把 an = a1·qn−1 改写成 an = (a1/q)·qn，它是关于 n 的指数函数，图像上的离散点落在指数曲线 y = (a1/q)·qx 上：
  • q > 1：指数曲线向上爆涨，相邻点越拉越开（单调递增）；
  • 0 < q < 1：指数曲线向下衰减，点越来越密地逼近 0（单调递减）；
  • q < 0：正负交替（摆动数列），点在横轴上下跳动；
  • q = 1：常数列，所有点等高。
等差数列是"直线上的等距点"，等比数列是"指数曲线上的等倍点"——一个是等步长（加），一个是等倍率（乘）。
物理含义：等比数列 = "等倍率增长 / 衰减"，描述一切"按比例"而非"按固定量"变化的现实过程：
  • 复利：本金 P、年利率 r，n 年后本利和 P(1+r)n，是公比 q = 1+r 的等比数列；
  • 放射性衰变 / 半衰期：每过一个半衰期物质剩一半，q = 1/2；
  • 细菌繁殖：每小时翻倍，q = 2。
"利滚利""越滚越快""逐级衰减"这些直觉，本质都是等比数列。

等比中项

若 a、G、b 成等比数列，则 G 是 a 与 b 的等比中项：

G² = a·b     即  G = ±√(a·b)   （a、b 同号时）
几何含义：G 是 a、b 的几何平均（对应等差中项的算术平均）。注意 G 有正负两个值（例如 4 与 9 的等比中项是 ±6），而等差中项只有一个值。

重要性质

下标和相等 ⇒ 项积相等：若 m + n = p + q，则 am·an = ap·aq。⚠️ 与等差数列相反——等差数列是"和"相等，等比数列是"积"相等，两者务必分清。

前 n 项和公式

         ┌  a₁(1 − qⁿ) / (1 − q)   （q ≠ 1）
  Sₙ =   ┤
         └  n · a₁                  （q = 1）

推导（错位相减法）：写出 Sn，再两边同乘 q 得 qSn，两式错开一位相减，中间各项全部抵消，只剩首尾：Sn − qSn = a1 − a1qn，故 Sn = a1(1 − qn)/(1 − q)。

几何含义（求和）：Sn 是"指数曲线上离散点的高度之和"。错位相减的几何本质：把 Sn 与 qSn（各点向右平移一格、高度按 q 缩放）上下对齐相减，中间"尾巴"两两抵消，只留下首尾两点。当 0 < q < 1 时，n → ∞ 有 Sn → a1/(1 − q)，无穷递缩等比数列收敛到一个有限值——几何上就是"每次走剩余路程的一半"，总路程不断逼近终点却永远差一点（芝诺悖论的极限解释）。
物理含义（求和）：等比求和 = 倍增（或衰减）总量的累计：复利若干年后的总本利、放射性物质多次半衰期后仍存留的总量、按固定倍率逐级衰减的分段总长度等，都是等比求和。

4.4 数列求和（方法总汇）

求前 n 项和 Sn，核心思路是"把不会的化成会的"——最终大多归结为等差或等比求和。常用方法如下：

① 公式法

等差、等比直接套公式（见 4.2、4.3）。先判断是等差还是等比，再选用对应公式。

② 倒序相加法

适用于"首尾等距项之和为定值"的数列（等差数列是典型）。正写一遍 + 倒写一遍，逐对相加：

Sₙ = a₁ + a₂ + … + aₙ₋₁ + aₙ
Sₙ = aₙ + aₙ₋₁ + … + a₂ + a₁
─────────────────────────────
2Sₙ = (a₁+aₙ) + (a₂+aₙ₋₁) + … + (aₙ+a₁) = n(a₁+aₙ)

③ 错位相减法

适用于「等差 × 等比」型，如 an = n·2n、an = (2n−1)·3n。同乘公比后错位相减，把"等差×等比"降成纯等比再求和。

④ 分组求和法

把数列拆成若干已知数列之和（差），分别求和再合并。例如 1+2, 2+4, 3+8, … 拆成等差数列 1,2,3,… 与等比数列 2,4,8,… 分别求和。

⑤ 裂项相消法（望远镜求和）

把通项拆成相邻两项之差，求和时中间项两两抵消、只留首尾。最经典的裂项：

1 / [n(n+1)]  =  1/n  −  1/(n+1)

Σ(k=1→n) 1/[k(k+1)] = (1 − 1/2) + (1/2 − 1/3) + … + (1/n − 1/(n+1))
                     = 1 − 1/(n+1) = n/(n+1)
几何含义：裂项相消是"望远镜求和"——像伸缩望远镜一样，中间每一节都与下一节重叠抵消，展开后只剩最外两端。把每段 1/[k(k+1)] 看成相邻单位分数之差，累加时相邻项正负对消，和只由起点 1 与终点 1/(n+1) 决定。
物理含义：求和本质是"把离散增量累加成总量"：速度序列求和 = 位移，流量序列求和 = 总量，功率序列求和 = 能量。裂项相消的物理含义是——总量只由起点与终点决定，与中间路径无关（如位移 = 末位置 − 初位置，中间如何运动被"抵消"掉）。

⑥ 并项求和法

对正负交替的摆动数列，把相邻两项"并成一组"再求和。例如 1 − 2 + 3 − 4 + …，每两项并成 −1，再数一共有几组。

典型例题（自测）

  1. 写出数列 1, 3, 5, 7, … 的通项公式，并求第 100 项。
  2. 等差数列中 a1 = 3，d = 2，求 an 与 S20。
  3. 等差数列中已知 a3 = 7，a7 = 15，求 a1、d 与 a10。
  4. 等比数列中 a1 = 2，q = 3，求 a5 与 S5。
  5. 等比数列中已知 a2 = 6，a4 = 54（q > 0），求 q 与 a1。
  6. 求和：1 + 2 + 4 + … + 512（判断是等比数列，套求和公式）。
  7. 求 Σ(k=1→n) 1/[k(k+1)]，并求它的前 100 项和。
  8. 用错位相减法求和：S = 1·2 + 2·4 + 3·8 + … + n·2n。

常见误区

  • ❌ "数列就是集合" → ❌ 数列有顺序、项可重复；集合无序且元素互异。1,2,3 与 3,2,1 是不同数列，但 {1,2,3} 与 {3,2,1} 是同一集合。
  • ❌ "等差通项 an = a1 + nd" → ❌ 应为 an = a1 + (n−1)d，首项到第 n 项只跨了 n−1 步。
  • ❌ "等比求和直接套 a1(1−qn)/(1−q)" → ❌ 必须先检查 q 是否等于 1；q = 1 时是常数列，Sn = n·a1，套公式会分母为 0。
  • ❌ "等比中项只有一个正数" → ❌ G = ±√(ab)，可正可负（a、b 同号时）；4 与 9 的等比中项是 ±6。
  • ❌ 下标和性质用错：等差数列是"和相等"（am+an = ap+aq），等比数列是"积相等"（am·an = ap·aq），两者张冠李戴。
  • ❌ 由递推式求通项后忘记验证 n = 1：不少递推得到的通项公式只对 n ≥ 2 成立，首项 a1 必须单独检验，必要时分段写出。
  • ❌ 错位相减时项数、首末项算错：乘以 q 后要对齐"错开一位"，相减结果只剩首尾两项，最后还要除以 (1 − q)。

课本外 · 典故与思考

典斐波那契的兔子问题与黄金比例（点击展开）

直觉先行：一对兔子出生后从第 2 个月起每月生一对新兔子，且永不死——每个月有多少对兔子？1202 年，比萨商人之子斐波那契（Leonardo Fibonacci，约 1170—约 1250）在《算盘书》里提出这个问题，得到数列

1, 1, 2, 3, 5, 8, 13, 21, 34, …

规律是：从第 3 项起，每一项等于前两项之和——写成递推式，就是本章 4.1 节的递推公式 aₙ₊₂ = aₙ₊₁ + aₙ。（兔子题本身是理想化的模型，但数列的数学是真的。）

与黄金比例的联系：相邻两项之比 5/3、8/5、13/8、21/13、… 越来越接近黄金比例 φ = (1+√5)/2 ≈ 1.618。在自然界，向日葵头状花序、松果、菠萝的螺旋数目里常能看到斐波那契数（例如相邻两族螺旋数是 21 和 34），因为"每次转 φ 个圆周角"能把种子排得最密。

顺带一提：《算盘书》还系统地向欧洲介绍了印度—阿拉伯数码（今天写作 0、1、2…9 的这套记数法），这一贡献的影响甚至比兔子问题更大。

一句话总结：一个"兔子问题"给出了本章最经典的递推数列，而它的相邻项之比，悄悄逼近了黄金比例。
趣棋盘上的麦粒：等比数列的"爆炸"（点击展开）

传说（未必真实）：国际象棋的发明者向国王讨赏，只要在第 1 个格放 1 粒麦子、第 2 格 2 粒、第 3 格 4 粒……每格翻一倍，放满 64 格。国王觉得这赏赐太便宜了，立刻答应——结果全国的粮食都不够。

这个传说之所以流传至今，是因为它背后是一个真实的数学事实：这是一个 a₁ = 1、q = 2 的等比数列求和，总数

1 + 2 + 4 + … + 2⁶³ = 2⁶⁴ − 1 ≈ 1.8 × 10¹⁹（粒）

约合 1800 亿吨以上的麦子，远超古代世界的粮食总量。本章的等比求和公式 a₁(1−qⁿ)/(1−q)，当年就能算出这位国王的破产。

物理含义："每步翻倍"的等倍率增长随处可见——复利"利滚利"、细菌每 20 分钟翻一倍、核裂变的链式反应，都是同一个等比数列在起作用。增长之快超出直觉，这正是等比数列最值得警惕的脾气。

一句话总结：国王输给的不是象棋发明者的聪明，而是等比数列 q = 2 的爆炸性增长。
思数学归纳法：一推到底的多米诺骨牌（点击展开）

想证明什么？例如：前 n 个奇数之和 1 + 3 + 5 + … + (2n − 1) = n²。这个结论对每个正整数 n 都对，但你不能挨个检验到无穷。怎么办？

两步走（多米诺骨牌思想）：

  • 奠基：验证 n = 1 时成立（推倒第一张牌）；
  • 递推：假设 n = k 时成立，能推出 n = k + 1 时也成立（任意一张倒下都会推倒下一张）。

两步合起来，就能从 1 一直推到无穷——每一张牌都"确实"会倒下。

历史：意大利数学家毛罗利科（Francesco Maurolico，1494—1575）在 1575 年的《算术》里第一次使用这种证明（正是用上面这个奇数求和当例子）；帕斯卡后来在《论算术三角形》里把它用得炉火纯青——帕斯卡三角形第 n 行的组合数公式，就是用归纳法证明的。

与本章的联系：归纳法本质上是"递推的证明版"——本章用递推公式 aₙ₊₁ = f(aₙ) 生成数列，归纳法则给"对每一个 n 都成立"这句话提供担保。

一句话总结：数列靠递推"往下长"，数学归纳法靠两步"往上推"——它们是一枚硬币的两面。

本章练习卷（含答案）

一、练习题

  1. 判断「数列就是集合」这句话是否正确，并说明理由；再写出数列 1, 3, 5, 7, … 的通项公式与第 20 项。
  2. 等差数列中 a1 = 2，d = 3，写出通项公式；并解释公差 d 在图像上的几何含义。
  3. 等差数列中 a1 = 3，an = 21，共 10 项。用「梯形面积」的观点求前 10 项和 S10。
  4. 等比数列中 a1 = 2，q = 3，求 a4 与 S4；并联系「复利」说明公比 q 的现实含义。
  5. 求和 1 + 2 + 4 + … + 512：先判断这是什么数列，再套用对应求和公式计算。
  6. 用裂项相消法求 Σ(k=1→100) 1/[k(k+1)]，并说明它的几何/物理含义。

二、参考答案（点击展开）

查看第1题答案

这句话错误。数列有顺序且项可重复，集合无序且元素互异，所以 1,2,3 与 3,2,1 是两个不同的数列。通项公式 an = 2n − 1；第 20 项 a20 = 2×20 − 1 = 39。

查看第2题答案

通项 an = 2 + (n−1)×3 = 3n − 1。公差 d = 3 是这些离散点所在直线的斜率，表示每向右走一步（项数 +1），项的值就上升 3，即每一步的固定「步长」。

查看第3题答案

S10 = n(a1 + an)/2 = 10×(3 + 21)/2 = 120。几何上这就是「上底 a1=3、下底 an=21、高 n=10」的梯形面积：(上底 + 下底) × 高 ÷ 2。

查看第4题答案

a4 = a1·q3 = 2×27 = 54；S4 = a1(1−q4)/(1−q) = 2×(1−81)/(1−3) = 2×(−80)/(−2) = 80。q = 3 相当于每期都变为上一期的 3 倍（增长率 200%），正如复利中「利滚利」的等倍率增长。

查看第5题答案

这是等比数列：a1 = 1，公比 q = 2，末项 512 = 29，故共有 10 项。S = a1(1−qn)/(1−q) = 1×(1−210)/(1−2) = 1023。

查看第6题答案

1/[k(k+1)] = 1/k − 1/(k+1)，裂项后中间各项两两抵消：原式 = (1 − 1/2) + (1/2 − 1/3) + … + (1/100 − 1/101) = 1 − 1/101 = 100/101。几何上是「望远镜求和」——像伸缩望远镜一样中间重叠抵消、只剩首尾两端；物理含义是总量只由起点与终点决定，与中间路径无关。
