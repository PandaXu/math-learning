第5章 一元函数的导数及其应用

高中 / 选择性必修第二册

一句话总纲：导数 = 函数在某一点的瞬时变化率。几何上它是曲线在该点切线的斜率，物理上它是瞬时速度（位移的导数）与瞬时加速度（速度的导数）。学完本章，你要能在心里"看见"：曲线任意一点附近都有一条恰好贴合的切线，切线的倾斜方向与倾斜程度，正是函数"正在上升还是下降、上升得多快"的答案。

5.1 导数的概念：从平均变化率到瞬时变化率

平均变化率（先看"整体快慢"）

设函数 y = f(x)，自变量从 x₀ 变到 x₀ + Δx，函数值相应从 f(x₀) 变到 f(x₀ + Δx)。称

        Δy     f(x₀ + Δx) − f(x₀)
       ──── = ───────────────────
        Δx            Δx

为函数在区间 [x₀, x₀ + Δx] 上的平均变化率。

几何含义：平均变化率就是割线的斜率——连接曲线上的两个点 (x₀, f(x₀)) 与 (x₀+Δx, f(x₀+Δx)) 的那条直线的斜率。它描述的是"这一段区间上，y 平均每单位 x 变化多少"。
物理含义：若 s = s(t) 是位移函数，则平均变化率 Δs/Δt 就是这段时间的平均速度。例：3 小时内走了 240 km，平均速度 = 240/3 = 80 km/h——但它只是"整体平均"，看不出每一瞬间的快慢。

瞬时变化率（导数）——平均的极限

平均速度的缺陷：它掩盖了中途的加速、减速。要让"平均"变成"瞬时"，就要让时间间隔 Δt 无限缩小到 0。于是：

                   f(x₀ + Δx) − f(x₀)
  f'(x₀) =  lim   ───────────────────
           Δx→0          Δx

这个极限值就叫函数 f(x) 在点 x₀ 处的导数（瞬时变化率），记作 f'(x₀)，也可写作 y'|_{x=x₀} 或 dy/dx|_{x=x₀}。

等价的定义式（令 x = x₀ + Δx，则 Δx → 0 即 x → x₀）：

                   f(x) − f(x₀)
  f'(x₀) =  lim   ─────────────
           x→x₀       x − x₀
物理含义（核心！）：位移对时间求导得瞬时速度，速度对时间求导得瞬时加速度。这就是微积分最经典的来源——牛顿研究运动时发现：瞬时速度是位移函数的导数，加速度是速度函数的导数。
几何含义（核心！）：让 Δx 无限变小，割线的两个端点无限靠近、最终重合为一点，割线就"转动到极限位置"变成切线。所以导数就是切线的斜率——它是"局部"的看法：把曲线在一点附近近似看成一条直线。

导函数

如果对区间内每个 x，f(x) 都可导，就得到一个以 x 为自变量的新函数 f'(x)，称为 f(x) 的导函数（简称导数）：

                  f(x + Δx) − f(x)
  f'(x) =  lim   ─────────────────
          Δx→0          Δx

关系：f'(x₀) 是导函数 f'(x) 在 x = x₀ 处的函数值。可导必连续（连续未必可导，例如尖点、折点处不可导）。

用定义求导的三个步骤：① 求增量 Δy = f(x+Δx) − f(x)；② 作比值 Δy/Δx；③ 取极限 Δx → 0。

5.2 导数的几何意义：切线的斜率

函数 y = f(x) 在点 x₀ 处的导数 f'(x₀)，等于曲线在点 (x₀, f(x₀)) 处切线的斜率。这就是导数的几何意义。

切线方程（点斜式）：

  y − f(x₀) = f'(x₀) · (x − x₀)

切线斜率告诉我们曲线在该点"正在怎样走"：

f'(x₀) 的符号切线方向函数在该点附近
f'(x₀) > 0切线向右上方倾斜上升（递增）
f'(x₀) < 0切线向右下方倾斜下降（递减）
f'(x₀) = 0切线水平暂时"平"下来（可能是极值点或平台）
几何含义：曲线在一点处是"上坡"还是"下坡"，坡度有多陡，全部由切线斜率（即导数）决定。|f'(x₀)| 越大，切线越陡，函数在该点变化越剧烈。
物理含义：位移-时间图像上，某点切线的斜率 = 该时刻的瞬时速度；速度-时间图像上，某点切线的斜率 = 该时刻的瞬时加速度。图像的"陡峭程度"直接对应物理量的变化快慢。

例：曲线 y = x² 在点 (1, 1) 处，f'(1) = 2，故切线方程为 y − 1 = 2(x − 1)，即 y = 2x − 1。

四则运算法则

  [u(x) ± v(x)]' = u'(x) ± v'(x)
  [u(x) · v(x)]' = u'(x)v(x) + u(x)v'(x)
  [C · u(x)]'    = C · u'(x)          （C 为常数）
  [u(x)/v(x)]'   = [u'(x)v(x) − u(x)v'(x)] / [v(x)]²   （v(x) ≠ 0）

例：求 y = x³ − 2x² + 5x − 7 的导数。

  y' = (x³)' − (2x²)' + (5x)' − (7)'
     = 3x² − 4x + 5

复合函数的求导法则（链式法则）

若 y = f(u)、u = g(x)，则复合函数 y = f(g(x)) 的导数为：

  y' = f'(u) · g'(x)，即  dy/dx = (dy/du) · (du/dx)

口诀："由外向内，层层求导再相乘"——先对外层函数求导（把内层整体看作 u），再乘以内层函数的导数。

例：y = (2x + 1)³，设 u = 2x + 1，则 y = u³。

  y' = 3u² · (2x+1)' = 3(2x+1)² · 2 = 6(2x+1)²

例：y = ln(x² + 1)，y' = [1/(x²+1)] · 2x = 2x/(x²+1)。

物理含义：链式法则对应"复合变化率"——位移对时间的速度 = 位移对某个中间量（如角度）的变化率 × 中间量对时间的变化率。它是处理"变量的变量"这一普遍问题的通用工具。

5.4 函数的单调性与导数

导数把"判断函数单调性"这件原本要比较函数值大小的事，变成了"只看导数符号"的简单判断：

条件结论
在区间内 f'(x) > 0f(x) 在该区间单调递增
在区间内 f'(x) < 0f(x) 在该区间单调递减
在区间内 f'(x) = 0f(x) 在该区间为常数
几何含义：导数 > 0 意味着每一点的切线都向右上倾斜，曲线"一路上坡"；导数 < 0 意味着切线都向右下倾斜，曲线"一路下坡"。导数符号 = 切线的倾斜方向 = 函数的升降方向。
物理含义：若 v(t) > 0，位移 s(t) 递增（物体在正方向上前进）；若 v(t) < 0，s(t) 递减（物体向反方向运动）。速度的正负决定位移的增减。

求单调区间的标准步骤：

  1. 求定义域与导函数 f'(x)；
  2. 令 f'(x) = 0 求出驻点（也叫临界点），这些点把定义域分成若干区间；
  3. 在每个区间内取一个"测试点"代入 f'(x) 判断正负；
  4. 据符号写出单调递增区间与单调递减区间。

例：f(x) = x³ − 3x² + 2，f'(x) = 3x² − 6x = 3x(x − 2)，驻点为 x = 0 与 x = 2。

  • x < 0 时，f'(x) > 0 → 递增；
  • 0 < x < 2 时，f'(x) < 0 → 递减；
  • x > 2 时，f'(x) > 0 → 递增。

故递增区间为 (−∞, 0) 和 (2, +∞)，递减区间为 (0, 2)。

5.5 函数的极值与最值

极值的定义

若在 x₀ 附近，f(x₀) 比周围所有函数值都大，则 f(x₀) 是极大值；比周围都小，则是极小值。极值是局部概念——"这一小片区域里的最高/最低点"，不是整个定义域的最高/最低。

极值的必要条件与充分条件

必要条件：可导函数在极值点处必有 f'(x₀) = 0（即极值点必是驻点）。但反过来不成立——驻点未必是极值点。

充分条件（导数变号法）：设 x₀ 是驻点，考察 f'(x) 在 x₀ 左右的符号：

x₀ 左侧 f'(x)x₀ 右侧 f'(x)结论
正（+）负（−）f(x₀) 为极大值
负（−）正（+）f(x₀) 为极小值
不变号（同正或同负）同号不是极值（如 y = x³ 在 x = 0 处）
几何含义：极大值点是曲线"从上升到下降"的转折点——切线斜率由正变负，切线由向右上倾斜转为向右下倾斜，山顶处切线恰好水平；极小值点是"从下降到上升"的转折点（谷底）。
物理含义：以竖直上抛为例，高度 h(t) 在最高点处 h'(t) = v(t) = 0（速度为零），且速度由正（上升）变负（下落）——最高点正是 h(t) 的极大值点。导数变号 = 运动方向发生反转。

求极值的步骤：① 求 f'(x)；② 令 f'(x) = 0 得驻点；③ 列表考察驻点左右导数符号；④ 据变号情况确定极值并计算极值。

最值（全局概念）

最值是整个区间上的最大值与最小值，是全局概念。对闭区间 [a, b] 上的连续函数，最值一定存在，且只可能在两类点取得：驻点（f'(x)=0 的点）与区间端点 a、b。

求最值的步骤：

  1. 求 f'(x)，解 f'(x) = 0 得所有驻点；
  2. 计算 f(驻点) 与 f(a)、f(b)；
  3. 比较这些函数值，最大者即最大值，最小者即最小值。

例：求 f(x) = x³ − 3x 在 [−2, 2] 上的最值。

  f'(x) = 3x² − 3 = 3(x − 1)(x + 1)，驻点 x = −1, 1
  f(−2) = −2,  f(−1) = 2,  f(1) = −2,  f(2) = 2
  最大值 = 2（在 x = −1 与 x = 2 取得），最小值 = −2（在 x = −2 与 x = 1 取得）
极值与最值的区别：极大值只在局部最大，可能比别的极小值还小；最值是全局。最值点若在区间内部取得，则它同时也是极值点；若最值在端点取得，则它未必是极值（端点处一般不谈极值）。

典型例题（自测）

  1. 用定义求 f(x) = x² 在 x = 1 处的导数，并写出曲线在 (1, 1) 处的切线方程。
  2. 求下列函数的导数：(a) y = 3x⁴ − 5x³ + 2x − 1；(b) y = x·eˣ；(c) y = sin x / x；(d) y = (x² + 1)⁵。
  3. 求 f(x) = x³ − 3x² − 9x + 5 的单调区间与极值。
  4. 求 f(x) = x³ − 12x 在闭区间 [−3, 3] 上的最大值与最小值。
  5. 一质点作直线运动，位移 s(t) = t³ − 6t² + 9t（单位：米，t 单位：秒）。求：何时速度为 0？质点的速度 v(t) 与加速度 a(t) 表达式是什么？

常见误区

  • ❌ "导数就是斜率本身，和极限无关" → ❌ 导数是割线斜率当 Δx → 0 时的极限，是一种瞬时变化率，必须先有极限概念。
  • ❌ "f'(x₀) = 0 一定是极值点" → ❌ 只是必要条件。例：y = x³ 在 x = 0 处 f'(0) = 0，但不是极值（导数不变号）。
  • ❌ "极大值一定大于极小值" → ❌ 极值是局部概念，某处的极大值可能比另一处的极小值还小。
  • ❌ "求最值只要令导数为 0 就行" → ❌ 闭区间最值还必须比较区间端点的函数值，端点可能取得最值。
  • ❌ "(uv)' = u'v'" → ❌ 乘法法则不是分别求导相乘，正确是 (uv)' = u'v + uv'；同理除法也不是 (u/v)' = u'/v'。
  • ❌ "复合函数 y = (2x+1)³ 求导忘了乘内层导数" → ❌ 漏掉链式法则的 g'(x) = 2，会错得 3(2x+1)²。要"由外向内层层求导再相乘"。
  • ❌ "cos x 的导数是 sin x" → ❌ (cos x)' = −sin x，注意负号；(sin x)' = cos x。

课本外 · 典故与思考

史微积分发明权之争：牛顿与莱布尼茨（点击展开）

两位主角：

  • 牛顿（Isaac Newton，1643—1727）：1665—1666 年，伦敦瘟疫大流行，剑桥大学停课，牛顿回到乡下老家，在一年多里发明了他称为"流数法"的微积分。但他没有立刻发表，只以手稿在少数人之间流传。
  • 莱布尼茨（Gottfried Wilhelm Leibniz，1646—1716）：1675 年前后在巴黎独立发展出微积分，并在 1684 年公开发表《求极大极小的新方法》——这是历史上第一篇正式发表的微积分论文。

争端：1699 年起，围绕"谁先发明"爆发了持续多年的优先权之争，英国皇家学会也介入调查。讽刺的是，英国数学家为了"捍卫牛顿"长期拒绝使用莱布尼茨的记号，反而把自己和欧洲大陆的数学交流隔离开来，拖慢了英国数学的发展。

今天的历史结论是清晰的：两人各自独立地发明了微积分。牛顿更早（约 1665—1666），莱布尼茨更早发表（1684），而本章导数公式表里那套"求导运算"，正是这场发明留下的共同遗产。

一句话总结：牛顿与莱布尼茨各自独立发明了微积分——真正的输家，是后来那些站队吵架的数学家。
思记号的力量：牛顿的"流数"与莱布尼茨的 dy/dx（点击展开）

牛顿把瞬时变化率叫做"流数"（fluxion，即"流动之数"）：位置是"流量"，位置的变化快慢是"流数"，记号是在字母上方加一点（如 ẋ 表示位置对时间的变化率）。这套名词生动，但记号只对"时间"一种自变量好用，而且点多点少很难分清。

莱布尼茨则把变化率写成 dy/dx（读作"dy 比 dx"），把微积分设计成一套符号运算：链式法则在他的记号下几乎"自己会说话"——

dy/dx = (dy/du) · (du/dx)

约分般的结构让复合求导（本章 5.3 节）一目了然。历史给出了判决：莱布尼茨的记号更成功，今天的教科书几乎全部采用 dy/dx、f'(x)（"带撇"的记法则来自拉格朗日）。

思考：好的记号不只是记录工具，更是思考的引擎——它把"瞬时变化率"这个困难的概念，压缩成一个可以机械操作的符号。微积分之所以能成为工程师人人会用的工具，记号功不可没。

一句话总结：同样是发明微积分，莱布尼茨多赢了一手——他赢在记号：dy/dx 沿用至今，而"流数"只剩在数学史里被提起。
问贝克莱的质问："消失量的幽灵"（点击展开）

1734 年，爱尔兰主教、哲学家贝克莱（George Berkeley，1685—1753）发表小册子《分析家》，向微积分开火。他抓住一个真问题：计算导数时，我们先是"设 Δx 不是 0"，用它去除、约分；最后又"令 Δx 等于 0"，把它丢掉。

他写道：这些"流数"到底是什么？是有限量？是无穷小？还是零？——它们都不是，它们是"已消失量的幽灵"（ghosts of departed quantities）。

这批评相当犀利——牛顿的无穷小确实经不起逻辑推敲。但贝克莱并不是要"废除微积分"（他自己承认微积分的结果是对的），而是在逼数学家回答"为什么可以这样算"。这个追问最终在 19 世纪开花结果：柯西与魏尔斯特拉斯用严格的"极限"语言（ε–δ 定义）重建了微积分——本章 5.1 节那句"当 Δx 趋向 0 时，Δy/Δx 的极限"，正是这场重建的产物。

一句话总结：一个看似"抬杠"的哲学质问，推动微积分用两百年时间补上了逻辑的窟窿。

本章练习卷（含答案）

一、练习题

  1. 已知位移函数 s(t) = 4t²（单位：米，t 为秒），求物体在 t = 1 到 t = 3 这段时间内的平均速度，并说明它在几何上对应位移—时间图像的什么？
  2. 用导数定义求 f(x) = x² 在 x = 2 处的导数 f'(2)，并解释它在几何上与物理上分别表示什么。
  3. 求下列函数的导数：① y = 3x⁴ − 2x³ + x − 5；② y = x·ln x；③ y = sin(2x + 1)。
  4. 已知曲线 y = x³，求它在点 (1, 1) 处的切线方程，并说明切线斜率与函数在该点"升降"的关系。
  5. 求 f(x) = x³ − 3x² 的单调区间与极值，并结合"山顶/谷底"解释极值点的几何意义。
  6. 一质点作直线运动，位移 s(t) = t³ − 6t² + 9t（t ≥ 0，单位：米/秒）。① 求速度 v(t) 与加速度 a(t)；② 求质点在何时刻瞬时速度为 0，并判断此时运动方向是否发生反转。

二、参考答案（点击展开）

查看第1题答案

平均速度 = Δs/Δt = [s(3) − s(1)] / (3 − 1) = [4·9 − 4·1] / 2 = (36 − 4)/2 = 16 m/s。几何上它是位移—时间图像上连接 (1, 4) 与 (3, 36) 两点的割线斜率，只反映整体平均快慢，看不出中途的瞬时变化。

查看第2题答案

由定义 f'(2) = lim(Δx→0) [f(2+Δx) − f(2)]/Δx = lim [(2+Δx)² − 4]/Δx = lim [4 + 4Δx + (Δx)² − 4]/Δx = lim (4 + Δx) = 4。几何上它是曲线 y = x² 在点 (2, 4) 处切线的斜率；物理上若 x 看作时间、f 看作位移，则它是 t = 2 时刻的瞬时速度。

查看第3题答案

① y' = 12x³ − 6x² + 1；② 由乘法法则 (uv)' = u'v + uv'：y' = (x)'·ln x + x·(ln x)' = ln x + x·(1/x) = ln x + 1；③ 由链式法则：y' = cos(2x+1)·(2x+1)' = 2cos(2x + 1)（外层 sin u 求导得 cos u，再乘内层 2x+1 的导数 2）。

查看第4题答案

y' = 3x²，故切点 (1, 1) 处斜率 k = f'(1) = 3·1² = 3。切线方程为 y − 1 = 3(x − 1)，即 y = 3x − 2。因 f'(1) = 3 > 0，切线向右上倾斜，说明函数在 x = 1 附近正处于上升状态，且上升得较快（|f'(1)| = 3 表示坡度较陡）。

查看第5题答案

f'(x) = 3x² − 6x = 3x(x − 2)，驻点为 x = 0 与 x = 2。x < 0 时 f'(x) > 0（递增）；0 < x < 2 时 f'(x) < 0（递减）；x > 2 时 f'(x) > 0（递增）。故递增区间 (−∞, 0)、(2, +∞)，递减区间 (0, 2)。x = 0 处导数由正变负，为极大值点，f(0) = 0；x = 2 处导数由负变正，为极小值点，f(2) = 8 − 12 = −4。几何上极大值点是曲线"由升转降的山顶"，极小值点是"由降转升的谷底"，两处切线均为水平（f'(x)=0）。

查看第6题答案

① 速度 v(t) = s'(t) = 3t² − 12t + 9，加速度 a(t) = v'(t) = 6t − 12。② 令 v(t) = 0：3t² − 12t + 9 = 3(t − 1)(t − 3) = 0，得 t = 1 与 t = 3（秒）。在 t = 1 处，v 由正（上升阶段）变负（下降阶段），位移由递增转递减，运动方向发生反转；在 t = 3 处，v 由负变正，位移由递减转递增，方向再次反转——这两处正对应位移函数 s(t) 的极值点（速度为零的"顶点/谷底"瞬间）。
