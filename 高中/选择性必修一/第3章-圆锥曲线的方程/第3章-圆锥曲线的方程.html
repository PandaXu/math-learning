第3章 圆锥曲线的方程

高中 / 选择性必修第一册

一句话总纲：圆锥曲线 = 「到定点（焦点）与到定直线（准线）的距离之比为常数 e 的点的轨迹」——0 < e < 1 得椭圆、e = 1 得抛物线、e > 1 得双曲线。学完本章，你要能在心里"看见"三条曲线：行星绕太阳的椭圆轨道、抛出去的物体走出的抛物线、以及由距离差定位出的双曲线，并能用 a、b、c、e、p 这几个参数把它们完全刻画出来。

3.1 圆锥曲线与曲线方程

圆锥曲线的由来（几何含义的源头）

「圆锥曲线」这个名字来自一个空间几何实验：用一个平面去截一个（两叶对顶的）圆锥面，改变平面与圆锥轴线的夹角，得到的截线（交线）正好就是圆、椭圆、抛物线、双曲线：

平面与圆锥的相对位置截得的曲线
平面垂直于圆锥的轴圆（椭圆的特殊情形）
平面与轴的夹角大于半顶角，且不平行于母线椭圆
平面平行于一条母线抛物线
平面与上下两叶都相交双曲线
核心直觉：圆、椭圆、抛物线、双曲线是「同一个圆锥面的不同截面」，所以它们共享统一的定义与统一的参数（离心率 e）。本章先各自给出定义与方程，最后再用 e 把它们统一起来。

曲线与方程（解析几何的基本思想）

解析几何的核心是用坐标（代数）去研究图形（几何）：把「点」写成有序数对 (x, y)，把「曲线」写成方程 F(x, y) = 0。两者要严格对应，必须同时满足两个条件：

  1. 完备性（曲线上 → 方程）：曲线上每一点的坐标 (x, y) 都是方程 F(x, y) = 0 的解；
  2. 纯粹性（方程 → 曲线上）：以方程 F(x, y) = 0 的解为坐标的点，都在曲线上。

此时称 F(x, y) = 0 是这条曲线的方程，这条曲线是方程的曲线。两个条件缺一不可——只有「完备性」会混进多余的点，只有「纯粹性」会漏掉曲线上的点。

求曲线方程的一般步骤（五步法）

  1. 建系：建立适当的平面直角坐标系，设动点为 M(x, y)；
  2. 列式：把题目给出的几何条件（如"距离之和为常数"）用坐标翻译成等式；
  3. 化简：两边平方、移项、合并，把等式化成最简形式；
  4. 验证：检查化简过程是否「增根」（平方会引入多余的点）或「失根」，必要时补上范围；
  5. 说明：指出所得方程表示的曲线（或轨迹）。
几何含义：方程是「点的集合」的代数名字——满足同一关系的所有点拼成一条曲线。物理含义：方程刻画的是动点运动所受的约束，例如"到两枚图钉的距离之和恒定"，正是用一根定长的绳子、两端钉住、笔尖绷紧画出的轨迹。

3.2 椭圆

椭圆的定义（几何）

定义：平面内与两个定点 F₁、F₂ 的距离的和等于常数（大于 |F₁F₂|）的点的轨迹叫做椭圆。这两个定点叫做椭圆的焦点，两焦点间的距离 |F₁F₂| 叫做焦距，记作 2c。

|MF₁| + |MF₂| = 2a    （常数 2a > 焦距 2c，即 a > c）
  • 为什么必须 2a > 2c？若 2a = 2c，轨迹退化为线段 F₁F₂；若 2a < 2c，满足条件的点不存在（三角形两边之和大于第三边）。
  • 画椭圆的方法：把一根绳子（长 2a + 2c）的两端固定在两个焦点（图钉）处，用笔尖绷紧绳子画一圈，笔尖画出的就是椭圆。
几何含义：椭圆是「到两焦点距离之和恒定」的点的集合，焦点是椭圆的"心脏"，焦距 2c 决定两心的远近。物理含义：这是开普勒第一定律——行星绕太阳运行的轨道是椭圆，太阳位于椭圆的一个焦点上；人造卫星的轨道也是椭圆。

椭圆的标准方程（如何从定义推出方程）

以两焦点所在直线为 x 轴、线段 F₁F₂ 的垂直平分线为 y 轴建系，则 F₁(−c, 0)、F₂(c, 0)。设椭圆上任意一点 M(x, y)：

√[(x+c)² + y²] + √[(x−c)² + y²] = 2a

移项后两边平方、再平方一次，化简得：
x²/a² + y²/(a²−c²) = 1

令 b² = a² − c²（b > 0），得到焦点在 x 轴上的椭圆标准方程：
x²/a² + y²/b² = 1   （a > b > 0，c² = a² − b²，焦点 F(±c, 0)）

焦点在 y 轴（两焦点在 y 轴上）时，标准方程把 x、y 互换位置：

y²/a² + x²/b² = 1   （a > b > 0，焦点 F(0, ±c)）

判断焦点在哪条轴上的方法：看哪个分母大——大分母对应的是 a²，焦点就在那一条坐标轴上（a > b 恒成立，长轴一定落在 a 所在的那条轴）。

椭圆的简单几何性质（以 x²/a² + y²/b² = 1 为例）

性质结论
范围|x| ≤ a 且 |y| ≤ b，椭圆被框在一个矩形 [−a, a]×[−b, b] 内
对称性关于 x 轴、y 轴、原点都对称（既是轴对称图形又是中心对称图形）；对称中心（原点）叫椭圆中心
顶点A₁(−a,0)、A₂(a,0)、B₁(0,−b)、B₂(0,b)；线段 A₁A₂ 叫长轴（长 2a），B₁B₂ 叫短轴（长 2b）；a 叫长半轴长，b 叫短半轴长
离心率e = c/a，且 0 < e < 1
a、b、c 关系c² = a² − b²（a 是最大者）

离心率 e 的几何意义（椭圆形状的"旋钮"）

离心率 e = c/a = 焦距/长轴长，它只由椭圆的形状决定（两个椭圆只要 e 相同，就"长得一样"——相似）。因为 b = a·√(1−e²)，所以：

  • e 越接近 0：c 越小，b 越接近 a，椭圆越"圆"；极限情形 e = 0 时 c = 0，两焦点重合，椭圆变成圆。
  • e 越接近 1：c 越接近 a，b 越接近 0，椭圆越"扁"。
几何含义：e 衡量椭圆"偏离圆"的程度，e 越大椭圆越扁长。物理含义：在天体运动中，e 描述轨道的"偏心"程度——近圆轨道 e ≈ 0，彗星那种又细又长的轨道 e 接近 1；行星轨道的 e 直接决定近日点与远日点的差距。

椭圆的反射性质与应用（物理含义）

椭圆有一条著名的光学（反射）性质：从一个焦点发出的光线（或声波、冲击波），经椭圆周反射后，必定通过另一个焦点。原因是椭圆上任意一点处的切线，恰好是两条"焦半径"（该点与两焦点的连线）所成夹角的角平分线的垂线。

  • 回音壁 / 耳语廊：站在一个焦点小声说话，声音经墙面反射后汇聚到另一个焦点，那里听得清清楚楚。
  • 体外冲击波碎石机：把冲击波源放在椭球面的一个焦点、结石放在另一个焦点，冲击波反射后集中轰击结石，把肾结石击碎而不伤及周围组织。
  • 行星轨道：太阳在焦点处，行星在轨道上受到的引力指向焦点。

3.3 双曲线

双曲线的定义（几何）

定义：平面内与两个定点 F₁、F₂ 的距离的差的绝对值等于常数（小于 |F₁F₂| 且不等于 0）的点的轨迹叫做双曲线。这两个定点叫做双曲线的焦点，两焦点间距离 |F₁F₂| = 2c 叫做焦距。

| |MF₁| − |MF₂| | = 2a    （0 < 2a < 2c，即 a < c）
  • 绝对值不能丢：去掉绝对值 |MF₁| − |MF₂| = 2a 只得到一支（离 F₂ 较近的那一支）；带上绝对值才得到左右两支。
  • 三个边界情形：常数 = 0 → 线段 F₁F₂ 的垂直平分线；常数 = 2c → 以 F₁、F₂ 为端点的两条射线；常数 > 2c → 无轨迹。
几何含义：双曲线是「到两焦点距离之差恒定」的点的集合，所以它有两支，两支分别对应"离这个焦点更近"与"离那个焦点更近"两种情形。物理含义：这是距离差定位（双曲线导航）的原理——测量自己到两个已知发射台的距离差（由信号到达的时间差算出），就确定自己落在一条双曲线上；再用第三个台画另一条双曲线，两条双曲线的交点就是你的位置（如罗兰 LORAN 导航系统）。

双曲线的标准方程

以两焦点所在直线为 x 轴、线段 F₁F₂ 的垂直平分线为 y 轴建系，由定义可化简得：

x²/a² − y²/b² = 1   （a > 0，b > 0，c² = a² + b²，焦点 F(±c, 0)）

焦点在 y 轴时：

y²/a² − x²/b² = 1   （焦点 F(0, ±c)）

与椭圆的关键区别（务必记牢）

椭圆中 c² = a² − b²（a 最大），双曲线中 c² = a² + b²（c 最大）。所以双曲线里"a 是否大于 b"没有要求，判断焦点在哪条轴要看哪个平方项是正的——正的平方项所在的那条轴就是焦点所在的轴。

双曲线的简单几何性质（以 x²/a² − y²/b² = 1 为例）

性质结论
范围x ≤ −a 或 x ≥ a（曲线在两条竖直线 x = ±a 的外侧，中间无图形）
对称性关于 x 轴、y 轴、原点对称；对称中心（原点）叫双曲线中心
顶点A₁(−a,0)、A₂(a,0)；线段 A₁A₂ 叫实轴（长 2a），a 叫实半轴长；B₁(0,−b)、B₂(0,b) 叫虚轴端点，线段 B₁B₂ 叫虚轴（长 2b），b 叫虚半轴长
渐近线y = ±(b/a)x
离心率e = c/a > 1
a、b、c 关系c² = a² + b²（c 是最大者）

渐近线的几何意义（双曲线的"骨架"）

双曲线的两支向外无限延伸时，会无限接近直线 y = ±(b/a)x，但永远不相交。画双曲线时通常先画出由直线 x = ±a、y = ±b 围成的"辅助矩形"，矩形的两条对角线就是渐近线，双曲线沿着对角线方向伸展开去。

几何含义：渐近线决定了双曲线"张开的方向和快慢"，是双曲线的骨架。物理含义：超音速飞行产生的冲击波波前是圆锥面，它与地面的交线正是一对双曲线，渐近线刻画了冲击波向两侧扩展的渐近方向。

离心率 e 与等轴双曲线

  • e = c/a > 1，且 e 越大，双曲线"开口越开阔"（越张得开）；e 越接近 1，开口越窄。
  • 等轴双曲线：a = b 时，方程为 x² − y² = a²，两条渐近线 y = ±x 互相垂直，离心率恒为 e = √2。
物理含义：双曲线的反射（光学）性质与椭圆相反——从一个焦点发出的光线，经双曲线一支反射后，反射光线的反向延长线经过另一个焦点（看起来像是从另一个焦点"发出来"的）。这在反射式望远镜的某些光路设计中有应用。

3.4 抛物线

抛物线的定义（几何：焦点 + 准线）

定义：平面内与一个定点 F 和一条定直线 l（l 不经过点 F）的距离相等的点的轨迹叫做抛物线。定点 F 叫做抛物线的焦点，定直线 l 叫做抛物线的准线。

|MF| = d(M, l)   （动点到焦点的距离 = 到准线的距离）
  • 焦点到准线的距离记作 p（p > 0），p 叫焦准距，它决定抛物线"开口的大小"。
  • 抛物线的离心率恒为 1——这正是它"到焦点与到准线距离之比"的定义本身。
几何含义：抛物线是「到一个定点与一条定直线等距」的点的集合，焦点与准线是它的两个"锚"。物理含义：这是抛体运动的轨迹——只受重力、初速度与重力方向不共线时，物体（忽略空气阻力）走过的路线就是抛物线。

抛物线的标准方程（四种形式）

取焦点到准线的垂线段中点为原点，对称轴为坐标轴建系。设焦点 F(p/2, 0)、准线 x = −p/2，由定义化简得：

y² = 2px   （p > 0，焦点 (p/2, 0)，准线 x = −p/2，开口向右）

其余三种标准方程及其焦点、准线、开口方向如下：

标准方程焦点准线开口方向
y² = 2px　(p>0)(p/2, 0)x = −p/2向右
y² = −2px　(p>0)(−p/2, 0)x = p/2向左
x² = 2py　(p>0)(0, p/2)y = −p/2向上
x² = −2py　(p>0)(0, −p/2)y = p/2向下

记忆规律：一次项决定对称轴（一次项是 x，则对称轴是 x 轴；一次项是 y，则对称轴是 y 轴）；一次项系数的正负决定开口朝向（正号朝正半轴方向开，负号朝负半轴方向开）；焦点的坐标是 (系数/4, 0) 或 (0, 系数/4)，准线在另一侧且与焦点关于顶点对称。

抛物线的简单几何性质（以 y² = 2px 为例）

性质结论
范围x ≥ 0，y 取一切实数（曲线在 y 轴右侧）
对称性关于 x 轴（对称轴）对称，无对称中心
顶点原点 O(0,0)，是抛物线与对称轴的交点，也是"离准线最近"的点
离心率e = 1
通径过焦点且垂直于对称轴的弦，长为 2p（可用来快速比较开口大小）

抛物线的反射性质与应用（物理含义）

抛物线有极其重要的反射（光学）性质：

  • 焦点 → 平行：从焦点发出的光线，经抛物线反射后，变成平行于对称轴的一束平行光。应用：探照灯、手电筒、汽车大灯——把光源（灯泡）放在焦点处，就能射出平行光束。
  • 平行 → 焦点：平行于对称轴射来的光线，经抛物线反射后，全部汇聚到焦点。应用：抛物面天线、卫星电视接收器、太阳灶——把信号（或阳光）集中到焦点处增强。
为什么抛物线能"聚焦"？因为抛物线由"到焦点与到准线距离相等"定义，这天然保证了：任意平行光线到达准线的路程相等，于是反射后到焦点的路程也相等——各条光线同时到达焦点（等光程），形成聚焦。这是抛物线反射性质背后的物理本质。

3.5 圆锥曲线的统一视角（第二定义）

统一定义（第二定义）：离心率 e 决定曲线形状

椭圆、抛物线、双曲线可以由同一条定义统一描述：

平面内动点 M 到定点 F（焦点）的距离，与到定直线 l（准线）的距离之比为常数 e：
          |MF| / d(M, l) = e
常数 e 的范围曲线类型补充
0 < e < 1椭圆到焦点近于到准线，轨迹"闭合"成椭圆
e = 1抛物线到焦点与到准线等距，轨迹"敞开"成抛物线
e > 1双曲线到焦点远于到准线，轨迹"张开"成双曲线

椭圆与双曲线准线的统一形式：对焦点在 x 轴上的椭圆、双曲线，对应准线为 x = ±a²/c，离心率 e = c/a；抛物线的准线为 x = −p/2，e = 1。

几何含义：第二定义把"两个焦点的和/差"这种双点定义，统一成"焦点 + 准线"这种点线定义，并指出唯一的开关就是 e。物理含义：在天体力学中，e 就是轨道能量的"刻度"——e < 1 是闭合的椭圆轨道（行星、卫星，被引力束缚），e = 1 是恰好能逃逸的抛物线轨道，e > 1 是掠过即走的双曲线轨道（脱离束缚）。一个 e，同时是几何形状参数和天体运动的能量参数，这是本章最深刻的统一。

准线定义中的定直线（与焦点配对，二者之比定义 e）反射聚焦中的"参照线"（等光程原理的几何基础）
焦距 2c两焦点间的距离决定椭圆扁圆、双曲线开口的"两心距离"
长轴 2a / 短轴 2b椭圆最长直径 / 最短直径轨道的尺寸参数（长轴决定轨道大小）
实轴 2a / 虚轴 2b双曲线两顶点间线段 / 辅助虚线段决定双曲线两支的距离与渐近线斜率
渐近线双曲线无限接近却永不相交的直线冲击波扩展的渐近方向、双曲线的"骨架"
离心率 e焦距/长轴(或实轴)长；刻画"偏离圆/张开"的程度轨道形状参数：e<1 椭圆、e=1 抛物线、e>1 双曲线（能量参数）
焦准距 p抛物线焦点到准线的距离决定抛物线开口大小（通径 = 2p）
a、b、c 关系椭圆 c²=a²−b²；双曲线 c²=a²+b²几何量之间的代数约束（a 最大 / c 最大）

典型例题（自测）

先独立思考，再对照解析

  1. 已知椭圆 16x² + 25y² = 400，求它的长轴长、短轴长、焦点坐标、离心率。
  2. 已知双曲线 4x² − 9y² = 36，求它的实轴长、虚轴长、焦点坐标、渐近线方程、离心率。
  3. 求抛物线 y² = −12x 的焦点坐标与准线方程。
  4. 动点 M 到定点 F(4, 0) 的距离与到定直线 x = 25/4 的距离之比为 4/5，求动点 M 的轨迹方程，并说明它是哪类曲线。
  5. 椭圆 x²/9 + y²/4 = 1 上一点 P 与两焦点 F₁、F₂ 构成三角形，若 ∠F₁PF₂ = 90°，求 △PF₁F₂ 的面积。
  6. 动圆 M 与圆 C₁: (x+3)² + y² = 1 外切，又与圆 C₂: (x−3)² + y² = 81 内切，求动圆圆心 M 的轨迹方程。

参考解析

  1. 化为标准式 x²/25 + y²/16 = 1：a = 5，b = 4，c = √(25−16) = 3。长轴长 2a = 10，短轴长 2b = 8，焦点 (±3, 0)，离心率 e = c/a = 3/5。
  2. 化为 x²/9 − y²/4 = 1：a = 3，b = 2，c = √(9+4) = √13。实轴长 6，虚轴长 4，焦点 (±√13, 0)，渐近线 y = ±(2/3)x，离心率 e = √13/3。
  3. 2p = 12 → p = 6，一次项系数为负 → 开口向左。焦点 (−3, 0)，准线 x = 3。
  4. 距离之比 4/5 < 1 → 椭圆。焦点 (4, 0) → c = 4；准线 x = a²/c = 25/4 → a² = 25，a = 5；b² = a² − c² = 9。轨迹为 x²/25 + y²/9 = 1。
  5. 焦点三角形面积公式 S = b²·tan(∠F₁PF₂/2)。这里 a = 3，b = 2，∠F₁PF₂ = 90°，故 S = b² = 4。
  6. 设动圆 M 半径为 r：外切 → |MC₁| = r + 1；内切 → |MC₂| = 9 − r。两式相加：|MC₁| + |MC₂| = 10（常数）。C₁(−3,0)、C₂(3,0)，2a = 10 → a = 5，2c = 6 → c = 3，b² = a² − c² = 16。轨迹为 椭圆 x²/25 + y²/16 = 1。

常见误区

  • ❌ "椭圆中 a、b、c 满足 c² = a² + b²" → ❌ 那是双曲线；椭圆是 c² = a² − b²（a 最大），双曲线才是 c² = a² + b²（c 最大）。
  • ❌ "双曲线的离心率 e < 1" → ❌ 双曲线 e > 1；椭圆才 0 < e < 1；抛物线 e = 1。
  • ❌ "双曲线是到两焦点距离之和为常数" → ❌ 双曲线是差的绝对值；之和为常数是椭圆。
  • ❌ 双曲线定义丢了"绝对值" → ❌ 只得一支；必须写 ||MF₁| − |MF₂|| = 2a 才是两支。
  • ❌ "椭圆的范围是 |x| ≥ a" → ❌ 椭圆 |x| ≤ a（闭合）；|x| ≥ a 是双曲线的范围。
  • ❌ 判断焦点位置只看"x² 在前还是 y² 在前" → ❌ 要看哪个分母大（椭圆）或哪个平方项为正（双曲线），与前后顺序无关。
  • ❌ "抛物线 y² = 2px 的焦点是 (p, 0)" → ❌ 焦点是 (p/2, 0)，准线是 x = −p/2，不要漏掉"除以 2"。
  • ❌ "抛物线的离心率是 0 或 > 1" → ❌ 抛物线 e 恒等于 1。
  • ❌ 长轴/实轴与"半轴长"混淆 → ❌ 长轴长是 2a，长半轴长是 a；写顶点坐标时用的是 ±a、±b。
  • ❌ 用第二定义时忘记"准线 x = a²/c"中的平方 → ❌ 椭圆、双曲线的准线是 x = ±a²/c（不是 a/c），抛物线的准线才是 x = −p/2。

本章练习卷（含答案）

一、练习题（由易到难，紧扣本章的几何/物理含义）

  1. 已知椭圆的标准方程为 x²/25 + y²/16 = 1，求它的长轴长、短轴长、焦距、焦点坐标与离心率，并说明焦点落在哪条坐标轴上。
  2. 已知双曲线的标准方程为 x²/9 − y²/16 = 1，求它的实轴长、虚轴长、焦距、焦点坐标、渐近线方程与离心率。
  3. 求抛物线 y² = 8x 的焦点坐标、准线方程与开口方向，并写出它的通径长。
  4. （物理含义）手电筒、汽车大灯为什么要把灯泡放在抛物面镜的焦点处？椭圆形的"耳语廊"中，为什么站在一个焦点小声说话，另一个焦点处反而能听得更清楚？请分别用抛物线和椭圆的反射性质解释。
  5. （第二定义）动点 M 到定点 F(3, 0) 的距离与到定直线 x = 25/3 的距离之比为 3/5，求动点 M 的轨迹方程，并说明它是哪类曲线、离心率是多少。
  6. 动圆 M 与圆 C₁: (x+4)² + y² = 4 外切，又与圆 C₂: (x−4)² + y² = 100 内切，求动圆圆心 M 的轨迹方程，并判断它是哪类曲线。

二、参考答案（点击展开）

查看第1题答案

分母 25 > 16，故焦点在 x 轴：a = 5，b = 4，c = √(25−16) = 3。长轴长 2a = 10，短轴长 2b = 8，焦距 2c = 6，焦点 (±3, 0)，离心率 e = c/a = 3/5。

查看第2题答案

a = 3，b = 4，c = √(9+16) = 5。实轴长 2a = 6，虚轴长 2b = 8，焦距 2c = 10，焦点 (±5, 0)，渐近线 y = ±(4/3)x，离心率 e = c/a = 5/3。

查看第3题答案

y² = 8x 中 2p = 8，得 p = 4。开口向右，焦点 (2, 0)，准线 x = −2，通径长 2p = 8。

查看第4题答案

抛物线：从焦点发出的光线，经抛物线反射后变成平行于对称轴的平行光束，所以把灯泡放在焦点处能射出照得更远、更集中的平行光。椭圆：从一个焦点发出的声波，经椭圆周反射后必定通过另一个焦点，因此一个焦点处的低声细语会汇聚到另一个焦点，那里的人听得清清楚楚。

查看第5题答案

距离之比 e = 3/5 < 1，是椭圆。焦点 (3, 0) → c = 3；准线 x = a²/c = 25/3 → a² = 25，a = 5；b² = a² − c² = 25 − 9 = 16。轨迹为 x²/25 + y²/16 = 1，离心率 e = 3/5。

查看第6题答案

设动圆 M 半径为 r。外切：|MC₁| = r + 2；内切：|MC₂| = 10 − r。两式相加得 |MC₁| + |MC₂| = 12（常数）。C₁(−4, 0)、C₂(4, 0)，2c = 8 → c = 4；2a = 12 → a = 6；b² = a² − c² = 36 − 16 = 20。轨迹为椭圆 x²/36 + y²/20 = 1。
