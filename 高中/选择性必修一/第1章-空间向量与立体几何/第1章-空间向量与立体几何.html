第1章 空间向量与立体几何

高中 / 选择性必修第一册

一句话总纲：空间向量 = 「带方向的箭头」。学完本章，你要能把立体几何中的方向、平行、垂直、距离、夹角全部翻译成向量的加法、数乘、数量积与坐标运算——让"看不见摸不着"的空间关系变成可以算的代数式，这正是向量法的威力所在。

记号约定：向量用带箭头的字母表示，如 a⃗、b⃗、v⃗（方向向量）、n⃗（法向量）；AB⃗ 表示从点 A 到点 B 的向量；|a⃗| 表示向量 a⃗ 的模（长度）；0⃗ 表示零向量。

1.1 空间向量及其运算

空间向量的概念

在空间中，既有大小又有方向的量叫空间向量。它用有向线段表示：从点 A 指向点 B 的有向线段记作 AB⃗，也可用单个字母 a⃗、b⃗、c⃗ 表示。向量 AB⃗ 的模（长度）记作 |AB⃗|，即线段 AB 的长度。

  • 零向量：长度为 0 的向量，记作 0⃗，方向任意。
  • 单位向量：模为 1 的向量。
  • 相等向量：大小相等且方向相同的向量（经平移后能完全重合）。
  • 相反向量：与 a⃗ 大小相等、方向相反的向量，记作 −a⃗。
  • 自由向量：向量只由大小和方向决定，与起点位置无关，可沿任意方向在空间中平移。这是向量法的根本前提——我们关心的永远是"朝哪、多长"，而不是"从哪出发"。
几何含义：向量是一个"带方向、有长度的箭头"，它把空间中的一次平移（位移）代数化：AB⃗ 就是"从 A 走到 B"这件事。物理含义：力 F⃗、速度 v⃗、位移 s⃗、加速度 a⃗、电场强度 E⃗ 都是向量——它们共同点在于"既要说明方向，又要说明大小"。

向量的加法与减法

加法法则（在空间中同样成立）：

  • 三角形法则：首尾相接。AB⃗ + BC⃗ = AC⃗（先走 AB 再走 BC，等于直接走 AC）。
  • 平行四边形法则：同一起点的两向量为邻边作平行四边形，对角线就是和向量。
  • 运算律：a⃗ + b⃗ = b⃗ + a⃗（交换律）；(a⃗ + b⃗) + c⃗ = a⃗ + (b⃗ + c⃗)（结合律）。

减法：a⃗ − b⃗ = a⃗ + (−b⃗)，即"减去一个向量 = 加上它的相反向量"。特别地，AB⃗ = OB⃗ − OA⃗（终点坐标向量减起点坐标向量）。

几何含义：加法就是平移的连续合成——先发生位移 a⃗ 再发生位移 b⃗，总效果是 a⃗ + b⃗；减法则是"反向平移"。物理含义：力的合成（平行四边形法则）、合位移、合速度都是向量加法；"相对速度 = 物体速度 − 参考系速度"就是向量减法。

向量的数乘（伸缩与反向）

实数 λ 与向量 a⃗ 的乘积 λa⃗ 仍是一个向量：

  • |λa⃗| = |λ| · |a⃗|（长度伸缩 |λ| 倍）。
  • 当 λ > 0 时，λa⃗ 与 a⃗ 方向相同；当 λ < 0 时，λa⃗ 与 a⃗ 方向相反；当 λ = 0 时，λa⃗ = 0⃗。

共线（平行）向量：方向相同或相反的非零向量叫共线向量。判定：向量 a⃗ 与 b⃗（b⃗ ≠ 0⃗）共线 ⟺ 存在唯一的实数 λ，使 a⃗ = λb⃗。

三点共线：A、B、C 三点共线 ⟺ AB⃗ 与 AC⃗ 共线（存在 λ 使 AB⃗ = λAC⃗）。

几何含义：数乘是"沿同一条直线把箭头拉长、缩短或掉头"，λ 就是缩放倍数 + 方向开关；共线向量就是"落在同一条直线上的箭头"（或平行直线）。物理含义：2F⃗ 表示两倍的力且方向不变，−F⃗ 表示大小相同、方向相反的力；共线向量对应"沿同一条作用线的量"。

共面向量

定义：平行于同一个平面的向量叫共面向量——把它们的起点平移到同一点时，它们都位于同一个平面内。

判定定理：若 a⃗、b⃗ 不共线，则向量 p⃗ 与 a⃗、b⃗ 共面 ⟺ 存在唯一的有序实数对 (x, y)，使 p⃗ = xa⃗ + yb⃗。

四点共面：空间四点 P、A、B、C 共面 ⟺ 存在实数 x、y，使 PA⃗ = xPB⃗ + yPC⃗（或等价地 OP⃗ = xOA⃗ + yOB⃗ + zOC⃗ 且 x + y + z = 1）。

几何含义：两个不共线向量只能"张成"一个平面，它们的所有线性组合 xa⃗ + yb⃗ 都躺在这个平面内——共面性 = "是否只由两个方向就能表示"。物理含义：同一平面内所有力的合力，总能用其中两个不共线的力表示出来（平面汇交力系）。

向量的数量积（点积 / 内积）

定义：设 〈a⃗, b⃗〉 为两向量 a⃗、b⃗ 的夹角（0 ≤ θ ≤ π），则

a⃗ · b⃗ = |a⃗| · |b⃗| · cos〈a⃗, b⃗〉

投影：向量 b⃗ 在向量 a⃗ 方向上的投影（有向投影）为 |b⃗|cos〈a⃗, b⃗〉，它可正可负可为零。于是数量积的几何意义就是：

a⃗ · b⃗ = |a⃗| × (b⃗ 在 a⃗ 方向上的投影长度)

运算律：

  • 交换律：a⃗ · b⃗ = b⃗ · a⃗；
  • 分配律：a⃗ · (b⃗ + c⃗) = a⃗ · b⃗ + a⃗ · c⃗；
  • 数乘结合：(λa⃗) · b⃗ = λ(a⃗ · b⃗)；
  • 注意：a⃗ · b⃗ 是一个实数，(a⃗ · b⃗) · c⃗ 无意义，所以数量积不满足结合律——不能写成 a⃗ · b⃗ · c⃗。

重要性质：

  • a⃗ ⊥ b⃗ ⟺ a⃗ · b⃗ = 0（垂直的根本判据，整章都用它）；
  • a⃗ · a⃗ = |a⃗|²，故 |a⃗| = √(a⃗ · a⃗)；
  • 夹角公式：cos〈a⃗, b⃗〉 = (a⃗ · b⃗) / (|a⃗| · |b⃗|)；
  • 柯西不等式形式：|a⃗ · b⃗| ≤ |a⃗| · |b⃗|。
几何含义：数量积是"一个向量在另一个向量方向上的投影与后者长度的乘积"；它用一个数度量了"两个方向有多一致"——点积为正说明夹角是锐角、为零说明垂直、为负说明是钝角。物理含义：恒力做功 W = F⃗ · s⃗ = |F⃗||s⃗|cosθ：力与位移同向做正功、垂直不做功、反向做负功——"力在位移方向上的投影 × 位移"正是功。

1.2 空间向量基本定理

从共线、共面到空间

先回顾两条"降维"定理：

  • 共线向量定理：a⃗、b⃗ 共线（b⃗ ≠ 0⃗）⟺ 存在唯一实数 λ，使 a⃗ = λb⃗。（一条直线上的向量由 1 个"基方向"唯一决定。）
  • 共面向量定理：a⃗、b⃗ 不共线时，p⃗ 与它们共面 ⟺ 存在唯一实数对 (x, y)，使 p⃗ = xa⃗ + yb⃗。（一个平面内的向量由 2 个"基方向"唯一决定。）

把这条链再走一步，就得到刻画整个三维空间的定理：

空间向量基本定理：若 a⃗、b⃗、c⃗ 是三个不共面的向量，
则空间中任一向量 p⃗ 都存在唯一的有序实数组 (x, y, z)，使得

        p⃗ = x·a⃗ + y·b⃗ + z·c⃗
  • {a⃗, b⃗, c⃗} 叫空间的一个基底，a⃗、b⃗、c⃗ 叫基向量。
  • 三基向量两两垂直 → 正交基底；若再都是单位向量 → 单位正交基底（最常用的是三个坐标轴方向的单位向量 i⃗、j⃗、k⃗）。
  • "唯一"保证了一旦选定基底，向量就与三元有序数组 (x, y, z) 一一对应——这就是后面坐标化的理论根基。
几何含义：两个不共线方向只能铺满一个平面，必须第三个不共面的方向才能"撑起"整个空间。任一向量能沿这三个方向被唯一分解——这句话的实质就是"空间的维数是 3"。物理含义：任意一个力、速度或位移都可以沿三个独立（不共面）的方向正交分解，如沿 x、y、z 轴分解；三维空间的物体有 3 个平动自由度，恰好对应三个基方向。

1.3 空间向量及其运算的坐标表示

空间直角坐标系与向量的坐标

在空间取三条两两垂直且交于一点 O 的数轴，分别叫 x 轴、y 轴、z 轴，并约定右手法则（右手的拇指、食指、中指依次指向 x、y、z 正方向），就得到空间直角坐标系 O-xyz。

  • 空间中点 P 的坐标 P(x, y, z)：x、y、z 分别是 P 到 yOz、zOx、xOy 三个坐标平面的"有向距离"。
  • 设沿 x、y、z 轴正方向的单位向量为 i⃗、j⃗、k⃗，则向量 a⃗ = x·i⃗ + y·j⃗ + z·k⃗ 记作 a⃗ = (x, y, z)，x、y、z 叫它的坐标（分量）。
  • 若 A(x₁, y₁, z₁)、B(x₂, y₂, z₂)，则 AB⃗ = (x₂ − x₁, y₂ − y₁, z₂ − z₁)（终点减起点）。

坐标运算公式

设 a⃗ = (x₁, y₁, z₁)，b⃗ = (x₂, y₂, z₂)：

运算公式
加法a⃗ + b⃗ = (x₁+x₂, y₁+y₂, z₁+z₂)
减法a⃗ − b⃗ = (x₁−x₂, y₁−y₂, z₁−z₂)
数乘λa⃗ = (λx₁, λy₁, λz₁)
数量积a⃗ · b⃗ = x₁x₂ + y₁y₂ + z₁z₂
模（长度）|a⃗| = √(x₁² + y₁² + z₁²)
夹角余弦cos〈a⃗, b⃗〉 = (x₁x₂ + y₁y₂ + z₁z₂) / (√(x₁²+y₁²+z₁²) · √(x₂²+y₂²+z₂²))
平行a⃗ ∥ b⃗（b⃗≠0⃗）⟺ x₁/x₂ = y₁/y₂ = z₁/z₂（对应坐标成比例）
垂直a⃗ ⊥ b⃗ ⟺ x₁x₂ + y₁y₂ + z₁z₂ = 0

两点间的距离、中点与定比分点

  • 两点距离：|AB| = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)——平面两点距离公式在空间中的直接推广。
  • 中点：线段 AB 中点 M 坐标 ((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2)。
  • 定比分点：若 AP⃗ = λ·PB⃗，则 P 的坐标为 ((x₁+λx₂)/(1+λ), (y₁+λy₂)/(1+λ), (z₁+λz₂)/(1+λ))。
几何含义：坐标就是把向量沿三个相互垂直的坐标轴方向分解后的投影长度；(x, y, z) 这三个数完整记录了向量的长短与朝向，于是"向量的运算"变成"三个数的运算"。物理含义：一个三维运动（位移、速度、加速度、力）可分解成沿 x、y、z 的三个独立的一维运动，坐标就是各方向上的分量；两点距离公式即三维空间中"两点间直线距离"。

1.4 用空间向量研究平行、垂直、距离与夹角

这是本章的"应用篇"。核心思想：给每一条直线配一个方向向量、给每一个平面配一个法向量，然后把所有位置关系都翻译成向量的共线、垂直、投影。

方向向量与法向量

  • 直线的方向向量：与直线平行（或就在直线上）的非零向量，记作 v⃗。一条直线的方向向量不唯一（彼此共线），但直线由"一点 + 一个方向向量"完全确定。
  • 平面的法向量：与平面垂直的非零向量，记作 n⃗。n⃗ ⊥ 平面 ⟺ n⃗ 垂直于平面内任意向量（等价于垂直于平面内两条相交直线）。

求法向量的通用方法：设 n⃗ = (x, y, z)，在平面内任取两个不共线向量 a⃗、b⃗，由 n⃗ · a⃗ = 0、n⃗ · b⃗ = 0 列出方程组，解出 x、y、z 的一组非零解（常令其中一个为 1，或取最简整数解）。

例：平面 α 内取 a⃗ = (1, 0, −1)，b⃗ = (0, 1, 1)，求 α 的法向量 n⃗ = (x, y, z)。

    n⃗ · a⃗ = 0   →   x − z = 0        →   x = z
    n⃗ · b⃗ = 0   →   y + z = 0        →   y = −z
    取 z = 1，得 n⃗ = (1, −1, 1)   （任取一组非零解即可）
几何含义：方向向量是直线的"朝向箭头"，法向量是平面的"垂直朝向箭头"——平面由它的法向量唯一确定方向（法向量旋转，平面就跟着转）。物理含义：法向量就是"面的朝向"，如镜面反射、平面的法线方向；重力在斜面上的正压力方向正是沿斜面的法向量。

用向量判定平行与垂直

位置关系向量条件本质
线线平行 l₁ ∥ l₂两方向向量共线：v⃗₁ ∥ v⃗₂（v⃗₁ = λv⃗₂）朝向相同（或相反）
线线垂直 l₁ ⊥ l₂v⃗₁ · v⃗₂ = 0朝向垂直
线面平行 l ∥ αv⃗ · n⃗ = 0 且直线不在平面内直线方向与平面法向垂直
线面垂直 l ⊥ αv⃗ ∥ n⃗（v⃗ = λn⃗）直线方向就是平面法向
面面平行 α ∥ β两法向量共线：n⃗₁ ∥ n⃗₂两平面朝向相同
面面垂直 α ⊥ βn⃗₁ · n⃗₂ = 0两平面朝向垂直
为什么好使？传统立体几何证明平行垂直要靠"作辅助线、找交线、用公理"，而向量法只需要算一个点积是否为 0、两个向量是否成比例——把几何证明变成代数判断，程序化、不易漏步骤。物理含义：判断"力是否沿平面"（切向力 vs 法向力）、"速度是否垂直撞击平面"、两运动方向是否正交，都是同一条代数判据。

用向量求距离

① 点到平面的距离：设平面 α 的法向量为 n⃗，平面内任取一点 A，则空间点 P 到 α 的距离为

        d = |AP⃗ · n⃗| / |n⃗|

直观理解：AP⃗ 在法向量 n⃗ 方向上投影的绝对值，就是 P 到平面的"垂线段"长度。

② 点到直线的距离：直线 l 的方向向量为 v⃗，l 上取一点 A，则点 P 到 l 的距离为

        d = |AP⃗| · sin〈AP⃗, v⃗〉  =  √( |AP⃗|² − (投影长度)² )

（即用勾股定理：斜边 |AP⃗|，减去它在直线上投影，余下的垂直分量即距离。若引入向量积，也可写作 d = |AP⃗ × v⃗| / |v⃗|。）

③ 异面直线的距离：对两异面直线 l₁、l₂，取 A ∈ l₁、B ∈ l₂，方向向量为 v⃗₁、v⃗₂，再取一个同时垂直于 v⃗₁、v⃗₂ 的非零向量 n⃗（即公垂线的方向），则

        d = |AB⃗ · n⃗| / |n⃗|

④ 平行线面、平行平面之间的距离：都归结为点到平面的距离（在其中一条线/一个面上任取一点算即可）。

几何含义：所有距离都是"沿某个垂直方向（法向量）的投影长度"——点到平面距离是沿法向量投影，异面直线距离是沿公垂线方向投影；"最短距离必然垂直于目标对象"是这些公式共同的几何直觉。物理含义：距离即"最短作用路径"，如电场中沿法线方向的最短距离、质点与平面/直线的最近距离；重力势能差 mg·h 中的 h 正是"沿竖直（法）方向的投影高度"。

用向量求夹角

  • 两直线夹角 θ ∈ [0°, 90°]：方向向量 v⃗₁、v⃗₂，cosθ = |v⃗₁ · v⃗₂| / (|v⃗₁| · |v⃗₂|)（取绝对值，因为线线角只取锐角或直角）。
  • 直线与平面的夹角 θ ∈ [0°, 90°]：方向向量 v⃗、法向量 n⃗，sinθ = |v⃗ · n⃗| / (|v⃗| · |n⃗|)（直线与平面夹角是"直线与它在该平面内投影"的夹角，等于方向向量与法向量夹角的余角）。
  • 二面角：两平面法向量 n⃗₁、n⃗₂ 的夹角等于二面角或其补角，cos〈n⃗₁, n⃗₂〉 = (n⃗₁ · n⃗₂) / (|n⃗₁| · |n⃗₂|)；需结合图形判断二面角是锐角还是钝角再定符号。
几何含义：夹角 = 两个"朝向箭头"之间的分离程度；数量积公式把"两条线/两个面张开多大角度"转化为两个向量的点积再反余弦。物理含义：力的方向与位移方向夹角决定功的正负（cosθ），入射光线与法线的夹角（入射角/反射角）、速度与磁场方向的夹角决定洛伦兹力大小，都是同一套"夹角—点积"语言。
拓展（向量积 / 叉积，求法向量的快办法）：对向量 a⃗、b⃗，定义 a⃗ × b⃗ 为一个新向量：其方向垂直于 a⃗、b⃗ 所在平面（右手法则），模为 |a⃗||b⃗|sin〈a⃗,b⃗〉（等于以 a⃗、b⃗ 为边的平行四边形面积）。于是两不共线向量 a⃗、b⃗ 所在平面的一个法向量可一步取为 n⃗ = a⃗ × b⃗，点面距离、异面直线距离也可写作叉积形式。这是老师常用、竞赛与大学常用的利器，选择性必修教材虽不强制，但值得掌握。

向量加法首尾相接的平移合成力的合成（平行四边形法则）、合位移、合速度
向量减法加相反向量（反向平移）相对位移、相对速度（终点减起点）
数乘沿直线的伸缩与反向（缩放倍数 + 方向开关）同向/反向按比例放大或缩小的力、速度
共线向量落在同一条直线上的箭头沿同一条作用线的量
共面向量平移到同一起点后位于同一平面同一平面内的一组力（平面汇交力系）
数量积投影相乘：一个向量在另一个方向上的投影 × 长度功 W = F⃗·s⃗；判垂直（投影为 0）
空间向量基本定理沿三个不共面方向的唯一分解（维数 = 3）力/速度沿三个独立方向分解，3 个平动自由度
坐标表示沿三个坐标轴的投影分量 (x, y, z)三维运动分解为三个独立的一维运动
方向向量 / 法向量直线/平面的"朝向箭头"运动方向、面的朝向（法线、镜面反射方向）
距离公式沿垂直方向（法向量）的投影长度最短路径、最小作用距离（如竖直投影高度 h）
夹角公式两个朝向箭头之间的分离程度力与位移夹角（功）、入射角、速度与磁场夹角

典型例题（自测）

  1. 向量表示：在平行六面体 ABCD–A₁B₁C₁D₁ 中，设 AB⃗ = a⃗、AD⃗ = b⃗、AA₁⃗ = c⃗，请用 a⃗、b⃗、c⃗ 表示 AC₁⃗、A₁C⃗、BD₁⃗。
  2. 共线共面：已知 a⃗ = (1, 2, 3)、b⃗ = (2, 4, 6)，判断 a⃗ 与 b⃗ 是否共线；再判断点 O(0,0,0)、A(1,2,3)、B(2,4,6)、C(1,1,1) 是否共面。
  3. 数量积与夹角：a⃗ = (1, 2, 3)、b⃗ = (−1, 1, 2)，求 a⃗ · b⃗、|a⃗| 及 cos〈a⃗, b⃗〉，并判断是否垂直。
  4. 法向量：求过三点 A(1,0,0)、B(0,1,0)、C(0,0,1) 的平面的一个法向量。
  5. 点到平面距离：求点 P(2, 3, 4) 到平面 x + y + z = 1 的距离。
  6. 证明位置关系：在正方体 ABCD–A₁B₁C₁D₁ 中，用向量证明 BD₁ ⊥ AC，并证明 B₁D₁ ∥ 平面 A₁BC（提示：设出坐标，写方向向量/法向量，算点积）。
  7. 夹角：在长方体 ABCD–A₁B₁C₁D₁ 中，AB = 2，AD = 1，AA₁ = 3，求异面直线 AB₁ 与 BC 所成角、直线 AC₁ 与平面 ABCD 所成角的正弦值。

参考答案（部分）：① AC₁⃗ = a⃗ + b⃗ + c⃗，A₁C⃗ = a⃗ + b⃗ − c⃗，BD₁⃗ = −a⃗ + b⃗ + c⃗；② 共线（b⃗ = 2a⃗）；O、A、B、C 共面；③ a⃗ · b⃗ = 7，|a⃗| = √14，不垂直；④ 可取 n⃗ = (1, 1, 1)；⑤ d = |2+3+4−1|/√3 = 8√3/3；⑥ BD₁ · AC = 0 故垂直，B₁D₁ 的方向向量与平面 A₁BC 的法向量点积为 0 故平行；⑦ 异面直线 AB₁ 与 BC 成 90°（AB₁ ⊥ BC），sinθ = 3/√14。

常见误区

  • ❌ "数量积满足结合律，a⃗ · b⃗ · c⃗ 有意义" → ❌ a⃗ · b⃗ 是数，不能再与向量 c⃗ 做点积；点积只满足交换律和分配律。
  • ❌ "两向量夹角就是两条直线夹角" → ❌ 线线角只取 [0°, 90°]，要加绝对值 cosθ = |v⃗₁·v⃗₂|/(|v⃗₁||v⃗₂|)；向量夹角本身是 [0°, 180°]。
  • ❌ "平面的法向量是唯一的" → ❌ 法向量有无穷多个（彼此共线），常取单位法向量或最简整数解。
  • ❌ "基底必须两两垂直、长度为 1" → ❌ 基底只需三个不共面的向量；单位正交基底只是最方便的特殊基底。
  • ❌ "共线向量一定同向" → ❌ 共线（平行）含同向与反向两种情况，且零向量与任意向量共线。
  • ❌ "点到平面距离公式分子不带绝对值" → ❌ 投影可能为负，距离必须取 |AP⃗ · n⃗| / |n⃗| 的绝对值。
  • ❌ "二面角大小 = 两法向量夹角" → ❌ 法向量夹角可能与二面角互补，须结合图形判断钝锐角后确定符号。
  • ❌ "线面平行只需方向向量与法向量垂直" → ❌ 还须保证直线不在平面内，否则可能线在面内。
  • ❌ "坐标成比例即可判平行，忽略了 0 的分量" → ❌ 判断 a⃗ ∥ b⃗ 应理解为"存在 λ 使 a⃗ = λb⃗"；坐标为 0 时不能直接写比例式，要逐分量处理。

二、参考答案（点击展开）

查看第1题答案

选 B。③ 错：向量相等必须"大小相等且方向相同"（平移后可重合），只比大小不够；①②④ 正确。要点：自由向量是向量法可以平移分解的根本前提；力、速度、位移、电场强度等都是"既有大小又有方向"的典型向量。

查看第2题答案

AC₁⃗ = AB⃗ + BC⃗ + CC₁⃗ = a⃗ + b⃗ + c⃗；BD₁⃗ = BA⃗ + AA₁⃗ + A₁D₁⃗ = −a⃗ + c⃗ + b⃗ = −a⃗ + b⃗ + c⃗。几何含义：从 A 出发先后沿 a⃗、b⃗、c⃗ 三次平移，总效果等于直接沿和向量 AC₁⃗ 平移——"首尾相接，总位移为和"。

查看第3题答案

(1) 共线：b⃗ = 2a⃗（对应坐标成比例 2/1 = 4/2 = 6/3），存在 λ = 2 使 b⃗ = λa⃗。(2) 共面：OA⃗ = (1,2,3)、OC⃗ = (1,1,1) 不共线，而 OB⃗ = (2,4,6) = 2·OA⃗ + 0·OC⃗，即 OB⃗ 可由 OA⃗、OC⃗ 线性表示，故四点共面（实际 O、A、B 三点共线）。

查看第4题答案

(1) a⃗ · b⃗ = 1×(−1) + 2×1 + 3×2 = −1 + 2 + 6 = 7。(2) |a⃗| = √(1² + 2² + 3²) = √14。(3) cos〈a⃗, b⃗〉 = 7 / (√14 × √6) = 7 / (2√21)；因 a⃗ · b⃗ = 7 ≠ 0，故不垂直。(4) 当力与位移垂直（θ = 90°，cosθ = 0）时 W = 0，例如手提重物沿水平方向匀速移动时，重力与位移垂直，重力不做功。

查看第5题答案

平面内取 AB⃗ = B − A = (−1, 1, 0)、AC⃗ = C − A = (−1, 0, 1)。设法向量 n⃗ = (x, y, z)，由 n⃗ · AB⃗ = 0 得 −x + y = 0 → y = x；由 n⃗ · AC⃗ = 0 得 −x + z = 0 → z = x。取 x = 1，得 n⃗ = (1, 1, 1)（法向量不唯一，任取一组非零解即可）。

查看第6题答案

(1) 建系得 B(1,1,0)、D₁(0,0,1)、A(1,0,0)、C(0,1,0)，BD₁⃗ = (−1, −1, 1)、AC⃗ = (−1, 1, 0)，BD₁⃗ · AC⃗ = 1 − 1 + 0 = 0，故 BD₁ ⊥ AC。(2) 建系：D(0,0,0)、A(2,0,0)、B(2,1,0)、C(0,1,0)、B₁(2,1,3)、C₁(0,1,3)。AB₁⃗ = (0,1,3)、BC⃗ = (−2,0,0)，cosθ = |AB₁⃗ · BC⃗| / (|AB₁⃗|·|BC⃗|) = 0 / (√10 × 2) = 0，故异面直线所成角为 90°；平面 ABCD 的法向量取 n⃗ = (0,0,1)，AC₁⃗ = (−2,1,3)，|AC₁⃗| = √14，sinθ = |AC₁⃗ · n⃗| / (|AC₁⃗|·|n⃗|) = 3 / √14。
