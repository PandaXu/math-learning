第2章 直线和圆的方程

高中 / 选择性必修第一册

一句话总纲：在平面直角坐标系里，"点"用坐标 (x, y) 表示，那么"直线"与"圆"这些几何图形就都能被方程精确描述——直线是一次方程，圆是二次方程。于是几何问题（相交、相切、距离、角度）全部翻译成了代数问题，斜率就是"变化率"、距离就是"路程"、相切就是"恰好一个交点"。本章的本质是：用代数这把尺子去量几何这条线。

2.1 直线的倾斜角与斜率

倾斜角：直线"朝哪边倾斜"（几何含义）

一条直线和 x 轴相交时，我们关心它到底"斜不斜、斜多少"。为此规定：

  • 倾斜角 α：直线向上的方向与 x 轴正方向所成的角。当直线与 x 轴平行或重合时，规定 α = 0°。
  • 范围：0° ≤ α < 180°。直线与 x 轴垂直时，α = 90°。

α 刻画的是方向：α = 0° 是"水平向右"，α 越接近 90° 直线越"陡"，α = 90° 是"竖直"，α 在 90° 到 180° 之间则是"向左上方倾斜"。

斜率 k：倾斜程度的"数值化"

倾斜角虽然直观，但用角度算起来不方便，于是引入斜率：

k = tan α   （α ≠ 90°）
  • α = 0° 时，k = 0（水平线）；
  • 0° < α < 90° 时，k > 0（直线"向右上"爬升）；
  • 90° < α < 180° 时，k < 0（直线"向右下"下降）；
  • α = 90° 时，tan α 不存在，斜率不存在（竖直线没有斜率）。

用两点算斜率

过两点 P₁(x₁, y₁)、P₂(x₂, y₂)（x₁ ≠ x₂）的直线斜率为：

k = (y₂ − y₁) / (x₂ − x₁) = Δy / Δx

它表示：x 每增加 1，y 变化 k。这是本章最重要的一个"物理直觉"。

物理含义：斜率 = 变化率。位移—时间图 (s–t 图) 上，直线的斜率就是速度；速度—时间图 (v–t 图) 上，直线的斜率就是加速度；山坡、楼梯、斜坡的"坡度"（铅直高度 ÷ 水平距离）本质上就是斜率。k 大 = 陡 = 变化快；k = 0 = 平 = 不变化；k 为负 = 下降 = 反方向变化。
几何含义：斜率只由"方向"决定，与直线在平面中的位置无关。不管直线画在高处还是低处，只要倾斜角相同，斜率就相同；平移一条直线，斜率不变。

2.2 直线的方程

直线的所有形式方程，本质都只含 x、y 的一次式，所以直线又被称为"一次曲线"。下面五种形式可互相转化。

① 点斜式（给定一点 + 斜率）

y − y₀ = k (x − x₀)

过点 (x₀, y₀)、斜率为 k。不适用于斜率不存在的竖直线（竖直线写作 x = x₀）。

② 斜截式（给定斜率 + y 轴截距）

y = kx + b

k 是斜率，b 是直线与 y 轴交点的纵坐标（叫纵截距）。

物理含义：这就是"匀速直线运动"的图像方程。把 s = vt + s₀ 与 y = kx + b 对照：斜率 k 对应速度 v（变化率），截距 b 对应初位移 s₀（起点），自变量 x 对应时间 t。一条直线 = 一个"变化率恒定"的过程。

③ 两点式（给定两点）

(y − y₁) / (y₂ − y₁) = (x − x₁) / (x₂ − x₁)    (x₁ ≠ x₂, y₁ ≠ y₂)

它是"斜率处处相等"的直接体现：直线上任意一点与 P₁ 连线的斜率，都等于 P₁P₂ 的斜率。

④ 截距式（给定两轴上的截距）

x / a + y / b = 1    (a ≠ 0, b ≠ 0)

直线在 x 轴上的截距为 a、在 y 轴上的截距为 b。a、b 是带符号的数，不是长度。

⑤ 一般式（万能形式）

Ax + By + C = 0    （A、B 不同时为 0）
  • 当 B ≠ 0 时，可化成斜截式：y = −(A/B)x − (C/B)，斜率 k = −A/B，纵截距 = −C/B。
  • 当 B = 0 时，方程变为 Ax + C = 0，即 x = −C/A，表示竖直线。
一般式是"最诚实"的形式：它能表示所有直线（包括竖直线），而点斜式、斜截式、两点式、截距式都有各自的"死角"。判定直线时优先用一般式。

2.3 两条直线的位置关系

设 l₁：A₁x + B₁y + C₁ = 0（斜率 k₁，纵截距 b₁），l₂：A₂x + B₂y + C₂ = 0（斜率 k₂，纵截距 b₂）。

平行

  • 斜率形式：k₁ = k₂ 且 b₁ ≠ b₂（斜率相同、截距不同，即"方向相同、位置不同"）。
  • 一般式判定：A₁B₂ − A₂B₁ = 0 且 A₁C₂ − A₂C₁ ≠ 0。
几何含义：平行 = 倾斜角相同 = 斜率相等。物理含义：两条平行线 = 两个"变化率相同"的过程（例如两车同速行驶，速度—时间图就是两条平行线）。

垂直

  • 斜率形式：k₁ · k₂ = −1（其中一条斜率不存在时，另一条斜率为 0）。
  • 一般式判定：A₁A₂ + B₁B₂ = 0。
为什么 k₁k₂ = −1？若 l₁ 的倾斜角为 α₁、l₂ 的为 α₂，且 l₁ ⊥ l₂，则 |α₁ − α₂| = 90°。由三角恒等式 tan(α ± 90°) = −1/tan α 可得 k₁k₂ = −1。几何直觉：把一条线"转正 90°"，它的斜率变成"负的倒数"——原来很陡的变很缓、原来向上爬的变向下滑。

相交与重合

  • 相交：A₁B₂ − A₂B₁ ≠ 0，即斜率不相等。交点坐标由两个方程联立解出。
  • 重合：A₁B₂ − A₂B₁ = 0 且 A₁C₂ − A₂C₁ = 0（两方程成比例，表示同一条直线）。

两条直线夹角的思路：一般用斜率 k₁、k₂ 代入 tan θ = |(k₂ − k₁) / (1 + k₁k₂)| 求夹角（k₁k₂ = −1 时分母为 0，此时夹角为 90°）。

物理含义：两直线相交的"交点" = 两个过程"相遇"的时刻与位置（例如两车相遇问题：两条 s–t 线的交点就是相遇点）。

2.4 距离公式

① 两点间距离

|P₁P₂| = √( (x₂ − x₁)² + (y₂ − y₁)² )

这是勾股定理的坐标版：两点在 x 方向的差 Δx 与 y 方向的差 Δy 是一对直角边，距离就是斜边。

物理含义：这就是"位移的大小"（路程的直线版）。物体从 (x₁, y₁) 移动到 (x₂, y₂)，位移的模长就是两点间距离。

② 点到直线的距离

d = |Ax₀ + By₀ + C| / √(A² + B²)

点 P(x₀, y₀) 到直线 l：Ax + By + C = 0 的距离。分子是把点坐标代入直线方程后取绝对值，分母是系数向量 (A, B) 的长度。

几何含义：点到直线的距离 = 该点到直线上最近一点的距离，垂线段最短。物理含义：物体到一条"约束轨道"（直线）的最近距离；分子 |Ax₀+By₀+C| 正比于"偏离轨道多少"，当点在直线上时分子为 0、距离为 0。

③ 两条平行线间的距离

两条平行直线 Ax + By + C₁ = 0 与 Ax + By + C₂ = 0（A、B 相同）之间的距离：

d = |C₁ − C₂| / √(A² + B²)
本质：两平行线间处处等距，任取一条线上的点算它到另一条线的距离即可。分母相同，只剩分子 |C₁ − C₂| 决定远近——常数项 C 控制着直线的"位置"。

2.5 圆的方程

圆的定义（几何含义）

圆 = 平面内到定点（圆心）距离等于定长（半径）的点的集合。这个定义本身就是"距离公式"的直接来源。

标准方程

(x − a)² + (y − b)² = r²
  • 圆心 C(a, b)，半径 r（r > 0）。
  • 它逐字翻译了定义："到圆心 (a, b) 的距离平方 = r²"。
  • 圆心在原点时简化为 x² + y² = r²。

一般方程

x² + y² + Dx + Ey + F = 0

配方可得：(x + D/2)² + (y + E/2)² = (D² + E² − 4F) / 4。

  • 圆心：(−D/2, −E/2)；半径 r = (1/2)√(D² + E² − 4F)。
  • 当 D² + E² − 4F > 0：表示圆；
  • 当 D² + E² − 4F = 0：表示一个点（退化圆）；
  • 当 D² + E² − 4F < 0：无轨迹（方程无实数解）。
识别要点：一般式要是圆的方程，必须同时满足：① x² 与 y² 的系数相等且不为 0；② 没有 xy 交叉项；③ 半径公式中的判别式 > 0。
物理含义：圆 = "到中心距离恒定"的轨道。钟表指针针尖的轨迹、匀速圆周运动的轨迹都是圆；半径 r 不变，意味着"与圆心的距离被守恒地锁定"。

2.6 直线与圆、圆与圆的位置关系

直线与圆：看"圆心到直线的距离 d"与半径 r 的大小

位置关系几何特征代数判定（联立方程）距离判定
相交直线穿过圆，有 2 个公共点Δ > 0d < r
相切直线与圆恰好 1 个公共点Δ = 0d = r
相离直线与圆无公共点Δ < 0d > r

其中 d = 圆心到直线的距离（用 2.4 的公式），Δ 是把直线方程代入圆方程后所得一元二次方程的判别式。两种方法殊途同归，距离法通常更快。

相切的物理/几何意义：相切是"恰好一个交点"的临界状态——直线是圆的切线，切点处的半径与切线垂直。这是"临界"概念的典范：d 从小于 r 变到大于 r 的过程中，必经过 d = r 这一瞬间。

圆与圆：看"圆心距 d"与两半径 r₁、r₂ 的关系

圆心距 d = √( (a₁ − a₂)² + (b₁ − b₂)² )
位置关系几何特征距离判定
外离两圆无公共点，且一圆在另一圆外d > r₁ + r₂
外切恰好 1 个公共点，圆心在公共点两侧d = r₁ + r₂
相交有 2 个公共点|r₁ − r₂| < d < r₁ + r₂
内切恰好 1 个公共点，一圆在另一圆内d = |r₁ − r₂|
内含无公共点，一圆在另一圆内0 ≤ d < |r₁ − r₂|
记忆口诀：外切相加、内切相减、相交夹在中间、外离更大、内含更小。几何含义：把"两圆半径之和/差"当作两道门槛，圆心距 d 跨过哪道门槛，位置关系就变到哪一档。
物理含义：两圆位置关系 = 两个"圆形作用范围"的空间关系。如两颗卫星的覆盖圈、两个圆的信号覆盖区域——外离互不覆盖、相交部分重叠、内含完全包含。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
倾斜角 α直线相对 x 轴正方向的"方向角"方向的标定（0°=水平，90°=竖直）
斜率 k直线的"陡峭程度" = Δy/Δx变化率：速度、加速度、坡度
直线方程平面内满足一次等式的点的集合匀速过程：s = vt + s₀、恒定的变化率
两直线平行方向相同、位置不同（斜率相等）两个变化率相同的过程
两直线垂直方向相差 90°（斜率乘积 = −1）方向正交（如东西与南北方向）
两直线交点两图形的公共点两个过程"相遇"的时刻与位置
两点间距离勾股定理的坐标版位移的大小（直线路程）
点到直线距离垂线段（最短距离）到"约束轨道"的最近距离
平行线间距离处处相等的带宽等宽轨道、走廊宽度
圆的方程到定点距离为定值的点集等距轨道（圆周运动、钟表指针）
直线与圆相切恰好一个交点，切线⊥半径临界状态（接触的瞬间）
圆与圆位置关系两圆心距与半径和/差比较两个覆盖圈的空间关系

典型例题（自测）

  1. 求过点 A(2, −1)、B(−1, 3) 的直线的倾斜角与斜率，并写出该直线的斜截式方程。
  2. 直线 l 的方程为 3x − 4y + 5 = 0，求：它的斜率、x 轴与 y 轴上的截距，以及点 P(1, 2) 到 l 的距离。
  3. 判断直线 l₁：2x + 3y − 1 = 0 与 l₂：4x + 6y + 5 = 0 的位置关系；若平行，求两线间的距离。
  4. 求圆心在 C(3, −2)、半径为 5 的圆的标准方程；再判断直线 3x − 4y − 9 = 0 与该圆的位置关系。
  5. 已知两圆 (x − 1)² + (y + 2)² = 9 与 (x + 3)² + (y − 1)² = 4，求圆心距并判断它们的位置关系。
  6. 把方程 x² + y² − 4x + 6y − 12 = 0 化为标准方程，写出圆心与半径，并说明它表示什么图形。

常见误区

  • ❌ "任何直线都有斜率" → ❌ 竖直直线（α = 90°）斜率不存在，它的方程只能写成 x = x₀。
  • ❌ "倾斜角越大直线越陡" → ❌ 倾斜角超过 90° 后直线开始"向左上"倾斜；应在各象限内比较，且 α ∈ [0°, 180°) 时 tan α 不单调。
  • ❌ "两直线平行就是斜率相等" → ❌ 还要排除重合：斜率相等且截距也相等时两直线重合，不是平行。
  • ❌ "两直线垂直就是斜率互为相反数" → ❌ 是互为负倒数（k₁k₂ = −1），不是相反数。
  • ❌ "点到直线距离公式分子不用加绝对值" → ❌ 距离必须非负，分子必须取 |Ax₀ + By₀ + C|。
  • ❌ "x² + y² + Dx + Ey + F = 0 一定是圆" → ❌ 需满足 D² + E² − 4F > 0；等于 0 是点，小于 0 无轨迹。
  • ❌ "截距是长度" → ❌ 截距是带符号的坐标，可为负，截距式 x/a + y/b = 1 中 a、b 都不能为 0。
  • ❌ "直线与圆相切就是没有交点" → ❌ 相切是恰好一个交点；没有交点是相离。

本章练习卷（含答案）

一、练习题

  1. 求过点 P(1, 2)、Q(3, 8) 的直线的斜率，并说明：这条直线上 x 每增加 1，y 变化多少？
  2. 已知一条直线的斜率为 −2，且经过点 (0, 4)。写出它的斜截式方程，并求它与 x 轴、y 轴的交点（即两轴上的截距）。
  3. 判断直线 l₁：y = 2x + 1 与 l₂：y = 2x − 3 的位置关系；若平行，求它们之间的距离（提示：化为一般式 2x − y + 1 = 0 与 2x − y − 3 = 0）。
  4. 求过点 P(2, 3) 且与直线 y = (1/2)x − 1 垂直的直线方程。
  5. 求圆心在 C(2, −1)、半径为 4 的圆的标准方程，并判断直线 3x + 4y − 12 = 0 与该圆的位置关系（求圆心到直线的距离与半径比较）。
  6. 已知圆 (x − 1)² + (y − 2)² = 9 与直线 x + y − 1 = 0 相交，求弦长（提示：先求圆心到直线的距离 d，再用 弦长 = 2√(r² − d²)）。

二、参考答案（点击展开）

查看第1题答案

斜率 k = (8 − 2) / (3 − 1) = 6 / 2 = 3。它表示 x 每增加 1，y 就增加 3——斜率就是这条直线的"变化率"。

查看第2题答案

斜截式：y = −2x + 4。与 y 轴交点令 x = 0，得 y = 4，即纵截距为 4；与 x 轴交点令 y = 0，得 x = 2，即横截距为 2。故交点为 (0, 4) 与 (2, 0)。

查看第3题答案

两直线斜率都为 2（方向相同），但纵截距分别为 1 与 −3（位置不同），故平行。距离 d = |1 − (−3)| / √(2² + (−1)²) = 4 / √5 = 4√5 / 5。

查看第4题答案

原直线斜率为 1/2，与其垂直的直线斜率 k = −1 / (1/2) = −2。由点斜式：y − 3 = −2(x − 2)，整理得 y = −2x + 7（一般式 2x + y − 7 = 0）。

查看第5题答案

标准方程：(x − 2)² + (y + 1)² = 16。圆心到直线距离 d = |3·2 + 4·(−1) − 12| / √(3² + 4²) = |6 − 4 − 12| / 5 = 10 / 5 = 2。因为 2 < 4（即 d < r），所以直线与圆相交。

查看第6题答案

圆心 (1, 2) 到直线 x + y − 1 = 0 的距离 d = |1 + 2 − 1| / √(1² + 1²) = 2 / √2 = √2。弦长 = 2√(r² − d²) = 2√(9 − 2) = 2√7。
