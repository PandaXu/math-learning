第13章 轴对称

初中 / 初二 / 八年级上册

一句话总纲：轴对称 = 「沿一条直线折叠后，图形左右完全重合」。折叠轴就是对称轴，折叠重合的点互称对称点；本章要你熟练掌握三种"折叠工具"——线段的垂直平分线、等腰三角形的三线合一、以及用"翻折把折线拉直"来解决最短路径问题。

13.1 轴对称与轴对称图形

核心概念：一个"折叠重合"的动作

把一个图形沿着某一条直线折叠，如果它能与另一个图形完全重合，那么就说这两个图形关于这条直线（成轴）对称，这条直线叫做对称轴，折叠后重合的点叫做对称点。

  • 对称轴：一条直线（不是线段，也不是射线），是折叠的"折痕"所在直线。
  • 对称点：折叠后互相重合的一对点，例如点 A 与点 A′（A 撇）关于直线 l 对称。
  • 轴对称图形：如果一个图形沿某条直线折叠后，直线两旁的部分能够互相重合，那么这个图形就叫做轴对称图形。
几何含义：轴对称的本质是关于一条直线的反射（镜像）——把直线当作"镜子"，图形在镜子里的像与它本身沿镜面折叠后完全重合。对称轴就是"镜子所在直线"，对称点就是"物体点与它的像点"。
物理含义：现实中的平面镜成像就是轴对称的活例子：你站在镜前，镜中的像与你关于镜面成轴对称，像与你的距离、大小都相等，只是左右颠倒。自然界里蝴蝶的翅膀、人的脸、雪花晶体、桥梁和建筑，大多设计成轴对称，因为它左右受力均衡、结构稳定、视觉对称美观。

轴对称与轴对称图形的区别与联系

比较轴对称（两个图形）轴对称图形（一个图形）
对象两个图形之间的位置关系一个图形自身的形状特征
对称轴只有 1 条（两个图形只有这一条折叠线）可以有 1 条，也可以有多条
举例两个三角形关于直线 l 对称等腰三角形、圆、正方形、正五角星
联系：把成轴对称的两个图形看成一个整体，它就是一个轴对称图形；把一个轴对称图形沿对称轴分成两部分，这两部分关于这条直线成轴对称。

轴对称的性质（折叠带来的"不变"与"相等"）

  1. 全等：关于某直线对称的两个图形全等（形状、大小完全相同，只是位置翻转）。
  2. 对称轴是垂直平分线：对称轴是任何一对对称点所连线段的垂直平分线。也就是说，连接对称点 A 与 A′ 的线段 AA′ 被对称轴垂直平分。
  3. 对应线段、对应角相等：两个图形中的对应线段（如对应边）相等，对应角相等。
  4. 交点落在对称轴上：如果两个图形关于某直线对称，且它们的某组对应线段（或延长线）相交，那么交点一定在对称轴上。
几何含义：性质 2 是本章的"总钥匙"——对称轴等价于"对称点连线的垂直平分线"。由此可以把"关于直线对称"翻译成"任意两对称点连成的线段都被这条直线垂直平分"，从而引出下一节的垂直平分线定理。

常见图形的对称轴条数

图形对称轴条数对称轴位置
线段2 条本身所在直线 + 它的垂直平分线
角1 条角平分线所在直线
等腰三角形1 条底边上的高（三线合一）所在直线
等边三角形3 条三条高（也是中线、角平分线）所在直线
矩形2 条两组对边中点的连线所在直线
正方形4 条2 条对角线 + 2 组对边中点连线
圆无数条任何一条直径所在直线
物理含义：对称轴越多，图形越"均衡"。圆有无数条对称轴，所以车轮、齿轮、转盘做成圆形——绕中心任意旋转都保持形状不变，转动最平稳；等腰梯形、风筝做成轴对称，是为了左右受力对称、飞行稳定。

13.2 线段的垂直平分线

定义

经过线段中点并且垂直于这条线段的直线，叫做这条线段的垂直平分线（也叫中垂线）。它同时满足两个条件：

直线 l 是线段 AB 的垂直平分线  ⟺  l ⊥ AB 且 l 过 AB 的中点

性质定理（从"线上"推出"距离相等"）

定理：线段垂直平分线上的点，到这条线段两个端点的距离相等。

若点 P 在 AB 的垂直平分线上，则 PA = PB
几何含义：垂直平分线可以看作"到线段两端距离相等的点组成的轨迹（集合）"。线上每一个点到 A、B 的距离都一样远——就像站在线段正中央的"公平位置"。
物理含义：PA = PB 说明点 P 到两个端点是"等距"的。在工程上，把货物吊点选在横梁的垂直平分线上，两端受力相等、最平稳；声音或信号从 P 发出，到 A、B 两处的时间相同（速度相同时"等距 ⇒ 同时到达"）。

判定定理（从"距离相等"推回"在线上"）

定理：到一条线段两个端点距离相等的点，在这条线段的垂直平分线上。

若 PA = PB，则点 P 在 AB 的垂直平分线上

性质定理与判定定理互为逆定理，合起来就是一句等价命题：

点 P 在 AB 的垂直平分线上  ⟺  PA = PB
几何含义：这条等价关系是"位置"与"距离"的互相翻译：想要证明某点在垂直平分线上，只需证明它到两端点距离相等；反之，点在线上就能直接得出两条线段相等。它是证明线段相等的利器。

尺规作图：作线段的垂直平分线

分别以 A、B 为圆心，以大于 AB 一半的同一长度为半径画弧，两弧交于两点，过这两个交点作直线，即为 AB 的垂直平分线。

为什么"大于 AB 一半"？半径太小时两弧不相交（交点不存在）；只有半径 > AB/2 时两弧才在两侧各交于一点。两个交点到 A、B 距离分别相等，故都在这条垂直平分线上，两点确定一条直线。

拓展：三角形三条边的垂直平分线交于一点，这一点到三个顶点的距离相等——它是三角形外接圆的圆心（外心）。

13.3 等腰三角形（三线合一）

定义与基本元素

有两条边相等的三角形叫做等腰三角形。相等的两条边叫腰，第三条边叫底边，两腰的夹角叫顶角，腰与底边的夹角叫底角。

几何含义：等腰三角形是轴对称图形，它有且只有 1 条对称轴——就是顶角的平分线（同时也是底边上的中线和高）所在直线。沿这条轴折叠，左右两个"半三角形"完全重合。

性质 1：等边对等角

定理：等腰三角形的两个底角相等（简写成"等边对等角"）。

在 △ABC 中，若 AB = AC，则 ∠B = ∠C

性质 2：三线合一（等腰三角形的核心！）

定理：等腰三角形的顶角平分线、底边上的中线、底边上的高，这三条线互相重合（简称为"三线合一"）。

AB = AC 时，顶角平分线 = 底边中线 = 底边上的高（同一条线段）
几何含义：这三条线重合的那条线段，正是等腰三角形的对称轴。它既是"把顶角平分"的角平分线，又是"把底边平分"的中线，还是"垂直底边"的高——一条线同时扮演三个角色，全因左右两半关于它对称。
物理含义：三线合一意味着这条线是三角形左右质量的对称轴，重心落在这条中线上，所以等腰三角形物体沿中线支撑最稳定；屋脊、桥拱、衣架、塔吊的三角支撑都做成等腰三角形，让受力沿中线均匀传递，不歪斜。

"三线合一"的灵活使用（知道其一，就能推出另外两个）：在等腰三角形中，只要知道顶角平分线 / 底边中线 / 底边高中的任意一条，它同时就是另外两条，并且垂直平分底边。这是证明线段相等、角相等、垂直关系的高频工具。

判定：等角对等边

定理：如果一个三角形有两个角相等，那么这两个角所对的边也相等（简写成"等角对等边"），即这个三角形是等腰三角形。

在 △ABC 中，若 ∠B = ∠C，则 AB = AC

等边三角形（特殊的等腰三角形）

  • 定义：三条边都相等的三角形。
  • 性质：三个内角都相等，且每个角都等于 60°；它有三条对称轴（三条高/中线/角平分线所在直线）；每条边上的"三线"都合一。
  • 判定：① 三边相等；② 三个角相等；③ 有一个角是 60° 的等腰三角形。
几何含义：等边三角形把"对称"发挥到极致——绕中心旋转 120° 图形不变（旋转对称），同时还有 3 条对称轴，是"正多边形"里最简单的成员，处处均匀。
物理含义：三边等长 ⇒ 三条中线都重合于重心且互相平分，受力最均匀，因此三角支架、桥梁桁架常用等边三角形单元，把外力平均分解到三边，结构最稳固。

13.4 最短路径问题（轴对称的实战应用）

核心思想：把"折线"通过翻折"拉直"

最短路径问题的通用思路是：当要求的路径是"折线"时，利用轴对称把其中一段翻折到另一侧，使折线变成一条直线段——因为两点之间线段最短，所以这条直线段就是最短路径。

几何含义：翻折不改变长度（轴对称是"刚体运动"，保距）。把一条边关于直线反射后，两条"折线路径"的总长等于一条直线段的长度，于是"最短的折线"问题就变成"最短的直线段"问题。
物理含义：这正是光的反射定律：光从一点经平面镜反射到另一点，走的是最短路径（费马原理），入射角等于反射角。把"人—河边—营地"的最短路线画出来，恰好就是一条满足"入射角 = 反射角"的光线路径。

经典模型一：将军饮马（两点在直线同侧）

问题：如图，点 A、B 在直线 l 的同侧，要在 l 上找一点 P，使 PA + PB 最小。

作法：

  1. 作点 A（或 B）关于直线 l 的对称点 A′；
  2. 连接 A′B，交直线 l 于点 P；
  3. 点 P 即为所求，最短距离 = A′B 的长度。
对称 → 连接 → 找交点：P = A′B ∩ l，且 PA + PB = A′B 最小
为什么最短？因为 A 与 A′ 关于 l 对称，所以 l 上任意一点到 A、A′ 距离相等（l 是 AA′ 的垂直平分线），即 PA = PA′。于是 PA + PB = PA′ + PB。要使 PA′ + PB 最小，就是要在 l 上找一点，使 "A′ 到该点再回到 B" 最短——显然当 A′、P、B 三点共线时最短，即 P 取 A′B 与 l 的交点。

经典模型二：造桥选址（平移 + 最短）

问题：河的两岸平行，A、B 在河两岸，要在河上垂直河岸架一座桥 MN（M 在上岸、N 在下岸），使 AM + MN + BN 最小。

思路：桥长 MN 固定，先把 A 沿垂直河岸方向平移桥长到 A′，问题转化为"在河岸上找点 N 使 A′N + NB 最小"——连接 A′B 与下岸交于 N，再过 N 作垂线交上岸于 M。

本质：当两定点在河两侧时，直接用"两点之间线段最短"连线即可；当在同侧时，用轴对称（或平移）把一侧"搬"到另一侧，把折线拉直。两种模型的统一心法是：对称（或平移）把问题化到"异侧"→ 直线段最短。

典型例题（自测）

例题 1：轴对称性质

如图，△ABC 与 △A′B′C′ 关于直线 l 对称，已知 AB = 5，∠C = 40°。求 A′B′ 的长和 ∠C′ 的度数。

解：成轴对称的两个图形全等 ⇒ 对应边、对应角相等。所以 A′B′ = AB = 5，∠C′ = ∠C = 40°。

例题 2：垂直平分线性质

已知 DE 是 △ABC 中 BC 边的垂直平分线，交 BC 于 D，交 AC 于 E，AB = 3，AC = 7。求 △ABE 的周长。

解：因为 E 在 BC 的垂直平分线上，所以 BE = CE。于是 △ABE 的周长 = AB + AE + BE = AB + AE + CE = AB + AC = 3 + 7 = 10。这里把 BE "搬到" CE，恰好凑成整条 AC。

例题 3：三线合一

在等腰 △ABC 中，AB = AC，顶角 ∠A = 100°，AD 是底边 BC 上的高。求 ∠BAD 与 ∠B 的度数。

解：由三线合一，AD 同时是顶角平分线 ⇒ ∠BAD = ∠A / 2 = 50°；又 ∠B + ∠C = 180° − 100° = 80°，且等边对等角 ⇒ ∠B = ∠C = 40°。

例题 4：最短路径（将军饮马）

A、B 两点在直线 l 同侧，A 到 l 的距离为 3，B 到 l 的距离为 5，A、B 沿 l 方向的距离为 6。求 PA + PB 的最小值（P 在 l 上）。

解：作 A 关于 l 的对称点 A′，则 A′ 到 l 的距离也是 3（在另一侧）。连接 A′B 交 l 于 P。以 l 为基准，A′ 与 B 到 l 的距离之和为 3 + 5 = 8，沿 l 方向仍相距 6。由勾股定理：PA + PB = A′B = √(8² + 6²) = √100 = 10。

例题 5：等边三角形判定

在 △ABC 中，AB = AC，且 ∠B = 60°。判断 △ABC 的形状。

解：AB = AC ⇒ 等腰三角形 ⇒ ∠C = ∠B = 60° ⇒ ∠A = 180° − 60° − 60° = 60° ⇒ 三个角都相等 ⇒ △ABC 是等边三角形（"有一个角是 60° 的等腰三角形是等边三角形"）。

常见误区

  • ❌ "对称轴是一条线段" → ❌ 对称轴是一条直线，不是线段或射线（例如线段的对称轴是"本身所在直线 + 垂直平分线所在直线"两条直线）。
  • ❌ "轴对称图形就是关于某直线对称的两个图形" → ❌ 轴对称图形指一个图形自身的特征；"成轴对称"指两个图形的位置关系，两者对象不同（但有联系）。
  • ❌ "等腰三角形有三条对称轴" → ❌ 一般等腰三角形只有 1 条对称轴；等边三角形才有 3 条。
  • ❌ "三线合一是三条不同的线" → ❌ 三线合一是"顶角平分线、底边中线、底边高"互相重合成同一条线段，不是三条并列的线。
  • ❌ "垂直平分线上任意点到线段两端点距离相等，反过来也成立，所以两句话等价" 用得对不对都行 → ❌ 性质与判定要分清方向：性质是"在线上 ⇒ 距离相等"，判定是"距离相等 ⇒ 在线上"，证明时别把因果写反。
  • ❌ "作垂直平分线时半径取任意长都行" → ❌ 半径必须大于 AB 的一半，否则两弧不相交，作不出交点。
  • ❌ "最短路径只要随便取 P 使 PA = PB 就行" → ❌ 将军饮马中 P 是 A′B 与 l 的交点（三点共线），不是 l 上任意点；对称点找错边（没翻到异侧）会得到错误答案。

课本外 · 典故与思考

典「对称」这个词，原本的意思是什么？——一段两千五百年前的审美（点击展开）

「对称」的英文是 symmetry，它来自古希腊语 symmetria：syn（共同）+ metron（度量、尺度）。连起来的意思是「按同一把尺子度量」——两边量出来一样长、一样大，就叫"相称"。

把"对称"捧上神坛的，是古希腊的毕达哥拉斯学派（公元前 6 世纪前后）。这群人坚信"万物皆数"，认为世界上最美的东西都藏着整数比例和对称结构：琴弦长度按 1:2、2:3 的比例排列，弹出的音才是和谐的和声；正多面体只有五种，它们是"宇宙的骨架"。对他们来说，对称 = 和谐 = 美，甚至把球形、完美对称当作宇宙天体的"出厂标准"。

这套审美影响深远：两千多年后的今天，我们夸一座建筑、一枚印章、一个汉字好看时，潜意识里说的还是同一个标准——左右两边"按同一把尺子量出来"一样。你本章学的对称轴、对称点，其实就是把古希腊那个抽象的"相称"，翻译成了可以精确画出来的几何语言。

一句话总结：「对称」在希腊语里是"按同一尺度度量"的意思，毕达哥拉斯学派把它当作美与和谐的标准——你现在画的对称轴，就是在把两千年前的审美变成数学。
趣雪花为什么都是六角形？——开普勒的一本新年小册子（点击展开）

下雪的时候你仔细观察：几乎每片雪花的晶体都是正六边形的骨架（有六条对称轴）。自然界为什么这么"偏爱"六？

1611 年元旦，大天文学家开普勒（就是发现行星运动三大定律的那位）给朋友写了一本薄薄的小册子，叫《论六角雪花》。他在里面认真地问：雪花为什么是六角的，而不是五角、七角？他想不出完整答案，但猜这跟"六是圆最自然的堆积方式"有关。

开普勒的问题直到三个多世纪后才被彻底说清：冰晶内部的水分子，在结冰时会按一种叫「六方晶系」的规则一层层排好——六个水分子围成一圈，圈圈相接就长出了六角形的骨架。雪花外形的六重对称，其实是内部分子排列规律的外在投影。

这背后是一条重要的自然哲学：宏观的对称，往往暴露了微观的秩序。水晶的六棱柱、蜂巢的六边形网格、石墨的六角形薄片，全都指向同一种"内部整齐"——对称不是巧合，它是物质自己写在自己表面的"内部说明书"。

一句话总结：雪花是六角形，因为冰晶内部的水分子按"六方"规则排列——宏观对称是微观秩序的外在表现，开普勒 1611 年就在琢磨这件事了。
思对称不只是"好看"——诺特定理：对称换守恒（点击展开）

本章的对称都是"图形"的对称。但物理学家发现，对称的威力远不止于此：规律的对称，能换来守恒定律。

1918 年，德国女数学家埃米·诺特证明了一个后来以她名字命名的定理（诺特定理），大意是：物理规律每拥有一种"对称性"，就对应着一条守恒定律。几个著名的例子：

  • 空间平移对称：在教室做的实验，搬到隔壁房间规律一样（规律不挑地方）⟹ 动量守恒；
  • 时间平移对称：今天做的实验，明天做规律还一样（规律不挑时间）⟹ 能量守恒；
  • 旋转对称：把实验装置转一个方向，规律不变（规律不挑方向）⟹ 角动量守恒。

也就是说，「世界规律不随某个变换而变」——和你本章学的"图形沿对称轴折叠后不变"——是同一个家族的概念，只是"对称"的对象从图形升级成了物理规律。

物理学家杨振宁多次强调，对称性是 20 世纪物理学的核心线索：从对称出发，能"推导"出大自然会遵守哪些守恒律。几何对称给了你"折叠后重合"的直观，而诺特定理告诉你：对称在物理里不是装饰，而是秩序的根源。

一句话总结：诺特定理：物理规律的每一种对称性，都对应一条守恒定律（如旋转对称 ⟹ 角动量守恒）——几何的对称，放大到整个物理世界，是秩序的根源。

本章练习卷（含答案）

一、练习题

  1. 下列图形中，对称轴条数最多的是哪一个？请说明理由。
    A. 等腰三角形　B. 矩形　C. 正方形　D. 圆
  2. 如图，△ABC 与 △A′B′C′ 关于直线 l 对称，已知 AC = 6，∠B = 35°。求 A′C′ 的长与 ∠B′ 的度数，并说明依据。
  3. 已知点 P 在线段 AB 的垂直平分线上，且 AB = 10，PA = 13。求 PB 的长；若再在 AB 的垂直平分线上任取一点 Q，判断 QA 与 QB 的大小关系。
  4. 在等腰 △ABC 中，AB = AC，AD 是底边 BC 上的高，且 ∠B = 50°。求 ∠BAD 和 ∠CAD 的度数，并指出"三线合一"里 AD 还同时是哪两条线。
  5. 在 △ABC 中，∠B = ∠C，AB = 8。求 AC 的长；若又知 ∠B = 60°，判断 △ABC 的形状。
  6. 将军饮马问题：A、B 两点在直线 l 的同侧，A、B 到 l 的距离分别为 4 和 9，且 A、B 沿 l 方向的距离为 12。要在 l 上找一点 P，使 PA + PB 最小。请写出作法，并求出 PA + PB 的最小值。

二、参考答案（点击展开）

查看第1题答案

选 D（圆）。圆有无数条对称轴——任何一条直径所在直线都是它的对称轴；而等腰三角形只有 1 条，矩形 2 条，正方形 4 条。所以圆最多。

查看第2题答案

A′C′ = AC = 6，∠B′ = ∠B = 35°。依据：成轴对称的两个图形全等，对应边、对应角分别相等。

查看第3题答案

由垂直平分线性质定理（线上的点到两端点距离相等）得 PB = PA = 13。因为 Q 也在 AB 的垂直平分线上，同样有 QA = QB。

查看第4题答案

等腰三角形中等边对等角 ⇒ ∠C = ∠B = 50°，故顶角 ∠A = 180° − 50° − 50° = 80°。由三线合一，AD 同时是顶角平分线 ⇒ ∠BAD = ∠CAD = 80° ÷ 2 = 40°。AD 还同时是底边 BC 上的中线和顶角 ∠A 的平分线（即"高 = 中线 = 顶角平分线"）。

查看第5题答案

由等角对等边 ⇒ AC = AB = 8。又 ∠B = ∠C = 60°，则 ∠A = 180° − 60° − 60° = 60°，三个角都相等 ⇒ △ABC 是等边三角形（也可用"有一个角是 60° 的等腰三角形是等边三角形"判定）。

查看第6题答案

作法：作点 A 关于直线 l 的对称点 A′（A′ 在 l 另一侧，到 l 的距离也是 4）；连接 A′B 交 l 于点 P，P 即为所求。求值：A′ 与 B 到 l 的距离之和为 4 + 9 = 13，沿 l 方向相距 12，由勾股定理得 PA + PB = PA′ + PB = A′B = √(13² + 12²) = √(169 + 144) = √313。当 A′、P、B 三点共线时路径最短（两点之间线段最短）。
