第14章 整式的乘法与因式分解

初中 / 初二 / 八年级上册

一句话总纲：整式的乘法与因式分解是一对「互逆」的代数运算——乘法把和展开成积的展开式，因式分解把和重新拆成积；而它们每一步的几何原型都是「矩形与正方形的面积拼接与面积切割」。
本章目录 14.1 幂的运算14.2 整式的乘法14.3 平方差公式与完全平方公式14.4 因式分解：提公因式法与公式法含义总结典型例题常见误区

14.1 幂的运算

幂是本章一切运算的地基。先回顾记号：an 表示 n 个 a 相乘，a 叫底数，n 叫指数。例如 23 = 2×2×2 = 8。

幂的运算规则（五条 + 两条补充）

规则公式口诀
同底数幂相乘am · an = am+n底数不变，指数相加
幂的乘方(am)n = amn底数不变，指数相乘
积的乘方(ab)n = anbn积中每个因式分别乘方
同底数幂相除am ÷ an = am−n（a≠0）底数不变，指数相减
零指数幂a0 = 1（a≠0）任何非零数的 0 次幂都等于 1
负整数指数幂a−n = 1 / an（a≠0）负指数 = 取倒数

逐条验证与示例：

x³ · x⁵ = x^(3+5) = x⁸
(x²)⁴ = x^(2×4) = x⁸        ← 注意：乘方运算，"指数相乘"
(2x)³ = 2³ · x³ = 8x³       ← 系数 2 也要乘方
x⁷ ÷ x³ = x^(7−3) = x⁴
2⁰ = 1；(−5)⁰ = 1
3⁻² = 1/3² = 1/9
几何含义：幂就是「维度」。a² 是边长为 a 的正方形面积（2 维），a³ 是棱长为 a 的立方体体积（3 维），a⁴ 以上是更高维空间的「超体积」。于是：
  • 同底数幂相乘 = 维度相加：a² · a³ = a⁵，即「一个平面（2 维）与一个立体（3 维）沿新的独立方向张成 2+3=5 维的超体」。
  • 幂的乘方 = 维度相乘：(a²)³ = a⁶，是把「平面」当作一个新单位再叠 3 层，维度 2×3=6。
  • 积的乘方 = 缩放分配到每个因子：(ab)² = a²b²，一个长 a、宽 b 的矩形，长宽同时放大到原来的 2 倍，面积放大 2²=4 倍，正好是 a² 与 b² 各自被平方。
  • 同底数幂相除 = 维度相减：a⁵ ÷ a² = a³，把 5 维超体沿 a² 方向「压平」掉 2 维，剩 3 维。
物理含义：
  • 零指数 = 「空积」：a⁰ = 1 表示「一个因子都不乘」，结果回到乘法的单位元 1——就像「0 倍的东西」并不存在，而「0 次相乘」恰好剩一个基准单位。
  • 负指数 = 倒数 / 翻转：a⁻ⁿ = 1/aⁿ，指数取负相当于把 a 从「分子地位」翻到「分母地位」。物理上大量物理量用负指数表示「每单位」：速度 m·s⁻¹ 是「米每秒」，密度 g·cm⁻³ 是「克每立方厘米」，负数指数把「除以」写成「乘以倒数」。

易错提醒：(x²)³ ≠ x⁵（指数要相乘，不是相加）；x² · x³ ≠ x⁶（乘法指数相加，不是相乘）。牢牢记住：底数相同的「相乘」管指数相加，「乘方」管指数相乘。

14.2 整式的乘法

整式的乘法一共三种，难度递进，但核心只有一句：系数与系数相乘，同底数幂相乘，最后把同类项合并。

14.2.1 单项式 × 单项式

3x²y · 4xy³ = (3×4) · (x²·x) · (y·y³) = 12x³y⁴
步骤：系数相乘 → 同底数幂相乘 → 落成一个单项式

14.2.2 单项式 × 多项式（乘法分配律）

a(b + c) = ab + ac
2x(x + 3) = 2x² + 6x
−3a(2a² − a + 5) = −6a³ + 3a² − 15a   ← 符号跟着系数走

14.2.3 多项式 × 多项式（逐项相乘再合并）

(a + b)(c + d) = ac + ad + bc + bd
(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6
几何含义：多项式乘法 = 矩形面积的分割求和。(a+b)(c+d) 就是一个「长为 a+b、宽为 c+d」的大矩形，把它沿两条线切成 4 个小矩形，面积分别是 ac、ad、bc、bd，总面积 ac+ad+bc+bd 正好等于逐项展开的结果。 
          c         d
     ┌─────────┬─────────┐
  a  │   ac    │   ad    │
     ├─────────┼─────────┤
  b  │   bc    │   bd    │
     └─────────┴─────────┘
  (a+b)(c+d) = ac + ad + bc + bd
这就是「数与形的统一」：代数式展开的每一项，都对应图里的一块小面积；合并同类项，就是把「形状相同、只是位置不同」的小块拼到一起。
物理含义：多项式乘法 = 两个独立量的「组合放大」。若速度 v = a+b、时间 t = c+d，则路程 s = (a+b)(c+d) = ac+ad+bc+bd，四个交叉项正是「a 段速度 × c 段时间、a 段速度 × d 段时间、……」四段路程之和。乘法分配律在物理上就是「整体 = 各部分贡献之和」。

14.3 平方差公式与完全平方公式

这两个公式是整式乘法里「最值得背下来」的两个，因为它们能直接套用，省去逐项展开的麻烦，也是下一节因式分解的「公式法」来源。

14.3.1 平方差公式

(a + b)(a − b) = a² − b²

文字表述：两数和与两数差的积，等于这两数的平方差。

  • 例：(x + 3)(x − 3) = x² − 9
  • 例：(2m + 5)(2m − 5) = (2m)² − 5² = 4m² − 25
  • 巧算：99 × 101 = (100 − 1)(100 + 1) = 100² − 1² = 9999
几何含义：大正方形挖掉小正方形，剩下一块「L 形」，切一刀拼成长方形。边长为 a 的大正方形面积 a²，从一角挖掉边长为 b 的小正方形（面积 b²，需 b < a），剩余面积 a² − b²。把这块 L 形沿虚线切开，能重新拼成一个「长为 a+b、宽为 a−b」的长方形，于是 a² − b² = (a+b)(a−b)。 
        a
  ┌────────────┐
  │            │
  │            │
  │       ┌────┤ b
  │ 剩面积 │ b² │
  │ a²−b² │    │
  └───────┴────┘
  切一刀 → 拼成 (a+b) × (a−b) 的长方形
平方差公式的几何本质就是：「面积之差」可以等价地写成「两个新边长的乘积」。
物理含义：平方差常用于「消除误差项」的近似与化简。例如物体动能 ½mv² 的变化量 ½m(v₂² − v₁²) 可写成 ½m(v₂+v₁)(v₂−v₁)；再如估算 401² − 399² = (401+399)(401−399) = 800×2 = 1600，两个大数的平方差瞬间化为乘法，把「差」转成「积」是化简运算的利器。

14.3.2 完全平方公式

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²

文字表述：两数和（差）的平方，等于它们的平方和，加上（或减去）它们积的 2 倍。

  • 例：(x + 4)² = x² + 8x + 16
  • 例：(3a − 2b)² = 9a² − 12ab + 4b²
  • 注意 (a − b)² 的中间项是 −2ab，不要漏掉负号。
几何含义：完全平方 = 正方形四块拼接。边长为 a+b 的正方形，切成四块：一个 a² 大正方形、一个 b² 小正方形、以及两个 ab 的长方形（沿两条对角线方向各一块）。总面积为 a² + ab + ab + b² = a² + 2ab + b²。 
         a          b
     ┌─────────┬──────┐
  a  │   a²    │  ab  │
     ├─────────┼──────┤
  b  │   ab    │  b²  │
     └─────────┴──────┘
  (a+b)² = a² + 2ab + b²
而 (a−b)² 就是「边长为 a 的大正方形，去掉两个 ab 长条后，又重复减掉了一个 b² 小方块，再加回来」：a² − ab − ab + b² = a² − 2ab + b²。中间的 2ab 之所以是「2 倍」，正是因为正方形里总有两块对称的 ab。
物理含义：完全平方 = 「平方和」与「交叉项的 2 倍」。这是物理中展开 (x+Δ)² 的标准动作：如长度从 L 热胀到 L+ΔL，面积 (L+ΔL)² = L² + 2LΔL + ΔL²，其中 2LΔL 是面积的一阶增量（两条细长条），ΔL² 是二阶小量（可忽略的角落）。理解 2ab 的来源，就理解了「为什么微小变化的平方项可以忽略」。

14.4 因式分解：提公因式法与公式法

14.4.1 什么是因式分解

定义：把一个多项式化成几个整式乘积的形式，叫做因式分解（也叫分解因式）。它是整式乘法的逆运算：

整式乘法：  (x+2)(x+3)  ──展开──▶  x² + 5x + 6
因式分解：  x² + 5x + 6  ──分解──▶  (x+2)(x+3)

判断要点：因式分解的最终结果必须是「乘积」形式，且不能再分。例：x² − 1 分解成 (x+1)(x−1) 就到位了，写成 x·x − 1 不叫因式分解。

基本顺序口诀：一提、二套、三检查。

  1. 一提：先看各项有没有公因式，先提出来。
  2. 二套：再看括号里能不能套平方差或完全平方公式。
  3. 三检查：分解到底，检查每个因式是否还能再分。

14.4.2 提公因式法

找到各项的最大公因式，把它提到括号外面：

ma + mb + mc = m(a + b + c)
6x² + 9x = 3x(2x + 3)              ← 公因式是 3x
4a²b − 6ab² + 2ab = 2ab(2a − 3b + 1)   ← 注意最后一项 2ab 提完后剩 1，别漏
几何含义：提公因式 = 把若干块矩形「按相同边长归并」成一个整体。6x² + 9x 可看成两个矩形：宽 6x 高 x，宽 9 高 x（或等价地，两块面积共用一个公共因子 x）。提出公因式 3x，等于把公共的「高度 3x」抽出来，剩下的 2x+3 是合并后的「底边」，即 3x(2x+3)。这正是「公共边 × 总长」的面积公式。
物理含义：提公因式 = 提取「共同的单位/共同的倍率」。例如把 F = ma₁ + ma₂ 写成 F = m(a₁+a₂)：质量 m 是两个加速度共同的倍率，提出来后式子更简洁，物理结构（总力 = 质量 × 合加速度）一眼可见。

14.4.3 公式法（平方差 + 完全平方）

用平方差公式分解：

a² − b² = (a + b)(a − b)
x² − 9 = x² − 3² = (x + 3)(x − 3)
4m² − 25 = (2m)² − 5² = (2m + 5)(2m − 5)
9a² − 16b² = (3a)² − (4b)² = (3a + 4b)(3a − 4b)

用完全平方公式分解：

a² + 2ab + b² = (a + b)²
a² − 2ab + b² = (a − b)²
x² + 6x + 9 = x² + 2·x·3 + 3² = (x + 3)²
x² − 10x + 25 = x² − 2·x·5 + 5² = (x − 5)²
几何含义：因式分解 = 把「面积」还原成「边长乘积」。x² − 9 是「边长 x 的大正方形挖掉边长 3 的小正方形」剩下的 L 形面积，分解成 (x+3)(x−3) 就是把这块 L 形拼回一个长为 x+3、宽为 x−3 的长方形——两个边长重新显形。同理 x²+6x+9 是一块能恰好拼成完整正方形的四块面积（x²、3x、3x、9），分解成 (x+3)² 就是还原出它的边长 x+3。
物理含义：因式分解 = 把一个量拆成「两个因素的乘积」，暴露其零点与结构。方程 x² − 9 = 0 因式分解成 (x+3)(x−3)=0 后，立即可读出两个解 x=−3、x=3（乘积为 0 必有某个因子为 0）。在物理上，许多公式正是「因式相乘」的形式，把和式拆成积式，能直接看出「什么条件下结果为零」。

两类综合（一提 + 二套配合使用）：

2x² − 8 = 2(x² − 4) = 2(x + 2)(x − 2)          ← 先提公因式 2，再套平方差
3x² + 12x + 12 = 3(x² + 4x + 4) = 3(x + 2)²     ← 先提公因式 3，再套完全平方

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
幂 aⁿ维度：a² 是面积（2 维）、a³ 是体积（3 维）幂次 = 重复放大次数（增长、缩放）
同底数幂相乘维度相加（a²·a³ = a⁵）不同方向独立扩张，指数叠加
幂的乘方维度相乘（(a²)³ = a⁶）「把整体当单位」再叠 n 层
积的乘方缩放分配到每个因子（(ab)² = a²b²）整体放大 n 倍，每个部分都放大 n 倍
同底数幂相除维度相减（a⁵ ÷ a² = a³）抵消掉相同方向的扩张
零指数 / 负指数回到单位 1 / 取倒数（翻转）「空积」=1；负指数 = 每单位（m·s⁻¹）
单项式 × 单项式两个量（系数、字母）各自相乘单位与数值同时相乘
多项式乘法矩形面积分割求和（ac+ad+bc+bd）整体 = 各部分贡献之和（分配律）
平方差公式大正方形挖小正方形，切一刀拼成长方形把「平方之差」化为「两数积」以化简/求增量
完全平方公式正方形四块拼接（a²+2ab+b²）展开 (x+Δ)²，看出 2ab 交叉项与 Δ² 小量
提公因式法按公共边长归并矩形提取公共单位/倍率，合并同类贡献
公式法因式分解把面积还原成边长乘积拆成因子，直接读出「零点/结构」

典型例题（自测）

  1. 计算：x⁴ · x²、(x³)⁵、(−2ab²)³、a⁸ ÷ a³、5⁰、2⁻³。
  2. 计算：(2x+3)(x−5)、(x−2y)(x+2y)、(3m+1)²、(2a−5)²。
  3. 巧算：98 × 102、201² − 199²、101²。
  4. 因式分解：12a³b − 8a²b²、x² − 16、25m² − 4n²、x² + 8x + 16、9a² − 12a + 4。
  5. 综合分解：3x² − 27、2x² + 20x + 50、−a² + 4b²（提示：先提负号）。
  6. 已知 (a+b)² = 49，ab = 12，求 a² + b² 的值。

常见误区

  • ❌ "a² · a³ = a⁶" → ❌ 同底数幂相乘，指数是相加，正确为 a⁵。
  • ❌ "(a³)² = a⁵" → ❌ 幂的乘方，指数是相乘，正确为 a⁶。
  • ❌ "(ab)² = ab²" → ❌ 积的乘方，系数 a 也要平方，正确为 a²b²。
  • ❌ "(a+b)² = a² + b²" → ❌ 漏掉了交叉项 2ab，正确为 a² + 2ab + b²。这是最经典的错误！
  • ❌ "(a−b)² = a² + 2ab + b²" → ❌ 中间项是 −2ab，不是 +2ab。
  • ❌ "提公因式时漏项" → ❌ 2ab + 4b 提 2b 后应是 2b(a+2)，第二项不能只剩 a 而没有常数 2。
  • ❌ "x² + 9 能用平方差分解" → ❌ 平方差必须是「减」，x² + 9（平方和）在实数范围内不能用公式法分解。
  • ❌ "x² + 6x + 9 分解成 (x+3)(x+3) 后不再化简" → ❌ 应写成 (x+3)²，相同因式要合并成幂的形式。

本章练习卷（含答案）

一、练习题

  1. 计算并说明指数规则：x³ · x⁴、(x²)⁵、(−2a²b)³、x⁸ ÷ x²、7⁰、2⁻³。（提示：分清「相乘」与「乘方」时指数如何变化）
  2. 用「矩形面积」解释 2x(x+3) = 2x² + 6x：把 2x 看成公共的宽，(x+3) 看成底边分成的两段，写出两块小面积并求和。
  3. 巧算：99 × 101 与 201² − 199²，并说明各用了哪个公式。
  4. 用「正方形四块拼接」解释 (a+b)² = a² + 2ab + b²，并回答：为什么交叉项系数是 2？
  5. 因式分解：3x² − 27 与 x² + 8x + 16，并写出分解顺序（一提、二套、三检查）。
  6. 已知 (a+b)² = 49，ab = 12，求 a² + b² 的值；再结合「长度由 L 热胀到 L+ΔL 时面积的变化」说明 2LΔL 这一项的实际含义。

二、参考答案（点击展开）

查看第1题答案

x³·x⁴ = x⁷（指数相加 3+4）；(x²)⁵ = x¹⁰（指数相乘 2×5）；(−2a²b)³ = (−2)³·(a²)³·b³ = −8a⁶b³；x⁸ ÷ x² = x⁶（指数相减 8−2）；7⁰ = 1；2⁻³ = 1/2³ = 1/8。口诀：同底数幂相乘指数相加，幂的乘方指数相乘。

查看第2题答案

把 2x 当作矩形的公共宽，把 (x+3) 当作底边分成的两段 x 与 3。两块小矩形面积分别为 2x·x = 2x² 和 2x·3 = 6x，总面积 2x² + 6x。这正是分配律 a(b+c) = ab + ac 的面积模型：公共宽 × 各段底边之和。

查看第3题答案

99×101 = (100−1)(100+1) = 100² − 1² = 9999（平方差公式）；201²−199² = (201+199)(201−199) = 400×2 = 800（把「平方之差」转成「两数之积」）。

查看第4题答案

边长为 a+b 的正方形可切成四块：一块 a²、一块 b²，以及两块 ab 的长方形（沿两个方向各一块、对角对称）。所以总面积为 a² + ab + ab + b² = a² + 2ab + b²，交叉项系数是 2 正因为有两块对称的 ab。若误写成 a² + b² 就漏掉了这两块。

查看第5题答案

3x²−27 = 3(x²−9) = 3(x+3)(x−3)：先提公因式 3，再套平方差。x²+8x+16 = x²+2·x·4+4² = (x+4)²：中间项 8x 对应 2·x·4，符合完全平方。分解顺序：一提公因式 → 二套公式 → 三检查是否分解到底。

查看第6题答案

由 (a+b)² = a² + 2ab + b² 得 a² + b² = (a+b)² − 2ab = 49 − 2×12 = 25。面积展开 (L+ΔL)² = L² + 2LΔL + ΔL² 中，2LΔL 是两条细长条带来的一阶面积增量，ΔL² 是二阶小量（ΔL 很小时可忽略），这解释了「微小变化的平方项为何可以忽略」。
