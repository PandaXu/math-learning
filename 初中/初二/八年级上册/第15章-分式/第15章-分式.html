第15章 分式

初中 / 初二 / 八年级上册

一句话总纲：分式 = 「分母里含字母的比值」，它的本质是"两个量相除得到的比例"。学完本章，你要能在心里"看见"一条双曲线——分母趋近 0 时比值冲向无穷（渐近线），分母无穷大时比值归零；约分、通分、四则运算、解方程，全都能还原成"同一个比值换了不同的表达方式"。

15.1 分式的概念

从分数到分式

我们熟悉的分数，分子、分母都是确定的数，如 3/4、−5/7、2/5。而分式把"数"推广到"式"——分子、分母是整式，并且分母里含有字母。

定义：一般地，如果 A、B 表示两个整式，并且 B 中含有字母，那么式子 A/B 叫做分式，其中 A 叫分子，B 叫分母。

 A
───   （A、B 是整式，B 中含有字母，B ≠ 0）
 B
  • 5/x、x/(x+1)、(2a)/(a²−1)、(x+y)/(x−y) 都是分式。
  • 3/4 是分数；x/2、x/π 不是分式——它们的分母是数（π 是圆周率，是一个确定的数，不是字母），所以是整式。
分式与分数的关系：分数是分式的特殊情况（分母不含字母）；分式是分数的推广（分母含字母，代表"会变化的量"）。因此分式继承了分数的全部法则，但又因为分母会变，多了一条最重要的限制——分母不能为 0。

分式有意义的条件：分母 ≠ 0

因为"除以 0"没有意义，所以分式 A/B 有意义的条件是 B ≠ 0。

 A
───  有意义  ⟺  B ≠ 0
 B

例：分式 1/(x−2)，当 x = 2 时分母为 0，分式无意义；当 x ≠ 2 时才有意义。求分式有意义的条件，就是"解不等式：分母 ≠ 0"。

几何含义（双曲线与渐近线）：把 y = 1/(x−2) 看成一条曲线，它的图像是一条双曲线（反比例函数的图像，我们以后会正式学到）。当 x 从右边逼近 2 时，分母 x−2 逼近 0，y 冲向 +∞；当 x 从左边逼近 2 时，y 冲向 −∞。图像会无限逼近竖直线 x = 2，却永远碰不到它。这条竖直线叫渐近线，它就是"分母为 0"在几何上的化身——在 x = 2 处函数根本没有定义，图像上是一个"断开的缺口"。
物理含义（分母不能为 0 的现实意义）：速度 v = s/t，时间 t 不能为 0（"0 小时走完全程"在物理上无意义）；密度 ρ = m/V，体积 V 不能为 0；浓度 = 溶质/溶液，溶液不能为 0。凡是"每单位××的量"，那个"单位量"（分母）都不能为 0。

分式值为 0 的条件：分子 = 0 且 分母 ≠ 0

要让一个分式等于 0，必须分子为 0；但同时分母不能为 0（否则分式无意义，根本谈不上"等于 0"）。两个条件缺一不可：

 A
─── = 0  ⟺  A = 0  且  B ≠ 0
 B

例：分式 (x−1)/(x+2)，令分子 x−1 = 0 得 x = 1，此时分母 1+2 = 3 ≠ 0，所以当 x = 1 时分式值为 0。而 x = −2 时，分子 −3 ≠ 0、分母为 0，分式无意义（不是"值为 0"）。

几何含义：分式值为 0 的点，就是图像与 x 轴的交点（y = 0 处），但要排除该点同时让分母为 0 的"断点"。例如 y = (x−1)/(x−2)：x = 1 时 y = 0，图像在点 (1, 0) 处穿过 x 轴；而 x = 2 处是渐近线，根本取不到 y 值。

分式的符号法则

分式的符号由分子、分母和分式整体三处共同决定，与分数完全一致（同号得正、异号得负）：

  −A     A       A
 ──── = ──── = −───   （只改变分子或分母一个的符号，分式整体前面加负号）
   B    −B       B

   A    −A
  ─── = ────           （分子、分母同时变号，分式的值不变）
   B    −B

例：−x/(x−1) = x/(1−x)（把分母 x−1 变号成 1−x，同时分式前面补一个负号，二者等价）。

15.2 分式的基本性质与约分、通分

基本性质

分式的分子与分母都乘（或除以）同一个不等于 0的整式，分式的值不变：

 A     A·M         A     A÷M
─── = ─────        ─── = ─────     （M ≠ 0）
 B     B·M         B     B÷M

这与"分数的基本性质"完全一样：分子、分母同乘（除）同一个非零数，分数值不变。区别只在于 M 现在可以是含字母的整式，所以必须特别强调 M ≠ 0。

几何含义（换单位不换比值）：把分子、分母同时放大或缩小 M 倍，相当于"换了一把更粗或更细的尺子"，量出的两个数都变了，但它们的比值不变。好比地图比例尺 1:100000 与 2:200000，画出来的是同一张地图、同一个形状，只是刻度粗细不同。
物理含义（单位换算的本质）：60 km/h = 60 km / 1 h = 60000 m / 3600 s = 50/3 m/s。分子、分母同乘（除）同一系数，速度这个比值不变——这正是"约分 / 通分"在做的事：约分 = 把公因子约掉（把单位约小），通分 = 统一分母（把单位统一）。

约分与最简分式

约分：根据基本性质，把分式的分子、分母的公因式约去。

最简分式：分子与分母没有公因式（除 ±1 之外）的分式。约分的结果必须化成最简分式。

约分的关键是先因式分解，再约去公因式：

a²b       a·(ab)      a
────  =  ────────  =  ──      （约去公因式 ab，要求 ab ≠ 0）
ab²       b·(ab)      b

x²−1      (x+1)(x−1)     x+1
─────  =  ───────────  =  ─────   （约去 x−1，要求 x ≠ 0 且 x ≠ 1）
x²−x       x(x−1)         x
注意：约分约的是"相乘的因式"，不是"相加的项"。例如 (a+b)/b 不能把 b 约成 a——b 在分子里是"加项"不是"因式"。正确结果是 (a+b)/b = a/b + 1，而不是 a。

通分与最简公分母

通分：把几个异分母的分式化成与原来相等的同分母分式。

最简公分母：取各分母所有因式的最高次幂的积（系数取各系数的最小公倍数）。

例：1/(2x²y) 与 1/(3xy³)
系数 2、3 的最小公倍数是 6；
字母 x 取最高次 x²，y 取最高次 y³；
∴ 最简公分母 = 6x²y³

1/(2x²y) = 3y²/(6x²y³)      1/(3xy³) = 2x/(6x²y³)
例：1/(x²−x) 与 1/(x²−1)
x²−x = x(x−1)，x²−1 = (x+1)(x−1)
最简公分母 = x(x−1)(x+1)

1/(x²−x) = (x+1) / [x(x−1)(x+1)]
1/(x²−1) = x / [x(x−1)(x+1)]
几何含义（统一刻度再拼接）：通分就是"把两条刻度不同的尺子，统一成同一把刻度更细的尺子"。1/2 和 1/3 要相加，先把整条线段等分成 6 份（6 就是最简公分母），3/6 和 2/6 就能直接"数格子"相加了。

15.3 分式的乘除与乘方

分式的乘法

 A     C     A·C
─── · ─── = ─────
 B     D     B·D

分子乘分子作新分子，分母乘分母作新分母。运算时先约分、后相乘，结果化成最简分式。

例：(x/y)·(y²/x²) = (x·y²)/(y·x²) = y/x（约去公因式 xy）。

几何含义（矩形面积）：(a/b)·(c/d) = ac/bd，相当于一个长 a/b、宽 c/d 的矩形，其面积是 ac/bd——分式乘法就是"两个比例相乘，得到一个新的比例"。

分式的除法

除以一个分式，等于乘这个分式的倒数（分子、分母颠倒位置）：

 A     C     A     D     A·D
─── ÷ ─── = ─── · ─── = ─────
 B     D     B     C     B·C

例：(a/b) ÷ (a/b²) = (a/b)·(b²/a) = b。

物理含义（比值复合与"单位约消"）：分式的乘除对应物理量的复合与换算，分子、分母的单位像数一样"约分"：
  • 速度 × 时间 = 路程：(s/t) · t = s —— 时间单位约掉了。
  • 路程 ÷ 速度 = 时间：s ÷ (s/t) = s · (t/s) = t —— 路程单位约掉了。
  • 密度 × 体积 = 质量：ρ · V = m —— 体积单位约掉了。
这就是物理中的量纲分析：把单位本身当成分式来乘除。

分式的乘方

分式的乘方，等于把分子、分母分别乘方：

( A )ⁿ     Aⁿ
(───)   =  ────     （n 是正整数）
( B )      Bⁿ

例：

( x² )³      x⁶
(────)    =  ────
( y  )       y³

( −2a² )³      (−2)³·(a²)³      −8a⁶
(──────)    =  ────────────  =  ─────
(  b   )           b³             b³
符号要点：负号也要参与乘方——负数的奇次幂为负、偶次幂为正。(−2)³ = −8，而 (−2)² = +4。所以 (−a/b)² = a²/b²（负号平方后变正），但 (−2a²/b)³ = −8a⁶/b³（负号三次方仍是负）。

15.4 分式的加减

同分母分式相加减

 A     C     A ± C
─── ± ─── = ─────
 B     B      B

分母不变，分子相加减。

例：3/(x+1) + 2/(x+1) = (3+2)/(x+1) = 5/(x+1)。

几何含义：同分母就是"同一把刻度尺"下的量，直接拼接（相加）或截断（相减）。3/5 米 + 1/5 米 = 4/5 米——都是"五分之一"这种刻度，直接数格子即可。

异分母分式相加减

先通分（化成同分母），再按同分母分式相加减。

1     1      y + x      x + y
── + ───  =  ───────  =  ─────      （最简公分母 xy）
x     y        xy          xy

  1         1        (x−1) + (x+1)        2x
────── + ──────  =  ───────────────  =  ──────
x + 1     x − 1       (x+1)(x−1)        x² − 1
物理含义（单位必须统一才能相加）：异分母分式相加，就像"1/2 小时 + 20 分钟"不能直接加——必须先把 1/2 小时换成 30 分钟（或把 20 分钟换成 1/3 小时），统一单位后再相加。通分就是"统一单位"。

分式的混合运算

运算顺序：先乘方，再乘除，最后加减；有括号先算括号。结果要化成最简分式。

例：计算 (1/x + 1/y) ÷ (1/x − 1/y)

1/x + 1/y = (x+y)/(xy)
1/x − 1/y = (y−x)/(xy)
原式 = (x+y)/(xy) · (xy)/(y−x) = (x+y)/(y−x)

15.5 分式方程

什么是分式方程

分母中含有未知数的方程叫分式方程。例如：1/x = 3/(x+2)、x/(x−1) = 2。

注意区分：分母不含未知数的（如 x/2 + 1 = 3）是整式方程，不是分式方程。

解分式方程的基本思路

核心是"化分式为整式"：方程两边同乘最简公分母，把分式方程转化为整式方程来解。但这一步可能引入增根，所以解完必须检验。

步骤：

  1. 去分母：两边同乘最简公分母，化为整式方程；
  2. 解整式方程；
  3. 检验：把解代入最简公分母（或原方程的各分母），若为 0 则是增根、舍去；若不为 0 则是原方程的解。

增根：为什么必须检验？

增根：去分母后整式方程的解中，使原分式方程的分母为 0 的根。它是"去分母"这个变形多出来的解，不是原方程的解，必须舍去。

产生原因：两边同乘的"最简公分母"可能为 0。用一个可能为 0 的式子去乘方程两边，会"偷偷"多出解——就像方程两边同乘 0 会让任何等式都成立、凭空冒出无数"解"一样。

完整例题（含增根）：

解方程：x/(x−1) + 1/(x+1) = 2/(x²−1)

去分母（两边同乘 (x−1)(x+1)）：
x(x+1) + (x−1) = 2
x² + x + x − 1 = 2
x² + 2x − 3 = 0
(x+3)(x−1) = 0   →   x = −3 或 x = 1

检验：x = 1 使 (x−1)(x+1) = 0，是增根，舍去；
      x = −3 使 (x−1)(x+1) = 8 ≠ 0，是原方程的解。
∴ 原方程的解是 x = −3。
几何含义（交点与渐近线）：分式方程的解，可以看成"双曲线"与"直线"（或另一条曲线）的交点横坐标。去分母相当于把双曲线方程"拉扯"成整式方程，拉扯过程中双曲线的渐近线可能会被"拉"成一个假交点——这个假交点就是增根。上例中 x = 1 处原分式根本不存在（图像断开、冲向无穷），整式方程算出的"交点"在图上并不存在，必须剔除。
物理含义（物理上无意义的解）：分式方程常表示"比值相等"的条件（速度相等、密度相等、浓度相等、效率相等）。解出的根若让分母为 0（时间为 0、体积为 0），或为负数（时间为负、长度为负），在物理上无意义，必须检验舍去。数学的"增根"，在现实中对应的就是"无意义的解"。

15.6 分式方程的应用

列分式方程解应用题的步骤

  1. 审题，找等量关系（通常是"××相等"或"××相差多少"）；
  2. 设未知数（通常设"单位量"或"总量"）；
  3. 用含未知数的分式表示各量，列方程；
  4. 解分式方程；
  5. 双检验：① 是否为增根；② 是否符合实际意义（如时间、速度不能为负或 0）。

题型一：工程问题

等量关系：工作总量 = 工作效率 × 工作时间。合作时，总效率 = 各效率之和。

例：一项工程，甲单独做 10 天完成，乙单独做 15 天完成。
问：两人合作，几天完成？

设合作需 x 天完成。
甲每天做 1/10，乙每天做 1/15，合作每天做 1/x。
列方程：1/10 + 1/15 = 1/x
解：3/30 + 2/30 = 1/x   →   5/30 = 1/x   →   x = 6
检验：x = 6 ≠ 0，且符合实际。
答：两人合作 6 天完成。
物理含义："工作效率 = 工作量 ÷ 时间"本身就是一个分式。把"每天完成几分之几"这种比值加起来，就是"每天一共完成几分之几"——分式加法在这里有了最自然的现实意义。

题型二：行程问题

等量关系：路程 = 速度 × 时间。

例：甲乙两地相距 60 km，一辆汽车从甲到乙后原路返回。
去时速度为 x km/h，返回时提速 15 km/h，
返回比去时少用 20 分钟（1/3 小时）。求去时速度。

设去时速度 x km/h，则返回速度 (x+15) km/h。
去时时间 = 60/x，返回时间 = 60/(x+15)。
列方程：60/x − 60/(x+15) = 1/3
去分母（两边乘 3x(x+15)）：
180(x+15) − 180x = x(x+15)
180x + 2700 − 180x = x² + 15x
x² + 15x − 2700 = 0
(x+60)(x−45) = 0   →   x = 45 或 x = −60
检验：x = −60 为负数（速度不能为负），舍去；x = 45 使分母 ≠ 0。
答：去时速度为 45 km/h。

题型三：浓度问题（分式 = 比值）

等量关系：浓度 = 溶质质量 ÷ 溶液质量（"浓度"本身就是一个分式/比值）。

例：有含盐 15% 的盐水 200 g，加水稀释成含盐 10% 的盐水，需加水多少克？

稀释前后"盐的质量"不变：盐 = 200 × 15% = 30 g。
设加水 x g，则新盐水 (200+x) g，浓度 = 30/(200+x) = 10%。
列方程：30/(200+x) = 0.1
解：30 = 0.1(200+x)   →   30 = 20 + 0.1x   →   x = 100
检验：x = 100 使分母 200+100 = 300 ≠ 0，且符合实际。
答：需加水 100 g。
物理含义：浓度、速度、密度、效率……这些量本质上都是分式（比值）。分式方程就是把这些比值之间的相等关系翻译成等式，去分母后变成熟悉的整式方程，再回头用"分母 ≠ 0、量非负"这些物理约束来检验。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
分式的概念分母含字母的比值；y = k/x 对应双曲线速度、密度、浓度、效率等"比值"
分母 ≠ 0（有意义）双曲线的渐近线——图像永远碰不到的那条线时间、体积等"单位量"不能为 0
分式值为 0图像与 x 轴的交点（分子 = 0 且分母 ≠ 0）比值为 0（分子为 0，分母仍有效）
基本性质（约分/通分）换单位不换比值（比例尺缩放）单位换算：60 km/h = 60000 m / 3600 s
分式乘法矩形面积（两个边长比相乘）比值复合、单位约消（速度×时间=路程）
分式除法乘倒数（分子、分母颠倒）路程÷速度=时间（单位约消）
分式加减同刻度直接拼接；异刻度先统一刻度统一单位后再相加（1/2 时 + 20 分）
分式方程双曲线与直线（曲线）的交点横坐标比值相等（速度、浓度、效率相等）
增根落在渐近线上的"假交点"物理上无意义的解（时间为 0/负等）

典型例题（自测）

  1. 当 x 取何值时，分式 (x−2)/(x+3) 有意义？当 x 取何值时它的值为 0？
  2. 约分：(x²−4)/(x²+4x+4)；(a²b−ab²)/(a²b²)。
  3. 计算：(x/y)·(y²/x²)；(a/b) ÷ (a/b²)；(1/x + 1/y) ÷ (1/x − 1/y)。
  4. 计算：(x²/y)³ 与 (−2a²/b)³。
  5. 通分并计算：1/(x+2) + x/(x−2)。
  6. 解分式方程 x/(x−1) + 1/(x+1) = 2/(x²−1)，并指出增根是谁。
  7. 应用题：一项工程甲单独 10 天、乙单独 15 天完成，两人合作几天完成？

常见误区

  • ❌ "分母里含字母的式子都是分式" → ❌ 像 x/π、x/2 的分母是数（π 是常数，不是字母），它们是整式不是分式。
  • ❌ "分式有意义 ⇔ 分子 ≠ 0" → ❌ 关键是分母 ≠ 0；分子可以为 0。
  • ❌ "分式值为 0 ⇔ 分子 = 0" → ❌ 还要同时满足分母 ≠ 0，否则分式无意义。
  • ❌ "约分就是约掉分母" → ❌ 约分约的是分子、分母的公因式，约后分母仍保留；而且只能约"相乘的因式"，不能约"相加的项"（(a+b)/b ≠ a）。
  • ❌ "通分就是把分母相乘" → ❌ 要用最简公分母（各因式的最高次幂的积），否则会算得又大又复杂甚至出错。
  • ❌ "去分母时漏乘不含分母的项" → ❌ 去分母是每一项都乘最简公分母，常数项、整式项也要乘。
  • ❌ "解完分式方程不用检验" → ❌ 这是最易丢分点。去分母可能产生增根，必须代入最简公分母检验并舍去。
  • ❌ "分式乘方时不管负号" → ❌ 负号也要乘方：(−a/b)² = a²/b²（负号平方后为正），但 (−2a²/b)³ = −8a⁶/b³（奇次幂仍为负）。
  • ❌ "应用题解出负数也照写" → ❌ 时间、速度、长度等不能为负或 0，要"双检验"（增根 + 实际意义）。

本章练习卷（含答案）

一、练习题

  1. 下列代数式中，哪些是分式，哪些是整式？5/x、x/2、(x+y)/(x−y)、3/π、(a+b)/3，并说明判断依据。
  2. 当 x 取何值时，分式 (x−2)/(x²−1) 有意义？当 x 取何值时它的值为 0？并说说"分母为 0"在双曲线图像上对应什么现象。
  3. 约分：(x²−4)/(x²+4x+4)；再通分：1/(x−1) 与 1/(x²−1)，写出最简公分母。
  4. 计算：(x/y²)·(y/x²)、(a/b) ÷ (a²/b²)、(−2x²/y)³；并用"单位约消"解释 (s/t)·t = s 的物理含义。
  5. 计算：1/(x+2) + x/(x−2)；并说明"通分"在几何上相当于什么操作。
  6. 解分式方程 x/(x−1) − 2/(x²−1) = 1，并指出增根是谁；再解应用题：一项工程甲单独做 10 天、乙单独做 15 天完成，两人合作几天完成？为什么分式方程应用题要"双检验"？

二、参考答案（点击展开）

查看第1题答案

分式：5/x（分母含字母 x）、(x+y)/(x−y)（分母含字母 x、y）。整式：x/2（分母是数 2）、3/π（π 是圆周率，是确定的数不是字母）、(a+b)/3（分母是数 3）。判断依据：分母里是否含字母——含字母是分式，不含字母（只是数）是整式。

查看第2题答案

有意义 ⟺ 分母 x²−1 ≠ 0，即 x ≠ ±1。值为 0 ⟺ 分子 x−2 = 0 且分母 ≠ 0，得 x = 2（此时分母 = 3 ≠ 0）。"分母为 0"对应双曲线 y = (x−2)/(x²−1) 在 x = ±1 处的竖直渐近线：图像无限逼近这条竖线却永远碰不到，函数在该处没有定义（出现"缺口"）。

查看第3题答案

约分：x²−4 = (x+2)(x−2)，x²+4x+4 = (x+2)²，约去公因式 (x+2) 得 (x−2)/(x+2)（注意 x ≠ −2）。通分：x²−1 = (x+1)(x−1)，最简公分母 = (x+1)(x−1)，所以 1/(x−1) = (x+1)/(x²−1)，1/(x²−1) 保持不变。

查看第4题答案

(x/y²)·(y/x²) = xy/(x²y²) = 1/(xy)。(a/b) ÷ (a²/b²) = (a/b)·(b²/a²) = b/a。(−2x²/y)³ = (−2)³·x⁶/y³ = −8x⁶/y³。(s/t)·t = (s·t)/t = s：时间单位 t 在分子、分母各出现一次被约掉，只剩路程 s——这正是物理量纲分析里"速度 × 时间 = 路程"的单位约消。

查看第5题答案

最简公分母 = (x+2)(x−2) = x²−4。原式 = (x−2)/(x²−4) + x(x+2)/(x²−4) = [x−2 + x²+2x]/(x²−4) = (x²+3x−2)/(x²−4)。"通分"在几何上相当于把两条刻度不同的尺子统一成同一把更细的尺子（统一单位刻度），统一之后才能直接"数格子"相加。

查看第6题答案

去分母：两边同乘最简公分母 (x+1)(x−1)，得 x(x+1) − 2 = x²−1，即 x²+x−2 = x²−1，解得 x = 1。但 x = 1 使最简公分母 x²−1 = 0，是增根，舍去，原方程无解。应用题：设合作需 x 天，则 1/10 + 1/15 = 1/x，即 3/30 + 2/30 = 1/x，5/30 = 1/x，解得 x = 6 天。要"双检验"：一是去分母可能产生增根，须代入最简公分母检验；二是"天数"这类实际量不能为负或 0，须检验解是否符合实际意义。
