第11章 三角形

初中 / 初二 / 八年级上册

一句话总纲：三角形是「三条线段首尾相接、首尾闭合」的最简刚性平面图形——三条边固定，形状就唯一确定；三内角之和恒为 180°，任意多边形都能拆成三角形，所以它是研究一切平面图形与稳定结构的"地基"。
本章目录 11.1 三角形的边（三边关系）11.2 三角形的角（内角和与外角）11.3 三角形的高、中线、角平分线11.4 三角形的稳定性11.5 多边形的内角和与外角和含义总结典型例题常见误区

11.1 三角形的边（三边关系）

什么是三角形？

定义：由不在同一条直线上的三条线段首尾顺次相接所组成的图形叫做三角形。

  • 组成三角形的三条线段叫三角形的边，相邻两边的公共端点叫顶点，相邻两边所夹的角叫三角形的内角（简称角）。
  • 三角形用符号 △ 表示。顶点为 A、B、C 的三角形记作 △ABC，读作"三角形 ABC"。
  • 三角形有三条边、三个顶点、三个内角——这是它全部的基本元素。
        A
       / \
      /   \
     /     \
    B-------C
   △ABC：三边 AB、BC、CA；三角 ∠A、∠B、∠C
几何含义：三角形是"最少边数"的封闭平面图形——一条、两条线段都围不成封闭区域，三条是能"圈出一块地盘"的最低配置。因此它是多边形中最基本、最不可再拆的单元。

三边关系（核心定理）

在一个三角形中：

两边之和大于第三边：a + b > c，b + c > a，c + a > b
两边之差小于第三边：|a − b| < c，|b − c| < a，|c − a| < b
  • 判定方法：判断三条线段能否组成三角形，只要看较短两边之和是否大于最长边即可（一次判断就够）。例：3、4、5 能成三角形（3 + 4 = 7 > 5）；3、4、7 不能（3 + 4 = 7 = 7，恰好不满足"大于"）。
  • 求第三边范围：已知两边 a、b，则第三边 c 满足 |a − b| < c < a + b。例：两边为 5 和 8，则第三边在 (3, 13) 之间，即 3 < c < 13。
几何含义：三边关系本质是"两点之间，线段最短"。把 a、b 看成从同一端点出发的两段折线，从起点到终点走直线（c）一定比绕路（a + b）短；反过来，若 a + b ≤ c，则两条短线段"够不着"接在一起，根本围不成封闭图形。
物理含义：两条"绳子"接起来必须比第三条长，才能把三个点"拉成一个圈"；如果不够长，结构就"塌"成一条直线。这就是为什么三根任意长度的杆子并非都能搭成三角架——杆长必须满足"短 + 短 > 长"。

三角形的分类

按边分：

  • 不等边三角形：三条边两两不等。
  • 等腰三角形：有两条边相等；相等的两边叫腰，另一边叫底，两腰的夹角叫顶角，腰与底的夹角叫底角。
  • 等边三角形：三条边都相等，是特殊的等腰三角形。

按角分：

  • 锐角三角形：三个角都是锐角（< 90°）。
  • 直角三角形：有一个角是直角（= 90°），夹直角的两边叫直角边，直角所对的边叫斜边。
  • 钝角三角形：有一个角是钝角（> 90°）。
几何/物理含义：分类不是死记，而是"给图形贴标签以便识别"。工程里说"直角三角形"立刻对应"直角、斜边、可套勾股定理"；说"等腰三角形"立刻对应"两条边一样长、受力对称"。

11.2 三角形的角（内角和与外角）

三角形内角和定理

定理：三角形的三个内角之和等于 180°。

∠A + ∠B + ∠C = 180°

证明思路（转化到"平角"）：过顶点 A 作 BC 的平行线，把 ∠B、∠C 通过"同位角/内错角"搬运到 A 点处，三个角拼成一条直线，恰好是一个平角 180°。

   （过 A 作 BC 的平行线）
      ∠B'  A  ∠C'  /
        ○───○───○  /
      \    / \    //
       ∠B  ∠A  ∠C
   ∠B' = ∠B（内错角），∠C' = ∠C（内错角）
   ∠B' + ∠A + ∠C' = 平角 = 180°
几何含义：把三个角"剪下来、搬到一个顶点上"恰好拼成一个平角——说明三角形的三个角加起来"刚好铺满半圈"。这是"角的搬运"思想的第一次登场：用平行线把分散的角集中到一点。
物理含义：内角和 180° 决定了"三个内角不能各自为政"——一个角变大，必然有别的角变小，总量守恒。航海与测量里，只要测出两个角，第三个角就被"锁定"，等于 180° 减去前两个之和，这是三角测量的基石。

推论 1：直角三角形的两锐角互余

若 ∠C = 90°，则 ∠A + ∠B = 180° − 90° = 90°，即两锐角互余。

物理含义：一个直角 + 两个锐角共 180°，就像一块"90° 的角尺"加"两个能拼成 90° 的小角"。实际中常用于已知一个锐角求另一个：如坡度 30° 的斜面，其与水平面的另一个锐角就是 60°。

推论 2：三角形的外角

定义：三角形的一边与另一边的延长线组成的角，叫做三角形的外角。

  • 每个顶点有两个互为对顶角的外角，通常各取一个。
  • 一个外角与它相邻的内角互补：外角 + 相邻内角 = 180°。

外角性质：

三角形的一个外角 = 与它不相邻的两个内角之和
∠ACD（外角）= ∠A + ∠B

由此进一步推出：三角形的一个外角大于任何一个与它不相邻的内角。

几何含义：外角是"站在三角形外看向内"的视角。它等于不相邻两内角之和，本质仍是内角和 180° 的另一种写法：外角把"补角"转成了"两个角之和"。
物理含义：想象沿三角形边界走一圈，每到一顶点都要"拐一个外角"。三个外角加起来正好是绕了一整圈 360°——这就是外角概念背后的"转向"直觉，也是下节"多边形外角和恒为 360°"的直接来源。

11.3 三角形的高、中线、角平分线

三角形有三类重要的特殊线段，都从顶点出发、作用在对边上，但"作用方式"各不相同。

高（从顶点到对边的垂线段）

定义：从三角形一个顶点向它的对边（或对边所在直线）作垂线，顶点与垂足之间的线段叫做三角形的高。

  • 每条边都对应一条高，所以三角形有三条高。
  • 锐角三角形的三条高都在形内；直角三角形的两条直角边互为高（斜边上的高在形内）；钝角三角形有两条高落在形外（延长线上）。
  • 三条高（或高所在直线）交于一点，叫三角形的垂心。
几何含义：高 = "顶点到对边的最短距离"。因为垂线段最短，高给出了三角形"从顶到边"的垂直跨度，是计算面积（底 × 高 ÷ 2）的核心。
物理含义：高就是"铅垂高度/落差"。一座三角形断面的山，高代表从山顶到山脚水平基线的竖直高度；坡度、水压、势能（mgh）都直接依赖这个垂直高度。

中线（顶点到对边中点的连线）

定义：连接三角形一个顶点与它对边中点的线段叫做三角形的中线。

  • 三角形有三条中线，且三条中线相交于一点，这点叫三角形的重心。
  • 重心把每条中线分成 2 : 1 两段（从顶点到重心的长度是整条中线的 2/3），这个比例到后面会系统学习。
几何含义：中线把三角形分成两个"等底同高"的三角形，因此中线平分三角形面积——这是"面积守恒"的直观体现。
物理含义：重心是三角形质量的平衡点：用一根针顶在重心处，三角形纸片可以保持水平不倾倒。三条中线的交点之所以是重心，正因为每条中线都把三角形分成"质量相等"的两半，三者的公共交点就是整块质量的集中点。

角平分线（平分内角的线段）

定义：从三角形一个内角的顶点出发，把这个角分成两个相等的角、且与对边相交的线段，叫做三角形的角平分线。

  • 注意与"角的平分线"（一条射线）区分：三角形的角平分线是一条线段，顶点到对边的部分。
  • 三条角平分线相交于一点，这点叫三角形的内心（是内切圆的圆心）。
几何含义：角平分线上的任意点到角两边的距离相等——它是"关于角对称"的那条对称轴（方向）。三条角平分线交于一点，意味着存在一个点到三边距离都相等，这正是内切圆的圆心。
物理含义：角平分线是"角"的镜面对称轴：光线从一个镜面角的两边反射时，入射与反射路径关于角平分线对称。也可理解为"公平地劈开一个角"——把 60° 一分为二成两个 30°。

小结：三条高交于垂心（垂直方向的汇合），三条中线交于重心（质量平衡点），三条角平分线交于内心（到三边等距）。三者"都是三条，都交于一点"，但几何与物理角色完全不同。

11.4 三角形的稳定性

结论：三角形具有稳定性——当三角形的三条边长确定时，三角形的形状和大小就唯一确定，不会变形；而四边形等多边形具有不稳定性，容易变形。

几何含义：这是"SSS 全等"的直接结果：三边一旦给定，三个顶点之间的距离被完全锁定，三角形被"钉死"。三条边像三根互相对顶的杆，谁也动不了——所以三角形是唯一由"边"就能唯一决定形状的多边形（四边形给四边还能"压扁"成不同形状，如正方形可压成菱形）。
物理含义：三角形是工程上最坚固的骨架单元。三个节点互相牵制，任一处受力都会沿三条边传递并抵消，不会像四边形那样"平行四边形式"地塌陷。因此：
  • 自行车车架、篮球架、桥梁桁架、屋顶屋架都用三角形结构加固。
  • 要把不稳定的四边形加固，只需在一条对角线上加一根斜杆，把它拆成两个三角形。
  • 活动衣架、伸缩门、起重机伸缩臂则故意利用四边形的可变形性，实现伸缩。

一句话：三角形"越受力越稳"，四边形"一推就变形"——前者用来加固，后者用来活动。

11.5 多边形的内角和与外角和

多边形与对角线

  • 在同一平面内，由若干条线段首尾顺次相接组成的封闭图形叫多边形（如四边形、五边形、六边形……）。
  • 连接多边形不相邻两个顶点的线段叫对角线。从 n 边形的一个顶点可引出 (n − 3) 条对角线。
  • n 边形共有对角线 n(n − 3) ÷ 2 条。

多边形内角和

从 n 边形的一个顶点引出所有对角线，可把它分成 (n − 2) 个三角形，每个三角形内角和 180°，于是：

n 边形内角和 = (n − 2) × 180°
多边形边数 n分成三角形数内角和
三角形31(3−2)×180° = 180°
四边形42(4−2)×180° = 360°
五边形53(5−2)×180° = 540°
六边形64(6−2)×180° = 720°
n 边形nn − 2(n−2)×180°
几何含义："把多边形切成三角形"是几何里最常用的降维手段——每切一刀（加一条对角线）就多出一个三角形、多 180°。三角形是"180° 的最小单元"，任意多边形的内角和就是"三角形数 × 180°"。
物理含义：内角和随边数线性增长：边数越多，图形越接近"圆"，各内角越接近平角。也可理解为把多边形"铺满"需要多少个 180° 的"半圈"。

多边形外角和（恒为 360°）

在 n 边形的每个顶点各取一个外角，这些外角的和恒等于 360°，与边数无关。

任意 n 边形的外角和 = 360°

为什么？每个顶点处"内角 + 外角 = 180°"，n 个顶点共 180°×n；减去内角和 (n−2)×180°，剩下：

外角和 = n×180° − (n−2)×180° = 360°
几何含义：想象一个人沿多边形边界走一圈，每到一顶点就"转一个外角"，走完一整圈、方向回到原位，累计恰好转过 360°。边数再多、形状再怪，转一整圈永远是 360°。
物理含义：外角和 = "转一整圈"的物理事实：无论路径是三角形、五边形还是圆形，绕行一周的方向改变总量都是 360°。汽车沿任意闭合跑道跑一圈，累计转向角恒为 360°。

正多边形：各边相等、各角也相等的多边形叫正多边形。正 n 边形每个内角 = (n−2)×180° ÷ n，每个外角 = 360° ÷ n。例：正六边形每个外角 60°、每个内角 120°。

典型例题（自测）

  1. 下列各组线段能否组成三角形？① 4、5、9；② 3、4、5；③ 5、5、9。并说明理由。
  2. 三角形两边分别为 5 和 8，求第三边 c 的取值范围；若第三边取整数，有哪几种可能？
  3. 在 △ABC 中，∠A = 50°，∠B = 60°，求 ∠C，并求 ∠C 的外角。
  4. 直角三角形的一个锐角为 37°，求另一个锐角。
  5. 在 △ABC 中，∠A = 40°，∠B = 70°，求 ∠ACB 的外角，并判断该外角与 ∠A、∠B 的大小关系。
  6. 求一个八边形的内角和；若它是正八边形，求每个内角与每个外角。
  7. 一个多边形的内角和等于 1440°，它是几边形？它的外角和是多少？

常见误区

  • ❌ "只要三条线段就能组成三角形" → ❌ 必须满足"任意两边之和大于第三边"（只需验证短+短>长）。如 4、5、9 不能组成三角形。
  • ❌ "第三边只要大于两边之差或小于两边之和即可" → ❌ 要同时满足两个条件，即 |a−b| < c < a+b。
  • ❌ "三角形内角和有时不是 180°" → ❌ 任何平面三角形的内角和恒为 180°，这是定理。
  • ❌ "外角等于相邻内角的补角，所以外角与相邻内角相等" → ❌ 外角与相邻内角互补（和为 180°），不是相等；外角等于不相邻的两个内角之和。
  • ❌ "钝角三角形的三条高都在三角形内" → ❌ 钝角三角形有两条高在形外（要延长对边）。
  • ❌ "三角形角平分线与角的平分线是一回事" → ❌ 角的平分线是射线，三角形的角平分线是线段（顶点到对边之间）。
  • ❌ "四边形也有稳定性" → ❌ 四边形具有不稳定性，会变形；三角形才稳定。
  • ❌ "多边形外角和随边数变化" → ❌ 任意多边形的外角和恒为 360°，与边数无关。
  • ❌ "n 边形内角和是 n×180°" → ❌ 是 (n−2)×180°，少算了两个"顶点处的半圈"。

第三边满足 |7 − 3| < c < 7 + 3，即 4 < c < 10；c 为整数，故 c = 5、6、7、8、9。物理含义：三根杆只有「较短两根之和 > 最长一根」时才能首尾相接围成一个圈，否则最短两根够不着、结构塌成一条直线。

查看第3题答案

∠C = 180° − 80° − 45° = 55°。∠C 处外角 = 180° − 55° = 125°（也等于不相邻两内角之和：80° + 45° = 125°）。

查看第4题答案

另一个锐角 = 90° − 28° = 62°。因内角和恒为 180°，直角占去 90°，两锐角互余。测量时只要测出两个角，第三个角 = 180° − 前两角之和，被「锁定」，无需再测。

查看第5题答案

C 处外角 = ∠A + ∠B = 35° + 55° = 90°。该外角大于 ∠A（35°）和 ∠B（55°），即外角大于任何一个不相邻内角。

查看第6题答案

正十二边形：内角和 = (12 − 2) × 180° = 1800°；每个内角 = 1800° ÷ 12 = 150°；每个外角 = 360° ÷ 12 = 30°。若内角和 1980°，则 (n − 2) × 180° = 1980°，n − 2 = 11，n = 13，是十三边形；外角和恒为 360°。
