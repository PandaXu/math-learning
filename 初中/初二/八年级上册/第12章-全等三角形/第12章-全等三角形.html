第12章 全等三角形

初中 / 初二 / 八年级上册

一句话总纲：全等 = 「平移、旋转、翻折之后能完全重合」的两个图形。学完本章，你要在脑中把"两个三角形"想象成"同一个刚体（不变形的硬纸片）被搬动、转动、翻面后落在不同位置"——所谓判定定理（SSS/SAS/ASA/AAS/HL），本质都是在回答一个问题：最少需要几个"尺寸数据"才能锁死一个三角形的形状与大小？

12.1 全等三角形的概念与性质

什么是全等？

全等形：能够完全重合的两个图形叫做全等形。用符号 ≌ 表示，读作"全等于"。两个三角形全等，记作 △ABC ≌ △DEF。

几何含义：全等 = 形状相同 且 大小相同。"完全重合"意味着两个图形之间只相差一次刚体运动——平移、旋转、翻折（轴对称）中的一种或组合。所以全等三角形是"同一个三角形换了位置、朝向或正反面"。
物理含义：全等对应"刚体不变性"。一块不会变形的硬纸片、一块钢板、一个机械零件，无论你怎么搬（平移）、怎么转（旋转）、怎么翻面（镜面反射），它的形状和大小都不变。工程上两个"全等"的零件可以互相替换、互换安装；物理里"刚体"就是内部任意两点距离永远不变的物体——全等正是"距离保持不变"这一刚性条件的图形化表达。

对应顶点、对应边、对应角

两个全等三角形重合时，互相重合的顶点、边、角分别叫做对应顶点、对应边、对应角。写 △ABC ≌ △DEF 时，字母顺序必须与对应关系一致：A 对 D、B 对 E、C 对 F。

△ABC ≌ △DEF   ⟹   AB = DE,  BC = EF,  CA = FD
                  ∠A = ∠D,  ∠B = ∠E,  ∠C = ∠F

全等三角形的性质（判定之后要"用"的东西）

  • 对应边相等：全等三角形的三组对应边分别相等。
  • 对应角相等：全等三角形的三组对应角分别相等。
  • 全等三角形的周长相等、面积相等（反之：面积相等的两个三角形不一定全等）。
  • 对应的高、中线、角平分线也分别相等。
核心用法："全等"是一座桥梁——我们无法直接量到的边或角，通过证明两个三角形全等，就能把"已知的边/角"搬运到"未知的边/角"上。证明题的思路是：找全等 → 得对应元素相等 → 证出结论。

12.2 判定：SSS（边边边）

定理：三边分别相等的两个三角形全等，简写为 SSS（Side-Side-Side）。

在 △ABC 与 △DEF 中：
  AB = DE
  BC = EF   ⟹  △ABC ≌ △DEF  (SSS)
  CA = FD
几何含义：三条边的长度一旦确定，三角形就被完全锁死了——形状和大小都唯一。三条边是"刚性三角"的全部信息：给你三根确定长度的木条，只能拼出一种三角形（最多差一个翻面）。
物理含义：这就是三角形的稳定性。三根杆件两端铆接后，框架不会变形，因为三边长度固定 ⟹ 三个角度也自动固定。所以自行车的车架、屋顶的桁架、起重机的吊臂、桥梁的钢架都用三角形结构来抗变形。而四边形只有四边确定时仍可被压扁（平行四边形可活动），所以窗框、伸缩门要加斜撑（对角线）拆成三角形才能稳固。

12.3 判定：SAS（边角边）

定理：两边和它们的夹角分别相等的两个三角形全等，简写为 SAS（Side-Angle-Side）。

在 △ABC 与 △DEF 中：
  AB = DE
  ∠A = ∠D    （∠A 是 AB 与 AC 的夹角）
  AC = DF    ⟹  △ABC ≌ △DEF  (SAS)
几何含义："两条边 + 它们张开的那个角"相当于极坐标定位：从一个顶点出发，给定一条边的长度（半径）、两条边之间的张角（方向）、再给定另一条边的长度，第三个顶点的位置就被唯一确定。两边夹角 = 一个"叉开的扇形"被完全钉死。
物理含义：这正是"两个力（矢量）合成"的图形。两个力的大小（两边）和它们之间的夹角（夹角）一旦确定，由平行四边形/三角形法则得到的合力大小与方向就唯一确定。同理，机械臂的两段连杆长度和关节转角确定后，末端（抓手）的位置也就唯一确定——SAS 是"两个长度 + 一个转角确定姿态"的原理。

⚠️ 边角边必须是"夹角"：若相等的角不是两边的夹角（是其中一边的对角），记作 SSA，它不能判定全等（详见"常见误区"）。

12.4 判定：ASA 与 AAS

ASA（角边角）

定理：两角和它们的夹边分别相等的两个三角形全等，简写为 ASA（Angle-Side-Angle）。

在 △ABC 与 △DEF 中：
  ∠B = ∠E
  BC = EF    （BC 是 ∠B 与 ∠C 的夹边）
  ∠C = ∠F    ⟹  △ABC ≌ △DEF  (ASA)
几何含义："两个角 + 中间夹着的那条边"确定一个三角形：两个角锁定了两条边的方向，夹边锁定了它们之间的距离，于是两条射线的交点被唯一确定。
物理含义：这是三角测量（triangulation）的原理。已知一条基线（夹边）的长度，再测得它两端到同一个目标点的两个方向角（两个角），就能唯一算出目标点的位置——这正是测绘、导航、GPS 定位、雷达测距背后的几何：一个长度 + 两个角度 = 确定一个点。

AAS（角角边）

定理：两角和其中一个角的对边分别相等的两个三角形全等，简写为 AAS（Angle-Angle-Side）。

在 △ABC 与 △DEF 中：
  ∠A = ∠D
  ∠B = ∠E
  BC = EF    （BC 是 ∠A 的对边）
  ⟹  △ABC ≌ △DEF  (AAS)
为什么 AAS 也成立？三角形内角和恒为 180°，已知两个角，第三个角就自动确定（∠C = 180° − ∠A − ∠B），于是"两角 + 一角对边"可以转化为"两角 + 夹边"的 ASA。所以 AAS 本质是 ASA 的推论。
物理含义：只要"两个方向角 + 其中一条边的长度"确定，物体的形状就被锁定——多余的信息（第三个角）是冗余的，因为三角形内角和守恒（180°）已经给了你第三条信息。这对应物理中"约束条件"的思想：系统的自由度 = 变量个数 − 约束个数。

12.5 判定：HL（斜边、直角边）

定理：斜边和一条直角边分别相等的两个直角三角形全等，简写为 HL（Hypotenuse-Leg）。只适用于直角三角形。

在 Rt△ABC 与 Rt△DEF 中，∠C = ∠F = 90°：
  斜边 AB = 斜边 DE
  直角边 BC = 直角边 EF   ⟹  Rt△ABC ≌ Rt△DEF  (HL)
为什么 HL 能行？直角三角形中，斜边 c 和一条直角边 a 确定后，另一条直角边 b = √(c² − a²) 由勾股定理唯一确定，于是三边都定了 ⟹ 回到 SSS。
物理含义：这是勾股定理（直角三角形三边关系）的直接应用。物理中"斜边 = 合力/合位移，直角边 = 两个互相垂直的分量"：只要"合量（斜边）"和"一个直角分量"确定，另一个垂直分量的大小就被唯一确定。所以 HL 本质是"直角三角形比普通三角形多一个 90° 约束，于是少需要一个数据"——约束越多，所需信息越少。

五种判定速查

判定需要相等的量适用一句话记法
SSS三边任意三角形三边定形（稳定性）
SAS两边 + 夹角任意三角形两长一夹
ASA两角 + 夹边任意三角形两角夹边
AAS两角 + 一角对边任意三角形两角非夹边
HL斜边 + 一条直角边直角三角形直角专用

不能判定全等的组合

  • SSA（边边角）：两边和其中一边的对角相等，不能判定全等——会出现"两个不同三角形满足同样条件"（歧义）。
  • AAA（角角角）：三个角相等只能说明"形状相同"，不能说明"大小相同"，那只是相似，不是全等。

12.6 角平分线的性质

性质定理

角平分线上的点到这个角的两边的距离相等。

若 OC 是 ∠AOB 的平分线，P 在 OC 上，
PD ⊥ OA 于 D，PE ⊥ OB 于 E，
则 PD = PE。
几何含义：角平分线是"到角两边距离相等的点的集合（轨迹）"。它把角"等分"成两个相等的角，而"到两边距离相等"这条性质，让角平分线成为角内部的等距线。
物理含义：角平分线是一条对称轴（把一个角沿角平分线对折，两边完全重合）。在光学里，平面镜反射满足"入射角 = 反射角"，而法线正是入射线与反射线夹角的角平分线；在机械里，楔形、锥形、刀具的对称刃口都沿角平分线分布，保证两侧受力对称。

判定定理（逆定理）

角的内部，到角的两边距离相等的点，在这个角的平分线上。

若 P 在 ∠AOB 内部，且 PD ⊥ OA、PE ⊥ OB，PD = PE，
则 P 在 ∠AOB 的平分线上（OP 是角平分线）。
为什么成立？构造两个直角三角形（共用斜边 OP，一组直角边 PD = PE），由 HL 可得 Rt△OPD ≌ Rt△OPE，于是 ∠POD = ∠POE，即 OP 平分角。这是"性质"与"判定"互相印证的好例子：用 HL 证明全等，是全等与角平分线的交汇点。

角平分线的尺规作法（几何含义落地）

角平分线可以只用圆规和直尺作出，其依据正是 SSS：

  1. 以顶点 O 为圆心，任意长为半径画弧，交 OA 于 D、OB 于 E。
  2. 分别以 D、E 为圆心，相同半径（大于 DE 的一半）画弧，两弧交于 P。
  3. 连接 OP，则 OP 是 ∠AOB 的平分线。
为什么对？OD = OE（同一半径），DP = EP（同一半径），OP = OP（公共边），由 SSS 得 △ODP ≌ △OEP，故 ∠DOP = ∠EOP。作图的每一步都在"构造全等"。

典型例题（自测）

  1. 如图（自画），已知 AB = AC，D 是 BC 的中点。求证：△ABD ≌ △ACD，并说明 ∠B = ∠C。
  2. 已知 AB = DE，AC = DF，∠A = ∠D。求证：BC = EF（用 SAS，说明用的是"夹角"）。
  3. 已知 ∠B = ∠E，BC = EF，∠C = ∠F。求证：△ABC ≌ △DEF，写出对应边。
  4. 已知 Rt△ABC 与 Rt△DEF 中，∠C = ∠F = 90°，斜边 AB = DE，直角边 BC = EF。求证：AC = DF。
  5. 已知 OC 平分 ∠AOB，P 在 OC 上，PD ⊥ OA 于 D，PE ⊥ OB 于 E。求证：PD = PE，并说出依据。
  6. 已知 △ABC 中，AD 是 BC 边上的中线，且 AB = AC。求证：AD 平分 ∠BAC（提示：用 SSS 先证 △ABD ≌ △ACD）。

常见误区

  • ❌ "两边及一边的对角相等（SSA）能判全等" → ❌ SSA 不能判定，会产生两个不同三角形（歧义），正确的是 SAS（夹角）。
  • ❌ "三个角相等（AAA）就是全等" → ❌ 那只是相似（形状同、大小可能不同），全等还要大小相等。
  • ❌ "HL 对任意三角形都适用" → ❌ HL 只适用于直角三角形，斜边、直角边是直角三角形特有的名称。
  • ❌ "全等符号 ≌ 的字母顺序随便写" → ❌ 顺序必须与对应关系一致，乱写会搞错对应边、对应角。
  • ❌ "面积相等（或周长相等）的两个三角形一定全等" → ❌ 反过来不成立：面积相等 ≠ 全等（底高乘积相同即可，形状可不同）。
  • ❌ "角平分线上的点到角两边距离相等，所以角平分线上的点就是中点" → ❌ 是"到两边的垂线段（距离）相等"，不是到角两边的端点或到边上任意点的连线相等。

本章练习卷（含答案）

一、练习题

  1. （对应元素）若 △ABC ≌ △DEF，且 ∠A = 40°，∠B = 60°，AB = 5 cm。请写出 ∠D、∠E 的度数以及边 DE 的长度，并说明依据。
  2. （SSS / 稳定性）三根木条的长度分别为 3 cm、4 cm、5 cm，钉成一个三角形。用同样三根木条再钉一个三角形，这两个三角形一定全等吗？为什么？（提示：说出判定定理，并联系"三角形稳定性"。）
  3. （SAS vs SSA）已知 AB = DE = 6，AC = DF = 5。请判断：下列哪个条件能保证 △ABC ≌ △DEF？① ∠A = ∠D；② ∠B = ∠E。说明理由。
  4. （ASA / 三角测量）在 △ABC 与 △DEF 中，∠B = ∠E = 50°，BC = EF = 8，∠C = ∠F = 70°。求证 △ABC ≌ △DEF，并写出对应边。
  5. （HL）在 Rt△ABC 与 Rt△DEF 中，∠C = ∠F = 90°，斜边 AB = DE = 13，直角边 BC = EF = 5。求另一条直角边 AC 的长度，并说明两个三角形是否全等、依据是什么。
  6. （角平分线性质）OC 是 ∠AOB 的平分线，P 在 OC 上，PD ⊥ OA 于 D，PE ⊥ OB 于 E。若 PD = 4，求 PE，并说明依据。

二、参考答案（点击展开）

查看第1题答案

∠D = 40°，∠E = 60°，DE = 5 cm。依据：全等三角形的对应角相等、对应边相等；△ABC ≌ △DEF 时 A 对 D、B 对 E、AB 对 DE。

查看第2题答案

一定全等。三边分别相等（3、4、5 对 3、4、5），由 SSS（边边边）可判定全等。三边一旦确定，三角形的形状和大小就被唯一锁死——这正是三角形的稳定性：三根定长木条只能拼出一种三角形。

查看第3题答案

① ∠A = ∠D 能判定（两边 6、5 与它们的夹角 ∠A 对应相等，用 SAS）；② ∠B = ∠E 不能判定——此时相等的角是边 AC 的对角，属于 SSA（边边角），会产生两个不同三角形，不能判定全等。

查看第4题答案

由 ∠B = ∠E、BC = EF（两角的夹边）、∠C = ∠F，满足 ASA，故 △ABC ≌ △DEF。对应边：AB = DE、BC = EF、AC = DF。

查看第5题答案

由勾股定理：AC = √(13² − 5²) = √(169 − 25) = √144 = 12。两个三角形全等，依据 HL（斜边和一条直角边分别相等的两个直角三角形全等）；全等后对应直角边 AC = DF = 12。

查看第6题答案

PE = 4。依据角平分线性质定理：角平分线上的点到角两边的距离相等。P 在平分线 OC 上，PD、PE 分别是到 OA、OB 的距离，故 PD = PE。
