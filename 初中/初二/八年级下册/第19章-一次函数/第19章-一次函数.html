第19章 一次函数

初中 / 初二 / 八年级下册

一句话总纲：一次函数 y = kx + b 的图象永远是一条直线：k 是这条直线的"倾斜程度"（斜率），决定它是上升还是下降、陡还是缓；b 是它与 y 轴交点的纵坐标（截距），决定它在坐标系中的上下位置。学完本章，你要能把"匀速运动、均匀变化"这类最稳定、最规律的现实变化，一眼画成一条直线，并且从这条直线里读出"变化的快慢与起点"。

19.1 函数与变量

常量与变量

在一个变化过程中，我们把数值发生变化的量叫做变量，把数值始终不变的量叫做常量。

变化过程常量变量
汽车以 60 km/h 匀速行驶，路程 s = 60t速度 60（km/h）时间 t、路程 s
圆的面积 S = πr²圆周率 π半径 r、面积 S
单价 5 元/支，买 x 支笔付 y 元，y = 5x单价 5数量 x、总价 y

关键：常量和变量是相对的，要放在"同一个变化过程"里看。上表中"速度 60"在"匀速行驶"这个语境下是常量，但若讨论"汽车变速行驶"，速度就变成了变量。

函数的概念（本章的地基）

定义：一般地，在一个变化过程中，如果有两个变量 x 和 y，并且对于 x 的每一个确定的值，y 都有唯一确定的值与其对应，那么就说 x 是自变量，y 是 x 的函数。当 x = a 时对应的 y = b，b 就叫做当自变量取 a 时的函数值。

  • 函数是一种"对应关系/法则"，不是一个具体的数：输入一个 x，按规则唯一地吐出输出 y。
  • 判断是否为函数的唯一标准：给定一个 x，y 是否唯一确定。一个 x 只能对应一个 y（但允许不同的 x 对应同一个 y）。
  • 如 y = x² 中 x = 2 只能得到 y = 4，是函数；而圆的方程 x² + y² = 1 中 x = 0 对应 y = 1 和 y = -1 两个值，y 不是 x 的函数。
几何/结构含义：函数是一台"确定性机器"——同一个输入永远产出同一个输出，不允许含糊。这正是数学描述自然规律的前提：现实世界的规律必须"可重复、可预测"，函数就是"可预测性"的数学化身。

函数的三种表示法

表示法形式优点缺点
解析式法（关系式法）y = 2x + 1简洁、能算任意值、便于推理不够直观
列表法把若干组对应值列成表对应值一目了然只能列有限组，看不出整体趋势
图象法在坐标平面描出点连成图形直观、能看出整体变化趋势读数不够精确

函数图象：把"关系"画成"图形"

定义：对于一个函数，如果把自变量与函数的每对对应值分别作为点的横、纵坐标，那么坐标平面内由这些点组成的图形，就是这个函数的图象。

画函数图象的一般步骤：①列表 → ②描点 → ③连线。

几何含义：函数图象 = 满足关系式的所有点的集合（轨迹）。两条等价的性质缺一不可：①图象上每一个点都满足函数关系式；②满足关系式的每一个点都在图象上。图象和关系式是"同一个东西的两种写法"——数（式子）与形（图形）在这里完成了统一。
物理含义：函数描述一个"变化过程"，图象就是把这个过程"拍成一张照片"：横轴是自变量（通常是时间、路程等"原因量"），纵轴是因变量（"结果量"）。图象的每一段升降，都对应现实中"变快、变慢、变大、变小"的具体事件。

19.2 正比例函数

定义

形如 y = kx（k 是常数，k ≠ 0）的函数叫做正比例函数，其中 k 叫做比例系数。

  • 抓住三点：① x 的次数是 1；② 系数 k ≠ 0；③ 没有常数项（截距为 0）。
  • 等价形式：两个量成正比例 ⟺ 它们的比值恒定，y/x = k（x ≠ 0）。

图象：一条经过原点的直线

正比例函数的图象是一条经过原点 (0, 0) 的直线。因为只要再确定除原点外的一个点，就能画出整条直线，所以画正比例函数常取 (0, 0) 和 (1, k) 两点。

例：y = 2x        过 (0,0) 与 (1,2)
     y = -x        过 (0,0) 与 (1,-1)

    y = 2x（上升，k>0）     y = -x（下降，k<0）
          ↗                    ↘

性质：k 的符号与大小决定一切

k 的取值图象经过增减性图象走势
k > 0第一、三象限y 随 x 增大而增大从左向右上升
k < 0第二、四象限y 随 x 增大而减小从左向右下降

此外，|k| 决定直线的倾斜程度：|k| 越大，直线越"陡"（越靠近 y 轴）；|k| 越小，直线越"平缓"（越靠近 x 轴）。

几何含义（斜率 k 的诞生）：在直线 y = kx 上任取一点 (x, y)（原点除外），都有 k = y/x，也就是"纵坐标 ÷ 横坐标"。它度量的是：横坐标每前进 1 个单位，纵坐标上升（或下降）k 个单位——这就是斜率（倾斜的"坡度"）。k 的正负决定"朝上还是朝下"，|k| 的大小决定"爬坡有多陡"。
物理含义（正比 = 均匀的稳定关系）：正比例函数刻画"两个量同步缩放"：s = vt（匀速直线运动中，时间翻倍路程就翻倍，速度 v 是比例系数）；总价 = 单价 × 数量（单价一定，总价与数量成正比）；F = kx（胡克定律，弹簧伸长量 x 与弹力 F 成正比）。它们共同的特征是比值恒定、没有"起步成本"——从 0 开始均匀增长。

19.3 一次函数的图象与性质

定义

形如 y = kx + b（k、b 是常数，k ≠ 0）的函数叫做一次函数。当 b = 0 时，y = kx，所以正比例函数是一次函数的特殊情况（截距为 0 的一次函数）。

  • 抓住两点：① 自变量 x 的次数是 1；② 系数 k ≠ 0。常数项 b 可以为 0，也可以为任何数。
  • 若 k = 0，则 y = b 是常数函数（图象是一条水平直线），它不再是"一次"函数。

图象与两个"定位参数"

一次函数的图象是一条直线（不经过原点的，一般直线）。这条直线完全由 k 和 b 两个数确定：

  • k（斜率）决定直线的倾斜方向与陡峭程度：k > 0 上升，k < 0 下降，|k| 越大越陡。
  • b（截距）决定直线与 y 轴交点的位置：直线必过点 (0, b)，即 b 是直线与 y 轴交点的纵坐标。
  • 与 x 轴交点：令 y = 0，解得 x = -b/k，即交点为 (-b/k, 0)。

平移关系：正比例函数"上下平移"得到一次函数

y = kx        （过原点的直线）
  │  当 b > 0 时，向上平移 b 个单位
  │  当 b < 0 时，向下平移 |b| 个单位
  ▼
y = kx + b

记忆口诀：一次函数就是"正比例函数这条直线，整体往上（或往下）搬了 b 个单位"。k 不变则直线的倾斜方向和陡峭程度不变，平移只改变"过不过原点"。

几何含义：这是本章最重要的"看图说话"能力——k 管"斜不斜、朝哪斜、多斜"，b 管"高不高、低不低"。两个参数各司其职：改变 k 是转动这条直线，改变 b 是上下平移这条直线。反之，看到一条直线，你就能读出它的斜率与截距，进而写出它的解析式。

性质：k、b 符号与图象所在象限

k 的符号b 的符号图象经过的象限增减性
k > 0b > 0第一、二、三象限y 随 x 增大而增大
k > 0b = 0第一、三象限y 随 x 增大而增大
k > 0b < 0第一、三、四象限y 随 x 增大而增大
k < 0b > 0第一、二、四象限y 随 x 增大而减小
k < 0b = 0第二、四象限y 随 x 增大而减小
k < 0b < 0第二、三、四象限y 随 x 增大而减小

画法：两点确定一条直线

直线由两点唯一确定，所以画一次函数只需取两个点（通常取它与坐标轴的两个交点最省事）：

  1. 令 x = 0，得 y = b，描出点 (0, b)；
  2. 令 y = 0，得 x = -b/k，描出点 (-b/k, 0)；
  3. 过这两点画直线并延长。
例：画 y = 2x + 4
    x = 0 → y = 4     点 (0, 4)
    y = 0 → x = -2    点 (-2, 0)
    过 (0,4) 与 (-2,0) 画直线即可。

待定系数法：由两点求解析式

已知直线经过两点求解析式，设 y = kx + b，把两点坐标代入，得到关于 k、b 的二元一次方程组，解出 k、b 即得解析式。

例：直线过 (1, 3) 和 (2, 5)，求解析式。
    设 y = kx + b，代入：
      3 = k + b
      5 = 2k + b
    解得 k = 2，b = 1  →  y = 2x + 1

更本质地，斜率可以直接由两点算出：k = (y₂ − y₁)/(x₂ − x₁)，这是"纵坐标的增量 ÷ 横坐标的增量"，与前面的"坡度"定义完全一致。

几何含义（斜率的完整定义）：直线上任意两点 (x₁, y₁)、(x₂, y₂)（x₁ ≠ x₂），斜率 k = (y₂ − y₁)/(x₂ − x₁) = Δy/Δx。它回答的问题永远是同一个："横坐标每增加 1，纵坐标平均变化多少？"所以直线上升时 k 为正、下降时 k 为负、越陡 |k| 越大，全部统一在这一个式子之下。
物理含义（线性变化 = 均匀变化）：一次函数描述"变化速率恒定"的现象——物理中大量定律都是它：s = vt + s₀（匀速直线运动的位移公式，初位置 s₀ 是截距，速度 v 是斜率）；v = v₀ + at（匀加速运动，初速度 v₀ 是截距，加速度 a 是斜率）；华氏温度 F = (9/5)C + 32（截距 32 是"冰点偏移"）。它们的共同点：每单位自变量变化带来的因变量变化量固定不变，图象就是一条直线。

19.4 一次函数与方程、不等式

这一节是"数与形"结合的高潮：同一个式子，既可以当作"函数"看图象，也可以当作"方程"求根，还可以当作"不等式"求范围。

一次函数与一元一次方程

方程 kx + b = 0 的解，就是直线 y = kx + b 与 x 轴交点的横坐标。因为"函数值为 0"恰好意味着"图象上的点落在 x 轴上（纵坐标为 0）"。

y = 2x + 4 与 x 轴交点：令 2x + 4 = 0 → x = -2
  方程 2x + 4 = 0 的解就是 x = -2（交点横坐标）

一次函数与一元一次不等式

不等式 kx + b > 0 的解集，就是直线 y = kx + b 位于 x 轴上方的那一部分所对应的 x 的取值范围；kx + b < 0 对应直线在 x 轴下方的部分。

y = 2x + 4：
   2x + 4 > 0  ⟺  x > -2   （直线在 x 轴上方的部分）
   2x + 4 < 0  ⟺  x < -2   （直线在 x 轴下方的部分）

一次函数与二元一次方程组

每个二元一次方程都可化成一次函数形式（y = kx + b），其图象是一条直线；一个二元一次方程组的解，就是这两条直线的交点坐标。交点既满足第一条直线、又满足第二条直线，正是"公共解"。

  • 两直线相交（k 不相等）→ 方程组有唯一解（交点坐标）。
  • 两直线平行（k 相等、b 不等）→ 无交点 → 方程组无解。
  • 两直线重合（k、b 都相等）→ 无数交点 → 方程组有无穷多解。
几何含义：方程、不等式、函数三者的翻译字典——"求方程的解"= 找直线与 x 轴交点的横坐标；"解不等式"= 判断直线在 x 轴上方还是下方的那一段；"解方程组"= 找两条直线的公共点（交点）。解 = 交点（或交点的横坐标），解的集合 = 图象上满足条件的区域。
物理含义：这对应现实中的"临界值"与"比较"问题：方程的解是"何时达到某个状态"（如汽车何时行驶到 100 km）；不等式的解是"何时超过/低于某个状态"（如水温何时降到 50℃ 以下）；方程组的解是"两种变化何时相遇"（如两人何时何地追上）。解出它们，就是把"抽象的代数答案"翻译回"具体的时刻、位置、数量"。

本章 · 几何与物理含义总结

概念几何含义物理含义
函数自变量 x 到函数值 y 的"唯一对应"法则；图象是满足关系式的所有点组成的图形描述一个可预测的变化过程（输入→唯一输出）
正比例函数 y = kx过原点的直线；k = y/x = 斜率，决定倾斜方向与陡峭程度正比关系：匀速运动 s = vt、总价 = 单价 × 数量、胡克定律 F = kx
一次函数 y = kx + b一般直线；k 管"斜与陡"，b 管"与 y 轴交点(0,b)"均匀变化：s = vt + s₀、v = v₀ + at、华氏温度换算
斜率 kk = Δy/Δx，横坐标前进 1 时纵坐标的变化量；k>0 上升、k<0 下降、|k| 越大越陡变化速率（速度、加速度、单价、比例系数）
截距 b直线与 y 轴交点的纵坐标；上下平移的距离初始值 / 起点（初位置、初速度、起步成本）
一次函数图象的平移y = kx 沿 y 轴平移 |b| 个单位得到 y = kx + b给"均匀变化"加上一个非零起点
方程 kx + b = 0直线与 x 轴交点的横坐标达到"零点/基准状态"的时刻
不等式 kx + b > 0（或 < 0）直线在 x 轴上方（或下方）部分的 x 范围超过（或低于）某一状态的取值范围
二元一次方程组两条直线的交点坐标两种变化"相遇/相等"的时刻与位置

典型例题（自测）

  1. 判断下列关系式中哪些是一次函数、哪些是正比例函数：y = 2x、y = -3x + 1、y = x²、y = 1/x、y = 5。
  2. 已知 y = (m - 2)x + m² - 4 是正比例函数，求 m 的值。
  3. 画出 y = -2x + 4 的图象，写出它与两坐标轴的交点坐标，并说出 y 随 x 的增减性。
  4. 已知直线经过点 (2, 7) 和 (-1, -2)，用待定系数法求它的解析式。
  5. 求直线 y = 3x - 6 与 x 轴交点的横坐标，并直接写出不等式 3x - 6 > 0 的解集。
  6. 两条直线 y = 2x + 1 与 y = -x + 4 交于一点，求交点坐标（即方程组 y = 2x + 1、y = -x + 4 的解）。

常见误区

  • ❌ "正比例函数是一次函数，所以一次函数都是正比例函数" → ❌ 反了：正比例函数是一次函数，但一次函数不一定过原点；只有 b = 0 时一次函数才是正比例函数。
  • ❌ "k 的绝对值越大，直线越平缓" → ❌ |k| 越大直线越陡（越靠近 y 轴）；|k| 越小越平缓。
  • ❌ "b 是直线与 x 轴交点的坐标" → ❌ b 是直线与 y 轴交点的纵坐标，交点写成 (0, b)；与 x 轴交点是 (-b/k, 0)。
  • ❌ "k < 0 时，b 也一定 < 0" → ❌ k 和 b 互相独立：k < 0、b > 0 时直线仍经过第一、二、四象限（如 y = -x + 3）。
  • ❌ "把 y = 5 也当作一次函数" → ❌ y = 5 是常数函数（k = 0），不是一次函数；一次函数要求 k ≠ 0。
  • ❌ "解不等式 2x + 4 > 0 就是求直线与 x 轴交点" → ❌ 与 x 轴交点是解方程 2x + 4 = 0；解不等式 2x + 4 > 0 要取直线在 x 轴上方部分对应的 x 范围（x > -2）。

本章练习卷（含答案）

一、练习题

  1. 下列各式中，哪些是正比例函数？哪些是一次函数？（只填序号）① y = 3x ② y = -2x + 1 ③ y = x² ④ y = 4/x ⑤ y = -x
  2. 对于一次函数 y = -3x + 2，写出它的斜率 k 与截距 b，并求出图象与 y 轴、x 轴交点的坐标。
  3. 已知函数 y = 2x + 1：求当 x = 3 时的函数值，并判断点 (1, 3) 是否在它的图象上。
  4. 一次函数 y = kx + b 的图象经过点 (0, -2) 和 (3, 4)，用待定系数法求 k、b，并写出解析式。
  5. 已知直线 y = 2x - 6：①它与 x 轴交点的横坐标是多少？②不等式 2x - 6 > 0 的解集是什么？③这条直线经过哪些象限？
  6. 求直线 y = x + 1 与 y = -x + 3 的交点坐标，并说明这等价于解哪个二元一次方程组。

二、参考答案（点击展开）

查看第1题答案

正比例函数：①、⑤（形如 y = kx，k ≠ 0 且无常数项）；一次函数：①、②、⑤（形如 y = kx + b，k ≠ 0）。③是二次函数、④是反比例函数，都不是一次函数。

查看第2题答案

k = -3，b = 2。与 y 轴交点：令 x = 0，得 y = 2，即 (0, 2)；与 x 轴交点：令 y = 0，得 -3x + 2 = 0，解得 x = 2/3，即 (2/3, 0)。因 k < 0，y 随 x 增大而减小。

查看第3题答案

当 x = 3 时，y = 2×3 + 1 = 7。点 (1, 3)：代入得 y = 2×1 + 1 = 3，恰好等于该点纵坐标 3，所以 (1, 3) 在图象上。

查看第4题答案

设 y = kx + b。代入 (0, -2) 得 b = -2；代入 (3, 4) 得 4 = 3k - 2，解得 k = 2。故解析式为 y = 2x - 2。

查看第5题答案

①令 2x - 6 = 0，得 x = 3。②2x - 6 > 0 ⟺ x > 3（即直线位于 x 轴上方部分对应的 x 范围）。③k = 2 > 0、b = -6 < 0，故经过第一、三、四象限。

查看第6题答案

解方程组 y = x + 1、y = -x + 3：由 x + 1 = -x + 3 得 2x = 2，x = 1，代入得 y = 2，交点坐标为 (1, 2)。它等价于解二元一次方程组 { y = x + 1, y = -x + 3 }（两条直线的交点即方程组的公共解）。
