第20章 数据的分析

初中 / 初二 / 八年级下册

一句话总纲：数据的分析 = 用少数几个数，替一批数据回答两个问题——「中心在哪里」（平均数 / 中位数 / 众数）和「散得有多开」（方差）。学完本章，你要能在心里"看见"：一组数据就是数轴上的一群质点，平均数 = 这群质点的重心，中位数 = 最中间的那个点，众数 = 扎堆最密的位置，而方差 = 它们离重心有多远的平方平均。

20.1 平均数与加权平均数

算术平均数（通常说的"平均数"）

定义：n 个数据 x₁, x₂, …, xₙ 的算术平均数（简称平均数），等于这 n 个数的和除以 n，记作 x̄（读作"x 拔"）：

x̄ = (x₁ + x₂ + ⋯ + xₙ) / n

例：5, 8, 8, 9, 10 的平均数是 (5+8+8+9+10) ÷ 5 = 40 ÷ 5 = 8。

几何含义（重心 / 平衡支点）：在数轴上，把每个数据都看成一个等质量的质点放在对应刻度上，平均数 x̄ 恰好就是这一群质点的重心位置。如果在 x̄ 处放一个支点把整条"数轴杠杆"架起来，杠杆会刚好水平平衡。
物理含义（质心 + 力矩平衡）：平均数就是物理里的质心（重心）坐标。它平衡的原因是一条硬规律：所有"偏离量"之和恒为 0，即 (x₁−x̄) + (x₂−x̄) + ⋯ + (xₙ−x̄) = 0。每个质点到重心的"力矩"（距离 × 质量）正负相互抵消，所以它既不会左倾也不会右倾——平均数正是这组数据的"平衡点"和"整体水平"的代表。

关键性质：所有数据与平均数的差（离均差）加起来一定等于 0。x̄ 是唯一有这条性质的数，这也是它"不偏不倚"的根源。

加权平均数（有权重的平均数）

当每个数据重要程度不同时，就要给它们配上"权"（weight，记作 w），用加权平均数表示整体水平：

x̄ = (x₁w₁ + x₂w₂ + ⋯ + xₙwₙ) / (w₁ + w₂ + ⋯ + wₙ)

权的含义：权 w 越大，说明这个数据越重要、对平均数的影响力越大。权可以是百分比、比例、频数（出现次数）、重要度等各种形式。

例（按成绩权重算总评）：平时成绩 80 分（占 30%）、期中 90 分（占 30%）、期末 85 分（占 40%），则总评：

x̄ = 80×0.3 + 90×0.3 + 85×0.4 = 24 + 27 + 34 = 85 分
几何 / 物理含义（不等质量的质心）：给不同位置的质点配上不同的质量（权 = 质量），加权平均数就是这群"不等质量质点"的重心。质量越大的点，越能把重心"拉"向自己：上面例子里期末权重最大（0.4），所以总评 85 比"三个分数直接平均 (80+90+85)÷3 = 85"更偏向期末的 85——这里两者恰好相同，但若期末改成 60 分，加权后会被明显拉低。

频数形式：当数据出现重复时，常用"频数"作权。若 x₁ 出现 f₁ 次、x₂ 出现 f₂ 次、…、xₖ 出现 fₖ 次，总次数 n = f₁+f₂+⋯+fₖ，则：

x̄ = (x₁f₁ + x₂f₂ + ⋯ + xₖfₖ) / n

重要关系：算术平均数是加权平均数的特例——当所有权都相等（每个数据的权都是 1/n）时，加权平均数就退化为算术平均数。

20.2 中位数

定义与求法

定义：把一组数据按从小到大排列后，位于正中间位置的那个数，叫做这组数据的中位数。它把数据"一刀切成两半"：一半不比它大，一半不比它小。

  • 数据个数 n 为奇数：中位数是排序后第 (n+1)/2 个数。例：3, 5, 7 的中位数是 5。
  • 数据个数 n 为偶数：中位数是中间两个数的平均数。例：3, 4, 5, 7 的中位数是 (4+5)÷2 = 4.5。
几何含义（使"总距离"最小的点）：中位数是数轴上这样一个位置——所有数据点到它的距离之和最小（数学上叫"最小化绝对偏差和 Σ|xᵢ−m|"）。把它放到数据点里"正中间"，左右两侧的点数一样多，谁都不能靠单方面挪动来减少总距离。
物理含义（最优选址 + 稳健）：想象一条街上有若干户人家，要在街上设一个"取货点"让所有人走到它的总路程最短——答案就是中位数所在的位置（一维最优选址）。另一个物理直觉是稳健（抗极端值）：中位数只看"位置次序"，一个点哪怕跑到无穷远，它也只占一个位置，不会把中心"拉偏"。因此描述"收入"这类含极端值的数据时，常用中位数而不是平均数。

例：数据 1, 2, 3, 4, 100 的平均数是 22（被 100 拉高），而中位数是 3（更接近大多数数据的真实水平）。这就是"稳健"的含义。

20.3 众数

定义

定义：一组数据中出现次数最多的那个数据，叫做这组数据的众数。

  • 众数可能不止一个：若两个值出现次数并列最多，就有两个众数。例：1, 2, 2, 3, 3 的众数是 2 和 3。
  • 众数也可能没有：若每个数据都只出现一次，就没有众数。例：1, 2, 3, 4。
几何含义（分布的高峰）：把数据点在数轴上按出现次数"堆"起来，众数就是堆得最高、最密集的那个刻度——它是这组数据"最扎堆"的位置，代表分布的"高峰"。
物理含义（最可能出现的状态）：众数回答的问题是"哪一种情况最常发生"。它是"多数人的选择"：商店进货最多的鞋码、全班人数最多的身高、投票里得票最多的选项，用的都是众数。注意它只关心"出现频率"，不关心其它数据具体是多少。

三种"集中趋势"指标的区别

指标找什么优点缺点典型用途
平均数整体重心用上全部数据，信息最全易被极端值拉偏求平均分、平均速度
中位数正中间位置不受极端值影响（稳健）只用"次序"，忽略具体大小收入、房价的"中间水平"
众数出现最多直接反映"多数"可能多个或没有，信息有限鞋码、尺码、投票结果

20.4 方差

为什么需要"波动程度"指标？

两组数据可以有相同的平均数，却完全不同。例如甲乙两人各 5 次射击成绩：

甲：8, 8, 9, 9, 10      平均数 x̄ = 8.8
乙：6, 8, 9, 10, 11     平均数 x̄ = 8.8

两人平均分一样，但甲的 5 次成绩挤在一起（稳定），乙的成绩大起大落（波动大）。只用"中心"不够，还需要一个数来量"散得有多开"，这就是方差。

极差（波动的最粗糙度量）

极差 = 最大值 − 最小值，是最简单的离散程度指标。上例甲的极差 = 10−8 = 2，乙的极差 = 11−6 = 5，乙更不稳定。但极差只用了两个数，信息损失大，因此引入更精细的方差。

方差与标准差

方差：各数据与平均数之差的平方的平均数，记作 s²：

s² = (1/n)[(x₁ − x̄)² + (x₂ − x̄)² + ⋯ + (xₙ − x̄)²]

标准差：方差的算术平方根，记作 s，单位与原始数据一致：

s = √s²

例：求 3, 5, 7 的方差。x̄ = (3+5+7)÷3 = 5，于是 s² = [(3−5)²+(5−5)²+(7−5)²]÷3 = (4+0+4)÷3 = 8/3 ≈ 2.67，标准差 s = √(8/3) ≈ 1.63。

快捷公式（计算更省事）：s² = (x₁² + x₂² + ⋯ + xₙ²)/n − x̄²，即"平方的平均 − 平均的平方"。

几何含义（离重心的平方距离）：以平均数（重心）为参照，方差 = 每个数据点到重心的距离的平方的平均值。它刻画的是一条数轴上"点群的散开程度"：点越挤向重心，方差越小；点越散向两边，方差越大。用"平方"而不是"距离本身"，是为了既消除正负抵消、又放大远处点的贡献。
物理含义（转动惯量 / 稳定性）：把数据看成分布在数轴上、总质量为 1 的一群质点，方差正是这个系统绕质心转动的转动惯量——质量离转轴（质心）越远，转动越难，系统越"不稳"。标准差则相当于"回转半径"，即数据到重心的"典型距离"。所以方差小 = 数据集中 = 稳定（射击稳、机器稳、成绩稳）。

回到甲乙的例子：

甲：s² = [ (8−8.8)²+(8−8.8)²+(9−8.8)²+(9−8.8)²+(10−8.8)² ] ÷ 5
     = (0.64+0.64+0.04+0.04+1.44) ÷ 5 = 2.80 ÷ 5 = 0.56
乙：s² = [ (6−8.8)²+(8−8.8)²+(9−8.8)²+(10−8.8)²+(11−8.8)² ] ÷ 5
     = (7.84+0.64+0.04+1.44+4.84) ÷ 5 = 14.80 ÷ 5 = 2.96

甲方差 0.56 < 乙方差 2.96，所以甲的成绩更稳定。

本章 · 几何与物理含义总结

概念几何含义物理含义
平均数数轴上等质量质点的重心（平衡支点）质心坐标；力矩平衡，代表"整体水平"
加权平均数不等质量质点的重心，权=质量质心；权越大越被"拉向"该点
中位数排序后正中间的点；使总距离最小的点一维最优选址；抗极端值，稳健
众数数轴上扎堆最密、堆得最高的位置"最可能发生的状态"，多数人的选择
极差最左点到最右点的跨度波动范围的最粗糙度量
方差各点到重心距离平方的平均（散开程度）绕质心的转动惯量；越小越稳定
标准差方差的"开方"（回到原单位）回转半径；数据到重心的"典型距离"

典型例题（自测）

  1. 求数据 5, 8, 8, 9, 10 的平均数、中位数和众数。
  2. 某同学平时 80 分（占 30%）、期中 90 分（占 30%）、期末 85 分（占 40%），求他的加权总评。
  3. 求数据 3, 5, 7 的方差与标准差（精确到 0.01）。
  4. 甲乙两名射击运动员各打 5 发，甲：8, 8, 9, 9, 10；乙：6, 8, 9, 10, 11。谁发挥更稳定？
  5. 求数据 1, 2, 3, 4, 100 的平均数与中位数，并说明哪一个更能代表"大多数数据"。

常见误区

  • ❌ "平均数一定在数据中间" → ❌ 平均数会被极端值拉偏（1, 2, 3, 4, 100 的平均数 22，远超大多数数据），此时应看中位数。
  • ❌ "偶数个数据的中位数直接取中间第 n/2 个" → ❌ 偶数个时要取中间两个数的平均数（3, 4, 5, 7 的中位数是 4.5 不是 4）。
  • ❌ "众数只能有一个" → ❌ 众数可以有多个（并列最多），也可以没有（每个数都只出现一次）。
  • ❌ "方差可以是负数" → ❌ 方差是"平方的平均"，恒有 s² ≥ 0，不可能为负。
  • ❌ "方差越大越好 / 越小越好" → ❌ 看场景：追求稳定（射击、机器精度）时方差小好；追求爆发或风险收益时，大方差未必坏。
  • ❌ "权一定就是频数" → ❌ 权还可以是百分比、比例、重要程度；频数只是权的一种。
  • ❌ "计算方差时分母用 n−1" → ❌ 初中阶段按教材用总体的方差，分母是 n；n−1 是高中"样本方差"的修正，别混。

本章练习卷（含答案）

一、练习题

  1. 求数据 5, 8, 8, 9, 10 的平均数、中位数和众数。
  2. 某同学平时成绩 80 分（占 30%）、期中 90 分（占 30%）、期末 85 分（占 40%），求他的加权总评成绩。
  3. 求数据 3, 4, 5, 7 的中位数，并说明偶数个数据求中位数时的规则。
  4. 求数据 3, 5, 7 的方差与标准差（保留两位小数）。
  5. 甲、乙两名射击运动员各打 5 发，成绩如下——甲：8, 8, 9, 9, 10；乙：6, 8, 9, 10, 11。谁发挥得更稳定？
  6. 对数据 1, 2, 3, 4, 100，平均数和中位数哪一个更能代表"大多数数据"？结合"重心"与"抗极端值"的几何/物理含义说明理由。

二、参考答案（点击展开）

查看第1题答案

平均数 = (5+8+8+9+10) ÷ 5 = 40 ÷ 5 = 8；从小到大排序为 5, 8, 8, 9, 10，第 3 个数是中位数，即 8；出现次数最多的是 8（出现 2 次），所以众数为 8。

查看第2题答案

加权总评 = 80×0.3 + 90×0.3 + 85×0.4 = 24 + 27 + 34 = 85 分。

查看第3题答案

排序后为 3, 4, 5, 7，中间两个数是 4 和 5，中位数 = (4+5) ÷ 2 = 4.5。规则：数据个数为偶数时，取排序后中间两个数的平均数。

查看第4题答案

平均数 x̄ = (3+5+7) ÷ 3 = 5；方差 s² = [(3−5)² + (5−5)² + (7−5)²] ÷ 3 = (4+0+4) ÷ 3 = 8/3 ≈ 2.67；标准差 s = √(8/3) ≈ 1.63。

查看第5题答案

甲、乙的平均数都是 8.8。甲方差 = [(8−8.8)²+(8−8.8)²+(9−8.8)²+(9−8.8)²+(10−8.8)²] ÷ 5 = 0.56；乙方差 = [(6−8.8)²+(8−8.8)²+(9−8.8)²+(10−8.8)²+(11−8.8)²] ÷ 5 = 2.96。0.56 < 2.96，故甲更稳定。

查看第6题答案

平均数 = (1+2+3+4+100) ÷ 5 = 22，中位数 = 3。中位数更能代表大多数数据：平均数作为"重心"会被极端值 100 拉偏，而中位数只看位置次序、抗极端值，因此更稳健。
