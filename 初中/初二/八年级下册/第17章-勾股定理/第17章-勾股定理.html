第17章 勾股定理

初中 / 初二 / 八年级下册

一句话总纲：勾股定理 = 直角三角形三边上的三个正方形之间的面积守恒：两条直角边的平方和等于斜边的平方（a² + b² = c²）。学完本章，你要能在心里"看见"每个直角三角形背后那三个正方形，并把它当作一把"万能直角尺"——用来判断直角（逆定理）、求最短路径、解折叠与测量问题。

17.1 勾股定理

定理内容

直角三角形的两条直角边的平方和，等于斜边的平方。

       A
       /|
      / |
   c /  | b    直角边 a、b，斜边 c
    /   |
   /____|
  B  a  C        a² + b² = c²

其中 a、b 是两条直角边，c 是斜边（直角所对的边）。中国古代把较短的直角边叫勾、较长的直角边叫股、斜边叫弦，所以"勾股定理"也叫"勾股弦定理"。西方称为毕达哥拉斯定理（Pythagorean theorem）。

几何含义：分别以直角三角形的三条边为边长，向外作三个正方形。勾股定理说的是——两条直角边上的正方形面积之和，恰好等于斜边上的正方形面积。S(勾) + S(股) = S(弦)。也就是 a² + b² = c² 里的"平方"不是抽象的运算，而是实实在在的面积。这是"数"与"形"最著名的一次结合。
物理含义：勾股定理是互相垂直的两个量的合成法则。① 位移合成：先向东走 a 米、再向北走 b 米，合位移的大小 c = √(a² + b²)；② 力/速度合成：两个互相垂直的分力 F₁ ⊥ F₂，合力大小 F = √(F₁² + F₂²)；③ 平面上任意两点，若水平差为 Δx、竖直差为 Δy，则直线距离 = √(Δx² + Δy²)。一句话：垂直分量用"平方和再开方"合成。

历史渊源

中国约公元前 1 世纪的《周髀算经》记载了商高与周公的对话："勾三，股四，弦五"，说明早在商周时期人们已知道 3、4、5 能组成直角三角形。三国时期数学家赵爽在《勾股圆方图注》中用"弦图"给出了一个漂亮的证明。古希腊的毕达哥拉斯学派也独立发现了这一定理。

证明：赵爽弦图（面积法）

构造一个以斜边 c 为边长的大正方形，内部拼入 4 个全等的直角三角形（直角边 a、b），中间正好留下一个小正方形（边长为 b − a）。因为"大正方形面积 = 4 个三角形面积 + 中间小正方形面积"，所以：

大正方形面积 = c²
c² = 4 × (½·a·b) + (b − a)²
   = 2ab + (b² − 2ab + a²)
   = a² + b²

于是得到 a² + b² = c²。这个证明的巧妙之处在于：只用"面积"这一个直观概念，不借助任何代数技巧，就把三边的平方关系揭示了出来。

另一种等价证法（毕达哥拉斯拼图）：把两个同样的正方形（边长 a+b）分别按不同方式切成几块，发现"两块直角边正方形"和"一块斜边正方形"恰好能填满同样大的区域，说明面积相等。

由定理推出的两个常用结论

  • 斜边最长：因为 c² = a² + b² > a²，也 > b²，所以 c > a 且 c > b。直角三角形中斜边一定是最长边，且直角所对的边是斜边。
  • 等腰直角三角形（45°-45°-90°）：当两条直角边相等（a = b）时，c² = a² + a² = 2a²，所以 c = √2 · a。即等腰直角三角形的斜边 = 直角边的 √2 倍，三边比为 1 : 1 : √2。

17.2 勾股定理的逆定理

逆定理内容

如果三角形三边长 a、b、c 满足 a² + b² = c²，那么这个三角形是直角三角形，且 c 所对的角是直角（90°）。

注意：勾股定理是"由直角推出边的平方关系"，逆定理是"由边的平方关系推出直角"，方向正好相反，但两者都成立。它们是"直角"与"a² + b² = c²"之间的一对等价条件。

几何含义：逆定理给了我们一把只用长度、不用量角器就能判断直角的"尺子"。只要量出三边，算一算"两小边的平方和是否等于最大边的平方"，就能断定最大边所对的角是不是直角。这是从"数"反推"形"的典型例子。
物理含义：工程与生活中"检验垂直"的实用方法——3-4-5 放线法：取 3 米、4 米、5 米三段绳（或钢尺）拉成一个三角形，若 3² + 4² = 5²，则 5 米边所对的角必为直角。木工、瓦工砌墙、测量员放样都用它来确认墙角或基线的垂直，保证结构方正。

为什么逆定理成立？（证明思路）

已知 △ABC 三边满足 a² + b² = c²（c 为最长边）。另作一个直角三角形 △A′B′C′，使它的两条直角边分别等于 a、b，那么由勾股定理，它的斜边长为：

c′ = √(a² + b²) = √(c²) = c

于是 △A′B′C′ 的三边为 a、b、c，与 △ABC 三边分别相等。由边边边（SSS）全等，△ABC ≌ △A′B′C′，所以 △ABC 也是直角三角形，且边长 c 所对的角是直角。

勾股数（Pythagorean triples）

满足 a² + b² = c² 的正整数三元组 (a, b, c) 叫做勾股数。它对应"三边都是整数"的直角三角形，是最方便计算和记忆的一类。

勾股数验证
3, 4, 53² + 4² = 9 + 16 = 25 = 5²
5, 12, 135² + 12² = 25 + 144 = 169 = 13²
7, 24, 257² + 24² = 49 + 576 = 625 = 25²
8, 15, 178² + 15² = 64 + 225 = 289 = 17²
9, 40, 419² + 40² = 81 + 1600 = 1681 = 41²
6, 8, 10（= 3,4,5 的 2 倍）6² + 8² = 36 + 64 = 100 = 10²
  • 放大性质：若 (a, b, c) 是勾股数，那么 (ka, kb, kc)（k 为正整数）也是勾股数。例：(3, 4, 5) 的 2 倍得 (6, 8, 10)，3 倍得 (9, 12, 15)。
  • 生成公式：取两个正整数 m > n，则下面一组数必是勾股数：
a = m² − n²
b = 2mn
c = m² + n²      （m > n 为正整数）

例：取 m = 2、n = 1 → a = 3、b = 4、c = 5；取 m = 3、n = 2 → a = 5、b = 12、c = 13。这套公式能"批量生产"无穷多组勾股数，说明勾股数有无穷多组。

17.3 勾股定理的应用

勾股定理的威力在于：凡是一个直角三角形，只要知道其中两条边，就能求出第三条边。本节讲三类最重要的应用：最短路径、折叠、测量。

17.3.1 最短路径问题（把曲面"展开"成平面）

典型场景：一只蚂蚁在圆柱、长方体等立体表面上，从一点爬到另一点，问最短路线是多少。

核心方法：因为蚂蚁只能在表面爬（不能穿进物体内部），所以要先把经过的面展开成一个平面；展开后，两点之间的最短路程就是连接两点的直线段，再用勾股定理求这条线段的长度。

几何含义：曲面上的最短路径（测地线）在"展开成平面"后变成直线段。展开是一种保距变换（不改变长度），把三维表面问题"降维"成平面问题，再用"两点之间线段最短 + 勾股定理求长"解决。
物理含义：蚂蚁、机器人沿表面移动，或光沿曲面传播（如光在镜面、光纤内壁反射），都沿最短路程走。展开后这条"最短路"就是直线，长度可用勾股定理算——这就是工程上"展开图 + 直线距离"求最短铺设、最短布线长度的原理。

例 A（长方体，蚂蚁从一个顶点到对角顶点）：长方体长 8、宽 6、高 3，蚂蚁从顶点 A 爬到空间对角顶点 C′，求最短路程。

蚂蚁经过两个相邻的面。把这两个面展开成平面，A 与 C′ 之间是一条直角三角形的斜边。三种展开方式对应三种可能：

方式1（沿"长"展开）：直角边 8 和 (6+3)=9 → √(8² + 9²)  = √145
方式2（沿"宽"展开）：直角边 6 和 (8+3)=11 → √(6² + 11²) = √157
方式3（沿"高"展开）：直角边 3 和 (8+6)=14 → √(3² + 14²) = √205

三者取最小：最短路程 = √145 ≈ 12.04。关键提醒：不能直接走"空间对角线" √(8² + 6² + 3²)，因为蚂蚁在表面上爬，无法穿过长方体的内部。

例 B（圆柱，侧面展开）：圆柱高 h、底面半径 r，蚂蚁从下底圆周上一点 A 爬到上底圆周上与 A 相对的 B 点（转过 180°）。把侧面展开成矩形（宽 h、长 2πr），B 位于矩形上边的中点，水平距离为半周长 πr，最短路程：

L = √(h² + (πr)²)

这就是"圆柱侧面展开图的对角线"。

17.3.2 折叠问题（折叠 = 轴对称）

折叠类题目的核心认识，是搞清楚折叠的几何本质：

  • 沿某条折痕把图形翻折，是轴对称（镜面对称）变换。
  • 折叠前后重合的两个图形全等：对应的边、角都相等。
  • 折痕是"对应点连线"的垂直平分线：折痕上任一点到两个对应点的距离相等。
几何含义：折叠 = 关于折痕的轴对称。抓住"折叠前后全等"和"对称点连线被折痕垂直平分"两条性质，就能把看似未知的线段"转移"到同一个直角三角形里，再用勾股定理列方程求出线段长。这是"对称 + 勾股"联用的经典套路。
物理含义：折叠的数学与光的反射一模一样——把折痕看成一面镜子，折叠前后的两个点互为"镜像"，对应点与镜面垂直且到镜面等距。光的反射定律（入射角 = 反射角）正是"对称点连线被镜面垂直平分"的体现，而"光总是沿最短路径走"也可以由此解释。

例 C（沿对角线折叠，求重叠边长）：长方形 ABCD 中，AB = 8，BC = 6。沿对角线 AC 折叠，使点 B 落在 B′，AB′ 与 CD 交于点 E。求 AE 的长。

解：

  1. 由折叠对称，∠EAC = ∠BAC；又 AB ∥ CD，所以 ∠BAC = ∠ACD；而 E 在 CD 上，∠ECA = ∠ACD。
  2. 因此 ∠EAC = ∠ECA，△AEC 是等腰三角形，得 AE = CE。
  3. 设 AE = CE = x，则 DE = CD − CE = 8 − x。在 Rt△ADE 中：AD = 6，DE = 8 − x，AE = x。
由勾股定理： x² = 6² + (8 − x)²
             x² = 36 + 64 − 16x + x²
             0  = 100 − 16x
             x  = 100/16 = 25/4 = 6.25

所以 AE = 25/4 = 6.25。整个解题过程只用了两件事：折叠的对称/全等找出等量关系，再用勾股定理列方程。

17.3.3 测量问题（把现实抽象成直角三角形）

很多实际问题没有现成的直角三角形，需要我们主动构造：旗杆、大树、梯子、河宽、两点距离……把它们抽象成一条直角边（水平）、一条直角边（竖直）、一条斜边（连线），就能用勾股定理求未知量。

几何含义：测量的本质是"垂直分解"——把任意两点间的距离分解成水平差 Δx 与竖直差 Δy 两个互相垂直的分量，斜距就是直角三角形的斜边。这是勾股定理在坐标与测量中最直接的几何应用。
物理含义：现实中的"斜距"总是可以看成两个垂直方向位移的合成：两点间距离 = √(水平距离² + 竖直高度差²)。测量旗杆高度、梯子顶端离地高度、断树折点位置、两点实地距离，都是"已知其中两条，求第三条"。

例 D（梯子靠墙）：一架长 10 米的梯子斜靠在墙上，底端离墙脚 6 米，求梯子顶端离地多高。

h = √(10² − 6²) = √(100 − 36) = √64 = 8（米）

进一步：若梯子顶端下滑 1 米（顶端高度从 8 米变到 7 米），底端会外移多少？

新底端距墙 = √(10² − 7²) = √(100 − 49) = √51 ≈ 7.14（米）
外移 ≈ 7.14 − 6 = 1.14（米）

注意：顶端下滑 1 米，底端并不是也外移 1 米——因为三边之间是平方关系，不是线性关系。

例 E（断树）：一棵大树在离地面 4 米处被风吹断，树梢恰好落在地面上距树根 3 米处，求大树原高。

折断部分长 = √(4² + 3²) = √(16 + 9) = √25 = 5（米）
大树原高 = 4 + 5 = 9（米）

延伸：平面直角坐标系中的两点距离公式

把勾股定理放到坐标系里，就得到两点间距离公式：平面上 A(x₁, y₁)、B(x₂, y₂)，则

AB = √((x₂ − x₁)² + (y₂ − y₁)²)

其中 (x₂ − x₁) 是水平差、(y₂ − y₁) 是竖直差。这正是"垂直分量平方和再开方"的坐标版，物理上就是位移向量的模（长度）。

典型例题（自测）

  1. 直角三角形的两条直角边分别是 5 和 12，求斜边长。
  2. 直角三角形斜边为 13，一条直角边为 5，求另一条直角边。
  3. 判断以 6、8、10 和 5、11、13 为三边的三角形是否分别是直角三角形，并指出直角所对的边。
  4. 长方体的长、宽、高分别为 8、6、3，求蚂蚁从一顶点沿表面爬到空间对角顶点的最短路程。
  5. 长方形 ABCD 中，AB = 8，BC = 6，沿 AC 折叠使 B 落在 B′，AB′ 与 CD 交于点 E，求 AE 的长。
  6. 一架长 10 米的梯子靠墙，底端离墙 6 米；若顶端下滑 1 米，求底端外移多少米（结果保留根号）。
  7. 等腰直角三角形的直角边为 2，求斜边；并用勾股数生成公式（取 m = 4、n = 1）写出一组勾股数。

常见误区

  • ❌ "勾股定理对任何三角形都成立" → ❌ 它只对直角三角形成立，且 a、b 必须是直角边，c 必须是斜边。
  • ❌ "a² + b² = c² 里 c 随便放哪条边" → ❌ c 必须是斜边（最长边）；用逆定理时也要先确认 c 是最大边。
  • ❌ "勾股数只有 3、4、5 一组" → ❌ 勾股数有无穷多组，如 5,12,13、8,15,17，以及任意一组的整数倍。
  • ❌ "2、3、4 也是勾股数" → ❌ 2² + 3² = 13 ≠ 16 = 4²，不满足平方和关系。
  • ❌ "蚂蚁问题直接走空间对角线 √(a² + b² + c²)" → ❌ 蚂蚁在表面爬，不能穿进内部，必须先展开成平面再求。
  • ❌ "折叠后图形变了" → ❌ 折叠是轴对称，折叠前后重合部分全等，折痕是对应点连线的垂直平分线。
  • ❌ "梯子顶端下滑 1 米，底端就外移 1 米" → ❌ 三边是平方关系，不是线性关系；下滑 1 米，底端外移约 1.14 米。
  • ❌ "开方忘记取正" → ❌ 线段长度、距离恒为正，√ 只取非负值。

课本外 · 典故与思考

典「毕达哥拉斯定理」这个名字，其实有点"名不副实"？（点击展开）

勾股定理在西方叫「毕达哥拉斯定理」。毕达哥拉斯（约公元前 570–前 495）是古希腊数学家，他创立的学派相信"万物皆数"，把数捧到了信仰的高度。传说他们发现这个定理后高兴得不得了，宰了一百头牛庆祝（这就是流传的"百牛大祭"传说——注意，这只是传说，没有可靠记载）。

但历史学家考据后发现：这一定理很可能不是毕达哥拉斯第一个发现的。哥伦比亚大学收藏着一块著名的古巴比伦泥板，叫「普林普顿 322 号」，制作时间约在公元前 1800 年——比毕达哥拉斯早了整整一千多年。泥板上刻着十五组勾股数，包括 3、4、5 和 5、12、13 这些你刚背过的组合，还精确地对应着一套勾股数生成规律。

也就是说：巴比伦人早就"知道"了勾股数；中国《周髀算经》里商高的"勾三股四弦五"也独立出现；毕达哥拉斯学派则把它整理成了系统的定理并传播开来。所以"毕达哥拉斯定理"这个名字，纪念的更多是他让这个定理广为人知，而不是"他第一个发现"。

数学史上很多名字都是这样：被记住的往往是传播者，而不是第一个发现者。

一句话总结：古巴比伦"普林普顿 322 号"泥板（约公元前 1800 年）已刻有 3-4-5 等十五组勾股数，比毕达哥拉斯早一千多年——西方叫"毕达哥拉斯定理"，更多是纪念他把它传开，而非他首先发现。
思从「勾股数无穷多」到费马大定理——一行批注引发的 358 年悬案（点击展开）

本章学到：勾股数 a² + b² = c² 有无穷多组（3-4-5、5-12-13、6-8-10……）。那如果把指数再往上抬一抬呢？

1637 年，法国数学家费马在读古希腊数学家丢番图的《算术》一书时，在书页空白处写下了一句著名的批注：

「对于 n > 2，方程 xⁿ + yⁿ = zⁿ 没有任何正整数解。我确信自己已经发现了绝妙的证明，可惜这里的空白太小，写不下。」

这句话就是数学史上最著名的"费马大定理"（也叫费马最后定理）。它看起来只是把勾股方程的次数从 2 改成 3、4、5……但接下来整整 358 年，无数数学家前赴后继，没有一个人能证明它。有人还真的找出了反例的错误证明，费马的"绝妙证明"始终是个谜——多数史学家相信，费马当时想的证明其实有漏洞。

最终攻克它的，是英国数学家安德鲁·怀尔斯：1994 年他给出了完整证明，1995 年正式发表，用到的工具是现代数学最深的分支（椭圆曲线、模形式）。有趣的是，怀尔斯说自己十岁那年在图书馆第一次读到费马大定理，从此被它吸引了一辈子。

而这一切的起点，只是"勾股数有没有更多"这个小问题。你八年级学的一个公式，通向的却是二十世纪数学最伟大的成就之一。

一句话总结：费马 1637 年批注"xⁿ+yⁿ=zⁿ（n>2）无正整数解"，358 年后（1994）怀尔斯才完成证明——它正是"勾股数无穷多"这个八年级知识点延伸出的世纪难题。
趣勾股定理有三百多种证法，其中一种出自一位美国总统（点击展开）

在数学的所有定理里，勾股定理的证明数量大概是最卷的：1940 年，美国数学教师卢米斯出版了《毕达哥拉斯命题》一书，一口气收集了 367 种不同的证明方法——从古希腊的面积法，到中国赵爽的弦图，再到用微积分、用相似三角形、用坐标的……应有尽有。

其中最传奇的一位"业余数学家"是——詹姆斯·加菲尔德，美国第 20 任总统。1876 年，还在国会任职的他想出了一种漂亮的"梯形证明"：

做一个直角梯形，上底 a、下底 b、高 a+b；
在中间放一个直角边为 a、b、斜边为 c 的直角三角形，
两边再各补一个直角三角形。
大梯形面积 = (a+b)(a+b)/2
          = 三个三角形面积之和 = ab/2 + ab/2 + c²/2
展开左边：(a² + 2ab + b²)/2 = ab + c²/2
两边同时去掉 ab：a²/2 + b²/2 = c²/2
两边乘 2：a² + b² = c²

一块梯形，不用任何代数技巧以外的工具，就证完了。加菲尔德总统后来在演讲里还乐呵呵地说，这是他在国会开会无聊时想出来的。

一个定理，能引来一位总统亲自证明，说明它既简单到人人可以上手，又深刻到值得人类研究几千年——这就是勾股定理的魅力。

一句话总结：卢米斯 1940 年收集了勾股定理的 367 种证法；1876 年美国总统加菲尔德给出了一个简洁的梯形面积证明——一个定理能吸引总统来证，既因为它简单，也因为它深刻。

本章练习卷（含答案）

一、练习题（由易到难，共 6 题，紧扣本章知识点）

  1. 直角三角形的两条直角边分别是 6 和 8，求斜边长，并指出斜边是哪条边。
  2. 判断以下两组线段能否构成直角三角形，若能，指出直角所对的边：① 7、24、25；② 4、5、6。
  3. 验证 (5, 12, 13) 是勾股数；再用勾股数生成公式（取 m = 3、n = 1）写出一组勾股数。
  4. 长方体长 8、宽 6、高 3，蚂蚁从一个顶点沿表面爬到空间对角顶点，求最短路程（结果保留根号）。
  5. 长方形 ABCD 中，AB = 8，BC = 6，沿对角线 AC 折叠，使点 B 落在 B′，AB′ 与 CD 交于点 E，求 AE 的长。
  6. 一架长 10 米的梯子斜靠在墙上，底端离墙脚 6 米，求梯子顶端离地高度；若顶端下滑 1 米，底端会外移多少米（结果保留根号）？

二、参考答案（点击展开）

查看第1题答案

斜边 c = √(6² + 8²) = √100 = 10。斜边是直角所对的那条最长边。

查看第2题答案

① 7² + 24² = 49 + 576 = 625 = 25²，是直角三角形，边长 25 所对的角是直角；② 4² + 5² = 41 ≠ 36 = 6²，不满足平方和关系，不是直角三角形。

查看第3题答案

5² + 12² = 25 + 144 = 169 = 13²，故 (5, 12, 13) 是勾股数。取 m = 3、n = 1：a = 3² − 1² = 8，b = 2×3×1 = 6，c = 3² + 1² = 10，得勾股数 (8, 6, 10)，即 (6, 8, 10)。

查看第4题答案

蚂蚁在表面爬，需把相邻两面展开成平面。三种展开方式的斜边分别是：√(8² + 9²) = √145，√(6² + 11²) = √157，√(3² + 14²) = √205。取最小，最短路程 = √145 ≈ 12.04。不能直接走空间对角线。

查看第5题答案

由折叠对称得 ∠EAC = ∠ECA，故 △AEC 为等腰三角形，AE = CE。设 AE = CE = x，则 DE = 8 − x。在 Rt△ADE 中：x² = 6² + (8 − x)² → x² = 100 − 16x + x² → x = 25/4 = 6.25。所以 AE = 6.25。

查看第6题答案

顶端高度 h = √(10² − 6²) = √64 = 8（米）。下滑 1 米后高度为 7 米，新底端距墙 = √(10² − 7²) = √51 ≈ 7.14（米），故底端外移 = √51 − 6 ≈ 1.14（米）。注意下滑 1 米不等于外移 1 米。
