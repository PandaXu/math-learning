第16章 二次根式

初中 / 初二 / 八年级下册

一句话总纲：二次根式 √a 就是「面积为 a 的正方形的边长」——它天生非负，把「开方」变成看得见的几何长度，把「化简、乘除、加减」变成「把边长换算成最简尺子、把面积与边长互化、把相同单位的长度拼接」。

16.1 二次根式的概念

什么是二次根式

定义：一般地，形如 √a（a ≥ 0）的式子叫做二次根式。其中「√」叫做二次根号，a 叫做被开方数。

  • 有意义的条件：被开方数 a ≥ 0。因为在实数范围内，负数没有平方根，所以 a < 0 时 √a 没有意义。
  • √a 的值：√a 表示 a 的算术平方根，即「平方等于 a 的那个非负数」。因此 √a 本身恒满足 √a ≥ 0。
  • 双重非负性：√a 成立时，必须同时满足「被开方数 a ≥ 0」和「根式值 √a ≥ 0」。这是二次根式一切运算的地基。
几何含义：√a 就是「面积为 a 的正方形的边长」。面积是 a，边长就是 √a；反过来，边长是 √a 的正方形，面积就是 a。例：√4 = 2（面积 4 的正方形边长是 2），√9 = 3（面积 9 的正方形边长是 3）。而 √2 就是「边长为 1 的正方形」的对角线长——由勾股定理，对角线² = 1² + 1² = 2，所以对角线 = √2。这就是 √2 第一次以真实几何长度的身份出现。
物理含义：√a 永远是一个非负的「大小」量，它代表长度、距离、速率这类「只讲大小、不讲方向」的量。比如面积 a 的量纲是「长度²」，对它开方 √a 就回到「长度」量纲——开方在物理上常常是「把平方量还原成基本量」。

一句话记牢：√ 是「面积 → 边长」的换算器，结果永远 ≥ 0。

16.2 二次根式的性质

性质一：(√a)² = a（a ≥ 0）

含义：「先开方、再平方」互相抵消，回到 a 本身。

(√a)² = a   （a ≥ 0）
(√3)² = 3， (√0.5)² = 0.5
几何含义：把「面积为 a 的正方形」的边长 √a 取出来，再以它为边长重新拼一个正方形，面积又变回 a——边长 → 面积的逆过程。

性质二：√(a²) = |a|（这是本章最易错的一条！）

            ┌  a    (a > 0)
 √(a²) = |a| ├  0    (a = 0)
            └ −a    (a < 0)
  • √(3²) = |3| = 3；√((−3)²) = |−3| = 3；√(0²) = 0。
  • 关键：a 本身可能是负数，但 √(a²) 先算平方 a²（≥ 0），再开方得到的是非负的结果，所以必须取 |a|，不能直接写成 a。
几何含义：√(a²) = |a| 就是「数轴上点 a 到原点 0 的距离」。无论 a 在原点右边（正）还是左边（负），距离都是正的 |a|。例：√((−3)²) = 3，正是「−3 这个点到原点的距离为 3」。
物理含义：|a| 就是「去掉方向、只留大小」。速度是 −3 m/s（向西），速率是 |−3| = 3 m/s；位移是 −5 m，路程（长度）是 5 m。√(a²) = |a| 是「把带方向的量变成大小」的标准动作。

性质三：积与商的算术平方根（为乘除打基础）

√(ab) = √a · √b   （a ≥ 0，b ≥ 0）
√(a/b) = √a / √b  （a ≥ 0，b > 0）

这两条说明「根号可以拆进乘积和分数里」，下一节乘除运算就是反复使用它们。

16.3 最简二次根式

什么叫「最简」

一个二次根式，若同时满足下面两条，就叫最简二次根式：

  1. 被开方数不含分母（根号里没有分数）；
  2. 被开方数中不含能开得尽方的因数或因式（根号里没有「平方因子」）。
根式是否最简原因
√7✅ 最简7 是质数，无平方因子，无分母
√12❌ 不是12 = 4×3，含能开尽方的因数 4
√(1/2)❌ 不是被开方数是分数，含分母
√(a²b)❌ 不是含能开尽方的因式 a²
2√3✅ 最简√3 内无平方因子，且无分母

化简方法：把「平方因子」请出根号

√(a²b) = a√b   （a ≥ 0，b ≥ 0）

√12 = √(4×3) = √4 × √3 = 2√3
√18 = √(9×2) = 3√2
√50 = √(25×2) = 5√2
√(1/2) = √2/√4 = √2/2   （分母有理化）
几何含义：化简 = 把边长换算成「以某个不可再拆的 √n 为最小尺子」来量。√12 = 2√3 意思是：面积为 12 的正方形，其边长等于「2 个 √3 单位」的长度，而不是一个孤零零的 √12。√3 是这里的「基本尺子」，2 是「尺子用了多少次」。
物理含义：化简 = 统一「单位」。就像 2500 m 要写成 2.5 km、50 cm 要写成 0.5 m 一样，√50 要写成 5√2，把「根号里的平方因子」提出来当作倍数，剩下 √2 作为不可再约的「基本单位」。统一单位之后才能比较大小、做加减。

16.4 二次根式的乘除

乘法：√a · √b = √(ab)（a ≥ 0，b ≥ 0）

√a · √b = √(ab)   （反过来：√(ab) = √a · √b）

√2 × √3 = √6
√2 × √8 = √16 = 4
2√3 × 3√2 = (2×3) × (√3 × √2) = 6√6
几何含义：乘法是「两个正方形边长相乘，得到更大正方形的边长」。√2 × √3 = √6，就是「面积 2 的正方形边长」×「面积 3 的正方形边长」=「面积 6 的正方形边长」。因为 (√2 × √3)² = (√2)²(√3)² = 2×3 = 6，所以这个积正是面积为 6 的正方形的边长。
物理含义：乘法对应「比例缩放」。把正方形的面积放大 k 倍，边长放大 √k 倍。例：面积从 2 变成 8（放大 4 倍），边长从 √2 变成 √8 = 2√2（放大 √4 = 2 倍）。这就是「面积按 k 倍缩放 → 线度按 √k 倍缩放」的物理规律。

除法：√a / √b = √(a/b)（a ≥ 0，b > 0）

√a / √b = √(a/b)   （反过来：√(a/b) = √a / √b）

√18 ÷ √2 = √(18/2) = √9 = 3
√6 ÷ √2 = √3
2√6 ÷ √2 = 2√3
几何含义：除法是「两条边长之比」。√6 ÷ √2 = √3，就是「面积 6 的正方形边长」除以「面积 2 的正方形边长」= √(6/2) = √3，等价于问「边长放大几倍，面积从 2 变成 6」。

分母有理化：把根号从分母赶走

分母含根式时，分子分母同乘一个有理化因式，使分母变成有理数：

1/√2   = 1×√2 / (√2 × √2) = √2/2
3/√5   = 3√5/5
1/(√3 + 1) = 1×(√3 − 1) / ((√3+1)(√3−1)) = (√3 − 1)/2
几何/物理含义：分母有理化 = 把「分数单位」换成整数。1/√2 和 √2/2 是同一个数（都约 0.707），但 √2/2 表示「把 √2 这个长度二等分」，更容易和别的长度相加、比较。它的本质是「长度之比」的标准化写法。

16.5 二次根式的加减

同类二次根式

化简后，被开方数相同的二次根式，叫做同类二次根式。例：√8 与 √2 表面不同，但 √8 = 2√2，与 √2 是同类。

加减法则：先化简，再合并同类二次根式

√8 + √18 = 2√2 + 3√2 = (2+3)√2 = 5√2
√27 − √12 = 3√3 − 2√3 = √3
2√3 + 5√3 − √3 = 6√3

核心要点：

  • 只有同类二次根式才能合并（像合并同类项一样，只把系数相加减，根式部分不变）。
  • √2 + √3 不能合并（被开方数不同，就像「2 厘米 + 3 米」不能直接相加一样）。
  • 遇到不是最简的根式，一定要先化简再判断能否合并。
几何含义：加减 = 用「同一把 √n 尺子」拼接长度。2√2 + 3√2 = 5√2，就是「2 段 √2 长的线」接上「3 段 √2 长的线」，总共 5 段 √2。而 √2 + √3 之所以不能合并，是因为它们是两把不同的尺子，拼起来只能写作 √2 + √3，无法合成一个整数倍的 √n。
物理含义：加减 = 「同类量（同单位）才能相加减」。2√2 和 3√2 具有相同的「单位」√2，可以直接相加；√2 和 √3 单位不同，必须保持分开写。这就像 2 米 + 3 米 = 5 米，但 2 米 + 3 秒无法相加。

全章运算顺序小结：先乘除（含分母有理化）→ 再加减 → 结果必须化为最简二次根式。乘法把根号内相乘、除法把根号内相除并有理化分母、加减只合并「同类（同被开方数）」。

常见误区

这些错误是本章失分重灾区

  • ❌ 「√(a²) = a」 → ❌ 应为 √(a²) = |a|。例：√((−3)²) = 3，而不是 −3。
  • ❌ 「√a + √b = √(a+b)」 → ❌ 根号不能这样合并。例：√4 + √9 = 2 + 3 = 5，而 √(4+9) = √13 ≈ 3.6，两者不等。
  • ❌ 「√a × √b = √(a+b)」 → ❌ 乘法应把根号内相乘：√2 × √3 = √6，不是 √5。
  • ❌ 被开方数写成负数 → ❌ √(−4) 在实数范围内没有意义，二次根式要求 a ≥ 0。
  • ❌ 加减前不先化简 → ❌ √8 + √2 先化成 2√2 + √2 = 3√2，不能直接写成 √10。
  • ❌ 把非同类根式合并 → ❌ √2 与 √3 被开方数不同，不能合并，√2 + √3 已是最简结果。
  • ❌ 分母有理化后仍留根号在分母 → ❌ 1/√2 应写 √2/2，而不是 1×√2/2×√2 这种半成品。
  • ❌ 把「最简」理解为「根号里越小越好」 → ❌ 最简 = 无分母 + 无平方因子，√12 必须写成 2√3，不能停在 √12。

课本外 · 典故与思考

史√2 的发现，曾让一个学派炸了锅——第一次"数学危机"（点击展开）

课本告诉你 √2 是边长为 1 的正方形的对角线长。可你是否想过：√2 到底是哪个"数"？它写不成任何分数。两千五百年前，这个发现曾让整个学派陷入恐慌。

古希腊的毕达哥拉斯学派（公元前 6–5 世纪）有一条铁律般的信条：万物皆数——而他们心中的"数"，就是整数和整数之比（今天叫有理数）。在他们看来，宇宙里任何量都能用两个整数一比了之。

传说（注意是传说，没有确凿记载）学派成员希帕索斯发现：边长为 1 的正方形的对角线 √2，根本写不成两个整数之比。这等于动摇了"万物皆数"的根基。据说他被扔进了大海……故事的真假说不清，但"√2 是无理数"这件事本身，是被严格证明了的。

证明用反证法，初二就能看懂：

假设 √2 = p/q，其中 p、q 是互质的整数（最简分数）。
两边平方：2 = p²/q²，即 2q² = p²。
于是 p² 是偶数 ⟹ p 是偶数，设 p = 2k。
代入：2q² = 4k² ⟹ q² = 2k² ⟹ q² 是偶数 ⟹ q 也是偶数。
p、q 都是偶数 ⟹ 与"互质"矛盾！
所以假设不成立，√2 不是有理数。

这是数学史上记载的第一次"危机"：原来数轴上存在有理数永远填不满的"洞"，√2 就是第一个被点名的那一个。你本章写下的每一个 √a，都站在这个两千五百年前的"大发现"之上。

一句话总结：传说毕达哥拉斯学派的希帕索斯发现 √2 写不成整数之比（还被传说扔进了海里）；反证法证明：若 √2 = p/q 为最简分数，则 p、q 都是偶数，矛盾——这是数学史上的第一次危机。
史那个弯弯的根号 √，是怎么变成现在这样的？（点击展开）

古希腊人求平方根，靠的是文字：欧几里得在《几何原本》里把平方根叫 radix quadrata——拉丁语"正方形的根"。为什么叫"根"？因为从面积（果实）反推边长（根）——开方就像从果实找回它的根，所以整个求平方根的运算就叫做"开根号"（radical）。

到 1525 年，德国数学家克里斯托夫·鲁道夫在一本代数书《Coss》里，第一次用了一个弯弯的符号来表示平方根。这个符号从哪来的？最流行的说法是：数学家们原来用拉丁词 radix 的首字母 r 表示开方，写着写着，那个 r 的尾巴越拉越长、越写越草，最后演变成了今天的 √。

根号顶上的那条横线（把被开方数整个盖住的那一笔），是后来才加上去的——一般归功于 17 世纪的笛卡尔，他把被开方数框进根号的"屋檐"下，这样 √(a+b) 和 √a + b 就不会再搞混了。

所以今天你随手一写的 √a，是"文字 → r → √ → 加横线"好几百年的浓缩：一个符号省下的解释，比它看起来的笔画要多得多。

一句话总结：平方根叫"根"（radix）源自拉丁语"正方形的根"；1525 年鲁道夫首次使用 √ 记号（一般认为由 radix 的首字母 r 演变而来），笛卡尔后来加上盖住被开方数的横线。
趣你手里的 A4 纸，就是 √2 的化身（点击展开）

拿出一张 A4 纸量一量：长 297 mm，宽 210 mm。算一下长宽比：297 ÷ 210 ≈ 1.414…——这不就是 √2 吗？

这不是巧合，是刻意设计的。国际标准 ISO 216（源自德国 1922 年制定的 DIN 476 标准）规定：A 系列纸张的长宽比一律是 √2 : 1。为什么选这么个奇怪的比例？因为它的数学性质太漂亮了：

设纸的长为 L、宽为 W = L/√2（长宽比 = √2）。
沿长边中点对折后，新纸的长 = W，新纸的宽 = L/2。
新长宽比 = W ÷ (L/2) = (L/√2) ÷ (L/2) = 2/√2 = √2。
比例不变！

也就是说：一张 √2 比例的纸，对折再对折，永远还是 √2 的比例。于是 A3 对折就是 A4，A4 对折就是 A5——复印店里的"缩小一半"从来不会变形，课本、试卷、打印纸可以无缝互相拼合、缩放。这个世界的纸张家族，是按一条二次根式的等式运转的。

下次拿起一张 A4 纸时，你可以告诉同桌：这张纸的长宽比，就是你在本章认识的那个老朋友 √2。

一句话总结：A 系列纸张（ISO 216，源自德国 DIN 476）长宽比固定为 √2 : 1，因为这样的纸对折后比例不变——你天天用的 A4 纸就是 √2 的化身。

查看第1题答案

由被开方数 x−3 ≥ 0，得 x ≥ 3。几何上，√a 是「面积为 a 的正方形的边长」，边长只能是正的长度（或 0），而面积也不可能为负——不存在「面积为负」的正方形，所以被开方数必须 ≥ 0，√a 才有意义。

查看第2题答案

√((−9)²) = |−9| = 9。因为 a = −9 是负数，√(a²) = |a|：先平方得 81，再取算术平方根只能取非负的 9，不能取 −9。而 (√9)² = 9 是「先开方、后平方」互相抵消，直接回到 a = 9（此时 a 本身 ≥ 0）。区别：√(a²) 的结果是 |a|（去掉符号后的距离/大小），(√a)² 的结果是 a（前提 a ≥ 0）。

查看第3题答案

边长 = √18 = √(9×2) = 3√2（米）。几何含义：√18 是面积为 18 的正方形的边长，把它换算成「以 √2 为最小尺子」来量，正好是 3 段 √2 的长度——√2 是不可再拆的基本尺子，3 是尺子用了多少次。

查看第4题答案

原边长 = √2，新边长 = √8 = 2√2，所以边长变为原来的 2 倍。因为面积从 2 变成 8，放大了 8÷2 = 4 倍，边长就放大 √4 = 2 倍，即 √8 ÷ √2 = √(8/2) = √4 = 2。

查看第5题答案

√8 + √18 = 2√2 + 3√2 = (2+3)√2 = 5√2。√8 和 √18 表面被开方数不同，但化简后都是 √2 的整数倍——它们共用「同一把 √2 尺子」。于是 2 段 √2 接上 3 段 √2，总共 5 段 √2。不化简就看不出它们是同类（同一把尺子），也就无法合并。

查看第6题答案

边长为 1 的正方形，其对角线 c 满足 c² = 1² + 1² = 2，取正的算术平方根得 c = √2。而 √2 + √2 = 2√2 表示「两条 √2 长的线段首尾拼接」——也就是把这条对角线长度接成原来的 2 倍（2 段 √2 尺子的拼接）。
