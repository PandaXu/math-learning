第18章 平行四边形

初中 / 初二 / 八年级下册

一句话总纲：平行四边形 = 「两组对边分别平行」的四边形，是矩形、菱形、正方形的共同祖先；把两条邻边看成两个力，对角线就是它们的合力（平行四边形法则）。本章既是平面图形的分类与判定，更是「向量合成、力的合成」的几何起点。

18.1 平行四边形的定义与性质

定义

两组对边分别平行的四边形叫做平行四边形，记作 □ABCD，读作"平行四边形 ABCD"。其中"对边"指不相邻的两条边，"对角"指不相邻的两个角。

      D ______________ C
      /              /
     /              /
    /       O      /
   /              /
  A ______________ B

  AB ∥ CD，AD ∥ BC（两组对边分别平行）

判断"对边/对角/邻边"的口诀：对边不共用顶点，对角不共用边。例如 AB 的对边是 CD（中间隔着整个图形），∠A 的对角是 ∠C。

性质（从边、角、对角线、对称性四个角度记）

  1. 边：平行四边形的对边平行且相等。AB = CD，AD = BC。
  2. 角：平行四边形的对角相等，邻角互补。∠A = ∠C，∠B = ∠D；∠A + ∠B = 180°。
  3. 对角线：平行四边形的对角线互相平分。AO = OC，BO = OD（O 为对角线交点）。
  4. 对称性：平行四边形是中心对称图形，对称中心是对角线的交点 O（绕 O 旋转 180° 与自身重合）。
几何含义：平行四边形可以看成「一条线段沿着另一条线段的方向平移扫出来的图形」。从顶点 A 出发，沿 AB 走到 B，再沿 AD 的方向平移到 C，最后反向走回 A——四条边两两平行，正是平移这个基本变换留下的轨迹。因此，平行四边形是"平移"的几何载体，也是"对边平行"这一结构的最小模型。
物理含义（平行四边形法则）：平行四边形最重要的物理应用是力的合成。两个共点力 F₁、F₂ 作用在同一点 A，以它们为邻边作平行四边形，从 A 点出发的那条对角线就表示合力 F 的大小和方向。
      D ______________ C
      /       F      /
     /       ↗      /
    /       /      /
   /       /      /
  A ______/______ B
         F₁ →

  力 F₁ = AB（向右），力 F₂ = AD（向右上）
  合力 F = AC（对角线）：F = F₁ + F₂（向量加法）

反过来，一个力也可以沿两个给定方向"拆开"成两个分力——这就是力的分解的几何依据。高中力学的向量合成与分解，其几何本质正是平行四边形。

18.2 平行四边形的判定

判定是性质的"反过来用"。性质说"是平行四边形 → 会有什么"；判定说"满足什么条件 → 一定是平行四边形"。判定方法按边、角、对角线三类记忆：

  1. 两组对边分别平行的四边形是平行四边形（即定义本身）。
  2. 两组对边分别相等的四边形是平行四边形。
  3. 一组对边平行且相等的四边形是平行四边形。
  4. 两组对角分别相等的四边形是平行四边形。
  5. 对角线互相平分的四边形是平行四边形。
几何含义：五条判定 = "证明一个四边形是平行四边形"的五个等价入口。实际解题时，已知条件里出现了什么，就优先用哪条：给了对角线 → 用第 5 条（对角线互相平分）；给了一组对边平行 → 想办法再证它相等，用第 3 条；给了两组对边相等 → 直接用第 2 条。
物理/工程含义：判定定理是"检验工具"。工程上判断一个四边形框架是否会保持对边平行（即平行四边形结构），最省事的办法是量对角线是否互相平分：对角线互相平分，框架就一定是平行四边形，受力才能沿对边方向对称传递、不产生额外扭转。

18.3 矩形

定义

有一个角是直角的平行四边形叫做矩形（长方形）。只要平行四边形里有一个角是直角，其余三个角跟着都变成直角（邻角互补 + 对角相等）。

性质

  1. 矩形的四个角都是直角（90°）。
  2. 矩形的对角线相等：AC = BD。
  3. 矩形既是轴对称图形（2 条对称轴：过对边中点的两条直线），又是中心对称图形（对称中心为对角线交点）。

重要推论：直角三角形斜边上的中线等于斜边的一半。

   D ______________ C
   |               |
   |       O       |   对角线 AC、BD 相等且互相平分
   |               |
   A ______________ B

  在直角三角形 ABC（∠B = 90°）中，
  斜边 AC 上的中线 BO = AO = OC = 1/2 · AC

这个推论把矩形与直角三角形联系起来：斜边中点到三个顶点的距离相等，也就是"直角三角形外接圆的圆心在斜边中点"。

判定

  1. 有一个角是直角的平行四边形是矩形（定义）。
  2. 对角线相等的平行四边形是矩形。
  3. 有三个角是直角的四边形是矩形。
几何含义：矩形 = 平行四边形 + "角被拉成直角"。平行四边形是"对边平行"，矩形在这个基础上把角固定成 90°，于是图形由"斜的框"变成"正的框"。对角线相等，正是"四角皆直"带来的额外对称。
物理含义：矩形是生活中最常见的"稳定框架"——门、窗、桌面、屏幕、书页。木工、装修要检验一个框架是不是"正矩形"（不歪斜），只需量两条对角线是否相等：对角线相等 → 四个角都是直角 → 框架方正。这就是判定定理在现实中的直接应用。

18.4 菱形

定义

有一组邻边相等的平行四边形叫做菱形。平行四边形只要有一组邻边相等，四条边就都相等了。

性质

  1. 菱形的四条边都相等。
  2. 菱形的对角线互相垂直，并且每一条对角线平分一组对角。
  3. 菱形既是轴对称图形（对称轴是两条对角线所在的直线，共 2 条），又是中心对称图形。

面积公式：菱形面积 = 对角线乘积的一半。

S菱形 = 1/2 · d₁ · d₂      （d₁、d₂ 为两条对角线长）

判定

  1. 有一组邻边相等的平行四边形是菱形（定义）。
  2. 对角线互相垂直的平行四边形是菱形。
  3. 四条边相等的四边形是菱形。
几何含义：菱形 = 平行四边形 + "四条边被拉成一样长"。四条边相等带来强对称性：对角线互相垂直、且每条对角线平分一组对角。菱形可以看成两个共底边的等腰三角形拼成，两条对角线分别是它们的底边与对称轴。
物理/现实含义：菱形高度对称，广泛出现在菱形瓷砖、风筝、扑克牌方块、部分晶体晶格中。对角线互相垂直 = 两条对角线像十字交叉的支架互相垂直支撑，受力沿对角线方向对称分布，结构稳定、铺装无缝。

18.5 正方形

定义

有一组邻边相等，并且有一个角是直角的平行四边形叫做正方形。正方形 = 矩形 + 菱形：它既是矩形，又是菱形。

性质

正方形同时具备矩形和菱形的全部性质：

  1. 四条边都相等，四个角都是直角。
  2. 对角线相等且互相垂直平分，每条对角线平分一组对角。
  3. 正方形有 4 条对称轴（两条对角线 + 过对边中点的两条直线），也是中心对称图形。

判定

  1. 有一组邻边相等的矩形是正方形。
  2. 有一个角是直角的菱形是正方形。
  3. 对角线互相垂直且相等的平行四边形是正方形。

三种特殊平行四边形的对比：

图形边角对角线对称轴
矩形对边平行且相等四个直角相等、互相平分2 条
菱形四边相等对角相等互相垂直、互相平分、平分对角2 条
正方形四边相等四个直角相等、垂直、互相平分、平分对角4 条
几何含义：正方形是"最对称的四边形"——矩形（直角）+ 菱形（等边）的完美叠加。从"平行四边形 → 矩形/菱形 → 正方形"，对称性逐级增强：一般平行四边形只有中心对称，矩形/菱形有 2 条对称轴，正方形有 4 条对称轴，是所有四边形中对称性最强的。
物理/现实含义：正方形的均匀对称带来"各向受力均匀"。像素点、方形瓷砖、棋盘格、魔方、显示屏都取正方形（正方体）结构：四边相等、四角皆直，绕中心每旋转 90° 都恢复原样（4 次旋转对称），铺装无缝、受力无方向偏置。

18.6 三角形的中位线

定义

连接三角形两边中点的线段叫做三角形的中位线。一个三角形有 3 条中位线。

        A
       / \
      /   \
     D-----E      D、E 分别是 AB、AC 的中点
    /       \    → DE 是 △ABC 的一条中位线
   /         \
  B___________C

  DE ∥ BC，且 DE = 1/2 · BC

三角形中位线定理

三角形的中位线平行于第三边，并且等于第三边的一半。

DE ∥ BC   且   DE = 1/2 · BC

注意区分：中位线连接的是两个中点（有 3 条）；中线连接的是一个顶点与对边中点（也有 3 条）。两者不是一回事，做题时先看线段的两个端点连的是"两个中点"还是"顶点 + 中点"。

几何含义：中位线把三角形"缩小一半"。连接三边中点得到的中位三角形，与原三角形相似（相似比 1 : 2），面积是原三角形的 1/4。中位线"平行且取半"，是"缩放 + 平行"这两个基本变换在三角形上的体现。
物理/工程含义：中位线 = "取半的支撑结构"。在桁架、脚手架、桥梁钢架中，连接两根杆的中点加一根横杆（中位线），它承受并传递的力可按比例折算（是底边的一半），实现用更短的材料搭出稳定的三角形骨架——省料且受力关系清晰。

典型例题（自测）

  1. 在 □ABCD 中，∠A = 60°，求 ∠B、∠C、∠D 的度数。
  2. 在 □ABCD 中，对角线 AC、BD 交于点 O，若 AC = 8，BD = 6，求 AO、BO 的长。
  3. 矩形 ABCD 中，AB = 3，BC = 4，求对角线 AC 的长，以及斜边 AC 上的中线长。
  4. 菱形 ABCD 的对角线 AC = 6，BD = 8，求菱形的边长与面积。
  5. 判断对错：① 对角线相等的四边形是矩形；② 对角线互相垂直的四边形是菱形；③ 对角线互相垂直且相等的四边形是正方形。
  6. 在 △ABC 中，D、E 分别是 AB、AC 的中点。若 BC = 10，求 DE；若 DE = 4，求 BC。
  7. 两个共点力 F₁ = 3 N、F₂ = 4 N 相互垂直，用作平行四边形法则求合力的大小。

常见误区

  • ❌ "对角线相等的四边形是矩形" → ❌ 必须是平行四边形；等腰梯形的对角线也相等，但不是矩形。正确的是"对角线相等的平行四边形是矩形"。
  • ❌ "对角线互相垂直的四边形是菱形" → ❌ 必须是平行四边形。正确的是"对角线互相垂直的平行四边形是菱形"。
  • ❌ "对角线互相垂直且相等的四边形是正方形" → ❌ 必须是平行四边形。正确的是"对角线互相垂直且相等的平行四边形是正方形"。
  • ❌ "有一组邻边相等的四边形是菱形" → ❌ 必须是平行四边形。正确的是"有一组邻边相等的平行四边形是菱形"。
  • ❌ "矩形的对角线互相垂直" → ❌ 矩形的对角线只相等、互相平分，不垂直；只有菱形和正方形的对角线才垂直。
  • ❌ "菱形的四个角相等" → ❌ 菱形只有对角相等；四个角都相等的是正方形。
  • ❌ "三角形中位线 = 中线" → ❌ 中位线连接两个中点，中线连接顶点与对边中点，是两种不同的线段。
  • ❌ "平行四边形是轴对称图形" → ❌ 一般平行四边形只有中心对称；只有矩形、菱形、正方形才有轴对称。

本章练习卷（含答案）

一、练习题

  1. 在 □ABCD 中，∠A = 65°，求 ∠B、∠C、∠D 的度数。
  2. 在 □ABCD 中，对角线 AC、BD 相交于点 O，AC = 10，BD = 12，求 AO、BO 的长。
  3. 矩形 ABCD 中，AB = 5，BC = 12，求对角线 AC 的长，以及直角三角形 ABC 斜边 AC 上的中线长。
  4. 菱形 ABCD 的两条对角线 AC = 12，BD = 16，求菱形的边长与面积。
  5. 判断下列命题对错，并说明理由：① 对角线相等的四边形是矩形；② 对角线互相垂直的四边形是菱形；③ 对角线互相垂直且相等的四边形是正方形。
  6. 在 △ABC 中，D、E 分别是 AB、AC 的中点，若 BC = 14，求 DE；又若两个共点力 F₁ = 6 N、F₂ = 8 N 相互垂直，用平行四边形法则求合力大小。

二、参考答案（点击展开）

查看第1题答案

∠C = ∠A = 65°（对角相等）；∠B = ∠D = 180° − 65° = 115°（邻角互补）。

查看第2题答案

平行四边形对角线互相平分，所以 AO = AC/2 = 5，BO = BD/2 = 6。

查看第3题答案

由勾股定理 AC = √(5² + 12²) = 13；直角三角形斜边上的中线等于斜边的一半，故中线 = 13/2 = 6.5。

查看第4题答案

菱形对角线互相垂直平分，边长 = √((12/2)² + (16/2)²) = √(36 + 64) = 10；面积 = 对角线乘积的一半 = 12 × 16 ÷ 2 = 96。

查看第5题答案

①②③ 都错。矩形、菱形、正方形的这些判定，前提都必须是「平行四边形」：等腰梯形的对角线也相等但不是矩形；对角线互相垂直的普通四边形不一定是菱形；对角线互相垂直且相等的普通四边形（如筝形）也不一定是正方形。正确说法应为「对角线相等的平行四边形是矩形」「对角线互相垂直的平行四边形是菱形」「对角线互相垂直且相等的平行四边形是正方形」。

查看第6题答案

DE 是 △ABC 的中位线，DE = BC/2 = 7。力的合成：以 F₁ = 6 N、F₂ = 8 N 为邻边的矩形，合力即对角线，F = √(6² + 8²) = 10 N。
