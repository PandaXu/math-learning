第1章 有理数

初中 / 初一 / 七年级上册

一句话总纲：有理数 = 「数轴上的所有整数和分数点」。学完本章，你要能在心里"看见"一条数轴——负数在左边、正数在右边、0 在中间，每一个运算规则都能还原成数轴上的"移动、翻转、拉伸"。

1.1 正数和负数

为什么需要负数？（物理含义）

现实中有大量"相反意义的量"，用正负号区分方向：

场景正负
温度零上 5℃ = +5零下 5℃ = -5
海拔海平面以上 300m = +300海平面以下 100m = -100
财务收入 200 元 = +200支出 200 元 = -200
运动向东走 3km = +3向西走 3km = -3
核心直觉：正负号不是"大小"，而是 方向 + 基准点（0）。0 是"基准/分界"，它既不是正数也不是负数；正数 > 0，负数 < 0。

一句话记牢：负数是"反方向"的数。温度的 +5 和 -5 离 0 一样远，只是方向相反。

基本概念

  • 正数：大于 0 的数，如 +3、1/2、2.7。
  • 负数：在正数前面加 "−" 号，如 −3、−1/2、−2.7。
  • 0：既不是正数也不是负数，是正负的分界。
  • 具有相反意义的量：必须"同类 + 单位一致"，如"上升 3m"与"下降 3m"。

1.2 有理数、数轴、相反数、绝对值

有理数的定义

整数：…, −3, −2, −1, 0, 1, 2, 3, …（正整数、0、负整数）
分数：能写成 a/b（a、b 是整数，b≠0）形式的数，如 1/2、−3/4。

有理数 = 整数 + 分数。

💡 为什么叫「有理数」？—— 一个词源小故事（点击展开）

一句话答案：有理数 = 能写成「两个整数之比」的数。英文 rational number 里的 rational 来自拉丁语 ratio（比、比例）：

有理数 = { a/b ｜ a、b 是整数，b ≠ 0 }

为什么中文叫「有理」？

  • 英文原意：rational 在数学语境里本义是「可比的」（来自 ratio），即「能表示成两个整数之比」。
  • 清末翻译：1850 年代，数学家李善兰与传教士伟烈亚力合译西方数学时，把 rational number 译成「有理数」——很可能是取了 rational 的另一个意思「合理的」。
  • 所以严格说，更贴切的译名应是「比数」，但「有理数」已沿用 160 多年，约定俗成。

对面的「无理数」呢？

irrational number（无理数）本义是「不能写成两个整数之比」的数，如 √2、π（无限不循环小数）。「无理」≠「没道理」——√2 就是正方形对角线的长度，非常有道理，只是它写不成 a/b 而已。（到第 6 章「实数」会正式见到。）

回到几何：有理数是数轴上所有「整数点 + 分数点」；无理数是那些永远对不准任何 a/b 刻度的点，它们藏在有理数之间，却一个都不是。

关键认识：有限小数和无限循环小数都能化成分数，所以它们都是有理数。例：0.5 = 1/2，0.333… = 1/3，−0.75 = −3/4。（反过来，像 π、√2 这种"无限不循环"的小数不是有理数，到第6章会见到。）

数轴（几何含义的核心！）

数轴三要素：原点（0）、正方向（通常向右）、单位长度。把每一个有理数都对应到数轴上一个点，这就是数与形的第一次统一。

  -4   -3   -2   -1    0    1    2    3    4
   |----|----|----|----|----|----|----|----|
             ← 负方向      ↑     正方向 →
                       原点
  • 正数在原点右边，负数在原点左边。
  • 右边的数总比左边的数大（这是比较大小的根本方法）。
  • 数轴是"一把无限长的标尺"，0 是刻度起点。

相反数（几何：关于原点的对称）

  • 只有符号不同的两个数互为相反数，如 +3 和 −3。
  • 几何含义：相反数在数轴上位于原点两侧，且到原点的距离相等——它们关于原点对称。
  • 0 的相反数是 0。
  • 记法：a 的相反数是 −a。注意 −a 不一定是负数：当 a = −3 时，−a = 3 是正数。

绝对值（几何：距离！）

定义：数轴上，一个数对应的点到原点的距离，叫做这个数的绝对值，记作 |a|。

  • |+3| = 3，|−3| = 3（都离原点 3 个单位）；|0| = 0

分情况（代数表达）：

        ┌  a    (a > 0)
 |a| =  ├  0    (a = 0)
        └ −a    (a < 0)

核心结论：

  1. |a| ≥ 0（距离不可能为负）。
  2. |a| = |−a|（相反数到原点距离相等）。
  3. 两个负数比大小：绝对值大的反而小。例：−3 < −2，因为 |−3| = 3 > 2 = |−2|（−3 离 0 更远，在更左边）。
物理含义：绝对值 = "去掉方向只留大小"。速度有方向（+3 m/s 向东、−3 m/s 向西），但"速率" = |速度| = 3 m/s，只关心快慢。

1.3 有理数的加减法（数轴上的"移动"）

加法法则

同号相加：取相同符号，绝对值相加。 (+3) + (+2) = +5；(−3) + (−2) = −5

异号相加：取绝对值较大的符号，用大绝对值减小绝对值。 (+5) + (−3) = +2；(+3) + (−5) = −2

互为相反数相加：得 0。如 (+3) + (−3) = 0。

几何含义：加法就是在数轴上移动。从 0 出发，"+3" 向右走 3 步，"再 −2" 向左走 2 步，最终停在 +1。

减法法则：减去一个数 = 加上它的相反数

a − b = a + (−b)
  • 3 − 5 = 3 + (−5) = −2
  • (−3) − (−5) = (−3) + (+5) = +2
为什么？减法就是"反向移动"。减去一个正数 = 向左走；减去一个负数 = 向左的相反 = 向右走。例："−3 − (−5)"：从 −3 出发，"减去 −5" 相当于把方向翻过来向右走 5 步，到 +2。

口诀：减负等于加正；减正等于加负。

1.4 有理数的乘除法（数轴上的"翻转与拉伸"）

乘法法则

符号规则（两数相乘）：

  • 同号得正：正×正=正，负×负=正
  • 异号得负：正×负=负，负×正=负
  • 任何数 × 0 = 0

绝对值相乘，再定符号。 (−3) × (−4) = +12；(−3) × 4 = −12

几何/物理含义：乘以一个负数 = 方向翻转（关于原点镜像）+ 长度拉伸。3 × (−1)：把 3 翻到 −3（乘以 −1 就是"镜像翻转"）；(−3) × (−1)：把 −3 再翻一次，回到 +3。负负得正 = 翻两次回到原点另一侧（即原位）。

多个数相乘的符号：数一数负号的个数——负号个数为偶数 → 结果为正；负号个数为奇数 → 结果为负。

倒数（几何：互为"倒置"）

  • 乘积为 1 的两个数互为倒数，如 2 与 1/2，−3/4 与 −4/3。
  • 0 没有倒数（因为不存在数与 0 相乘得 1）。

除法法则：除以一个数 = 乘它的倒数

a ÷ b = a × (1/b)   (b ≠ 0)
  • 符号规则与乘法相同：同号得正，异号得负。 (−12) ÷ (−4) = +3；12 ÷ (−4) = −3

一句话：除法是乘法的逆运算，除一个数等于乘它的倒数，符号规则完全一样。

1.5 有理数的乘方与科学记数法

乘方

aⁿ = a × a × … × a   (n 个 a 相乘)
  • a 叫底数，n 叫指数，aⁿ 读作 "a 的 n 次方"。
  • 正数的任何次幂都是正数。
  • 负数的偶次幂是正数，奇次幂是负数。 (−2)² = 4，(−2)³ = −8
  • 注意：(−2)² = 4，但 −2² = −(2²) = −4（负号在括号外，先算乘方再取负）。

科学记数法（物理含义：书写极大/极小量）

把数写成 a × 10ⁿ（1 ≤ |a| < 10，n 为整数）：

  • 地球到太阳的距离约 149,600,000 km = 1.496 × 10⁸ km
  • 光速约 300,000,000 m/s = 3 × 10⁸ m/s
  • 一个原子的直径约 0.0000000001 m = 1 × 10⁻¹⁰ m
科学记数法的本质：10 的幂次 = 小数点的移动位数，让极大/极小的物理量一眼可读。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
正负数原点两侧的方向温度、海拔、收支的相反量
数轴数与点一一对应的标尺一条有方向、有刻度、有原点的"位置轴"
相反数关于原点的对称点大小相同、方向相反的两种状态
绝对值到原点的距离去掉方向后的"大小"（速率、长度）
加法数轴上的平移（移动）连续位移的合成
减法加相反数（反向移动）反向位移
乘法拉伸 + 关于原点翻转缩放与方向反转（负号=翻转）
除法乘倒数按比例缩小（倒数=反向缩放）
乘方连乘指数增长（面积=平方、体积=立方）
科学记数法——极大/极小量的紧凑书写

典型例题（自测）

  1. 在数轴上标出：−3、0、+2、−1.5，并从小到大排列。
  2. 求 |−7|、|+7|、|0|，并比较 −7 与 +7、−7 与 −9 的大小。
  3. 计算：(−8) + (+3)、(−8) − (−3)、(−8) × (−3)、(−8) ÷ 4。
  4. 判断符号：(−1)²⁰²⁴ 与 (−1)²⁰²⁵ 各是多少？
  5. 把 0.000000001 用科学记数法表示；把 −2.5 × 10⁶ 写成普通数。

常见误区

  • ❌ "−a 一定是负数" → ❌ 当 a 是负数时 −a 是正数。
  • ❌ "绝对值是去掉负号" → ❌ 绝对值是"到原点的距离"，恒非负，是几何概念。
  • ❌ "−2² = 4" → ❌ −2² = −4，先乘方后取负；(−2)² 才是 4。
  • ❌ "0 有倒数" → ❌ 0 没有倒数，除数不能为 0。
  • ❌ "两个负数比较大小看绝对值大的就大" → ❌ 绝对值大的负数反而小。

课本外 · 趣味延伸：为什么无理数才是数字王国的"绝对主力"？

趣点击展开：数轴上几乎所有的点都是无理数——三个层次的震撼真相

第一层：数轴上的"密度"骗了你的眼睛

如果你看数轴，有理数密密麻麻，任何两个有理数之间（比如 1 和 2 之间）都有无穷多个有理数（1.1、1.11、1.111……）。这会给你一种错觉：有理数把数轴填满了。

但真相是：有理数虽然"密密麻麻"，却像空气中的灰尘——分布很广，但"总体积"为零。数轴上几乎所有的点，都是无理数。

第二层：康托尔的"无穷大"比较（核心暴击）

数学家康托尔用了一个绝妙的办法证明：无理数比有理数多得多，而且是不同等级的"无穷"。

  • 有理数是可以"排队"的：你可以把所有的分数排成一个序列（1/1, 1/2, 2/1, 1/3, 2/2, 3/1……）。既然能排成一列，它就属于"可数无穷"（阿列夫零），跟自然数的个数一样多。
  • 无理数是无法排队的：康托尔用"对角线证明"告诉你，无论你怎么试图给无理数编号，永远会有漏网之鱼。它属于"不可数无穷"（阿列夫一）。

打个比方：有理数像天上的星星（虽然很多，但你可以数），无理数像地上的沙子（你根本数不完）。在数学上，这两个"无穷大"不在同一个量级。

第三层：随机选一个数，几乎必是无理数

这是一个极其震撼的结论：如果让你在数轴上随便戳一个点（完全随机），你戳到有理数的概率是 0%，戳到无理数的概率是 100%。

因为有理数虽然无穷，但在整个实数范围里，它们就像大海里的几滴水。你随手一捞，捞到"水珠"（有理数）的概率接近零，捞到"海水"（无理数）是必然。

一句话总结：我们小学到大学做的大量算术题，几乎都在研究那 0% 的有理数；而那个占 100% 的无理数（π、e、√2），我们只能靠"无限逼近"去近似它，永远写不完它的精确值。所以，"不讲道理"的，才是这个宇宙的常态——现实中的物理常数、自然界的大多数长度比例，几乎都是无理数。

本章练习卷（含答案）

一、练习题

  1. 某地一天最高气温记作 +6℃，最低气温记作 −3℃。这一天最高气温比最低气温高多少？这两个数中哪个更接近 0？
  2. 在数轴上描出 −4、−1、0、+2、−2.5 五个点，并把它们从小到大排列；再写出 −4 的相反数和绝对值。
  3. 计算：(−15) + (+8)、(−9) − (−4)、(−6) × (+7)、(−56) ÷ (−8)。
  4. 计算：(−2)⁴ 与 −2⁴ 各等于多少？它们相等吗？为什么？
  5. 把 0.000 000 025 用科学记数法表示；再把 3.6 × 10⁶ 写成普通数。
  6. 从 0 出发，先"向东走 5 步"记为 +5，再"向西走 8 步"记为 −8。最终停在数轴的什么位置？这对应哪个算式？

二、参考答案（点击展开）

查看第1题答案

高 9℃：6 − (−3) = 6 + 3 = 9。更接近 0 的是 −3，因为 |−3| = 3 < 6 = |+6|（离原点更近）。

查看第2题答案

从小到大：−4 < −2.5 < −1 < 0 < +2（数轴上右边的数总比左边的大）。−4 的相反数是 +4，绝对值 |−4| = 4（到原点的距离）。

查看第3题答案

(−15)+(+8)=−7（异号，取绝对值大的符号，15−8=7）；(−9)−(−4)=(−9)+(+4)=−5；(−6)×(+7)=−42（异号得负）；(−56)÷(−8)=+7（同号得正）。

查看第4题答案

(−2)⁴ = 16（负数的偶次幂为正），−2⁴ = −(2⁴) = −16（负号在括号外，先算乘方再取负）。它们不相等，相差一个符号。

查看第5题答案

0.000 000 025 = 2.5 × 10⁻⁸（小数点向右移 8 位）；3.6 × 10⁶ = 3,600,000（小数点向右移 6 位）。

查看第6题答案

最终停在 −3（从 0 向右 5 到 +5，再向左 8 到 −3）。对应算式：(+5) + (−8) = −3。
