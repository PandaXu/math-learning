第4章 几何图形初步

初中 / 初一 / 七年级上册

一句话总纲：世界由「点、线、面、体」构成，它们靠运动互相生成：点动成线、线动成面、面动成体。这是几何的起点。
本章目录 4.1 几何图形4.2 直线、射线、线段4.3 角含义总结典型例题常见误区

4.1 几何图形

立体图形（占据空间的图形）

  • 柱体：长方体、正方体、圆柱、棱柱（上下底面全等）
  • 锥体：圆锥、棱锥（一个底面，收拢到一个顶点）
  • 球体：球
  • 台体：圆台、棱台（锥体截去顶）
几何直觉：柱体 = "底面沿一条直线平移扫出来"；锥体 = "底面收缩到一个点"；球 = "一个圆绕直径旋转"。

平面图形（画在平面内的图形）

三角形、四边形（长方形、正方形、平行四边形、梯形）、圆、线段、角、直线、射线等。

点、线、面、体

  • 体：由面围成，如长方体有 6 个面。
  • 面：有平面、曲面（如圆柱侧面是曲面）。
  • 线：面与面相交得到线（如长方体的棱）。
  • 点：线与线相交得到点（如长方体的顶点）。

运动生成（核心思想！）

运动结果
点动成线笔尖划过纸 → 线；流星划过夜空 → 光线
线动成面雨刷扫过 → 扇形面；门的一条边转动 → 面
面动成体长方形绕一边旋转 → 圆柱；直角三角形绕直角边旋转 → 圆锥
物理含义：这是"维度递增"的直觉——0维(点) → 1维(线) → 2维(面) → 3维(体)。旋转体（圆柱、圆锥、球）本质都是"一个平面图形绕一条轴旋转"。

展开图

把立体图形表面剪开铺平得到展开图。正方体的展开图有 11 种（分为"141、231、222、33"四类）。训练空间想象力：看到一个立体，能在脑子里"拆开铺平"和"折起来还原"。

4.2 直线、射线、线段

三种线的区别

图形端点延伸表示
直线0 个向两方无限延伸直线 AB 或直线 l
射线1 个向一方无限延伸射线 AB（A 是端点）
线段2 个不能延伸线段 AB 或线段 a

两条基本事实（公理）

  1. 两点确定一条直线（过两点有且只有一条直线）。物理应用：木匠用两个点弹墨线；两个钉子固定一块木板。
  2. 两点之间，线段最短。物理应用：光沿直线传播；"两点之间直线最近"；蚂蚁走直线最短。

线段的比较与中点

  • 比较：度量法（用刻度尺量）或叠合法（把一条线段移到另一条上比）。
  • 中点：把线段分成两条相等线段的点。若 C 是线段 AB 的中点，则 AC = BC = ½AB。
几何含义：中点 = 线段上到两端距离相等的点（也是线段的"对称中心"）。

4.3 角

角的概念

静态定义：有公共端点的两条射线组成的图形，公共端点叫顶点，两条射线叫边。
动态定义：一条射线绕端点旋转到另一个位置形成的图形。

物理含义：角 = 旋转量。钟表指针转过的角度、门转过的角度，都是"转动"。

角的度量（度、分、秒）

  • 单位：度（°）、分（′）、秒（″）
  • 换算（六十进制）：1° = 60′，1′ = 60″
  • 例：0.5° = 30′；1.25° = 1°15′

角的分类：

角大小
锐角0° < α < 90°
直角α = 90°
钝角90° < α < 180°
平角α = 180°（两条边成一直线）
周角α = 360°（转一整圈）

角的比较与运算

  • 比较：度量法、叠合法。
  • 角的和差：两个角可以相加、相减。
  • 角平分线：从顶点出发，把角分成两个相等角的射线。若 OC 是 ∠AOB 的平分线，则 ∠AOC = ∠COB = ½∠AOB。

余角和补角

  • 余角：两个角的和等于 90°（直角），则互余。如 30° 与 60°。
  • 补角：两个角的和等于 180°（平角），则互补。如 120° 与 60°。
  • 性质：同角（或等角）的余角相等；同角（或等角）的补角相等。
几何直觉：互余 = 两个角拼成一个直角；互补 = 两个角拼成一条直线（平角）。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
点线面体维度递进的基本元素空间的层次结构
点动成线…运动生成图形轨迹（流星、雨刷、旋转）
两点确定一直线唯一的连接弹墨线、钉木板
两点之间线段最短最短路径光沿直线传播
线段中点到两端等距对称中心、重心平衡点
角两条射线的张开程度旋转量、方向差
角平分线把角平分均匀分割方向
余角/补角拼成直角/平角两角合成特定姿态

典型例题（自测）

  1. 长方体有几个面、几条棱、几个顶点？
  2. 下列能确定一条直线的是：过一点、过两点、过三点？
  3. 线段 AB = 10 cm，C 是 AB 的中点，D 是 AC 的中点，求 AD 的长。
  4. 把 25.2° 化成度分秒；把 15°30′ 化成度。
  5. 一个角的补角是它的 3 倍，求这个角的度数。（提示：设角为 x，补角 180° − x = 3x）

常见误区

  • ❌ "射线 AB 和射线 BA 是同一条射线" → ❌ 端点不同（A 与 B），方向相反。
  • ❌ "两点之间直线最短" → ❌ 准确说法是"两点之间线段最短"（直线无限长）。
  • ❌ "1° = 100′" → ❌ 度分秒是六十进制：1° = 60′，1′ = 60″。
  • ❌ "锐角 + 钝角 = 平角" → ❌ 不一定，如 30° + 100° = 130° ≠ 180°。
  • ❌ "互为余角的两角一定有一个锐角" → ❌ 两角都为 45° 时也互余（90°）。

本章练习卷（含答案）

一、练习题

  1. （概念·点线面体）填空：点动成____、线动成____、面动成____；正方体有____个面、____条棱、____个顶点。
  2. （判断·射线）「射线 AB 和射线 BA 是同一条射线」这句话对吗？为什么？
  3. （判断·公理）「两点之间直线最短」这句话对吗？正确的说法应该是什么？
  4. （计算·线段中点）线段 AB = 12 cm，C 是 AB 的中点，D 是 AC 的中点，求 AD 的长。
  5. （计算·度分秒）把 25.2° 化成度分秒；把 15°30′ 化成度。
  6. （综合·余补角）一个角的补角是它的 3 倍，求这个角的度数。

二、参考答案（点击展开）

查看第1题答案

线、面、体；正方体有 6 个面、12 条棱、8 个顶点。依据：点动成线（笔尖画线）、线动成面（雨刷扫过）、面动成体（长方形绕一边旋转成圆柱）。

查看第2题答案

不对。射线 AB 以 A 为端点、向 B 方向延伸；射线 BA 以 B 为端点、向 A 方向延伸，二者端点不同、方向相反，是两条不同的射线。

查看第3题答案

不对。正确说法是「两点之间线段最短」——直线向两方无限延伸，谈不上「最短」。同时注意另一条基本事实：两点确定一条直线（过两点有且只有一条直线）。

查看第4题答案

C 是 AB 中点 → AC = BC = ½×12 = 6 cm；D 是 AC 中点 → AD = ½×6 = 3 cm。答：AD = 3 cm。

查看第5题答案

25.2° = 25° + 0.2×60′ = 25°12′；15°30′ = 15 + 30÷60 = 15.5°。（度分秒为六十进制：1° = 60′，1′ = 60″）

查看第6题答案

设这个角为 x，则补角 = 180° − x。由题意 180° − x = 3x，得 180° = 4x，x = 45°。答：这个角是 45°。
