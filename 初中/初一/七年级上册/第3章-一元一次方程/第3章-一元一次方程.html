第3章 一元一次方程

初中 / 初一 / 七年级上册

一句话总纲：方程是「天平」——等号是支点，两边必须保持平衡。解方程就是"在天平上搬东西"，每一步都保证平衡不被破坏，最终把未知数 x 单独留在一边，答案自然露出来。

3.1 从算式到方程

什么是方程？

方程：含有未知数的等式。

  • 是方程：x + 3 = 7、2x − 1 = 0、3y = 12
  • 不是方程：3 + 2 = 5（没未知数）、x + 3（不是等式）

一元一次方程：只含一个未知数，未知数的次数是 1，且等号两边都是整式。是：2x − 1 = 0；不是：x² = 4（次数 2）、x + y = 3（两个未知数）。

方程的解：使方程左右两边相等的未知数的值，也叫根。例：x = 3 是方程 x + 4 = 7 的解（因为 3 + 4 = 7）。解方程：求方程解的过程。

物理含义：方程 = 天平平衡。左边 = 右边 相当于天平两端放上砝码后平衡；未知数 x = 一个"不知道多重、但已知平衡关系"的砝码。

等式的性质（解方程的"合法操作"）

  1. 等式两边加（或减）同一个数（或式子），结果仍相等： 
    若 a = b，则 a ± c = b ± c
  2. 等式两边乘同一个数，或除以同一个不为 0 的数，结果仍相等： 
    若 a = b，则 ac = bc；a/c = b/c (c ≠ 0)
天平直觉：两边同时放上/拿走相同的砝码，或同时放大/缩小相同的倍数，天平依然平衡。注意：除以 0 是禁止的。

3.2 解一元一次方程

核心目标

把方程化成 x = a 的形式（"x 等于多少"）。

方法一：移项

规则：把方程中的某项从等号一边移到另一边时，必须变号。

x + 3 = 7
x = 7 − 3      （把 +3 移到右边，变成 −3）
x = 4
为什么移项要变号？其实移项 = 等式性质1（两边同时减 3）：x + 3 − 3 = 7 − 3，即 x = 7 − 3。表面看是"+3 跑到右边变成 −3"，本质是"两边同时拿走 3"。

方法二：去括号

3(x + 2) = 15
3x + 6 = 15      （分配律去括号）
3x = 15 − 6      （移项）
3x = 9
x = 3            （两边同除以 3）

方法三：去分母

当方程含分数时，两边同乘以所有分母的最小公倍数，化分数为整数。

x/2 + x/3 = 5
3x + 2x = 30     （两边同乘 6，即分母 2、3 的最小公倍数）
5x = 30
x = 6

解一元一次方程的完整五步

  1. 去分母：两边同乘最小公倍数；
  2. 去括号：分配律；
  3. 移项：含 x 的项移到一边，常数移到另一边（变号）；
  4. 合并同类项；
  5. 系数化为 1：两边同除以 x 的系数。

口诀：去分母 → 去括号 → 移项 → 合并 → 系数化 1。检验方法：把求出的 x 代回原方程，看两边是否相等。

3.3 实际问题与一元一次方程

解题四步（"建模"思想）

  1. 设未知数：用 x 表示题目所求；
  2. 找等量关系：找到题目中"相等"的那句话（关键）；
  3. 列方程：把等量关系翻译成含 x 的等式；
  4. 解方程并检验：解出 x，代回原题看是否符合实际。

经典题型

① 行程问题（路程 = 速度 × 时间，s = vt）

  • 甲、乙两地相距 120 km，一辆车以 40 km/h 出发，几小时到达？设需 x 小时，则 40x = 120，x = 3（小时）。

② 利润/折扣问题（售价 = 进价 × (1 + 利润率)）

  • 一件衣服进价 80 元，按 20% 利润定价后打 9 折出售，售价多少？售价 = 80 × (1 + 20%) × 90% = 80 × 1.2 × 0.9 = 86.4（元）。

③ 工程问题（工作量 = 效率 × 时间）

  • 一项工程，甲单独做 6 天完成，乙单独做 12 天完成，两人合作几天完成？甲效率 1/6，乙效率 1/12，设合作 x 天： 
    (1/6 + 1/12)x = 1  →  (1/4)x = 1  →  x = 4（天）

④ 配套/比例问题：找"份数相等"的关系列方程。

本质：所有应用题都是"翻译"——把一句中文等量关系翻译成一个数学等式。最难的一步是找等量关系。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
方程等号=天平的支点平衡状态的数学描述
等式的性质两边同步操作仍平衡天平两边同加同减同乘同除
移项把量搬到天平另一边（变号）把砝码从一边挪到另一边
解方程把 x 单独"隔离"出来求出未知砝码的重量
一元一次方程数轴上求"某个位置"直线与 x 轴的交点（更高观点）
应用题——把现实问题翻译成数学
更高观点的几何含义（为将来埋伏笔）：方程 ax + b = 0 可以看成"函数 y = ax + b 的值为 0"，它的解 x = −b/a 就是直线 y = ax + b 与 x 轴交点的横坐标。到"一次函数"（初二）时你会重新认识它。

典型例题（自测）

  1. 判断：下列哪些是一元一次方程？2x − 1 = 0、x² = 9、x + y = 5、3x = 6。
  2. 解方程：5x − 3 = 2x + 6
  3. 解方程：(x + 2)/3 − (x − 1)/2 = 1
  4. 小明今年 x 岁，爸爸今年 40 岁，5 年后爸爸的年龄是小明的 2 倍，求 x。
  5. 解方程并检验：4 − 3(2 − x) = 5x

常见误区

  • ❌ "移项不变号" → ❌ 移项必须变号（本质是两边同时加减）。
  • ❌ "两边同除以 0" → ❌ 0 不能作除数。
  • ❌ "去分母时漏乘不含分母的项" → ❌ 去分母要每一项都乘最小公倍数。
  • ❌ "解出 x 后不检验" → ❌ 应代回原方程验证，应用题还要看是否符合实际。
  • ❌ "设未知数不明确" → ❌ 要写清"设什么为 x"。

课本外 · 典故与思考

典刻在墓碑上的方程——"代数之父"丢番图留给后人的年龄谜题（点击展开）

丢番图（Diophantus，约公元3世纪）是古希腊研究方程的先驱。关于他流传下来最著名的"作品"，据说刻在他的墓碑上（见于后世文献记载）：

  • 他生命的 1/6 是童年；
  • 再过 1/12，他长出了胡子；
  • 又过 1/7，他结了婚；
  • 婚后 5 年，他有了一个儿子；
  • 儿子活到父亲寿命的 一半就去世了；
  • 儿子去世 4 年后，父亲也去世了。

设丢番图活了 x 岁，这些"人生大事"加起来就是他的全部寿命，直接翻译成方程：

x/6 + x/12 + x/7 + 5 + x/2 + 4 = x

通分合并得 25x/28 + 9 = x，移项得 9 = 3x/28，所以 x = 84。

一句话总结：一千七百多年前的人，就把"人生大事"写成了方程——方程不是课本发明的，而是人类很早就在用的思维工具。
思算术是"倒着算"，方程是"正着想"——同一道题的两种思维（点击展开）

看这道题："一个数加上 3 再乘 2，结果等于 10。这个数是多少？"

算术解法（逆向）：从结果倒着推——10 ÷ 2 = 5，5 − 3 = 2。每一步都把题目里的运算"反过来"做。

方程解法（顺向）：设这个数为 x，直接把题目按顺序翻译成等式 (x + 3) × 2 = 10，再按规则解。思路和题目叙述的顺序完全一致。

为什么方程更强大？

  • 题目越绕，逆向越容易算错（把"加"想成"减"、把"乘"想成"除"）；正向翻译永远只有一条路。
  • 方程的思路可以"机械化"：只要规则固定，谁都能一步步做下去——这正是后来计算机解数学题的方式。
  • 遇到"一半多3、再剩4"这类连环条件，算术倒推几乎让人抓狂，方程却只是"排好队翻译"。
一句话总结：算术是"摸着答案往回找"，方程是"把条件排好队，顺着问答案"——学会设 x，就是学会把难题"正过来想"。

本章练习卷（含答案）

一、练习题（由易到难，先独立完成再看答案）

  1. 判断：下列哪些是一元一次方程？① 3x = 6；② x² = 9；③ x + y = 5；④ 2x − 1 = 0。
  2. 解方程：5x − 3 = 2x + 6。
  3. 解方程：3(x + 2) = 15。
  4. 解方程：x/2 + x/3 = 5。
  5. 解方程：(x + 2)/3 − (x − 1)/2 = 1。
  6. 应用题：甲、乙两地相距 120 km，一辆车以 40 km/h 匀速行驶，几小时到达？请设未知数并列方程求解。

二、参考答案（点击展开）

查看第1题答案

一元一次方程要求：只含一个未知数、次数为 1、两边都是整式。① 3x = 6 是；④ 2x − 1 = 0 是。② x² = 9 次数为 2，③ x + y = 5 含两个未知数，均不是。

查看第2题答案

移项：5x − 2x = 6 + 3 → 3x = 9 → x = 3。检验：左 = 5×3 − 3 = 12，右 = 2×3 + 6 = 12，相等，x = 3 正确。

查看第3题答案

去括号：3x + 6 = 15 → 移项：3x = 15 − 6 = 9 → 系数化为 1：x = 3。

查看第4题答案

去分母：两边同乘 6（2、3 的最小公倍数）→ 3x + 2x = 30 → 5x = 30 → x = 6。

查看第5题答案

去分母：两边同乘 6 → 2(x + 2) − 3(x − 1) = 6 → 2x + 4 − 3x + 3 = 6 → −x + 7 = 6 → −x = −1 → x = 1。注意去括号时“−3(x−1)”要变号。

查看第6题答案

设需 x 小时，由“路程 = 速度 × 时间”列方程：40x = 120 → x = 3。答：3 小时到达。检验：40 × 3 = 120，符合题意。
