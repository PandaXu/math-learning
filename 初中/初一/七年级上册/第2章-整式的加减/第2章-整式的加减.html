第2章 整式的加减

初中 / 初一 / 七年级上册

一句话总纲：字母代表「变化的量」，整式是"用字母写规律的句子"；整式的加减本质就是合并同类项——把"同一种东西"归到一起。本章是从「算术（算具体数字）」走向「代数（用字母表示规律）」的关键转折。

2.1 整式：单项式、多项式

为什么需要字母？（物理含义）

当数量会变化、或有一般规律时，用字母代替具体数字：

场景用字母表达
长方形面积长 a、宽 b → 面积 S = ab
匀速运动路程速度 v、时间 t → 路程 s = vt
正方形周长边长 a → 周长 C = 4a
规律1, 2, 3, …, n → 第 n 个是 n
核心直觉：字母 = 一个"随时可以代入具体值的占位符"。数字只能算"这一个"，字母能表达"这一类"。

单项式（monomial）

定义：由数与字母的乘积组成的式子叫单项式。单独一个数或一个字母也是单项式。例：3x²、−5a、x、7、0、−2/3·ab 都是单项式。反例：x + 1（有加减号）、3/x（字母在分母）不是单项式。

两个关键属性：

  1. 系数：单项式中的数字因数。如 3x² 的系数是 3，−5a 的系数是 −5，x 的系数是 1（省略不写）。
  2. 次数：所有字母的指数之和。3x²：次数 2；−2/3·ab：次数 1 + 1 = 2；7（不含字母）：次数为 0，叫"零次单项式"。
几何直觉：x² 的"次数 2"对应面积（平方），x³ 对应体积（立方）。系数是"缩放倍数"，次数是"维数"。

多项式（polynomial）

定义：几个单项式的和。每个单项式叫多项式的项，不含字母的项叫常数项。例：3x² − 5x + 7 有 3 项：3x²、−5x、+7（符号跟着项走，7 是常数项）。

次数：多项式里次数最高的那一项的次数。3x² − 5x + 7 的次数是 2，叫"二次三项式"。

整式 = 单项式 + 多项式；分母不含字母。

易混点：多项式里"项"的系数看那一项自己的数字因数，如 −5x 的系数是 −5。

2.2 整式的加减

同类项（like terms）

定义：所含字母相同，且相同字母的指数也相同的项，叫同类项。常数项彼此也是同类项。

  • 是同类项：3x² 与 −7x²；−4ab 与 2ab；5 与 −9
  • 不是同类项：3x² 与 3x（指数不同）；3x 与 3y（字母不同）
物理/生活含义：同类项 = "同一种东西"。3 个苹果 + 2 个苹果 = 5 个苹果；但 3 个苹果 + 2 个梨不能合并。字母和指数决定"品种"，系数决定"数量"。

合并同类项

法则：系数相加，字母部分保持不变。

3x² + 5x² = (3+5)x² = 8x²
−4ab + 2ab = (−4+2)ab = −2ab

口诀：系数相加，字母照抄。本质：把同品种的物品"数个数"合起来。

去括号（重要法则！）

  1. 括号前是 +：直接去掉括号，各项符号不变。 
    a + (b − c) = a + b − c
  2. 括号前是 −：去掉括号后，括号里每一项都变号。 
    a − (b − c) = a − b + c
为什么括号前是负号要全部变号？a − (b − c) 里的 "−" 相当于"乘以 −1"分配到括号里：−(b − c) = (−1)×b + (−1)×(−c) = −b + c。回到第1章的"乘以 −1 = 关于原点翻转"，括号前负号 = 把括号内整体翻个方向。

整式加减的完整步骤

  1. 去括号（注意符号）；
  2. 找出同类项；
  3. 合并同类项；
  4. 结果按某一字母的降幂（指数从高到低）排列。

例：化简 3x² − (2x − x²) + (5x − 1)

= 3x² − 2x + x² + 5x − 1      （去括号，第二项括号前是 −，变号）
= (3x² + x²) + (−2x + 5x) − 1   （分组：同类项放一起）
= 4x² + 3x − 1                （合并系数）

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
字母表示数用"一般规律"代替"具体数字"公式：s = vt、S = ab
单项式一个"整体块"（系数=大小，次数=维度）x²=面积、x³=体积
多项式几块"不同维度的块"的和混合量：成本 = 单价×数量 + 固定费用
同类项形状相同、可叠加的"同品种块"苹果归苹果、梨归梨
合并同类项把同形状的块拼成一块把同品种物品数个数相加
去括号分配律（负号 = 整体翻转方向）拆解与重组

典型例题（自测）

  1. 指出单项式 −4a²b 的系数和次数；多项式 2x³ − 3x² + x − 5 的项数、次数、常数项。
  2. 判断同类项：3x²y 与 −5yx² 是不是同类项？（提示：字母可交换顺序，看字母与指数）
  3. 合并：5a − 3b + 2a + 4b
  4. 去括号并化简：−(2x − 3y) + 2(x − y)
  5. 一个长方形，长为 (2a + 3) m，宽为 a m，用整式表示它的周长和面积，并化简。

常见误区

  • ❌ "3x² 的系数是 3x" → ❌ 系数是数字因数 3，不是 3x。
  • ❌ "3x² 与 3x 是同类项" → ❌ 指数不同（x² 与 x），不能合并。
  • ❌ "−(a − b) = −a − b" → ❌ 括号前是负号，每一项都变号，应为 −a + b。
  • ❌ "多项式 3x² − 5x + 7 的次数是 1" → ❌ 次数看最高项 3x² 的次数 2。
  • ❌ "−x 的系数是 0" → ❌ −x 的系数是 −1（省略了 1）。

本章练习卷（含答案）

一、练习题

  1. 写出单项式 −4a²b 的系数和次数；再写出多项式 2x³ − 3x² + x − 5 的项数、次数和常数项。
  2. 判断 3x²y 与 −5yx² 是不是同类项，并说明理由（想一想：判断同类项只看什么，不看什么？）。
  3. 合并同类项：5a − 3b + 2a + 4b。
  4. 去括号并化简：−(2x − 3y) + 2(x − y)。
  5. 一个长方形，长为 (2a + 3) m，宽为 a m，用整式表示它的周长和面积，并化简。若 a = 2，算出具体的周长和面积各是多少。
  6. 某仓库原有 (3x² + 4x − 5) 件货物，第一次运进 (x² − 2x + 8) 件，第二次运出 (2x² + x − 3) 件。用整式表示运完后仓库的存货，并化简（提示：运出相当于减去，注意去括号时符号）。

二、参考答案（点击展开）

查看第1题答案

系数是 −4，次数是 2 + 1 = 3（字母 a²、b 的指数之和）。多项式 2x³ − 3x² + x − 5：共 4 项（2x³、−3x²、+x、−5），次数取最高项 2x³ 的次数 3，常数项是 −5。

查看第2题答案

是同类项。判断只看所含字母和相同字母的指数，不看字母的排列顺序，也不看系数。3x²y 与 −5yx² 都含字母 x、y，且 x 的指数都是 2、y 的指数都是 1，所以是同类项。

查看第3题答案

把同品种归到一起：5a − 3b + 2a + 4b = (5a + 2a) + (−3b + 4b) = 7a + b。口诀：系数相加，字母照抄。

查看第4题答案

第一个括号前是负号，各项变号：−(2x − 3y) = −2x + 3y；2(x − y) = 2x − 2y。合起来：−2x + 3y + 2x − 2y = (−2x + 2x) + (3y − 2y) = y。

查看第5题答案

周长 C = 2×[(2a+3) + a] = 2×(3a + 3) = 6a + 6（m）；面积 S = (2a + 3)·a = 2a² + 3a（m²）。当 a = 2：周长 = 6×2 + 6 = 18 m，面积 = 2×2² + 3×2 = 8 + 6 = 14 m²。

查看第6题答案

存货 = (3x² + 4x − 5) + (x² − 2x + 8) − (2x² + x − 3)。先去括号（注意第三个括号前是负号，变号）：= 3x² + 4x − 5 + x² − 2x + 8 − 2x² − x + 3。合并同类项：(3x² + x² − 2x²) + (4x − 2x − x) + (−5 + 8 + 3) = 2x² + x + 6（件）。
