第9章 不等式与不等式组

初中 / 初一 / 七年级下册

一句话总纲：不等式 = 「数轴上的一条射线（半直线）」。等号把数轴"切"成一个点，不等号把数轴"切"成两半——解集就是从临界点出发、向一侧无限延伸的那半条线；乘负数要变号，本质就是"关于原点翻转"。

1.1 不等式及其解集

不等式：用"不等号"连接的式子

用 <（小于）、>（大于）、≤（不大于，即小于或等于）、≥（不小于，即大于或等于）、≠（不等于）等不等号连接两个式子，就得到一个不等式。

  • 不含未知数（恒成立或恒不成立）：7 > 5、a + 2 > a、3 < 2。
  • 含未知数（需要求解）：x + 1 < 5、2x - 3 ≥ 7、-3y ≤ 0。
  • <、> 是"严格"不等，不允许等于；≤、≥ 允许"等于"。

不等式的解与解集

使不等式成立的未知数的值，叫不等式的解；一个不等式所有解组成的集合，叫这个不等式的解集。

例：对 x + 1 < 5——

  • x = 3 时，3 + 1 = 4 < 5 成立，所以 3 是它的一个解；
  • x = 4 时，4 + 1 = 5，不成立，所以 4 不是解；
  • x = 0、x = -100、x = 3.9……都成立，把这些解"合起来"就是解集：x < 4。

求不等式解集的过程叫解不等式。注意："解不等式"是过程，"解集"是结果，二者不同。

解集在数轴上的表示（几何含义的核心！）

一个不等式的解集，在数轴上就是从"临界点"出发、向一侧无限延伸的一条射线（半直线）。边界点的画法：

  • 空心圆圈 ○：表示不包含该点，对应严格不等号 <、>；
  • 实心圆点 ●：表示包含该点，对应 ≤、≥。
x < 4 的解集（空心 ○，向左延伸）：
        ○←————————————————
  -2  -1   0   1   2   3   4   5   6

x ≥ 4 的解集（实心 ●，向右延伸）：
        ●————————————————→
  -2  -1   0   1   2   3   4   5   6
几何含义：等式 x = 4 在数轴上只是一个点；而不等式 x < 4、x ≥ 4 在数轴上是半条数轴（一条射线）。一句话：等号切出一个点，不等号切出半个数轴，解集就是其中一半。空心与实心，就是"这条半线要不要把自己的端点算进去"。
物理含义：不等式是"阈值 / 界限"的数学表达——只规定一个临界值和一个方向，不规定具体数值。例："电梯载重不超过 1000 kg" → m ≤ 1000；"冲奶粉水温不低于 40℃" → t ≥ 40；"车速不得超过 120 km/h" → v ≤ 120。

1.2 不等式的性质

不等式有三条基本性质，前两条与等式一致，第三条（乘除负数）是本章最容易出错的地方。

性质1（加减不变号）：若 a > b，则 a ± c > b ± c
性质2（乘除正数不变号）：若 a > b，c > 0，则 ac > bc，a/c > b/c
性质3（乘除负数要变号）：若 a > b，c < 0，则 ac < bc，a/c < b/c
  • 性质1：不等号两边同时加（或减）同一个数（或式子），不等号方向不变。
  • 性质2：不等号两边同时乘（或除以）同一个正数，不等号方向不变。
  • 性质3：不等号两边同时乘（或除以）同一个负数，不等号方向改变（"<" 变 ">"，">" 变 "<"）。
为什么性质3要变号？用具体数看：3 > 2 成立。两边同乘 -1，得 -3 与 -2；在数轴上 -3 比 -2 更靠左，所以 -3 < -2。即 3 > 2 乘 -1 之后变成了 -3 < -2，方向必须反过来。
几何含义：性质1是平移——把两个点同时向左/右平移相同距离，左右顺序不变；性质2是拉伸/压缩——以原点为中心均匀放大或缩小整条数轴，正数之间的顺序不变；性质3是关于原点的镜像翻转——乘以负数把每个点翻到原点另一侧，原来在右边的点翻到了左边，左右顺序整体颠倒，所以不等号方向反转。
物理含义：乘负数 = "方向反转"。向东 +3 m/s 与向西 -3 m/s 大小关系本来相反；若把"向东"重新规定为负方向，原来"谁快谁慢"的大小关系就整体翻转一次——这正是"乘负数变号"。

与等式性质的对比

运算等式不等式
两边加减同一个数（式子）仍相等方向不变
两边乘 / 除以同一个正数仍相等方向不变
两边乘 / 除以同一个负数仍相等方向改变

关键区别只有一处：乘或除以负数时，等式不变，不等式要变号。

1.3 一元一次不等式

定义

只含一个未知数、未知数的次数是 1、且未知数的系数不等于 0的不等式，叫一元一次不等式。如 x - 3 > 5、2x + 1 ≤ 7、-3x > 9、(x - 1)/2 < 3。它的最简形式是 ax > b、ax < b、ax ≥ b、ax ≤ b（其中 a ≠ 0）。

解法步骤

  1. 去分母：两边同乘各分母的最小公倍数（是正数，方向不变）。
  2. 去括号。
  3. 移项：移项要变号（实质是性质1：两边同加减同一个式子）。
  4. 合并同类项。
  5. 系数化为 1：若系数是负数，两边除以该负数时，不等号方向要改变。

例1（系数为正）：解 3x - 2 > 4

3x - 2 > 4
    3x > 4 + 2      （两边加 2）
    3x > 6
     x > 2           （两边除以 3，正数，不变号）

例2（系数为负，必须变号！）：解 -2x + 6 < 10

-2x + 6 < 10
    -2x < 10 - 6    （两边减 6）
    -2x < 4
      x > -2        （两边除以 -2，负数，方向改变！）

例3（先去分母）：解 (x - 1)/2 < 3

 x - 1 < 6          （两边乘 2，正数，不变号）
     x < 7          （两边加 1）

检验：取解集内一个值，如 x = 0 代入原式，0 - 1 = -1，-1/2 < 3 成立，说明方向没错。

几何含义：一元一次不等式的解集永远是数轴上一条射线，它的"边界点"就是对应方程 ax + b = 0 的解 x = -b/a。解不等式，本质就是找到这个临界点，再判断往左还是往右、空心还是实心。
物理含义：它回答"最多 / 最少 / 至少 / 至多是多少"这类临界值问题。例："一件商品售价 x 元，买 3 件总价不超过 100 元" → 3x ≤ 100 → x ≤ 100/3（约 33.3 元）。现实里任何"不超过 / 不低于"的约束都能翻译成一元一次不等式。

1.4 一元一次不等式组

定义与解集

把几个含有同一个未知数的一元一次不等式合在一起，就组成一个一元一次不等式组。不等式组里每个不等式解集的公共部分（交集），就是这个不等式组的解集。

   x > 2
   x < 5        ← 这是一个一元一次不等式组

解法：分别求解 → 数轴找公共部分

  1. 分别求出每个不等式的解集；
  2. 把各解集画在同一条数轴上；
  3. 找出它们重叠的部分，就是不等式组的解集。

例1：解不等式组 x + 1 > 0 与 2x - 4 < 2

x + 1 > 0   →   x > -1
2x - 4 < 2   →   2x < 6   →   x < 3

x > -1 与 x < 3 在数轴上的重叠是中间一段：
      -1 < x < 3

四种情形（口诀）

不等式组数轴上的重叠解集
x > 2 且 x > 5两条向右的射线，重叠在更靠右的部分x > 5（同大取大）
x < 2 且 x < 5两条向左的射线，重叠在更靠左的部分x < 2（同小取小）
x > 2 且 x < 5一左一右，重叠在中间2 < x < 5（大小小大中间找）
x > 5 且 x < 2一右一左，没有重叠无解（大大小小无解）

例2（无解）：解不等式组 3x + 1 > 7 与 2x < 2

3x + 1 > 7   →   x > 2
    2x < 2   →   x < 1

x > 2 与 x < 1 没有公共部分 → 无解（解集为空集 ∅）
几何含义：不等式组的解集是数轴上多条射线的重叠区间，结果可能是：一条射线（同大 / 同小）、一条线段（有限区间）（大小小大中间找）、或空集（大大小小无解）。这也是"区间"概念的第一次出现——2 < x < 5 就是开区间 (2, 5)，对应数轴上一段不含端点的线段。
物理含义：它表达"双重（或多重）约束"，即"既要满足 A、又要满足 B"。例："货车载重至少 500 kg 且不超过 1000 kg" → 500 ≤ m ≤ 1000，对应一个区间。现实中凡是"有下限又有上限"的条件（温度范围、价格区间、时间窗口），都可以写成不等式组。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
不等式把数轴"切"成两半的大小关系阈值、界限的数学表达
不等式的解集从临界点出发的一条射线（半直线）满足条件的所有取值
空心圆 ○ / 实心点 ●边界点不包含 / 包含"小于"与"不大于"的差别
性质1（加减）数轴上的平移，左右顺序不变同时加/减同一量，相对大小不变
性质2（乘正数）以原点为中心的拉伸，顺序不变等比例缩放不改变方向
性质3（乘负数）关于原点的镜像翻转，顺序颠倒方向反转（正负号整体翻转）
一元一次不等式一条射线，边界点 = 对应方程的解临界值问题："最多 / 至少多少"
一元一次不等式组多条射线的重叠区间（射线/线段/空集）多重约束："既要…又要…"

典型例题（自测）

  1. 在数轴上表示：x < -1、x ≥ 2、-1 ≤ x < 2，并说明每个边界点是空心还是实心。
  2. 用不等号表示：a 是正数；b 是非负数；c 不大于 5；d 不小于 -3。
  3. 利用性质3判断：已知 a > b，判断 -3a 与 -3b、a/(-2) 与 b/(-2) 的大小关系。
  4. 解不等式 3(x - 2) ≥ x + 4，并把解集表示在数轴上。
  5. 解不等式 -(2x - 3)/3 < 1，注意系数为负时的变号。
  6. 解不等式组：x - 1 > 0 且 2x + 1 ≤ 7，并写出解集。
  7. 应用题：某班有 x 名学生，每人发 5 本练习册，手头只有 48 本且不够发。列不等式并求 x 的最小整数值。

常见误区

  • ❌ "不等式两边乘 / 除以负数时方向不变" → ✅ 必须变号，这是性质3，也是全章头号易错点。
  • ❌ "x < 4 的解集在数轴上 4 处画实心点" → ✅ 严格不等号用空心圆圈；只有 ≤、≥ 才用实心点。
  • ❌ "不等式组的解集是把各解集合在一起（并集）" → ✅ 是求公共部分（交集），不是并集。
  • ❌ "移项不变号" → ✅ 移项要变号（实质是性质1：两边同加减同一个数）。
  • ❌ "去分母时乘负数不用变号" → ✅ 去分母乘的是最小公倍数（正数）不变号；但"系数化为 1"时若除以负数必须变号。
  • ❌ "a ≤ b 与 a < b 意思一样" → ✅ ≤ 允许等于、< 不允许，对应边界点实心 / 空心不同。

本章练习卷（含答案）

一、练习题

  1. 用不等号表示下列语句，并指出每个边界点在数轴上应画空心圆圈还是实心圆点：a 是正数；b 是非负数；c 不大于 5；d 不小于 -3。
  2. 已知 a > b，不代入具体数值，利用不等式的性质判断下列各组的大小关系并说明理由：-3a 与 -3b；a/(-2) 与 b/(-2)；a + 5 与 b + 5。
  3. 解不等式 3(x - 2) ≥ x + 4，并把解集表示在数轴上。
  4. 解不等式 -(2x - 3)/3 < 1，特别注意系数为负时不等号方向的变化。
  5. 解不等式组 x - 1 > 0 且 2x + 1 ≤ 7，并写出解集（即两个解集的公共部分）。
  6. 某班有 x 名学生，每人发 5 本练习册，手头只有 48 本且不够发。列不等式并求 x 的最小整数值，再说明这个临界值对应数轴上的哪种边界点。

二、参考答案（点击展开）

查看第1题答案

a 是正数 → a > 0；b 是非负数 → b ≥ 0；c 不大于 5 → c ≤ 5；d 不小于 -3 → d ≥ -3。边界点画法：a > 0 在 0 处画空心圆圈（不包含 0）；b ≥ 0 在 0 处画实心圆点（包含 0）；c ≤ 5 在 5 处画实心圆点；d ≥ -3 在 -3 处画实心圆点。

查看第2题答案

由 a > b：两边同乘负数 -3，方向改变，故 -3a < -3b；除以 -2 即乘负数 -1/2，方向改变，故 a/(-2) < b/(-2)；两边同加 5（性质1，平移），方向不变，故 a + 5 > b + 5。核心：乘 / 除以负数要变号（关于原点翻转），加减与乘正数不变号。

查看第3题答案

3(x - 2) ≥ x + 4 → 去括号 3x - 6 ≥ x + 4 → 移项 3x - x ≥ 4 + 6 → 2x ≥ 10 → 两边除以正数 2，不变号，x ≥ 5。数轴上在 5 处画实心圆点并向右无限延伸。

查看第4题答案

两边同乘正数 3，不变号：-(2x - 3) < 3 → -2x + 3 < 3 → 两边减 3：-2x < 0 → 两边除以负数 -2，方向改变：x > 0。检验：取 x = 1，得 -(2-3)/3 = 1/3 < 1 成立，方向正确。

查看第5题答案

x - 1 > 0 → x > 1；2x + 1 ≤ 7 → 2x ≤ 6 → x ≤ 3。两解集在数轴上的公共部分是 1 < x ≤ 3，即开区间 (1, 3] 对应的一段线段：1 处空心、3 处实心。

查看第6题答案

5x 本超过 48 本仍不够发 → 5x > 48 → 两边除以正数 5，不变号，x > 9.6。x 为整数，最小整数值是 10。临界点 9.6 用空心圆圈表示（不包含 9.6 本身），解集从 9.6 向右无限延伸。
