第5章 相交线与平行线

初中 / 初一 / 七年级下册

一句话总纲：相交线与平行线，研究的是两条（或多条）直线之间的"位置关系"——要么相交成一个点（研究它张开的角），要么平行永不相交（研究它被第三条线截出的角），而"角相等 / 角互补"就是判断这两种关系、并由此推出更多结论的唯一钥匙。

5.1 相交线、对顶角与邻补角

两条直线相交

在同一平面内，若两条直线只有一个公共点，就说这两条直线相交，这个公共点叫做交点。两条直线相交，一共会形成 4 个角：两对对顶角、四对邻补角。

几何含义："相交"的本质是两条直线的方向不同，于是它们必然在某一点相遇并交叉。交点是唯一的公共点，4 个角把交点周围的"平面"分成 4 份，每一份的"张开程度"就是一个角。
物理含义：两条直线相交就是生活中的"交叉结构"——十字路口（两条道路交于一点）、剪刀（两片刀刃绕转轴相交）、字母 X 的形状。交点就是那个"汇聚点"。

对顶角：关于交点的"对角"

定义：两条直线相交，具有公共顶点，且一个角的两边分别是另一个角两边的反向延长线的两个角，叫做对顶角。图中 ∠1 与 ∠3、∠2 与 ∠4 分别互为对顶角。

性质（对顶角相等）：∠1 = ∠3，∠2 = ∠4。

为什么相等？因为 ∠1 与 ∠2 是邻补角（和 180°），∠3 与 ∠2 也是邻补角（和 180°），同一个 ∠2 的两边分别是 ∠1 和 ∠3 的一边，所以：

∠1 + ∠2 = 180°  且  ∠3 + ∠2 = 180°   ⟹   ∠1 = ∠3
几何含义：对顶角是"隔着一个顶点互相望过去"的两个角，它们关于交点 O 成中心对称——把其中一个角绕着 O 旋转 180°，正好与另一个重合，所以必然相等。
物理含义：想象一把剪刀：两片刀刃交叉处形成的"上下两个张口角"就是对顶角。无论你怎么开合剪刀，上下两个张口角始终一样大——这就是"对顶角相等"在手边的体现。

邻补角：拼成一个平角

定义：有公共顶点和一条公共边，且另外两边互为反向延长线的两个角，叫做邻补角。图中 ∠1 与 ∠2、∠2 与 ∠3、∠3 与 ∠4、∠4 与 ∠1 都互为邻补角。

性质（邻补角互补）：互为邻补角的两个角之和为 180°。例如 ∠1 + ∠2 = 180°。

几何含义：邻补角的两个角共用一条边，它们拼起来正好是一条直线（平角 180°）。所以"邻补"= 相邻 + 互补，是"紧挨着、合起来凑成一条直线"。
物理含义：一条笔直的马路在路口处"向左转"与"向右转"的两个方向角，合起来就是 180°；指针转过一个角再转回来，两个相邻方向角也正好互补。邻补角描述的是"同一直线上被拆开的两个方向"。

对顶角 vs 邻补角，一张表分清：

比较对顶角邻补角
公共顶点有有
公共边无（两边互为反向延长线）有（一条公共边）
数量关系相等互补（和 180°）
图中例子∠1 与 ∠3、∠2 与 ∠4∠1 与 ∠2、∠2 与 ∠3 等

5.2 垂线与垂线段

垂直：相交成直角的特殊情况

两条直线相交所成的 4 个角中，只要有一个角是直角（90°），就说这两条直线互相垂直，其中一条直线是另一条的垂线，它们的交点叫做垂足。记作 a ⊥ b，或 AB ⊥ CD（读作"a 垂直于 b"）。

注意：两条直线相交时，只要有一个角是 90°，其余三个角也必然都是 90°（因为对顶角相等、邻补角互补）。

几何含义：垂直是"相交"中最端正的一种——两直线方向相差 90°，形成的 4 个角全相等（都是直角）。它把平面均分成 4 个全等的直角扇形。
物理含义：垂直 = 生活中的"铅垂线 / 竖直方向"。建筑工人吊一根系重物的线，重力让线垂直于地面；墙要砌得"直"，就是让墙与地面垂直。角尺（直角尺）的两条边也互相垂直。

垂线的性质：唯一性

性质 1：在同一平面内，过一点有且只有一条直线与已知直线垂直。这个"一点"既可以在直线上，也可以在直线外。

  • "有" 表示存在（总能画出一条垂线）；
  • "只有" 表示唯一（不会出现两条不同的垂线）。
物理含义："过一点到地面只有一条铅垂线"——一个位置的重力方向是唯一确定的，所以竖直方向（垂线）也只有一条。

垂线段最短 & 点到直线的距离

连接直线外一点 P 与直线 l 上各点的线段有无数条，其中垂直于 l 的那一条（垂线段）最短，简称"垂线段最短"。这条垂线段的长度，就叫做点 P 到直线 l 的距离。

几何含义：垂线段是"点到直线上所有点"中最短的连线，即点到直线的最短路径。它把"点到线的远近"用一条线段的长度精确刻画出来。
物理含义：这解释了为什么"走最近的路要直着走"：从你脚下到一条马路边，垂直走过去最近；跳远成绩测量的是落点到起跳线的垂直距离（不是斜线）；量身高也是头顶到地面的垂线段长度。

要点区分：距离 是一个数（长度），而 垂线段 是一个图形（线段）。两者别混为一谈。

5.3 同位角、内错角、同旁内角（三线八角）

什么是"三线八角"？

两条直线 l₁、l₂ 被第三条直线 t（叫截线）所截，一共会形成 8 个角。研究这些角之间的位置关系，是判定两条直线是否平行的基础。先看图：

几何含义："三线八角"不是要死记 8 个角，而是给这 8 个角按"位置关系"分类。位置相同、位置交错、位置同旁，三种关系各自对应一套"若相等/互补就能推平行"的规律。
物理含义：想象一条斜插过两条铁轨的桥（截线），桥与两条铁轨相交出 8 个角；或梯子的一根横档搭在两根竖杆上。识别这些角的位置，是判断"两条铁轨是否平行"的关键。

同位角：位置相同（F 形）

定义：在截线 t 的同侧，且分别在两条被截线 l₁、l₂ 的同一方向（同上或同下、同左或同右）的一对角，叫做同位角。图中：

  • ∠1 与 ∠5（在截线右侧、都在两条线上方）、∠2 与 ∠6（在截线左侧、都在两条线上方）
  • ∠3 与 ∠7（在截线左侧、都在两条线下方）、∠4 与 ∠8（在截线右侧、都在两条线下方）

把一组同位角的边描出来，形似英文字母 F，所以叫 "F 形"。

几何含义：同位角是"两条直线上朝向完全相同的两个角"。当两条直线平行时，它们的"朝向"一致，所以同位角必然相等；反过来，同位角相等也说明两直线"朝向一致"（平行）。

内错角：内部且交错（Z 形）

定义：都在两条被截线 l₁、l₂ 的内部（之间），并且在截线 t 的两侧（交错）的一对角，叫做内错角。图中：

  • ∠3 与 ∠5、∠4 与 ∠6

把它们描出来形似字母 Z（或反 Z），所以叫 "Z 形"。

几何含义："内错"二字拆开记——"内"指夹在两条线之间，"错"指一左一右交错。它是"藏在两条线之间、斜着错开"的两个角。

同旁内角：内部且同旁（U 形）

定义：都在两条被截线 l₁、l₂ 的内部，并且在截线 t 的同侧（同旁）的一对角，叫做同旁内角。图中：

  • ∠3 与 ∠6（都在左侧）、∠4 与 ∠5（都在右侧）

把它们描出来形似字母 U（或 C），所以叫 "U 形"。

几何含义："同旁"指都在截线的同一侧，加上"内"（两条线之间）。当两直线平行时，同旁内角互补（合起来 180°），这是它与同位角、内错角最大的不同——它靠"和为 180°"而非"相等"来判断平行。

名称位置特征图形图中例子

5.4 平行线的判定

平行线 & 平行公理

定义：在同一平面内，不相交的两条直线叫做平行线，记作 a ∥ b。（"同一平面内"五个字不能丢：在空间里还有既不平行也不相交的异面直线。）

平行公理：过直线外一点，有且只有一条直线与这条直线平行。

几何含义：平行 = 两条直线的方向完全相同，所以永远"对齐地并排走"，永远不会相遇。方向一致，是"平行"的全部秘密。
物理含义：平行线无处不在——铁路的两条铁轨、双杠的两根杠、道路的两条车道线、梯子的两根竖杆。它们必须平行，否则火车会脱轨、车道会撞车。

三个判定定理：由"角"推"平行"

判定 = 已知角度关系，证明两直线平行。三条核心判定：

判定方法已知条件推出的结论图形
判定 1同位角相等两直线平行F 形
判定 2内错角相等两直线平行Z 形
判定 3同旁内角互补两直线平行U 形

写成符号（设两直线为 a、b，被截线 t 所截）：

若 ∠1 = ∠2（同位角相等），    则 a ∥ b
若 ∠3 = ∠4（内错角相等），    则 a ∥ b
若 ∠5 + ∠6 = 180°（同旁内角互补），则 a ∥ b
几何含义：判定定理在说：只要角的关系对了，两直线就一定"方向一致"。同位角相等说明两线"同向"、内错角相等说明两线"错而不偏"、同旁内角互补说明两线"合起来不弯"——三种说法本质都是"方向一致"。
物理含义：这是工程上"检验平行"的方法：想知道两根杆子是否平行，就拿一根尺（截线）搭上去量角度——对应角相等，就平行；同侧两角加起来是 180°，也平行。木工、装修都用这套"量角判平行"。

另外两条常用判定：

  • 平行于同一条直线的两条直线互相平行（平行的传递性：若 a ∥ c 且 b ∥ c，则 a ∥ b）。
  • 在同一平面内，垂直于同一条直线的两条直线互相平行（若 a ⊥ c 且 b ⊥ c，则 a ∥ b）。

5.5 平行线的性质

三个性质定理：由"平行"推"角"

性质 = 已知两直线平行，推出角度关系。它和判定正好互为逆过程：

性质定理已知条件推出的结论图形
性质 1两直线平行同位角相等F 形
性质 2两直线平行内错角相等Z 形
性质 3两直线平行同旁内角互补U 形
若 a ∥ b，则 同位角相等；内错角相等；同旁内角互补。

例如 a ∥ b 时：
∠1 = ∠5（同位角），∠3 = ∠5（内错角），∠3 + ∠6 = 180°（同旁内角）
几何含义：平行 = 方向一致，于是两条平行线被同一条截线所截时，"对应位置"的角自然相等。性质定理把这个"方向的确定性"翻译成了"角度的相等/互补"。
物理含义：已知铁轨平行，就能由"一个已知角"算出其余所有角——测出桥与铁轨的一个夹角，另外几个角不用再量就能算出。工程上据此"由平行求角度"，是测量与放样的基础。

判定 vs 性质：方向正好相反

这是本章最容易混淆、也最核心的一组关系，务必分清：

对比平行线的判定平行线的性质
逻辑方向由角 → 推平行由平行 → 推角
已知角相等 / 互补两直线平行
结论两直线平行角相等 / 互补
用途证明（判断）两线平行已知平行时求角度
口诀"角等推平行""平行推角等"
几何含义：判定与性质互为逆命题——判定问"方向一致吗？"，性质答"方向一致会带来什么？"。方向一致（平行）⇔ 对应角相等，这一正一反正是同一个几何事实的两面。

5.6 命题与定理

命题：能判断真假的语句

命题是判断一件事情的语句，它必须能明确判断为"真"或"假"。例如：

  • "对顶角相等" —— 是命题（真）。
  • "相等的角是对顶角" —— 是命题（假）。
  • "你好吗？" —— 不是命题（疑问句，无法判断真假）。
  • "请画一条垂线" —— 不是命题（祈使句）。

每个命题都由题设（已知条件）和结论（由条件推出的判断）两部分组成，常写成 "如果……那么……" 的形式："如果"后面是题设，"那么"后面是结论。

命题：对顶角相等
改写：如果 两个角是对顶角（题设），那么 这两个角相等（结论）。
几何含义：命题是几何推理的"句子单元"，一个命题就是一个"条件 → 结论"的箭头。把命题拆成"题设"和"结论"，是证明的第一步——搞清楚"我有什么，我要证明什么"。
物理含义：科学里到处是命题："如果物体只受重力，那么它竖直下落"、"如果两力平衡，那么合力为零"。判断真假、拆出条件与结论，是所有自然科学推理的通用语言。

真命题、假命题、定理、公理

  • 真命题：题设成立时，结论一定成立的命题。
  • 假命题：题设成立时，结论不一定成立的命题（举一个反例就能推翻）。
  • 定理：经过推理证实为正确的真命题。如"对顶角相等""垂线段最短""平行线的判定与性质"都是定理。
  • 公理（基本事实）：不需要证明、人们长期实践公认的正确命题，是推理的起点。如"两点确定一条直线""过直线外一点有且只有一条直线与它平行"。
几何含义：几何体系像一座塔：公理是地基（不证自明），定理是楼层（由公理一步步证明搭起来），命题则是施工时的"判断材料"。知道"定理必须证明、公理直接承认"，就理解了数学推理的结构。

逆命题

把一个命题的题设与结论互换，得到的新命题叫原命题的逆命题。

原命题：如果 两个角是对顶角，那么 这两个角相等。（真）
逆命题：如果 两个角相等，    那么 这两个角是对顶角。（假！相等的角不一定是顶角）
几何含义：判定与性质正是互逆的典型——"同位角相等 ⇒ 两直线平行"与"两直线平行 ⇒ 同位角相等"互为逆命题，而且两者都真。但要注意：原命题真，逆命题不一定真（如上例），每个逆命题都要单独检验。

典型例题（自测）

  1. 两条直线相交，已知 ∠1 = 40°，求另外三个角 ∠2、∠3、∠4 的度数（∠1 与 ∠2 是邻补角，∠1 与 ∠3 是对顶角）。
  2. 判断：下面每组角分别是什么关系（对顶角 / 邻补角 / 同位角 / 内错角 / 同旁内角）？∠1 与 ∠3；∠3 与 ∠5；∠4 与 ∠6；∠3 与 ∠6。
  3. 如图，直线 AB、CD 被 EF 所截，∠1 = 110°，∠2 = 70°。问 AB 与 CD 是否平行？为什么？（提示：∠1 与 ∠2 是什么关系？）
  4. 已知 a ∥ b，∠1 = 65°。求与 ∠1 是内错角的 ∠2、与 ∠1 是同旁内角的 ∠3 各是多少度。
  5. 过直线 l 外一点 P 作 l 的垂线，再连接 P 与 l 上另一点 Q（Q 不是垂足）。比较线段 PQ 与垂线段的长短，并说明依据。
  6. 把命题"同旁内角互补，两直线平行"改写成"如果……那么……"的形式，写出它的题设、结论，并写出它的逆命题。

常见误区

  • ❌ "相等的角是对顶角" → ❌ 这是"对顶角相等"的逆命题，是假命题。两个角相等不一定是顶角（可能是同位角、内错角，或毫不相干的角）。
  • ❌ "同位角、内错角、同旁内角只有在平行时才有" → ❌ 这三种角由"三线相交"天然形成，与是否平行无关；平行只是让它们"相等/互补"。
  • ❌ "判定与性质分不清" → ❌ 判定是由角推平行，性质是由平行推角，方向相反，别背混。
  • ❌ "点到直线的距离就是垂线段" → ❌ 距离是垂线段的长度（一个数），垂线段是图形（一条线段）。
  • ❌ "过一点有无数条直线与已知直线垂直" → ❌ 是"有且只有一条"，垂直方向唯一。
  • ❌ 把平行线定义里的"在同一平面内"丢掉 → ❌ 丢了它，空间中还会出现"既不平行也不相交"的异面直线，定义就不成立了。
  • ❌ "过一点有且只有一条直线与已知直线平行" → ❌ 平行公理必须说"过直线外一点"；若点在直线上，则不存在与之平行的直线（有无数条重合或相交）。

课本外 · 典故与思考

史两千年都想"证明"的平行公设——结果却证明出了新几何（点击展开）

本章学的"过直线外一点有且只有一条直线与已知直线平行"，就是平行公设（欧几里得《几何原本》第五公设的一种说法）。它不像"两点确定一条直线"那样显然，两千多年来，无数数学家都想把它当作一条定理"证明"出来，却都失败了。

直到19世纪，事情出现了惊人的转折：

  • 罗巴切夫斯基（Lobachevsky）和鲍耶（Bolyai）在1820年代前后几乎同时发现：把这条公设改一改（比如"过直线外一点可以作无数条平行线"），照样能推出一套自洽的、全新的几何——这就是"非欧几何"。
  • 据说高斯（Gauss）也独立发现了这个结果，但害怕引起争议，没有公开发表。
  • 更颠覆的是：后来的物理学发现，在宇宙大尺度上，空间的几何可能真的不是欧几里得式的。
一句话总结：两千年的"证明失败"不是数学的失败，而是通往新世界的门票——公理不是唯一的真理，而是可以选择的"游戏规则"。
趣地球仪上的"平行线"——经线在赤道平行，却在南北极相交（点击展开）

找一个地球仪观察：所有经线在赤道附近都"平行"着走（都和赤道垂直、彼此保持等距），可沿着经线往北走，它们越靠越近，最后全部在南极、北极汇成一个点！

这说明：在球面上，"平行公设"失效了——球面上任意两条"直线"（大圆）最终都会相交，根本画不出"永不相交的平行线"。

飞机航线就是活例子：从北京飞纽约，最短航线并不是地图上那条"横着的直线"，而是贴着北极附近飞过的一个大圆弧——因为地球是个球，球面上的"直线"是大圆。

这和本章学的"在同一平面内、永不相交的平行线"并不矛盾：平行线是平面世界的规矩，球面有球面自己的规矩。

一句话总结：你在地球仪上亲手"拆掉"了平行公设——上一块讲的两千年悬案，答案就藏在这个地球仪里。

本章练习卷（含答案）

一、练习题

  1. 两条直线 AB 与 CD 相交于点 O，已知 ∠1 = 50°（∠1 与 ∠2 互为邻补角，∠1 与 ∠3 互为对顶角）。求其余三个角 ∠2、∠3、∠4 的度数。
  2. 两条直线 l₁、l₂ 被截线 t 所截，共形成 ∠1～∠8 八个角。请各指出一组同位角、内错角、同旁内角，并说出它们分别形似哪个字母（F / Z / U）。
  3. 直线 AB、CD 被直线 EF 所截，∠1 与 ∠2 是同旁内角，且 ∠1 = 110°，∠2 = 70°。问 AB 与 CD 是否平行？为什么？
  4. 已知 a ∥ b，直线 c 分别交 a、b 于 P、Q。若 ∠1 = 65°，且 ∠1 与 ∠2 是内错角、∠1 与 ∠3 是同旁内角。求 ∠2 与 ∠3 的度数。
  5. 过直线 l 外一点 P 作 PO ⊥ l 于点 O，再在 l 上取另一点 Q（Q 与 O 不重合），连接 PQ。比较线段 PQ 与 PO 的长短，并说明依据；PO 的长度叫做什么？
  6. 把命题"内错角相等，两直线平行"改写成"如果……那么……"的形式，指出它的题设与结论，并写出它的逆命题（判断真假）。

二、参考答案（点击展开）

查看第1题答案

∠2 = 180° − 50° = 130°（邻补角互补）；∠3 = ∠1 = 50°（对顶角相等）；∠4 = ∠2 = 130°（对顶角相等）。

查看第2题答案

例如：同位角 ∠1 与 ∠5（F 形）；内错角 ∠3 与 ∠5（Z 形）；同旁内角 ∠3 与 ∠6（U 形）。答案不唯一，只要位置特征正确即可。

查看第3题答案

平行。因为 ∠1 + ∠2 = 110° + 70° = 180°，同旁内角互补，所以 AB ∥ CD（判定 3）。

查看第4题答案

由 a ∥ b 得内错角相等，∠2 = ∠1 = 65°；同旁内角互补，∠3 = 180° − 65° = 115°。

查看第5题答案

PQ > PO（即 PO 最短）。依据是"垂线段最短"：连接直线外一点与直线上各点的所有线段中，垂线段最短。PO 的长度叫做点 P 到直线 l 的距离。

查看第6题答案

改写：如果 两条直线被第三条直线所截，内错角相等，那么 这两条直线平行。题设：内错角相等；结论：两直线平行。逆命题：如果 两条直线平行，那么 它们被第三条直线所截时内错角相等（真，即平行线性质 2）。
