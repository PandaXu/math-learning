第6章 实数

初中 / 初一 / 七年级下册

一句话总纲：实数 = 「填满整条数轴的所有点」。从"求面积求边长"引出平方根、算术平方根、立方根，再发现像 √2、π 这样的无理数——它们真实存在却无法写成分数，正是它们把有理数之间的"缝隙"补满，让数与数轴上的点做到一一对应。学完本章，你要能在心里"看见"：每个根号背后都是一段可以画出来的线段，整条数轴从此再没有空洞。

6.1 平方根

从一道题出发：已知面积，求边长

一个正方形的面积是 9，它的边长是多少？设边长为 x，则 x² = 9。显然 3² = 9，所以边长可以是 3。但注意，(−3)² = 9 也成立！也就是说，方程 x² = 9 有两个解：x = 3 和 x = −3。

几何含义："求平方根"就是已知正方形的面积，反求它的边长。面积 9 的正方形，边长是 3（长度只能取正），但作为方程的解，−3 是 3 "关于原点的对称长度"——它表示"沿反方向量的同一条线段"。所以正数的平方根成对出现，一正一负，互为相反数。

定义

一般地，如果一个数 x 的平方等于 a，即

x² = a

那么这个数 x 叫做 a 的平方根（也叫做二次方根）。求一个数的平方根的运算，叫做开平方。开平方与平方互为逆运算。

记法

正数 a 的平方根有两个，记作 ±√a，读作"正负根号 a"。其中 √a 表示正的那个平方根，−√a 表示负的那个平方根。

平方根的三条性质

  • 正数有两个平方根，它们互为相反数。例：9 的平方根是 ±3；±√9 = ±3。
  • 0 的平方根是 0，且只有一个。因为只有 0² = 0。√0 = 0。
  • 负数没有平方根。因为在实数范围内，任何数的平方都不可能是负数（x² ≥ 0 恒成立）。例：−4 没有平方根。
物理含义：开平方是"面积"到"边长"的换算。若一块正方形田地的面积是 9 m²，它的边长就是 √9 = 3 m——面积单位（m²）开方后回到长度单位（m）。而 −3 在"田地边长"的语境里被舍弃，因为长度是恒非负的量；它只在"解方程求所有可能"时才出现。

√a 与 ±√a 的区别（务必分清）

  • √9 = 3：指 9 的正的平方根（即算术平方根，见 6.2）。
  • ±√9 = ±3：指 9 的全部两个平方根。
  • −√9 = −3：指 9 的负的平方根。

6.2 算术平方根

为什么要单独拎出"算术平方根"？

回到"面积求边长"：边长只能是正数或 0，不能是负数。于是我们把正数 a 的正的平方根单独命名，称为算术平方根。

定义与记法

  • 正数 a 的算术平方根：a 的正的平方根，记作 √a，读作"根号 a"。a 叫做被开方数。
  • 0 的算术平方根是 0，即 √0 = 0。
  • 规定：√a 本身永远只表示"非负的那个根"。

双重非负性（本章最重要的性质之一）

√a 里藏着两个"非负"，缺一不可：

√a 有意义  ⟺  被开方数 a ≥ 0     （根号里面非负）
          且  结果 √a ≥ 0        （根号结果非负）

换句话说：根号里的数不能为负，根号出来的数也不能为负。

两条核心公式

(√a)² = a      （a ≥ 0）      —— 先开方再平方，还原
 √(a²) = |a|   （a 为任意实数）—— 先平方再开方，取绝对值！
  • (√5)² = 5，(√0.3)² = 0.3：开方与平方"正着来、反着去"互相抵消。
  • √(3²) = √9 = 3；但 √((−3)²) = √9 = 3，而不是 −3！因为结果是"算术平方根"，必须非负，所以先平方再开方时要给原数套上绝对值：√(a²) = |a|。
几何含义：算术平方根就是"面积 a 的正方形的边长"这一段线段的实际长度。长度永远 ≥ 0，所以算术平方根永远 ≥ 0。双重非负性翻译成几何语言就是：正方形的面积不能为负（a ≥ 0），它的边长也不能为负（√a ≥ 0）。√(a²) = |a| 翻译成几何语言就是：a 的绝对值 = a 到原点的距离，无论 a 在原点左边还是右边，距离都一样取正。
物理含义：算术平方根对应那些"只有大小、没有方向"或"约定恒为正"的物理量——长度、面积开方求边长、速率、能量等。例如：一块 50 m² 的正方形玻璃，边长 = √50 ≈ 7.07 m，不会出现"−7.07 m"这样的答案，因为长度没有负值。

估算 √a 的大小（夹逼法）

√a 经常不是整数，怎么知道它大约是多少？用夹逼法：找两个相邻整数，让 a 夹在它们的平方之间。

例：估计 √2。

1² = 1 < 2 < 4 = 2²      →  1 < √2 < 2
1.4² = 1.96 < 2 < 2.25 = 1.5²  →  1.4 < √2 < 1.5
1.41² = 1.9881 < 2 < 2.0164 = 1.42²  →  1.41 < √2 < 1.42

不断缩小夹缝，就能把 √2 ≈ 1.41421356… 逼近到任意精度。这本质上是在数轴上"从两头夹住"√2 对应的那个点。

6.3 立方根

从"已知体积求棱长"出发

一个正方体的体积是 8，它的棱长是多少？设棱长为 x，则 x³ = 8。因为 2³ = 8，所以棱长是 2。那如果体积是 −8 呢？(−2)³ = −8，棱长"沿反方向"也可以是 −2——这是平方根做不到的（平方根里负数没有根）。

定义与记法

一般地，如果一个数 x 的立方等于 a，即

x³ = a

那么这个数 x 叫做 a 的立方根（也叫做三次方根），记作 ³√a，读作"三次根号 a"。求一个数的立方根的运算，叫做开立方。开立方与立方互为逆运算。

立方根的性质

  • 正数的立方根是正数：³√8 = 2。
  • 负数的立方根是负数：³√(−8) = −2。
  • 0 的立方根是 0：³√0 = 0。
  • 任何实数都有且只有一个立方根（这是与平方根最大的不同）。
几何含义：立方根是"已知正方体的体积，反求它的棱长"。体积 8 的正方体棱长为 2；体积 −8 的"反向正方体"棱长为 −2。因为立方不改变符号（奇数次幂保号），所以体积为正棱长就为正，体积为负棱长就为负——方向和符号一一对应，不需要像平方根那样成对讨论。
物理含义：开立方是"体积"到"棱长/边长"的换算。体积单位（m³）开三次方后回到长度单位（m）。例如一个容积为 1000 cm³ 的正方体容器，棱长 = ³√1000 = 10 cm。带有方向（正负）的量在三次方里方向被保留，所以负体积对应负棱长——比如在"沿某方向的伸缩"模型中，体积的符号可以表示方向。

两条核心公式（注意：不需要绝对值！）

(³√a)³ = a      （a 为任意实数）
 ³√(a³) = a     （a 为任意实数）—— 不需要加绝对值！

为什么这里不用绝对值？因为立方是奇次幂，不改变符号：³√((−2)³) = ³√(−8) = −2，直接还原成 −2。而平方是偶次幂，会把 −2 变成 +4，符号信息丢失，所以 √(a²) 才需要 |a| 补回来。对照记忆：偶次开方要取绝对值，奇次开方不用。

平方根与立方根对照表

对比项平方根（偶次）立方根（奇次）
正数有两个，互为相反数（±√a）一个正的（³√a）
000
负数没有平方根一个负的（³√(−a) = −³√a）
先乘方再开方√(a²) = |a|（要绝对值）³√(a³) = a（不要绝对值）

6.4 无理数

一个"画得出来却写不成分数"的数

画一个边长为 1 的正方形，用勾股定理算它的对角线长 d：

d² = 1² + 1² = 2   →   d = √2 ≈ 1.41421356…

这条对角线实实在在存在，它的长度 √2 也确定无疑。可是 √2 既不是整数，也写不成任何分数（a/b），它的小数展开 1.414213562373… 无限且永不循环。这样的数，就是无理数。

定义

无限不循环小数叫做无理数。它是"不能写成分数 a/b（a、b 为整数，b≠0）形式"的数。

有理数 vs 无理数（判断的根本标准）

类别小数形态能否写成分数例子
有理数有限小数 或 无限循环小数能0.5 = 1/2，0.333… = 1/3
无理数无限不循环小数不能√2，π，³√3，−√5

常见无理数来源：开方开不尽的数（√2、√3、³√2…）和π 这类常数，以及人为构造的无限不循环小数（如 0.1010010001…，每两个 1 之间多一个 0）。

几何含义（本章思想的枢纽）：√2 是"边长为 1 的正方形的对角线"，是一段能画出来、能量出来、真实存在的线段长度。把它对应的点标在数轴上，这个点明明存在，却无法用任何分数表示。这说明：有理数在数轴上留下了一个个"洞"，光靠有理数填不满整条数轴。无理数的发现，就是发现"数轴上还有有理数够不着的点"。
物理含义：无理数不是数学家的臆造，而是自然界真实存在的量。π = 圆周长 ÷ 直径，是任何圆都有的比值；√2 是正方形对角线与边长的比（A4 纸张的长宽比也是 √2:1）；黄金比例 (1+√5)/2 出现在贝壳、向日葵的螺旋里。它们"无限不循环"，却精确地刻画了现实世界。

√2 为什么不是有理数？（了解即可）

思路用反证法：假设 √2 = a/b（已约成最简分数，a、b 互质）。两边平方得 2 = a²/b²，即 a² = 2b²，所以 a² 是偶数，进而 a 是偶数，设 a = 2k，代入得 4k² = 2b²，即 b² = 2k²，b 也是偶数。于是 a、b 都是偶数，与"已约成最简"矛盾。所以假设不成立，√2 不是有理数，它是无理数。

6.5 实数及其在数轴上的表示

实数的定义与分类

有理数和无理数统称实数。把有理数（整数、分数）与无理数合在一起，就得到了实数大家庭：

实数
 ├── 有理数
 │    ├── 整数（正整数、0、负整数）
 │    └── 分数（有限小数、无限循环小数）
 └── 无理数（无限不循环小数，如 √2、π、³√3、−√5）

实数与数轴一一对应（本章的落脚点）

在第 1 章里，数轴上标的是整数和分数（有理数）；现在有了无理数，数轴被补满了：

  • 每一个实数都能用数轴上的一个点来表示（例如 √2 可以用"单位正方形对角线"在数轴上精确画出）。
  • 数轴上的每一个点都表示一个实数（任何一个位置，都对应一个确定的有理数或无理数）。
  • 于是实数与数轴上的点一一对应——数轴是一把"没有空隙的连续标尺"。
几何含义（核心！）：无理数的加入，把有理数留下的"洞"全部填上，使数轴成为一条连续无断点的直线。这就是"实数"二字的几何本质：实数 = 数轴上所有点的集合。一句话：数轴是实数的"照片"，实数是数轴的"坐标"。

如何在数轴上画出 √2（尺规作图思路）

以点 0 为起点向右取 1 个单位到点 A（OA = 1）；
在点 A 处竖直向上作长为 1 的线段 AB（AB = 1）；
连接 OB，则 OB = √(1² + 1²) = √2；
以 O 为圆心、OB 为半径画弧，与正半轴交于点 P，
点 P 对应的数就是 √2。

              B
              |
              |  AB = 1
              |
 ---O---------A------------P-----→
    0         1            √2
    |-- OA=1 --|
    |---- OB=√2（半径）----|

这个作图的意义在于：√2 不是"大约画在哪"，而是能被精确构造出来——它和 1、2 一样，是数轴上确确实实的一个点。同理，√3 可以用直角边为 √2 和 1 的直角三角形得到，√5 可以用直角边为 2 和 1 的直角三角形得到（勾股定理）。

实数的相反数与绝对值（与有理数完全一致）

  • 相反数：只有符号不同的两个数互为相反数。实数 a 的相反数是 −a。例：√2 的相反数是 −√2；π 的相反数是 −π。几何上，它们关于原点对称。
  • 绝对值：数轴上表示数 a 的点到原点的距离，记作 |a|。恒有 |a| ≥ 0，且 |−a| = |a|。例：|−√2| = √2，|π| = π，|−π| = π。
物理含义：实数的绝对值同样是"去掉方向只留大小"。一辆车以 √2 m/s 向东或向西，速率都是 |±√2| = √2 ≈ 1.414 m/s；位移 −√2 m 表示"向负方向移动了 √2 m"。实数让"连续变化的量"（时间、长度、温度、电流…）都能在数轴上找到精确的位置。

实数的大小比较

  • 根本法则：数轴上右边的点总比左边的点大（对一切实数成立）。
  • 正实数 > 0 > 负实数。
  • 两个正实数比大小：绝对值大的大。例：√2 ≈ 1.414 < 1.5。
  • 两个负实数比大小：绝对值大的反而小。例：−√3 < −√2，因为 |−√3| = √3 > √2 = |−√2|（−√3 离原点更远，在更左边）。

实数的运算

实数和有理数一样，可以进行加、减、乘、除（除数不为 0）、乘方运算，且满足交换律、结合律、分配律。有理数的运算法则和运算性质对实数同样适用。开方运算则是"新能力"：

  • 一个正数的平方根有两个，算术平方根只有一个。
  • 负数不能开偶次方（没有平方根），但可以开奇次方（有立方根）。

常见误区

本章最容易踩的坑

  • ❌ "16 的平方根是 4" → ✅ 平方根是 ±4，4 只是它的算术平方根。求"平方根"要写全一正一负。
  • ❌ "负数没有平方根，所以 −√4 无意义" → ✅ 有误。没有平方根的是被开方数为负（√(−4) 无意义）；而 −√4 = −2 是"4 开方后取负"，完全有意义。
  • ❌ "√(a²) = a" → ✅ 应为 √(a²) = |a|。例：√((−3)²) = 3，不是 −3。
  • ❌ "³√(a³) 也要加绝对值" → ✅ 不需要。奇次幂不改变符号，³√((−2)³) = −2 直接成立。
  • ❌ "带根号的数都是无理数" → ✅ 不对。√4 = 2、√9 = 3、³√8 = 2 都是有理数。判断标准是"无限不循环小数"。
  • ❌ "π 是无理数吗？22/7 = π 所以 π 是有理数" → ✅ 错。22/7 ≈ 3.142857 只是 π 的近似值，π ≠ 22/7，π 是无限不循环小数，是无理数。
  • ❌ "√2 = 1.414 是精确值" → ✅ 1.414 只是近似值，√2 = 1.41421356… 无限不循环，等号只能写成 ≈。
  • ❌ "数轴上的点都表示有理数" → ✅ 错。数轴上的点与实数一一对应，有理数只是其中一部分，√2、π 也在数轴上。
  • ❌ "0 的平方根是 ±0" → ✅ 不规范。0 的平方根只有一个，就是 0。
  • ❌ "开方和平方一定可以随便抵消" → ✅ 注意顺序。先开方再平方 (√a)² = a（a ≥ 0）；先平方再开方 √(a²) = |a|，结果不同。

  5. 一块正方形地砖的面积是 20 m²，求它的边长（用含根号的式子表示，并用夹逼法精确到 0.1）；再说明如何用勾股定理在数轴上画出 √2。
  6. 比较大小：√7 与 3、−√3 与 −√2；并用自己的话解释"实数与数轴上的点一一对应"的几何含义。

二、参考答案（点击展开）

查看第1题答案

49 的平方根是 ±7（因为 7² = 49 且 (−7)² = 49），算术平方根是 7（只取非负的那一个）。区别：平方根成对出现、互为相反数；算术平方根是其中唯一的非负根，记作 √49 = 7。

查看第2题答案

√((−5)²) = √25 = 5（先平方再开方，偶次幂丢符号，需补绝对值，即 = |−5| = 5）；(√6)² = 6（先开方再平方，互相还原，直接等于被开方数）。要点：√(a²) = |a|，而 (√a)² = a（a ≥ 0）。

查看第3题答案

³√(−27) = −3（因为 (−3)³ = −27）；³√125 = 5。负数没有平方根是因为任何实数的平方都 ≥ 0，得不到负数；但立方是奇次幂、保号，所以任何实数（含负数）都有且只有一个立方根。

查看第4题答案

有理数：22/7、√16（=4）、³√(−8)（=−2）；无理数：√2、π、0.1010010001…。判断标准是能否写成有限小数或无限循环小数（即分数 a/b）；无限不循环小数才是无理数。

查看第5题答案

边长 = √20 = 2√5 ≈ 4.5 m。夹逼：4² = 16 < 20 < 25 = 5² → 4 < √20 < 5；4.4² = 19.36 < 20 < 20.25 = 4.5² → 4.4 < √20 < 4.5，故 ≈ 4.5。画 √2：在数轴上取 OA = 1，在 A 处作垂线段 AB = 1，则 OB = √(1² + 1²) = √2；以 O 为圆心、OB 为半径画弧交正半轴于 P，点 P 对应的数就是 √2。

查看第6题答案

√7：因 2² = 4 < 7 < 9 = 3²，得 2 < √7 < 3，故 √7 < 3。两个负数比较，绝对值大的反而小：|−√3| = √3 > √2 = |−√2|，故 −√3 < −√2。"一一对应"的几何含义：每个实数都能在数轴上找到唯一的一个点，数轴上每个点也都对应唯一的一个实数——无理数把有理数留下的"洞"补满，数轴成为连续无断点的直线。
