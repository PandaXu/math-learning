第7章 平面直角坐标系

初中 / 初一 / 七年级下册

一句话总纲：平面直角坐标系 = 「用两根互相垂直的数轴给平面上的每个点发一个"门牌号"(x, y)」。学完本章，你要能在心里"看见"一张坐标网格——横轴 x 定左右、纵轴 y 定上下，点的位置、距离、对称、移动，全部都能翻译成坐标的加减与符号。

7.1 有序数对

从"一个数"到"一对数"

第1章我们学过：一个数对应数轴上的一个点，这是"一维"的定位——只要给出一个数，位置就确定了。但现实中的位置常常需要两个数才能定下来：

场景用到的两个数例
电影票座位排数 + 列数（座号）第 5 排第 8 座
棋盘落子列 + 行第 3 列第 2 行
地图经纬度纬度 + 经度北纬 39°、东经 116°（北京）
教室座位第几排 + 第几列第 2 排第 3 列

定义

把有顺序的两个数 a 与 b 组成的数对，记作 (a, b)，叫做有序数对。其中 a 是第一个数，b 是第二个数。

「有序」二字是关键

顺序不能颠倒：当 a ≠ b 时，(a, b) 与 (b, a) 表示不同的位置。例如电影票 (5, 8) 是第 5 排第 8 座，而 (8, 5) 是第 8 排第 5 座——两个完全不同的座位。
几何含义：一个数 → 数轴上的一个点（一维）；一个有序数对 → 平面上的一个点（二维）。有序数对是"从直线到平面"的升级——把一根标尺扩展成"两根标尺交叉成的网格"。
物理含义：有序数对本质是两个独立方向的读数。就像给房间里的某个位置定位："先向东走 3 米，再向北走 2 米"——(3, 2) 里的两个数分别回答"横向多少、纵向多少"两个独立的问题。

7.2 平面直角坐标系

坐标系的构成

在平面内画两条互相垂直、原点重合的数轴，就组成平面直角坐标系（也叫笛卡尔坐标系）：

  • 水平的数轴叫 x 轴（横轴），取向右为正方向；
  • 铅直的数轴叫 y 轴（纵轴），取向上为正方向；
  • 两条轴的交点叫原点，记作 O；
  • 两条轴上的单位长度通常取一致，这样图形才不会"变形"。

点的坐标：给点发"门牌号"

对平面内任意一点 P，过 P 分别向 x 轴、y 轴作垂线：垂足在 x 轴上对应的数叫点 P 的横坐标（记作 x），垂足在 y 轴上对应的数叫点 P 的纵坐标（记作 y）。这样点 P 就对应一对有序数 (x, y)，叫做点 P 的坐标，记作 P(x, y)。

读法：点 P 的坐标是 (x, y)，其中 x 是横坐标（写在前面），y 是纵坐标（写在后面）。先横后纵，先 x 后 y，顺序绝不可错。

几何含义（本章最核心的定理）：平面直角坐标系建立了平面上的点 与 有序实数对 之间的一一对应。每一个点有唯一坐标，每一对坐标对应唯一一个点。这和第1章"数轴上的点与有理数一一对应"是同一个思想，只是从一维推广到了二维——用数字精确描述图形，这就是解析几何的起点。
物理含义：坐标系 = 给空间装上的"参照系"。(x, y) 就是物体相对原点的位置读数：横坐标回答"在原点东边还是西边多远"，纵坐标回答"在北边还是南边多远"。测量位置、画运动轨迹、做导航，第一步都是先"建立坐标系"。

7.3 象限

坐标轴把平面分成四块

x 轴与 y 轴把坐标平面分成四个区域，每个区域叫做一个象限。从右上角开始，按逆时针方向依次编号：

象限位置点的坐标符号例
第一象限右上(+, +)(2, 3)
第二象限左上(−, +)(−2, 3)
第三象限左下(−, −)(−2, −3)
第四象限右下(+, −)(2, −3)

记忆口诀：「一全正，二负正，三负负，四正负」——四个象限的符号依次是 (+,+)、(−,+)、(−,−)、(+,−)。

坐标轴上的点不属于任何象限

x 轴上的点纵坐标为 0，y 轴上的点横坐标为 0，原点两个坐标都是 0。它们都躺在坐标轴上，不属于任何象限。做题时先判断"是否在坐标轴上"，再谈象限。
几何含义：象限 = 由符号划分的四个"方向扇区"。一个点落在哪个象限，完全由它的坐标符号决定；反之，知道象限就知道坐标的正负。象限让"方向"有了可以计算的符号语言。
物理含义：以原点为参照，四个象限就是四个方位：第一象限 = 东北方，第二象限 = 西北方，第三象限 = 西南方，第四象限 = 东南方。天气预报、风向、行军图里的方位，都能用象限的语言表达。

7.4 点的坐标

4.4.1 由点写坐标 & 由坐标描点

已知点求坐标：过点分别作 x 轴、y 轴的垂线，读出垂足对应的数。

已知坐标描点：先在 x 轴上找到横坐标的位置，作 x 轴的垂线；再在 y 轴上找到纵坐标的位置，作 y 轴的垂线；两条垂线的交点就是该点。也可以理解为"从原点出发，先沿 x 方向走横坐标那么多，再沿 y 方向走纵坐标那么多"。

几何含义：描点就是"横向走 x、纵向走 y"这两步位移的合成。点 (x, y) 可以看成：从原点出发，向右（x > 0）或向左（x < 0）走 |x| 个单位，再向上（y > 0）或向下（y < 0）走 |y| 个单位，到达的位置。
物理含义：(x, y) 就是物体相对原点的位置矢量的两个分量：x 是"东西方向"的分量，y 是"南北方向"的分量。走"先向东 3 米，再向北 4 米"与直接"沿斜线走 5 米（方向东北偏东）"到达同一点——这就是矢量分解的思想雏形。

4.4.2 特殊点的坐标

点的位置坐标特征例
原点 O(0, 0)O(0, 0)
x 轴上的点纵坐标 = 0，即 (x, 0)(3, 0)、(−5, 0)
y 轴上的点横坐标 = 0，即 (0, y)(0, 4)、(−2 是错的，应为 (0, −2))
第一、三象限角平分线上的点横坐标 = 纵坐标(2, 2)、(−3, −3)
第二、四象限角平分线上的点横坐标 = −纵坐标(3, −3)、(−2, 2)

4.4.3 点到坐标轴的距离（几何：距离！）

点 P(x, y) 到坐标轴的距离，就是过该点作垂线后垂线段的长度（永远是正数或 0）：

点 P(x, y) 到 x 轴的距离 = |y|   （竖着量的高度）
点 P(x, y) 到 y 轴的距离 = |x|   （横着量的宽度）
几何含义：坐标是"带方向的读数"，距离是"去掉方向只留长度"。所以求距离必须加绝对值：点到 x 轴的距离看纵坐标的绝对值，点到 y 轴的距离看横坐标的绝对值。坐标可正可负，距离恒非负。这与第1章"绝对值 = 到原点的距离"一脉相承。
物理含义：距离 = 长度的度量，不关心方向。一个点无论在东边还是西边、北边还是南边，它"离 y 轴（或 x 轴）多远"是一个只取正值的长度，所以用绝对值。

4.4.4 关于坐标轴、原点的对称点（几何：对称！）

对称关系对称点坐标变化规律例：P(2, −3)
关于 x 轴对称(x, −y)横坐标不变，纵坐标变号(2, 3)
关于 y 轴对称(−x, y)纵坐标不变，横坐标变号(−2, −3)
关于原点对称(−x, −y)横、纵坐标都变号(−2, 3)
几何含义：关于 x 轴对称 = 以 x 轴为"镜子"上下翻转，所以左右（横坐标）不动、上下（纵坐标）翻号；关于 y 轴对称 = 左右翻转；关于原点对称 = 旋转 180°，两个坐标同时翻号。记住"对哪条轴对称，哪个坐标就不变（只翻另一个）"。
物理含义：对称 = 镜像变换。镜面反射（照镜子时左右互换、关于镜面对称）、旋转 180°（掉头）都是生活中的对称。坐标的变号规则让我们能"算"出对称位置，而不必真的画出图形。

4.4.5 平行于坐标轴的直线上点的特征

  • 平行于 x 轴（水平）的直线上的所有点，纵坐标相同；
  • 平行于 y 轴（竖直）的直线上的所有点，横坐标相同。
几何含义：水平线 = "高度不变"，竖直线 = "左右位置不变"。一条水平线可以写成 y = 常数（如 y = 2），一条竖直线可以写成 x = 常数（如 x = −3）。这是"方程表示图形"的最早萌芽。

7.5 用坐标表示地理位置

方法一：建立平面直角坐标系

要在地图上表示一个区域内各点的位置，通常这样做：

  1. 选原点：选一个适当的参照点（如学校、广场、某条路的交叉口）作为原点 O；
  2. 定方向：通常取正北、正东分别为 y 轴、x 轴的正方向（即"上北下南、左西右东"）；
  3. 定单位长度：按图上的实际比例确定一个单位长度代表多长（如 1 格 = 100 米）；
  4. 标出各点：测出各地点的坐标，在图上描点并注明地点名称。
物理含义：这就是地图与导航的原理。建立坐标系 = 建立"参照系 + 比例尺"，每个地点的坐标就是它相对参照点的位置。GPS 定位、电子地图、航海的经纬网，本质上都是给地球（或某区域）套上一个坐标系。

方法二：用方向和距离定位（极坐标思想）

除了用 (x, y)，还可以用"方向 + 距离"定位：从参照点出发，指出目标在什么方向（方位角，如"北偏东 30°"），以及相距多远。

几何含义：这是"极坐标"思想的萌芽——用一个角（方向）和一个长度（距离）确定点的位置，与 (x, y) 的"直角坐标"形成对照。同一点可以有两种描述：直角坐标 (x, y) 或 极坐标（方向, 距离）。
物理含义：生活中指路常说"往东北方向走 500 米"，而不是"向东 353.6 米再向北 353.6 米"——方向 + 距离更贴近人的直觉。导航、雷达（探测目标方位和距离）、海上航向都使用这种描述。

7.6 用坐标表示平移

点的平移规律（核心结论）

平移不改变点的"形状与朝向"，只改变位置。在坐标系中，点的平移就是坐标的加减：

平移方向坐标变化口诀
向右平移 a 个单位横坐标 +a，纵坐标不变：(x + a, y)左右平移：左减右加（改横坐标）
向左平移 a 个单位横坐标 −a，纵坐标不变：(x − a, y)
向上平移 b 个单位纵坐标 +b，横坐标不变：(x, y + b)上下平移：上加下减（改纵坐标）
向下平移 b 个单位纵坐标 −b，横坐标不变：(x, y − b)
点 P(x, y)
  向右平移 a 个单位 →  P'(x + a, y)    向左平移 a 个单位 →  P'(x − a, y)
  向上平移 b 个单位 →  P'(x, y + b)    向下平移 b 个单位 →  P'(x, y − b)
几何含义：平移 = 整个图形沿某方向整体滑动，每一点移动的距离和方向都相同，所以图形的大小、形状、朝向全都不变（只"搬了个地方"）。在坐标语言里，平移就是"给所有点的对应坐标同时加上同一个数"。
物理含义：平移就是位移。一个物体整体向东移动，它的每一个点的横坐标都增加相同的量；整体向北移动，每一个点的纵坐标都增加相同的量。坐标的加减精确地记录了"移动了多少、朝哪个方向"。

图形的平移 = 所有关键点一起平移

一个图形（如三角形）的平移，就是把它各个顶点按同一规律平移，再把新顶点连起来。因此：

  1. 先确定图形各顶点的坐标；
  2. 对每个顶点按"左减右加、上加下减"求出平移后的坐标；
  3. 描出新顶点、连线，得到平移后的图形。

注意方向词

「向右 / 向上」是加，「向左 / 向下」是减；并且横坐标只受左右平移影响、纵坐标只受上下平移影响，两者互不干扰。例：点 (3, −2) 先向右平移 4 个单位，再向上平移 3 个单位，得到 (3 + 4, −2 + 3) = (7, 1)。
几何含义（坐标法解平移题）：平移问题不必真的把图形"搬"着画，只要对顶点坐标做加减，就能精确、快速地得到新图形。这就是用代数方法解决几何问题——"以数解形"的威力。

典型例题（自测）

  1. 写出点 A(3, −4)、B(−5, 2)、C(0, −6)、D(−1, 0) 分别在第几象限（或在哪条坐标轴上），并求它们到 x 轴、y 轴的距离。
  2. 若点 P(a, b) 在第二象限，判断 a、b 的符号；点 Q(−a, −b) 在第几象限？
  3. 求点 (2, −3) 关于 x 轴、y 轴、原点对称的点的坐标。
  4. 点 P(x, y) 先向右平移 5 个单位，再向下平移 3 个单位后得到 (−2, 4)，求原点的坐标 P。
  5. 以学校为原点，正东为 x 轴正方向、正北为 y 轴正方向建立坐标系（1 格 = 100 米）：小明家在学校东偏北 200 米、300 米处，写出小明家的坐标。

常见误区

  • ❌ "点的坐标 (x, y) 与 (y, x) 一样" → ❌ 有序数对顺序不能颠倒，先横后纵。(2, 3) 与 (3, 2) 是不同点。
  • ❌ "点 (0, 3) 在第一象限" → ❌ 它在 y 轴上，坐标轴上的点不属于任何象限。
  • ❌ "点 (−3, 4) 在第二象限，所以它在 x 轴下方" → ❌ 纵坐标 4 > 0，在 x 轴上方；象限位置要按 (横, 纵) 分别判断。
  • ❌ "点 P(−3, 4) 到 x 轴的距离是 −3" → ❌ 距离恒非负：到 x 轴距离 = |4| = 4，到 y 轴距离 = |−3| = 3。
  • ❌ "关于 x 轴对称，横坐标也变号" → ❌ 关于 x 轴对称是上下翻转：横坐标不变，只有纵坐标变号。
  • ❌ "向右平移是横坐标减" → ❌ 向右平移横坐标加，向左才是减；"左减右加、上加下减"。
  • ❌ "平移会改变图形的形状" → ❌ 平移只改变位置，图形大小、形状、朝向都不变。

二、参考答案（点击展开）

查看第1题答案

A(3, 5) 横、纵坐标均为正 → 第一象限；B(−4, 2) 横负纵正 → 第二象限；C(−3, −6) 横、纵均为负 → 第三象限；D(0, −2) 横坐标为 0 → 在 y 轴上（不属于任何象限）；E(−5, 0) 纵坐标为 0 → 在 x 轴上（不属于任何象限）。

查看第2题答案

到 x 轴的距离 = |纵坐标| = |4| = 4；到 y 轴的距离 = |横坐标| = |−3| = 3。Q(4, −3) 与 P(−3, 4) 横纵坐标对调且符号变化，二者位置不同：P 在第二象限（西北方向），Q 在第四象限（东南方向），说明有序数对顺序不能颠倒，坐标可正可负、距离恒非负。

查看第3题答案

第一、三象限角平分线上的点满足 横坐标 = 纵坐标，即 a = b；到 y 轴的距离 = |a| = 5，故 a = 5 或 −5。因此点 M 可能是 (5, 5) 或 (−5, −5)。

关于 x 轴对称：横坐标不变、纵坐标变号 → (2, 3)，在第一象限；关于 y 轴对称：纵坐标不变、横坐标变号 → (−2, −3)，在第三象限；关于原点对称：横、纵坐标都变号 → (−2, 3)，在第二象限。

查看第5题答案

点 P 平移后的坐标是 (−2, 4)，逆推：向右平移 5 个单位是横坐标 +5，向下平移 3 个单位是纵坐标 −3，所以原坐标 P = (−2 − 5, 4 + 3) = (−7, 7)。三角形平移：向上 2、向左 3 即纵坐标 +2、横坐标 −3，得 A′(−2, 4)、B′(0, 1)、C′(−5, 2)。

查看第6题答案

东 200 米 = 横坐标 +2，北 300 米 = 纵坐标 +3，小明家坐标 (2, 3)，在第一象限；西 100 米 = 横坐标 −1，北 200 米 = 纵坐标 +2，图书馆坐标 (−1, 2)，在第二象限。
