第26章 反比例函数

初中 / 初三 / 九年级下册

一句话总纲：反比例函数 = 「乘积保持不变的两种量」之间的关系，图象是双曲线；它的几何灵魂是"双曲线上任一点到两坐标轴的垂线段围成的矩形面积恒等于 |k|"，物理灵魂是"总量一定时，一个量变大另一个量必然变小"。

26.1 反比例函数的概念

什么是反比例函数？（定义）

一般地，形如

        k
  y = ───      (k 为常数，且 k ≠ 0)
        x

的函数叫做反比例函数。其中 x 是自变量，y 是 x 的函数，k 叫做比例系数。

  • 自变量取值范围：x ≠ 0（因为 0 不能作除数，函数值 y 也永远不等于 0）。
  • 三种等价形式：y = k/x ⇔ xy = k ⇔ y = kx⁻¹（k≠0）。做题时看到其中任意一种都要认出"这是反比例函数"。
  • 判断标准：两个变量的乘积是同一个非零常数，即 xy = k（k≠0）。
物理含义（核心！）：反比例关系描述的是"总量固定、两者此消彼长"的情形。乘积 xy = k 中，k 就是那个"不变的积"。例如：路程 s 一定时，速度 v 与时间 t 满足 v = s/t，跑得越快、用时越短；总价一定时，单价与数量成反比；压强 p = F/S（压力 F 一定）中，受力面积越大、压强越小。
几何含义（先埋个伏笔）：把 xy = k 看成"长 × 宽 = 定值"，那么所有满足条件的点 (x, y) 就构成一组"面积恒为 |k| 的矩形"的顶点——这就是后面图象是"双曲线"、且"矩形面积恒等于 |k|"的根本原因。

正比例函数 vs 反比例函数（对照表）

项目正比例函数 y = kx（k≠0）反比例函数 y = k/x（k≠0）
变量关系比值恒定：y/x = k（商不变）乘积恒定：xy = k（积不变）
图象过原点的直线双曲线（两支）
x 的范围全体实数x ≠ 0
关键词"成正比""同步变化""成反比""此消彼长"
一句话区分：正比例是"你翻几倍、我也翻几倍"（比值不变）；反比例是"你翻几倍、我缩成几分之一"（乘积不变）。

26.2 反比例函数的图象（双曲线）

用描点法画 y = 6/x

第一步列出自变量的若干取值（注意 x 不能取 0），算出对应的 y，再描点、连线：

x−6−3−2−11236
y = 6/x−1−2−3−66321

把这些点描在坐标系里连成光滑曲线，就得到两条互不相交、关于原点对称的曲线——合起来叫做双曲线。

        y
        │
        │        ● (1,6)
        │      /
        │    /      y = 6/x (第一象限一支)
        │  /
   ─────┼────────────── x
      / │
    /   │
  ●     │   y = 6/x (第三象限一支)
 (-1,-6)│

双曲线的三个标志性特征

  1. 两支、关于原点对称：双曲线既是中心对称图形（对称中心是原点），又是轴对称图形（对称轴是直线 y = x 和 y = −x 这两条角平分线）。
  2. 无限接近坐标轴，但永不与坐标轴相交：x 轴、y 轴是双曲线的渐近线。因为 x 和 y 都不能为 0，所以图象上没有在坐标轴上的点。
  3. 位置由 k 的正负决定：k > 0 时两支分别在第一、三象限；k < 0 时两支分别在第二、四象限。
几何含义（双曲线的"心脏"）：在双曲线上任取一点 P，过 P 分别向 x 轴、y 轴作垂线段，与坐标轴围成一个矩形。这个矩形的面积恒等于 |k|（因为长=|x|、宽=|y|，而 |x|·|y| = |xy| = |k|）。反过来说：双曲线就是"所有使这个矩形面积为定值 |k| 的点"连成的曲线——这正是它叫"反比例"、并且两头弯曲、永远够不到坐标轴的原因。

k 的大小如何影响"胖瘦"与"远近"？

|k| 越大，双曲线离原点"越远"、两支越向外张开；|k| 越小，双曲线越贴着坐标轴。k 的符号决定在哪两个象限，k 的绝对值决定离坐标轴的远近。

26.3 反比例函数的性质

性质总表（k 的符号决定一切）

项目k > 0k < 0
图象位置第一、三象限第二、四象限
在每个象限内的增减性y 随 x 的增大而减小y 随 x 的增大而增大
对称性关于原点中心对称；关于 y=x、y=−x 轴对称关于原点中心对称；关于 y=x、y=−x 轴对称
与坐标轴无交点（渐近）无交点（渐近）

增减性（务必加"在每个象限内"）

  • k > 0：在每个象限内，y 随 x 的增大而减小。例如 y = 6/x：x 从 1 增大到 2，y 从 6 减小到 3。
  • k < 0：在每个象限内，y 随 x 的增大而增大。例如 y = −6/x：x 从 1 增大到 2，y 从 −6 增大到 −3。

最容易踩的坑

反比例函数的增减性不能跨象限说。k > 0 时，不能说"y 随 x 增大而减小"就说成"x 越大 y 越小"：取第一象限的 x=1（y=6）和第三象限的 x=−1（y=−6），x 从 −1 增大到 1，y 反而从 −6 增大到 6。所以必须限定"在每个象限内"。

对称性（几何含义的又一体现）

  • 中心对称：把图象绕原点旋转 180°，与自身重合——因为 y = k/x 中同时把 x、y 换成 −x、−y，式子不变。
  • 轴对称：关于直线 y = x（一、三象限角平分线）和 y = −x（二、四象限角平分线）对称——这源于"x、y 互换式子仍成立"。
物理含义：性质总表其实刻画了"总量 k 的正负"如何约束变化方向。k > 0（如速度、路程同为正的量）：一个增大另一个就减小；k < 0 意味着两个量符号相反，一个增大时另一个"向反方向"增大。无论哪种，乘积恒为 k，这正是"守恒量"在图象上的体现。

26.4 反比例函数的应用

应用一：待定系数法求解析式

反比例函数只有一个待定常数 k，因此只要一个条件（一个点的坐标）就能确定。步骤：

  1. 设 y = k/x（k≠0）；
  2. 把已知点 (x₀, y₀) 代入，得 k = x₀·y₀；
  3. 写回解析式。

例：图象过点 (2, −3)，则 k = 2 × (−3) = −6，解析式为 y = −6/x。

应用二：面积与 k 的关系（几何含义的直接应用）

  • 双曲线上任一点 P 向两坐标轴作垂线，围成的矩形面积 S = |xy| = |k|。
  • 过 P 作一条轴的垂线，与原点连成直角三角形，其面积是矩形的一半：S = |k|/2。
几何含义（最常考的结论）：反比例函数图象上的点与坐标轴围出的矩形/三角形面积与点的位置无关，只由 |k| 决定。这一条是把"反比例函数"和"面积"两个知识点绑在一起的总枢纽。

应用三：生活中的反比例关系（物理含义）

场景公式谁是常数 k"此消彼长"的含义
匀速运动中路程一定v = s / t路程 s速度越快，用时越短
压强与受力面积（压力一定）p = F / S压力 F受力面积越小，压强越大（刀刃越薄越锋利）
欧姆定律（电压一定）I = U / R电压 U电阻越大，电流越小
杠杆平衡（动力臂×动力=阻力臂×阻力）F₁L₁ = F₂L₂阻力矩 F₂L₂动力臂越长越省力
总价一定时单价与数量单价 × 数量 = 总价总价单价越贵，能买的数量越少
物理含义（统一视角）：这些例子的共同点是——有一个"守恒量"被固定住（路程、压力、电压、力矩、总价），于是另外两个量只能"反着走"。反比例函数就是这类"守恒约束"的数学表达。

典型例题（自测）

  1. 下列函数哪些是反比例函数？并指出比例系数 k：(1) y = 3/x；(2) y = x/3；(3) xy = −5；(4) y = 4x⁻¹；(5) y = 2/(x+1)。
  2. 已知反比例函数图象过点 (−4, 3)，求解析式，并判断点 (2, −6) 是否在图象上。
  3. 画出 y = −4/x 的大致图象，说明它位于哪两个象限、在每个象限内 y 随 x 如何变化。
  4. 双曲线 y = 6/x 上一点 P 的横坐标为 3，求 P 到两坐标轴垂线段围成的矩形面积和三角形面积。
  5. 面积为 12 cm² 的矩形，宽 x (cm) 与长 y (cm) 成什么函数关系？写出解析式并求 x = 4 时的长。
  6. 一辆汽车以速度 v (km/h) 匀速行驶 300 km 的路程。写出 v 关于时间 t (h) 的函数关系式，并求 t = 5 时的速度。

常见误区

  • ❌ "y = k/x 中 k 可以为 0" → ❌ k 必须不为 0，否则 y 恒为 0，不是反比例函数。
  • ❌ "反比例函数的增减性可以跨象限说" → ❌ 必须限定"在每个象限内"：k > 0 时，跨象限比 y 反而会增大。
  • ❌ "双曲线与坐标轴有交点" → ❌ x、y 都不能为 0，双曲线只是无限接近坐标轴（渐近线），永不相交。
  • ❌ "矩形面积等于 k" → ❌ 面积是 |k|（要取绝对值），k 可能为负，面积必为正。
  • ❌ "y = x/3 是反比例函数" → ❌ 它是正比例函数（可写成 y = (1/3)x），反比例要求 x 在分母上。
  • ❌ "反比例函数图象是直线" → ❌ 它是双曲线，由两支互不相交、关于原点对称的曲线组成。

课本外 · 典故与思考

史波义耳定律：科学史上第一个"反比例定律"（点击展开）

1662 年，英国化学家罗伯特·波义耳把一段空气密封在弯管内，用汞柱给它加压，再记录"压强 × 体积"——他惊讶地发现，温度不变时，压强与体积的乘积几乎是一个常数：

PV = 常数      （温度一定时，即 P = k/V）

这正是我们这一章的反比例函数！波义耳还没有"函数"的概念，但他测出的那条"P 随 V 变化"的曲线，就是一支双曲线。14 年后，法国物理学家马略特独立发现了同样的规律，所以这条定律在法国也叫"马略特定律"。

今天，潜水员的氧气瓶、打气筒、甚至连呼吸的原理，背后都是这个 PV = 常数。

一句话总结：反比例函数不是纸上的抽象曲线——它是一条被实验"吹"出来的气体定律。
典"双曲线"这个名字，来自两千年前的圆锥切片（点击展开）

平面斜着切一个圆锥，切出的曲线有好几种：完整地横切一圈得到椭圆，斜着切一面得到抛物线，竖着（或更斜地）同时切两面，得到两段不相连的曲线——就是双曲线。

公元前 200 年左右，古希腊数学家阿波罗尼奥斯写了一部八卷的《圆锥曲线论》，第一次系统地研究这些曲线，并给它们命名："双曲线"的希腊语 hyperbolē 本义是"超出、越过"（因为它越出了圆锥的另一面）；椭圆 ellipsē 是"不足"；抛物线 parabolē 是"平行、比较"。

所以，y = 6/x 画出的那两支曲线，早在坐标轴发明之前，就已经在圆锥面上被研究过了——数学里很多概念，先有"形"，后有"式"。

一句话总结：双曲线、抛物线、椭圆其实是"圆锥的三种切法"——一次买三送一的几何。

一、练习题

  2. 已知 y 与 x 成反比例，且当 x = 3 时，y = −4。(1) 求这个反比例函数的解析式；(2) 求当 x = −6 时 y 的值；(3) 判断点 (2, −6) 是否在该函数图象上。
  3. 反比例函数 y = (m−1)/x 的图象两支分别位于第二、四象限。(1) 求比例系数 (m−1) 应满足的条件，即 m 的取值范围；(2) 此时在每个象限内，y 随 x 的增大如何变化？
  4. 双曲线 y = 6/x（k > 0，图象在第一、三象限）上，取第一象限内一点 P，过 P 分别向 x 轴、y 轴作垂线，垂足为 A、B。(1) 矩形 PAOB 的面积是多少？(2) 若点 P 沿该双曲线移动，这个矩形面积会变吗？(3) 连接 OP，△POA 的面积是多少？
  5. 判断下列说法是否正确，并说明理由："因为 y = 4/x 中 k = 4 > 0，所以 y 随 x 的增大而减小。"
  6. 一辆汽车匀速行驶 240 km 的路程，速度 v（km/h）与行驶时间 t（h）满足 v = 240/t。(1) 行驶 3 小时的速度是多少？(2) 若要求 4 小时内到达，速度至少应为多少？(3) 自变量 t 的取值范围是什么？为什么？

二、参考答案（点击展开）

查看第1题答案

反比例函数须满足"两个变量的乘积是同一个非零常数"（形如 y = k/x，k≠0）。(1) 是，k = 8；(2) 不是，它是正比例函数 y = (1/8)x（x 在分子上）；(3) 是，k = 12（xy = 12 即 y = 12/x）；(4) 是，k = 5（x⁻¹ 即 1/x）；(5) 不是，多了 "+1"，不能化成 y = k/x 的形式（此时 xy = 2 + x，乘积不是常数）。

查看第2题答案

(1) 设 y = k/x，代入 x = 3、y = −4，得 k = 3 × (−4) = −12，故解析式为 y = −12/x。(2) 当 x = −6 时，y = −12 ÷ (−6) = 2。(3) 把点 (2, −6) 代入检验：2 × (−6) = −12 = k，乘积等于比例系数，所以点 (2, −6) 在该函数图象上。

查看第3题答案

(1) 图象位于第二、四象限 ⟺ 比例系数 k < 0，即 m − 1 < 0，解得 m < 1。(2) 当 k < 0 时，在每个象限内，y 随 x 的增大而增大。

查看第4题答案

(1) 矩形面积 = |x|·|y| = |xy| = |k| = 6。(2) 不会变。双曲线上任一点与两坐标轴围成的矩形面积恒等于 |k| = 6，与点的位置无关——这正是反比例函数的核心几何含义。(3) △POA 是矩形 PAOB 的一半（以对角线 OP 为斜边的直角三角形），面积为 |k|/2 = 3。

查看第5题答案

不正确。反比例函数的增减性必须限定"在每个象限内"。反例：取 x₁ = −1 得 y₁ = −4，取 x₂ = 1 得 y₂ = 4；x 从 −1 增大到 1，y 反而从 −4 增大到 4，说明跨象限时不满足"y 随 x 增大而减小"。正确表述：在每个象限内，y 随 x 的增大而减小。

查看第6题答案

(1) v = 240/3 = 80 (km/h)。(2) 4 小时内到达即 t ≤ 4；由 v = 240/t，t 越小 v 越大，故 t = 4 时速度最小，v ≥ 240/4 = 60 (km/h)，即速度至少为 60 km/h。(3) t > 0。t 是行驶时间，物理上只能取正数；且 t = 0 时分母为 0、式子无意义，负数时间也没有实际意义。这正体现反比例函数"自变量 x ≠ 0，且在实际情境中受现实约束"。
