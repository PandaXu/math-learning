第27章 相似

初中 / 初三 / 九年级下册

一句话总纲：相似 = 「形状相同、大小成比例的图形」。学完本章，你要能把"放大、缩小、投影、测高"这些现实动作，都翻译成"角相等 + 边成比例"这套几何语言——角决定形状，边之比（相似比 k）决定大小，而面积按 k²、位似按"中心投影"放大或缩小。

27.1 图形的相似与相似多边形

什么是"相似"？（先与"全等"对照）

你已经学过全等：形状相同、大小也相同，两个图形能完全重合。而相似只要求形状相同，大小可以不同——即一个图形是另一个图形放大或缩小后得到的。

  • 全等：形状相同 + 大小相同（重合）。
  • 相似：形状相同 + 大小可不同（成比例放大/缩小）。
物理含义：相似就是"缩放（scaling）"这一动作。照片放大、地图按比例尺缩小、模型按比例制作，得到的图形都与原图相似。相似比 k 就是"缩放系数"：k > 1 是放大，0 < k < 1 是缩小，k = 1 时就是全等（不缩放）。

相似图形的直观判断

把两张图片"整体放大/缩小"时，每个角都不变、每条边都按同一个倍数变。因此"形状相同"可以精确地定义为：

形状相同 ⇔ 对应角相等 且 对应边成比例（比例相等）

相似多边形（正式定义）

定义：两个边数相同的多边形，如果它们的角分别相等、边成比例，那么这两个多边形叫做相似多边形。相似多边形对应边的比叫做相似比（记作 k）。

例如四边形 ABCD 与 A′B′C′D′ 相似，记作 四边形ABCD ∽ 四边形A′B′C′D′，且：

∠A = ∠A′，∠B = ∠B′，∠C = ∠C′，∠D = ∠D′
AB/A′B′ = BC/B′C′ = CD/C′D′ = DA/D′A′ = k

两个条件缺一不可，举反例体会：

  • 正方形与一般菱形：边可以都相等（成比例，k=1），但角不相等（正方形 90°，菱形不一定）→ 不相似。
  • 一般矩形与正方形：角都相等（都是 90°），但边不成比例（矩形长≠宽）→ 不相似。
  • 所有正方形彼此相似；所有等边三角形彼此相似；所有圆彼此相似。
几何含义："对应角相等"保证形状一致（没有压扁、没有扭曲）；"对应边成比例"保证大小按同一倍数缩放（没有单方向拉伸）。角管"形"，比例管"大小"——这正是"相似"拆成两个字的含义。

相似比 k 的取值与含义

  • k > 1：从原图到目标图是放大（例：1:2 的地图放大为 2 倍，k=2）。
  • k < 1：缩小（例：地图比例尺 1:10000，图上与实地的比 k = 1/10000）。
  • k = 1：对应边相等，结合角相等即全等。所以全等是相似比 k = 1 的特殊相似。
物理含义：地图比例尺、照片放大倍数、模型比例，本质上都是"相似比 k"。地图上 1 cm 对应实地 100 m，即 k = 1 cm / 10000 cm = 1/10000。读懂相似比，就读懂了所有"按比例"的问题。

27.2 相似三角形（定义与平行线定理）

相似三角形的定义与符号

三角形是边数最少的多边形，也是相似问题里最重要的对象。三个角分别相等、三条边成比例的两个三角形叫做相似三角形。

△ABC ∽ △A′B′C′   ⇔
∠A = ∠A′，∠B = ∠B′，∠C = ∠C′
AB/A′B′ = BC/B′C′ = CA/C′A′ = k
  • 符号 ∽ 读作"相似于"。
  • 对应顶点必须写在对应位置：△ABC ∽ △A′B′C′ 意味着 A↔A′、B↔B′、C↔C′，不能写乱，否则比例式全错。
  • k 是相似比；反过来 △A′B′C′ ∽ △ABC 的相似比是 1/k。

平行线分线段成比例（基本事实）

基本事实：两条直线被一组平行线所截，所得的对应线段成比例。

      A        D
      |--------|         l₁ ∥ l₂ ∥ l₃
      |        |         （三条平行线截两条直线）
   B  |-----   |  E
      |        |
      |        |
   C  |--------|  F
        （示意：上下对应线段成比例）

AB/BC = DE/EF     （同一条被截直线上"上段:下段"）
AB/AC = DE/DF     （"上段:全长" 对应相等）
几何含义：平行线像"等距的横杠"，把两条斜线按相同的比例切成一段段。无论斜线多陡、多长，平行线截出的"分点位置比例"是一样的——这是"比例"第一次由平行线保证的几何事实。

由平行得相似（预备定理，A 字型与 8 字型）

预备定理：平行于三角形一边的直线，截其他两边（或两边的延长线），所得的对应线段成比例；所构成的三角形与原三角形相似。

A 字型：                   8 字型（X 字型）：

      A                         A      D
     /\                        \     /
    /  \                        \   /
  D/____\E        DE ∥ BC        \ /    DE ∥ BC
  /      \         ⇒             /\
 /        \       △ADE ∽ △ABC   /  \
B----------C                    B----C

AD/AB = AE/AC = DE/BC = k
物理含义："平行 → 相似"是测高的第一块基石：阳光可看作平行光，物体、影子、光线围成的三角形彼此相似（见 27.5）。这也是"平行投影"的核心性质——平行光把图形按比例投到屏上，投影图形与原图形相似。

27.3 相似三角形的判定

定义要求"三角相等 + 三边成比例"，条件太多。实际判定可以"减条件"，只要抓住本质——角决定形状，边（成比例）决定大小。

四条判定定理

① 预备定理（平行法）：
   平行于三角形一边的直线截得的三角形与原三角形相似。

② 三边成比例（SSS）：
   AB/A′B′ = BC/B′C′ = CA/C′A′   ⇒  △ABC ∽ △A′B′C′

③ 两边成比例且夹角相等（SAS）：
   AB/A′B′ = AC/A′C′ 且 ∠A = ∠A′  ⇒  △ABC ∽ △A′B′C′

④ 两角分别相等（AA）：
   ∠A = ∠A′，∠B = ∠B′  ⇒  △ABC ∽ △A′B′C′
   （两角相等 ⇒ 第三角也相等，故三角都相等）

直角三角形的特殊判定（HL）

斜边和一条直角边成比例的两个直角三角形相似：

Rt△ 中：斜边/斜边′ = 直角边/直角边′  ⇒  两直角三角形相似

与"全等判定"对照记忆

全等（形状+大小相同）相似（形状相同、大小成比例）
SSS（三边相等）SSS（三边成比例）
SAS（两边+夹角相等）SAS（两边成比例 + 夹角相等）
ASA / AAS（两角+一边）AA（两角相等，角不需要边参与）
HL（斜边+直角边相等）HL（斜边+直角边成比例）
记忆规律：把全等里的"边相等"换成"边成比例"，"角相等"保持"角相等"，就得到相似判定。因为角完全决定形状（角相等→同形），边只决定大小（边成比例→同比例）。

最容易考的 AA 判定

两角分别相等 ⇒ 相似。常用"两角"来源：

  • 公共角（两个三角形共用一个角）；
  • 对顶角（8 字型）；
  • 平行线得到的同位角、内错角相等；
  • 同弧（圆周角）、垂直关系等。
物理含义：现实中"量角"往往比"量整条长"容易（比如瞄准、视线夹角），所以 AA 是测绘里最实用的判据：只要两束视线（光线）的夹角一致，物与像就相似。这也解释了为什么"相似"本质上等价于"角对应相等"。

注意：SSA 不能判定相似

两边成比例，但相等的是其中一边的对角（不是夹角），不能保证相似。反例：构造两边成比例但形状明显不同的两个三角形（"圆上动点"问题中常出现两解）。判定时必须用夹角。

27.4 相似三角形的性质

若 △ABC ∽ △A′B′C′，相似比为 k，则：

① 对应角相等，对应边成比例

∠A = ∠A′，∠B = ∠B′，∠C = ∠C′
AB/A′B′ = BC/B′C′ = CA/C′A′ = k

② 对应线段（高、中线、角平分线）之比 = 相似比

对应高之比   = 对应中线之比   = 对应角平分线之比 = k
几何含义：把图形整体放大 k 倍时，不仅边长乘 k，连图形内部任何对应的"线"（高、中线、角平分线）也一起乘 k。这就是"缩放"的均匀性：每个方向、每个部位都按同一个比例变。

③ 周长比 = 相似比

C(△ABC) / C(△A′B′C′) = k
（因为周长 = 三边之和，三边各乘 k，和也乘 k）

④ 面积比 = 相似比的平方

S(△ABC) / S(△A′B′C′) = k²
（因为 S = ½·底·高，底乘 k、高乘 k，故面积乘 k²）
物理含义（平方律）：面积比 = 相似比的平方，这是几何里的"平方律（square law）"。生活中到处是它：正方形边长×2 → 面积×4；地图放大 2 倍 → 图幅面积×4；物体尺寸×2 → 承重面（面积）×4，而体积×8（立方律）。所以"放大一倍，面积不是翻倍而是翻四倍"，这是最容易出错的直觉陷阱。

27.5 相似三角形的应用

核心思路：把"测不了的长度"转成"可测的相似比"

测量高大物体（旗杆、树、楼、塔）或隔河的宽度时，无法直接量，就构造相似三角形，利用对应边成比例，由已知边求未知边。

应用一：影子测高（平行光 → 相似）

同一时刻、同一地点，阳光是平行光：
 物高 / 物影长 = 人高 / 人影长 = 常数 k

例：小明身高 1.5 m，影长 2 m；
    同时测旗杆影长 10 m，求旗杆高 x。
    1.5 / 2 = x / 10  ⇒  x = 7.5 (m)
物理含义：太阳光近似平行光，物体、影子与光线围成的直角三角形两两相似，所以"物高与影长之比"对同一时刻的所有物体都相等。这是"平行投影"的典型应用——相似而不一定位似。

应用二：隔河测宽 / 测不可达距离

利用 8 字型或 A 字型构造相似，测量岸上可量的小三角形，去求河对岸不可达的大三角形对应边。

      A
      |\            △ADE ∽ △ABC（DE ∥ BC）
      | \           若 AD、AE、DE 可测，AB 已知，
      |  \          则 BC = AB · (DE/AD) 可求。
      D---E
      |    \
      B-----C   （对岸）

应用三：镜面反射测高 / 视线测高

把镜子平放在地面上，调整位置使人眼恰能从镜中看到树顶。由光的反射定律，入射角=反射角，构成两个相似直角三角形，从而测高。

物理含义：测高问题的共同点是"用光线作边、用角度作形状、用相似比作尺子"。太阳（平行光）、镜子（反射）、视线（瞄准）提供了相等角，相似三角形把"角相等"翻译成"边成比例"，从而完成测量。

27.6 位似

位似的定义

两个图形不仅相似，而且对应顶点的连线都相交于同一点，对应边互相平行（或在同一条直线上），这样的两个图形叫做位似图形，这个交点叫做位似中心，此时相似比也叫位似比。

        A′
       /|
      / |
  A  /  |        OA、OB、OC 的延长线交于 O（位似中心）
   \/   |        OA/OA′ = OB/OB′ = OC/OC′ = k（位似比）
    \   |        AB ∥ A′B′，BC ∥ B′C′，AC ∥ A′C′
     B--C
      \
       \  B′---C′
        O（位似中心）

位似与相似的关系

  • 位似图形一定是相似图形（它满足相似的全部条件）。
  • 相似图形不一定是位似图形：两个全等的平移图形相似，但对应顶点连线不交于一点，不是位似。
  • 位似比 k 即相似比；位似中心可在两图形之间、外部，甚至在一个图形的边上。
几何含义：位似 = 相似 + "所有对应点都从同一点（位似中心）沿直线同比例地拉开/收拢"。可以想象从位似中心 O 发出许多射线，原图每个点沿自己的射线移动到位似图上——这是"从一个中心放大缩小"。

平面直角坐标系中的位似变换

以原点 O 为位似中心，相似比为 k 时，任意点 P(x, y) 的对应点坐标为：

P(x, y)  →  P′(kx, ky)      （在位似中心同侧）
P(x, y)  →  P″(−kx, −ky)    （在位似中心异侧，关于原点对称）

例：△ABC 顶点 A(2,3)、B(2,1)、C(6,1)，以原点为位似中心、相似比 2 放大：

同侧：A′(4,6)、B′(4,2)、C′(12,2)
异侧：A″(−4,−6)、B″(−4,−2)、C″(−12,−2)
物理含义（中心投影）：位似就是"中心投影 / 透视投影"的几何模型。光线从一点（位似中心）发出，物体被投到屏上，物与像成位似：小孔成像、幻灯机、放大镜（透镜）、路灯下的影子都是中心投影。对比记忆：太阳光（平行光）→ 平行投影 → 相似；灯光/透镜（点光源）→ 中心投影 → 位似。这是区分"影子为什么有的成相似、有的成位似"的关键。

位似作图要点

  1. 定好位似中心 O 与位似比 k。
  2. 连接 O 与各顶点并延长；
  3. 按 OA′ = k·OA（或反向 OA″ = −k·OA）截取对应点；
  4. 顺次连接对应顶点即得位似图形。

概念几何含义物理/现实含义

典型例题（自测）

  1. 判断对错并说明理由：① 所有正方形都相似；② 所有矩形都相似；③ 所有等边三角形都相似；④ 所有等腰三角形都相似；⑤ 所有圆都相似。
  2. 已知 △ABC ∽ △DEF，相似比 k = 3，AB = 4 cm，△DEF 的周长为 15 cm。求 DE 的长，以及 △ABC 的周长；若 △ABC 的面积为 18 cm²，求 △DEF 的面积。
  3. 用判定定理说明：① 三边长分别为 3、4、5 与 6、8、10 的两个三角形是否相似？② 两边为 4、6 且夹角 60° 与两边为 8、12 且夹角 60° 是否相似？③ 一个三角形两角为 50°、60°，另一个为 50°、70°，是否相似？
  4. 同一时刻，身高 1.6 m 的同学影长 1.2 m，旁边旗杆影长 9 m，求旗杆高。
  5. 以原点为位似中心，把点 P(3,−2) 按相似比 2 放大，写出同侧与异侧对应点的坐标；再把点 Q(−1, 4) 按相似比 1/2 缩小，写出对应点坐标。
  6. （提高）给出一个"两边成比例但对应角是其中一边对角"的反例：画两个三角形，说明仅凭 SSA 无法判定相似。

常见误区

  • ❌ "形状相同就是大小也相同" → ❌ 那是全等；相似只要求形状相同，大小成比例。
  • ❌ "所有矩形都相似 / 所有菱形都相似" → ❌ 矩形角虽相等但边不成比例，菱形边虽成比例但角不相等；正方形、等边三角形、圆才"全体彼此相似"。
  • ❌ "两边成比例就能判定相似" → ❌ 必须是两边成比例且夹角相等（SAS）；SSA（一边的对角）不能判定。
  • ❌ "相似比是多少，面积比就是多少" → ❌ 周长比 = k，但面积比 = k²（放大 2 倍，面积 4 倍，不是 2 倍）。
  • ❌ "相似图形一定是位似图形" → ❌ 位似一定相似，但相似不一定位似；还要求对应点连线交于同一点。
  • ❌ "位似图形对应边一定平行" → ❌ 对应边互相平行或在同一条直线上（三点共线时边在同一直线上）。
  • ❌ "坐标系里放大 k 倍就是坐标乘 k，符号不用管" → ❌ 以原点为位似中心时，还有异侧情形 (−kx, −ky)，别漏掉关于原点对称的另一组解。
  • ❌ "写 △ABC ∽ △DEF 时顶点随便排" → ❌ 对应顶点必须写在对应位置，否则比例式对应关系全乱。

课本外 · 典故与思考

史泰勒斯测金字塔：第一个用"影子"量出巨人高度的人（点击展开）

传说（注意是传说——记载来自后世的传记，未必确凿）：公元前 6 世纪，希腊学者泰勒斯到埃及旅行，埃及人问他：你能不爬上去，量出金字塔的高度吗？

泰勒斯的方法正是我们 27.5 学的影子测高：选一个时刻，先量自己影子的长度和自己的身高，再量金字塔的影子，然后按比例算：

金字塔高 / 金字塔影长 = 人高 / 人影长

因为同一时刻的太阳光是平行光，两个直角三角形相似。这个做法简单到近乎"作弊"，但它被认为是人类第一次用"相似"完成了看似不可能的测量。

一句话总结：泰勒斯的故事无论真假，都点破了本章的核心——量不出的东西，用相似去"换"出来。
思地图比例尺里藏着一个"面积陷阱"（点击展开）

地图上写的 1 : 100000 表示图上 1 cm 对应实地 100000 cm = 1 千米。这是相似比 k = 1/100000。

但如果你以为"图上面积也按这个比例缩小"，就掉进陷阱了：面积比是 k²，所以

图上 1 cm² 对应实地 (1 km)² = 1 km²

也就是说，在比例尺 1 : 100000 的地图上，一枚一元硬币（面积约 5 cm²）盖住的地方，实地约是 5 平方公里。看地图估算面积时，先平方再乘，别只乘一次。

一句话总结：长度按 k 缩、面积按 k² 缩——地图上的每一个平方厘米，都对应着实地一大片平方公里。

本章练习卷（含答案）

一、练习题

  1. （相似图形的定义）判断下列各组图形是否一定相似，并简述理由：①两个正方形；②两个矩形；③两个菱形；④两个等边三角形；⑤两个圆。
  2. （相似比与对应边）已知 △ABC ∽ △DEF，相似比 k = 2（即 △ABC 的各边是 △DEF 对应边的 2 倍）。若 BC = 8，求对应边 EF 的长。
  3. （AA 判定与平行线）在 △ABC 中，D 在 AB 上、E 在 AC 上，且 DE ∥ BC。说明 △ADE ∽ △ABC，并写出三组对应边的比例式。
  4. （判定定理综合）判断下列两个三角形是否相似，并写出依据：①三边分别为 3、4、5 与 6、8、10；②两边为 4、6 且夹角 60° 与两边为 8、12 且夹角 60°。
  5. （性质：周长比与面积比）若 △ABC ∽ △DEF，相似比 k = 3，△ABC 的周长为 36 cm、面积为 27 cm²，求 △DEF 的周长与面积。
  6. （位似与坐标系）以原点 O 为位似中心、相似比 k = 2，写出点 P(3, −2) 的同侧与异侧对应点坐标；再把点 Q(−1, 4) 按相似比 1/2 缩小，写出同侧对应点坐标。

二、参考答案（点击展开）

查看第1题答案

①一定相似：所有正方形的角都是 90°、边成比例；②不一定相似：矩形角都相等（都是 90°），但邻边之比未必相等，即边不一定成比例；③不一定相似：菱形四条边可成比例（边长比相同），但角不一定相等；④一定相似：等边三角形三个角都是 60°，边成比例；⑤一定相似：所有圆彼此相似。

查看第2题答案

相似比 k = AB/DE = BC/EF = 2，即 △ABC 的边是对应边的 2 倍，所以 EF = BC ÷ 2 = 8 ÷ 2 = 4。

查看第3题答案

因为 DE ∥ BC，∠ADE = ∠B（同位角）、∠AED = ∠C（同位角），且 ∠A 为公共角，由 AA 判定得 △ADE ∽ △ABC；对应边比例式为 AD/AB = AE/AC = DE/BC。

查看第4题答案

①相似：3/6 = 4/8 = 5/10 = 1/2，三边成比例（SSS 判定）；②相似：4/8 = 6/12 = 1/2，且夹角都是 60°，两边成比例且夹角相等（SAS 判定）。

查看第5题答案

周长比 = 相似比 = 3，故 △DEF 的周长 = 36 ÷ 3 = 12 cm；面积比 = 相似比的平方 = 3² = 9，故 △DEF 的面积 = 27 ÷ 9 = 3 cm²。

查看第6题答案

P(3, −2) 按 k = 2 放大：同侧 P′(6, −4)，异侧 P″(−6, 4)；Q(−1, 4) 按 k = 1/2 缩小：同侧 Q′(−1/2, 2)。
