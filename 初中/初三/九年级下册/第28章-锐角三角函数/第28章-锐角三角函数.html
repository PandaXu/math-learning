第28章 锐角三角函数

初中 / 初三 / 九年级下册

一句话总纲：锐角三角函数 = 「用一个锐角，定死一个直角三角形的形状」。正弦、余弦、正切是三角形的三条「边比」，它们只由角决定、与三角形大小无关；学完本章，你要能在心里把「角」翻译成「边之比」，再用它去测量无法直接丈量的高度与距离。

28.1 正弦、余弦、正切

为什么需要三角函数？（几何动机）

回忆相似三角形：两个直角三角形，只要有一个锐角相等，它们就相似；相似三角形的对应边成比例。反过来想——只要锐角 ∠A 确定，直角三角形的形状就被唯一确定了，于是任意两条边的比值也就被唯一确定了，跟这个三角形画得有多大无关。

这三个「由角唯一决定的边之比」，就是三角函数。用它们，我们可以从角度出发去求边长，也可以从边长反推出角度——这就是「角」与「边」之间的桥梁。

核心直觉：三角函数是「角 → 形状 → 边比」的编码表。同一个 30° 角，无论三角形放大缩小多少倍，对边/斜边 永远是 1/2。这就像「形状的指纹」——角度不变，指纹不变。

三条边的命名：对边、邻边、斜边

在直角三角形 Rt△ABC 中，设 ∠C = 90°，考察锐角 ∠A：

边相对 ∠A 的位置记号（按边长）

∠A 的对边∠A 正对着的那条直角边a
∠A 的邻边∠A 旁边的另一条直角边（不是斜边）b

关键提醒：「对边」「邻边」永远是相对某个锐角说的。同一条直角边，对 ∠A 是邻边，对 ∠B 却是对边——换个角度，命名就互换。

三个三角函数的定义

             ∠A 的对边      a
  正弦 sinA = ────────── = ───
                斜边         c

             ∠A 的邻边      b
  余弦 cosA = ────────── = ───
                斜边         c

             ∠A 的对边      a
  正切 tanA = ────────── = ───
             ∠A 的邻边      b
  • 正弦 sinA：对边比斜边。
  • 余弦 cosA：邻边比斜边。
  • 正切 tanA：对边比邻边（两条直角边之比，与斜边无关）。
几何含义：sinA 与 cosA 把「斜边」投影到「竖直」与「水平」两个方向——它们回答「斜边这个总长度，有多少落在竖直方向、多少落在水平方向」；tanA 回答「竖直与水平的配比」，也就是这条边的倾斜程度（斜率）。所以 sin、cos 是投影，tan 是坡度。
物理含义：任何斜着的量都可以用 sin、cos 拆成「竖直分量 + 水平分量」。例如斜面上物体的重力 G 沿斜面下滑的分力是 G·sinθ、垂直压着斜面的分力是 G·cosθ；一个斜向拉力 F 与水平成 θ 角，则水平分力 F·cosθ、竖直分力 F·sinθ。三角函数是「力的分解」的语言。

取值范围与基本性质

因为直角三角形的直角边总比斜边短，所以对锐角 A（0° < A < 90°）恒有：

0 < sinA < 1，  0 < cosA < 1，  tanA > 0（可任意大）

同角关系（三条黄金公式）：

① sin²A + cos²A = 1     （由勾股定理 a² + b² = c² 两边同除以 c² 得到）
② tanA = sinA / cosA    （对边/邻边 = 对边/斜边 ÷ 邻边/斜边）
③ 互余关系：sinA = cos(90° − A)，cosA = sin(90° − A)，
   tanA = 1 / tan(90° − A)（因为两个锐角 A、B 互余，A 的对边正是 B 的邻边）
几何含义：sin²A + cos²A = 1 就是勾股定理的「比值版」——一个单位长度斜边，在竖直方向的投影 sinA 与水平方向的投影 cosA，满足「两投影的平方和 = 1」。这正是一个半径为 1 的圆（单位圆）上的点坐标 (cosA, sinA)，到高中会全面展开。

28.2 特殊角的三角函数值（30°、45°、60°）

三个特殊角，两个「标准三角形」

特殊角的值不需要死记，它们都来自两块「最标准的三角板」：

  • 45°：等腰直角三角形（45°-45°-90°）。设两直角边都为 1，则斜边 = √2。
  • 30° 与 60°：30°-60°-90° 三角形（把边长为 2 的等边三角形沿高对半分）。短直角边（对 30°）= 1，斜边 = 2，长直角边（对 60°）= √3。
45° 等腰直角△：                30°-60°-90°△（等边△的一半）：
  直角边 1、1、斜边 √2            短边 1、斜边 2、长边 √3

  sin45° = 1/√2 = √2/2           sin30° = 1/2      sin60° = √3/2
  cos45° = 1/√2 = √2/2           cos30° = √3/2     cos60° = 1/2
  tan45° = 1/1 = 1               tan30° = 1/√3 = √3/3
                                  tan60° = √3/1 = √3

特殊角三角函数值速查表

角 αsin αcos αtan α
30°1/2√3/2√3/3
45°√2/2√2/21

记忆规律：

  • sin 一列：1/2 → √2/2 → √3/2（分母都是 2，分子是 √1、√2、√3 递增）。
  • cos 一列：正好是 sin 一列的倒过来：√3/2 → √2/2 → 1/2（因为 cosα = sin(90°−α)）。
  • tan 一列：√3/3 → 1 → √3（等于 sin/cos，逐级放大）。
几何含义：记住两句话即可现场推导——「30° 所对的直角边等于斜边的一半」（所以 sin30° = 1/2），「45° 的直角三角形两直角边相等」（所以 tan45° = 1）。其余全部由勾股定理与定义推出。
物理含义：sin30° = 1/2 在物理里极常用：光滑斜面上物块沿斜面下滑的加速度 a = g·sinθ，当斜面倾角 30° 时 a = g/2；要把一个物体匀速拉上 30° 坡，至少需要 G·sin30° = G/2 的力。特殊角让力、速度、高度的换算直接变成简单分数。

28.3 解直角三角形

什么是「解直角三角形」？

直角三角形共有六个元素：三条边 a、b、c 与三个角 A、B、C（其中 C = 90°）。已知其中某些元素（至少一条边），求出其余所有未知元素的过程，叫「解直角三角形」。

解题的三组工具

工具内容作用
三边关系勾股定理 a² + b² = c²已知两边求第三边
两角关系A + B = 90°（两锐角互余）已知一角求另一角
边角关系sin、cos、tan 三个定义已知一边一角求其它边

四种基本类型

已知条件求解步骤
① 两直角边 a、b勾股定理求 c；tanA = a/b 求 A；B = 90° − A
② 斜边 c 与一直角边 a勾股定理求 b；sinA = a/c 求 A；B = 90° − A
③ 一直角边 a 与一锐角 AB = 90° − A；tanA = a/b 求 b；sinA = a/c 求 c
④ 斜边 c 与一锐角 AB = 90° − A；sinA = a/c 求 a；cosA = b/c 求 b
几何含义：「解直角三角形」的本质是——给定形状的一部分信息，把整个三角形的形状和大小复原出来。因为直角三角形由「一个锐角」决定形状、由「一条边」决定大小，所以「一边 + 一角」或「两边」就足以唯一确定整个三角形。
物理含义：这对应「矢量合成的逆运算」——已知一个斜向量的大小和方向角，把它分解成水平、竖直两个分量（用 sin、cos）；反过来，已知两个垂直分量，用勾股定理与 tan 合成出合矢量的大小与方向。这是物理中几乎所有「分解与合成」的数学模型。

精确值与近似值

若角是 30°、45°、60°，结果应保留精确值（含 √ 或分数）；若角不是特殊角，则用计算器求 sin/cos/tan，结果按题目要求四舍五入。注意：先列式、后代值、最后一步才取近似，避免中间四舍五入积累误差。

28.4 应用：仰角俯角、坡度、方位角

三角函数的最大价值，是让我们不用爬上去，就能量出高度；不用走过去，就能量出距离。关键是把实际问题抽象成一个直角三角形，找到「已知边、已知角、所求边」。

① 仰角与俯角

  • 仰角：视线在水平线上方时，视线与水平线所成的角。
  • 俯角：视线在水平线下方时，视线与水平线所成的角。
  • 规律：从高处看低处的俯角 = 从低处看高处的仰角（两直线平行，内错角相等）。
物理含义：测旗杆高、测楼高、测飞机高度，用的都是「仰角 + 水平距离」这条直角三角形：高度 = 水平距离 × tan(仰角)。雷达、测距仪也是靠仰角 + 斜距，用 高度 = 斜距 × sin(仰角) 换算。

② 坡度与坡角

  • 坡角 α：坡面与水平面的夹角。
  • 坡度（坡比）i：坡面的铅直高度 h 与水平宽度 l 的比，记作 i = h : l = h/l。
  • 关键联系：坡度 i = tan(坡角 α)——坡度就是正切！
物理含义：公路、铁路、登山道标注的「坡度 1:2」其实就是在说 tanα = 1/2，即每水平前进 2 米，上升 1 米。坡越陡，α 越大，tanα 越大——正切就是「陡峭程度」的量化。

③ 方位角与方向角

  • 方位角：从某点的指北方向线起，顺时针转到目标方向线的水平角（0°~360°）。例：方位角 135° 表示从正北顺时针转 135°，指向东南。
  • 方向角：以南北为基准、东西为偏转来描述方向，如「北偏东 30°」「南偏西 45°（即西南）」。做题时先在图上标出南北方向，再画出偏转角度。
物理含义：航海、航空、GPS 定位都靠方位角确定方向；结合速度与时间算出航程，再用 sin、cos 把航程分解成「东西位移」与「南北位移」，就能确定到达点的精确坐标。

应用题的通用四步

  1. 画图：把题中的高度、距离、角度标到图上，找出（或补出）直角三角形。
  2. 定角定边：明确已知的是哪个角、哪条边，要求的是哪条边。
  3. 选函数：按「已知边—所求边」选 sin/cos/tan（见下表）。
  4. 列式求解：列方程、解出未知量，保留精确值或按题取近似。
已知 + 所求用哪个函数
已知斜边，求对边sin（对边 = 斜边 × sinA）
已知斜边，求邻边cos（邻边 = 斜边 × cosA）
已知邻边，求对边tan（对边 = 邻边 × tanA）
已知两边，求角反用 sin/cos/tan（比值 → 角度）

典型例题（自测）

例题 1 · 求值

  1. 计算：sin30° + cos60° + tan45°。
  2. 计算：sin²45° + cos²45°，并用公式 sin²A + cos²A = 1 验证。
  3. 计算：tan30° × tan60°，观察结果说明了什么？

例题 2 · 解直角三角形

  1. 在 Rt△ABC 中，∠C = 90°，∠A = 30°，斜边 c = 10，求两条直角边 a、b（保留精确值）。
  2. 在 Rt△ABC 中，∠C = 90°，直角边 a = 3、b = 4，求斜边 c 与 ∠A 的正弦、余弦、正切。

例题 3 · 应用

  1. 小明在离旗杆底部 30 m 处，测得旗杆顶端的仰角为 45°，求旗杆高度。
  2. 一段坡的坡角为 30°，沿坡面走了 100 m，求他上升了多少米。
  3. 某人朝「北偏东 60°」方向走了 8 km，求他向东、向北各走了多少千米。

常见误区

  • ❌ 把对边、邻边搞反 → ⚠️ 对边、邻边是相对某个锐角而言的；先明确「考察哪个角」，再数边，切勿背死位置。
  • ❌ sinA = 对边/邻边 → ❌ sin 是「对边/斜边」，邻边/斜边 才是 cos；正切 tan 才是「对边/邻边」。
  • ❌ sin、cos、tan 的值会随三角形大小改变 → ❌ 锐角一定，边比就固定不变（相似三角形的对应边成比例），只与角有关。
  • ❌ sin60° = √3/3 → ❌ sin60° = √3/2；√3/3 是 tan30°。混淆 sin 与 tan 的表格。
  • ❌ 坡度 = 坡角的度数 → ❌ 坡度是 tan(坡角)，是「高/宽」的比值，不是角度本身。
  • ❌ 已知角不是特殊角就用手算 → ❌ 非特殊角用计算器查 sin/cos/tan，并注意最后一步再取近似。
  • ❌ 仰角与俯角用错、或认为两者不同 → ❌ 同一位置的仰角与俯角相等（内错角），只是观察者位置高低不同。

本章练习卷（含答案）

一、练习题

  1. 在 Rt△ABC 中，∠C=90°，∠A=30°，斜边 c=10，求两条直角边 a、b（保留精确值）。
  2. 求值：sin²45° + cos²45°，并说明结果为什么恒等于 1。
  3. 已知锐角 A 满足 sinA = 3/5，求 cosA 与 tanA。
  4. 小明站在离旗杆底部 20 m 处，测得旗杆顶端仰角为 60°，求旗杆高度（保留精确值）。
  5. 一段坡的坡度 i = 1:2（即 tanα = 1/2），某人沿坡面走了 50 m，求他上升了多少米。
  6. 一艘船朝「北偏东 30°」方向航行 20 km，求它向东、向北各走了多少千米；这个方向用方位角表示是多少度？

二、参考答案（点击展开）

查看第1题答案

由「30° 所对的直角边等于斜边的一半」：a = c·sin30° = 10 × 1/2 = 5；b = c·cos30° = 10 × √3/2 = 5√3。答：a = 5，b = 5√3。

查看第2题答案

sin45° = cos45° = √2/2，故 sin²45° + cos²45° = 1/2 + 1/2 = 1。它恒等于 1，是因为 sin²A + cos²A = 1 就是勾股定理的「比值版」：单位斜边在竖直、水平方向的投影平方和恒为 1。

查看第3题答案

sinA = 对边/斜边 = 3/5，设对边 = 3k、斜边 = 5k，则邻边 = √((5k)² − (3k)²) = 4k。故 cosA = 邻边/斜边 = 4/5，tanA = 对边/邻边 = 3/4。

查看第4题答案

旗杆高 = 水平距离 × tan(仰角) = 20 × tan60° = 20√3 m。

查看第5题答案

坡度 tanα = 1/2，即「高 : 水平 = 1 : 2」。设上升 x m，则水平前进 2x m，坡面长 = √(x² + (2x)²) = x√5 = 50，得 x = 50/√5 = 10√5 m。答：上升 10√5 m。

查看第6题答案

「北偏东 30°」= 从正北向东偏 30°，向北方向分量更大：向北 = 20 × cos30° = 10√3 km，向东 = 20 × sin30° = 10 km。方位角是从正北顺时针转过的角度，此处恰好就是 30°。
