第24章 圆

初中 / 初三 / 九年级上册

一句话总纲：圆 = 「到定点（圆心）距离相等的所有点」组成的图形——它是最"公平"、最"对称"的图形。学完本章，你要能在心里"看见"一个圆：圆心决定位置、半径决定大小，弦与弧、角与切线、弧长与扇形面积，全部还原成"到圆心的距离"和"绕圆心转过的角"这两把尺子。

24.1 圆的基本概念

圆的定义

在平面内，线段 OA 绕着它的一个端点 O 旋转一周，另一个端点 A 所形成的图形叫做圆。这个"旋转一周"的过程，正好是圆规画圆的过程。

  • 圆心 O：定点，决定圆的位置。
  • 半径 r：连接圆心和圆上任意一点的线段 OA，决定圆的大小。
  • 圆的集合定义：圆是"到定点（圆心）的距离等于定长（半径）的所有点的集合"。这句话是本章一切定理的总根源。
核心直觉：圆上的每一点到圆心的距离完全相等（都是 r）。圆是最"公平"的图形——它把圆周上的每一点都放在离中心同样远的位置，这正是车轮、表盘、齿轮都要做成圆形的根本原因。

与圆有关的元素

元素定义几何含义
弦连接圆上任意两点的线段圆上两点的"直线捷径"
直径经过圆心的弦最长的弦，长度 = 2r
弧圆上任意两点间的部分沿圆周的"弯路"，分优弧、劣弧
半圆直径的两个端点把圆分成的两条弧每条弧所对的圆心角 = 180°
圆心角顶点在圆心的角两条半径张开的角
圆周角顶点在圆上、两边都与圆相交的角两条弦在圆周上张开的角

等圆 / 等弧：能够完全重合的两个圆叫等圆（半径相等即可）；在同圆或等圆中，能够完全重合的弧叫等弧。

物理含义：半径 r 相当于"臂长"，圆心 O 相当于"固定转轴"。圆规、时钟指针、电风扇叶片、摩天轮座舱的轨迹，都是"固定转轴 + 定长臂"扫出的圆。一个点做匀速圆周运动时，它到圆心的距离（半径）不变，只是位置角在匀速增加。

圆的对称性

  • 圆是轴对称图形，任何一条直径所在的直线都是它的对称轴（无数条）。
  • 圆是中心对称图形，对称中心是圆心。
  • 圆还具有旋转不变性：绕圆心旋转任意角度都与自身重合——这是圆区别于一般图形的最强对称性。
物理含义：圆是"各向同性"的化身——转动车轮、旋转的陀螺、滚动的硬币，转任何角度看起来都一样，因此圆在力学、机械（齿轮、轴承、飞轮）中无处不在。

24.2 垂径定理

定理内容

垂径定理：垂直于弦的直径，平分这条弦，并且平分弦所对的两条弧。

即：若直径 CD 垂直于弦 AB，垂足为 E，则 AE = BE，且弧 AC = 弧 BC、弧 AD = 弧 BD。

        C
        |
   A────E────B      CD ⊥ AB
        |          E 是 AB 中点
        |          AE = BE
        D

为什么成立？（几何含义）

证明的关键是圆的对称性：圆关于任何一条直径所在的直线对称。把圆沿直径 CD 折叠，圆的两半完全重合；又因为 CD ⊥ AB，弦的两端 A、B 关于 CD 对称，所以 A 与 B 重合，从而 AE = BE，两段弧也重合。

几何含义：垂径定理把"垂直"翻译成"平分"——对称轴垂直于被平分的线段。它本质上是等腰三角形三线合一的翻版：连 OA、OB，△OAB 是等腰三角形，OE 既是底边 AB 上的高，又是底边的中线（和顶角平分线）。

推论（知二推三）

在同圆或等圆中，一条直线若满足下列条件中的任意两个，就能推出其余三个：

  1. 过圆心（是直径所在直线）；
  2. 垂直于弦；
  3. 平分弦（注意：被平分的弦不能是直径）；
  4. 平分弦所对的优弧；
  5. 平分弦所对的劣弧。
物理含义：垂径定理就是"从圆心向弦作垂线，垂足正好落在弦的正中点"。在工程中，要找一个圆形工件（如管材截面）的圆心，或测量圆拱桥的拱高，常常先量弦长与弦心距，再用勾股定理反求半径——这正是垂径定理 + 勾股定理的组合拳。

弦心距与半径、弦长的关系

设弦 AB 长为 a，圆心到弦的距离（弦心距）为 d，半径为 r，垂足 E 为中点，则在直角三角形 OEA 中：

r² = d² + (a/2)²
  • 同圆中，弦心距越小，弦越长；弦心距越大，弦越短。
  • 弦心距为 0（即过圆心）时，弦就是直径，最长。
这条式子把"弦长、弦心距、半径"三个量绑在同一个直角三角形里，是解决弦长计算题的万能钥匙。

24.3 圆心角与圆周角

弧、弦、圆心角的关系

在同圆或等圆中，下面几组量是"同进退"的：

  • 相等的圆心角 ⇔ 相等的弧 ⇔ 相等的弦 ⇔ 相等的弦心距。
几何含义：圆心角是"绕圆心转过的角度"，弧是"圆周上走过的路程"，弦是"两端的直线距离"。因为圆是旋转对称的，转过的角越大，走过的弧越长，两端的弦越长——三者被同一个旋转角统一起来。

圆周角定理

圆周角定理：一条弧所对的圆周角等于它所对圆心角的一半。

∠APB = ½ ∠AOB      （∠AOB 是弧 AB 所对的圆心角）

证明思想（分三种位置：圆心在角内、在角的一边上、在角外）都归结为一句话：连半径，用"等边对等角 + 外角等于不相邻两内角之和"。

推论

  1. 同弧或等弧所对的圆周角相等；在同圆或等圆中，相等的圆周角所对的弧也相等。
  2. 半圆（或直径）所对的圆周角是直角；反之，90° 的圆周角所对的弦是直径。这就是著名的"直径对直角"。
  3. 圆内接四边形的对角互补（两对角之和都是 180°）。
几何含义：圆周角是"站在圆周上看到的视角"，圆心角是"站在中心看到的视角"。同一个弧，站在圆上看的视角恰好是站在圆心看的视角的一半——这来自"同弧圆周角都相等"这一事实：所有站在该弧对面的圆周上的点，看这条弧的视角都相同。
物理含义：圆周角定理是"视角不变性"：运动员沿圆形跑道奔跑时，看对面某段固定跑道（同一段弧）的视角始终不变；雷达、剧场、足球场的视线设计都用到"直径对直角"——站在以两障碍物为直径的圆上，看它们的夹角永远是直角。

24.4 直线与圆的位置关系

三种位置关系

设圆的半径为 r，圆心到直线 l 的距离为 d，则：

位置关系公共点个数数量条件图示特征
相离0 个d > r直线在圆外，碰不到圆
相切1 个（切点）d = r直线刚好"擦过"圆
相交2 个（交点）d < r直线"穿过"圆
核心思想：判断直线与圆的位置关系，不看图，只看"圆心到直线的距离 d"与"半径 r"的大小。这又把位置关系还原成了"距离"这把尺子——d 是圆心到直线的垂线段长，垂足是圆心到直线最近的点。
物理含义：直线与圆的关系就是"物体掠过圆形目标"：一辆车沿直线行驶（直线），圆形水坑是圆。若车到坑心的最近距离大于半径（d > r），车轮碰不到坑——相离；刚好等于半径——擦边相切；小于半径——压进坑里相交（压过弦）。

与方程的联系（拓展视野）

直线与圆相交时，两个交点之间的线段是弦。求弦长，先求弦心距 d，再用 r² = d² + (a/2)²。若 d = 0（直线过圆心），弦就是直径。

24.5 切线

切线的判定与性质

切线的定义：直线与圆有唯一公共点（相切）时，这条直线叫圆的切线，公共点叫切点。

判定定理：经过半径的外端，并且垂直于这条半径的直线，是圆的切线。

性质定理：圆的切线垂直于过切点的半径。

几何含义：切线是"刚好碰到圆、又不穿进去"的那条直线。它与过切点的半径垂直，意味着切点是圆心到直线上所有点里最近的点——从圆心向切线作垂线，垂足正是切点，垂线段长正好是半径。
物理含义：切线就是圆周运动的瞬时方向！系绳子的石头绕手旋转，绳子突然断开，石头沿切线方向飞出；雨滴从旋转的车轮、旋转的雨伞边沿甩出，也沿切线飞。因为"切线方向 = 半径垂直方向 = 那一瞬间的运动方向"。

切线长定理

从圆外一点 P 引圆的两条切线 PA、PB（A、B 为切点），则：

  • 切线长相等：PA = PB；
  • 圆心与这一点的连线平分两条切线的夹角：∠APO = ∠BPO。
几何含义：两条切线段关于 PO 对称——因为 △PAO ≌ △PBO（斜边 PO 公用、直角边 OA = OB = r）。切点 A、B 关于直线 PO 对称。
物理含义：从圆外一点看圆，两条切线是"视线刚好与圆擦边的两个极限方向"，切线长就是从该点"摸到"圆边缘的最短接触距离；两条切线张成的角，就是从该点看圆的视角。灯塔照亮范围、灯罩的照射角都与此有关。

弦切角（拓展）

顶点在圆上、一边与圆相交、另一边与圆相切的角叫弦切角。弦切角等于它所夹的弧所对的圆周角：∠弦切角 = ½ 所夹弧的度数。这可以看成切线"退化"后仍遵守"圆周角等于弧的一半"。

三角形的内切圆与外接圆

圆圆心（心）性质作法
外接圆外心（三边垂直平分线交点）到三顶点距离相等作两边垂直平分线，交点为圆心
内切圆内心（三条角平分线交点）到三边距离相等作两角平分线，交点为圆心
物理含义：外接圆是"三个顶点都能套在同一个圈上"（雷达三站共圆定位）；内切圆是"三角形里能塞进的最大圆盘"（如三角形盒子里能放的最大圆饼）。内心到三边距离相等，恰是"公平地站在三条边正中央"。

24.6 弧长与扇形面积

弧长公式

设圆的半径为 r，n° 的圆心角所对的弧长为 l，则：

l = (n / 360) × 2πr = nπr / 180
几何含义：弧长是圆周长的"按比例切一刀"。整圆是 360°，n° 占整圆的 n/360，所以弧长也占整个圆周 2πr 的 n/360。弧长只由"半径"和"圆心角"决定，与弧的"胖瘦位置"无关。

扇形面积公式

由组成圆心角的两条半径和圆心角所对的弧围成的图形叫扇形。设扇形圆心角为 n°，半径为 r，弧长为 l，面积为 S，则：

S = (n / 360) × πr²          （用圆心角 n 表示）
S = ½ l r                    （用弧长 l 表示，很像三角形面积）
几何含义：扇形面积 = 圆面积 πr² 的 n/360。第二个式子 S = ½lr 揭示了扇形"其实是一个卷起来的三角形"——底是弧长 l、高是半径 r。把扇形越切越细、摊平成近似三角形，就能直观理解它。
物理含义：扇形是"钟表指针扫过的区域""扇形齿轮的齿面""披萨切块"。钟表分针扫过的角度 ∝ 时间，扫过的面积可用 S = ½lr 或 S = nπr²/360 直接算出；扫地机器人、雷达扫描的覆盖区域都是扇形。

圆锥的侧面展开（弧长与扇形的应用）

圆锥的侧面沿母线展开是一个扇形：扇形的半径 = 圆锥的母线长 l，扇形的弧长 = 圆锥底面圆的周长 2πr。

扇形圆心角 n°：  n/360 × 2π·母线 = 2π·底面半径r
                即  n = 360° × (r / 母线)
物理含义：把圆锥"剪开摊平"就是扇形，这正是制作圆锥形漏斗、灯罩、纸杯、冰淇淋蛋筒下料的方法——先按扇形裁纸，再卷成锥体。

典型例题（自测）

  1. ⊙O 的半径为 5 cm，弦 AB = 8 cm，求圆心 O 到弦 AB 的距离。
  2. 一条弦把圆分成 2:3 的两段弧，求这两段弧所对的圆心角各是多少度。
  3. ⊙O 中，弧 AB 所对的圆心角 ∠AOB = 80°，求弧 AB 所对的圆周角 ∠ACB 的度数。
  4. ⊙O 的直径 AB = 10，点 C 在圆上且 ∠ACB = 90°，AB 是直径，若 AC = 6，求 BC。
  5. ⊙O 的半径为 3，圆心到直线 l 的距离为 4，判断直线 l 与 ⊙O 的位置关系；若距离改为 2 呢？
  6. 从圆外一点 P 引 ⊙O 的两条切线 PA、PB，切点为 A、B，若 ∠APB = 60°，求 ∠AOB。
  7. 半径为 6 cm、圆心角为 120° 的扇形，求其弧长和面积。
  8. 圆锥的底面半径为 3，母线长为 5，求其侧面展开扇形的圆心角。

常见误区

  • ❌ "直径是弦，所以弦也是直径" → ❌ 弦是圆上任意两点连线，只有过圆心的弦才是直径；直径是最长的弦，弦不一定是直径。
  • ❌ "等弧一定在同圆或等圆中" → ❌ 长度相等的两条弧不一定能完全重合（半径不同的圆上，同长的弧所对圆心角不同），"等弧"必须在同圆或等圆中比较。
  • ❌ "垂直于弦的直线一定平分弦" → ❌ 必须是"垂直于弦的直径（或过圆心的直线）"才平分弦。
  • ❌ "平分弦的直径垂直于弦" → ❌ 若被平分的弦是直径，这条结论不成立（两条直径互相平分，但不一定垂直）。
  • ❌ "圆周角等于圆心角" → ❌ 圆周角 = 圆心角的一半（同弧所对）。
  • ❌ "直径所对的圆周角是 60°" → ❌ 直径（半圆）所对的圆周角是 90°（直角）。
  • ❌ "d > r 时直线与圆相交" → ❌ 相离是 d > r；相交是 d < r；相切是 d = r（记牢"距离大于半径就碰不到"）。
  • ❌ "切线有无数个公共点" → ❌ 切线与圆只有一个公共点（切点）；两个公共点是割线（相交）。
  • ❌ "弧长公式里 n 的单位无所谓" → ❌ 弧长 l = nπr/180 中的 n 是角度数；用弧度制时是 l = r·θ（θ 用弧度），两者不能混用。
  • ❌ "扇形面积 S = ½lr 里 r 是底面半径" → ❌ 这里的 r 是扇形半径（在圆锥展开里是母线长），不是圆锥底面半径。

课本外 · 典故与思考

史祖冲之：把 π 算到小数点后 7 位，领先世界近千年（点击展开）

公元 5 世纪（南朝宋、齐年间），数学家祖冲之把圆周率算到了一个惊人的精度。他给出两个分数近似值：

约率：22/7 ≈ 3.142857
密率：355/113 ≈ 3.14159292…

其中 355/113 精确到小数点后第 7 位（3.1415926…）。直到 16 世纪，欧洲数学家才重新算出这个值——祖冲之之后，世界领先了差不多一千年。

他是怎么算的？史书记载他"以圆径一亿为一丈"逐位给出圆周——据研究，用的正是割圆术：不断把正多边形的边数加倍来逼近圆，可能算到二万多边形甚至更多。没有计算机，全靠手算。

一句话总结：密率 355/113 不是蒙出来的——它是"圆"这个最对称的图形，与人类耐心的一场千年博弈。
史阿基米德：用 96 边形"夹住"π（点击展开）

公元前 3 世纪，阿基米德想算 π。他没有 π 这个符号，却想到一个极其朴素又极其聪明的办法：让圆被正多边形夹住——外面套一个外切正多边形（比圆大），里面放一个内接正多边形（比圆小），圆周率就一定被这两个多边形的相关比值"夹"在中间。

他从正六边形出发，把边数一路翻倍到 96 边形，最终得出：

223/71 < π < 22/7    即  3.1408… < π < 3.1428…

这距今已经 2200 多年。他的"夹逼"思想至今仍是数学里最常用的武器之一——很多量没法直接算，就先把它夹住。

一句话总结：割圆术的灵魂不是"算得多"，而是"夹得紧"——正多边形从里外两面把圆死死抱住。
问化圆为方：一个困扰人类两千年的"不可能"（点击展开）

古希腊人提出过三个"尺规作图"难题：只用圆规和无刻度直尺，能不能——三等分任意角？把立方体的体积加倍？化圆为方（作一个和给定圆面积相等的正方形）？

"化圆为方"看起来并不难：圆的面积是 πr²，只要能造出长度为 √π 的线段就行。但两千多年里，无数人前赴后继，全部失败。

直到 1882 年，德国数学家林德曼证明：π 是超越数（它不满足任何整系数多项式方程），而尺规作图能造出的数全都满足某个整系数多项式方程。于是答案揭晓：化圆为方在数学上不可能，三大难题就此彻底落幕。

一句话总结：有些问题"看似简单却永远做不出来"——数学的进步，有时就是证明"这件事做不到"。

本章练习卷（含答案）

一、练习题（由易到难，紧扣本章知识点）

  1. 圆的定义：⊙O 的半径为 5，平面内三点 P、Q、R 满足 OP = 5、OQ = 3、OR = 7。分别判断 P、Q、R 与 ⊙O 的位置关系（圆上 / 圆内 / 圆外），并说明判断依据。
  2. 垂径定理：⊙O 的半径为 13 cm，弦 AB = 24 cm。求圆心 O 到弦 AB 的距离（弦心距），并说明为什么垂足就是弦的中点。
  3. 圆周角定理：⊙O 中，弧 AB 所对的圆心角 ∠AOB = 100°。求 (1) 弧 AB 所对的圆周角 ∠ACB 的度数；(2) 若点 D 与 C 在弧 AB 的同侧（同弧所对），∠ADB 等于多少？
  4. 直线与圆的位置关系：⊙O 的半径为 5，圆心 O 到直线 l 的距离为 d。(1) 当 d = 5 时，直线 l 与 ⊙O 的位置关系是什么？(2) 当 d = 4 时呢？此时直线被圆截得的弦长是多少？
  5. 切线：从圆外一点 P 引 ⊙O 的两条切线 PA、PB，切点分别为 A、B。若 ∠APB = 60°，求 ∠AOB（圆心角）的度数，并说明 PA 与 PB 的大小关系。
  6. 弧长、扇形与圆锥展开：圆锥的底面半径为 3，母线长为 5。求 (1) 其侧面展开扇形的圆心角 n；(2) 该扇形的弧长和侧面面积。

二、参考答案（点击展开）

查看第1题答案

答：P 在圆上（OP = r = 5），Q 在圆内（OQ = 3 < 5），R 在圆外（OR = 7 > 5）。依据：圆的集合定义——到圆心距离等于半径的点在圆上，小于半径在圆内，大于半径在圆外。

查看第2题答案

答：弦心距 d = √(r² − (a/2)²) = √(13² − 12²) = √(169 − 144) = √25 = 5 cm。步骤：过圆心 O 作弦 AB 的垂线，垂足为 E，由垂径定理知垂足平分弦，故 AE = BE = 12 cm；在直角三角形 OEA 中用勾股定理 d² + 12² = 13²，解得 d = 5 cm。

查看第3题答案

答：(1) 圆周角等于同弧所对圆心角的一半，∠ACB = ½ × 100° = 50°。(2) 同弧（或等弧）所对的圆周角相等，所以 ∠ADB = ∠ACB = 50°。

查看第4题答案

答：(1) d = 5 = r，相切——圆心到直线的距离等于半径，直线与圆有唯一公共点（切点）。(2) d = 4 < r，相交，有两个交点；弦长 a = 2√(r² − d²) = 2√(25 − 16) = 2√9 = 6。

查看第5题答案

答：由切线长定理，PA = PB；∠AOB = 120°。理由：OA ⊥ PA、OB ⊥ PB，四边形 OAPB 中 ∠OAP = ∠OBP = 90°，四内角和为 360°，故 ∠AOB = 360° − 90° − 90° − 60° = 120°。

查看第6题答案

答：(1) 侧面展开扇形半径 = 母线长 5，弧长 = 底面周长 2π × 3 = 6π；由 n/360 × 2π × 5 = 6π，得 n = 360° × 3/5 = 216°。(2) 弧长 l = 6π；侧面面积 S = ½ · l · 母线 = ½ × 6π × 5 = 15π（也可用 πrl = π × 3 × 5 = 15π）。
