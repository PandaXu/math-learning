第21章 一元二次方程

初中 / 初三 / 九年级上册

一句话总纲：一元二次方程 ax² + bx + c = 0（a≠0） 是「抛物线 y = ax² + bx + c 与 x 轴（高度为 0 的水平线）相交」这一几何事件的代数表达：它的每一个实根，都是抛物线与 x 轴交点的横坐标；判别式 Δ 则回答「有几个交点」。学完本章，你要能在心里同时"看见"两条路——代数上的配方 / 求根 / 因式分解，与几何上的抛物线开口、对称轴、交点，以及物理上的抛体落地、匀加速相遇等模型。

21.1 一元二次方程的概念

什么是"一元二次方程"

只含有一个未知数，并且未知数的最高次数是 2 的整式方程，叫做一元二次方程。把它整理后的一般形式是：

ax² + bx + c = 0     (a ≠ 0)

├ a —— 二次项系数
├ b —— 一次项系数
└ c —— 常数项
  • 一元：只有一个未知数 x（不像二元方程有 x、y 两个）。
  • 二次：未知数的最高次数是 2（来自 x² 这一项）。
  • a ≠ 0 是硬性条件：若 a = 0，方程退化为一次方程 bx + c = 0，就不叫"二次"了。
  • b、c 可以等于 0，例如 2x² = 0、3x² - 12 = 0、x² + 4x = 0 都是一元二次方程。
几何含义：一元二次方程 ax² + bx + c = 0 的每一个实数解，都对应抛物线 y = ax² + bx + c 与 x 轴（即直线 y = 0） 的一个交点的横坐标。换句话说：解方程 = 求曲线与水平线"海拔 0"相交的位置。这是继数轴之后，数与形的又一次统一——方程从"一串待解的符号"变成了"一条看得见的曲线与一条直线的位置关系"。
物理含义：竖直上抛 / 自由落体的高度公式 h(t) = -½gt² + v₀t + h₀ 就是一个关于时间 t 的一元二次式。问"物体何时落地"（h = 0）、"何时经过某个高度 h₀"（h = h₀），本质上都是解一个一元二次方程。系数 a、b、c 对应着"重力加速度的一半、初速度、初始高度"这类实实在在的物理量。

21.2 直接开平方法

适用情形：已经"平方好了"的方程

形如 x² = p 或 (x + m)² = n 的方程，可以直接"两边开平方"来解。它是一元二次方程里最朴素、最直观的一类。

x² = p   （或  (x + m)² = n）

p > 0   →  x = ±√p        （两个互为相反数的实根）
p = 0   →  x = 0          （两个相等的实根）
p < 0   →  无实数根        （实数的平方不可能为负）
  • p > 0：例如 x² = 9，开平方得 x = ±3，注意一正一负两个根都不能丢。
  • p = 0：例如 x² = 0，只有 x = 0，习惯上叫"两个相等的实根"（二重根）。
  • p < 0：例如 x² = -4，在实数范围内无解（任何实数的平方都 ≥ 0）。要等到高中引入复数才有解。

带括号的情形：(x + m)² = n 先整体开平方，再移项。

(x - 3)² = 16
x - 3 = ±4
x = 3 ± 4   →  x = 7 或 x = -1
几何含义：x² = p 就是"边长为 x 的正方形，面积等于 p"。解 x = ±√p 表示：面积为 p 的正方形，其边长是 √p；而 ± 号表示在数轴上，距离原点 √p 的两个点（+√p 与 -√p）关于原点对称。当 p < 0 时"面积为负"，这样的正方形不存在，所以无实数根——几何上一目了然。
物理含义：初速度为 0 的匀加速直线运动，位移公式 s = ½at²。已知位移 s 和加速度 a 求时间 t：t² = 2s/a，开平方得 t = ±√(2s/a)——负号对应"往回追溯的过去时刻"，通常只取正根 t > 0 作为物理上合理的时间。

21.3 配方法

思想：把"一般式"变成"能直接开平方的形式"

配方法的本质是把 ax² + bx + c = 0 化为 (x + m)² = n，再回到直接开平方。这是所有方法里最"原理化"的一种，求根公式正是由它推出来的。

四个标准步骤

  1. 化 1：二次项系数化为 1（方程两边同除以 a）。
  2. 移项：把常数项移到等号右边。
  3. 配方：两边同时加上"一次项系数一半的平方"，把左边凑成完全平方式。
  4. 开平方：用直接开平方法求解。

完整示范（解 x² + 6x + 5 = 0）：

x² + 6x + 5 = 0
x² + 6x = -5                     ← 移常数项
x² + 6x + 9 = -5 + 9             ← 加 (6/2)² = 9
(x + 3)² = 4                     ← 左边配成完全平方
x + 3 = ±2
x = -3 ± 2  →  x = -1 或 x = -5

为什么要加 9？因为 x² + 2·m·x + m² = (x + m)²。这里一次项系数是 6，即 2m = 6，m = 3，所以必须补上 m² = 3² = 9，左边才能变成完全平方。

几何含义：配方法的名字就来自几何里的"补形"。把 x² + 6x 看成"一个面积为 x² 的正方形 + 一块长为 6、宽为 x 的长条"，这块长条可以分成两个 3×x 的窄条贴在正方形两侧，还缺一个 3×3 的角；补上这个面积为 9 的角，整体就变成一个边长为 (x+3) 的完整正方形，面积 (x+3)²。这就是"配方 = 补成正方形"的字面含义，也是古人解二次方程的原始图景。
物理含义：把匀变速运动的高度式 h = -½gt² + v₀t + h₀ 配成 h = -½g(t - t顶)² + h顶 的形式后，能直接读出"顶点"：t顶 = v₀/g 是到达最高点的时刻，h顶 = h₀ + v₀²/(2g) 是最高点高度。配方法把"一团二次式"整理成"一眼看出极值"的形状。

21.4 公式法与判别式

求根公式：万能解法

对一般式 ax² + bx + c = 0（a≠0） 配方，可直接导出适用于所有一元二次方程的求根公式：

        -b ± √(b² - 4ac)
x = ─────────────────────
              2a

判别式 Δ（读作"得尔塔"）

Δ = b² - 4ac

根的情况完全由 Δ 的符号决定：

判别式根的情况与 x 轴的交点
Δ > 0两个不相等的实根两个交点
Δ = 0两个相等的实根 x = -b/(2a)一个交点（顶点恰在 x 轴上，相切）
Δ < 0无实数根无交点

公式是怎么来的（配方推导，理解即可）

ax² + bx + c = 0
→  x² + (b/a)x = -c/a
→  x² + (b/a)x + (b/2a)² = (b/2a)² - c/a
→  (x + b/2a)² = (b² - 4ac) / (4a²)
→  x + b/2a = ± √(b² - 4ac) / (2a)
→  x = [-b ± √(b² - 4ac)] / (2a)
几何含义：判别式 Δ 就是抛物线 y = ax² + bx + c 与 x 轴交点个数的判官：Δ > 0 时曲线"穿过"x 轴两次；Δ = 0 时曲线顶点恰好落在 x 轴上（相切，只有一个切点）；Δ < 0 时整条抛物线悬在 x 轴上方或下方，永远碰不到 x 轴。求根公式里 -b/(2a) 是对称轴，±√Δ/(2a) 表示两个根关于对称轴左右对称分布——两个交点关于对称轴镜像。
物理含义：竖直上抛中，问"物体能否到达高度 H"，等价于问方程 -½gt² + v₀t + (h₀ - H) = 0 的判别式：Δ ≥ 0 才能到达该高度（Δ = 0 时刚好在最高点擦过），Δ < 0 则初速度不够，永远达不到。判别式把"能不能、有几个时刻"这样的物理问题一次判断清楚。

21.5 因式分解法

原理：零乘任何数得零

若两个因式的乘积为 0，则至少有一个因式为 0。把方程左边分解成两个一次因式之积，就能"一拆二"分别求解：

a(x - p)(x - q) = 0
⟺  x - p = 0  或  x - q = 0
⟺  x = p  或  x = q

常用分解手段

  • 提公因式：x² - 4x = 0 → x(x - 4) = 0 → x = 0 或 x = 4
  • 平方差公式：a² - b² = (a + b)(a - b)，如 x² - 9 = 0 → (x + 3)(x - 3) = 0
  • 完全平方公式：a² ± 2ab + b² = (a ± b)²，如 x² - 6x + 9 = 0 → (x - 3)² = 0 → x = 3（重根）
  • 十字相乘：对 x² + (p+q)x + pq = (x+p)(x+q) 反用。

示范（十字相乘解 x² - 5x + 6 = 0）：

x² - 5x + 6 = 0
(x - 2)(x - 3) = 0
x - 2 = 0 或 x - 3 = 0
x = 2 或 x = 3
几何含义：抛物线 y = (x - 2)(x - 3) 可以看成两个一次函数 y₁ = x - 2、y₂ = x - 3 的乘积。当 y = 0（落在 x 轴上）时，只要其中一个因子为 0 即可——所以两个交点分别位于 x = 2 和 x = 3，恰好是这两个一次函数各自的零点。因式分解把一个"二次曲线与 x 轴相交"的问题，拆成了两个"一次直线过零点"的问题。
物理含义：当一个物理过程可写成"两个独立条件相乘 = 0"时，因式分解法能一次性找出所有满足条件的时刻。例如"位移为 0"t(v₀ - ½gt) = 0：t = 0 是出发时刻，t = 2v₀/g 是重新落回原高度的时刻——两个根对应两个真实发生的物理瞬间。

21.6 根与系数的关系（韦达定理）

定理内容

若 x₁、x₂ 是一元二次方程 ax² + bx + c = 0（a≠0） 的两个根，那么它们与系数之间有如下关系：

x₁ + x₂ = -b / a          （两根之和）
x₁ · x₂ =  c / a          （两根之积）

特别地，当 a = 1（即 x² + px + q = 0）时，简化为：x₁ + x₂ = -p，x₁x₂ = q。

两个高频推论（务必背熟）

x₁² + x₂² = (x₁ + x₂)² - 2x₁x₂
(x₁ - x₂)² = (x₁ + x₂)² - 4x₁x₂

这些式子让我们不解方程就能求出与根有关的对称式的值。

几何含义：两根之和 x₁ + x₂ 的几何意义是"两个交点横坐标之和"。因为两个根关于对称轴 x = -b/(2a) 左右对称，所以 x₁ + x₂ = 2 × (-b/(2a)) = -b/a——即两根之和等于对称轴横坐标的 2 倍。两根之积 x₁x₂ = c/a 则与抛物线在 y 轴上的截距 c 及开口大小 a 有关。韦达定理在几何上就是"对称轴把两个交点等分"这件事的代数化。
物理含义：抛体运动中，物体两次经过同一高度 H 的时刻 t₁、t₂ 满足 t₁ + t₂ = 2t顶（其中 t顶 是到达最高点的时刻），即"两时刻之和等于顶点时刻的 2 倍"——这正是韦达定理两根之和的物理版本。用 t₁ + t₂ = 2v₀/g 无需解方程就能求出抛体在空中停留的总时间。

21.7 一元二次方程的应用

一元二次方程是刻画平方关系的模型，凡是"一个量是另一个量的二次函数"的场景都能用它列方程求解。解应用题的通用流程：审题设未知数 → 找等量关系列方程 → 解方程 → 检验（舍去不合题意的根，如负时间、负长度）→ 作答。

（一）平均增长率 / 降低率问题

若基数为 a，平均增长率为 x，经过两期后的量为 b，则：

a(1 + x)² = b      （增长）
a(1 - x)² = b      （降低）

例：某厂产量 2 万吨，两年后达到 2.42 万吨，求平均年增长率。设增长率为 x，则 2(1 + x)² = 2.42，解得 1 + x = 1.1，x = 10%（舍去负根）。

几何含义："每期按比例缩放再缩放"相当于在数轴上连续做两次等比拉伸，(1+x)² 就是连续两次乘同一个倍率后总面积/总量放大到原来的平方倍——面积类问题（长宽各增 x）天然是平方关系。
物理含义：连续两次同比例的变化就是"指数/几何增长"的离散版本，与利息复利、细菌翻倍、放射性衰变同源；平方项代表"两期复合"的效果。

（二）几何面积问题

靠墙围篱笆、相框加宽、道路占地等，面积常表示为一边长的二次式，令其等于给定面积即得一元二次方程。

例：用 40m 长的篱笆靠墙围一个矩形（只围三边），
面积为 200m²。设垂直于墙的边为 x，则平行于墙的边为 40 - 2x：
x(40 - 2x) = 200
2x² - 40x + 200 = 0
x² - 20x + 100 = 0  →  (x - 10)² = 0  →  x = 10
几何含义：面积问题的根就是"使矩形面积达到目标值的边长"，解方程 = 求曲线 S = x(40 - 2x)（一条开口向下的抛物线，表示面积随边长的变化）与水平线 S = 200 的交点。

（三）抛体运动问题（物理）

竖直上抛的高度：h = h₀ + v₀t - ½gt²。问"何时落地"即令 h = 0 解关于 t 的一元二次方程；问"何时到达某高度 H"即令 h = H。

例：以 20 m/s 竖直上抛（g = 10 m/s²，从地面出发）：
h = 20t - 5t²
问何时回到地面：20t - 5t² = 0
→ 5t(4 - t) = 0  →  t = 0（出发）或 t = 4（回到地面）
几何含义：h(t) 的图像是一条开口向下的抛物线，解方程 h = 0 就是求它与 t 轴（高度为 0）的交点横坐标；顶点是最高点，对称轴时刻 t = v₀/g 恰是两根（出发、落地时刻）的中点。

（四）销售利润问题

利润 = (售价 - 成本) × 销量。设每件涨价 x 元，销量按线性规律下降，利润就是 x 的二次式，令利润等于目标值得到一元二次方程。

例：进价 30 元、售价 40 元、每天卖 60 件；每涨 1 元少卖 2 件。
设涨价 x 元，利润 y = (40 + x - 30)(60 - 2x) = (10 + x)(60 - 2x)。
问利润何时为 800 元：(10 + x)(60 - 2x) = 800，展开解得 x = 10 或 x = -10（舍）。
几何含义：利润是涨价幅度 x 的二次函数，图像是开口向下的抛物线；"利润 = 800"是它与水平线 y = 800 的两个交点，顶点对应最大利润。
物理含义：利润抛物线与抛体轨迹同形——开口向下、有最高点、两边对称，本质上都是"二次量 = 常量"的结构：一个量上升、另一个量下降，乘积在中间取极值。

典型例题（自测）

先独立做，再看思路

  1. 判断下列哪些是一元二次方程，并写出 a、b、c：3x² - 2x - 1 = 0、x² = 0、x + 1/x = 2、(x - 1)(x + 2) = 0。
  2. 用直接开平方法解：(x - 1)² = 25、2x² - 8 = 0。
  3. 用配方法解：x² - 4x - 5 = 0、x² + x - 1 = 0。
  4. 用公式法解：2x² + 3x - 2 = 0，并求出 Δ 的值。
  5. 用因式分解法解：x² - 7x + 12 = 0、x(x - 3) = 10。
  6. 已知方程 x² - 5x + k = 0 的一个根是 2，求另一个根及 k 的值。
  7. 已知 x₁、x₂ 是 x² - 3x - 1 = 0 的两根，不解方程求 x₁² + x₂² 与 (x₁ - x₂)² 的值。
  8. 某商品连续两次降价，由 100 元降到 81 元，求平均每次降价的百分率。

常见误区

⚠ 高频易错点

  • ❌ "x² = 9 的解是 x = 3" → ❌ 少了 x = -3。开平方要 ±，丢掉负根是本章第一大错。
  • ❌ "x² = -9 有解 x = ±3" → ❌ 实数的平方恒非负，x² = -9 在实数范围内无解。
  • ❌ "配方法加的是 (b/2)²" 记成加 b² 或 b/2 → ❌ 要加的是一次项系数一半的平方：x² + 6x 加 3² = 9，不是加 36。
  • ❌ "用公式时把 a、b、c 抄反" → ❌ 必须先把方程整理成 ax² + bx + c = 0 的标准形，再对号入座；-b 的负号不能漏。
  • ❌ "Δ > 0 有两个根，Δ = 0 只有一个根" → ❌ 严格说 Δ = 0 是两个相等的实根（二重根），不是"只有一个"。
  • ❌ "因式分解后 (x-2)(x-3)=0 得 x=2 且 x=3" → ❌ 是 x=2 或 x=3，两个根分别成立，不能同时取。
  • ❌ "韦达定理 x₁+x₂ = b/a" → ❌ 是 -b/a，负号最容易被遗忘。
  • ❌ "应用题解出负根直接写进答案" → ❌ 负数的时间、长度、百分率下降率等不合题意，要检验舍去。
  • ❌ "忘了 a ≠ 0 的条件" → ❌ 若 a = 0 则不是二次方程，讨论根时先确认 a 是否为零。

本章练习卷（含答案）

一、练习题

  1. 判断下列哪些是一元二次方程，并把属于一元二次方程的整理成一般式 ax² + bx + c = 0，指出 a、b、c：① 3x² - 2x - 1 = 0；② x² = 0；③ 2x - 1 = 0；④ (x - 1)(x + 2) = 0。
  2. 用直接开平方法解方程 x² = 25 和 (x - 3)² = 16。结合「正方形面积 = 边长²」的几何含义，说明为什么 x² = 25 有两个根，而 x² = -4 在实数范围内无解。
  3. 用配方法解方程 x² + 8x - 9 = 0，并解释配方时「为什么两边要同时加上 16」。
  4. 用公式法解方程 2x² - 5x + 2 = 0；再不解方程，用判别式 Δ 判断 x² - 4x + 5 = 0 对应的抛物线与 x 轴交点的个数，并说明理由。
  5. 用因式分解法解方程 x² - 7x + 12 = 0，并用韦达定理（两根之和、两根之积）验证所得两个根与系数的关系。
  6. 一小球以 20 m/s 竖直上抛（g = 10 m/s²），高度 h = 20t - 5t²。求：小球何时回到地面（h = 0）？何时到达最高点？最高点的高度是多少？

二、参考答案（点击展开）

查看第1题答案

①②④ 是一元二次方程，③ 是一次方程。① 已是一般式：a = 3，b = -2，c = -1；② x² = 0：a = 1，b = 0，c = 0；④ 展开得 x² + x - 2 = 0：a = 1，b = 1，c = -2。

查看第2题答案

x² = 25 → x = ±5。几何上，面积为 25 的正方形边长为 5，但数轴上「距原点 5」的点有 +5 和 -5 两个，二者关于原点对称，所以有两个根。(x - 3)² = 16 → x - 3 = ±4 → x = 7 或 x = -1。而 x² = -4 无实数根：任何实数的平方都 ≥ 0，「面积为负」的正方形不存在。

查看第3题答案

x² + 8x - 9 = 0 → x² + 8x = 9 → x² + 8x + 16 = 9 + 16 → (x + 4)² = 25 → x + 4 = ±5 → x = 1 或 x = -9。加 16 是因为一次项系数 8 的一半是 4，4² = 16，补上它左边才能凑成完全平方式 (x + 4)²（相当于把缺角的矩形补成完整正方形）。

查看第4题答案

2x² - 5x + 2 = 0：a = 2，b = -5，c = 2，Δ = b² - 4ac = 25 - 16 = 9 > 0，x = [-(-5) ± √9]/(2×2) = (5 ± 3)/4，故 x = 2 或 x = 1/2。对于 x² - 4x + 5 = 0：Δ = 16 - 20 = -4 < 0，无实数根；抛物线 y = x² - 4x + 5 开口向上且顶点在 x 轴上方，与 x 轴没有交点（0 个交点）。

查看第5题答案

x² - 7x + 12 = 0 → (x - 3)(x - 4) = 0 → x = 3 或 x = 4。验证韦达定理：x₁ + x₂ = 3 + 4 = 7 = -(-7)/1，x₁·x₂ = 3 × 4 = 12 = 12/1，与「两根之和 = -b/a、两根之积 = c/a」完全一致。

查看第6题答案

回到地面即 h = 0：20t - 5t² = 0 → 5t(4 - t) = 0 → t = 0（出发时刻）或 t = 4 s（回到地面）。到达最高点时刻在对称轴（两根 0 与 4 的中点）处：t = -b/(2a) = 20/(2×5) = 2 s；最高点高度 h(2) = 20×2 - 5×2² = 40 - 20 = 20 m。
