第25章 概率初步

初中 / 初三 / 九年级上册

一句话总纲：概率 = 「在所有等可能结果中，事件所占的那一份」。学完本章，你要能在心里"看见"一个转盘或一张方格表——随机事件是"结果不确定"的区域，概率是这个区域占整体的大小，列举法是把整体一格一格数清楚，频率则是用大量试验去"量"出这个大小。

25.1 随机事件

三类事件：必然、不可能、随机

在一定的条件下，事件按照"是否一定发生"分成三类：

事件类型定义例子（掷一枚骰子）
必然事件一定发生"点数 < 7" 一定发生
不可能事件一定不发生"点数为 7" 一定不发生
随机事件（不确定事件）可能发生，也可能不发生"点数为偶数" 可能发生也可能不发生
  • 确定性事件 = 必然事件 + 不可能事件（结果完全确定）。
  • 随机事件：在相同条件下重复试验，每次结果事先无法确定，但它发生的"可能性大小"是有规律的——这正是本章要研究的对象。
几何含义：把所有可能的结果画成一个整体区域（叫"样本空间"），那么必然事件 = 整个区域，不可能事件 = 空集（什么也不占），随机事件 = 整体区域里的一个非空、非全体的子区域。掷骰子就像把一个大圆盘切成 6 等份，"点数为偶数"占了其中 3 份。
物理含义：现实中大量现象的结果受众多微小因素影响而无法预先确定：掷硬币、抽签、明天的天气、一次测量的误差、一粒种子的发芽与否。单个结果不确定，但大量重复后却呈现出稳定的比例——这是"随机"背后隐藏的确定规律。

25.2 概率

概率的定义：可能性大小的度量

概率：刻画随机事件发生可能性大小的数值，事件 A 的概率记作 P(A)（P 是英文 probability 的首字母）。

一般地，如果一次试验有 n 种等可能的结果，事件 A 包含其中的 m 种，那么：

        m   事件A包含的结果数
P(A) = ─── = ─────────────────
        n     所有等可能结果数

概率的取值范围：

0 ≤ P(A) ≤ 1

P(不可能事件) = 0      P(必然事件) = 1
随机事件：0 < P(A) < 1
  • P(A) 越接近 1，事件越可能发生；越接近 0，越不可能发生。
  • 概率是 0 到 1 之间（含端点）的实数，它是对"可能性"的量化，不是"事后"的必然结论。
几何含义：把样本空间看作一块总大小为 1 的"地"（一条线段、一个圆盘或一张面积图），每个基本结果等可能 = 每份大小相等。于是 P(A) = A 占的份数 ÷ 总份数 = A 区域的长度/面积 ÷ 总长度/面积。掷骰子：总区域 6 等份，掷出偶数占 3 份，P = 3/6 = 1/2。这就是后面"几何概型"的雏形——概率就是"区域大小的比值"。
物理含义：概率是大量随机现象背后的统计规律。一枚硬币"正面"概率为 1/2，不是说抛两次必有一次正面，而是抛成千上万次后正面约占一半。概率把"不确定的单次结果"翻译成"确定的长期比例"，是保险、天气预报、质量抽检、随机抽样共同的数学基础。

从 0 到 1 的"可能性标尺"

0 ──────────── 0.5 ──────────── 1
不可能   可能性很小   一半一半   可能性很大   必然
(0)                     (1/2)             (1)

例：明天太阳从东边升起 → P = 1；明天太阳从西边升起 → P = 0；明天下雨 → 0 < P < 1。

25.3 列举法求概率

核心思想：把所有等可能结果"不重不漏"地列出来

求概率的关键是准确数出 n（总数）和 m（有利数）。当试验只涉及一步，或步骤较少时，直接列举即可；当涉及两步或三步时，用列表法或树状图法保证不重不漏。

几何含义：列举 = 把"总区域"切成等大的格子，一格一格地数。列表法是画一张方格表（横是第一个量、纵是第二个量），每个格子对应一个等可能结果；树状图是把每步的分支画成分叉，叶子就是最终结果。格子和叶子都必须"等大小（等可能）"，数出来的 m/n 才是概率。
物理含义：列举就是穷尽实际可能发生的情况：同时掷两枚骰子，物理上两枚骰子各自独立、互不影响，所以 6×6 = 36 种组合每种的"出现机会"相同；抽签时先后顺序不影响公平性。列举法保证了我们对真实世界所有可能情形的完整盘点。

方法一：直接列举（一步试验）

例：掷一枚质地均匀的骰子，求"掷出偶数"的概率。

  • 所有等可能结果 n = 6：1, 2, 3, 4, 5, 6。
  • 事件"偶数"包含 m = 3：2, 4, 6。
  • P(偶数) = 3/6 = 1/2。

方法二：列表法（两步试验）

例：同时掷两枚质地均匀的骰子，求"点数之和为 7"的概率。

用表格列出第一枚的点数（行）与第二枚的点数（列），共 6×6 = 36 个格子，每个格子等可能：

      第二枚 →  1    2    3    4    5    6
第一枚 ↓
  1           (1,1)(1,2)(1,3)(1,4)(1,5)(1,6)
  2           (2,1)(2,2)(2,3)(2,4)(2,5)(2,6)
  3           (3,1)(3,2)(3,3)(3,4)(3,5)(3,6)
  4           (4,1)(4,2)(4,3)(4,4)(4,5)(4,6)
  5           (5,1)(5,2)(5,3)(5,4)(5,5)(5,6)
  6           (6,1)(6,2)(6,3)(6,4)(6,5)(6,6)

和为 7 的格子（沿一条对角线）：(1,6)、(2,5)、(3,4)、(4,3)、(5,2)、(6,1)，共 6 种。

P(和为7) = 6/36 = 1/6
注意：(1,6) 和 (6,1) 是两个不同结果，都要算。骰子有"先后"或"左右"之分，36 个格子才是等可能的，不能把有序对压成无序对（否则就不等可能了）。

方法三：树状图法（两步或三步试验）

例：抛三枚硬币，求"恰好两枚正面"的概率。

每枚硬币有正(H)、反(T)两种等可能结果，三步各 2 个分支，共 2×2×2 = 8 条路径：

第1枚    第2枚    第3枚    结果
        ┌─ H ──── HHH
        ├─ T ──── HHT
   H ───┤
        ├─ H ──── HTH
        └─ T ──── HTT
   ─────┤
        ┌─ H ──── THH
        ├─ T ──── THT
   T ───┤
        ├─ H ──── TTH
        └─ T ──── TTT

8 种结果等可能。"恰好两枚正面"有 HHT、HTH、THH 共 3 种。

P(恰好两正面) = 3/8

列举法的适用条件与步骤

  1. 等可能：所有结果出现的机会必须相同（质地均匀、随机抽取、机会均等）。
  2. 不重不漏：列表按行列、树状图按分支，把全部结果完整列出。
  3. 计数：数出总结果 n 与有利结果 m。
  4. 代入：P(A) = m/n，并化成最简分数。

列表法 vs 树状图：列表法适合两步且每步结果较多（如两个骰子）；树状图适合两步或三步以上、每步结果较少的试验（如多次抛硬币、抽卡），路径一目了然。

25.4 频率估计概率

问题：很多事件的概率无法"数出来"

像"种子发芽""命中目标""次品率"这类事件，结果不是等可能的，无法用 m/n 直接算。这时我们反过来：做大量重复试验，用频率去估计概率。

频率：在 n 次重复试验中，事件 A 发生了 m 次，则

                m   事件发生的次数
频率 f(A) = ─── = ─────────────────
                n     试验总次数

核心规律：频率稳定于概率

大量重复试验中，随机事件的频率会稳定在它的概率附近，试验次数越多，越接近。历史上抛硬币的著名记录：

试验者抛掷次数 n正面次数 m正面频率 m/n
蒲丰404020480.5069
费勒1000049790.4979
皮尔逊24000120120.5005

正面频率始终围绕 0.5 上下波动，且次数越多越贴近 0.5——这就用试验"量"出了概率。

几何含义：把每次试验后的频率画成点、连成折线，你会看到一条围绕水平直线（概率值）上下摆动的折线，试验越多，摆幅越小、越贴近这条水平线。这条水平线 P 就是折线的"收敛目标"——频率是随机行走的曲线，概率是它渐近趋近的直线。
物理含义：这是"大数定律"的直观表现：个别随机现象无规律，大量重复却呈现稳定的统计规律。掷一次硬币无法预测，掷一万次正面比例几乎必在 0.5 附近。工程上用频率估计概率：灯泡寿命合格率、零件次品率、种子发芽率、运动员命中率，都靠大量实测数据"逼近"真实的概率。

频率与概率的区别与联系

频率概率
本质一次试验的实际统计结果事件本身固有的可能性
取值随试验次数而变，有波动固定的常数（客观规律）
范围0 ≤ 频率 ≤ 10 ≤ 概率 ≤ 1
关系试验次数很大时，频率稳定于概率，可用频率估计概率

注意：频率是"测得值"（会波动），概率是"真值"（固定不变）；用频率估计概率永远是近似，不是精确相等。

本章 · 几何与物理含义总结

概念几何含义物理/现实含义
必然事件 / 不可能事件整个区域 / 空集一定发生 / 一定不发生的事
随机事件样本空间里的非空非全体子区域结果不确定、受多因素影响的现象
概率 P(A) = m/n事件区域大小 ÷ 总区域大小（等份格子的占比）大量重复后事件的稳定比例（长期规律）
0 ≤ P(A) ≤ 1从 0（不占）到 1（占满）的"标尺"可能性从"不可能"到"必然"的刻度
列举法（列表/树状图）把总区域切成等大格子/分叉，一格一格数穷尽真实世界所有等可能情形
频率 = m/n绕水平直线摆动的折线每次实测得到的统计比例（会波动）
频率估计概率折线渐近趋近那条水平直线大数定律：大量重复呈现稳定规律

典型例题（自测）

  1. 指出下列事件是必然事件、不可能事件还是随机事件：① 明天会下雨；② 太阳从东边升起；③ 掷一枚骰子掷出 7 点；④ 抽奖抽中一等奖。
  2. 一个袋中有 3 个红球、2 个白球，大小质地相同。随机摸出 1 个球，求 P(红球)、P(白球)。
  3. 同时掷两枚质地均匀的骰子，求：① 点数之和为 8 的概率；② 点数相同的概率。
  4. 抛三枚硬币，用树状图求"至少两枚正面"的概率。
  5. 某厂抽检 1000 件产品，其中 12 件次品。估计该厂产品的次品率，并说明这是"概率"还是"频率"。
  6. 一枚硬币抛 100 次，正面出现 45 次。能否说"正面概率是 0.45"？为什么？

常见误区

  • ❌ "概率很大就一定会发生，概率很小就绝不会发生" → ❌ 概率大只是可能性大，不是必然；P = 0.99 的事件也可能这次不发生。
  • ❌ "抛两次硬币必有一次正面" → ❌ 概率 1/2 是长期比例，不是短期平均分配；两次都反面的概率是 1/4，完全可能。
  • ❌ "掷两枚骰子，'和为 7'和'和为 12'一样可能" → ❌ 和为 7 有 6 种组合、和为 12 只有 (6,6) 1 种，概率分别是 1/6 和 1/36，不能只看"和"这个结果就以为等可能。
  • ❌ "把 (1,6) 和 (6,1) 看成同一个结果" → ❌ 两枚骰子有先后之分，(1,6) 与 (6,1) 是两个不同的等可能结果，合并后就不等可能了，m/n 公式失效。
  • ❌ "频率 = 概率" → ❌ 频率是实测值、会随试验次数波动；概率是固定的真值。只能说"频率估计概率"，次数越多越接近，但不相等。
  • ❌ "P(A) 可以为负数或大于 1" → ❌ 任何事件的概率都在 0 ≤ P(A) ≤ 1 之间。
  • ❌ "概率为 0 的事件一定不会发生" → ❌ 在"有限等可能"模型里 P = 0 等价于不可能事件，但更一般地说，概率为 0 只是"可能性无限小"，未必绝对不发生（超出本章范围，先记住：本章语境下 0 对应不可能事件）。

课本外 · 典故与思考

史概率论诞生于两封信：帕斯卡与费马的"赌金分配"（点击展开）

1654 年，法国数学家帕斯卡收到赌友德·梅雷带来的一道老难题：

两个人赌掷骰子，谁先赢满 6 局谁拿走全部赌金。比赛因故中断时，甲已赢 5 局、乙已赢 3 局，赌金该怎么分才公平？

帕斯卡一时解不出，就写信给另一位数学家费马。两人在 1654 年夏天来回通信，用不同的方法（帕斯卡用递推，费马用列举剩余局数）得出了同一个答案：甲拿 7/8，乙拿 1/8——因为若把比赛继续下去，乙只有"连赢 3 局"这一种赢法，概率是 (1/2)³ = 1/8。

他们把"赢面"从凭感觉争论，变成了可以计算的数。后世公认：概率论就从这几封信诞生。

一句话总结：今天写概率题的你，和 1654 年通信的两位大数学家，算的是同一件事——把"运气"变成数学。
思买彩票为什么"长期必亏"？算一算期望就懂了（点击展开）

把"中奖概率 × 奖金"全部加起来，得到的数叫期望值——它回答"买一次平均能拿回多少"。如果期望值小于票价，长期买就必亏。

期望值 = Σ（中奖概率 × 中奖金额）
       < 票价  ⇒  长期平均必亏

以常见的双色球为例：一等奖（约 500 万元）的概率大约是 1/1772 万，把所有奖级的期望奖金全加起来，大约只有票价的一半左右。也就是说，每买 2 元的票，平均只能拿回约 1 元——剩下的一半用于公益和奖池。

这不是说"你一定会亏"——确实有人中大奖，但那是概率小、波动大。概率论给出的诚实答案是：平均下来亏，是数学上的必然，与运气无关。

一句话总结：彩票是"小概率、大奖励"的游戏——期望值算下来长期为负，这就是概率论给出的答案。

本章练习卷（含答案）

一、练习题

  1. （事件类型）判断下列事件是必然事件、不可能事件还是随机事件：① 掷一枚质地均匀的骰子，点数大于 0；② 掷一枚质地均匀的骰子，点数为 8；③ 明天本市会下雨。
  2. （直接列举）一个袋中装有 3 个红球、2 个白球，它们除颜色外大小、质地完全相同。随机摸出 1 个球，求 P(摸到红球) 与 P(摸到白球)。
  3. （一步概率）掷一枚质地均匀的骰子，求：① P(点数为质数)；② P(点数大于 4)。
  4. （列表法）同时掷两枚质地均匀的骰子，用列表法求"点数之和为 9"的概率。
  5. （树状图）抛三枚硬币，用树状图求"至少两枚正面朝上"的概率。
  6. （频率估计概率）某工厂抽检 2000 件产品，发现其中 26 件是次品。① 估计该厂产品的次品率；② 说明这个次品率是"概率"还是"频率"，为什么用它来估计概率。

二、参考答案（点击展开）

查看第1题答案

① 必然事件（骰子点数只有 1～6，一定大于 0，对应样本空间的整个区域）；② 不可能事件（点数不可能为 8，对应空集）；③ 随机事件（可能发生也可能不发生，是样本空间里一个非空、非全体的子区域）。

查看第2题答案

共有 3 + 2 = 5 个球，每种结果等可能，n = 5。P(摸到红球) = 3/5；P(摸到白球) = 2/5。两者之和 = 1，红球占的区域是总区域的 3/5。

查看第3题答案

总结果 n = 6（1,2,3,4,5,6）。① 质数有 2、3、5，共 m = 3 种，P(点数为质数) = 3/6 = 1/2；② 点数大于 4 的有 5、6，共 m = 2 种，P(点数大于 4) = 2/6 = 1/3。

查看第4题答案

两枚骰子共 6×6 = 36 个等可能格子（n = 36）。"点数之和为 9"的格子有 (3,6)、(4,5)、(5,4)、(6,3)，共 m = 4 种（注意 (3,6) 与 (6,3) 是两个不同结果）。P(和为 9) = 4/36 = 1/9。

查看第5题答案

三枚硬币共 2×2×2 = 8 条等可能路径。"至少两枚正面" = 恰好两枚正面（HHT、HTH、THH，3 种）+ 恰好三枚正面（HHH，1 种），共 m = 4 种。P(至少两正面) = 4/8 = 1/2。

查看第6题答案

① 次品率 = 26/2000 = 0.013 = 1.3%。② 这是"频率"（一次实测得到的统计比例，会随抽样波动），不是概率；因为产品是否次品并非等可能，无法用 m/n 直接算概率，所以用大量试验测得的频率去估计概率——试验次数越多，频率越接近真实的概率（大数定律）。
