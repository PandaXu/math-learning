第23章 旋转

初中 / 初三 / 九年级上册

一句话总纲：旋转 = 「绕一个固定点转动一个角度」，是继平移、轴对称之后的第三种全等变换；而中心对称就是「恰好转 180°」的旋转，中心对称图形就是「绕某点转 180° 还能与自身重合」的图形。学完本章，你要能在心里"看见"图形绕点转动，并把每次转动还原成"转轴、方向、角度"三个要素。

23.1 旋转

旋转的定义

在平面内，把一个平面图形绕着平面内某一点 O 转动一个角度，叫做图形的旋转（rotation）。点 O 叫做旋转中心，转动的角叫做旋转角。如果图形上的点 P 经过旋转变为点 P′，那么 P 与 P′ 叫做这个旋转的对应点。

旋转与平移、轴对称并列，是初中阶段必须掌握的三大全等变换（刚体变换）之一。

旋转的三要素

要完整描述一次旋转，必须同时说清三件事，缺一不可：

要素含义通俗说法
旋转中心 O旋转时固定不动的那个点「绕谁转」
旋转方向顺时针 或 逆时针「朝哪转」
旋转角 α转过的角度大小（通常 0° < α ≤ 360°）「转多少」

同一个图形，绕不同的中心、朝不同的方向、转不同的角度，得到的结果完全不同——这就是"三要素"的意义。

几何含义：旋转是平面到自身的一一映射（保距变换 / 等距变换）。它保持任意两点间的距离不变、任意两条线段所成的夹角不变，因此图形的形状与大小都不变，只有位置和方向发生改变。
物理含义：旋转对应刚体绕定点（定轴）的转动——风车叶片绕轴心转、钟表指针绕表盘中心转、方向盘绕中心转、齿轮与螺旋桨的转动。转过的角度就是"角位移"，转动的快慢就是"角速度" ω。因为旋转保距保形，刚体在转动中不会变形。

旋转的性质

  1. 对应点到旋转中心的距离相等：OP = OP′，OQ = OQ′……（所有对应点都在"以 O 为圆心"的同一个圆周上）。
  2. 对应点与旋转中心所连线段的夹角等于旋转角：∠POP′ = ∠QOQ′ = α。
  3. 旋转前、后的图形全等（形状、大小都不变）。
旋转是等距变换：对任意两点 A、B，
旋转后得到 A′、B′，必有  A′B′ = AB（距离不变）。

一句话记牢：旋转后，图形"换了个姿势，但形状大小一模一样"，每个点都绕中心走了同样大小的角、保持了与中心同样的距离。

旋转作图

抓住性质 1、2 两点：距离相等 + 夹角等于旋转角。

  1. 定中心、定方向、定角度 α；
  2. 把图形上的关键点（顶点等）与旋转中心连线；
  3. 将每条连线绕中心、按指定方向转过角度 α，在终点取对应点（保持到中心的距离不变）；
  4. 顺次连接对应点，得到旋转后的图形。

23.2 中心对称

定义

把一个图形绕着某一点旋转 180°，如果它能够与另一个图形重合，那么就说这两个图形关于这个点对称，或中心对称（central symmetry），这个点叫做对称中心（简称中心）。这两个图形在旋转后能重合的对应点叫做关于中心的对称点。

本质：中心对称就是"旋转角恰好等于 180°"的特殊旋转。它完全继承旋转的三要素与全部性质，只是方向固定为"转半圈"。

几何含义：若 A 与 A′ 关于点 O 中心对称，则 O 必是线段 AA′ 的中点——点 O 把每一对对称点"对折"到彼此的位置上（绕 O 转半圈，两点互换位置）。
物理含义：旋转 180° 就是"掉头 / 反向"——电动机轴转半圈、钟表指针从 12 点转到 6 点（方向完全相反）。对称中心 O 就像杠杆的支点：两侧等距的两点关于支点处于对称（平衡）的位置。

性质

  1. 对称点所连线段都经过对称中心，而且被对称中心平分：若 A 与 A′ 关于 O 对称，则 A、O、A′ 三点共线，且 OA = OA′。
  2. 关于中心对称的两个图形是全等图形。
中心对称（旋转 180°）的两条核心性质：
 ① 对称点连线都过对称中心 O，且被 O 平分（O 是中点）；
 ② 两个图形全等。

中心对称的作图

已知：点 A 与对称中心 O。
求作：点 A 关于 O 的对称点 A′。
作法：
  1. 连接 AO；
  2. 延长 AO 至 A′，使 OA′ = OA；
  3. 点 A′ 即为所求。

一句话：找对称点 = 连点 → 延长 → 取等长。把一个图形各关键点的对称点都作出来，再连起来，就得到它关于 O 中心对称的图形。

中心对称与旋转的关系

中心对称是旋转角为 180° 的旋转，因此它继承旋转的全部性质；反过来，一次旋转角恰为 180° 的旋转，就是中心对称。可以说：中心对称 ⊂ 旋转（中心对称是旋转的特殊情形）。

23.3 中心对称图形

定义

把一个图形绕着某一点旋转 180°，如果旋转后的图形能够与原来的图形重合，那么这个图形叫做中心对称图形（centrally symmetric figure），这个点就是它的对称中心。

一句话：中心对称图形 = "自己绕中心转 180° 后，还能和自己完全重合"的图形。

几何含义：图形上任意一点绕中心转 180° 后仍在图形上——图形关于中心"半周自洽"。即对图形内任一点 A，它的中心对称点 A′ 也一定在图形内，且二者被对称中心平分。
物理含义：物体绕中心转半圈后外观不变，体现"反向对称 / 均匀平衡"——如两叶螺旋桨关于轴心、车轮关于圆心、齿轮关于中心。这种对称性让转动更平稳、受力更均衡，是很多机械零件设计成中心对称图形的原因。

常见中心对称图形

图形对称中心
线段线段的中点
平行四边形两条对角线的交点
矩形两条对角线的交点
菱形两条对角线的交点
正方形两条对角线的交点
圆圆心
正偶数边形（正六边形、正八边形……）图形的中心

注意反例：正三角形（等边三角形）绕中心转 180° 后不能与自身重合，所以正三角形不是中心对称图形（它是轴对称图形）。一般地，正奇数边形都不是中心对称图形。

中心对称图形 vs 中心对称（两个图形的对称）

中心对称中心对称图形
对象两个图形之间的关系一个图形自身的性质
描述甲绕 O 转 180° 与乙重合它绕 O 转 180° 与自身重合
例子△ABC 与 △A′B′C′ 关于点 O 对称平行四边形、圆、线段

联系：把中心对称的两个图形看成一个整体，这个整体就是一个中心对称图形；反之，把中心对称图形沿对称中心"一分为二"，这两部分就关于对称中心对称。

23.4 中心对称与轴对称的区别与联系

对比表

对比项轴对称中心对称
运动方式沿一条直线（对称轴）翻折 180°绕一个点（对称中心）旋转 180°
对称元素一条直线（轴）一个点（中心）
对应点连线被对称轴垂直平分经过对称中心且被对称中心平分
图形是否全等是是

联系

  • 两者都是全等变换，变换前后形状、大小都不变。
  • 有些图形既有轴对称又有中心对称：线段、圆、正方形、正偶数边形。
  • 有些图形只有中心对称、没有轴对称：一般的平行四边形。
  • 有些图形只有轴对称、没有中心对称：等腰三角形、正三角形。

三大全等变换一览

变换几何方式物理对应
平移沿某方向整体移动平动（直线运动）
轴对称沿直线翻折镜像 / 反射
旋转（含中心对称）绕点转动（中心对称 = 转 180°）转动（旋转运动）
几何含义：平移、轴对称、旋转都是刚体变换（等距变换）——保距、保角、保形状大小；中心对称是旋转角为 180° 的特例。
物理含义：平移对应平动，轴对称对应反射（镜像），旋转对应转动；中心对称就是"转半圈的掉头 / 反向"。

概念几何含义物理/现实含义

典型例题（自测）

  1. △ABC 绕点 O 顺时针旋转 90° 得到 △A′B′C′。（1）指出旋转中心、旋转方向、旋转角；（2）若 OA = 5，求 OA′；（3）判断 △ABC 与 △A′B′C′ 是否全等，为什么？
  2. 已知点 A 与点 A′ 关于点 O 中心对称，且 AO = 3。求 AA′ 的长，并说明 A、O、A′ 三点的位置关系。
  3. 判断下列图形哪些是中心对称图形：平行四边形、等腰三角形、圆、正三角形、线段、正六边形。
  4. △ABC 与 △A′B′C′ 关于点 O 中心对称，写出三对对应点；若 AB = 6，求 A′B′。
  5. 把等边三角形绕它的中心 O 旋转多少度能与自身重合？它是中心对称图形吗？为什么？
  6. 举出三个"既是轴对称图形又是中心对称图形"的例子，并分别写出它们的对称轴和对称中心。

常见误区

  • ❌ "旋转 180° 与轴对称（翻折 180°）是一回事" → ❌ 轴对称沿直线翻折，中心对称绕点旋转，对称元素不同（直线 vs 点）。
  • ❌ "中心对称图形就是轴对称图形" → ❌ 二者互不包含：一般的平行四边形是中心对称但不是轴对称；等腰三角形是轴对称但不是中心对称。
  • ❌ "正三角形是中心对称图形" → ❌ 正三角形绕中心转 180° 不能与自身重合，它只是轴对称图形。
  • ❌ "对应点到旋转中心的距离相等" 理解成 "对应点之间的距离相等" → ❌ 是"到中心的距离"相等（OP = OP′），不是任意两点间的距离都相等。
  • ❌ "旋转角一定小于 180°" → ❌ 旋转角可以是任意角度，如 270°、360°。
  • ❌ "两个全等图形一定关于某点中心对称" → ❌ 全等 ≠ 中心对称，还要求每一对对应点的连线都经过同一个点、且被该点平分。

课本外 · 典故与思考

趣每一片雪花都是六边形——"旋转对称"的自然招牌（点击展开）

雪花结晶几乎都是六角形：绕中心转 60°、120°、180°……都能与自身重合，这是一种旋转对称（转 180° 能重合，所以它还是中心对称图形）。

1611 年，天文学家开普勒写了一篇著名的短文《关于六角雪花的论说》。他既没有显微镜，也说不清原因，却认真地推理：雪花既然总是六角的，说明自然界里有一种"整齐划一"的力量。如今我们知道，答案藏在水分子里——冰晶按固定的角度结合，长出了正六边形的骨架。

不止雪花：食盐的晶体、石英、石榴石……矿物学里专门用"对称性"给晶体分类，旋转对称是其中最基本的类型之一。

一句话总结：本章学的"绕中心转 180° 与自身重合"不是练习题里的雕虫小技——它是从雪花到晶体的世界级美学。
史两千年前的"天文计算机"：满身都是齿轮（点击展开）

1901 年，潜水员在希腊安提基特拉岛附近的海底打捞出一台锈成一团的青铜装置。科学家研究了几十年才发现：它内部装着数十个青铜齿轮，互相咬合转动，能模拟月亮的运行、预测日食，甚至能计算 223 个朔望月的"沙罗周期"。

它大约制造于公元前 150 年左右，比欧洲文艺复兴时的机械钟早了 1500 多年，被称为"世界上第一台模拟计算机"。齿轮传动靠的，正是我们这一章讲的旋转：每个齿轮绕自己的轴旋转，齿与齿咬合，把转动精确地一级一级传下去。

有意思的是，如此精巧的技术后来似乎失传了，直到 14 世纪的机械钟才"重新发明"了它。

一句话总结：旋转不只是几何课上的概念——它是人类第一台精密机器的心脏。

  4. （中心对称作图）用直尺和圆规作出点 A 关于对称中心 O 的对称点 A′，并写出简要作法。

二、参考答案（点击展开）

查看第1题答案

旋转中心是点 O，旋转方向是逆时针，旋转角是 60°。描述一次旋转必须同时说清"中心、方向、角度"三个要素，缺一不可。

查看第2题答案

OP′ = OP = 4（对应点到旋转中心的距离相等）；∠QOQ′ 等于旋转角（对应点与旋转中心连线所成的夹角等于旋转角）；旋转前后的图形全等，因为旋转是保距保形的等距变换，形状、大小都不变。

查看第3题答案

AA′ = 2AO = 10。A、O、A′ 三点共线，且点 O 是线段 AA′ 的中点（对称点连线经过对称中心且被对称中心平分）。

查看第4题答案

作法：① 连接 AO；② 延长 AO 到 A′，使 OA′ = OA；③ 点 A′ 即为所求。一句话概括：连点 → 延长 → 取等长。

查看第5题答案

是中心对称图形的有：线段（对称中心为线段中点）、平行四边形（对角线交点）、圆（圆心）、正六边形（图形中心）。等腰三角形、正三角形不是中心对称图形（它们只是轴对称图形）。

查看第6题答案

"既是轴对称又是中心对称"的例子：线段（轴为垂直平分线、中心为中点）或圆、正方形；"是中心对称但不是轴对称"的例子：一般的平行四边形。正三角形绕中心旋转 120°（或 240°、360°）能与自身重合；它不是中心对称图形，因为绕中心转 180° 后不能与自身重合。
