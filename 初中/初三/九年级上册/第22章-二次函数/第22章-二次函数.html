第22章 二次函数

初中 / 初三 / 九年级上册

一句话总纲：二次函数 y = ax² + bx + c（a≠0）的图象是一条抛物线：顶点是它的最高点或最低点，对称轴把它分成左右镜像对称的两半，而与 x 轴的交点正是对应一元二次方程 ax² + bx + c = 0 的根。学完本章，你要能把一个代数式在脑中"画"成一条抛物线——开口方向、顶点、对称轴、与坐标轴的交点一眼看穿，并把它还原成抛体运动、最优化利润、最省材料等真实问题。

22.1 二次函数的概念

定义

形如

y = ax² + bx + c    (a、b、c 是常数，a ≠ 0)

的函数叫做二次函数。其中 ax² 叫二次项，a 叫二次项系数；bx 叫一次项，b 叫一次项系数；c 叫常数项。

  • 为什么 a ≠ 0？若 a = 0，则 y = bx + c 就退化成一次函数（直线），不再是"二次"。
  • b、c 可以等于 0。例如：y = x²（b=c=0）、y = −3x² + 1（b=0）、y = x² + 2x（c=0）都是二次函数。
  • 判断依据：看化简后的解析式中，自变量 x 的最高次数是否为 2，且二次项系数不为 0。
几何含义：二次函数 y = ax² + bx + c 的图象是一条抛物线——光滑的"U"形或倒"U"形曲线。二次项 x² 让图象"弯曲"（产生曲率），一次项 bx 和常数项 c 只负责移动它的位置、不改变"弯曲的形状"（形状只由 a 决定）。
物理含义：抛体运动的高度随时间变化就是二次函数。例如竖直上抛：h(t) = −½gt² + v₀t + h₀（g 是重力加速度，v₀ 是初速度，h₀ 是初始高度）。这里的 −½g 相当于 a（负的，开口向下），v₀ 相当于 b，h₀ 相当于 c。x² 项对应"匀加速运动"——位移与时间的平方成正比，这正是"越落越快、越走越远"的数学本质。

a 决定开口方向与开口大小

  • a > 0：开口向上，图象像"碗"/"U"，顶点是最低点。
  • a < 0：开口向下，图象像"∩"，顶点是最高点。
  • |a| 越大，开口越窄（越"瘦高"）；|a| 越小，开口越宽（越"扁平"）。|a| 相同则形状完全相同，只是方向或位置不同。
y = 2x²   开口向上、较窄（陡）
y = x²    开口向上、标准
y = ½x²   开口向上、较宽（缓）
y = −x²   开口向下（与 y = x² 关于 x 轴镜像对称）

c 决定与 y 轴的交点

y = ax² + c 的图象与 y 轴交于点 (0, c)：c > 0 时整体上移，c < 0 时整体下移。当 b = 0 时，对称轴就是 y 轴（直线 x = 0）。

几何含义（抛物线为什么叫"抛物线"）：从更高角度看，抛物线是"到定点（焦点）与到定直线（准线）距离相等的点的轨迹"，因此它天生具有完美的轴对称性。初中只需记住直观结论：抛物线是"U"形或倒"U"形的光滑曲线，关于过顶点的竖直直线左右对称。
物理含义（为什么抛出的物体走抛物线）：斜抛或平抛物体（不计空气阻力）在水平方向做匀速直线运动（x = v₀t），竖直方向受重力做匀加速运动（y = −½gt²）。把时间 t 消去后，竖直位移 y 恰好是水平位移 x 的二次函数——所以投篮、跳水、喷泉、炮弹的轨迹都是抛物线。a = −½g < 0 说明重力总把轨迹"往下拉"，所以开口向下。

22.3 顶点与对称轴（配方法）

顶点式：一眼读出顶点与对称轴

把一般式配方，可以写成顶点式：

y = a(x − h)² + k     （顶点为 (h, k)，对称轴为直线 x = h）
  • 顶点：抛物线与对称轴的交点，是图象的"拐弯点"（最高点或最低点）。
  • 对称轴：过顶点、垂直于 x 轴的直线 x = h，把抛物线分成左右镜像对称的两半——在对称轴两侧等距离处的两个点，纵坐标相同。
  • 注意符号：y = a(x + 2)² + 1 的顶点是 (−2, 1)，因为 x + 2 = x − (−2)，即 h = −2。

配方法（把一般式化为顶点式）

步骤：① 提出二次项系数 a；② 配上"一次项系数一半的平方"；③ 整理常数。

例：y = 2x² − 8x + 5
   = 2(x² − 4x) + 5              ← 提出 2
   = 2(x² − 4x + 4 − 4) + 5      ← 加上并减去 (4÷2)² = 4
   = 2(x − 2)² − 8 + 5           ← 前三项凑成完全平方
   = 2(x − 2)² − 3
∴ 顶点 (2, −3)，对称轴 x = 2，开口向上（a=2 > 0）。

一般式下的顶点公式（直接套用）

对称轴：x = −b / (2a)
顶  点：( −b/(2a) , (4ac − b²)/(4a) )

其中顶点纵坐标也常记作 (4ac − b²)/(4a)。用公式验证上例：a=2, b=−8, c=5，得 x = −(−8)/(2×2) = 2，y = (4×2×5 − 64)/(4×2) = (40−64)/8 = −3，与配方结果一致。

a、b、c 各自的作用小结

系数作用几何/物理直观
a决定开口方向与开口大小（形状）a>0 开口向上（碗）；a<0 开口向下（重力拉弯）；|a| 定胖瘦
b（与 a 配合）决定对称轴位置 x = −b/2a把顶点左右平移；b=0 时顶点恰好在 y 轴上
c决定与 y 轴交点 (0, c)图象的"纵向起点"；对抛体就是初始高度 h₀
几何含义（平移）：y = a(x − h)² + k 的图象，就是由最基本的 y = ax² 向右平移 h 个单位、再向上平移 k 个单位得到的（h > 0 向右、h < 0 向左；k > 0 向上、k < 0 向下）。注意是 (x − h)，所以"减 h 反而向右"——这是初学者最容易记反的一点。
物理含义：对抛体运动，顶点就是轨迹的最高点（a < 0 时），此刻竖直速度为零、物体由"上升"转为"下降"；对称轴 x = h 对应"到达最高点的时刻"左右的时间对称——上升和下降花费同样的时间，同一高度总对应上升、下降两个对称时刻。

22.4 最值

顶点处取最值

因为顶点是抛物线的最高点或最低点，所以二次函数的最值一定在顶点取得：

  • a > 0（开口向上）：顶点是最低点。当 x = −b/2a 时，y 取最小值 (4ac − b²)/(4a)；因为图象向上无限延伸，没有最大值。
  • a < 0（开口向下）：顶点是最高点。当 x = −b/2a 时，y 取最大值 (4ac − b²)/(4a)；因为图象向下无限延伸，没有最小值。
例：y = −2x² + 8x − 6 （a = −2 < 0，开口向下）
   x = −8 / (2×(−2)) = 2
   y_max = (4×(−2)×(−6) − 64) / (4×(−2)) = (48 − 64)/(−8) = 2
∴ 当 x = 2 时，y 有最大值 2。

自变量有取值范围时要"分段讨论"

若题目限定 x 在某个区间内（如 0 ≤ x ≤ 10），则最值未必恰在顶点：

  1. 先看顶点横坐标是否落在给定区间内——在，则顶点处取到区间内的极值；
  2. 再比较两个端点的函数值；
  3. 在"顶点值 + 两端点值"中，最大者为最大值、最小者为最小值。
几何含义：最值就是图象上最高点/最低点的纵坐标，也就是顶点的 y 坐标。找最值 = 找抛物线的"顶"。有范围限制时，相当于把抛物线"切下一段"，要看这段上的最高/最低点在哪里。
物理含义：最大高度（投篮最高点、烟花最高点）、最大利润（卖多少件最赚钱）、最小成本（怎样造最省料）、最大面积（怎样围地最大）——所有"最优化"问题的本质都是求顶点纵坐标。

22.5 与一元二次方程的关系

交点就是"根"

求抛物线 y = ax² + bx + c 与 x 轴的交点，就是令 y = 0，即解一元二次方程 ax² + bx + c = 0。抛物线与 x 轴交点的横坐标，就是对应方程的根。

判别式 Δ 决定交点个数

Δ = b² − 4ac

Δ > 0  →  与 x 轴有 2 个交点，方程有两个不相等的实根
Δ = 0  →  与 x 轴有 1 个交点（顶点恰好落在 x 轴上，相切），方程有两个相等的实根（一个根）
Δ < 0  →  与 x 轴没有交点，方程没有实数根（图象整体在 x 轴上方或下方）

交点式

若抛物线与 x 轴的两个交点横坐标为 x₁、x₂，则解析式可写成：

y = a(x − x₁)(x − x₂)    （交点式，a ≠ 0）

已知与 x 轴交点求解析式时，用交点式再代入另一点求 a，往往比一般式更快。

延伸到不等式

ax² + bx + c > 0 的解集，对应图象在 x 轴上方的部分对应的 x 范围；< 0 对应图象在 x 轴下方的部分。结合开口方向和两个交点（或判别式）即可写出解集。

几何含义：方程的根 = 抛物线与 x 轴（水平线 y=0）交点的横坐标；判别式 Δ 刻画的是"抛物线是否够到 x 轴、是穿过还是相切"。Δ < 0 时抛物线"悬在空中"或"整体浸在水下"，碰不到 x 轴。
物理含义：对抛体运动 h(t) = 0 就是问"什么时候落地"，解一元二次方程得到两个时刻 t₁（通常是起点）和 t₂（落地时刻）。Δ < 0 意味着物体永远到不了该高度（例如求它何时到 10 米，但它最高只有 8 米）；交点式则直接告诉你"起点和落点"两个水平位置。

22.6 二次函数的应用

应用一：面积最值（几何）

用一段定长的篱笆围矩形，何时面积最大？设一边长为 x，另一边由总长确定，面积 S 是关于 x 的二次函数，配方求顶点即得最大面积。结论：周长一定时，正方形面积最大。

应用二：利润最值（经济/物理量）

总利润 = (售价 − 成本) × 销量。销量常随售价上升而下降（线性关系），代入后利润就是售价的二次函数，开口向下，顶点即最大利润与对应的最优售价。

应用三：抛体与桥梁（物理）

投篮、喷泉、炮弹轨迹、拱桥、隧道截面都可抽象为抛物线，用顶点求最大高度，用与 x 轴交点求落地位置或跨度。

通用解题步骤

  1. 设变量：明确自变量 x（如边长、售价、时间）与因变量 y（面积、利润、高度）；
  2. 列函数：根据等量关系写出 y = ax² + bx + c；
  3. 求顶点 / 交点：用配方法或顶点公式求最值，令 y = 0 求与 x 轴交点；
  4. 检验实际意义：答案是否在自变量的合理范围内、是否为正、是否符合题意。
几何 + 物理的合一：所有二次函数应用题，本质上都是"画一条抛物线，然后找它的顶点（最值）或与 x 轴的交点（临界条件）"。顶点回答"最好/最坏能到多少"，交点回答"什么时候发生、在哪里发生"。

典型例题（自测）

  1. 已知 y = −2x² + 8x − 6，求：开口方向、对称轴、顶点坐标、与 x 轴和 y 轴的交点、最大值，并画出草图。
  2. 用配方法把 y = x² − 6x + 5 化为顶点式，写出顶点与对称轴。
  3. 抛物线与 x 轴交于 (−1, 0)、(3, 0)，且经过点 (0, −3)，求它的解析式（提示：用交点式）。
  4. 用 20 米长的篱笆围成一个矩形，求长、宽各为多少时面积最大，最大面积是多少？
  5. 判断 y = x² + 2x + 3 与 x 轴的交点个数；若方程 x² + 2x + 3 = 0 无实根，说明抛物线在 x 轴的上方还是下方。
  6. 一枚烟花以 h(t) = −5t² + 20t + 1（米）上升，求它到达的最大高度和所需时间，以及它何时落地（取正根）。

常见误区

  • ❌ "二次函数中 a 可以等于 0" → ❌ a = 0 时退化为一次函数（直线），不再是二次函数。
  • ❌ "顶点横坐标是 b/2a" → ❌ 漏了负号，应为 x = −b/2a。
  • ❌ "开口向上一定有最大值" → ❌ 开口向上是最小值，图象向上无限延伸，没有最大值；开口向下才有最大值。
  • ❌ "对称轴永远是 y 轴" → ❌ 只有 b = 0 时对称轴才是 y 轴（x = 0），一般情况是 x = −b/2a。
  • ❌ "抛物线与 x 轴一定相交" → ❌ Δ < 0 时没有交点，图象整体在 x 轴上方或下方。
  • ❌ "求最值直接代入区间端点" → ❌ 要先判断顶点是否落在自变量取值范围内，再与端点值比较。
  • ❌ "y = (x+2)² + 1 的顶点是 (2, 1)" → ❌ 顶点是 (−2, 1)，因为 x+2 = x−(−2)，h = −2。
  • ❌ "方程有两个实根 = 抛物线与 x 轴有两个交点，方程一个根 = 一个交点" → 严格说 Δ=0 是"两个相等实根"，对应抛物线与 x 轴"相切于一点"。

本章练习卷（含答案）

一、练习题

  1. 下列函数哪些是二次函数？并写出二次项系数 a：① y = 3x² − 2x + 1；② y = x + 5；③ y = −x²；④ y = (x + 1)(x − 1)。
  2. 比较 y = 2x²、y = ½x²、y = −2x² 三条抛物线的开口方向与开口大小，并说明系数 a 各起什么作用。
  3. 用配方法把 y = x² − 4x + 1 化为顶点式，写出顶点坐标与对称轴。
  4. 已知 y = −x² + 6x − 5，求它的对称轴、顶点坐标、最大值，以及与 x 轴交点的横坐标。
  5. 抛物线与 x 轴交于 (1, 0)、(5, 0) 两点，且经过点 (0, −5)，用交点式求它的解析式，并判断开口方向。
  6. 用 40 米长的篱笆靠墙围一个矩形（一边靠墙，只围其余三边）。问长、宽各为多少时面积最大？最大面积是多少？并结合"顶点是抛物线的最高点"解释为什么这样取。

二、参考答案（点击展开）

查看第1题答案

① 是二次函数，a = 3；② 不是（x 的最高次数是 1，为一次函数）；③ 是二次函数，a = −1（此时 b = c = 0）；④ 展开得 y = x² − 1，是二次函数，a = 1。判断依据：化简后自变量 x 的最高次数为 2，且二次项系数不等于 0。

查看第2题答案

y = 2x² 开口向上、最窄（|a|=2 大，越"瘦高"）；y = ½x² 开口向上、最宽（|a|=½ 小，越"扁平"）；y = −2x² 开口向下，与 y = 2x² 关于 x 轴镜像对称。a 的正负决定开口方向（a>0 向上、a<0 向下），|a| 决定开口大小（越大越窄、越小越宽）。

查看第3题答案

y = x² − 4x + 1 = (x² − 4x + 4) − 4 + 1 = (x − 2)² − 3。所以顶点坐标为 (2, −3)，对称轴为直线 x = 2。步骤要点：先配"一次项系数一半的平方"即 (4÷2)² = 4，加上再减去，再整理常数。

查看第4题答案

a = −1 < 0，开口向下。对称轴 x = −b/(2a) = −6/(2×(−1)) = 3；顶点纵坐标 y = −9 + 18 − 5 = 4，顶点为 (3, 4)，最大值为 4。令 y = 0：−x² + 6x − 5 = 0，即 x² − 6x + 5 = 0，因式分解 (x − 1)(x − 5) = 0，得与 x 轴交点横坐标为 x = 1 和 x = 5。

查看第5题答案

用交点式 y = a(x − 1)(x − 5)。代入 (0, −5)：−5 = a(0 − 1)(0 − 5) = 5a，得 a = −1。所以解析式为 y = −(x − 1)(x − 5) = −x² + 6x − 5。因为 a = −1 < 0，开口向下。

查看第6题答案

设垂直墙的两条边各为 x 米，则靠墙那条边长为 40 − 2x 米。面积 S = x(40 − 2x) = −2x² + 40x。这是开口向下的二次函数，顶点即最大值：x = −40/(2×(−2)) = 10，此时靠墙边 40 − 2×10 = 20。最大面积 S = 10 × 20 = 200（平方米）。所以宽 10 米、长 20 米时面积最大，为 200 平方米。解释：a = −2 < 0，抛物线开口向下，顶点是它的最高点，最高点的纵坐标就是面积的最大值。
